## 0. 執行摘要

### 一句話結論
> 全市場嚴格符合"淨現金 ≥ 市值"的標的約 **40-50 家**（A股 < 5 / 港股約 174 家但公開渠道僅識別 12 家 / 美股約 30 家）。其中真正值得深入研究的"股東友好 + 商業質量可驗證"的 Tier 1 候選僅 **4 家**，其餘多數為價值陷阱高發區（燒錢 biotech、港股老千嫌疑、中概退市風險、國企沉睡現金池）。

### 結構性發現
1. **A股淨現金池已近枯竭**：經過 2025 年 A 股總市值 +46% 的上漲、小微盤 +36%，嚴格口徑候選僅剩個位數，且多為國資沉睡現金。
2. **港股是"淨現金折價"系統性富礦**：約 20% 非金融非地產公司現金已高於市值（174 / 879 家），但公開 WebSearch 拿不到完整名單（需 Wind / 烏龜量化 / Bloomberg 等付費終端）。
3. **美股集中在 biotech + 中概**：Nasdaq Biotech Index 約 25% 成員市值低於現金，活動投資人估計被"鎖死"的淨現金價值約 300 億美元。
4. **股東友好度是核心分化點**：同樣"淨現金 ≥ 市值"，分紅/回購記錄直接決定是真折價還是價值陷阱。

## 1. 篩選方法

### 1.1 嚴格口徑（本報告採用）
```
淨現金 = 貨幣資金 + 交易性金融資產 + 其他短期投資 − 有息負債（長短期借款 + 應付債券）
篩選：淨現金 ≥ 當前總市值
```

### 1.2 寬口徑（部分數據源使用，本報告標註區分）
```
NCAV（格雷厄姆淨流動資產）= 流動資產 − 總負債
篩選：NCAV ≥ 市值（含應收/存貨等非現金流動資產，口徑更寬泛）
```

### 1.3 硬性排除規則
- **金融股**：銀行、保險、券商、信託、資管、融資租賃、消費金融
- **房地產股**：開發商、物業管理、REITs、商業地產
- **理由**：這兩類行業"現金"對應準備金/預收款/負債，與工業股淨現金口徑不可比

### 1.4 並行掃描架構
三個市場 Agent 並行 WebSearch，每個 Agent 獨立完成：
- 數據源 2-3 個交叉驗證
- 頭部 5 家抽查一手公告（HKEX 披露易 / SEC EDGAR / 巨潮資訊）
- 置信度標註（高 / 中 / 低）

## 3. Tier 1 四家深度要點

### 3.1 恆天立信（00641.HK）— 港股 — 紡織機械
**關鍵事實**
- 全球第二大紡織機械製造商
- 歷史派息比率 **43%**（港股淨現金折價股中股東回報記錄最清晰的一家）
- 2018 年數據：現金 5.97 億人民幣 + 流動資產 22.25 億 vs 市值 10.23 億港幣

**為什麼便宜**
- 紡織機械週期下行 + 國內同行價格戰
- 家族控股 + 港股小盤流動性折價

**核心盡調問題（買入前必答）**
1. **2024 / 2025 年報的最新現金和有息負債？**（掃描數據來自 2018 年，必須重新核對）
2. 近 3 年派息率是否維持 40%+？還是已經下調？
3. 家族控股股東持股比例？董事薪酬佔淨利潤比例？過去 5 年有無供股/配股？
4. 主業萎縮速度：紡織機械營收近 5 年 CAGR 多少？全球市佔率變化？

### 3.2 力勁科技（00558.HK）— 港股 — 壓鑄裝備
**關鍵事實**
- 亞洲最大壓鑄機製造商（特斯拉 Giga Press 一體化壓鑄供應商）
- 有中期股息派發（4.5 港仙/股）
- 2023 年財報：現金 6.29 億人民幣 + 流動資產 36.5 億 vs 市值 7.7 億港幣

**為什麼便宜 / 為什麼不再那麼便宜**
- 2024-2025 年一體化壓鑄商業化放緩、新能源車價格戰擠壓上游
- **但 2025 年已跟隨"人形機器人/鎂合金壓鑄"主題反彈 20%+**，**折價可能已部分收斂**

**核心盡調問題**
1. 以 2026-04-17 最新股價鎖定淨現金/市值倍數（是否仍 ≥ 1.0？）
2. 一體化壓鑄的長期競爭格局：特斯拉自研壓鑄產能的威脅？
3. 人形機器人鎂合金壓鑄訂單的真實性（是否已落地還是概念）？
4. 中期股息是否可持續？2024-2025 年派息率變化？

### 3.3 九毛九（09922.HK）— 港股 — 餐飲
**關鍵事實**
- 太二酸菜魚 + 慫火鍋 + 九毛九西北菜母公司
- **有分紅、有回購記錄**（管理層低位回購動作可見）
- 輕資產模式，歷史盈利沉澱 + 上市募資堆積現金

**為什麼便宜**
- 太二同店銷售連續下滑（2023-2025）
- 慫火鍋擴張期虧損
- 餐飲行業整體消費降級承壓

**核心盡調問題**
1. 最新季度同店銷售（SSS）和單店模型（RevPASH / AUV）趨勢
2. 管理層資本配置選擇：回購 vs 新店擴張的比例（歷史 + 未來計劃）
3. 太二的品牌護城河是否正在消失？（從"人均等位 3 小時" → "流量下滑"）
4. 現金用途：是"還給股東"還是"燒在門店擴張"？

### 3.4 PHAT — Phathom Pharmaceuticals — 美股 — 已商業化 biotech
**關鍵事實**
- 主產品 Voquezna（vonoprazan）— 新型鉀離子競爭性酸阻滯劑（P-CAB），2024 年 FDA 批准用於 GERD
- 2025 年放量中，**現金流轉正在望**（不是典型燒錢 biotech）
- 現金 > 4 億美元 vs 市值近似

**為什麼便宜 / 為什麼合理**
- Biotech 商業化早期都會經歷"產品上市 → 銷售爬坡 → 市場懷疑期"
- GERD 市場已有 PPI（質子泵抑制劑）多年主導，新產品滲透率爬升速度未驗證
- 但 Voquezna 在日本 Takeda 版本（Takecab）已證明商業成功

**核心盡調問題**
1. Voquezna 2026 年 Q1 最新銷售數據（月度處方量、放量斜率）
2. 現金跑道：2026-2027 年能否實現 EBITDA 轉正？
3. 核心競品威脅：Takeda、其他 P-CAB 管線
4. 專利週期 + 仿製藥威脅時點

## 4. Tier 2：高折價但需特定催化劑

### 4.1 SOHU（Sohu.com）— 淨現金/市值 2.67x，最極端
**觀點**：張朝陽控制下的"永久折價股"
- 12 億美元現金 vs 4.5 億市值，折價極端
- 核心利潤源暢遊（天龍八部端遊）已出售給張朝陽個人相關公司（2020），剩餘業務持續虧損
- 張朝陽長期回購但從不派息，小眾個人風格
- **關鍵判斷**：如果你相信張朝陽會私有化或特別分紅，是超額收益機會；否則現金會被慢慢燒掉
- **段永平視角**：這不是好生意（互聯網門戶衰退 + 管理層資本配置記錄差）

### 4.2 DQ（Daqo New Energy）— 淨現金/市值 1.54x
**觀點**：光伏週期底部博弈
- 21.5 億美元淨現金 vs 14 億市值
- 但 2025 年虧損 3.9 億、FCF -4.2 億 → **現金正在被燒**
- 光伏多晶硅產能過剩嚴重，週期見底時點高度不確定
- **關鍵判斷**：淨現金墊能撐幾輪週期？多晶硅價格何時反彈？
- **巴菲特視角**：強週期 + 商品屬性 + 燒錢，不符合"好生意"

### 4.3 江蘇國泰（002091）— 淨現金/市值 1.4x
**觀點**：國資沉睡現金池
- 226 億現金+理財 vs 130 億市值
- 紡服供應鏈主業停滯 + 鋰電材料子公司（瑞泰新材）下行週期
- **釋放節奏取決於國企市值管理政策**，個人股東無話語權
- **段永平視角**：國企"把錢還給股東"的概率歷史上接近零

### 4.4 ARVN（Arvinas）— 淨現金/市值 1.4-1.7x
**觀點**：有 Pfizer 分成背書的 biotech 相對安全
- PROTAC 蛋白降解龍頭
- 與 Pfizer 合作 vepdegestrant（ER+ 乳腺癌）有里程碑金 + 分成
- 現金跑道至 2028 下半年
- **李錄視角**：商業化前的 biotech 本質是"彩票"，即使有淨現金保護

### 4.5 VASO Corp — 淨現金/市值 1.09x
**觀點**：小盤高質量，但流動性問題
- 市值 $23M，現金 $25M，無重大負債
- **有實質醫療 IT 業務**（非空殼）
- 流動性極差（微盤），機構無法建倉
- **適合小額個人配置**，不適合任何規模化資金

## 5. 價值陷阱警示清單（Tier 3）

### 5.1 燒錢型臨床 Biotech（排除理由：不是"好生意"）
CRBP、ALDX、DSGN、ACHL、ADVM、EQ、ATRA、BCAB、EWTX、PHVS、MCRB、IBRX、CNTA、ANAB 等大量臨床階段 biotech：

**核心問題**：淨現金折價看起來誘人，但：
- 每季度燒 5000 萬-1 億美元
- 2-3 年內現金會被燒掉
- 催化劑（臨床讀數）是二元事件：成功則暴漲、失敗則清零
- **本質是期權而非價值投資**

**投資建議**：除非對某個 biotech 技術有深度專業判斷，否則**一律迴避**。

### 5.2 港股老千股高發區
港股小市值 + 控股股東持股 > 50% + 連續多年不分紅不回購 + 頻繁關聯交易/供股配股 = 老千嫌疑。

**本掃描特別警示**：
- **兆科眼科-B（06622.HK）**：淨現金/市值 180% 最極端，但不分紅、李氏家族控股、持續燒錢、關聯交易密度高 → **典型港股偽菸蒂**
- **明源雲（01906.HK）**：累計跌 94%，現金正在被燒
- **通達集團（00698.HK）**：歷史關聯交易質疑

**原則**：**港股"淨現金折價" ≈ "老千股"高度重合**，174 家池子裡真正乾淨可投的可能不足 20%。

### 5.3 中概退市風險股
CANG（Cango）等已轉型 BTC 挖礦、LIZI（荔枝）等音頻直播小盤股：
- 業務本身持續虧損
- ADR 合規性和退市風險
- **不建議重倉**，僅適合套利性小倉位

### 5.4 A股造假歷史股
- **ST香雪（300147）**：關聯方佔款 48 億，賬面現金是幻覺 → 剔除範例
- 需要檢查所有候選股歷史是否有證監會立案、審計保留意見

### 5.5 大宗供應鏈"假現金"

## 7. AI 研究侷限性聲明

### 7.1 AI 能做什麼
- ✅ 快速彙總多個公開數據源的候選清單
- ✅ 識別宏觀結構性信號（港股 174 家系統性折價、biotech 板塊性折價）
- ✅ 按規則機械篩選（排除金融/地產）
- ✅ 標註價值陷阱的典型信號

### 7.2 AI 不能做什麼
- ❌ 訪問 Wind / Bloomberg / 烏龜量化 等付費終端
- ❌ 實時跑全市場數據庫（只能搜第三方整理的名單）
- ❌ 穿透底層資產（貨幣資金中的受限部分、理財背後的非標）
- ❌ 識別真正的老千股（需要多年跟蹤和業內信息）
- ❌ 判斷管理層誠信（需要和人接觸、訪談、觀察）

### 7.3 資料多 ≠ 確定性高，資料少 ≠ 確定性低
- **美股 biotech 資料最多**，但確定性最低（臨床二元事件）
- **港股小盤資料最少**，但裡面可能藏著真正的菸蒂
- **確定性來自商業模式本身，不來自資料數量**
