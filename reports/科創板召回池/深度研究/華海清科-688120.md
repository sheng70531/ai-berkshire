# 華海清科（688120）深度投資研究

> 研究日期：2026年5月16日
> 市值：約946億元（用戶提供）/ 股價267.51元（2026年5月15日收盤）
> 定位：國產CMP（化學機械拋光）設備絕對龍頭

---

## 一、商業模式與競爭壁壘

### 1.1 主營業務與產品線

華海清科是國內唯一實現12英寸CMP設備規模化量產的企業，圍繞"裝備+服務"平臺化戰略，產品線已擴展至多個領域：

| 產品/業務 | 發展階段 | 說明 |
|-----------|---------|------|
| CMP拋光設備 | 成熟放量 | 核心基本盤，累計出機超1000臺（截至2026年4月） |
| 減薄設備 | 產業化早期爬坡 | 12英寸減薄貼膜一體機已批量發貨至多家龍頭 |
| 劃切設備 | 驗證推進中 | 半導體後道封裝環節 |
| 溼法/清洗設備 | 早期放量 | SiC清洗裝備、大硅片終端清洗裝備已驗證通過並實現銷售 |
| 離子注入設備 | 驗證推進中 | 前道核心設備，2025年大批量導入新品類 |
| 晶圓再生服務 | 擴產中 | 天津廠區20萬片/月，崑山擴建至40萬片/月，遠期總產能60萬片/月 |
| 關鍵耗材與維保 | 持續增長 | 設備保有量提升帶動的長尾收入 |

2025年半導體裝備收入佔總營收87.22%，CMP設備仍是絕對基本盤。

### 1.2 全球競爭格局

CMP設備全球市場高度集中，基本被美日兩家壟斷：

| 廠商 | 全球市佔率 | 覆蓋製程 |
|------|-----------|---------|
| 應用材料（美國） | 約64% | 覆蓋至3納米及以下 |
| 荏原（日本） | 約29% | 覆蓋至5納米 |
| 華海清科（中國） | 約7%（全球），國內約32%（2022年） | 量產至14納米，更先進製程驗證中 |

幾個關鍵觀察：

- **國內市場份額快速攀升**：華海清科國內市佔率從2019年的6.1%躍升至2022年的31.9%。在國產CMP設備銷售中佔據90%以上份額，國內幾乎沒有同體量競爭者。
- **12英寸成熟製程已站穩**：在12英寸成熟製程CMP設備中，公司市佔率從2020年的20.6%提升至2022年的46.7%，接近半壁江山。
- **中國CMP設備進口比例從2022年的89%降至2025年的63%**，國產化率提升至近四成。

### 1.3 與應用材料/荏原的技術差距

| 維度 | 華海清科 | 應用材料/荏原 |
|------|---------|-------------|
| 量產製程 | 14納米及以上（更先進製程驗證中） | 3-5納米及以下 |
| 拋光頭配置 | 7分區拋光頭（與國際同級） | 7分區拋光頭 |
| 差異化 | 拋光盤驅動方式、終點檢測、後清洗乾燥技術方案不同 | 技術方案更成熟 |
| 工藝覆蓋 | 邏輯、3D NAND、DRAM主流產品線 | 全品類全製程 |
| 毛利率 | 約42%（2025年） | 45%-47% |
| 收入規模 | 46億人民幣（2025年） | 應用材料約270億美元（FY2024） |

**關鍵判斷**：在已量產的成熟製程（14納米及以上），華海清科的CMP產品性能已可對標國際龍頭，實現一對一替代。但在先進製程（7納米以下，拋光步驟增至30餘道）方面，與應用材料/荏原仍有代際差距。先進製程驗證進展是未來成長性的關鍵變量。

### 1.4 護城河判斷

**（1）客戶粘性極高**

半導體設備驗證週期1-2年，一旦導入極難替換。公司產品已覆蓋中芯國際、長江存儲、長鑫存儲、華虹集團等國內主流晶圓廠產線，深度綁定。

**（2）國產替代具有"必選項"屬性**

在中美科技博弈背景下，下游晶圓廠被迫提高國產設備採購比重。華海清科作為國內唯一有規模化能力的CMP設備商，是國產替代的"唯一選項"。

**（3）規模與經驗壁壘**

累計出機超1000臺CMP裝備，積累了大量工藝數據和現場調試經驗，這是後來者難以短期複製的。國內競爭者晶亦精微主要聚焦8英寸，12英寸尚在驗證階段，短期構不成威脅。

**但另一方面**，護城河的"深度"需要打問號：CMP設備在半導體前道設備中的技術難度和價值量，低於光刻機、刻蝕機、薄膜沉積設備。如果國際巨頭在中國市場加大降價力度，公司的競爭優勢可能被壓縮。

## 二、財務質量分析

### 2.1 營收與利潤趨勢

| 年度 | 營收（億元） | 同比增速 | 歸母淨利潤（億元） | 同比增速 | 毛利率 |
|------|------------|---------|------------------|---------|--------|
| 2022年 | 16.49 | +104.9% | 5.02 | +153.0% | 約48% |
| 2023年 | 25.08 | +52.1% | 7.27 | +45.0% | 46.0% |
| 2024年 | 34.06 | +35.8% | 10.23 | +41.4% | 43.2% |
| 2025年 | 46.48 | +36.5% | 10.84 | +5.9% | 41.8% |
| 2026Q1 | 12.01 | +31.7% | 2.47 | +6.0% | — |

（數據來源：公司年報、季報）

2020-2025年營收複合增長率超60%，歸母扣非淨利潤複合增長率超130%，增長軌跡極為亮眼。

**但2025年出現了一個顯著信號：營收增速（36.5%）與利潤增速（5.9%）嚴重背離，收入增速是利潤增速的6倍以上**。這一背離延續到了2026Q1（營收+31.7%，淨利潤+6.0%），必須引起重視。

### 2.2 毛利率持續下滑

| 年度 | 毛利率 |
|------|--------|
| 2022年 | 約48% |
| 2023年 | 46.0% |
| 2024年 | 43.2% |
| 2025年 | 41.8% |

毛利率連續3年下滑，累計下降約6個百分點。原因分析：

- **新產品爬坡拉低整體毛利率**：減薄裝備、離子注入裝備、清洗裝備處於產業化早期，爬坡成本高、客戶導入期定價策略激進。
- **先進製程CMP設備驗證期讓利**：先進製程機型處於客戶驗證和初步放量階段。
- **規模效應尚不足以對沖新品拖累**。

值得注意的是，2025年毛利率41.8%已低於應用材料的45%-47%水平。如果毛利率繼續下滑，將對盈利能力構成實質性壓力。

### 2.3 資產負債表與現金流

| 指標 | 2025年數據 | 趨勢 |
|------|-----------|------|
| 資產負債率 | 43.23% | 同比下降1.62個百分點，尚屬健康 |
| 合同負債 | 17.55億元（2025H1） | 同比增長30.8%，在手訂單充足 |
| 存貨 | 37.03億元（2025H1） | 同比增長20.2% |
| 經營現金流淨額 | 8.0億元（2025全年） | 同比下降30.7% |
| 研發投入 | 5.43億元（2025年） | 同比增長38.0%，佔營收11.69% |

**現金流質量惡化是一個警示信號**：

- 2025年經營現金流淨額同比下降30.7%，經營現金流/淨利潤比值低於1。
- 2026Q1每股經營性現金流同比大幅下降59.1%至0.02元，盈利的現金含量明顯偏低。
- 應收賬款在2026Q1同比激增78.2%，遠超營收增速，可能反映回款壓力或下游客戶結算週期拉長。

**積極的一面**：合同負債17.55億元同比增長30.8%，作為預收款性質的先行指標，表明在手訂單充足，未來收入確定性較高。

## 三、成長性與估值

### 3.1 國產CMP設備替代空間

CMP是晶圓製造的核心工序之一，每片晶圓需要經過多道CMP拋光（先進製程需30道以上）。替代空間的核心驅動力：

- **中國大陸CMP設備市場空間**：預計2026年約14.7億美元（約106億人民幣），CMP耗材市場空間不低於11.8億美元。
- **國產化率仍有大幅提升空間**：CMP設備進口比例從2022年的89%降至2025年的63%，意味著國內廠商已拿下約37%的份額，但仍有63%的進口替代空間。
- **華海清科在國產CMP設備中份額超90%**，幾乎獨佔國產替代紅利。

簡單測算：假設中國CMP設備年市場空間100億元人民幣，國產化率從37%提升至60%，華海清科佔國產份額90%，則對應營收空間約54億元，與2025年46.48億元營收相比還有約15%的增量空間。若國產化率進一步提升至80%，空間約72億元。

**但另一方面**，這一測算僅考慮了存量替代。真正的增長彈性來自：（1）先進製程CMP步驟數大幅增加帶來的設備需求增量；（2）新建產線的增量需求；（3）晶圓再生、耗材服務等長尾收入。

### 3.2 先進製程拓展進展

- 公司CMP產品已覆蓋邏輯、3D NAND、DRAM主流產品線。
- 在HBM、三維堆疊等先進封裝工藝產線上已作為基準設備。
- 先進製程CMP機型出貨量增長顯著，但具體製程節點的突破程度（14納米以下）尚未披露明確量產數據。
- 2025年第1000臺CMP裝備出機，標誌從成熟製程批量進入國內先進製程大生產線。

### 3.3 平臺化擴展

公司從單一CMP設備向"裝備+服務"平臺化轉型，減薄、清洗、離子注入、晶圓再生等新業務線逐步貢獻增量收入。這既是成長空間的來源，也是當前毛利率下滑的原因——新品類處於爬坡期，盈利能力尚未釋放。

### 3.4 估值分析

| 估值指標 | 數據 |
|---------|------|
| 當前市值 | 約946億元（用戶提供） |
| 2025年歸母淨利潤 | 10.84億元 |
| 2025年PE（靜態） | 約87倍 |
| 2026E歸母淨利潤（東海證券預測） | 14.15億元 |
| 2026E PE | 約67倍 |
| 2027E歸母淨利潤（東海證券預測） | 18.45億元 |
| 2027E PE | 約51倍 |

**估值判斷**：

- 87倍靜態PE對應5.9%的淨利潤增速，估值與業績增速之間存在顯著背離。市場定價隱含了對公司未來3-5年高增長的強預期。
- 若2026年利潤增長至14億元級別（增速約30%），對應67倍PE，仍然不便宜。
- 參考可比公司：拓荊科技2025年營收65億、利潤增速更快，可對比估值水平。
- **核心問題**：2025年利潤增速僅6%，是階段性的（新品爬坡期投入加大導致），還是趨勢性的（競爭加劇、毛利率系統性下滑）？前者意味著當前估值可能合理，後者意味著估值可能偏高。

## 四、風險評估

### 4.1 核心風險矩陣

| 風險類別 | 具體描述 | 影響程度 |
|---------|---------|---------|
| **利潤增速與估值背離** | 2025年淨利潤僅增5.9%，靜態PE約87倍，若增速無法回升，估值面臨回調壓力 | 高 |
| **毛利率持續下滑** | 連續3年下滑6個百分點至41.8%，新品爬坡+競爭定價雙重壓力 | 高 |
| **客戶集中度高** | 前五大客戶銷售佔比64.07%（2025年），過度依賴少數大客戶 | 中高 |
| **應收賬款激增** | 2026Q1應收賬款同比增78.2%，遠超營收增速，回款質量存疑 | 中高 |
| **現金流惡化** | 2025年經營現金流下降30.7%，2026Q1經營現金流大降59.1% | 中高 |
| **先進製程技術追趕** | 與應用材料/荏原在7納米以下先進製程仍有代際差距 | 中 |
| **新品類擴張風險** | 減薄、離子注入、清洗等新賽道競爭格局不同於CMP，不確定性更高 | 中 |
| **國際巨頭降價競爭** | 若應用材料/荏原在中國市場降價搶份額，公司毛利率將進一步承壓 | 中 |
| **產能瓶頸** | 晶圓再生擴產需要時間，短期產能可能制約業務增長 | 低中 |

### 4.2 最大下行風險

**場景一：利潤增速無法恢復至20%以上**

如果2026-2027年淨利潤增速持續低於20%（2025年僅5.9%），當前87倍PE的估值基礎將瓦解。以30倍PE、15億利潤計算，對應市值約450億，較當前有約50%下行空間。

**場景二：先進製程驗證受阻+國際競爭加劇**

如果公司在14納米以下製程的CMP設備驗證進展不及預期，同時應用材料/荏原在成熟製程降價競爭，公司可能陷入"高端上不去、低端守不住"的困境。

### 4.3 積極因素

- 國產替代是確定性趨勢，CMP設備進口比例仍有63%的替代空間。
- 合同負債持續增長，在手訂單充足，短期收入增長有保障。
- 第1000臺CMP裝備出機，規模效應有望在中長期改善毛利率。
- 先進封裝（HBM、三維堆疊）帶來的增量需求是新的增長極。

## 五、綜合結論

### 定性判斷

華海清科是一傢俱有明確"國產替代"邏輯的稀缺標的：國內CMP設備幾乎唯一的規模化供應商，下游綁定國內主流晶圓廠，受益於國產化率提升的確定性趨勢。

**但當前面臨三個結構性問題需要持續跟蹤**：

1. **增收不增利**：2025年營收增36%但利潤僅增6%，是新品爬坡的階段性現象，還是競爭格局惡化的趨勢性信號？目前數據不足以下定論。
2. **毛利率能否企穩**：連續3年下滑6個百分點至42%以下，已低於國際可比公司。如果新產品放量後毛利率不能回升至44%以上，盈利能力將持續承壓。
3. **估值安全邊際不足**：87倍PE對應6%的利潤增速，市場對高增長的隱含預期與當前業績之間存在巨大落差。除非2026年利潤增速能回升至30%以上，否則當前估值缺乏支撐。

### 投資評級

當前階段：**觀察，等待利潤增速拐點確認**

- 如果2026年中報/三季報顯示利潤增速回升至25%以上、毛利率企穩在42%以上，可以考慮在60倍PE以下的價格介入。
- 如果利潤增速持續低於15%，則需要重新評估公司是否值得87倍PE的溢價。

### 關鍵跟蹤指標

| 指標 | 跟蹤頻率 | 關注方向 |
|------|---------|---------|
| 毛利率變化 | 每季度 | 是否企穩回升至42%以上 |
| 歸母淨利潤增速 | 每季度 | 是否回升至25%以上 |
| 合同負債 | 每半年 | 在手訂單是否持續增長 |
| 經營現金流/淨利潤比值 | 每季度 | 是否回升至1以上 |
| 應收賬款/營收比 | 每季度 | 是否回落至正常水平 |
| 先進製程CMP出貨佔比 | 每半年 | 先進製程收入佔比是否提升 |
| 新品類（減薄/離子注入）毛利率 | 每半年 | 爬坡期是否結束 |
| 前五大客戶集中度 | 每年 | 是否有新客戶導入分散風險 |
| 國內CMP設備國產化率 | 每年 | 進口替代進度 |
