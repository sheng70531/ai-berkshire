# 鼎通科技（688668）深度投資研究

> 研究日期：2026年5月16日
> 科創板召回池評級：四星
> 當前市值：約343億元
> 2025年營收/淨利潤：15.88億元 / 2.41億元

---

## 一、商業模式與競爭壁壘

### 1.1 主營業務拆解

鼎通科技成立於2010年，總部位於東莞，是一家專注於高速通訊連接器及其組件和汽車連接器及其組件的高新技術企業。公司的核心商業模式是為安費諾、莫仕、泰科等全球連接器巨頭提供精密零組件和代工服務。

**兩大業務板塊（2025年數據）：**

- **通訊連接器及組件（核心主業）**：2025年收入佔比約61%，產品包括CAGE（散熱外殼）、散熱器、Wafer、Housing、信號PIN等，廣泛應用於AI服務器、數據中心等高速通訊設備。傳輸速度從56G升級至112G，224G產品已開始量產。CAGE產品在通訊業務中佔比約71%。
- **汽車連接器及組件**：2025年收入佔比約26%，主要為比亞迪提供電控連接器和高壓連接器，同時開拓長安汽車等新客戶。

**產品傳輸速度升級路徑：** 56G → 112G → 224G。112G產品從2024年Q2起逐步放量，2025年成為主力；224G產品2025年下半年開始量產，2026年二、三季度加速放量。

### 1.2 客戶結構與供應鏈定位

**核心定位：全球連接器巨頭的Tier 2供應商**

鼎通科技處於AI算力產業鏈的中上游，其直接客戶為全球連接器巨頭，終端客戶為AI算力廠商：

| 直接客戶 | 終端客戶 |
|---------|---------|
| 安費諾 | 英偉達 |
| 莫仕 | 谷歌 |
| 泰科電子 | Meta |
| 富士康 | 思科 |
| 立訊精密 | 微軟 |
| 中航光電 | 國內數據中心 |

**供應鏈角色解析：**
- 在英偉達GB200機櫃中，CAGE、散熱器、背板線模組等是GPU和NVLinkSwitch互聯的核心組件
- 鼎通科技作為安費諾等巨頭的長期合作零組件供應商，負責生產殼體、散熱器、Wafer等精密零部件
- 本質上是"賣鏟子"的角色——不直接面對終端客戶，但受益於整個AI算力建設的大潮

### 1.3 行業競爭格局

**全球高速連接器市場格局：**

| 企業 | 定位 | 全球份額 |
|------|------|---------|
| 安費諾 | 全球龍頭 | 約25%+ |
| 泰科電子 | 全球第二 | 約20%+ |
| 莫仕 | 全球第三 | 約15%+ |
| 三家合計 | — | 約69% |
| 國內廠商合計 | 組件/代工為主 | 約31% |

**鼎通科技在國內的競爭位置：**
- 國內高速通訊連接器組件領域的領先企業
- 主要通過供應線材、組件及代工等方式進入全球市場
- 競爭對手包括永貴電器、維峰電子等國內精密連接器廠商
- 與安費諾等建立了10年以上的穩定合作關係，客戶壁壘較高

### 1.4 護城河分析

**客戶壁壘（強）：**
- 與安費諾、泰科、莫仕等全球前三大連接器廠商建立了長期穩固合作關係
- 連接器行業客戶認證週期長（通常12-24個月），一旦通過認證替換成本高
- 在英偉達GB200等關鍵產品上已經卡位，新進入者難以短期替代

**精密製造能力（中等）：**
- 224G產品對精密加工的要求極高，良率和交付能力是核心競爭力
- 液冷散熱產品的性能已獲得客戶認可，技術門檻在提升

**規模效應（中等）：**
- 隨著112G和224G產品放量，產能利用率提升帶來規模效應
- 但精密零組件行業的規模效應不如整機組裝明顯

**不足之處：**
- 本質上是Tier 2代工/零組件供應商，話語權和定價權有限
- 毛利率約30%，反映了代工型商業模式的固有侷限
- 對安費諾等大客戶的依賴度高，大客戶集中度風險明顯
- 相比安費諾等巨頭，自主品牌連接器業務極少

## 二、財務質量分析

### 2.1 近三年營收與利潤趨勢

| 年份 | 營業收入（億元） | 同比增長 | 歸母淨利潤（億元） | 同比增長 | 毛利率 | 淨利率 |
|------|----------------|---------|------------------|---------|--------|--------|
| 2023 | 7.35 | -8.5% | 0.57 | -49.1% | 約25% | 約7.7% |

| 2025 | 15.88 | 53.89% | 2.41 | 117.99% | 30.08% | 約15.2% |

**關鍵觀察：**
- 2023年受行業下行影響業績下滑，2024-2025年隨AI算力需求爆發強勁反彈
- 2025年營收和淨利潤均創歷史新高，淨利潤同比翻倍以上
- 毛利率從2023年約25%持續回升至30.08%，同比提升2.7個百分點，體現了產品結構升級和行業景氣度回升

**2026年Q1表現：** 營收4.57億元，同比增長20.78%；歸母淨利潤0.80億元，同比增長51.86%。112G和224G需求旺盛，液冷產品批量交付。

- 但30%的綜合毛利率在科創板中屬於偏低水平，反映了代工型商業模式的利潤天花板
- 與安費諾（毛利率約33-35%）相比，差距不大但在縮小

## 三、成長性與估值

### 3.1 未來增長驅動因素

**驅動因素一：AI算力建設持續拉動（確定性最高）**
- 英偉達GB200/B300等新一代AI服務器持續迭代，每次升級都帶來新的連接器需求
- 全球AI數據中心資本開支持續高增長，2026年預計保持30%+增速
- 112G產品需求旺盛，224G產品從2026年二季度開始加速放量

**驅動因素二：產品升級帶來量價齊升**
- 從56G到112G到224G，每代產品的單位價值更高
- 224G液冷散熱產品相比傳統風冷方案單價提升，散熱效率較風冷提升30%+
- 產品結構升級推動毛利率持續改善

**驅動因素三：液冷技術放量（彈性較大）**
- 液冷配套I/O連接器方案已定型，224G液冷散熱產品性能獲客戶認可
- AI服務器功耗持續增長，液冷方案滲透率從10%+向50%+提升是大趨勢
- 公司液冷產品已批量交付，2026年有望加速放量

**驅動因素四：汽車連接器穩健增長**
- 比亞迪電控和高壓連接器保持穩定增長
- 長安汽車電控連接器2026年開始量產
- 新能源汽車高壓化趨勢推動單車連接器價值量提升

### 3.2 行業空間

- 全球高速連接器市場規模約800億美元，AI相關連接器是增長最快的細分領域
- 中國連接器市場規模超2000億元，佔全球約32%
- AI服務器連接器市場2025-2028年複合增速預計超40%
- 液冷連接器是新增增量市場，2026年全球規模預計達百億元級別

### 3.3 當前估值水平

| 指標 | 數值 |
|------|------|
| 總市值 | 約343億元 |
| 2025年歸母淨利潤 | 2.41億元 |
| 靜態PE（基於2025年利潤） | 約142倍 |
| 2026年Q1年化淨利潤 | 約3.2億元（0.80億×4） |
| 滾動PE（簡單年化） | 約107倍 |

| 2026年動態PE | 約70-86倍 |

### 3.4 估值判斷

**樂觀情景：** 224G加速放量疊加液冷滲透率超預期，2027年淨利潤達7-8億元，給予50-60倍PE，對應市值350-480億元，當前價格處於合理下沿。

**中性情景：** 業績按正常增速兌現，2027年淨利潤5-6億元，給予45-55倍PE，對應市值225-330億元，當前估值偏貴。

**悲觀情景：** AI算力建設放緩或安費諾訂單轉移，2027年淨利潤3-4億元，給予30-40倍PE，對應市值90-160億元，存在巨大下行空間。

**綜合判斷：** 當前343億元市值對應2025年利潤142倍PE，估值極貴。雖然AI算力建設的大方向明確，但鼎通科技作為Tier 2零組件供應商，其商業模式的利潤天花板和話語權有限性決定了難以支撐如此高的估值倍數。當前價格隱含了極為樂觀的增長預期，安全邊際嚴重不足。

## 四、風險評估

### 4.1 商業模式天花板風險（核心風險）

鼎通科技本質上是連接器巨頭的代工/零組件供應商，不擁有自主品牌連接器，也不直接面對終端客戶。這種商業模式決定了：
- 話語權和定價能力有限，毛利率天花板約30-35%
- 依賴大客戶的訂單分配，議價空間小
- 安費諾等客戶有能力培育替代供應商，供應商可替代性較高
- 與安費諾等巨頭的毛利率差距雖在縮小，但"打工人"的本質未變

### 4.2 客戶集中度風險（較高）

安費諾等前五大客戶合計佔比預計在70%以上。如果核心客戶調整供應策略、引入競爭對手或自建產能，公司營收可能出現大幅波動。特別是在AI行業景氣度高漲時，客戶可能扶持多家供應商以分散供應風險。

### 4.3 AI算力週期波動風險（中等偏高）

AI算力建設具有明顯的資本開支週期性。當前全球雲廠商資本開支處於高景氣階段，但歷史表明這種高增長不可持續。一旦AI算力投資放緩（如大模型進步放緩、雲廠商削減開支），連接器需求可能出現斷崖式下滑。2023年公司營收下滑8.5%、淨利潤下滑49%的經歷已經說明瞭這一風險。

### 4.4 技術迭代風險（中等）

從112G到224G再到未來的448G，每次技術迭代都要求供應商跟上客戶的技術要求。如果公司在新一代產品的良率、成本、交付能力上落後於競爭對手，可能丟失份額。特別是銅纜連接向光互聯的長期趨勢可能從根本上改變市場格局。

### 4.5 估值風險（很高）

142倍靜態PE對於一家毛利率僅30%的零組件代工企業而言過於昂貴。市場給予的估值溢價主要來自AI算力的"主題熱度"，而非公司自身的商業模式壁壘。一旦市場熱度消退或業績增速放緩，估值迴歸可能非常劇烈。

### 4.6 最大的下行風險

**最大下行風險是"AI算力資本開支放緩 + 大客戶訂單調整 + 估值迴歸"的三重打擊。** 在這種情景下，公司可能重演甚至超過2023年的業績下滑。考慮到當前極高的估值倍數（142倍），悲觀情景下市值可能回落至100億元以下，對應當前股價70%以上的下行空間。

## 五、綜合結論

### 5.1 核心判斷

鼎通科技是AI算力建設浪潮的直接受益者，通過與安費諾、泰科、莫仕等全球連接器巨頭的深度合作，在112G/224G高速連接器組件領域建立了較強的客戶壁壘和製造能力。公司2025年業績翻倍增長，2026年一季度繼續保持50%+的利潤增速，處於高速成長期。

**但本質上這是一家代工型企業。** 30%的毛利率、對大客戶的高度依賴、有限的定價能力，這些都是商業模式的固有侷限。AI算力的主題熱度讓市場給予了遠超其商業模式應得的估值溢價。

### 5.2 是否值得深入跟蹤

**結論：行業趨勢明確，公司卡位不錯，但商業模式不夠優秀，當前估值嚴重偏貴，不建議在現價買入。**

建議納入觀察池，但應對這家公司保持更高的估值紀律：
1. 需要等待估值大幅回調至合理區間（PE 40-50倍）
2. 需要持續驗證毛利率能否突破35%，以證明商業模式在升級
3. 自主品牌連接器業務進展是判斷公司能否突破代工天花板的關鍵

### 5.3 關鍵觀察指標

| 指標 | 觀察要點 | 頻率 |
|------|---------|------|
| 112G/224G產品收入佔比 | 產品結構升級進度 | 每季度 |
| 綜合毛利率 | 能否突破35%大關 | 每季度 |
| 液冷產品收入 | 放量節奏和毛利率 | 每季度 |
| 前五大客戶集中度 | 客戶分散化進展 | 半年度 |
| AI服務器行業資本開支 | 先行指標，反映景氣度 | 每月 |
| 安費諾季度營收增速 | 間接反映鼎通科技的訂單趨勢 | 每季度 |
| 汽車連接器收入佔比 | 業務多元化進展 | 半年度 |

### 5.4 估值錨點

- **理想買入區間**：PE 30-40倍（基於未來一年預測利潤），對應市值120-200億元
- **合理持有區間**：PE 40-55倍
- **考慮賣出區間**：PE 80倍以上（當前已遠超）
