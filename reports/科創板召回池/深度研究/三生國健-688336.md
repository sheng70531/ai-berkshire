# 三生國健（688336）深度投資研究

> 研究日期：2026年5月16日
> 初篩評級：4星（科創板召回池）
> 定位：自免疫領域平臺型生物藥企業，輝瑞60億美元授權合作創國產創新藥首付款紀錄

---

## 一、商業模式與競爭壁壘

### 1.1 主營業務拆解

三生國健成立於2002年，2020年7月登陸科創板，是中國第一批專注於抗體藥物的創新型生物醫藥企業。公司是三生製藥（01530.HK）控股子公司，實控人為婁競。

**業務板塊梳理：**

| 板塊 | 主要產品/項目 | 2025年情況 |
|------|-------------|-----------|
| 成熟產品 | 益賽普（TNF-α抑制劑） | 集採壓力下價格下降，銷量有所增長 |
| 成長產品 | 賽普汀（CD20單抗）、健尼哌（IL-2R單抗） | 賽普汀增速放緩，健尼哌基數小增速快 |
| CDMO | 合同研發生產 | 約0.7億/半年（2024H1），增速約60% |
| 里程碑收入 | 輝瑞707項目授權 | 2025年確認約28.9億元首付款收入 |

**2025年全年業績：**
- 營業總收入42.0億元，同比增長251.8%
- 歸母淨利潤29.0億元，同比增長311.5%
- 扣非淨利潤27.7億元，同比增長1025.0%

**核心問題：扣除輝瑞授權收入後，常規業務體量如何？**

- 輝瑞707項目首付款確認收入約28.9億元
- 扣除後，常規業務營收約13.1億元
- 對比2024年營收約11.9億元，常規業務增長約10%
- 以2024H1數據推算（益賽普3.3億+賽普汀1.6億+健尼哌0.3億+CDMO 0.7億），常規產品年化約12-13億

**結論：剝離輝瑞一次性收入後，常規業務體量約13億元，增速約10%，體量偏小。**

### 1.2 輝瑞合作深度拆解

這是理解三生國健估值的關鍵。

**合作標的：707項目（SSGJ-707）**
- 靶點：PD-1/VEGF雙特異性抗體
- 技術平臺：基於公司自研CLF2平臺開發
- 臨床進展：2025年4月獲CDE突破性治療認定，加速一線NSCLC適應症開發
- II期數據：在NSCLC患者中ORR和DCR數據優異，安全性良好

**財務條款：**

| 項目 | 金額 |
|------|------|
| 首付款（不可退還） | 12.5億美元（約90億人民幣） |
| 開發/監管/銷售里程碑 | 最高48億美元 |
| 銷售分成 | 雙位數百分比梯度分成 |
| 合計最高交易金額 | 60.5億美元 |

**中國大陸選擇權：**
2025年7月，輝瑞獲得中國大陸獨家開發和商業化707的選擇權，期權金+行權金合計不超過1.5億美元。

**權益分配：**
707項目在三生國健體內的權益比例約30%（其餘70%歸三生製藥集團層面）。

**關鍵問題：後續里程碑能否兌現？**

- 48億美元里程碑需要707在全球多個適應症、多個監管區域獲批並達到特定銷售額才能全部觸發
- 首款適應症（一線NSCLC）面臨激烈競爭：阿斯利康Imfinzi+化療、默沙東Keytruda+化療等已是標準治療方案
- PD-1/VEGF雙抗賽道競爭者眾多（阿斯利康的AZD2936、禮來/信達的IBI363等）
- 樂觀情景下，後續里程碑可能分批在3-8年內逐步兌現
- 悲觀情景下，如果III期臨床數據不及預期，後續里程碑可能大幅縮水

### 1.3 自免管線評估

公司自2021年戰略轉型，聚焦自身免疫性疾病領域，目前在研22個自免項目。

**核心管線進展：**

| 項目代號 | 靶點 | 適應症 | 進展 |
|---------|------|--------|------|
| 608 | IL-17 | 銀屑病 | 2024年11月申報NDA |
| 610 | IL-5 | 成人哮喘 | III期入組中 |
| 611 | IL-4Rα | 特應性皮炎 | III期主要終點已讀出，預計2025H2申報NDA |
| 安沐奇塔單抗 | — | — | 2026年2月獲批上市 |

**管線評價：**

- 正面：管線覆蓋面廣，22個自免項目形成梯隊，608和611均接近商業化
- 但另一方面：靶點多為已驗證的"me-too"或"me-better"靶點（IL-17、IL-4Rα、IL-5），面臨度普利尤單抗（達必妥）、司庫奇尤單抗等重磅藥物的競爭
- 自免領域商業化需要龐大的學術推廣團隊和患者教育投入，三生國健的商業化能力尚待驗證

### 1.4 公司治理關注點

三生國健與母公司三生製藥（01530.HK）之間存在大量關聯交易和資產注入歷史。媒體曾報道"三次左手倒右手"的運作模式。707項目的權益僅30%歸屬三生國健，大頭在母公司層面。需關注關聯交易的公允性和少數股東權益保護。

## 二、財務質量

### 2.1 盈利能力分析（剝離輝瑞一次性收入）

| 指標 | 2023年 | 2024年 | 2025年（常規） | 2025年（含輝瑞） |
|------|--------|--------|---------------|----------------|
| 營業收入 | 約9.7億 | 約11.9億 | 約13.1億（估計） | 42.0億 |
| 歸母淨利潤 | 約1.7億 | 約7.0億 | — | 29.0億 |

- 常規業務收入約13億元，增速約10%，對應400億市值的PS約31倍
- 扣除輝瑞授權後的常規淨利潤難以準確計算（因為費用結構混合），但考慮到高研發投入（研發費用率約32%），常規業務的淨利潤體量可能僅2-4億元
- 2026Q1歸母淨利潤1.78億元，同比增長73%，但這是在2025Q1低基數上的增長

### 2.2 研發投入

2025Q1研發費用同比增長45.83%，研發投入佔營收比重32.20%。22個在研項目需要大量持續投入，這是把"雙刃劍"——既是未來管線的基礎，也意味著短期利潤承壓。

### 2.3 現金流與資產質量

輝瑞首付款12.5億美元（約90億人民幣，其中約28.9億歸屬三生國健確認為收入）帶來了充裕的現金。但這是一次性收入，需關注：
- 後續研發投入節奏是否會顯著加大
- 是否有分紅或回購計劃將現金回饋股東
- 母公司層面的資金調配是否影響上市公司利益

## 三、成長性與估值

### 3.1 增長驅動力

**短期（1-2年）：**
- 608（IL-17銀屑病）和611（IL-4Rα特應性皮炎）獲批上市後的商業化放量
- 安沐奇塔單抗（2026年2月已獲批）的銷售起步
- 707項目後續里程碑觸發的可能性（取決於全球臨床進展）

**中期（3-5年）：**
- 自免管線中多款產品陸續獲批，從單品公司向平臺型公司轉型
- 707項目如果全球獲批上市，銷售分成將帶來持續收入流

**遠期：**
- 如果自免平臺驗證成功，更多創新靶點進入臨床
- 707全球銷售分成的長期貢獻

### 3.2 估值判斷

| 指標 | 數值 |
|------|------|
| 當前市值 | 約412億元 |
| 2025年歸母淨利潤（含輝瑞） | 29.0億元 |
| 表觀PE（含輝瑞） | 約14倍 |
| 常規業務估計淨利潤 | 2-4億元（估計） |
| 常規業務PE | 100-200倍（估計） |
| 動態PE（2026年3月數據） | 約66倍 |

**估值的核心矛盾：**

- 表面看PE僅14倍，非常便宜。但輝瑞28.9億首付款是一次性的，不可持續。
- 剝離輝瑞收入後，常規業務PE高達100-200倍，說明市場對管線給予了極高的期望值。
- 412億市值對應的是"平臺型自免公司"的預期估值，而非當前業務的估值。
- 關鍵假設檢驗：608、611等新品能否在3年內貢獻10億+收入？考慮到競品眾多（度普利尤單抗在中國銷售已達數十億級別），這個目標有挑戰。

**結論：當前估值反映了輝瑞合作後市場對公司創新能力的重新定價，但常規業務體量偏小、管線多為跟隨靶點、商業化能力未經驗證，412億市值包含了大量預期。適合長期跟蹤管線進展，不宜追高。**

## 四、風險評估

### 4.1 核心風險

| 風險因素 | 嚴重程度 | 說明 |
|---------|---------|------|
| 輝瑞合作不可持續性 | ★★★★★ | 28.9億首付款是一次性收入，後續里程碑觸發高度不確定 |
| 管線臨床失敗風險 | ★★★★☆ | 22個在研項目，每個都有臨床失敗的可能 |
| 商業化執行風險 | ★★★★☆ | 自免領域需要強大的商業化團隊，公司歷史上商業化能力一般 |
| 關聯交易風險 | ★★★☆☆ | 與母公司三生製藥存在大量關聯交易，707權益僅30% |
| 益賽普集採風險 | ★★★☆☆ | 基本盤產品面臨集採降價，收入持續承壓 |
| 競品風險 | ★★★★☆ | 自免領域競爭激烈，度普利尤單抗等先發優勢明顯 |

### 4.2 正面因素

- 輝瑞合作驗證了公司的創新能力和分子設計水平
- 22個自免管線構成了較好的產品梯隊
- 707項目如果成功，銷售分成可帶來長期持續收入
- 2026年2月安沐奇塔單抗獲批，管線兌現能力初步驗證

## 五、綜合結論

**投資吸引力評分：★★★☆☆（中性，需跟蹤管線兌現）**

三生國健因輝瑞60億美元授權合作而"一戰成名"，市場對其創新能力給予了重新定價。但冷靜分析後，幾個核心問題值得深思：

1. **常規業務偏小**：剝離輝瑞收入後，年營收僅約13億，對應400億+市值明顯偏貴。
2. **輝瑞合作的"含金量"分析**：12.5億美元首付款中僅約28.9億人民幣歸屬三生國健（約30%權益），大頭在母公司。
3. **管線以跟隨靶點為主**：IL-17、IL-4Rα等均為已驗證靶點的me-too/me-better，差異化競爭力有待臨床數據驗證。
4. **從"賣藥"到"license-out"的估值邏輯切換**：市場正在用biotech平臺估值法（管線價值疊加），而非傳統PE估值，這增加了估值的主觀性。

公司如果能在未來2-3年內實現608、611等產品的成功商業化，同時707海外臨床進展順利觸發新的里程碑付款，估值有望獲得基本面支撐。反之，則面臨估值回調風險。

### 關鍵跟蹤指標

1. **608（IL-17銀屑病）NDA審評進度和獲批時間**
2. **611（IL-4Rα特應性皮炎）NDA申報和審評**
3. **707項目全球III期臨床數據和進展**
4. **季度常規產品收入增速**：益賽普、賽普汀等是否企穩
5. **輝瑞後續里程碑觸發情況**
6. **關聯交易公允性**：與三生製藥的交易條款是否對上市公司有利
7. **研發費用率變化**：22個項目的投入節奏和資金使用效率
