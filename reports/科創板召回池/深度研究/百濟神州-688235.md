# 百濟神州（688235）深度投資研究

**研究日期：2026年5月16日**
**當前市值：約3885億元（A股） | 三地上市：科創板688235 / 港股06160 / 美股ONC**

---

## 一、商業模式與競爭壁壘

### 1.1 核心產品：澤布替尼（百悅澤/BRUKINSA）

澤布替尼是百濟神州自主研發的新一代布魯頓酪氨酸激酶（BTK）抑制劑，用於治療多種B細胞惡性腫瘤，包括慢性淋巴細胞白血病（CLL）/小淋巴細胞淋巴瘤（SLL）、套細胞淋巴瘤（MCL）、華氏巨球蛋白血癥等。

**全球銷售數據（核心跟蹤指標）：**

| 時間段 | 銷售額（人民幣） | 同比增速 |
|--------|-----------------|----------|
| 2023年全年 | 約92億元 | +130%（估算） |
| 2024年全年 | 188.59億元（約26億美元） | +106.4% |
| 2025年全年 | 280.67億元 | +48.8% |
| 2025年Q1 | 50.72億元 | +64% |
| 2025年H1 | 125.27億元 | +56.2% |
| 2025年前三季度 | 199.50億元 | +51% |
| 2026年Q1 | 75.98億元 | +49.8%（估算） |

數據來源：公司財報、經濟參考報、藥智新聞。

**關鍵競爭格局數據：**

全球BTK抑制劑市場2024年規模約125億美元，2025年預計達219億美元。澤布替尼的市場份額變化是理解公司價值的核心：

- 2024年全年：全球BTK市場份額21.2%，位居第三
- 2024年Q4：份額提升至24.9%，超越阿斯利康阿可替尼，升至第二
- 2025年Q1：首次躍居全球BTK市場整體份額第一
- 2025年Q3：美國市場份額達33.8%，超越伊布替尼成為美國第一
- 2025年Q4：全球市場份額突破30%

對手方面：強生/艾伯維的伊布替尼（Imbruvica）因專利到期（核心化合物專利2028年5月到期）和安全性劣勢，份額持續下滑但2024年仍以51.1%全球份額居首；阿斯利康的阿可替尼（Calquence）增長平緩，已被澤布替尼超越。

**澤布替尼的核心壁壘：**

1. **臨床數據碾壓前代**：頭對頭臨床試驗ALPINE研究證明澤布替尼在CLL/SLL中療效優於伊布替尼，且心臟毒性更低——這是BTK領域首個成功的頭對頭優效性試驗
2. **先發規模優勢**：已在全球70多個市場獲批，覆蓋面遠超其他新一代BTK抑制劑
3. **專利保護期較長**：化合物專利2034年到期，且通過與仿製藥企和解，美國市場仿製藥不得在2037年之前銷售
4. **適應症持續拓展**：從CLL/SLL、MCL逐步拓展至更多B細胞惡性腫瘤，擴大可及患者群

**但另一方面**，澤布替尼面臨的新威脅正在浮現：2026年2月，阿可替尼與維奈克拉的聯合療法獲美國批准，成為首個全口服、固定時長的CLL/SLL治療方案。這種"有限療程"模式可能對BTK抑制劑的"持續治療"模式構成結構性挑戰。

### 1.2 第二大產品：替雷利珠單抗（百澤安）

替雷利珠單抗是公司自主研發的PD-1單克隆抗體，已獲批14項適應症，覆蓋肺癌、胃癌、食管癌、肝癌、鼻咽癌等主要實體瘤。

**銷售數據：**

| 時間段 | 銷售額 | 同比增速 |
|--------|--------|----------|
| 2024年全年 | 44.67億元（6.21億美元） | +17.4% |
| 2025年Q1 | 12.45億元 | +19.3% |
| 2025年H1 | 26.43億元 | +20.6% |

替雷利珠單抗已在全球46個市場獲批上市，2025年上半年新增20個市場納入報銷範圍（包括日本、歐洲、澳大利亞）。但坦率說，國內PD-1賽道極度內卷，替雷利珠單抗在國內面臨恆瑞卡瑞利珠單抗、信達信迪利單抗等強勁競爭，增速遠不及澤布替尼。

### 1.3 核心管線：索托克拉（sonrotoclax）——第二增長極候選

索托克拉是百濟神州自主研發的新一代BCL2抑制劑，被市場視為澤布替尼之後最重要的"第二增長極"。

**臨床進展：**
- R/R MCL（復發/難治套細胞淋巴瘤）和R/R CLL/SLL的新藥上市申請已獲國家藥監局受理，均納入優先審評
- III期臨床：索托克拉聯合澤布替尼 vs 安慰劑聯合澤布替尼治療R/R MCL，已完成首例入組
- 早期數據亮眼：索托克拉聯合澤布替尼治療初治CLL/SLL，客觀緩解率100%，完全緩解率35%

索托克拉的戰略意義在於：與澤布替尼聯合使用可提供"BTK+BCL2"的固定時長方案，直接回應阿可替尼+維奈克拉聯合療法的競爭威脅，守住並擴大血液腫瘤領域的市場地位。

### 1.4 管線全景

截至2026年2月，百濟神州擁有40多款處於臨床開發和商業化階段的產品。公司計劃從2026年起每年將有8-10個新分子實體進入臨床。除索托克拉外，重點管線包括：
- EGFR CDAC藥物（針對三代TKI耐藥問題，計劃2025年下半年啟動研究）
- 百澤安皮下製劑（計劃2025年下半年啟動III期）
- 多個實體瘤早期管線

### 1.5 護城河評估

**優勢：**
- 澤布替尼在BTK領域的臨床數據、全球商業化能力和品牌認知構成了強大的護城河
- 全球化銷售網絡已建立（覆蓋70多個市場），這是國內創新藥企中獨一無二的
- BTK+BCL2的聯合佈局構建了血液腫瘤領域的生態閉環

**不足：**
- 收入高度集中於單一產品（澤布替尼佔產品收入74.3%），風險集中度過高
- 替雷利珠單抗在國內PD-1紅海中增長空間有限
- 管線中尚無確定性的"第二個澤布替尼"級別產品

## 三、成長性與估值

### 3.1 澤布替尼的天花板在哪裡

這是投資百濟神州最核心的問題。

**市場空間：** 全球BTK抑制劑市場預計從2025年的219億美元增長至2030年的251億美元。加上BCL2抑制劑和BTK CDAC，到2028年相關市場總規模預計達220億美元。

**澤布替尼峰值銷售預測：**
- 保守估算：按目前全球30%份額計算，2030年BTK市場251億美元 × 30% ≈ 75億美元
- 樂觀估算：若份額繼續提升至40%+（隨伊布替尼專利到期份額加速轉移），峰值可達100億美元
- 行業機構Evaluate Pharma預測2028年約40億美元（可能偏保守，因預測時澤布替尼增長尚未充分體現）

**但需關注增速放緩信號：** 澤布替尼增速從2024年的106%下降至2025年的49%，2026年Q1進一步放緩至約50%。這符合大品種放量後的自然規律，但投資者需要密切跟蹤美國市場份額是否見頂。

### 3.2 新增長驅動力

1. **索托克拉（BCL2抑制劑）：** 若獲批上市，與澤布替尼聯合可構建"BTK+BCL2"組合方案，既防守（對抗固定時長療法競爭），又進攻（拓展新適應症）。參照艾伯維維奈克拉（Venclexta）2024年約22億美元銷售額，索托克拉若成功上市，峰值銷售可期10億美元級別
2. **替雷利珠單抗全球化：** 已進入46個市場，海外增量空間存在，但全球PD-1競爭激烈，預期貢獻有限
3. **管線新分子：** 8-10個/年的新分子進入臨床，但大部分處於早期，短期內難以貢獻收入

### 3.3 當前估值水平

| 估值指標 | 數值 | 備註 |
|----------|------|------|
| A股市值 | 約3885億元 | 三地上市中最高 |
| 港股市值 | 約A股折價35% | 約2525億元（估算） |
| 美股市值 | 約2230億元（換算人民幣） | 三地最低 |
| 2025年PS（A股） | 約10.2倍 | 382億營收 |
| 2026年PS（A股） | 約8.6-8.9倍 | 預計436-452億營收 |
| 2026年動態PE（A股） | 約70-84倍 | 基於一致預期EPS約3.25元 |
| 券商目標價 | 浦銀國際326元 | 買入評級 |

**與全球同類藥企對比：**

百濟神州的估值處於"從高成長生物科技向成熟藥企過渡"的尷尬區間。以70-84倍PE對標：
- 成熟大藥企（輝瑞、默沙東等）通常10-20倍PE
- 高成長生物科技（Vertex等）通常30-40倍PE
- 百濟神州當前估值隱含了極高的增長預期

正如市場分析所指出的：**百濟神州面臨"估值懸崖"風險**——當公司從"高增長生物科技"轉型為"成熟藥企"時，估值中樞可能從PS驅動切換到PE驅動，對標從Vertex變成渤健（Biogen），PE可能從70倍壓縮到20-30倍。避免"估值懸崖"的唯一路徑是持續證明高增長，即儘快找到澤布替尼之後的"第二增長極"。

## 四、風險評估

### 4.1 單品依賴風險（高）

澤布替尼2025年佔產品收入74.3%、佔總營收73.4%。2026年Q1佔比仍為73.6%，未見改善。這種高度集中的產品結構意味著：任何影響澤布替尼銷售的不利因素，都將直接衝擊公司整體業績。

### 4.2 專利懸崖時間表（中期風險）

- 澤布替尼化合物專利：2034年4月到期
- 適應症專利族群：分別於2027年6月、2031年12月、2035年4月到期
- 仿製藥和解保護：美國市場仿製藥不得在2037年前銷售
- **總結：** 2034-2037年是關鍵時間窗口。公司有約8-11年時間培育第二增長曲線

### 4.3 地緣政治風險（高，且不可控）

這是懸在百濟神州頭上最大的不確定性因素：
- **收入敞口：** 超過一半的收入來自美國市場
- **政策風險：** 美國《生物安全法案》雖未直接限制已上市藥物，但可能大幅提升後續管線在美獲批難度
- **極端情景：** 若中美關係急劇惡化導致澤布替尼在美銷售受限，公司將失去最大收入來源

**但另一方面：** 澤布替尼已成為美國CLL/SLL標準治療方案，有大量美國患者正在使用，禁售會直接損害患者利益，因此極端情景發生的概率不高。但這種風險無法完全排除，且無法對沖。

### 4.4 競爭風險（中）

- 阿可替尼+維奈克拉的固定時長方案可能蠶食BTK抑制劑持續治療市場
- 非共價BTK抑制劑（如禮來的Pirtobrutinib）針對BTK耐藥患者的競爭
- BTK CDAC（蛋白降解）新技術路線可能構成遠期替代威脅

### 4.5 管理層評估

**創始人兼CEO歐雷強（John Oyler）：** 2010年聯合創立百濟神州，技術型企業家，此前創立並出售了BioDuro。優點是具備全球化視野和執行力，帶領百濟從零打造出全球BTK第一品種；但作為非科學家出身的CEO，公司對外部引進的研發能力依賴較高。

**總裁兼COO吳曉濱：** 前輝瑞中國國家經理，在其領導下輝瑞中國業務大幅增長。商業化能力突出，是百濟神州國內銷售團隊建設的關鍵人物。

**治理層面的擔憂：** 百濟神州三地上市（開曼註冊），股權結構較為分散，且累計虧損超600億元，歷史股東的利益回收仍是長期問題。

### 4.6 最大下行風險

1. **美國政策打擊**：若《生物安全法案》或後續政策限制百濟神州在美業務，將直接砍掉50%+收入。這是低概率、高影響的黑天鵝事件
2. **澤布替尼增長見頂+第二增長極未能接力**：若2027-2028年澤布替尼增速降至個位數，且索托克拉未能貢獻顯著收入，估值可能出現戴維斯雙殺
3. **固定時長療法顛覆持續治療模式**：若阿可替尼+維奈克拉方案被廣泛採用，BTK單藥持續治療市場可能萎縮

## 五、綜合結論

### 定性判斷

百濟神州是中國創新藥企全球化最成功的案例，澤布替尼是中國藥企有史以來最成功的創新藥。2025年首次盈利標誌著公司從"燒錢期"進入"收穫期"。

**核心矛盾在於：這個"收穫期"能持續多久、規模能有多大。**

樂觀情景下，澤布替尼峰值銷售突破60-80億美元，索托克拉成功接力，公司成長為全球Top 20藥企。悲觀情景下，澤布替尼增速放緩、地緣政治風險爆發或固定時長療法顛覆市場，公司淪為"一品獨大、青黃不接"的平庸藥企。

### 估值判斷

當前A股3885億市值對應2026年約70-84倍PE，隱含了非常高的增長預期。即使考慮到公司確實處於盈利快速釋放期，這個估值水平已經price in了大部分樂觀預期，安全邊際不足。

**三地估值差異值得關注：** 港股折價35%、美股折價更多，說明成熟市場投資者對公司的估值更為審慎。如果要投資百濟神州，港股或美股可能是更合理的入場點。
