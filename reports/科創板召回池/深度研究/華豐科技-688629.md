# 華豐科技（688629）深度投資研究

> 研究日期：2026年5月16日
> 科創板召回池評級：四星
> 當前市值：約582億元
> 上市日期：2023年（科創板）

## 一、商業模式與競爭壁壘

### 1.1 主營業務拆解

華豐科技成立於1958年，深耕連接器領域超過60年，總部位於四川綿陽。公司主營光、電連接器及線纜組件的研發、生產與銷售，形成了"防務為核心、通訊與工業為兩翼"的戰略佈局。

**三大應用領域：**

- **防務類連接產品**：為航天科工、中國電科、中國兵工、中國船舶、航天科技、航空工業等大型防務集團提供軍用連接器，是公司的傳統優勢領域，收入佔比在下降但仍是利潤貢獻的核心。
- **通訊類連接產品**：服務於華為、中興等通訊設備製造商，產品涵蓋高速背板連接器、高速線纜組件（銅纜/光纜）。2025年通訊業務收入爆發式增長，成為營收增長的主要驅動力。華為為第一大客戶，2025年上半年收入佔比達64.29%。
- **工業類連接產品**：覆蓋新能源汽車、軌道交通等領域，已進入比亞迪、上汽通用五菱等車企供應鏈。新能源高壓連接器成為新增長點。

**2025年產品結構（按產品形態）：**

| 產品類型 | 收入（億元） | 佔比 |
|---------|------------|------|
| 組件（線纜組件等） | 15.55 | 61.53% |
| 連接器 | 7.26 | 28.72% |
| 系統互連產品 | 1.35 | 5.32% |
| 其他配套件 | 0.83 | 3.27% |
| 其他 | 0.29 | 1.16% |
| **合計** | **25.28** | **100%** |

**2025年全年業績：**

| 指標 | 2025年 | 同比增長 |
|------|--------|---------|
| 營業收入 | 25.28億元 | +131.50% |
| 歸母淨利潤 | 3.59億元 | +2120.06%（上年基數極低） |
| 毛利率 | 31.44% | 同比提升 |

### 1.2 行業地位與競爭格局

**全球連接器市場格局：**

全球連接器市場規模超800億美元，呈高度分散格局。頭部企業包括泰科電子（TE Connectivity）、安費諾（Amphenol）、莫仕（Molex）等，主要為歐美企業主導。

**國內防務連接器格局：**

| 企業 | 定位 | 2025年收入規模（估計） |
|------|------|---------------------|
| 中航光電 | 國內軍用連接器龍頭 | 約200億元 |
| 航天電器 | 軍用高端連接器 | 約60億元 |
| **華豐科技** | **軍民融合連接器** | **25.28億元** |
| 陝西華達 | 軍用連接器 | 較小 |

- 防務連接器市場競爭格局相對穩定，中航光電、航天電器、華豐科技、陝西華達形成頭部格局
- 中國防務連接器市場規模從2017年91億元增至2026年約236億元，年複合增長率11.16%

**高速互聯領域新格局：**

在AI算力驅動下，高速背板連接器和高速線纜組件成為新增長極。國內供應商中，華豐科技、慶虹電子、中航光電三家形成頭部市場格局。

- 公司112Gbps高速背板連接器已量產出貨
- 224Gbps產品持續優化中
- 6條高速線模組產線已投產，2024年7月開始批量交付

### 1.3 護城河分析

**客戶認證壁壘（強）：**
- 防務領域客戶認證週期長（通常2-3年），一旦進入供應鏈極難被替換
- 華為通訊業務深度綁定，第一大客戶佔比超64%
- 多個防務集團長期合作關係

**技術積累壁壘（中強）：**
- 60年連接器製造經驗，技術積累深厚
- 高速連接器112G已量產、224G在研，技術節奏緊跟行業前沿
- 但與泰科、安費諾等全球巨頭相比，在產品廣度和技術深度上仍有差距

**軍品資質壁壘（強）：**
- 軍品生產資質獲取難度高，新進入者面臨較高政策和資質門檻
- 公司擁有完整的軍品科研生產資質體系

**不足之處：**
- 對華為單一客戶依賴度過高（64%），業務過於集中
- 與TE、安費諾等全球龍頭相比，收入體量差距懸殊（全球龍頭年收入超千億）
- 毛利率31%在連接器行業中處於中等水平，定價權有待加強

## 二、財務質量分析

### 2.1 核心財務指標

| 指標 | 2024年 | 2025年 | 變化 |
|------|--------|--------|------|
| 營業收入 | 10.92億元 | 25.28億元 | +131.50% |
| 歸母淨利潤 | -0.17億元（估計） | 3.59億元 | 扭虧大幅增長 |
| 毛利率 | 約20% | 31.44% | +約11個百分點 |
| 淨利率 | 虧損 | 約14.2% | 大幅改善 |

**2026年一季度業績：**

| 指標 | 2026Q1 | 同比增長 |
|------|--------|---------|
| 營業收入 | 6.33億元 | +56.15% |
| 歸母淨利潤 | 1.05億元 | +230.43% |
| 扣非淨利潤 | 0.97億元 | +322.95% |
| 經營現金流淨額 | 4.28億元 | 由負轉正 |

### 2.2 財務質量評估

**亮點：**
- 2025年營收翻倍增長（+131.5%），從虧損到盈利3.59億元，業績拐點確立
- 毛利率從約20%提升至31.44%，反映產品結構改善和高速產品放量
- 2026Q1經營現金流4.28億元大幅改善，由負轉正，說明收款質量好轉
- 2026Q1利潤增速（+230%）遠超收入增速（+56%），規模效應顯現

**隱憂：**
- 應收賬款上升，年報簡析中明確提示"應收賬款體量較大"
- 2024年基數極低（虧損），2025年的高增速有低基數效應
- 毛利率31%在連接器行業中僅屬中等，與TE（約35%）、安費諾（約33%）相比仍有差距
- 對華為收入佔比超64%，如果華為需求波動，對公司影響巨大

### 2.3 收入結構轉變

公司正在經歷從"防務為主"到"通訊驅動增長"的轉型：

- 2025年營收增長14.36億元中，通訊業務和工業新能源汽車業務是主要貢獻
- 華為作為第一大客戶佔比達64%，說明通訊業務已成為公司最大收入來源
- 防務業務雖然增速相對溫和，但毛利率較高，仍是利潤的重要支撐

> **數據提示**：從防務到通訊的轉型雖然帶來了收入的爆發式增長，但也顯著提高了對華為單一客戶的依賴度。這種"把雞蛋集中放在一個籃子裡"的局面需要密切關注。

## 三、成長性與估值

### 3.1 成長驅動力

**短期驅動（1-2年）：**
- AI服務器和數據中心建設需求持續增長，高速線纜組件訂單放量
- 華為算力服務器採購需求強勁，公司作為核心供應商直接受益
- 防務重點項目陸續交付，防務收入穩步增長

**中期驅動（3-5年）：**
- 224Gbps/448Gbps高速互聯產品迭代升級，跟隨AI算力代際升級
- 新能源汽車高壓連接器持續滲透，拓展比亞迪等新客戶
- 國產算力技術和產能躍升，帶動國產高速連接器需求

**長期天花板：**
- 中國連接器市場規模超300億美元，華豐科技僅佔約1%
- 若能在通訊+防務+工業三條線均衡發展，收入天花板可達百億級
- 但另一方面，連接器行業競爭激烈，利潤率提升空間有限

### 3.2 估值分析

**當前估值水平：**

| 估值指標 | 數值 | 說明 |
|---------|------|------|
| 市值 | 582億元 | - |
| 2025年PE（TTM） | 約162倍 | 582億/3.59億 |
| 2026年PE（預估） | 約78倍 | 券商一致預期約7.5億淨利（估計值） |
| PS（TTM） | 約23倍 | 582億/25.28億 |

**可比公司估值：**

| 公司 | 2025年PE | 特點 |
|------|---------|------|
| 中航光電 | 約35-40倍 | 軍用連接器龍頭，規模更大 |
| 航天電器 | 約50-60倍 | 軍用連接器，規模較小 |
| 華豐科技 | 約162倍 | AI高速互聯+防務雙輪驅動 |

**估值判斷：**

- 基於2025年業績，162倍PE明顯偏貴。但2025年是公司業績拐點年，利潤基數低
- 若2026年淨利能達到7-8億元（Q1淨利1.05億，全年看4倍以上放大合理），對應PE約73-83倍
- 與中航光電的35-40倍PE相比，華豐科技享受了"AI算力"概念溢價
- 市場給予高估值的核心邏輯是：公司正從傳統防務連接器企業轉型為AI算力核心器件供應商

> **估值結論**：當前估值處於高位，已包含較多對AI算力業務的樂觀預期。如果通訊業務能保持高增速、華為訂單持續放量，當前估值可能通過業績增長消化。但若AI算力需求不及預期或華為訂單出現波動，估值調整風險較大。

## 四、風險評估

### 4.1 核心風險清單

| 風險類型 | 風險描述 | 影響程度 |
|---------|---------|---------|
| 大客戶依賴 | 華為收入佔比超64%，單一客戶風險極高 | ★★★★★ |
| 估值風險 | 2025年PE超160倍，預期充分 | ★★★★ |
| AI需求波動 | 若AI算力建設節奏放緩，通訊業務增速將顯著下降 | ★★★★ |
| 競爭加劇 | TE、安費諾等外資加速佈局中國市場 | ★★★ |
| 防務政策 | 軍費增長放緩或採購策略調整 | ★★★ |
| 毛利率壓力 | 31%毛利率處於中等水平，競爭可能進一步壓縮 | ★★★ |
| 應收賬款 | 應收賬款體量較大，潛在壞賬風險 | ★★ |

### 4.2 關鍵跟蹤指標

1. **華為收入佔比變化**：是否持續超60%？新客戶拓展能否稀釋集中度？
2. **通訊業務季度增速**：AI算力需求是否持續拉動高速互聯產品放量
3. **224G/448G產品進展**：下一代高速連接器技術突破和量產時間表
4. **毛利率趨勢**：產品結構改善能否持續推動毛利率上行
5. **防務業務穩定性**：防務訂單是否保持穩定增長
6. **應收賬款週轉天數**：關注回款質量，特別是大客戶賬期變化
7. **經營現金流**：Q1已轉正，後續季度能否維持

## 五、綜合結論

### 總體評價

華豐科技是一家正在經歷戰略轉型的老牌連接器企業。60年防務連接器積澱為其提供了穩定的基本盤，而AI算力時代的到來讓公司的高速互聯產品獲得了爆發式增長機遇。2025年營收翻倍、利潤從虧損到3.59億元的業績拐點令人矚目，2026Q1延續強勁增長態勢。

但需要審慎看待以下問題：

1. **華為依賴度過高**是最大風險點，64%的收入集中在單一客戶身上
2. **估值已充分反映樂觀預期**，162倍PE需要未來幾年持續高增長來消化
3. **毛利率31%在行業中僅屬中等**，相比全球龍頭定價權仍有差距
4. 從防務到通訊的收入結構轉變雖然帶來增長，但也增加了週期性波動風險

### 建議關注時點

- 2026年中報發佈（2026年8月）：驗證通訊業務增速的可持續性和防務業務的穩定性
- 華為訂單佔比變化：若降至50%以下將顯著降低集中度風險
- 224G/448G產品批量出貨：標誌技術升級的里程碑節點
- 估值回調至50-70倍PE區間：安全邊際更為充足
