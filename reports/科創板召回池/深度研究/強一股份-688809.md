# 強一股份（688809）深度投資研究

> 研究日期：2026年5月16日
> 科創板召回池評級：四星
> 當前市值：約586億元
> 上市日期：2025年12月30日（科創板）

## 一、商業模式與競爭壁壘

### 1.1 主營業務拆解

強一股份成立於2012年，總部位於蘇州工業園區，專注於集成電路測試核心耗材——探針卡的研發、生產與銷售。公司是國內率先實現MEMS探針卡自主量產的企業，也是近年來唯一躋身全球探針卡前十的境內廠商。

**核心產品線：**

- **MEMS探針卡（核心產品）**：用於晶圓級芯片測試，採用微機電系統（MEMS）工藝製造的探針陣列，具備高密度、高精度特點。探針密度達數萬針，精度7微米，可測試45微米間距，已達世界先進水平。2025年探針卡銷售收入9.64億元，佔總營收95%以上。
- **懸臂式探針卡**：傳統探針卡產品，主要用於中低端芯片測試。
- **測試服務及其他**：為客戶提供配套測試技術支持。

**2025年全年業績：**

| 指標 | 2025年 | 同比增長 |
|------|--------|---------|
| 營業收入 | 10.12億元 | +57.81% |
| 歸母淨利潤 | 3.95億元 | +69.43% |
| 扣非淨利潤 | 3.91億元 | +72.26% |
| 主營業務收入 | 10.00億元 | +58.64% |

### 1.2 行業地位與市佔率

**全球競爭格局：**

探針卡是半導體測試環節的關鍵耗材，全球市場高度集中。2025年全球前十大探針卡廠商合計市場份額約80%。

| 排名 | 企業 | 國家 | 特點 |
|------|------|------|------|
| 1 | FormFactor | 美國 | 全球龍頭，MEMS技術領先 |
| 2 | Technoprobe | 意大利 | 歐洲龍頭 |
| 3 | MJC | 日本 | 日本市場主導 |
| 4-5 | 其他境外廠商 | - | - |
| **6** | **強一股份** | **中國** | **全球前十唯一境內企業** |

- 前三名（FormFactor、Technoprobe、MJC）合計佔全球超50%市場份額
- 強一股份2025年全球市佔率約3.87%，從2023年的第9位升至第6位
- 國產探針卡廠商合計全球份額約6.12%，強一股份佔國產陣營的63%

**與頭部對手的差距：**

- 與FormFactor相比，強一股份在先進製程MEMS探針卡（如5nm以下）的技術成熟度和產品線廣度仍有差距
- 但另一方面，公司在成熟製程MEMS探針卡領域已具備較強競爭力，且憑藉本土化服務優勢和性價比優勢，正在加速搶佔份額

### 1.3 護城河分析

**技術壁壘（中強）：**
- 國內首個建成百級潔淨度MEMS探針卡生產車間
- MEMS探針製造技術門檻極高，涉及微機電系統、精密加工、材料科學等多學科交叉
- 2025年研發費用1.32億元，同比增長68.31%，研發投入持續加大

**客戶認證壁壘（強）：**
- 探針卡是定製化產品，需要根據客戶芯片設計定製，一旦通過認證形成強粘性
- 公司已進入主流晶圓廠和芯片設計公司供應鏈
- 華為旗下哈勃投資是公司股東之一，側面印證客戶生態關係

**國產替代卡位優勢（核心）：**
- 全球前十唯一境內企業，在中美科技博弈背景下具有戰略稀缺性
- AI算力芯片測試需求爆發，境內芯片測試需求快速增長
- 客戶傾向於使用國產探針卡以保障供應鏈安全

**不足之處：**
- 技術與FormFactor等全球龍頭仍有代差，先進製程覆蓋不足
- 產品線單一，僅有探針卡一個品類
- 全球3.87%的份額仍較小，抗風險能力有限

## 二、財務質量分析

### 2.1 核心財務指標

| 指標 | 2025年 | 說明 |
|------|--------|------|
| 營業收入 | 10.12億元 | 同比+57.81% |
| 歸母淨利潤 | 3.95億元 | 同比+69.43% |
| 毛利率 | 65.03% | 同比+3.37個百分點 |
| 淨利率 | 約39% | 高盈利能力 |
| 研發費用 | 1.32億元 | 同比+68.31% |
| 負債率 | 8.38%（2026Q1） | 極低槓桿 |

**2026年一季度業績：**

| 指標 | 2026Q1 | 同比增長 |
|------|--------|---------|
| 營業收入 | 2.85億元 | +229.39% |
| 歸母淨利潤 | 1.12億元 | +697.6% |

| 經營現金流淨額 | 6983萬元 | -37.84% |

### 2.2 財務質量評估

**亮點：**
- 毛利率65%、淨利率約39%，盈利能力極強，體現定製化產品的高附加值
- 負債率僅8.38%，幾乎無財務風險，剛IPO完成現金充裕
- 營收和利潤的高速增長（Q1營收同比增229%）驗證了景氣週期的強勁

**隱憂：**
- 存貨賬面餘額2.02億元，計提跌價準備2496萬元，存貨跌價風險不容忽視
- Q1經營現金流雖為正但同比下降37.84%，需關注應收賬款回收情況
- 部分收入存在跨期確認（2025年已發貨但未滿足收入確認條件的訂單在2026Q1確認），Q1的爆發性增長部分來自會計時點效應

### 2.3 客戶集中度風險

這是強一股份最值得關注的財務風險點：

| 年份 | 前五大客戶收入佔比 |
|------|----------------|
| 2023年 | 75.91% |
| 2024年 | 81.31% |
| 2025年 | 76.93% |

- 前五大客戶連續三年貢獻超75%收入
- 存在對"B公司"的重大依賴（合併考慮直接和間接收入）
- 前五大供應商採購佔比62.07%，上游也存在集中度問題

> **數據提示**：客戶集中度超七成，意味著任何一個大客戶的訂單波動都可能對公司業績產生顯著影響。這是典型的"大客戶依賴型"企業風險特徵。

## 三、成長性與估值

### 3.1 成長驅動力

**短期驅動（1-2年）：**
- AI算力芯片測試需求爆發，下游客戶對MEMS探針卡的需求持續放量
- 半導體行業景氣上行週期，晶圓廠擴產帶動測試耗材需求
- IPO募資後產能擴張，新建先進自動化產線即將投產

**中期驅動（3-5年）：**
- 國產替代持續推進，全球份額從3.87%向更高水平攀升
- 先進製程MEMS探針卡技術突破，向5nm以下製程延伸
- 先進封裝（Chiplet等）對探針卡提出新需求，打開增量空間

**長期天花板：**
- 全球探針卡市場規模約30億美元，公司當前份額僅3.87%
- 若能達到10%全球份額（約3億美元/21億元），營收天花板在當前基礎上翻倍
- 但另一方面，探針卡市場規模有限，長期天花板不算很高

### 3.2 估值分析

**當前估值水平：**

| 估值指標 | 數值 | 說明 |
|---------|------|------|
| 市值 | 586億元 | - |
| 2025年PE（TTM） | 約148倍 | 586億/3.95億 |
| 2026年PE（預估） | 約98倍 | 按Q1年化淨利4.48億計算（估計值） |
| PS（TTM） | 約58倍 | 586億/10.12億 |

**估值判斷：**

- 當前PE約148倍（基於2025年利潤），顯著高於半導體耗材行業平均水平
- 公司2025年12月底剛上市，市場對其給予了極高的成長溢價
- 即使按2026年一季度業績年化，PE仍在100倍左右，估值偏貴
- 但另一方面，考慮到公司處於高速成長期（Q1營收增229%）、國產替代的戰略稀缺性以及AI算力催化，市場願意為成長性支付溢價

> **估值結論**：當前估值已充分反映樂觀預期，安全邊際不足。若2026年全年淨利能達到6-8億元（對應PE 73-98倍），估值雖貴但在高成長科創板可以勉強接受。但若業績增速放緩，估值回調風險較大。

## 四、風險評估

### 4.1 核心風險清單

| 風險類型 | 風險描述 | 影響程度 |
|---------|---------|---------|
| 客戶集中度 | 前五大客戶佔比77%，對B公司存在重大依賴 | ★★★★★ |
| 估值風險 | PE超100倍，已透支較多成長預期 | ★★★★ |
| 技術追趕風險 | 先進製程探針卡與FormFactor仍有差距 | ★★★ |
| 存貨跌價 | 存貨2億元，若需求不及預期可能減值 | ★★★ |
| 行業週期性 | 半導體行業具有強週期性，景氣下行將直接衝擊 | ★★★ |
| 產品單一 | 僅探針卡一個產品線，抗風險能力有限 | ★★★ |
| 解禁風險 | IPO後原始股東未來面臨解禁壓力 | ★★★ |

### 4.2 關鍵跟蹤指標

1. **季度營收增速**：觀察AI算力需求是否持續拉動，重點關注增速拐點
2. **客戶集中度變化**：前五大客戶佔比是否下降，新客戶拓展進度
3. **全球市佔率排名**：是否能從第6位繼續向上攀升
4. **先進製程產品進展**：5nm以下製程MEMS探針卡的研發和客戶認證進度
5. **存貨和應收賬款變化**：關注資產質量，特別是存貨跌價準備
6. **毛利率趨勢**：65%的毛利率能否維持，競爭加劇是否壓縮利潤空間

## 五、綜合結論

### 總體評價

強一股份是國內探針卡領域的絕對龍頭，也是全球前十中唯一的境內企業。公司受益於三重利好疊加：AI算力芯片測試需求爆發、半導體景氣上行週期、國產替代戰略推進。2025年業績高速增長（營收+58%、淨利+69%），2026Q1延續強勁勢頭（營收+229%）。

但需要清醒認識到：

1. **客戶集中度過高**是最大隱憂，超77%的大客戶依賴使得業績波動風險顯著
2. **產品線單一**（僅探針卡），長期天花板有限
3. **當前估值偏貴**，PE超100倍已透支較多成長預期
4. 與FormFactor等全球龍頭的技術差距仍然存在

### 投資評級

| 維度 | 評分 | 說明 |
|------|------|------|
| 商業模式 | ★★★★ | 定製化產品+國產替代稀缺性，但產品線單一 |
| 競爭壁壘 | ★★★ | 技術壁壘中強，但與全球龍頭有差距 |
| 財務質量 | ★★★★ | 高毛利+高淨利+低負債，但客戶集中度高 |
| 成長性 | ★★★★★ | 短期增速極快，中期空間明確 |
| 估值合理性 | ★★ | 100倍以上PE，安全邊際不足 |
| **綜合** | **★★★☆** | **好公司，但當前價格偏貴，等待回調** |

### 建議關注時點

- 2026年中報發佈（2026年8月）：驗證全年高增長的可持續性
- 估值回調至60-80倍PE區間：對應市值約400-500億元
- 先進製程探針卡技術突破公告：催化長期價值重估
