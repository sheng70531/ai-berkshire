# Temu vs Amazon：業務異同深度分析

> 分析日期：2026年5月15日

---

## 一、商業模式對比

### 1.1 Amazon：多元帝國

Amazon已經遠遠超越"電商公司"的定義，是一個橫跨七大業務板塊的科技巨頭：

| 業務板塊 | 2025年收入 | 佔總收入比 | 增速 |
|---------|-----------|-----------|------|
| 北美電商（含1P+3P） | 4263億美元 | 59.5% | +10% |
| 國際電商 | 1619億美元 | 22.6% | +13% |
| AWS雲計算 | 1287億美元 | 18.0% | +20% |
| 廣告服務 | 680億美元 | 9.5% | ~23% |
| 訂閱服務（Prime等） | 496億美元 | 6.9% | +12% |
| **合計** | **7169億美元** | | |

注：廣告和訂閱收入已包含在北美/國際分部中，存在重疊統計。

Amazon的電商模式是**1P自營 + 3P市場的混合體**：
- **1P自營**：Amazon直接採購商品、定價、銷售，承擔庫存風險
- **3P市場**：第三方賣家在平臺上銷售，Amazon收取佣金（通常15%）+ FBA物流費
- 82%的活躍賣家使用FBA，私有品牌賣家FBA使用率高達92%
- 賣家利潤率約25%-30%

### 1.2 Temu：極致效率的單一業務

Temu的業務結構遠比Amazon簡單，核心就是**跨境電商平臺**：

| 指標 | 2025年數據 |
|------|-----------|
| GMV | 約925億美元 |
| 同比增速 | +70%-75% |
| 月活用戶 | 約4.17億（Q2 2025） |
| 用戶增速 | +68% |

**全託管模式**（佔比約90%）：
- 賣家只負責供貨，Temu負責定價、運營、物流、售後
- 本質是"平臺做莊"，賣家變成了Temu的供應商
- 賣家利潤率極薄，僅2%-5%

**半托管模式**（佔比約10%，快速增長中）：
- 賣家自行將商品發至海外倉，負責最後一公里配送
- Temu負責流量和前端運營
- 在美國搜索場景中，70%的流量已分配給半托管商品

**新拼姆自營品牌**（2026年3月啟動）：
- 初始投入15億元現金，計劃三年投入1萬億元
- 目標：滲透國內產業集群，孵化自營品牌
- 覆蓋產品標準、倉儲物流、知識產權、法務合規全鏈條
- 本質上是從"流量分發平臺"向"品牌製造商"的戰略躍遷

### 1.3 電商模式的核心差異

| 維度 | Amazon | Temu |
|------|--------|------|
| 賣家准入 | 各類賣家均可入駐 | 僅限工廠和品牌方 |
| 定價權 | 賣家自主定價 | 全託管模式下平臺定價 |
| 物流時效 | Prime 1-2天達 | 5-10天（跨境直郵），本地倉逐步加速 |
| 賣家利潤 | 25%-30% | 2%-5% |
| 平臺角色 | 基礎設施+流量入口 | 深度介入運營的"超級買手" |
| 自營商品 | 有Amazon Basics等自有品牌 | 新拼姆剛起步 |

### 1.4 物流模式對比

**Amazon FBA全球物流網絡**：
- 全球1200+個履約中心
- 40000+輛半掛卡車
- 25000+輛電動配送車
- 110+架貨運飛機
- 美國包裹配送量已超UPS和FedEx之和
- 2025年履約支出906億美元
- 核心優勢：1-2天送達的確定性體驗

**Temu的物流體系**（快速演進中）：
- 全球13個自營倉庫（歐洲10個、美國2個、墨西哥1個）
- 美國自營倉處理量佔美國總量的15%-20%，預計2026年提升至20%-25%
- 歐洲目標：2025年底前80%歐洲訂單通過本地倉處理
- 每單退貨成本節省約0.60美元
- 核心瓶頸：仍高度依賴跨境直郵，時效和成本劣勢明顯

**差距總結**：Amazon用20年建成了全球最大的商業物流網絡，Temu剛剛開始建設本地倉。這個差距不是幾年能追上的，但Temu正在用"半托管+本地倉"模式快速縮小時效差距。

## 二、業務重合度

### 2.1 正面競爭的品類和市場

**品類重疊極高**：Temu有77%的商品與Amazon上架商品存在近似匹配，其中10%是完全相同的商品。在時尚和美妝品類，重疊率高達94%。

**核心競爭品類**：
- 時尚服飾（Temu最大品類，佔銷售額41%）
- 家居用品
- 小電子產品/配件
- 美妝個護
- 日用百貨

**不競爭的領域**：
- 高價值電子產品（手機、電腦、電視）
- 品牌商品（Nike、Apple等大品牌不入駐Temu）
- 生鮮食品（Amazon有Whole Foods和Amazon Fresh）
- 雲計算、數字內容、智能硬件等Amazon的非電商業務

### 2.2 Amazon Haul的進展

Amazon於2024年11月推出Haul，直接對標Temu：
- 所有商品低於20美元，從中國倉庫直郵
- 配送時間約兩週
- 已擴展至全球多個市場，並推出獨立App

**但進展不及預期**：
- 月度使用率僅16%，遠落後於Temu的28%和Shein的23%
- 僅24%的美國消費者嘗試過至少一次購買
- 核心問題：消費者行為轉變緩慢，Haul缺乏足夠的差異化吸引力
- Amazon需要在用戶體驗、配送速度或獨家優惠上找到突破口

### 2.3 美國市場份額

| 平臺 | 美國電商市場份額 | 跨境電商份額 |
|------|----------------|-------------|
| Amazon | ~42% | 24% |
| Temu | ~18% | 24% |

值得注意：在跨境電商這個細分領域，Temu已經追平Amazon，兩者均為24%。但在美國電商整體市場，Amazon的份額是Temu的2.3倍。

### 2.4 價格帶重疊

| 指標 | Temu | Amazon |
|------|------|--------|
| 平均客單價 | 23.9美元 | 52美元 |
| Prime會員客單價 | - | 60-62美元 |
| 非Prime客單價 | - | 43-45美元 |
| Prime Day客單價 | - | 57.97美元 |

Temu的客單價約為Amazon的46%。兩者的價格帶存在一定重疊，主要在以下區間：
- **高度重疊**：10-30美元區間（日用品、小件商品）
- **部分重疊**：30-50美元區間（服裝、家居）
- **幾乎無重疊**：50美元以上（電子產品、品牌商品Amazon佔絕對優勢）

## 三、用戶群對比

### 3.1 用戶規模

| 指標 | Amazon | Temu |
|------|--------|------|
| 全球用戶 | ~3億+ | ~4.17億MAU |
| 美國用戶 | ~2億（Prime會員） | 下降顯著（關稅後） |
| Prime會員數 | 全球約2.4億付費會員 | 無會員體系 |

### 3.2 用戶畫像差異

**Temu用戶畫像**：
- 年齡分佈廣泛：千禧一代（25-42歲）使用率最高（21%），X世代（43-55歲）緊隨其後（20%）
- 性別平衡：男性50.31%，女性49.69%
- 收入水平：早期以年收入5萬美元以下人群為主（55%），後期向5-10萬美元中產擴展（50%）
- 購物動機：極致低價、"淘寶"式探索樂趣、高性價比日用品
- 26%的美國受訪者過去一年在Temu購物過

**Amazon用戶畫像**：
- 以中產及以上家庭為主
- Prime會員黏性極強：42%選擇年付，58%選擇月付
- 購物動機：便捷送達、品牌信賴、一站式購物
- 品類偏好更廣泛，包括高價值商品

### 3.3 用戶重疊情況

一個關鍵發現：**Amazon Prime會員更傾向於在Temu購物**，比非Prime會員的Temu使用率更高。這說明：
- 兩者並非完全替代關係，更像互補
- 高頻網購用戶傾向於"Amazon買必需品，Temu買額外小物件"
- 在過去三個月內Amazon交易超過20次的消費者中，超過6%同時也在Temu和Shein購物

### 3.4 購物頻次和消費力

| 指標 | Temu | Amazon |
|------|------|--------|
| 客單價 | 23.9美元 | 52美元 |
| 月均下單次數 | 2.1次/用戶 | 更高（Prime會員頻次更高） |
| 月均消費額 | ~48.5美元/活躍用戶 | 顯著更高 |
| 用戶粘性來源 | 低價+遊戲化+推送 | Prime會員權益+配送速度+內容 |

### 3.5 關稅衝擊對Temu美國用戶的影響

2025年5月2日美國取消de minimis免稅政策後：
- Temu美國日活下降58%
- 月活下降30%
- Temu被迫暫停美國全託管模式
- 隨後通過降價60%、免收進口費等手段回拉用戶
- 美國市場佔Temu GMV比例從約31%下降
- 歐洲市場份額上升至40%，增速80%-100%

## 四、核心差異總結

### 4.1 利潤引擎：AWS vs 無

這是兩家公司最本質的差異。

**Amazon的AWS**：
- 2025年收入1287億美元，增速20%
- 是Amazon的利潤引擎和戰略縱深
- AWS的存在讓Amazon可以容忍電商業務的低利潤甚至虧損來打價格戰
- 給Amazon提供了巨大的AI和技術能力反哺

**Temu/PDD Holdings**：
- 沒有云計算業務，沒有第二增長曲線
- 利潤主要來自拼多多國內主站
- Temu本身尚未盈利，預計2025-2026年接近盈虧平衡
- PDD Holdings 2025年Q3淨利潤293億元（約41億美元），同比+17%

**關鍵含義**：Amazon可以用AWS的利潤長期補貼電商競爭（包括Haul），而Temu必須在電商業務本身實現盈利。這是結構性的不對等。

### 4.2 用戶粘性：Prime會員 vs 價格驅動

**Amazon Prime**：
- 2億美國會員，全球2.4億
- 年度訂閱收入496億美元
- Prime Day 2025消費者支出241億美元，同比+70%
- 會員權益覆蓋：次日達、Prime Video、Prime Music、Prime Reading等
- 高轉換成本：一旦付費，用戶傾向於在Amazon上集中消費以"值回票價"

**Temu的用戶留存**：
- 無會員體系，靠低價吸引用戶
- 遊戲化設計（轉盤、優惠券、社交分享）提升打開率
- 大量補貼獲客，CAC（獲客成本）較高
- 關稅衝擊證明：當價格優勢被削弱時，用戶流失極快（日活下降58%）
- 缺乏Prime那樣的"鎖定效應"

**結論**：Amazon的用戶粘性來自"生態系統鎖定"，Temu的用戶粘性來自"持續的價格優勢"。前者更持久，後者更脆弱。

### 4.3 物流基礎設施：20年積累 vs 剛剛起步

| 維度 | Amazon | Temu |
|------|--------|------|
| 全球履約中心 | 1200+ | 13個自營倉 |
| 運輸工具 | 4萬+卡車、2.5萬+電動車、110+飛機 | 依賴第三方物流 |
| 配送時效 | 1-2天（Prime） | 5-10天（縮短中） |
| 年度履約支出 | 906億美元 | 遠小於此 |
| 美國包裹量 | 超過UPS+FedEx之和 | 僅15%-20%通過本地倉 |

Temu正在快速建設，但與Amazon的差距是數量級的。這種基礎設施差距直接影響用戶體驗和運營效率。

### 4.4 廣告業務：680億 vs 剛起步

**Amazon廣告**：
- 2025年收入680億美元，同比+23%
- 已成為僅次於Google和Meta的第三大數字廣告平臺
- 廣告是高利潤率業務，直接提升Amazon的整體盈利能力
- Sponsored Products、Sponsored Brands、DSP等產品矩陣成熟

**Temu廣告**：
- 目前主要是平臺對外投放廣告獲客（Meta、Google上的鉅額廣告支出）
- 平臺內廣告（商家付費推廣）剛起步
- 2025年不強制全託管商家投廣告，2026年起逐步推廣
- 美國半托管廣告業務因關稅導致商家投放意願下降
- 廣告曾佔收入80%以上（2022年），但這主要是國內拼多多的數據

**關鍵差距**：Amazon的廣告業務是"印鈔機"，商家主動付費獲取流量。Temu目前還在"燒錢買流量"階段，從花錢做廣告到賺廣告費，這個轉變需要足夠的用戶規模和商家生態支撐。

## 五、競爭格局總結

### 5.1 Temu對Amazon的真實威脅

1. **低價品類分流**：在10-30美元的日用品、服飾、家居小件領域，Temu確實在分流Amazon的一部分訂單
2. **跨境電商份額追平**：兩者在跨境電商領域已各佔24%，說明Temu在這個細分領域有真實競爭力
3. **用戶心智佔領**：26%的美國消費者已經在Temu購物過，這個滲透率不低
4. **品類重疊度高**：77%的商品重疊意味著消費者可以在兩個平臺之間比價

### 5.2 Temu難以撼動Amazon的領域

1. **Prime生態鎖定**：2億美國會員的黏性不是低價能打破的
2. **物流基礎設施**：1-2天達 vs 5-10天達，體驗差距巨大
3. **品牌信任**：大品牌優先選擇Amazon，Temu仍以白牌/工廠品為主
4. **利潤縱深**：AWS+廣告兩大利潤引擎讓Amazon有無限"彈藥"
5. **高價值品類**：電子產品、品牌商品等高客單價領域是Amazon的護城河
6. **政策韌性**：關稅衝擊下Temu日活暴跌58%，Amazon幾乎不受影響

### 5.3 結論

Temu和Amazon與其說是直接競爭對手，不如說是在電商市場的**不同層級**運營：

- **Amazon**是全品類、全價格帶、全鏈路的電商基礎設施，附加雲計算和數字媒體的科技巨頭
- **Temu**是聚焦低價白牌商品的跨境電商平臺，正在從"價格屠夫"向"品牌孵化器"轉型

兩者的競爭主要集中在**低價日用品這個細分戰場**。在這個戰場上，Temu有價格優勢但缺乏時效和信任；Amazon有生態優勢但Haul目前進展緩慢。短期內，兩者更可能是共存關係而非零和博弈——畢竟Prime會員反而更愛逛Temu，說明消費者把兩個平臺當作不同場景的購物選擇。

真正的變數是**政策風險**：de minimis取消已經證明，Temu的商業模式對貿易政策高度敏感。如果中美貿易摩擦持續升級，Temu在美國市場的前景將面臨結構性挑戰，而Amazon幾乎不受影響。
