# 拼多多 — 疑慮與待研究清單

**建立日期：2026年4月12日**
**狀態：持續更新**

---

## 核心疑慮

### 疑慮1：PDD的護城河是否真實存在？5年後還會在嗎？

**當前判斷的矛盾點：**
- PDD的差異化功能（拼團、百億補貼、農產品直髮）已被競爭對手全面模仿
- 最深的護城河（微信社交關係鏈）屬於騰訊，不屬於PDD
- 低價心智護城河需要持續"餵養"（補貼），停止補貼是否會瓦解？
- 用戶忠誠度弱，切換成本接近零

**需要研究的問題：**
- [ ] PDD的用戶復購率和留存率數據，與淘寶、京東對比
- [ ] 微信與PDD的合作關係是否有正式協議？騰訊是否持有PDD股份？
- [ ] 過去3年PDD在下沉市場的滲透率變化
- [ ] 農產品供應鏈的實際壁壘有多深——競爭對手要多長時間能追上？
- [ ] 抖音電商的增速是否在蠶食PDD的份額？具體數據

---

### 疑慮2：Temu什麼時候可以盈利？條件是什麼？

**當前已知：**
- 2024年經營虧損約320億元，2025年約500億元
- 歐洲市場2025年已局部盈利
- 美國市場被關稅重創，原有模式（免稅+空運直郵）已不成立
- 瑞銀預測：2026年底季度性盈虧平衡，2029年利潤率約6%

**需要研究的問題：**
- [ ] 半托管模式和全託管模式的單位經濟模型（unit economics）各是什麼？哪個更有盈利前景？
- [ ] 海外倉模式的建倉進展——目前在哪些國家有倉？規模多大？
- [ ] 美國關稅的最新動態——145%關稅是否有可能下調？中美談判進展
- [ ] 歐洲市場盈利的具體原因——是因為物流成本更低？還是競爭格局更好？
- [ ] SHEIN的盈利模式是什麼——Temu能否參考？SHEIN盈利了嗎？
- [ ] Temu在哪些國家/地區的模式最接近可持續盈利？

---

### 疑慮3：新拼姆什麼時候能做成？成功的標誌是什麼？

**當前已知：**
- 一期150億，三年1000億，上海成立
- 目標：整合PDD+Temu供應鏈，孵化面向全球的中國自營品牌
- 類比：從義烏白牌升級為Anker/大疆級別的品牌

**核心不確定性：**
- PDD沒有品牌建設基因
- 從白牌到品牌，Anker用了10年，大疆用了8年
- 渠道衝突：自營品牌會和平臺第三方商家競爭

**需要研究的問題：**
- [ ] 新拼姆具體打算做哪些品類？有沒有已經公佈的品類方向？
- [ ] 新拼姆的團隊構成——是從PDD內部轉，還是外部招募品牌/消費品人才？
- [ ] 中國出海品牌的成功案例分析：Anker、大疆、Shokz的共同路徑是什麼？
- [ ] Temu的用戶認知研究——海外用戶對Temu的品牌感知是什麼？是否有可能升級？
- [ ] 150億一期資金的使用方向——供應鏈投入vs品牌營銷vs海外倉的比例
