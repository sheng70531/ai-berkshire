# Temu與Shein：業務重合度與客群重合度深度分析

> 分析日期：2026年5月15日
> 數據來源：Sensor Tower、Earnest Analytics、ecdb、Statista、Business of Apps等第三方機構

---

## 一、商業模式根本差異

### 1.1 Shein：自有品牌零售商 + 第三方平臺

Shein的本質是一家**垂直一體化的快時尚品牌公司**，同時疊加了第三方市場（Shein Marketplace）：

| 維度 | 數據 |
|------|------|
| 1P（自營）佔GMV比例 | **76%**（2025年） |
| 3P（第三方市場）佔GMV比例 | **24%**（2025年） |
| 核心品類 | 時尚服裝佔總收入**77%** |
| 非服裝品類佔比 | 從2022年不到20%增長至2024年超過40% |
| 供應鏈模式 | 小批量快反（每次僅生產幾百件），算法驅動測款 |
| 供應商網絡 | 以廣州為核心的數千家緊密協作供應商 |

**Shein的關鍵能力**：通過算法分析數字行為識別時尚趨勢，快速轉化為設計並小批量生產，根據消費者反饋再決定是否放量。這種"按需生產"模式讓Shein在時尚品類擁有極強的產品週轉效率。

### 1.2 Temu：純平臺型全品類市場

Temu的本質是一個**連接消費者和中國供應商的全品類電商平臺**（類比早期拼多多的海外版）：

| 維度 | 數據 |
|------|------|
| 1P佔GMV比例 | **0%** |
| 3P佔GMV比例 | **100%**（純第三方模式） |
| 核心品類 | 全品類覆蓋200+細分，時尚佔比**41%** |
| 運營模式 | 全託管/半托管（平臺定價、平臺控物流） |
| 供應鏈模式 | 工廠直供，直接連接製造端和消費端 |
| 定價權 | 平臺決定最終售價，賣家讓渡定價權 |

**核心區別**：Shein更像Zara（自有品牌零售商），Temu更像拼多多/早期淘寶（平臺市場）。但兩者都深度介入供應鏈管理，Temu的全託管模式實質上是一種"準自營"。

### 1.3 收入來源拆解

**Shein收入結構**：
- 自營商品銷售收入（主體，約76%）
- 第三方市場佣金和服務費（約24%）
- 2025年總收入約240億美元，GMV約540億美元（全年推算）

**Temu收入結構**：
- 佣金+服務費（全部來自第三方賣家）
- 2025年平臺GMV約925億美元
- 目前仍處於虧損狀態，預計2026年實現盈利
- PDD 2025Q1財報顯示交易服務收入（主要來自Temu）已大幅增長

## 二、業務重合度分析

### 2.1 品類重合

根據YipitData數據，**Temu和Shein的商品品類重合度低於30%**。

| 品類 | Shein | Temu | 競爭程度 |
|------|-------|------|----------|
| **女裝** | 核心主力（佔收入約50%+） | 有覆蓋但非強項（約15-20%） | 中高 |
| **男裝** | 有覆蓋，增長中 | 有覆蓋 | 中 |
| **配飾/飾品** | 強勢品類 | 有覆蓋 | 中 |
| **美妝護膚** | 有覆蓋 | 有覆蓋 | 中 |
| **家居家廚** | 擴展中 | 強勢品類 | 中 |
| **3C電子** | 弱/幾乎無 | 強勢品類 | **極低** |
| **工具五金** | 無 | 有覆蓋 | **無** |
| **寵物用品** | 有覆蓋 | 有覆蓋 | 低 |
| **運動戶外** | 有覆蓋 | 有覆蓋 | 中 |
| **玩具** | 弱 | 有覆蓋 | 低 |

**結論**：品類重合主要集中在**低價時尚服裝和配飾**領域。Shein在時尚領域有絕對優勢（77%的收入來自時尚），而Temu的品類分佈更分散。Temu在3C電子、家居工具等品類是Shein幾乎不涉及的領域。

### 2.2 地域重合

兩個平臺在全球主要市場正面交鋒，但各有側重：

| 地區 | Temu | Shein | 競爭態勢 |
|------|------|-------|----------|
| **美國** | MAU佔全球11%（下降趨勢，同比降28%） | 美國MAU約2570萬 | 正面競爭但Temu份額下滑 |
| **歐盟** | MAU佔全球34%（同比增74%），1.42億MAU | 2025年新增1520萬歐洲用戶，用戶總量領先Temu約3000萬 | **最激烈戰場** |
| **拉丁美洲** | MAU佔全球26%（同比增122%），巴西流量超MercadoLibre | 有佈局但相對較弱 | Temu攻勢兇猛 |
| **東南亞** | 正在進入越南、印尼等市場 | 已有較成熟佈局 | Temu是挑戰者 |
| **中東** | 有覆蓋 | 折扣力度較大（阿聯酋27%、沙特23%） | 中等競爭 |

**Temu覆蓋約100個國家，Shein覆蓋超過200個國家**。地域重合度高，但Temu在歐洲和拉美增速遠超Shein，而Shein在美國和東南亞的用戶忠誠度更高。

### 2.3 價格帶重合

| 維度 | Temu | Shein |
|------|------|-------|
| 平均客單價（美國） | **約25-40美元** | **約58-100美元** |
| 折扣力度 | 平均60-75%折扣 | 通常低於20%折扣 |
| 補貼訂單佔比 | **85%** | **59%** |
| 法國年均消費 | 約300歐元 | 約270歐元 |
| 定價策略 | 極致低價+激進補貼，大量商品低於成本價銷售 | 動態定價+閃購，基於趨勢需求調價 |

**結論**：Temu的價格帶整體低於Shein。兩者在**5-20美元**的超低價區間有顯著重合，但Shein在**20-60美元**的輕奢快時尚區間有獨立空間。Temu的策略是"以價換量"，平均每單虧損約30美元；Shein已實現盈利。

### 2.4 供應鏈重合

- **地理重合**：兩者都以**廣東省（廣州、深圳一帶）** 為供應鏈核心
- **供應商爭奪**：Temu正積極挖角Shein的廣州供應商，甚至以**三倍薪酬**挖Shein供應鏈部門員工
- **模式差異**：
  - Shein：與供應商深度綁定，提供設計方案+訂單保障，形成"準僱傭"關係
  - Temu：更鬆散的合作關係，供應商自主性更強，但平臺控制定價
- **部分供應商確實同時供貨兩個平臺**，但Shein的核心供應商網絡更封閉、更緊密

## 三、客群重合度分析

### 3.1 用戶畫像對比

| 維度 | Temu | Shein |
|------|------|-------|
| **核心年齡段** | 25-44歲（約40%），**59歲以上**是最高頻購物群體 | 13-35歲，**Z世代約65%** +年輕千禧一代35% |
| **性別分佈** | 男性偏多（約**57%**） | 女性為主（約**60-75%**） |
| **收入水平** | 近一半收入來自年收入超19萬美元的高收入用戶 | 平均年收入約6.53萬美元，以中低收入為主 |
| **用戶畫像關鍵詞** | 全品類尋找低價的"淘寶客"，年齡偏大，男性居多 | 追逐時尚趨勢的年輕女性，價格敏感但注重潮流 |
| **購物偏好重疊** | 與其他低價零售商（Dollar Tree、Walmart等）重疊度高 | 與時尚和美容專賣店（Forever 21、H&M等）重疊度高 |

**畫像差異極大**：Shein用戶是"追潮流的年輕女性"，Temu用戶是"找便宜的多年齡段混合群體"。

### 3.2 用戶重疊率

根據YipitData數據，**Temu和Shein的用戶重合度僅約5%**。

其他參考數據：
- 美國44%的成年人使用過Temu，31%使用過Shein（Morning Consult, 2025年1月）
- 與TikTok Shop的用戶重疊：Shein用戶28%也用TikTok Shop，Temu用戶25%也用TikTok Shop
- 兩個平臺與TikTok Shop的用戶重疊率遠高於它們之間的直接重疊

**5%的用戶重疊率意味著**：絕大多數消費者只在其中一個平臺購物，這兩個平臺實際上在服務不同的消費需求。

### 3.3 用戶使用場景差異

| 場景 | Temu | Shein |
|------|------|-------|
| **核心場景** | "我需要一個便宜的XX工具/小物件" | "我想買最新款的衣服/配飾" |
| **購物動機** | 價格驅動，追求極致性價比 | 趨勢驅動，追求時尚感和新鮮感 |
| **瀏覽行為** | 搜索導向，目的性較強 | 瀏覽導向，"逛"的成分更重 |
| **用戶粘性** | 周活躍度較低 | 周活躍度高於Temu **15%** |
| **在線時長** | 較短 | 高於Temu約**5%** |
| **復購率** | 90天內96%為回頭客 | 用戶流失率更低，忠誠度更高 |

### 3.4 品牌認知差異

消費者對兩個平臺有清晰的心智區分：

- **Shein = "便宜的Zara"**：時尚、潮流、快速上新，質量可接受
- **Temu = "什麼都有的極致低價市場"**：像一個海量SKU的超級折扣店
- 在Fashionista 2025年的盲測中，Shein服裝在5次洗滌後**73%保持形態和顏色**，而Temu可比產品僅**52%**
- Shein在服裝品類的品牌力遠強於Temu

## 四、關鍵數據彙總

### 4.1 規模對比（2025年數據）

| 指標 | Temu | Shein |
|------|------|-------|
| 年GMV | 約925億美元 | 約540億美元（推算） |
| 年收入 | 約925億美元（全部3P） | 約240億美元 |
| GMV增速 | **50%**（2025H1同比） | **15-20%**（2025H1同比） |
| 全球MAU | **4.165億**（2025Q2） | 約2.5-3億（估算） |
| 全球累計下載 | **突破10億次**（2025Q2） | 約6-7億次 |
| 盈利狀態 | 虧損（預計2026年盈利） | 已盈利 |
| 覆蓋國家 | 約100個 | 超過200個 |
| 2025年最下載購物App排名 | **第1名** | **第2名** |

### 4.2 美國市場MAU對比

| 時間 | Temu美國MAU | Shein美國MAU |
|------|-----------|-------------|
| 2025Q2 | 約1.34億（但同比下降28%） | 約2570萬 |

注：Temu的"MAU"統計口徑可能包含網頁端訪客，Shein的數據主要為App端。不同數據源口徑差異較大，需注意可比性。

### 4.3 關稅衝擊

2025年5月起，美國取消800美元以下小額包裹免稅政策，對中國商品徵收最高120%關稅或100美元/件的固定費用（6月起升至200美元）。

- **影響**：兩平臺均宣佈自2025年4月25日起漲價
- **應對**：加速在美國建設本地倉儲，引入美國本土賣家以規避關稅
- **差異化影響**：Shein因自有品牌屬性，有更多調價彈性；Temu因極致低價定位，漲價對其打擊更大

## 五、核心結論

### 5.1 業務重合度判斷：**中等偏低（約25-30%）**

1. **品類重合度低於30%**（YipitData數據），僅在低價服裝和配飾領域直接競爭
2. **商業模式根本不同**：Shein是品牌零售商（76%自營），Temu是純平臺（100%第三方）
3. **供應鏈有部分重合**但模式迥異：Shein是"深度綁定+快反"，Temu是"鬆散合作+極致低價"
4. **地域高度重合**但各有優勢市場：Temu在歐洲和拉美增速領先，Shein在用戶總量和忠誠度上領先

### 5.2 客群重合度判斷：**極低（約5%）**

1. **用戶重疊率僅5%**，遠低於兩者各自與TikTok Shop的重疊率（25-28%）
2. **用戶畫像幾乎互補**：Shein是"年輕女性追時尚"，Temu是"多年齡段找便宜"
3. **使用場景完全不同**：時尚瀏覽 vs 低價搜索
4. **品牌心智清晰區分**：消費者並不將兩者視為替代品

### 5.3 對拼多多投資研究的啟示

1. **Temu的真正競爭對手不是Shein，而是Amazon和各地本土電商**。品類重合度和客群重合度的數據都證明，市場對"Temu vs Shein"的敘事過度簡化
2. **Shein在時尚品類的護城河（品牌+供應鏈+算法）是Temu難以複製的**，反之Temu在全品類低價市場的規模優勢Shein也難以追趕
3. **兩者更可能走向差異化共存**：Shein深耕時尚，Temu做全品類低價平臺，類似Zara和Walmart的關係
4. **真正的風險變量是關稅政策**，而非相互競爭。2025年美國取消小額免稅政策對兩者都是系統性風險
5. **Temu的增速遠高於Shein**（50% vs 15-20%），但虧損換增長的模式可持續性存疑
