# 33億的池塘和AI這條鯰魚

> 《看懂群核科技》系列 · 第 03 篇 · 競爭與增長
> 閱讀時間約 10 分鐘

---

## 一個不大的池塘

670億港元的市值，買的是哪門子未來？把群核的市值和它所在市場的規模放在一起，這個問題的答案讓人不安。

| 維度 | 數據 | 來源 |
|------|------|------|
| 中國空間設計軟件市場（2024） | **33億元** | 弗若斯特沙利文 |
| 群核市佔率（2024） | **23.2%** | 弗若斯特沙利文 |
| 群核收入（2025） | **8.20億元** | 招股書 |
| 預測市場規模（2029） | **66億元** | 弗若斯特沙利文（CAGR 14.9%） |
| 群核上市後市值峰值 | **~670億港元** | 港交所行情（2026年4月20日） |

**670億港元的市值，對應的是一個33億元的市場——市值是整個行業規模的20倍。** 即便到2029年市場翻倍到66億，群核拿下30%的份額，收入也不過**20億元**。

這就是群核科技估值討論中繞不開的**天花板問題**。

公司試圖用兩條路突破天花板：
1. **海外擴張**——Coohom進軍東南亞和拉美
2. **縱向延伸**——從設計工具升級為空間智能平臺（SpatialVerse）

這兩條路後面會分別展開。先看競爭。

## 誰在和群核搶飯碗

### 競爭格局一覽

| 玩家 | 市佔率（2024） | 定位 | 核心差異化 |
|------|:----------:|------|---------|
| **群核（酷家樂）** | **23.2%** | 雲原生全鏈設計平臺 | 用戶規模、網絡效應、GPU渲染速度 |
| **Autodesk（3ds Max）** | **21.9%** | 專業級3D設計 | 全球品牌、BIM生態、高端市場 |
| **三維家** | **~10%（估計）** | 定製家居工廠對接 | 後端生產系統集成 |
| **中望CAD** | **~5%（估計）** | 國產CAD替代 | 政策紅利、價格優勢 |
| **飛路AI等新勢力** | **<1%** | AI原生設計 | 零門檻、全鏈閉環 |

（市佔率數據來源：弗若斯特沙利文；三維家、中望CAD為估計值）

**前兩名合計只有45%**——市場仍然分散，沒有形成贏家通吃的格局。

### 三維家：最近的"宿敵"

群核和三維家的競爭已持續多年，甚至打過知識產權官司。兩者的差異：

| 維度 | 群核（酷家樂） | 三維家 |
|------|-------------|-------|
| 強項 | 前端設計體驗、渲染速度 | 後端工廠對接、生產系統集成 |
| 客戶重心 | 設計師、裝修公司 | 定製傢俱工廠 |
| 技術路線 | 雲原生 + 自建GPU集群 | 依賴第三方雲 |
| 融資狀態 | 已上市 | 未上市，曾獲紅星美凱龍投資 |

群核在**前端設計**更強，三維家在**後端製造**更強。兩者的競爭實際上是"往對方領地滲透"——群核試圖往生產端走，三維家試圖提升設計體驗。

**關鍵判斷**：短期內雙方各守陣地的格局不會大變。但如果AI大幅降低前端設計的壁壘，群核在設計端的差異化優勢可能被侵蝕，而三維家與工廠的深度綁定反而更難被替代。

### Autodesk：高端市場的巨人

Autodesk在中國空間設計軟件市場拿了**21.9%** 的份額——幾乎和群核持平。但兩者服務的客戶群有明顯區隔：

- Autodesk面向專業建築師和設計事務所，產品線覆蓋AutoCAD、3ds Max、Revit
- 群核面向中小裝修公司和獨立設計師，核心賣點是"簡單、快速、便宜"

**群核的策略是"農村包圍城市"**——先在中低端市場建立規模，再往上走。但Autodesk的品牌、生態和BIM全流程能力，在高端市場幾乎不可撼動。

### 飛路AI等新勢力：來自底層的顛覆

最值得警惕的不是傳統競爭對手，而是AI原生的設計工具。

飛路AI等新玩家的邏輯是：**用AI直接生成設計方案，跳過"畫圖"這個環節**。用戶輸入一句話描述（"三室兩廳、北歐風格、預算20萬"），AI自動生成完整的空間方案和效果圖。

如果這個路徑跑通，酷家樂作為"設計工具"的價值就會被根本性削弱——因為**用戶不再需要"畫圖"了**。

**但反方觀點是**：AI生成的方案目前在精度和可落地性上遠不及專業設計工具。家裝設計不是"出一張好看的圖"——它需要精確到毫米的尺寸、符合施工規範的材料清單、能對接工廠的生產參數。這些是Midjourney和飛路AI短期內做不到的。

## AI：機遇、威脅、還是兩者兼有？

這是分析群核科技時最複雜、也最關鍵的變量。

### AI對群核有利的一面

1. **數據護城河**：4.8億3D模型 + 50億渲染圖，是訓練空間AI模型的獨家數據集。群核已發佈SpatialLM（空間語言模型）和SpatialGen（空間生成模型），有先發優勢。

2. **AI提升用戶體驗**："酷家樂AI"日均出圖超**30萬張**（來源：群核科技官方），AI輔助設計可以降低使用門檻、提高出圖效率，增加用戶粘性。

3. **新的商業故事**：SpatialVerse平臺為具身AI機器人提供空間仿真數據。群核已與智元機器人、銀河通用、穹徹智能等企業合作。如果具身AI市場爆發，群核可能切入一個遠大於33億的市場。

（來源：群核科技官方發佈、知乎專欄技術博文、智源社區報道）

### AI對群核不利的一面

1. **渲染功能貶值**：如果Midjourney、Sora等通用AI能生成高質量室內效果圖，"10秒渲染"這個核心賣點就不那麼值錢了。

2. **設計門檻降低**：AI讓非專業用戶也能做出不錯的設計方案，這可能導致獨立設計師減少——而設計師是酷家樂的核心用戶和流量入口。個人客戶NRR暴跌到**86.4%**，可能已經反映了這個趨勢。

3. **轉換成本被侵蝕**：如果AI能自動將設計方案從酷家樂遷移到其他平臺，群核的轉換成本壁壘就被削弱了。

### 關鍵判斷

**5年視角**：群核大概率仍然存在，企業客戶的嵌入深度保證基本盤不會崩塌。但個人用戶可能持續流失，AI新工具蠶食邊緣市場，增速進一步放緩。

**10年視角**：高度不確定。如果通用AI的空間理解能力接近人類設計師水平，整個"設計工具"品類可能被重新定義。群核要麼成功轉型為"空間智能基礎設施"，要麼淪為一個萎縮市場裡的舊時代工具。

反方：也存在一種可能——AI不是替代設計師，而是讓更多人參與設計。"人人都是設計師"反而擴大了工具市場的TAM。但這個假設需要驗證。

## 海外：第二曲線還是一廂情願？

2025年海外版Coohom收入同比增長**28%**，是群核增長最快的板塊。公司在東南亞、拉美等市場拓展，試圖打開第二增長曲線。

| 維度 | 數據 |
|------|------|
| 海外收入佔比（2025） | **~9%** |
| 海外收入增速（2025） | **28%** |
| 全球空間設計軟件市場（2024） | **~210億元**（弗若斯特沙利文） |
| 預計2029年全球市場 | **~370億元**（CAGR 15.4%） |

（數據來源：弗若斯特沙利文行業報告、群核科技招股書）

**全球市場210億元，是國內市場的6倍多——天花板確實高得多。**

但海外擴張面臨的挑戰也很現實：

1. **Autodesk是全球霸主**：在海外市場，群核面對的不是三維家，而是Autodesk的全產品線——品牌、生態、渠道都遠非群核可比。
2. **本地化成本高**：不同國家的戶型標準、裝修規範、材料體系都不同，產品適配是重投入。
3. **海外SaaS獲客成本遠高於國內**：國內靠設計師社群和品牌商渠道自然擴散，海外需要真金白銀做市場。

**海外業務是真實的增長點，但在總收入裡只佔9%、絕對值不到1億元，距離成為"第二曲線"還有很長的路。**

## 家裝行業：退潮的河

上面討論了競爭和AI，但對群核影響最大的變量，可能不是競爭對手，而是**它所在的行業本身**。

群核**95%以上**的收入來自家裝產業鏈。而中國家裝市場與房地產週期高度綁定：

| 指標 | 趨勢 |
|------|------|
| 中國新房銷售面積（2021-2025） | 持續下滑，2025年已較高點腰斬 |
| 存量房翻新市場 | 2025年規模約**8000億元**，佔家裝總量突破**60%** |
| 家裝行業總規模（2025） | **~3.8萬億元** |

（數據來源：中國家居家裝行業研究報告、公開媒體報道）

好消息是**存量房翻新正在接力新房**——中國存量房超**6億套**，翻新裝修是結構性增長。但壞消息是翻新裝修的**客單價**通常低於新房精裝，設計複雜度也更低——這意味著設計工具的價值可能打折。

更直接的證據是群核的遞延收入連續下滑（6.17億 → 5.42億 → 5.10億），客戶從多年訂閱轉向一年一簽——**下游承壓正在傳導到群核的財務數據上。**

反方：即使房地產下行，設計數字化滲透率還在提升。過去很多小裝修公司用CAD手繪甚至紙筆畫圖，未來會逐漸轉向酷家樂這樣的雲端工具。滲透率提升可以部分對沖行業下行。

**但問題是**：酷家樂已經有6500萬註冊用戶了——家裝行業裡該知道的人都知道了。滲透率再提升的空間，可能沒有想象中那麼大。

## 本篇小結

| 維度 | 判斷 |
|------|------|
| 行業天花板 | 33億元偏低，2029年66億也不算大——市值670億缺乏基本面支撐 |
| 競爭格局 | 群核領先但不壟斷，三維家守住工廠端，Autodesk守住高端 |
| AI變量 | 雙刃劍——數據優勢是機遇，但渲染貶值和門檻降低是威脅 |
| 海外增長 | 真實但早期——28%增速好看，但絕對值小、挑戰大 |
| 行業週期 | 家裝市場從新房轉向翻新，總量未崩但客戶預算在縮減 |
| 空間智能 | 敘事性感、數據有厚度，但商業化收入僅佔3.1%，驗證尚遠 |

**一句話：群核科技正在一個不大的池塘裡當最大的魚，同時試圖遊向大海（海外+空間智能）。但池塘在退水，大海里有更大的魚，而AI這條鯰魚到底是幫它還是吃它，現在還看不清楚。**
