# 家居設計SaaS的隱形冠軍

## 一家讓人困惑的公司

2026年4月17日，群核科技（00068.HK）在港交所上市，發行價**7.62港元**。三天後，股價一度觸及43.62港元——較發行價漲超4倍，市值從130億港元飆至670億港元。一家年收入8億、經營現金流為負的家裝SaaS公司，用三天時間完成了港股近年最戲劇性的上市表演。

（數據來源：港交所公開行情、新浪財經報道）

如果你問酷家樂的六千多萬註冊用戶，他們會說：這是一個做戶型圖的工具。
如果你問資本市場，他們會說：這是"杭州六小龍"首個IPO、全球空間智能第一股。
如果你問價值投資者，他們會說：一家剛扭虧的SaaS公司賣到PS 50倍以上？瘋了。

**三個人看的是同一家公司，講的卻是三個完全不同的故事。**

這個系列要做的，是把故事拆開，只看事實——然後讓你自己判斷。

---

## 群核科技到底是什麼

一句話：**群核科技是一家為家裝行業提供雲端3D設計工具的SaaS公司，核心產品叫"酷家樂"。**

設計師用酷家樂畫戶型圖、生成效果圖；家裝公司用它給客戶展示方案、促成簽單；家居品牌商（歐派、索菲亞等）把自家產品的3D模型傳上去，讓設計師在方案裡直接調用。

本質上，酷家樂做的是**家裝設計環節的數字基礎設施**。

這個生意的財務特徵非常清晰：

| 指標 | 2025年數據 | 說明 |
|------|-----------|------|
| 總收入 | **8.20億元** | 同比+8.6% |
| 訂閱收入佔比 | **97%** | 純SaaS模式 |
| 毛利率 | **82.2%** | SaaS級優秀水平 |
| 經調整淨利潤 | **0.57億元** | 剛跨盈虧線 |
| IFRS淨利潤 | **-4.28億元** | 仍在虧損 |
| 經營活動現金流 | **-1.92億元** | 失血未止 |

（數據來源：群核科技港股招股書2026年4月更新版）

把這些放在一起，你會發現一個矛盾——**毛利率82%，看起來是臺印鈔機；但經營現金流為負，實際上還在燒錢。**

高毛利沒轉化為高利潤的原因很簡單：**銷售費用率33.4% + 研發費用率35.5% = 69%**，兩項費用吃掉了絕大部分毛利。公司仍在大量投入獲客和研發，遠未進入利潤收割期。

## 三個常見的認知偏差

### 偏差一："酷家樂就是個畫圖工具"

這是最普遍的認知，也是最表層的。

酷家樂不只是畫圖。它構建了一個**設計師-品牌商-家裝公司**的三角網絡：

- **設計師**用酷家樂做方案 → 需要品牌商的產品素材
- **品牌商**（歐派、索菲亞等）上傳3D產品模型 → 獲得設計師的方案展示和推薦
- **家裝公司**看到設計師和品牌商都在用 → 採購酷家樂作為企業標配

截至2025年，平臺上有超過**4.8億個3D模型**，累計**6500萬註冊用戶**，其中約**200萬月活非付費用戶**和約**47000家企業客戶**。

這個三角網絡一旦形成，競爭對手要同時撬動三方才能打破。**這是酷家樂最核心的壁壘，不是渲染速度，不是GPU集群。**

但反方觀點也成立：網絡效應的前提是三方都"離不開"。如果品牌商同時把模型傳到三維家，設計師同時用Midjourney出效果圖，這個網絡效應就會被稀釋。

### 偏差二："空間智能是個好故事"

群核科技在IPO敘事中把自己重新定義為 **"空間智能基礎設施公司"**，推出了SpatialVerse平臺，聲稱可以為具身AI機器人提供訓練數據和仿真環境。

公司確實做了一些事：

- 發佈了空間語言模型SpatialLM和空間生成模型SpatialGen
- 與智元機器人、銀河通用等具身智能公司達成合作
- 基於NVIDIA Isaac Sim構建空間仿真環境

（來源：群核科技官方發佈、知乎專欄、智源社區報道）

**但看看數字**：2025年，包括SpatialVerse在內的"其他業務"收入佔比僅**3.1%**。也就是說，"空間智能"貢獻的收入大約是**2500萬元**——在8.20億總收入裡幾乎可以忽略不計。

從"設計工具"到"空間智能平臺"，這個跨越的商業化驗證還遠未完成。市場目前給群核的高估值，很大程度上是在為這個**尚未兌現的敘事**定價。

反方：敘事在IPO階段從來就不靠當期收入驗證——市場買的是"萬一成了"的期權價值。但也正因為是期權，定價就不該按確定性來。

### 偏差三："杭州六小龍"概念 = 長期投資價值

群核科技是"杭州六小龍"（群核科技、宇樹科技、雲深處科技、遊戲科學、深度求索、強腦科技）中**第一個上市的**。作為概念股的"排頭兵"，它天然承載了市場對整個AI板塊的情緒。

**1071倍**的公開認購超額倍數、首日**144%** 漲幅——這些數字更多反映的是打新熱情和概念炒作，而非基本面定價。

（數據來源：群核科技招股書、證券時報報道）

冷靜下來看：群核科技**97%的收入來自家裝設計SaaS**，跟宇樹的機器人、深度求索的大模型在商業模式上完全不同。把它們放在一個概念裡，對群核的估值分析幫助不大。

## 群核科技的真實座標

拋開敘事和概念，用幾個維度給群核科技畫一幅真實肖像：

| 維度 | 群核科技的位置 |
|------|-------------|
| 行業 | 中國空間設計軟件市場**第一名**，市佔率**23.2%**（2024，弗若斯特沙利文） |
| 市場規模 | 中國空間設計軟件市場2024年約**33億元**，預計2029年**66億元**（CAGR 14.9%）|
| 全球對標 | Autodesk（市佔率21.9%，全球設計軟件龍頭）是最直接的對標 |
| 收入增速 | 從2024年的**13.8%** 降到2025年的**8.6%**——減速明顯 |
| 盈利狀態 | 經調整口徑剛扭虧，IFRS口徑仍虧損，經營現金流為負 |
| 估值水平 | IPO時PS約**14倍**，上市後一度超過**50倍**——極度昂貴 |

（市場數據來源：弗若斯特沙利文行業報告；財務數據來源：群核科技招股書）

一句話總結：**群核是一家在33億元的小池塘裡拿到23%份額的SaaS龍頭，產品好、毛利高，但增速在放緩、盈利基礎薄弱、估值被概念炒到了遠超基本面的位置。**
