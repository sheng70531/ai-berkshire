## 評級標準

每家公司按以下維度評分（★1-5星）：
- **生意質量**：商業模式是否優秀，是否容易理解
- **護城河強度**：競爭優勢是否可持續
- **管理層質量**：管理團隊能力和誠信
- **估值吸引力**：當前價格相對內在價值
- **綜合評分**：加權綜合判斷

最終判斷：是否值得進入深度研究階段
