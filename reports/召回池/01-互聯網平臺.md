## 騰訊控股（0700.HK）

### 核心業務

騰訊是中國最大的互聯網公司，業務覆蓋社交通信、遊戲、數字內容、金融科技、雲計算和企業服務。核心產品微信/WeChat月活超14億，是中國最大的超級應用，承載社交、支付、短視頻（視頻號）、小程序等全場景生態。收入構成方面，2025年全年營收7518億元，其中增值服務（遊戲+社交）佔比約40%，金融科技及企業服務佔比約31%，網絡廣告佔比約29%。騰訊在遊戲領域全球收入排名第一，擁有《王者榮耀》《和平精英》等長青產品，並通過投資Epic Games、Riot Games等構建全球遊戲版圖。廣告業務受益於視頻號商業化和AI精準投放持續高增。騰訊在中國互聯網行業地位無可撼動，是唯一同時在社交、遊戲、支付、雲計算四大領域佔據頭部位置的公司。

### 護城河分析

騰訊的護城河是中國互聯網行業中最寬最深的，核心來源於微信構建的社交網絡效應。14億月活用戶及其社交關係鏈的遷移成本極高，這不是用錢能複製的壁壘。微信生態已從即時通訊擴展到支付、小程序、視頻號、搜索，形成"用戶-商家-開發者"的多邊網絡效應，越用越強。

遊戲業務方面，騰訊同時擁有全球最大的遊戲分發渠道和頂級自研能力，形成"渠道+內容"雙重壁壘。金融科技依託微信支付的高頻使用場景，理財、保險、信貸業務自然延伸。雲業務雖不是最大，但依託騰訊生態的企業客戶資源，增長穩健。

弱點在於：遊戲行業受監管政策影響大，版號審批不確定性始終存在；視頻號雖然增長快但面臨抖音的強力競爭；國際化相對滯後，海外收入佔比有限。此外，騰訊體量已極大，維持雙位數增長的難度在加大。

### 管理層簡評

馬化騰是騰訊靈魂人物，技術出身，決策風格穩健務實。騰訊的管理層以職業經理人團隊為主導，劉熾平、James Mitchell等高管在戰略和投資領域表現優異。騰訊的管理文化強調"用戶體驗優先"和"開放連接"，在過去20多年中做出了多次正確的戰略選擇：從QQ到微信的自我革命、從封閉到開放生態的轉型、視頻號的及時佈局。治理結構清晰，馬化騰持股約8%但擁有較強影響力。騰訊在資本配置上也表現出色，大規模回購+分紅+分拆減持投資組合，股東回報意識強。

### 估值判斷

當前Non-IFRS PE約18倍，處於騰訊歷史估值區間的中低位。考慮到14%的營收增速、24%的ROE、強勁的自由現金流和AI驅動的增長潛力，18倍PE對於這種質量的公司並不算貴。同行對比，蘋果PE約30倍，Meta約25倍，騰訊相對便宜。但需考慮港股市場整體折價因素和地緣政治風險的持續影響。整體估值合理偏低。

### 初步評級

- 生意質量：★★★★★
- 護城河強度：★★★★★
- 管理層質量：★★★★★
- 估值吸引力：★★★★
- 綜合評分：★★★★★
- 是否值得深入研究：是
- 一句話總結：中國互聯網行業當之無愧的核心資產，生意質量一流，估值合理，長期持有首選。

## 阿里巴巴（9988.HK）

### 核心業務

阿里巴巴是中國最大的電商平臺公司，同時是領先的雲計算服務商。核心業務包括淘寶天貓（國內電商）、國際電商（速賣通、Lazada、Temu競爭市場）、阿里雲（中國排名第一）、本地生活（餓了麼、高德）、菜鳥物流等。2025財年（截至2025年3月）全年營收約9963億元。收入結構中，淘天集團仍是最大收入來源，但增速放緩至低個位數；阿里雲受益於AI需求增長加速，AI相關收入連續多個季度三位數增長；國際電商和本地生活處於投入期。阿里在中國電商市場的份額受到拼多多、抖音電商等的持續侵蝕，但仍是品牌電商的第一選擇。

### 護城河分析

阿里的護城河正在經歷深刻變化。傳統優勢在於：淘寶天貓作為最大的品牌電商平臺擁有龐大的商家生態和消費者基礎，菜鳥物流網絡覆蓋全球，支付寶/螞蟻金服在金融科技領域有深厚積累。阿里雲是中國最大的公有云平臺，在AI時代憑藉全棧自研能力（芯片、平臺、大模型）構建了新的競爭壁壘，蔡崇信稱其為"全球少數同時擁有強大AI和領先雲計算的公司"。

但護城河也在被削弱：拼多多以低價策略搶走大量價格敏感型用戶；抖音電商以內容驅動交易，改變了用戶購物路徑；淘寶閃購等即時零售佈局面臨美團、京東的激烈競爭。阿里核心電商業務僅個位數增長，反映出競爭壓力之大。此外，雲計算雖增長快但處於大規模投入期，自由現金流大幅下降，短期盈利能力承壓。

### 管理層簡評

2023年吳泳銘接任CEO後推動"用戶為先、AI驅動"戰略，蔡崇信擔任董事會主席。吳泳銘是阿里"十八羅漢"之一，技術背景深厚，上任以來進行了大刀闊斧的改革：裁員6.6萬人、聚焦核心業務、加大AI投入（三年超3800億元）。管理層戰略方向正確，但執行效果仍需時間驗證。阿里歷史上的治理問題值得關注：頻繁更換高管、組織架構反覆調整、螞蟻金服上市受阻等事件影響了市場信心。馬雲退居幕後但仍有影響力，當前管理層格局尚處於磨合期。

### 估值判斷

當前15倍PE（Non-GAAP），是中國大型互聯網公司中估值最低的之一。若按分部估值法，阿里雲、螞蟻金服、菜鳥等單獨拆出均有顯著價值，整體可能存在"集團折價"。但低估值有其原因：核心電商增長乏力、競爭格局惡化、自由現金流下降、AI投入期盈利承壓。與騰訊18倍、拼多多約22倍相比，阿里估值偏低反映了市場對其基本面的擔憂。屬於典型的"便宜但不確定是否值"的狀態。

### 初步評級

- 生意質量：★★★★
- 護城河強度：★★★
- 管理層質量：★★★
- 估值吸引力：★★★★
- 綜合評分：★★★★
- 是否值得深入研究：是
- 一句話總結：低估值和AI雲的增長潛力有吸引力，但核心電商護城河被侵蝕是最大隱憂，需要持續跟蹤吳泳銘的改革成效。

## 美團（3690.HK）

### 核心業務

美團是中國最大的本地生活服務平臺，核心業務包括餐飲外賣、到店及酒旅（團購、點評）、即時零售（美團閃購/買菜）和新業務（社區電商、海外擴張Keeta等）。2025年全年營收3649億元，核心本地商業收入2608億元，新業務收入1040億元。美團在外賣市場穩定保持60%以上的GTV份額，是絕對龍頭。到店酒旅是現金牛業務，利潤率高。美團的商業模式本質是通過即時配送網絡連接消費者和商家，擁有超過800萬活躍商家和數百萬騎手的龐大配送網絡。2025年年度交易用戶數突破8億。

| 市值 | 約5200億港元（2026年5月，按84港元/股估算） |

### 護城河分析

美團的護城河來自其即時配送網絡的規模效應。數百萬騎手覆蓋全國，配送效率行業領先，商家和用戶的多邊網絡效應強。到店酒旅業務有大眾點評的評價數據積累，是另一層壁壘。在外賣領域，儘管面臨京東、抖音等新進入者的挑戰，美團憑藉更成熟的運力體系和更低的虧損水平守住了60%以上的份額。

但2025年的財報暴露了護城河的脆弱面：京東外賣以補貼策略猛攻，迫使美團大幅增加補貼投入，核心本地商業板塊從盈利轉為虧損69億元。這說明美團的護城河雖寬，但並非不可撼動，尤其在對手願意持續燒錢的情況下。到店酒旅也面臨抖音本地生活的持續滲透。美團的護城河更像是"運營效率型"而非"結構性"的，需要持續投入維護。

### 管理層簡評

王興是中國互聯網行業最受尊敬的CEO之一，連續創業經歷（校內網、飯否、美團）展現了極強的戰略判斷力和執行力。他在"千團大戰"中勝出、成功整合大眾點評、擊退餓了麼的經歷證明瞭其競爭能力。王興提出的"反內卷""做正確的事"理念也體現了長期思維。但當前面臨的挑戰是：面對京東外賣的進攻，管理層被迫選擇大規模補貼應戰，導致利潤表劇烈惡化。這是否是被動之舉還是戰略主動，值得深入分析。海外業務Keeta在香港已盈虧平衡，顯示出國際化的初步成效。

### 估值判斷

美團當前處於虧損狀態，傳統PE估值失效。按2024年經調整淨利潤358億元計算，當前市值對應約15倍PE，並不算貴。但關鍵問題是2025年鉅虧後，盈利何時恢復。如果競爭態勢緩和，美團憑藉其運營效率應能較快恢復盈利。但如果京東外賣持續燒錢，虧損期可能延長。目前股價較52周高點149.8港元腰斬，反映了市場的悲觀預期。對於能承受波動的投資者，這可能是一個被過度悲觀定價的機會，但風險也不小。

### 初步評級

- 生意質量：★★★★
- 護城河強度：★★★
- 管理層質量：★★★★★
- 估值吸引力：★★★
- 綜合評分：★★★★
- 是否值得深入研究：是
- 一句話總結：中國本地生活絕對龍頭，王興能力一流，但外賣大戰致盈利劇烈惡化，需要判斷競爭何時緩和才能下手。

## 京東集團（9618.HK）

### 核心業務

京東是中國第二大電商平臺（按營收計第一），核心業務是自營電商（3C數碼、家電、日百等品類），同時運營第三方商家平臺、京東物流、京東健康等。2025年全年營收13091億元，是中國電商行業唯一萬億級收入體量的公司。京東零售收入11264億元佔主導，服務收入佔比21.8%創新高。京東的核心差異化在於自建物流體系——全國覆蓋的倉儲配送網絡保證了"當日達/次日達"的履約體驗。員工總數超90萬，其中大部分是一線物流人員。2025年京東進入外賣市場，推出京東外賣獨立App，是重大戰略擴張。

### 關鍵財務指標

| 指標 | 數值 |
|------|------|
| 市值 | 約3354億港元（2026年5月，按130港元/股估算） |
| PE(TTM) | 約10倍（Non-GAAP口徑） |
| ROE | 數據待確認（利潤下降較大） |
| 營收（2025年） | 13091億元 |
| 營收增長率 | 13% |
| 淨利潤（2025年） | 196億元（GAAP）；270億元（Non-GAAP） |
| 淨利潤增長率 | -53%（GAAP）；-43%（Non-GAAP） |
| 毛利率 | 15.6% |
| 淨利率 | 約2.2%（GAAP） |
| 資產負債率 | 52.1% |
| 自由現金流 | 65億元（同比下降85%） |

### 護城河分析

京東的護城河主要來自自建物流網絡。多年持續投入形成的全國倉配體系是競爭對手難以短時間複製的重資產壁壘，保證了京東在3C數碼、家電等標品品類的履約優勢。京東的用戶認知也很清晰："正品+快速配送"。供應鏈管理能力是其核心競爭力，京東零售的經營利潤率持續提升至4.6%就是效率優化的體現。

弱點同樣明顯：毛利率僅15.6%，遠低於平臺型電商（阿里40%+），這是自營模式的固有侷限；淨利率只有2%出頭，盈利能力薄弱。外賣業務是一場豪賭——2025年外賣虧損148億元，嚴重拖累利潤和現金流。京東在女性用戶、下沉市場、內容化電商方面的短板也長期存在。物流雖是護城河，但也是沉重的成本負擔。

### 管理層簡評

劉強東是京東的靈魂人物，2023年後重新強化對公司的掌控，持股比例升至69.35%（投票權）。劉強東推動了低價策略和外賣業務擴張，展現了強勢決策風格。CEO許冉是財務出身，在"降本增效"方面做出了成績，京東零售利潤率持續提升。但管理層面臨的質疑是：外賣市場投入是否值得？2025年外賣虧損148億元，自由現金流從437億暴跌至65億，這是否是戰略誤判還是長期佈局？劉強東的集權式管理風格有利於決策效率，但也增加了決策風險。

### 估值判斷

當前約10倍PE（Non-GAAP），是港股互聯網公司中最便宜的之一。13091億元的營收體量、強大的物流基礎設施、90萬員工，對應僅3354億港元市值，看起來很便宜。但便宜有其道理：利潤暴跌、自由現金流枯竭、外賣持續燒錢前景不明。如果剔除外賣業務虧損，京東零售本身的估值確實偏低。高盛曾指出"中國電商價值重估空間巨大"，但重估的前提是盈利能力的恢復。

### 初步評級

- 生意質量：★★★
- 護城河強度：★★★
- 管理層質量：★★★
- 估值吸引力：★★★★
- 綜合評分：★★★
- 是否值得深入研究：是（但優先級低於騰訊、美團）
- 一句話總結：萬億營收+自建物流的硬資產價值被低估，但自營電商利潤率先天不足，外賣燒錢是最大變量。

## 網易（9999.HK）

### 核心業務

攜程的護城河來自幾個層面：一是高星級酒店的供給端壁壘，70%的獨家/深度合作關係是多年積累的結果；二是實時房控系統和庫存管理系統的技術優勢；三是品牌在商旅和高端旅遊領域的認知度。攜程81%的毛利率證明瞭其平臺模式的優越性。國際化（Trip.com）打開了增長天花板，入境遊是獨特的結構性機會。

但攜程的競爭環境在惡化：同程藝龍在下沉市場份額不斷增長、抖音以"內容種草+直接預訂"模式快速滲透、京東推出"零佣金三年"爭奪高端酒店。攜程遭受的反壟斷調查也值得警惕，如果被要求降低佣金率，將直接衝擊盈利能力。此外，攜程2025年334億淨利潤中近200億為股權投資收益，核心運營利潤可能只有134億左右，盈利質量需要打折扣。

### 管理層簡評

攜程的管理層正在經歷一輪更替。聯合創始人範敏和季琦已辭任，梁建章仍任執行董事長但更多參與人口研究等學術工作。CEO孫潔自2016年起掌舵，在財務管理和國際化方面表現出色。攜程管理層面臨的質疑主要有兩點：一是高管持續減持（梁建章等合計套現超7億），信號不佳；二是在反壟斷大環境下，攜程可能面臨商業模式的調整壓力。整體管理層的專業性較強，但創始團隊的退出和減持需要關注。

### 估值判斷

按核心運營利潤約134億元計算，當前PE約20倍，並不算便宜。表面上14倍PE有吸引力，但需要剔除大量非經常性投資收益的幹擾。攜程反壟斷調查的不確定性是當前最大的估值壓制因素——如果被要求大幅降低佣金，利潤將顯著受損。81%的毛利率也可能被監管"盯上"。在競爭加劇和監管風險並存的背景下，當前估值談不上低估。股價從613港元高點回落至420港元左右，部分反映了這些風險。

## 騰訊音樂（1698.HK）

### 核心業務

騰訊音樂（TME）是中國最大的在線音樂平臺，旗下擁有QQ音樂、酷狗音樂、酷我音樂三大平臺，合計市場份額約69%。核心業務分為在線音樂服務（訂閱+廣告+數字專輯等）和社交娛樂服務（直播打賞等，佔比持續縮小）。2025年全年總收入329億元，同比增長15.8%，調整後淨利潤99.2億元，同比增長22%。在線音樂訂閱收入177億元，付費用戶1.274億。超級會員突破2000萬，是提升ARPU的關鍵舉措。騰訊音樂還積極拓展IP衍生業務，包括線下演唱會、專輯銷售和粉絲經濟。2026年5月宣佈收購喜馬拉雅，進一步擴展音頻版圖。

### 護城河分析

騰訊音樂的護城河來自其在音樂版權方面的絕對優勢和用戶規模。QQ音樂、酷狗、酷我三大平臺的曲庫資源是行業最全的，69%的市場份額使其在與唱片公司的版權談判中有強大議價權。付費用戶1.274億形成了穩定的訂閱收入基礎。騰訊系的流量支持（微信、QQ）也是競爭對手難以獲取的渠道優勢。

但護城河也在面臨新的挑戰：字節跳動的汽水音樂正在快速滲透，網易雲音樂在社區和個性化推薦方面有差異化優勢。更根本的問題是，音樂流媒體的用戶ARPU偏低（對比視頻流媒體），天花板不高。直播打賞業務持續萎縮，傳統社交娛樂收入在下降。騰訊音樂的收購喜馬拉雅雖然擴展了版圖，但整合風險不容忽視。

### 管理層簡評

騰訊音樂的管理層受騰訊集團的強影響，戰略方向與騰訊整體協同。管理層在訂閱化轉型方面執行力強，將付費率從低個位數提升至行業領先水平，超級會員策略有效提升了ARPU。IP衍生業務（演唱會、周邊）的佈局顯示了管理層在多元變現上的探索。2025年利潤增長22%的同時保持15.8%的收入增長，說明運營效率在持續提升。但管理層面臨的挑戰是如何在汽水音樂的競爭壓力下保持增長勢頭，以及如何整合喜馬拉雅。

### 估值判斷

股價從2025年8月高點103港元暴跌至35港元（跌幅66%），當前PE僅約10倍，在港股互聯網板塊中屬於極低水平。市場大跌的原因包括：2026年Q1增速放緩（收入僅增7.3%）、汽水音樂競爭加劇的擔憂、喜馬拉雅收購的不確定性。但從基本面看，329億收入、99億調整後利潤、44%毛利率、69%市場份額的公司僅值1400億港元，存在明顯的錯殺可能。如果增長能保持在10%以上，10倍PE就是低估。風險在於增長進一步放緩和競爭格局惡化。
