# 泡泡瑪特（9992.HK）財務質量審計報告

**核心問題：2025年賺的130億是真錢還是假錢？2026年利潤質量會怎樣？**

> 報告日期：2026年5月16日 | 股價：163港元 | 市值：2168億港元

---

## 一、結論先行：130億是真錢，但有兩個瑕疵

**總評：利潤質量 ★★★★（4/5）**

2025年泡泡瑪特的130億利潤基本是"真金白銀"。經營現金流128.65億，與GAAP淨利潤127.76億幾乎1:1匹配，現金流轉換效率極高。銀行借款為零，現金儲備137.75億。這是一張教科書級的財務報表。

**但兩個瑕疵值得警惕**：
1. 存貨增速（246%）大幅超過收入增速（185%），週轉天數惡化21天
2. 自由現金流率（FCF/淨利潤=77%）因資本開支和存貨擴張被壓低

> "一個好公司的利潤表可以騙人，但現金流量表很難騙人。" ——巴菲特

**解讀**：

- 但2024年該比率為1.59（現金流大幅超過利潤），2025年降至1.007，原因是營運資本消耗了35.5億——主要來自存貨暴增
- 自由現金流98.8億雖然絕對值可觀，但佔淨利潤的比率從1.47x跌至0.77x，說明增長在"吃"現金

### 2.3 資本開支構成

2025年資本開支9.85億元，同比增長164%，但僅佔營收的2.7%——這是一個極度輕資產的生意模型。

2026年資本開支預計顯著擴大，管理層披露的新投入方向包括：
- 美國門店擴張至超100家（紐約時代廣場、第五大道旗艦店Q4開業）
- 北京主題樂園二期擴建
- 越南工廠已投產，但暫無海外購廠計劃
- 大電影仍處於劇本創作階段
- 首家固定甜品店落戶秦皇島阿那亞

**風險提示**：分紅率從35%降至25%，資金轉向重資產投入，管理精力面臨分散風險。

## 三、利潤質量檢驗

### 3.1 應收賬款質量

```
工具驗算記錄：
============================================================
  應收賬款增速 = (9.21 - 4.78) / 4.78 × 100 = 92.7%
  收入增速 = 184.7%
============================================================
```

| 指標 | 2025年 | 2024年 | 判斷 |
|------|--------|--------|------|
| 應收賬款 | 9.21億 | 4.78億 | +92.7% |
| 收入 | 371.2億 | 130.4億 | +184.7% |
| 應收賬款增速/收入增速 | 0.50x | — | 極度健康 |
| 應收賬款週轉天數 | 7天 | 11天 | 改善4天 |

**判定：A+（完美）**。應收賬款增速僅為收入增速的一半，週轉天數反而從11天壓縮至7天。這意味著公司越做越大，收款反而越快——典型的強勢品牌特徵。泡泡瑪特大量是現金直接零售，渠道話語權極強。

### 3.2 存貨質量——唯一的紅燈

```
工具驗算記錄：
============================================================
  存貨增速 = (56.15 - 16.22) / 16.22 × 100 = 246.2%
  收入增速 = 184.7%
  存貨增速/收入增速 = 1.33x（存貨增速遠超收入增速）
============================================================
```

| 指標 | 2025年 | 2024年 | 判斷 |
|------|--------|--------|------|
| 存貨 | 54.73億（另有數據56.15億） | 15.25億（另有16.22億） | +259% |
| 存貨週轉天數 | 123天 | 102天 | 惡化21天 |
| 存貨/營收 | 14.7% | 11.7% | 上升3pct |

**判定：B-（需要關注）**。存貨增速（246-259%）顯著超過收入增速（185%），週轉天數惡化21天。

管理層解釋的理由：
1. 海外渠道擴張需要更多前置備貨（門店從少到多，物流鏈條變長）
2. LABUBU持續供不應求，主動增加備貨
3. 越南工廠投產增加在途庫存

**但另一方面**：如果2026年LABUBU熱度下降（Q1已有信號），大量存貨可能面臨減值風險。潮玩產品生命週期短，過季存貨價值衰減快。123天意味著平均存貨要4個月才能賣出去——對於潮流消費品來說偏長。

### 3.3 GAAP vs Non-GAAP差異

```
工具驗算記錄：
============================================================
  GAAP淨利潤：127.76億元
  經調整（Non-GAAP）淨利潤：130.84億元
  差異：3.04億元
  差異佔比：2.38%
============================================================
```

**判定：A（極度健康）**。GAAP與Non-GAAP差異僅3億元（2.38%），幾乎可以忽略。調整項主要是股份支付費用。這與某些科技公司動輒30-50%的GAAP/Non-GAAP差異形成鮮明對比。泡泡瑪特沒有利用Non-GAAP調整來"美化"業績。

### 5.3 2026年利潤質量前瞻

- 應收賬款：直營佔比提升，週轉天數有望繼續維持在7天以內

- 資本開支：主題樂園、海外旗艦店、越南工廠，2026年capex可能翻倍至15-20億
- 自由現金流率：如果capex翻倍而營收增速降至20-30%，FCF/淨利潤可能進一步下降

### 核心判斷

**"130億是真錢嗎？"——是的，而且是質量極高的真錢。**

證據：
1. 經營現金流128.65億與淨利潤127.76億幾乎1:1，沒有應計利潤的"虛胖"
2. 零銀行借款、零利息支出，利潤不依賴財務槓桿
3. GAAP/Non-GAAP差異僅3億（2.38%），公司沒有濫用調整項
4. 應收賬款週轉天數7天，說明收入變現極快

**"2026年利潤質量會怎樣？"——大概率維持高質量，但需要監控存貨。**

關鍵觀察點：
- 如果存貨週轉天數從123天繼續惡化至140天以上，可能意味著產品滯銷風險
- 資本開支擴大（樂園、海外門店）會壓低自由現金流率
- 毛利率確定性下降0.5pct（原材料漲價），需要觀察是否通過提價轉嫁

> "評估一個公司的利潤質量，關鍵看三件事：現金流是否跟得上利潤，存貨是否跟得上銷售，應收是否跟得上收入。三者之中只要有兩個跟不上，就該提高警惕。" 
> 
> 泡泡瑪特的情況：現金流跟上了，應收跟上了，存貨沒跟上。三分之二合格，一個需要關注。
