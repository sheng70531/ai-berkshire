# 看懂泡泡瑪特（二）：全世界找不到第二個泡泡瑪特，但歷史不會撒謊

> 上一篇我們拆了泡泡瑪特的商業模式。這一篇回答一個更根本的問題：環顧全球，有沒有跟泡泡瑪特類似的公司？它們後來怎麼樣了？

投資裡有一句老話：太陽底下沒有新鮮事。

泡泡瑪特的故事聽起來很新——盲盒、潮玩、情緒消費、沒有故事的角色。但剝開這層外衣，它本質上在做的事情，前人都做過：**用一個沒有敘事的可愛形象賺錢，靠稀缺性製造溢價，把玩具賣給成年人。**

我找了五家公司來做對標。不是為了簡單類比，而是想從它們的命運裡，找到泡泡瑪特可能的未來。

---

## 一、三麗鷗：最像泡泡瑪特的公司，也是最該研究的公司

三麗鷗是誰？就是凱蒂貓的母公司。一隻沒有嘴、沒有故事、沒有動畫長片撐腰的白色貓咪，活了52年，全產業鏈累計商品零售額估計超過800億美元（第三方估算，指全球所有授權商品的終端銷售總額，史上僅次於寶可夢）。但先把一個容易誤讀的口徑說破：這800億是全世界被授權商賣貨的流水，不是三麗鷗的收入——公司自己近29年（1998-2026財年）的累計淨利潤只有約2,000億日元，摺合約100億人民幣，還不到泡泡瑪特2025年一年的淨利潤。零售額的大頭，留在了被授權商和渠道手裡。

這跟泡泡瑪特的處境驚人地相似。拉布布也沒有故事，茉莉也沒有故事，它們存在的全部意義就是"被看見時讓人心情好一點"。

| 維度 | 三麗鷗 | 泡泡瑪特 |
|------|--------|----------|
| 核心角色 | 凱蒂貓（1974年至今） | 拉布布、茉莉等（2016年至今） |
| 角色有沒有故事 | 沒有，刻意不設定 | 沒有，設計驅動 |
| 收入模式 | 授權為主（佔70%以上） | 自產自銷為主（直營+電商） |
| 最新財年營收 | 2026財年（2026年3月止）1941億日元，約94億人民幣 | 2025年371億人民幣 |
| 最新財年利潤率 | 營業利潤率40.1%（2026財年） | 經調整淨利潤率約35%（2025年） |
| 角色生命週期 | 凱蒂貓52年，但有過10年低谷 | 拉布布約3年，正在巔峰期 |

### 凱蒂貓是怎麼活過52年的？

關鍵不是凱蒂貓有多好，而是三麗鷗做對了幾件事：

**第一，沒有嘴就是最大的護城河。** 三麗鷗社長的原話是："沒有嘴，消費者就會把自己的情緒投射上去。"開心的時候覺得它在笑，難過的時候覺得它在陪你。這種"空白畫布"效應讓凱蒂貓跨越了文化、年齡和性別。拉布布的邏輯一模一樣——那個咧嘴的小怪獸，你說它在笑也行，說它在搞怪也行。

**第二，三麗鷗經歷過真正的至暗時刻。** 2014財年營業利潤衝上210億日元的峰值後，公司經歷了連續7年的利潤下滑（2015-2021財年）：營業利潤一路跌到2020財年的21億、2021財年乾脆轉為營業虧損33億；淨利潤從2017財年的65億跌到2020財年的不到2億，2021財年淨虧39.6億（三麗鷗歷期財報）。原因很簡單：過度依賴凱蒂貓和日本國內市場、線下零售萎縮、新角色孵化乏力，最後疫情補了一刀。

**第三，三麗鷗靠什麼翻身的？** 兩件事——換了年輕的社長（創始人的孫子，上任時才31歲），以及把商業模式從"賣貨"轉向"賣授權"。授權模式輕資產、高毛利，讓三麗鷗從2021年開始進入爆發期。2025財年營業利潤518億日元創歷史新高，約為2020財年低點（21億）的25倍；2026財年（2026年3月止）再上一個臺階——營業利潤779億、淨利潤546億日元，都是公司66年曆史的最高紀錄（2026年6月發佈的決算）。

**這對泡泡瑪特的啟示是什麼？** 凱蒂貓證明瞭"沒有故事的角色"可以活很久，但有一個前提——**公司必須在角色熱度下降時有能力轉型。** 三麗鷗花了7年才完成這個轉型，期間股價腰斬再腰斬。泡泡瑪特遲早也會面對同樣的考驗。

還有一個對標時最容易被忽略的差別：**價值捕獲率。** 三麗鷗的授權模式是"賺小錢、但幾乎不佔資本"——凱蒂貓800多億美元的終端零售流水裡，公司29年累計淨利潤折算下來約100億人民幣；而泡泡瑪特的直營模式把零售額幾乎全部裝進自己的收入表，371億收入對應128億淨利潤。所以兩家公司利潤率看著接近，賺錢的絕對量級差了一個數量級——泡泡瑪特一年的淨利潤，超過三麗鷗29年的總和。三麗鷗告訴你這個物種能活多久，但它從來沒告訴你這個物種能長多大——泡泡瑪特已經長到了三麗鷗從未到過的地方，這既是它的成就，也意味著前面沒有地圖。

## 二、萬代南夢宮：內容驅動型的對照組

萬代是另一個極端。高達靠動畫續命，龍珠靠漫畫續命，航海王靠連載續命——它們的角色之所以活了幾十年，是因為不斷有新的故事餵給消費者。

| 維度 | 萬代南夢宮 | 泡泡瑪特 |
|------|-----------|----------|
| 核心角色 | 高達、龍珠、航海王 | 拉布布、茉莉、小甜豆 |
| 角色驅動力 | 動畫/漫畫/遊戲持續產出 | 設計師新系列 + 盲盒機制 |
| 2025財年營收 | 約1.24萬億日元（約600億人民幣） | 371億人民幣 |
| 玩具業務營收 | 約5100億日元（約250億人民幣） | 371億人民幣（全部是玩具相關） |
| 核心用戶 | 男性為主，全年齡 | 女性75%，30歲以下58% |
| 增長引擎 | 遊戲大作（如《艾爾登法環》）週期性拉動 | 新角色 + 海外擴張 |

萬代的模式泡泡瑪特幾乎不可能複製。原因很直接：泡泡瑪特沒有內容生產能力，也沒有在建。它不拍動畫，不做遊戲，不連載漫畫。角色的生命力完全依賴設計迭代和營銷節奏。

但萬代的數據提供了一個參照系：**一個成熟的角色經濟公司，長期年收入的天花板大概在什麼位置。** 萬代的玩具業務做了幾十年，穩定在250億人民幣左右。泡泡瑪特2025年已經做到371億，增速放緩到20%之後，體量上已經不小了。

## 三、迪士尼：泡泡瑪特夠不著的飛輪

迪士尼經常被拿來跟泡泡瑪特對標，王寧自己也說過"想做中國的迪士尼"。但坦率地說，這個對標有點不切實際。

| 維度 | 迪士尼 | 泡泡瑪特 |
|------|--------|----------|
| 2025財年總營收 | 約944億美元（約6800億人民幣） | 371億人民幣 |
| 衍生品/授權收入 | 約53億美元，利潤率53% | 371億（幾乎全部是衍生品） |
| 飛輪 | 電影→角色→衍生品→樂園→流媒體 | 設計→盲盒→門店→樂園（剛起步） |
| 內容投入 | 每年數十億美元 | 幾乎為零 |
| 樂園投入 | 上海迪士尼300億+ | 泡泡瑪特城市樂園3億 |

迪士尼的核心是一個內容飛輪：先花幾億美元拍一部《冰雪奇緣》，角色火了之後賣玩具、賣衣服、開主題區。每一環都在強化下一環。

泡泡瑪特沒有這個飛輪。它的角色不是從故事裡長出來的，是從設計師的畫板上長出來的。這意味著它不需要花幾億美元拍電影——這是優勢；但也意味著角色缺少敘事錨點——這是劣勢。

泡泡瑪特的城市樂園投了3億，佔地4萬平方米，對標的是吉卜力美術館那種"輕量級體驗"，不是迪士尼那種重資產樂園。方向是對的，但規模差了兩個數量級。

**結論：拿泡泡瑪特對標迪士尼，不如拿它對標三麗鷗。迪士尼是內容公司，泡泡瑪特是角色公司，根本不是一個物種。**

## 四、反面教材一號：為什麼必須研究透徹的公司

說完了正面案例，接下來說反面的。這家公司是美國最大的潮玩公司，2017年上市，一度風光無限，然後摔得很慘。

| 維度 | 這家美國潮玩公司 | 泡泡瑪特 |
|------|-----------------|----------|
| 上市時間 | 2017年 | 2020年 |
| 巔峰營收 | 13.2億美元（2022年） | 371億人民幣（2025年） |
| 2025年營收 | 9.08億美元（2025年年報，2026-07核查） | 371億人民幣 |
| 最新市值 | 約2.5億美元 | 約2000億港元 |
| 核心模式 | 授權別人的角色做手辦 | 自有+獨家簽約角色做盲盒 |
| 產品均價 | 10-15美元 | 59-99元人民幣 |
| 用戶畫像 | 35歲，男女各半 | 30歲以下58%，女性75% |

### 它是怎麼垮的？

故事分三段：

**第一段：高速增長（2017-2021）。** 靠不斷拿新的影視角色授權，營收從6.5億美元一路衝到10.3億美元。邏輯很簡單——每出一部新電影，就做一波對應的手辦。漫威、星球大戰、哈利波特、權力的遊戲，什麼火做什麼。

**第二段：庫存危機（2022-2023）。** 問題出在2022年。公司過於樂觀地備了大量庫存，結果需求急轉直下。2023年更慘：公司宣佈銷燬3000萬至3600萬美元的多餘庫存，全年淨虧損1.54億美元。

**第三段：掙扎求存（2024-2026）。** 2024年勉強把虧損收窄到1470萬美元，但營收繼續下滑到10.5億美元。2025年更差，上半年營收同比下滑超過20%，僅第二季度就虧了4100萬美元。到2026年初，公司市值只剩2.5億美元，債務卻高達2.25億美元。2026年的指引是"持平到增長3%"——對於一家潮玩公司來說，這基本就是躺平。

### 泡泡瑪特跟它有什麼本質區別？

**區別一：自有角色對比授權角色。** 這是最核心的差異。那家公司80%以上的收入來自別人的角色，每賣一個手辦都要交授權費，利潤率天然受限。更致命的是，它沒有定價權——角色不是自己的，消費者的忠誠度在角色身上而不在品牌上。泡泡瑪特的茉莉、SKULLPANDA、DIMOO 版權已經買斷；拉布布所屬的 THE MONSTERS 版權雖仍歸藝術家龍家昇，但泡泡瑪特持有約至2030年4月的全球獨家開發權和中國獨家銷售權。2025年報顯示，全部設計及授權費合計9.5億元、僅佔收入約2.6%，遠低於那家公司約17%的版稅率，利潤率高得多。

**區別二：情感連接深度不同。** 那家公司的手辦本質上是"影視周邊"。消費者買蜘蛛俠手辦，是因為喜歡蜘蛛俠，不是因為喜歡這個品牌。泡泡瑪特的用戶買拉布布，很多時候不是因為它"代表"什麼故事，而是單純喜歡這個形象本身。這種沒有中間商的情感連接，黏性更強。

**區別三：稀缺性管理能力不同。** 那家公司的策略是"什麼火做什麼"，瘋狂鋪貨，最後庫存堆積如山。泡泡瑪特至少在前期做了更好的稀缺性管理——盲盒機制、隱藏款、限定款，都在製造"不容易得到"的感覺。

**但也有一個相似之處讓人警惕：** 兩家公司都高度依賴"持續推新"來維持增長。那家公司需要不斷拿新的影視角色授權，泡泡瑪特需要不斷推出新系列、新角色。一旦推新的節奏放慢，或者消費者對新品的熱情下降，增長就會斷檔。那家公司已經掉進了這個陷阱。泡泡瑪特現在還沒有，但2026年增速從184%驟降到"不低於20%"，這個減速本身就值得警惕。

## 五、反面教材二號：歷史上最著名的收藏品泡沫

1990年代末，美國出現過一次瘋狂的收藏品泡沫。一種5美元的豆豆玩偶，被炒到幾千美元一隻。巔峰的1998年，製造商銷售額超過14億美元，利潤據信超過7億美元，超過了美泰和孩之寶的總和。

然後泡沫破了。

| 維度 | 那次收藏品泡沫 | 泡泡瑪特二手市場 |
|------|---------------|------------------|
| 原價 | 5美元 | 59-99元人民幣 |
| 巔峰溢價 | 數百倍 | 3-10倍 |
| 稀缺性來源 | 限量退役 + 小店獨家 | 盲盒隨機 + 限定款 |
| 崩盤觸發 | 公司宣佈全線退役後反而恐慌拋售 | 官方大規模補貨打破稀缺預期 |
| 崩盤幅度 | 跌去98% | 部分款式跌去80%以上 |
| 製造商結局 | 公司仍在運營，但規模縮水90%以上 | 待觀察 |

### 二手價暴跌的模式是否相似？

**相似度很高，但有一個關鍵區別。**

相似之處：

- 都是"人為稀缺性"催生的溢價。據公開報道，拉布布毛絨的月產能一度提升至約3000萬隻，二手價應聲崩盤。這跟那次泡沫後期過度生產導致的價格崩潰如出一轍。
- 都有"商家公開暫停收購"的信號。這是二手市場信心崩潰的標誌性事件。
- 拉布布3代的部分隱藏款從巔峰跌去了88%。那次泡沫裡，那些豆豆玩偶最終跌去了98%。路徑高度一致。

**關鍵區別在於：** 泡泡瑪特不只是一個收藏品公司，它還有龐大的一手零售業務。那次泡沫裡的製造商本質上就是在賣收藏品，二手市場崩了，一手市場也沒了。但泡泡瑪特的大部分消費者是買來自己玩的，不是買來炒的。二手市場的崩盤確實會傷害品牌形象，但只要一手購買需求還在，公司就不會像那個豆豆玩偶一樣徹底崩盤。

這引出一個核心問題：**泡泡瑪特的消費者裡，到底有多少是"玩家"，多少是"炒家"？** 如果炒家佔比很高，那二手價暴跌就是危險信號。如果玩家才是主體，那二手價跌了反而是好事——更多真正喜歡的人買得起了。

## 總結：泡泡瑪特到底最像誰？

| 對標公司 | 相似度 | 泡泡瑪特可以學到什麼 | 最大風險警示 |
|----------|--------|---------------------|-------------|
| 三麗鷗 | ★★★★★ | "空白畫布"角色可以活50年，但中間會有漫長低谷 | 必須提前準備"第二曲線"，三麗鷗花了7年才走出來 |
| 萬代南夢宮 | ★★☆☆☆ | 內容驅動的角色經濟更穩定，但泡泡瑪特走不了這條路 | 沒有內容續命，角色生命週期天然更短 |
| 迪士尼 | ★★☆☆☆ | 飛輪效應是終極目標，但差距太大 | 不要試圖做中國迪士尼，做好中國三麗鷗就很了不起 |
| 美國潮玩公司 | ★★★★☆ | 自有或獨家簽約的角色比純授權角色值錢得多，這是泡泡瑪特的結構性優勢 | "持續推新"的增長模式一旦失速，會非常難看 |
| 90年代收藏品泡沫 | ★★★☆☆ | 人為稀缺性是雙刃劍，補貨策略直接決定品牌命運 | 二手價暴跌已經在發生，必須密切關注一手需求是否受影響 |

**我的判斷：泡泡瑪特最可能走的路是"三麗鷗路徑"——先高速增長，然後經歷一個痛苦的減速期甚至衰退期，最後如果管理層夠聰明，通過商業模式轉型（比如從賣貨轉向授權）實現第二次增長。**

但前提是：管理層得在高速增長的時候就開始準備過冬的糧草，而不是等到冬天來了才慌。三麗鷗在低谷期換了社長才翻身，泡泡瑪特的王寧還在盛年——這是優勢，也是風險。優勢是他有時間和精力來駕馭轉型；風險是，一個在順風局裡從沒輸過的創始人，能不能在逆風局裡做出正確的決策。

至於最壞的可能——拉布布變成下一個豆豆玩偶——我認為概率不大，但不能排除。泡泡瑪特不是隻有拉布佈一個角色，它有一個角色矩陣。但目前拉布佈一個角色就貢獻了38%的收入，這個集中度太高了。如果拉布布真的過氣了，其他角色能不能接上，是一個沒有被驗證過的問題。
