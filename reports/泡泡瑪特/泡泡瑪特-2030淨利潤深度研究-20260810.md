# 泡泡瑪特（Pop Mart, 09992.HK）2030 年淨利潤深度研究

> **研究問題**：泡泡瑪特 5 年後（到 2030 年）的淨利潤預測會是多少？含四個子問題——(1) 基於歷史財務、券商預測與增長驅動測算 2030 淨利潤合理區間；(2) 消費者對潮玩產品的長期喜好是否可持續、盲盒/IP 收藏品的復購與留存趨勢；(3) Labubu（THE MONSTERS 系列）熱度週期處於什麼階段、是否會退潮及退潮時點與幅度；(4) IP 矩陣（MOLLY、SKULLPANDA、DIMOO、CRYBABY 等）能否接替 Labubu 的增長貢獻，IP 孵化運營、海外擴張、品類拓展能否支撐持續增長。
>
> **完成日期**：2026-08-10
> **方法**：5 個搜索角度並行 → 抓取 21 個信源 → 提取 98 條聲明 → 對 25 條核心聲明做 3 票對抗式核驗（需 2/3 反駁才推翻）→ 綜合去重後保留 7 條結論。核驗結果：25 條全部確認、0 條被推翻。
> **免責**：本報告為研究記錄，2030 淨利潤區間為基於券商 2026-2028 一致預期的外推測算，非券商原始預測，不構成投資建議。

---

## 一、執行摘要

沒有券商直接預測泡泡瑪特 2030 年淨利潤。三家券商（信達、第一上海、東吳）對 2026-2028 年歸母/經調整淨利潤的一致預期落在 **150-218 億元** 區間，增速由 2025 年的三位數爆發（歸母 127.76 億元、同比 +308.8%）逐年回落至約 15-20% 的常態化水平。

以 2028 年約 210-218 億元為錨、按券商隱含的 15-20% 放緩增速外推兩年，**2030 年歸母淨利潤的合理區間約 270-400 億元人民幣，中樞約 300-330 億元** 。若 IP 矩陣接力與海外擴張兌現則偏上沿；若 Labubu 快速退潮且其他 IP 未能顯著補位則偏下沿甚至低於此區間。

消費者黏性與 IP 接力方面證據偏正面：Labubu 熱度確已從 2025 下半年回落，但星星人已成為亞洲除 Labubu 外最受歡迎的 IP，MOLLY / SKULLPANDA / CRYBABY / DIMOO 等多個 IP 收入破 10-35 億元、公司形成"一超多強"矩陣，降低了對單一 IP 的依賴。

**核心不確定性有兩點** ：Labubu 退潮的時點與幅度（當前佔營收 38.1%、集中度過高曾引發財報後股價單日跌超 15%），以及非 Labubu IP 能否在海外市場持續接棒。這兩點是 2030 預測偏差的最大來源。

## 二、核驗結論（7 條，均經 3 票對抗式核驗）

### 結論 1｜2030 淨利潤區間：270-400 億元、中樞約 300-330 億元（外推）

- **置信度**：高
- **核驗**：3-0（多個一手研報），其中 2030 外推為綜合分析、非研報原話
- **證據**：信達證券預計 2026-2028 歸母淨利潤 150.5 / 181.0 / 217.5 億元（增速 +17.83% / +20.21% / +20.21%）；第一上海預計 2026-2028 股東淨利潤 149.62 / 179.41 / 210.75 億元（經調整口徑 150.48 / 180.41 / 211.90 億元）；東吳證券預計 2025-2027 歸母 92.68 / 134.84 / 170.75 億元、經調整上調至 100.3 / 144.9 / 182.9 億元。三家 2028 錨點集中在 210-218 億元。券商隱含增速已從 2025 年三位數降至 15-20%，以 2028 年約 215 億元按 15-20% 外推兩年得約 270-310 億元（12-15% 更保守約 270-285 億元、20% 樂觀約 310 億元），綜合區間 270-400 億元、中樞約 300-330 億元。
- **信源**：信達研報 PDF、第一上海研報 PDF、東吳研報 PDF

### 結論 2｜最新基期已確立：2025 年營收 371.2 億、淨利約 127.76-130.1 億、毛利率 72.1%

- **置信度**：高
- **核驗**：3-0，多來源一致（英文引用存在"億/billion"單位誤譯，中文數值正確）
- **證據**：2026-03-25 發佈的 2025 年報經多來源交叉驗證：營收 371.2 億元（+184.7%）、首破 300 億；淨利潤 127.76 億元（+308.8%，母公司股東應佔口徑）或 130.1 億元（+293.3%，年內溢利口徑）、經調整 130.8 億元（+284.5%）；毛利率 72.1%（前值 66.8%）。2024 基數營收 130.38 億、淨利 31.25 億，2025 淨利約為其 4 倍。券商實際 2025 預測（如東吳 92.68 億、經調整 100.3 億）反而低於真實值，說明基期偏保守、外推有上修空間。
- **信源**：新浪財經、華爾街見聞、新京報

### 結論 3｜高增長趨於常態化：CEO 目標 2026「不低於 20%」，增速逐年回落

- **置信度**：高
- **核驗**：3-0（一手研報 + 發佈會口徑）
- **證據**：王寧在 2025 年報發佈會將 2026 年定為"休整年"、目標增長"不低於 20%"。第一上海預測營收 2025-2028 為 371.20 / 444.99 / 520.92 / 597.74 億元，增速 +184.7% / +19.9% / +17.1% / +14.7%；信達預測營收 371.20 / 452.98 / 544.99 / 649.82 億元，增速約 +22% / +20% / +19%，EPS 由 9.61 升至 16.22 元。高增長逐步常態化是 2030 外推的基礎假設。
- **信源**：華爾街見聞、第一上海研報 PDF、信達研報 PDF

### 結論 4｜IP 矩陣「一超多強」成形，降低單一 IP 依賴（樂觀情形的關鍵支柱）

- **置信度**：高
- **核驗**：3-0（半年報/全年報 + 研報），個別接力表述有分歧但主力 IP 事實成立
- **證據**：2025 全年 SKULLPANDA 35.4 億、CRYBABY 29.3 億、MOLLY 29.0 億、DIMOO 27.8 億、星星人 20.6 億元，均同比增長；2025H1 有 5 個 IP 破 10 億（MOLLY 13.6 / SKULLPANDA 12.2 / CRYBABY 12.2 / DIMOO 11.1 億）、另 13 個藝術家 IP 過億。第一上海指出星星人已成"亞洲市場除 Labubu 外最受歡迎 IP"，摩根士丹利估其 2026 中國銷售或達 Labubu 約一半。東吳看好 Labubu 和 MOLLY 兩個"有望常青"頭部 IP 提供現金流與流量支撐。
- **信源**：新浪財經、新華網、華爾街見聞、第一上海研報 PDF

### 結論 5｜Labubu 熱度已從 2025 下半年高點回落進入退潮早期，但仍是最大單一 IP、集中度過高構成核心風險

- **置信度**：高
- **核驗**：3-0（財報 + 研報 + 媒體交叉驗證）
- **證據**：THE MONSTERS 2025 全年營收 141.6 億元（+365.7%）、佔總營收 38.1%（2024 年為 23%），H1 為 48.1 億元（+668%）、佔 34.7%、唯一破 40 億的頭部 IP。單一 IP 集中度引發投資者擔憂、財報發佈後股價一度跌超 15%（CNBC 記收盤跌超 22%）。第一上海明確"Labubu 熱度較去年下半年回落"，二級市場星星人二手價一度反超 Labubu、mini Labubu 二手價從峰值跌 24%。東吳列示"頭部 IP 熱度自然衰減但其他 IP 收入尚未貢獻顯著收入"為核心風險。退潮已啟動但幅度/時點未定。
- **信源**：華爾街見聞、新浪財經、東吳研報 PDF、第一上海研報 PDF

### 結論 6｜海外擴張是當前最強增長引擎，但海外佔比尚未過半、且 Labubu 熱度高度由海外驅動

- **置信度**：高
- **核驗**：3-0，"海外驅動"表述略有外延但載體數據準確
- **證據**：2025H1 美洲區營收 22.6 億元（+1142.3%，線上 +1977.4%）、歐洲及其他區 4.8 億元（+729.2%），全球門店 18 國 571 家。海外合計約 55.9 億元佔總營收約 40%，中國大陸約 82.8 億元（約 60%）仍為主體——海外是增長引擎但非營收多數。東吳將"海外拓展不及預期"列為核心風險，海外擴張兌現度是 2030 區間上下沿的關鍵擺動因素。
- **信源**：新華網、新浪財經

### 結論 7｜券商普遍維持「買入」，估值給到 2026 年 20-30 倍 PE

- **置信度**：高
- **核驗**：3-0（一手研報）
- **證據**：東吳給予 2026 年 30 倍 PE、對應 4346 億元市值、較 2025/8/8 有 28% 空間、維持買入；第一上海目標價 226 港元（較 152.4 港元收盤價有 48.3% 空間）、基於 2026 財年經調整淨利潤 20 倍。東吳認為"短期市場過度關注 Labubu 邊際熱度、低估 IP 矩陣長期價值"。PE 區間 20-30 倍的分歧本身反映 Labubu 退潮與 IP 接力能否成立的市場不確定性。
- **信源**：東吳研報 PDF、第一上海研報 PDF

## 三、侷限與告警

1. **2030 數字是外推、非券商預測** 。本報告 2030 區間（270-400 億元、中樞 300-330 億元）為基於 2026-2028 券商錨點按 15-20% 放緩增速的綜合外推，誤差隨年限放大，屬分析判斷而非研報原話。
2. **時效性** 。2025 年報（2026-03 發佈）與三份研報（2025-08 至 2026-05）為最新，但潮玩行業與單一 IP 生命週期波動快，Labubu 退潮速度可能在數季度內改變全部假設。
3. **源質量瑕疵** 。第一上海與東吳的 PDF 託管於阿里雲 OSS 測試桶（testtoo1.oss-cn-hangzhou）而非東方財富官方域名，屬託管異常，但核心數字經獨立媒體交叉驗證；多條英文引用存在"億"誤譯為"billion"的 10 倍單位錯誤，被審的中文原始數值正確。
4. **券商系統性低估** 。券商 2025 實際預測（東吳歸母 92.68 億 vs 實際 127.76 億）明顯偏低，說明模型對爆發力存在系統性低估，外推可能偏保守。
5. **接力證據的分類瑕疵** 。THE MONSTERS × FIFA 被部分信源歸為"Labubu 之外 IP"實屬 Labubu 家族，接力證據中此點分類有誤；"售罄"部分源於飢餓營銷而非純有機需求，作為長期黏性代理偏弱。
6. **淨利潤口徑不統一** 。母公司股東應佔 127.76 億 / 年內溢利 130.1 億 / 經調整 130.8 億，跨券商比較時需注意可比性。

## 四、待解問題（研究盲區）

1. **Labubu 退潮的量化衰減曲線** ：從 2025 下半年高點回落後，THE MONSTERS 佔比 38.1% 將在 2027-2030 如何演變？軟著陸還是斷崖式下滑？現有證據只確認"已回落"，未給出量化衰減曲線。
2. **非 Labubu IP 的海外接棒能力** ：星星人、CRYBABY、MOLLY 等能否在海外複製 Labubu 的破圈成功？當前接力證據主要來自中國/亞洲市場，海外接棒能力未被數據充分驗證。
3. **新品類的利潤增量** ：樂園、遊戲、飾品對 2030 淨利潤的增量貢獻有多大？現有核驗聲明幾乎未覆蓋城市樂園、遊戲、飾品等品類拓展的財務數據與盈利模型。
4. **利潤率能否維持** ：2025 毛利率已達 72.1% 歷史高位，規模擴張、海外佔比提升、渠道結構變化對未來利潤率的影響方向未明確；淨利率走向比毛利率更關鍵。
