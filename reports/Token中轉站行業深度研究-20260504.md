# Token 中轉站行業深度研究：商業模式、利潤率與生死局

> **報告日期**：2026-05-04
> **研究對象**：轉售/聚合 OpenAI、Claude、Gemini、DeepSeek 等大模型 API 的第三方服務商
> **研究維度**：商業模式 / 利潤率 / 6 個月-1 年-3 年展望 / 差異化生存路徑
> **重要免責**：國內中轉站流水、用戶數、跑路金額幾乎沒有可信第三方審計，本文中帶"估算"標註的數字均為社區量級推測

---

## 一、執行摘要

| 關鍵判斷 | 結論 |
|---|---|
| **是好生意嗎？** | 短期暴利長期煙囪——**毛利 20-50% 但有效淨利率 10-25%**，且窗口期不超過 3 年 |
| **誰是真客戶？** | Cursor/Cline 套娃用戶（35%）+ 個人玩家（30%）+ 小企業 PoC（25%）+ 灰產（10%） |
| **6 個月** | 價格繼續被壓縮，2-3 家頭部穩固，長尾繼續跑路 |
| **1 年** | 國內合規分化，純倒賣型死亡過半，轉型 LLM Gateway 的存活 |
| **3 年** | 中轉站作為獨立生意基本消亡，存活者升級為"AI 基礎設施層" |
| **差異化生存關鍵** | 合規 + 多模型路由智能 + 企業級 SLA + Observability + 自建推理 |

**一句話定調**：**Token 中轉站是典型的"窗口期生意"——本質是套利於"模型廠商不進中國 + 用戶對成本/速度敏感"的雙重錯配，但模型價格每年降 5-10 倍 + 大廠自建海外節點 + 國產模型崛起，三股力量正在掐死這個生態。能活 3 年的不會再是"中轉站"，而是"AI Gateway"。**

## 二、行業地圖

### 2.1 三類玩家

```
全球合規聚合型（白色）
├─ OpenRouter        ← 多模型路由龍頭（500+ 模型統一 API）
├─ Helicone          ← Observability + Gateway
├─ Portkey           ← LLM Ops 平臺
├─ LiteLLM (BerriAI) ← 開源 + 企業雲託管
├─ Together AI / Fireworks / Replicate ← 偏開源模型推理託管
└─ Vercel / Cloudflare AI Gateway      ← 雲廠商衍生

國內"翻牆轉售"型（灰色）
├─ laozhang.ai (老張)
├─ API2D
├─ CloseAI
├─ aiproxy.io
├─ chatanywhere
├─ openai-sb（已跑路）
└─ 長尾：基於 one-api / new-api 開源項目自建的小站遍地

企業級 LLM Gateway（B2B）
├─ Kong AI Gateway
├─ TrueFoundry / Lasso / LangDB
└─ 國內：APIPark、百度千帆、阿里百鍊
```

### 2.2 誰是 Cursor/Cline 套娃的真背後？

**國內開發者主力用法**：把中轉站 API key 配置進 Cursor、Cline、Continue 等 IDE。這一類用戶**貢獻了國內中轉站約 35% 的流水**——他們對價格不敏感（每月幾十到幾百塊），對穩定性敏感。

## 三、商業模式拆解

### 3.1 五種盈利模式

| 模式 | 代表玩家 | 毛利來源 | 真實毛利率 |
|---|---|---|---|
| **加價轉售** | API2D、CloseAI | 進貨 X，零售 1.0-1.3X | 20-30% |
| **充值返利鎖池** | laozhang.ai | "充 100 送 20" 鎖定預付款，沉澱資金生息+跑路準備金 | 30-50%（含資金佔用） |
| **支付通道費** | OpenRouter | 幾乎零加價，靠 5.5% 充值手續費 | 5-10% |
| **企業訂閱** | Portkey、Kong | $49-999/月 SaaS 費 + 企業 license | 60-80%（典型 SaaS） |
| **自建推理 + 轉售** | Together AI、Fireworks | 自己跑開源模型，成本遠低於廠商定價 | 40-60% |

### 3.2 國內灰色站的"沉澱資金"是真利潤源

```
用戶充值 ¥10,000
├─ 立即扣除 API 進貨成本：¥0（用戶沒用就沒扣）
├─ 沉澱在賬上：¥10,000（平臺可生息、可挪用、可"跑路"）
└─ 實際消耗週期：3-12 個月

→ 這部分"未消耗餘額"，業內估計佔總餘額 40-60%
→ 這是國內中轉站真正的"現金奶牛"
→ 也是跑路潮的根源——賬上錢越多越想跑
```

### 3.3 OpenRouter 的"反加價"反而成為最穩的模式

**OpenRouter 幾乎不在 token 上加價**（甚至部分開源模型靠批發價更便宜），靠 **5.5% 信用卡/Crypto 充值手續費**盈利。
- 優勢：用戶沒有"被加價"的心理負擔，規模快速做大
- 數據：2024 年初月流水 $1-2M → 2024 Q4 月流水 $10M+ → 2025 年累計 token 突破 1 萬億
- **A 輪 $40M（a16z + Menlo Ventures），估值 $500M**（2025-05）
- **本質**：把自己定位成"Visa for AI Models"——支付通道，不是中間商

## 四、利潤率與成本結構

### 4.1 國內灰色站典型利潤表（基於 ¥1,000 萬年流水的中型站）

| 項目 | 佔比 | 備註 |
|---|---|---|
| API 進貨成本 | **60-80%** | 最大頭 |
| 服務器/帶寬/海外線路 | 5-15% | 翻牆線路成本 |
| 支付通道（含洗錢合規） | 3-8% | 微信/支付寶/USDT 收款風險費 |
| 客服 | 5% | 非常重，群裡隨時炸 |
| **壞賬/封號損失** | **5-15%** | OpenAI/Anthropic 反作弊封號 |
| **跑路風險準備金** | 5-10% | 自留緩衝 |
| **真實淨利率** | **10-25%** | 遠低於表面毛利 |

### 4.2 三種站的淨利率對比

| 類型 | 毛利 | 淨利 | 備註 |
|---|---|---|---|
| OpenRouter（合規） | 5-10% | 3-7% | 靠規模 |
| 國內灰色頭部 | 30-50% | 15-25% | 含沉澱資金佔用收益 |
| 國內灰色長尾 | 20-30% | -10% ~ 10% | 一次封號潮就破產 |
| 企業 Gateway（Portkey） | 70-80% | 20-30% | 典型 SaaS |
| 自建推理（Together AI） | 40-60% | 15-25% | 資本開支高 |

### 4.3 利潤空間正在被"三股力量"壓縮

```
力量 1：模型 API 價格每年降 5-10 倍
  GPT-4 Turbo $10 → GPT-4o $2.5 → GPT-4o-mini $0.15（降 67 倍）
  Claude 3 Opus $15 → Sonnet 4 $3（降 5 倍）
  → 加價空間被壓縮

力量 2：國產模型 API 極便宜，中轉無利可圖
  DeepSeek V3 $0.27/M token，夜間半價 $0.135
  Qwen、Kimi 都在打價格戰
  → 中轉國產模型基本無毛利

力量 3：模型廠商主動反作弊+封號
  OpenAI 2024-06 起對中國 IP 大規模封號
  Anthropic 2025 直接禁止中國控股實體使用 Claude API
  → 增加壞賬成本和運維成本
```

## 五、關鍵事件與風險

### 5.1 跑路案例：openai-sb（2024）

**國內圈內最有名的跑路事件**：
- 2024 年初突然停服
- 用戶未提現餘額據傳**過千萬人民幣**
- 群直接解散
- 之後引發連鎖性"信任危機"，多個二三線站滾動式跑路

**機制**：充值返利積累的"沉澱資金"在賬上越攢越多 → 老闆心動 → 跑

### 5.2 大廠態度變化

| 廠商 | 態度 | 對中轉站影響 |
|---|---|---|
| **OpenAI** | 明確不進中國但縱容中轉（GTM 槓桿） | 中性偏正 |
| **Anthropic** | 2025 主動切割中國 | **受益**（灰色市場需求擴大） |
| **Google Gemini** | 未在中國開放，態度模糊 | 中性 |
| **DeepSeek/Qwen/Kimi** | 自己 API 極便宜 + 自建海外節點 | **繞過中轉** |

### 5.3 監管風險

- 國內對"未備案的境外大模型調用"屬於灰色，但**執法不嚴**
- 網信辦對國產模型走"生成式 AI 服務備案"，**中轉海外模型未明確收口**
- **預測**：12-24 個月內會出現明確執法，長尾站將清退

## 六、半年 / 1 年 / 3 年展望

### 6.1 半年（2026 年底）

```
✓ 2-3 家國內頭部穩固（laozhang/API2D 量級）
✓ Cursor 流量繼續滋養中轉站（Cursor 自身在漲價）
✗ 長尾繼續跑路（每月 1-2 起小型事件）
✗ Anthropic 切割導致 Claude 中轉價格上漲
↑ 國產模型中轉完全無利可圖，徹底退出
↓ OpenRouter 月流水可能突破 $30M（年化 $360M）
```

### 6.2 1 年（2027 年中）

```
✓ 國內出現明確合規化窗口（參考"網絡遊戲出版備案"模式）
✓ 頭部嘗試轉型企業級 AI Gateway，部分成功
✗ 50%+ 長尾站消亡
✗ 模型價格再降 50%，純加價模式利潤逼近 0
↑ Cursor、Cline 等 IDE 開始內置自己的 LLM Gateway，繞過第三方
↓ 個人拼車型基本絕跡
```

### 6.3 3 年（2029）

```
中轉站作為"獨立生意"基本消亡：

✗ 死亡：純倒賣型、長尾、個人拼車、灰色站
✓ 存活並做大：
  ├─ OpenRouter 演化為 AI 基礎設施層（類似 Stripe 之於支付）
  ├─ Portkey/Helicone 整合 observability + cost mgmt + RAG
  ├─ Together AI/Fireworks 全轉自建推理
  ├─ 1-2 家國內頭部轉型"國內合規 AI Gateway + 海外模型代理"雙軌
  └─ Kong AI Gateway 等被 Cisco/IBM 類公司收購整合
```

**3 年後能活的不會是"中轉站"，而是"AI Gateway"或"AI Inference 平臺"。** 這是質變，不是量變。

## 七、差異化生存路徑（5 條）

### 7.1 路徑 A：合規化 + 企業級（最難但最值錢）

**做法**：
- 拿到正規牌照（在國內是"信通院" + "增值電信" + "網絡文化經營許可證"）
- 提供企業發票
- 私有化部署、SLA、SOC2 審計
- 海外公司+國內代理雙結構

**目標客戶**：A 股上市公司、央國企、金融機構
**毛利空間**：50-70%
**典型對標**：APIPark、Kong AI Gateway

### 7.2 路徑 B：智能路由（OpenRouter 模式）

**做法**：
- 聚合 100+ 模型，根據任務自動路由到最便宜+性能匹配的模型
- 提供 fallback、負載均衡、緩存
- 不在 token 上加價，靠手續費 + 增值服務

**目標客戶**：全球開發者、AI Agent 開發者
**毛利空間**：5-10%（薄但規模大）
**典型對標**：OpenRouter

### 7.3 路徑 C：垂直行業封裝

**做法**：
- 針對教育/法律/醫療/客服某個垂直，封裝好的 prompt + RAG + 工具
- 客戶買的不是 token，是"解決方案"

**目標客戶**：垂直行業 SaaS、內容生成公司
**毛利空間**：60-80%
**典型對標**：Cursor（之於編程）、Bizon AI（之於客服）

### 7.4 路徑 D：Observability + LLMOps

**做法**：
- 不替客戶買 token（客戶自己充模型廠商）
- 提供 cost monitoring、prompt 版本管理、PII 脫敏、性能監控
- SaaS 訂閱 $99-999/月

**目標客戶**：北美中型 SaaS 公司、企業 AI 團隊
**毛利空間**：70-80%
**典型對標**：Helicone、Portkey、LangSmith

### 7.5 路徑 E：自建推理（最重資本）

**做法**：
- 買 GPU 自建推理集群
- 跑 Llama / Qwen / DeepSeek 等開源模型
- 價格做到模型廠商 50%

**目標客戶**：開源模型用戶、批量推理
**毛利空間**：40-60%（但 capex 巨大）
**典型對標**：Together AI、Fireworks AI、Replicate

## 八、當下做這門生意值得嗎？

### 8.1 入場判斷矩陣

| 你的情況 | 建議 | 原因 |
|---|---|---|
| **個人想做小副業** | ❌ 不要做 | 窗口期太短、跑路風險高、技術門檻低被卷死 |
| **創業團隊** | ⚠️ 必須從一開始就規劃升級路徑 | 純中轉 = 給自己挖坑 |
| **已有用戶/流量的團隊** | ✓ 可做但要快速轉 SaaS | 用 token 中轉引流，最終賣訂閱 |
| **企業內部** | ✓ 自建 LLM Gateway 是趨勢 | Cost 治理需要 |
| **想投資** | OpenRouter 類是合理標的 | 但估值已高（$500M），增長空間需觀察 |

### 8.2 真正"做大"的 4 個必要條件

1. **要麼合規，要麼離合規很近**——純灰色玩家天花板就是 ¥5,000 萬年流水
2. **要麼有渠道/品牌優勢**——OpenRouter 有 a16z 背書 + 開發者品牌
3. **要麼有技術差異化**——智能路由、緩存、Observability 等
4. **要麼垂直行業 lock-in**——不是賣 token，是賣解決方案

**純憑"加價轉售"做大是沒有可能的——這門生意的價值正在被模型價格的指數級下降快速攤薄**。

## 九、價值投資視角

### 9.1 這是一門好生意嗎？

**用 7 個標準評判**（參考段永平/巴菲特的"好生意"checklist）：

| 維度 | 評分 | 備註 |
|---|---|---|
| 品牌/IP | ❌ | 中轉站本身沒品牌 |
| 網絡效應 | ⚠️ | OpenRouter 有些（更多模型→更多用戶→議價權更強） |
| 轉換成本 | ❌ | 用戶隨時可換 |
| 規模經濟 | ⚠️ | 有但不強 |
| 長期需求 | ❌ | **窗口期生意**，3 年後基本消亡 |
| 現金流 | ✓ | 短期現金流不錯（沉澱資金） |
| 資本配置 | ❌ | 大部分玩家會把錢拿去跑路 |

**總評：2-3 / 7，不是好生意——典型的"短期暴利、長期消亡"模式**

### 9.2 哪些角色值得投資？

```
✓ 投資標的：
  - OpenRouter 類合規聚合（已被 a16z 投了）
  - Portkey / Helicone / Langfuse 等 LLMOps SaaS
  - Together AI / Fireworks 等自建推理（重資本）

✗ 不值得投：
  - 國內灰色中轉
  - 個人拼車
  - 長尾倒賣
```

### 9.3 大廠會不會自己下場？

| 廠商 | 自己進中國賣 token？ | 概率 |
|---|---|---|
| OpenAI | 不進 | <5% |
| Anthropic | 不進（已切割） | <5% |
| Google | 不進 | <10% |
| DeepSeek/Qwen | 自建海外節點 | **>50%** |
| AWS Bedrock / Azure | 國內雲協作 | 中等 |

**結論**：海外廠商**短期不會自己下場服務中國**，中轉站窗口期至少還有 2-3 年。但國產模型自建海外節點會蠶食大量市場。

## 十、最終判斷

### 一句話總結

> **Token 中轉站是一門"窗口期暴利、3 年後必死"的生意——本質是套利於"模型廠商不進中國 + 用戶對成本/速度敏感"的雙重錯配。短期淨利可觀（10-25%），但模型價格指數下降、大廠自建節點、監管收緊三股力量正在掐死這個生態。能活 3 年的不再是"中轉站"而是"AI Gateway"——這是質變，不是簡單升級。**

### 三個具體建議

1. **如果你是用戶**：不要囤太多餘額（跑路風險），按月充
2. **如果你是創業者**：進入門檻低 → 必死，必須從第一天起規劃"智能路由 + 企業級 + 垂直 SaaS"的升級路徑
3. **如果你是投資人**：跳過中轉環節，直接看 OpenRouter / Portkey / Together AI 這種已經"下一站"的玩家
