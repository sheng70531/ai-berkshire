**關鍵事件**：

- **2025年**：價格戰從"搶份額"進入"生死戰"階段。12月單月利潤率僅1.8%，創歷史新低。主機廠將壓力通過延長賬期（部分達12個月）和超10%降價要求傳導至供應鏈

### 7. 主要政策

| 時間 | 政策 | 核心內容 | 效果 |
|------|------|----------|------|
| 2024年 | 汽車以舊換新（定額補貼） | 報廢更新+購置新能源車，定額補貼 | 超900億補貼，拉動銷量增長>10% |
| 2025年 | 以舊換新加力擴圍 | 擴大範圍，補貼延續 | 超1,150萬輛參與，帶動1.6萬億新車銷售額 |
| 2026年 | 以舊換新（比例補貼） | 按車價比例補貼：新能源12%（最高2萬）、燃油10%（最高1.5萬） | 預計繼續拉動中高端車型消費 |
| 2025年 | 購置稅減免政策延續 | 新能源車免徵購置稅至2025年底 | 持續降低購車成本 |
| 2024-2025年 | 新能源汽車下鄉 | 推動三四線及農村市場普及 | 5萬-15萬元車型佔比提升 |

### 3. 燃油車的命運

**短期（2026-2028）**：
- 純燃油車新車銷量將快速萎縮至30-35%份額
- 主流合資品牌加速推出插混/增程車型（如豐田、大眾）
- 部分純燃油車型停產，產線轉向混動

**中期（2028-2030）**：
- 傳統意義上的純燃油車新車佔比降至15-20%
- 根據《節能與新能源汽車技術路線圖2.0》，2030年新車平均油耗降至4.0L/100km，倒逼全面混動化
- 純燃油車僅在部分商用車和特殊用途場景保留

**關鍵判斷**：燃油車不會突然消亡，而是通過"混動化"實現過渡。到2030年，市場上的"燃油車"實際上絕大多數將是HEV/PHEV混動車型，純燃油新車將成為少數。

## 三、未來10年（2026-2035）展望

### 1. 中國汽車市場的終極格局

**市場規模**：
- 國內新車銷量穩定在3,200-3,600萬輛/年（存量替換為主）
- 海外銷量+本地化生產達1,500-2,000萬輛/年
- 中國車企全球總產銷有望達5,000-5,500萬輛/年

**競爭格局**：預計形成"3+5+N"的金字塔結構
- **3家超級車企**（年銷500萬輛+）：比亞迪 + 2家從吉利/長安/奇瑞中產生
- **5家大型車企**（年銷100-300萬輛）：理想、蔚來、小米等 + 存活的合資品牌（大眾中國、豐田中國）
- **N家細分市場玩家**（年銷10-50萬輛）：專注越野/豪華/性能等細分賽道

> 來源：[普華永道](https://imgtec.eetrend.com/blog/2023/100570308.html)、[36氪](https://36kr.com/p/3183228334743171)

### 2. 燃油車是否會消亡

**結論：純燃油車將近乎消亡，但內燃機不會完全退出**

| 時間節點 | 純燃油新車佔比（預測） | 混動（HEV/PHEV）佔比 | 純電佔比 |
|----------|----------------------|---------------------|----------|
| 2025年（實際） | ~46% | ~22% | ~32% |
| 2028年 | ~25% | ~30% | ~45% |
| 2030年 | ~15% | ~25% | ~60% |
| 2035年 | <5% | ~15% | ~80% |

> 來源：[新浪財經](https://finance.sina.com.cn/stock/t/2025-07-10/doc-infeytkq0220191.shtml)、[36氪](https://36kr.com/p/3183228334743171)

**關鍵判斷**：
- 2035年新能源滲透率達85-90%（含純電+插混+增程）
- 剩餘10-15%以大電池混合動力為主，純燃油幾乎退出乘用車市場
- 商用車（重卡等）的純電替代較慢，2035年新能源滲透率約75%
- 內燃機在增程器、混動等場景仍有存在價值，但角色從"主角"變為"配角"

### 3. 存活的品牌數量預測

| 預測來源 | 當前品牌數 | 2030年存活 | 淘汰率 |
|----------|-----------|-----------|--------|
| AlixPartners | 129家（電動車品牌） | 15家可持續盈利 | 88% |
| 業界共識 | ~200家（含傳統+新勢力） | ~30-40家存活 | 80-85% |
| 長期穩態（2035年） | - | ~10家巨頭 | - |

> 來源：[AlixPartners/巨亨網](https://news.cnyes.com/news/id/6049467)、[汽車之家](https://chejiahao.autohome.com.cn/info/15896067)

**淘汰節奏**：
- 2026-2028年：平均每月約2個品牌退出，主要是缺乏造血能力的新勢力和邊緣合資品牌
- 2028-2030年：中型品牌開始兼併重組，行業進入"決賽圈"
- 2030-2035年：格局趨於穩定，形成10家左右的汽車巨頭

**已經出現的危險信號**：哪吒、威馬已實質退出；極越突然關停；部分二線合資品牌（Stellantis在華品牌等）大幅收縮

### 4. 汽車產業鏈的價值重新分配

**從"硬件為王"到"軟件定義"的價值遷移**：

| 價值環節 | 2023年佔比 | 2030年預測佔比 | 變化趨勢 |
|----------|-----------|---------------|----------|
| 傳統三大件（發動機/變速箱/底盤） | ~30% | ~10% | 大幅萎縮 |
| 三電系統（電池/電機/電控） | ~25% | ~30% | 穩步增長 |
| 智能化（芯片/軟件/傳感器） | ~10% | ~25% | 爆發式增長 |
| 售後服務 | ~20% | ~15% | 因電動車低維保需求下降 |
| 軟件訂閱/OTA/數據服務 | ~2% | ~10% | 從無到有 |
| 出行服務（Robotaxi等） | ~3% | ~10% | 快速增長 |

> 來源：[普華永道](https://www.strategyand.pwc.com/cn/zh/reports-and-studies/2022/china-automotive-value-pools-2030-sep2022.html)、[麥肯錫](https://news.qq.com/rain/a/20230404A063C300)

**核心趨勢**：
- 普華永道預測2030年中國汽車價值池總規模將翻一番，超4.5萬億美元
- 2024年新能源汽車產業協同估值1.9萬億元，2030年目標突破5萬億元
- 全固態電池2026-2027年進入示範階段（350-400Wh/kg），2030年初步規模化（400-500Wh/kg）
- 寧德時代等電池巨頭將成為產業鏈最大贏家之一
- 傳統Tier 1供應商（博世、大陸等）面臨轉型壓力

### 5. 中國車企的全球競爭力

**當前優勢**：

| 維度 | 中國車企競爭力 |
|------|---------------|
| 新能源技術 | 全球領先（電池、電驅動、插混技術） |
| 智能化 | 第一梯隊（端到端自動駕駛、智能座艙） |
| 供應鏈成本 | 顯著優勢（比西方低30-40%） |
| 產品迭代速度 | 12-18個月（傳統車企36-48個月） |
| 價格競爭力 | 同級別產品價格低20-30% |

**2030年全球格局預測**（麥肯錫）：
- 全球Top10車企中將有3-4家中國企業（目前僅比亞迪1家）
- 中國車企全球市場份額從目前約5%提升至15-20%
- 在東南亞、中東、南美等新興市場份額有望超30%

**主要挑戰**：
- 歐美貿易壁壘（關稅、碳關稅、數據合規）
- 品牌認知度不足（在發達市場仍需建設）
- 地緣政治風險
- 利潤率偏低（全球擴張需要利潤支撐）

### 6. 對汽車互聯網平臺的影響

**兩大平臺現狀對比**：

| 指標 | 汽車之家 | 懂車帝 |
|------|---------|--------|
| 模式 | "人找車"搜索邏輯 | "車找人"推薦算法 |
| DAU | ~7,700萬 | ~1,000萬+ |
| 2025年營收 | 64.5億元（-8.3%） | 未公開（衝刺IPO） |
| 2025年淨利潤 | 16.1億元（-21.6%） | 未公開 |
| 市值/估值 | 20.5億美元（縮水超80%） | ~30億美元（2024年融資估值） |
| 員工數 | 4,242人（較2023年減23%） | 未公開 |
| IPO狀態 | 已上市（NYSE+HKEX） | 2026年衝刺港股IPO（擬融10-15億美元） |

> 來源：[新浪財經](https://finance.sina.com.cn/roll/2026-04-14/doc-inhummyn4258714.shtml)、[澎湃新聞](https://www.thepaper.cn/newsDetail_forward_32666870)

**汽車之家的困境**：
- 媒體服務收入從2019年峰值~36億元降至2025年11.5億元（-24.3%）
- 線索服務收入27.1億元（-13.6%），傳統"賣線索"模式被車企直營削弱
- 毛利率從78.9%降至72.4%
- 經營現金流從常年20億+降至8.9億元

**新能源時代對平臺的結構性衝擊**：

1. **直營模式削弱線索價值**：特斯拉、蔚來、小米等直營品牌不需要第三方線索平臺，車企建立自有私域流量池
2. **內容生態變化**：短視頻（抖音/懂車帝）取代圖文（汽車之家），用戶獲取信息方式劇變
3. **成交鏈路縮短**：新能源車線上選配、線上下單佔比提升，傳統"看-比-詢-購"鏈路被壓縮
4. **售後服務萎縮**：電動車維保需求遠低於燃油車，售後相關業務面臨縮減

**未來5-10年平臺演變預測**：

| 趨勢 | 影響 |
|------|------|
| 直營品牌佔比提升至40%+ | 線索業務持續萎縮 |
| AI選車/智能推薦 | 平臺內容價值被AI替代 |
| 車企自有App/社區 | 用戶黏性從第三方平臺轉移 |
| Robotaxi/共享出行興起 | 個人購車決策減少 |
| 二手車/汽車金融 | 成為平臺新利潤增長點 |

**核心判斷**：汽車互聯網平臺正面臨商業模式的根本性挑戰。傳統的"流量-線索-廣告"三角模型在新能源直營時代被解構。懂車帝依託字節跳動生態仍有增長空間，但汽車之家需要從"汽車信息平臺"轉型為"汽車交易和服務平臺"，否則將面臨持續萎縮。

## 總結：中國汽車市場的三大歷史性轉折

### 轉折一：新能源替代已不可逆轉
從2023年滲透率31.6%到2025年47.9%，再到2030年預期超70%，新能源汽車已從"政策驅動"進入"市場驅動"階段。這不是一個線性過程，而是一個S曲線的加速階段。

### 轉折二：自主品牌主導地位已確立
自主品牌從2023年56%到2025年70%的份額躍升，不是暫時現象而是結構性變化。合資品牌的反攻窗口已經關閉，未來的問題不是"自主品牌能否超越合資"，而是"哪些合資品牌還能存活"。

### 轉折三：中國正從"汽車大國"走向"汽車強國"
出口從491萬輛到710萬輛，海外建廠加速推進，智能化技術全球領先。2030年全球Top10車企中有3-4家中國企業的預測正在變為現實。中國汽車產業正在重新定義全球競爭格局。
