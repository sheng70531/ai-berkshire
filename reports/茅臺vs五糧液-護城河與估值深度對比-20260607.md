# 茅臺 vs 五糧液：護城河與估值深度對比

> 分析日期：2026年6月7日
> 本文不構成任何投資建議。

---

## 核心結論

| 維度 | 茅臺 | 五糧液 | 判斷 |
|------|------|--------|------|
| **護城河深度** | ★★★★★ | ★★★ | 茅臺是白酒唯一的"絕對護城河" |
| **估值低估程度** | 中度低估 | 重度低估（但有原因） | 五糧液紙面更便宜，便宜背後是治理塌方+渠道危機 |
| **確定性** | 高 | 低 | 茅臺能算清楚的賬，五糧液算不清楚 |
| **綜合投資價值** | ★★★★ | ★★★ | 茅臺是更好的投資標的 |

**結構和騰訊vs阿里驚人地相似：行業老大護城河遠勝老二，老二紙面更便宜但便宜有代價。**

## 二、價格體系：定價權是最核心的護城河差異

### 飛天茅臺 vs 第八代普五

| 維度 | 飛天茅臺 | 第八代普五 |
|------|---------|-----------|
| 出廠價 | **1,269元**（2026年3月提至） | 1,019元 |
| 批價（2026年5月） | **1,640-1,680元** | 760-780元 |
| 終端零售價 | ~1,539元（官方）/ 批價以上 | ~809元（電商低至719元） |
| 批價/出廠價 | **129-132%**（溢價） | **75%**（倒掛） |
| 經銷商利潤 | 每瓶賺**300-400元** | 每瓶**虧70-200元** |
| 2026年是否提價 | **已提價**（+8.6%） | 明確表示不考慮提價 |
| 提價歷史 | 上市以來10次提價，出廠價漲5.8倍 | 多年未實質提價 |

**這張表是兩家公司護城河差距的縮影。** 茅臺批價高於出廠價29-32%，經銷商搶著要貨；五糧液批價低於出廠價25%，經銷商每賣一瓶就虧錢。一個是供不應求的賣方市場，一個是供過於求的買方市場。

## 三、護城河逐層拆解

### 第一層：品牌

| 維度 | 茅臺 | 五糧液 |
|------|------|--------|
| 品牌定位 | **中國唯一的"社交硬通貨"** | 千元價格帶領軍者 |
| 場景不可替代性 | 極高——"商務宴請不上茅臺就是不重視" | 中等——可被國窖1573、劍南春替代 |
| 金融屬性 | 有——可保值增值、可變現 | 無 |
| 心智壟斷 | 2,000元以上價格帶**無競品** | 1,000元價格帶競爭者眾多 |
| 品牌稀缺性 | **不可複製**（產區+工藝+歷史三重稀缺） | 可被模仿（濃香型工藝門檻低於醬香型） |

**茅臺的品牌護城河不是"很強"，而是"獨一檔"。** 在中國白酒行業，茅臺是唯一兼具消費品屬性、社交屬性和金融屬性的品牌。五糧液只有消費品屬性。

### 第二層：產能約束

| 維度 | 茅臺 | 五糧液 |
|------|------|--------|
| 核心工藝 | 醬香，12987工藝（1年生產週期+5年熟化） | 濃香，發酵週期60-90天 |
| 熟化週期 | **至少5年**（今年產的酒，2031年才能賣） | 1-3年 |
| 產區依賴 | **極高**——茅臺鎮核心產區的微生物環境不可複製 | 中等——宜賓有優勢但非唯一產區 |
| 擴產難度 | **極高**——受產區面積、微生物環境、熟化週期三重約束 | 中等——10萬噸新產能已在建 |
| 當前可售產能 | ~4.7萬噸/年 | ~2.7萬噸/半年（高端） |
| 設計產能利用率 | **126%**（超負荷運轉） | ~70%（有餘量） |

**茅臺的產能約束是天然的、不可突破的護城河。** 5年熟化週期意味著即使茅臺今天把所有產能翻倍，新增的酒也要2031年才能上市。這種"時間鎖"讓任何競爭對手都無法通過砸錢來快速追趕。五糧液的濃香工藝雖然也需要老窖池，但發酵週期短、熟化要求低、擴產更容易，護城河深度差了一個量級。

### 第三層：定價權

| 維度 | 茅臺 | 五糧液 |
|------|------|--------|
| 當前定價權 | **極強**——供不應求，提價後批價仍遠高於出廠價 | **幾乎沒有**——批價低於出廠價，無法提價 |
| 提價頻率 | 上市25年提價10次 | 多年未實質提價 |
| 提價空間 | 充裕——出廠價1,269元，批價1,640+，還有空間 | 無——出廠價1,019元已高於批價780元 |
| 對標 | 全球奢侈品（愛馬仕毛利率71%，茅臺92%） | 國內白酒同行 |

### 第四層：財務質感

| 指標 | 茅臺 | 五糧液 | 含義 |
|------|------|--------|------|
| 毛利率 | **92%** | 77-81% | 茅臺一瓶酒成本約60元，賣1,269元 |
| 淨利率 | **48-50%** | 22-36% | 茅臺每賺100塊有近50塊是利潤 |
| ROE | **~30%** | 6.9%（出清年）/ ~25%（正常年） | 茅臺的資本回報率更高且更穩 |
| 資本支出需求 | 極低 | 低 | 兩者都是輕資產，但茅臺更輕 |

### 護城河總評

| 維度 | 茅臺 | 五糧液 |
|------|------|--------|
| 品牌 | ★★★★★（唯一的社交硬通貨） | ★★★★（強但可被替代） |
| 產能壁壘 | ★★★★★（5年熟化+產區不可複製） | ★★★（老窖池有價值但擴產更容易） |
| 定價權 | ★★★★★（供不應求，持續提價） | ★★（批價倒掛，無定價權） |
| 渠道控制 | ★★★★（直銷反超，主動縮減經銷商） | ★★（渠道庫存積壓，被迫補貼經銷商） |
| 財務質感 | ★★★★★（92%毛利率，A股最強之一） | ★★★★（77%毛利率，優秀但不極致） |
| **綜合** | **★★★★★** | **★★★** |

## 四、誰被低估得更嚴重？

### 茅臺：中度低估

| 維度 | 數據 |
|------|------|
| 當前PE | ~21倍（TTM）/ ~20倍（前瞻） |
| 歷史PE中樞 | 25-30倍 |
| 當前PE/歷史中樞 | **70-84%**（低於均值） |
| 股息率 | **~4%** |
| 安全邊際 | 1,780億現金 + 零負債 + 79%分紅率 |

**低估原因：** 行業調整週期 + 首次營收淨利雙降 + 社會庫存堰塞湖 + 管理層治理陰影（5年3任董事長被查）

**低估是否合理？** 部分合理。行業調整是真實的，但茅臺的基本面（92%毛利率、供不應求、持續提價）沒有被破壞。20倍PE買一家毛利率92%、ROE 30%、零負債、4%股息率的公司，即使行業不復蘇，下行風險也很有限。

### 五糧液：紙面重度低估，但低估有充分理由

| 維度 | 數據 |
|------|------|
| 當前市值 | ~3,580億 |
| 按調整後2025年淨利潤 | PE ~40倍（失真） |
| 按機構預測2026年淨利潤~360億 | **前瞻PE ~10倍** |
| 股息率 | **~5.3%** |
| 回購+增持 | 110-150億（力度極大） |

**低估原因：**
1. **303億會計差錯** — 一次性出清渠道壓貨泡沫，暴露了多年虛增收入的問題
2. **兩任董事長落馬** — 李曙光（2025年）、曾從欽（2026年2月），治理信任崩塌
3. **證監會立案調查** — 如果被認定為"信息披露違規"，可能面臨行政處罰
4. **批價倒掛** — 出廠價1,019元 vs 批價760-780元，經銷商虧錢賣
5. **被汾酒反超** — 2025年淨利潤排名：茅臺第一、汾酒第二、瀘州老窖第三、五糧液第四
6. **濃香品類份額下滑** — 濃香市場份額2年降10個百分點，被醬香和清香兩面夾擊

**低估是否合理？** 大部分合理。五糧液的低估不是市場犯錯，而是在為**治理塌方+渠道危機+品類競爭劣勢**定價。這些問題每一個都是結構性的，不是一兩個季度能解決的。

## 六、投資判斷

### 如果只能買一個：買茅臺

**理由：**
1. **護城河差距是質的差異** — 茅臺的護城河是"不可複製"級別（產區+5年熟化+品牌壟斷），五糧液的護城河是"可被蠶食"級別（濃香工藝門檻低+千元價格帶競爭激烈）
2. **定價權一個天上一個地下** — 茅臺在提價，五糧液批價倒掛。這是兩家公司本質差距的最直觀體現
3. **治理風險截然不同** — 茅臺雖然歷史上有腐敗問題，但核心產品"不依賴管理層也能賣得好"。五糧液的303億事件暴露的是系統性的治理缺陷，恢復信任需要數年
4. **下行保護更強** — 茅臺20倍PE+4%股息+1,780億現金+92%毛利率，即使行業繼續調整，下行空間有限。五糧液10倍前瞻PE看似便宜，但分母（360億利潤預測）的可靠性存疑

### 五糧液不是不能買，但你需要賭三件事同時發生

1. 證監會調查結果溫和（認定為會計差錯而非信披違規）
2. 批價在2026年下半年企穩回升至900元以上
3. 新管理層能真正推動渠道改革、恢復市場信心

如果三件事都發生，10倍前瞻PE的五糧液可能翻倍。但如果任何一件沒發生，當前價格可能不是底。

### 一句話總結

> **茅臺和五糧液的差距，不是"老大和老二"的差距，而是"有定價權和沒有定價權"的差距。** 茅臺提價8.6%，批價還高出出廠價30%——這是壟斷性品牌的證明。五糧液出廠價1,019元，批價780元——這是品牌力不足以支撐價格的證明。在白酒行業調整期，有定價權的公司能安全穿越週期，沒有定價權的公司只能祈禱行業回暖。
