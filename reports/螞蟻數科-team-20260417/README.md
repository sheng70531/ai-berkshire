## 研究方法

本研究採用**未上市公司多Agent並行研究框架**：

- **並行啟動**：5位AI分析師同時獨立研究，避免互相干擾
- **多源核驗**：每個關鍵數據點至少2個獨立來源交叉驗證
- **置信度標註**：所有數據標註 🟢高 / 🟡中 / 🔴低
- **誠實留白**：信息缺失處明確標註"未公開"，不強行填充
- **雙口徑分離**：營收等關鍵數據明確區分管理口徑 vs 第三方可比口徑
- **對標驅動**：用22家上市可比公司的實際估值水位反推合理估值
