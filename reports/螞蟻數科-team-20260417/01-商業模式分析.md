# 螞蟻數科 商業模式與產品用戶分析

> 分析師：business-decoder | 日期：2026-04-17 | 數據置信度：🟢高 / 🟡中 / 🔴低

---

## 一、核心生意定義

**一句話定義**：螞蟻數科是螞蟻集團旗下的"產業數字化技術服務商"，把螞蟻集團十幾年在金融級風控、區塊鏈、隱私計算、AI 上沉澱的"內功"，以 ABC（AI + Blockchain + Cloud）三件套打包賣給外部企業（尤其是金融機構、大企業、政務、跨境貿易商），並面向 Web3/RWA 這條新賽道佔位"機構級鏈上基礎設施"。🟢

**解決什麼問題**：
- 金融機構在 AI/數據/區塊鏈上"想做但不敢做、做不動"——既缺金融級技術棧，又有合規與安全的強約束
- 實體企業（能源、製造、跨境貿易）想把資產"上鍊"獲得跨境融資 / 流動性，但沒有合規的發行—登記—結算基礎設施
- 大企業想把大模型用在嚴肅業務（不是聊天玩具），需要可控、可審計、低幻覺的智能體平臺

**為誰創造價值**：
1. 國內金融機構（銀行/券商/保險）—— 佔客戶結構主力
2. 大型實體企業（能源、出行、醫療、零售）
3. 政務和公共服務機構
4. 跨境貿易商 / Web3 機構（通過 ZAN/Jovay/RWA 服務）
5. 海外金融科技夥伴（中亞、東南亞、中東）

## 三、收入模式拆解

螞蟻數科未單獨披露詳細財務（未上市），但能拼出大致結構：

**已公開關鍵數據**：
- 2024 年實現**盈虧平衡** 🟢
- 2025 年預計營收**增長 50%** 🟢
- 海外營收 2025 年同比 **+300%** 🟢
- 全球服務 **1.3 萬+** 企業客戶、**300+** 合作伙伴、覆蓋 24 個國家/地區 🟢
- 母公司螞蟻集團 2024 年淨利潤 383 億元（+61%），2025 估值約 6350 億元 🟢

**收入模型推算結構**（🟡 推算）：

| 收入類型 | 形式 | 估測佔比 | 備註 |
|---|---|---|---|
| 解決方案 + 訂閱 (B2B SaaS) | 螞蟻鏈 BaaS / 摩斯 / Agentar 平臺年費 + License | 50-60% | 主體 |
| 項目制諮詢交付 | 大型金融機構智能體定製 / 政務區塊鏈項目 | 20-30% | 高 ACV、低毛利 |
| 按效果付費 (Outcome-based) | Agentar 在金融場景按"準確率/收益提升"分潤 | 5-10% | 創新模式，2025 落地 |
| 海外/Web3/RWA | ZAN 節點、Jovay gas/服務、RWA 發行服務費 | 5-15% 且快速上升 | 高增長曲線 |
| 算力/MaaS | 隱私計算一體機、Morse Station 硬件 | 5-10% | 含硬件 |

**整體營收體量推算**：以"剛盈虧平衡 + 1.3 萬企業客戶 + 增速 50%"反推，2025 年營收**估計約 50-100 億元人民幣**區間 🔴（無官方披露，僅供量級感知）。

## 四、客戶結構

**客群構成**（按公開案例歸納）🟢：

1. **金融機構（核心，估計貢獻 40-50% 收入）**
   - 燈塔客戶：**寧波銀行**（Agentar KBase 全行落地，複雜問答準確率從 68% → 91%；票據識別錯誤率 0.8% → 0.05%，年減損 3000 萬元）
   - **工商銀行**（聯合發佈 Finova 金融評測）
   - 200+ 金融機構合作落地

2. **大型實體企業（增長重點）**
   - **協鑫能科**：合資設立"螞蟻鑫能"，落地 2 億元光伏 RWA（國內首單）；同時螞蟻推動 80 億美元能源資產上鍊
   - 康師傅（招聘智能體）、愛爾眼科（數智員工）

3. **海外夥伴**
   - **馬來西亞 Touch'n Go**（最大 e-Wallet，60% 市佔，ZOLOZ eKYC 覆蓋 75% 用戶註冊）
   - **哈薩克斯坦 BCC 銀行**（共建本地超級 App）
   - 中東（迪拜）、香港持牌虛擬資產機構

4. **政務/公共服務**：螞蟻鏈長期合作客戶

**關鍵客戶結構特徵**：高度依賴"燈塔客戶帶 case"，**頭部 KA 集中度高**，長尾 SMB 幾乎不是其打法（與 Stripe/Plaid 模式不同）。

## 八、戰略定位（與螞蟻集團母公司 / 阿里關係）

**螞蟻集團內**：螞蟻數科是集團"AI First + 支付寶雙飛輪 + 全球化"三大戰略中 **"AI First 對外輸出"和"全球化技術腿"** 的載體。集團其他獨立子公司（螞蟻國際做 C 端跨境/錢包、OceanBase 做數據庫）各走各路。

**與阿里關係**：阿里集團已不是螞蟻集團股東（2023 年阿里巴巴減持完成），但同源、同生態、同投資關係仍在。技術上保持**獨立研發**：
- **阿里通義千問**：定位通用大模型 + 公有云 MaaS
- **螞蟻百靈**（含 Ling/Ring/Ming 三系列）：定位金融/可信場景的垂直大模型，獨立技術路線（MoE 萬億 + 思考模型 + 全模態）

二者**幾乎不直接競爭客戶**：通義打開發者+互聯網+通用雲；螞蟻數科打金融+合規+垂直 To B。

**集團內分工金句**：阿里通義是"水電煤"，螞蟻數科是"金融級精裝修+監管認證"。🟢

## 九、AI / 大模型戰略

**自有大模型矩陣（百靈家族，集團基礎研究 + 螞蟻數科商業化）** 🟢：
- **Ling 系列**：MoE 非思考模型，2025/10 發佈 Ling-1T（萬億參數）
- **Ring 系列**：思考/推理模型，2026/2 開源 Ring-2.5-1T（首個混合線性架構萬億思考模型）
- **Ming 系列**：原生全模態，2026/2 發佈 Ming-Flash-Omni 2.0（語音+音效+音樂統一生成）
- 截至 2025/11 累計開源 18 個模型，參數從 100 億到萬億
- 重大突破：使用國產 AI 芯片訓練大模型，進一步降本

**B 端商業化（螞蟻數科主導）**：
- **Agentar 智能體平臺**：2025 Q2 發佈，金融機構零代碼搭智能體，全棧貫通算力/數據/模型/應用
- **Agentar-Fin-R1**：基於 Qwen3 的金融推理模型（32B/8B），在 BIRD-SQL、金融測評榜單超越 OpenAI o1、DeepSeek-R1
- **Agentar-Scale-SQL**：登頂 BIRD-SQL 全球第一
- 入選 2025 國際標準金融應用卓越案例（與寧波銀行）
- 2026 年成為"主流企業智能體開發平臺"標杆之一

**與阿里通義的協同與邊界**：
- **協同**：底層算力（部分用阿里雲/集團自建）；阿里減持後兩家研發獨立但生態聯通
- **邊界**：阿里通義吃通用市場，螞蟻百靈+Agentar 吃金融/監管嚴苛行業；客戶重疊度低
- **隱憂**：金融雲市場恒生電子、華為雲、騰訊雲金融雲、阿里雲金融部門也在卷，螞蟻數科作為"獨立子公司"如何穩定獲得阿里雲算力供給和定價是潛在不確定性

## 十、整體評分與核心結論

### 綜合評分：⭐⭐⭐⭐ (4 / 5)

| 維度 | 評分 |
|---|---|
| 商業模式清晰度 | ⭐⭐⭐⭐ |
| 護城河 | ⭐⭐⭐½ |
| 增長曲線 | ⭐⭐⭐⭐ |
| 財務質量 | ⭐⭐⭐ (剛盈虧平衡) |
| 戰略定位獨佔性 | ⭐⭐⭐⭐⭐ (全球少數同時具備 AI+RWA+隱私計算+牌照的玩家) |

### 三條核心結論

1. **螞蟻數科是"金融級 To B 技術堆棧的國家隊"**——它的真正價值不是單賣區塊鏈/AI/隱私計算任何一項，而是把"螞蟻集團十幾年監管打磨過的金融級技術"做成對外可售的解決方案，併疊加"按效果付費"等創新模式。這種"母體催熟+對外商業化"的路徑，國內只有阿里雲、華為雲、騰訊雲金融線可比，但都缺它在區塊鏈+隱私計算+RWA 上的牌照儲備。

2. **真正的"非共識機會"在 RWA / 穩定幣 / Jovay 這條第三曲線**——這是同行做不了或不敢做的：需要香港牌照、需要機構級鏈、需要隱私計算合規、還要跨境結算能力。螞蟻數科+協鑫能科 2 億元光伏 RWA + 香港穩定幣牌照申請 + Jovay L2，已構成完整閉環，2025-2027 是關鍵窗口期。但風險是政策窗口可能反覆。

3. **關鍵變量是 IPO 節奏與"螞蟻母體輸血/獨立性"的平衡**——CEO 趙聞飆說"明年外灘大會再答 IPO 時間表"（即 2026 外灘大會，對應 2026/9 左右）。當前盈虧平衡 + 50% 增速 + 海外 +300% 是上市鋪墊期典型曲線。但要警惕：(a) 與螞蟻國際、OceanBase 在集團資源分配上的競爭；(b) 母體場景與數據多大程度可複用；(c) 阿里雲的算力供給關係。**估值與變現路徑取決於"獨立 IPO" vs "併入螞蟻集團整體上市"兩種路徑選擇**。
