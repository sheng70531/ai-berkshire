資料截止：2026年9月12日。金額除註明外均為人民幣億元。阿里巴巴財年截至每年3月31日（FY2026＝2025年4月1日至2026年3月31日），京東按自然年。"TTM"指最近四個已披露季度拼接。利潤全部用會計準則口徑（阿里、京東均為美國公認會計準則）的普通股股東應佔淨利潤，不用公司自行調整的口徑。2036指十年後的單個年度利潤，為2036年名義人民幣，不是十年累計。本文不含估值與價格判斷。

哪些是主動投入虧損：

1. 即時零售。公司在三份季度公告裡都把中國電商集團EBITA同比下降歸因於"即時零售、用戶體驗和技術投入"。前三季同比降幅合計753.50億元，是即時零售虧損的上限代理（含用戶體驗與技術投入；且上年同期餓了麼本身已有虧損基數）。6月季度同比只降2.39億元，因為2025年6月季度基數已含閃購初期投入，但管理層稱虧損"顯著縮窄"，按3月季度同比降幅157.32億元的一半到三分之二估計單季虧損約80至120億元。TTM即時零售投入虧損估計區間：700 / 800 / 900億元（低值＝753.50×0.85＋60，中值取整，高值＝753.50＋150）。
2. AI投入。6月季度AI實驗室與應用虧損138.61億元（上年同期32.24億元）。前三季這部分埋在"所有其他"裡，所有其他虧損從上年同期的18.33 / 31.76 / 34.13擴大到33.70 / 97.92 / 211.60億元，公司歸因為"技術業務投入"。TTM AI投入虧損估計：400 / 515 / 554億元（低值只算同比惡化部分，中值＝四季所有其他與AI實驗室虧損合計33.70＋97.92＋211.60＋172.04＝515.26，高值＝6月季度AI實驗室虧損×4）。所有其他裡還有菜鳥、盒馬等非AI業務，中值可能高估AI部分。
3. 商譽減值（12月季度95.15、6月季度85.41億元）為非經常項目，正常化口徑直接剔除。

正常化公式（TTM口徑，億元）：

```text
正常化稅後歸母 = (合併經調整EBITA 649.01 + 即時零售虧損還原 + AI虧損還原 − 股份薪酬 109.48 − 無形攤銷約30) × (1 − 25%) + 稅後常態融資與投資收益 40 − 少數股東 10
低值 = (649.01 + 700 + 400 − 109.48 − 30) × 0.75 + 40 − 10 = 1237.15
中值 = (649.01 + 800 + 515 − 109.48 − 30) × 0.75 + 40 − 10 = 1398.40
高值 = (649.01 + 900 + 554 − 109.48 − 30) × 0.75 + 40 − 10 = 1502.65
```

假設說明：稅率25%為法定稅率，公司FY2026實際稅率23%（300.45 / 1,293.87）但受投資收益擾動；未分攤總部費用48.94億元已在合併經調整EBITA內扣除，不再重複扣；稅後常態融資與投資收益40億元的來路是4,745億元類現金按2.5%約119億元利息，減FY2026利息支出97.93億元，加權益法收益（FY2026為27.85億元，主要是螞蟻），稅後約40億元，不含市值變動；少數股東按FY2026實際（少數股東分擔虧損14.65億元）附近取−10億元。結論：正常化稅後歸母約1,250 / 1,400 / 1,500億元，與FY2025歸母1,294.70億元、FY2025公司非公認會計準則淨利潤1,581億元處於同一量級，即當前TTM歸母733億元中約有600至800億元差距是主動投入造成的。這個數字回答"投入停了能賺多少"，不回答"投入會不會停"；把它當作已實現利潤使用是錯誤的。

```text
高值 = (530.55 + 64.49 − 53.69 + 0 + 88.10 − 29.54 + 100) × 0.82 − 45 = 528.93
```

假設說明：新業務殘留虧損60 / 30 / 0億元（低值接近2024年水平加海外投入，高值假設全部打平）；其他淨額取60 / 80 / 100億元，低於TTM實際157.21億元，因為實際數含投資處置與公允價值收益，2023年該項為74.96億元；稅率25% / 20% / 18%，公司2023至2025年實際稅率分別為26.5%、13.3%、8.6%，波動來自稅收優惠與虧損主體不能抵稅；少數股東60 / 50 / 45億元，高於TTM實際48.77億元，因為外賣虧損在全資主體，而京東物流（持股約63%）、京東健康、京東工業的利潤要分給少數股東，投入停止後少數股東分走的利潤不會減少。結論：正常化稅後歸母約390 / 470 / 530億元，對照2024年實際歸母413.59億元（當年新業務虧損28.65億元、零售經營利潤410.77億元），2025年零售經營利潤已升到514.02億元，所以正常化中值高於2024年是合理的。與阿里一樣，這是"投入停了能賺多少"，不是已實現利潤。

### 3.7 2036年度利潤三情景（自建）

按[騰訊與拼多多底稿](../七公司商業質量與十年利潤-20260906/騰訊與拼多多底稿.md)的統一公式：各業務收入基數×十年收入增長因子×2036年歸母經濟淨利率，加常態投資收益。淨利率已負擔研發、股份薪酬、折舊攤銷、履約、總部費用、利息、稅項和少數股東權益，不含公允價值變動。

2026全年研究收入基數（對外收入代理，不是公告分部收入預測）：京東零售11,150億元（2025年11,263.99億元，2026年上半年5,639.71億元同比−1.7%，下半年按持平假設）；京東物流對外收入1,600億元（2025年分部收入2,171.46減分部間抵銷837.42約為1,334億元，2026年上半年分部收入同比+26.5%）；新業務280億元（2026年上半年135.39億元）。三項合計13,030億元，與2026年合併收入的量級檢查（上半年6,620.95加下半年按2025年下半年6,513.43持平）一致。2026年盈利校核：`11150×0.036 + 1600×0.012 + 280×(−1.2) + 40 = 124.6`億元，與TTM歸母147.94億元同量級；零售3.6%淨利率對應約4.8%經營利潤率稅後，新業務−120%對應2026年上半年虧損的年化收窄趨勢。

| 假設 | 保守 | 基準 | 樂觀 |
|---|---:|---:|---:|
| 零售收入年增速 / 2036經濟淨利率 | 0% / 2.5% | 3% / 4.5% | 5% / 6% |
| 物流對外收入年增速 / 2036歸母經濟淨利率 | 2% / 0.5% | 6% / 1.5% | 9% / 2.5% |
| 新業務收入年增速 / 2036經濟淨利率 | −5% / −10% | 12% / 2% | 20% / 8% |
| 常態稅後淨利息與投資收益 | 30 | 60 | 90 |

```text
保守 = 11150×1.00^10×0.025 + 1600×1.02^10×0.005 + 280×0.95^10×(−0.10) + 30 = 301.74
基準 = 11150×1.03^10×0.045 + 1600×1.06^10×0.015 + 280×1.12^10×0.02 + 60 = 794.68
樂觀 = 11150×1.05^10×0.06 + 1600×1.09^10×0.025 + 280×1.20^10×0.08 + 90 = 1413.12
```

每個假設的依據：

- 零售增速。實物商品網上零售額2025年增5.2%、2026年1至7月網上商品零售額增4.6%（見第四節），京東零售2025年+10.9%靠國補，2026年上半年−1.7%。保守取零增長（份額被即時零售和內容電商分流），基準3%（略低於大盤），樂觀5%（與大盤持平並靠品類擴張）。
- 零售淨利率。零售分部2025年經營利潤率4.6%，管理層長期目標"高個位數"。基準4.5%淨利率約等於6%經營利潤率稅後（乘0.75），意味著長期目標兌現一半以上；樂觀6%對應8%經營利潤率稅後，即目標完全兌現；保守2.5%對應利潤率回到2022至2023年水平（3.4%經營利潤率）。
- 物流。京東物流對外業務毛利低，分部2025年經營利潤率2.4%，京東持股約63%，歸母淨利率再打折，所以基準只給1.5%。
- 新業務。保守假設外賣收縮且長期虧損10%；基準假設外賣、京喜、海外合計做到微利2%，與管理層"2029財年即時零售盈利"這類同行目標相比不激進；樂觀假設外賣協同和海外規模化後8%。新業務收入基數小，對2036結果影響有限，主要影響是能否停止吞噬零售利潤。
- 淨利息與投資收益。2,216億元現金及短期投資，按2%稅後約44億元，減去有息負債利息約30億元，基準60億元含權益法投資（京東持有達達、永輝等）常態貢獻。

保守不是下限：若零售利潤率回到2021年（經營利潤率2.5%以下）且外賣持續每年虧損300億元以上，2036歸母可能低於100億元。樂觀要求零售同時實現增長和高個位數利潤率，2014年以來京東零售從未在同一年做到"增速高於大盤且經營利潤率超過6%"。

## 五、來源邊界與未取得項

- 雙源核驗：兩家公司的年度與季度收入、歸母淨利潤、現金及現金等價物、現金加短期投資合計，均以發行人文件對照StockAnalysis（數據來自標普全球），全部一致。歷史收入序列以美國證監會XBRL接口（發行人自報）對照StockAnalysis，全部一致或差異小於0.1%。
- 單源事實：分部收入與利潤、回購與股息金額、股本數、資本開支、管理層表述只有發行人來源；港交所公告與美國證監會文件是同一發行人，不能互為獨立源。
- 未取得：阿里巴巴與京東2026年8月港交所月報表（配售後與最新回購後的精確股本）；阿里菜鳥、大文娛、本地生活的單獨分部利潤（公司已停止披露）；阿里即時零售與京東外賣的單獨虧損額（公司只給合併分部數與定性表述）；阿里FY2012、京東2011年的官方XBRL收入；IDC 2025全年中國公有云市場規模與2026年預測。
- 口徑提醒：阿里歸母淨利潤含大額投資市值變動，京東2025年第四季度含商譽減值，兩家的TTM歸母都不宜直接乘以市盈率去推"正常水平"；第2.6與3.6節的正常化利潤是研究估計，依賴"投入虧損上限＝分部利潤同比降幅"這一近似，誤差可能在±20%。
- 2036三情景是假設，不是預測置信區間；阿里數字沿用9月6日底稿並複核，京東數字為本次新建，兩者方法一致但阿里按"分部經營貢獻×稅率"、京東按"收入×淨利率"展開，閱讀時注意公式形式不同。
