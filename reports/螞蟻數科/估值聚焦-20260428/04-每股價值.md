> **本報告聚焦：螞蟻數科"每股價值"的多層次推算與橋樑打通**

## 0. 執行摘要

螞蟻數科目前是一家**有限責任公司**，註冊資本21.07億元人民幣（2024年5月由1億元增資完成），尚未完成股份制改造，**沒有真正意義上的"每股"概念**——只有"每元註冊資本對應的市場價值"。員工股權激勵工具（SER/RSU）的標的是**螞蟻集團**而非螞蟻數科，2025年3月"一拆四"映射後螞蟻數科只佔其中**1.4%** 的隱含權益。

本報告把"每股價值"拆解為三層：
- **A層（當下口徑）**：每元註冊資本對應市場價值 → **21.4 ~ 35.6元**
- **B層（員工激勵隱含口徑）**：每份SER中的"數科部分"會計公允價 → **1.51元/SER**（市場化修正後約1.51 ~ 1.69元）
- **C層（IPO後預測）**：參考可比公司，IPO招股價區間 → **港幣6 ~ 30元/股**（取決於上市總股本與估值組合）

三層之間的差距主要由**會計保守 + 關聯交易折價 + 流動性折價 + IPO倍數擴張**構成，乘數關係約為 **B → A 約14-24倍，A → C 約0.5-3倍**（取決於上市後股本設計）。

## 1. 概念分層：先講清楚"哪個每股"

很多坊間討論把"螞蟻數科每股值多少"作為一個單一問題在討論，**這是錯誤的**。現階段螞蟻數科的"每股"至少要分三個層次：

### 1.1 三層含義對照表

| 層次 | 標的物 | 單位 | 是否市場化 | 當下是否存在 |
|---|---|---|---|---|
| **A層 / 當下出資份額** | 螞蟻數科本身 | 每"元"註冊資本對應的市場估值 | 否（無外部融資錨） | ✅ 已存在 |
| **B層 / 員工激勵隱含** | 螞蟻集團股權（含1.4%數科映射） | 每份SER（拆分後108.21元）中的數科部分 | 半市場化（基於母公司公允價） | ✅ 已存在 |
| **C層 / IPO後股票** | 螞蟻數科上市股份 | 每股股票（擬港幣計價） | 是（公開市場） | ❌ 暫未存在 |

### 1.2 為什麼這三層必須分開

1. **法律實體不同**：A層是"螞蟻鏈（上海）數字科技有限公司"的出資權益；B層標的是"螞蟻科技集團股份有限公司"的股權；C層是未來重組後的IPO主體（大概率是新設港股控股公司）。
2. **流動性不同**：A層完全無流動性（有限責任公司股權轉讓需股東會批准）；B層是公司內部映射，離職員工被強制現金回購；C層若上市則港股二級市場可自由交易。
3. **價值來源不同**：A層反映"今天螞蟻數科作為一家公司值多少"；B層反映"螞蟻集團內部會計上把數科算作多少"；C層則反映"未來上市市場願意給多少倍數"。
4. **持有人不同**：A層股東僅為螞蟻集團及其控股平臺；B層是歷史在職/離職員工；C層未來是公開市場投資者。

> **核心提醒**：B層（SER中的數科部分）不等於"持有螞蟻數科股票"。這是2025年3月"一拆四"事件中部分員工與公司爭議的根本來源——SER的標的物始終是螞蟻集團，數科只是會計映射。

## 2. A層：每元註冊資本對應的市場價值

### 2.1 已知事實

- 螞蟻數科主體註冊資本：**21.07億元**（2024年5月增資後，未再變動）
- 4/17已有研究估值區間：**450-750億RMB**（中位數550億）
- 截至2026-04-28，**無外部獨立融資定價**（增資性質屬於內部資本結構調整）

### 2.2 推算

**公式**：每元註冊資本對應市場價值 = 公司估值 / 註冊資本總額

| 估值假設 | 估值（RMB） | 每元註冊資本對應價值 |
|---|---|---|
| 保守 | 300億 | **14.2元** |
| 4/17下限 | 450億 | **21.4元** |
| 4/17中性 | 550億 | **26.1元** |
| 4/17上限 | 750億 | **35.6元** |
| 樂觀 | 1,500億 | **71.2元** |

### 2.3 重要警示

- 這個數字是"虛擬的市場價值"，**沒有可交易性**——螞蟻集團目前100%持股，外部投資者無法按這個價格買入。
- 21.07億"註冊資本"不等於"21.07億股"。中國《公司法》下有限責任公司只有出資額而無股票概念。一旦未來股改並完成IPO，會按"1元註冊資本拆為N股"的方式重新設計股本結構。
- 增資到21.07億的實際"出資來源"未公開披露，業內推測含部分員工持股平臺對螞蟻數科的認購。

## 3. B層：員工激勵SER隱含的"數科部分"價值

### 3.1 一拆四的會計公允價值

**核心數據**（來源：新浪財經2025-03-11原文，已多方交叉確認 🟢）：

| 項目 | 拆分前 | 拆分後（僅螞蟻集團部分） | 縮水幅度 |
|---|---|---|---|
| SER 稅前公允價 | 115.85元/份 | **108.21元/份** | -6.6% |
| RSU 公允價 | 20.95元/份 | **19.58元/份** | -6.5% |

**映射比例**：螞蟻集團 **93.4%** / 螞蟻國際 **4.8%** / 螞蟻數科 **1.4%** / OceanBase **0.4%**

### 3.2 隱含的"每份SER中數科部分"

**會計口徑**（基於一拆四公允價）：

```
SER中數科部分 = (115.85 − 108.21) × (1.4% ÷ 6.6%) ≈ 1.62元/SER
```
或等價地用映射比例反算：
```
SER中數科部分 ≈ 108.21 × (1.4% ÷ 93.4%) ≈ 1.62元/SER
```

> 取整後約 **1.5 ~ 1.7元/SER** 是會計意義上"每一份SER背後映射的數科價值"。

### 3.3 用市場化估值反推（核心修正）

會計公允價的侷限：**(1)** 沒有外部融資錨定；**(2)** 關聯交易未剔除；**(3)** 內部分配可能保守。

參考螞蟻集團2025年胡潤估值6,350億（經5,710億一拆四公允價對接驗證）：

| 螞蟻數科估值假設 | 佔集團比例 | 每份SER中數科部分 |
|---|---|---|
| 80億（員工激勵隱含口徑） | 1.40% | 1.51元/SER |
| 300億（保守市場化） | 5.25% | 5.69元/SER |
| 550億（中性，4/17中位數） | 9.63% | 10.42元/SER |
| 750億（4/17上限） | 13.13% | 14.21元/SER |
| 1,500億（樂觀） | 26.27% | 28.42元/SER |

**注**：佔集團比例 = 螞蟻數科估值 / (集團5,710億 + (螞蟻數科估值 − 80億) × 1)。簡化算法：直接用螞蟻數科估值 ÷ 5,710億 × 108.21。

> **關鍵發現**：當前會計映射下，**每份SER的"數科部分"僅1.51-1.62元**；但若按市場化中性估值（550億）反推，應當對應**約10.4元/SER**——會計口徑較市場化口徑**低估約6-7倍**。這是離職員工抗議"強制回購"的核心商業邏輯。

### 3.4 但要小心：B層不等於"數科股票"

即便按市場化反推到10元/SER，員工拿到的依然是**螞蟻集團**SER的現金流權——除非螞蟻數科獨立IPO並執行"分發"機制（目前協議中**未授予在職員工此類權利**）。1.4%的映射只在內部回購定價時使用。

## 5. 三層之間的橋樑

### 5.1 價值乘數關係圖

```
B層會計口徑(1.51-1.62元/SER中數科部分)
        ↓ × 6.5x（會計保守 + 關聯交易剔除）
B層市場化口徑(約10.4元/SER中數科部分)
        ↓ 單位轉換（每份SER → 螞蟻數科估值）
A層中性估值(550億RMB / 21.07億元註冊資本 = 26.1元/元註冊資本)
        ↓ 股本拆細 + 流動性溢價
C層IPO中性招股價(約18-26 HKD/股，中型股本)
```

### 5.2 差距來源拆解

| 差距 | 幅度 | 主要來源 |
|---|---|---|
| B層會計 vs B層市場化 | ~6.5倍 | 會計公允價採用集團內部口徑，未引入市場倍數；關聯交易未剔除 |
| B層 vs A層 | 由口徑決定 | 1.4%映射比例可能嚴重低估數科作為獨立IPO標的的價值（見4/17報告） |
| A層 vs C層 | 0.5-3倍 | 一級到二級流動性溢價（IPO折價反向算），股本設計 |

### 5.3 核心問答

**問：當下持股的"賬面每股"vs"IPO預期每股"差距是多少倍？**

- 會計口徑每份SER中數科部分 ≈ 1.51元
- 中性IPO場景下"每份SER最終能換回的數科上市流通價值"≈ 取決於是否有獨立換股機制
- 若假設上市時按比例分發：1.51元 → 中性約10元（市場化估值修正）→ IPO上市再溢價30-50% → 約13-15元/SER的數科部分流通價值
- **乘數 ≈ 8-10倍**（僅當數科按550億估值IPO並允許員工分享時）

但**前提條件極為嚴苛**：
1. 數科必須完成上市（CEO公開稱"明年外灘大會再答IPO時間表"，最早2027下半年）
2. 集團必須設計在職員工分享數科上市收益的機制（截至4/17未公開此類承諾）
3. 上市估值必須達到中性550億以上

## 7. 流動性折價與時間價值討論

### 7.1 流動性折價層次

非上市股權到上市股權的折價通常分三段：

| 折價類型 | 通常幅度 | 螞蟻數科適用情況 |
|---|---|---|
| **私募一級市場到二級市場** | 30-50% | 中國私募股權基金過去兩年折價40-50%（TR Capital數據，2024-2025） |
| **Pre-IPO到IPO定價** | 10-25% | IPO通常給基石投資者15-20%賬面收益空間 |
| **港股小盤流動性** | 10-30% | 港股2025-2026年度日均成交額分佈兩極分化，小盤股流動性差 |

> **綜合判斷**：當下A層"中性26.1元/元註冊資本"在沒有外部融資錨的情況下，**還需要打30-40%的折扣**才是真正"可成交價"。即真實A層估值可能落在 18-21元/元註冊資本之間。

### 7.2 時間價值折扣

員工股權激勵的時間維度（參考螞蟻集團2025年4月起新規）：

- **Cliff期**：1年（首次歸屬前不得出售）
- **Vesting期**：4年（按季度1/16歸屬）
- **IPO最早時點**：2027年下半年（CEO公開口徑）→ 距今約18個月

**折現率假設10%**（參考螞蟻集團權益資本成本）：

```
今天1元 vs 2027年底1元 → 折現因子 ≈ 0.85
今天1元 vs 2030年底（充分流通）→ 折現因子 ≈ 0.62
```

> **關鍵發現**：即便假設上市達成，**今天的"賬面價值"比上市後流通價至少打0.85折**。疊加IPO失敗概率（保守假設30-40%），真實"風險調整後"價值還要再打折。

### 7.3 港股小盤流動性折價案例

- **金融壹賬通**（OCFT）：2019年12月IPO招股價10美元，2026年4月僅7.89美元，折價21%；港股6638成交極度清淡
- **港股18C特科技**：2025-2026年度新掛牌的小盤科技股普遍出現首日破發或交投清淡

> **教訓**：即便C層掛牌成功，**前2-3年股價大概率在招股價上下波動**，真正流通價值兌現可能要到上市3年以上。

- 螞蟻數科**SER總份數和員工持股池佔股本比例**——螞蟻集團2020年招股書披露30.79億股對應SERs（佔當時總股本約13%），但"一拆四"後子公司單獨的股本設計未披露
- 螞蟻數科**最終上市架構**——是否會設VIE、是否新設港股控股殼、是否引入Pre-IPO融資
- **在職員工數科部分的退出/分享機制**——目前協議未公開承諾數科上市後允許員工獨立持股

## 9. 綜合結論

### 9.1 三層每股價值錨定

> **A層（當下出資份額）**：每元註冊資本市場價值 **21-36元**（基於4/17估值450-750億區間），中性26.1元/元註冊資本
> **B層（員工激勵隱含）**：會計口徑每份SER的數科部分 **1.51-1.62元**；市場化修正口徑 **5.7-14.2元**（保守-上限），中性10.4元
> **C層（IPO預測）**：港幣 **8-30元/股**（中性場景，取決於股本設計），中性約18-26 HKD/股

### 9.2 當下"賬面"vs"IPO預期"的乘數關係

| 路徑 | 起點 | 終點 | 乘數 |
|---|---|---|---|
| 會計口徑 SER數科部分 → 中性市場化數科估值 | 1.51元 | 10.4元 | **6.9倍** |
| 中性市場化數科估值 → 流通後IPO上市價值 | 10.4元 | 13-15元 | **1.3-1.5倍** |
| **總乘數（會計 → 流通）** | 1.51元 | 13-15元 | **約8.6-9.9倍** |

> **核心結論**：若中性情景兌現且員工能分享數科部分獨立上市的收益，**當下賬面價值與未來流通價值之間的乘數約8-10倍**。但兌現前提苛刻（IPO成功 + 分享機制）。一旦IPO失敗（極端情景），賬面價值=0。

### 9.3 給讀者的判斷框架

1. **判斷估值區間**：相信4/17的"450-750億"中位還是相信"80億員工激勵反推口徑"？前者隱含市場化邏輯，後者隱含會計保守。
2. **判斷IPO概率**：基礎概率約50-60%（參考螞蟻國際2026先行、數科最早2027下半年）。
3. **判斷股本設計**：緊湊型（11億股）vs 大型（33億股）招股價相差約3倍。
4. **判斷流動性**：港股小盤上市後2-3年通常流動性差，"賬面價值"到"可兌現現金"還有30-50%折價。

> **最樸素的回答**：如果今天有人問"螞蟻數科一份SER背後的數科部分值多少？"——**會計回答1.6元，市場化回答10元，樂觀IPO兌現回答15元，IPO失敗回答接近會計回購價**。差距6-10倍。
