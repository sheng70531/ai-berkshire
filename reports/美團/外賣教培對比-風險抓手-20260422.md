# 外賣"雙減式打擊"尾部風險與抓手研究

**ai-berkshire 外賣風險抓手專員 | 2026-04-22**

## 1. 核心判斷

外賣"雙減式毀滅打擊"**綜合概率約 5-8%**，屬尾部風險但不可忽略。**最可能導火索**：騎手極端天氣群體性死亡 + 央視連續調查 + 人民日報系列評論員文章三重共振。**次可能導火索**：重大食品安全公共衛生事件。**當前早期信號強度約 3/5**（教培 2021-05 是 5/5），距離毀滅級仍有 1.5-2 檔升級空間。**2026-03 經濟日報社論 + 市監總局進駐調查已構成監管預警區間的明確入口**。

## 2. 外賣可能被整頓的 5 大社會問題

### 問題一：騎手過勞死/事故死亡（烈度最高）
**已發生案例**：
- 2020-12 餓了麼騎手韓某送單途中猝死
- 2021《中國新聞週刊》：騎手每 2.5 小時 1 單，每天 12 小時+
- 2024 多地極端天氣騎手傷亡

**為何最高烈度**：死亡事件**強情感動員力** + 家屬上訪 + 弱勢群體敘事 = 監管高度敏感。

**可能觸發**：一次重大群死群傷（>10 名騎手遇難）→ 央視連續 3 天 → 人民日報評論員 → 中央深改委審議

**政策抓手**：強制社保、最高工時約束、極端天氣停單、算法禁罰、勞動關係認定

### 問題二：食品安全系統性問題
**已發生案例**：2021 餓了麼黑作坊、2023 無證外賣店、315 晚會多次點名

**為何易介入**：《食安法》《網絡餐飲服務食品安全監督管理辦法》已完備，**監管無需新立法**。

**可能觸發**：某城市**數千人集體中毒 + 致死** + 平臺系統性審核失職

**政策抓手**：商家門檻提高、強制明廚亮灶、平臺連帶責任、黑名單全國聯網

### 問題三：算法壓榨/騎手被困系統
**已發生案例**：2020《外賣騎手困在系統裡》（**標誌性爆文**）、2021 央視"算法困境"、2025 多次央視報道

**為何高層關注**：**"平臺不能凌駕於人之上"** 是習近平多次強調的立場。

**可能觸發**：算法致死群體性悲劇 + 學界深度研究 + 監管專項調查

**政策抓手**：算法備案公開、第三方獨立審計、禁止"超時即罰"、算法申訴權

### 問題四：商家絕望/中小餐飲倒閉潮
**已發生數據**：
- 2025 餐飲商家利潤率從 32% 壓到 24%
- **71% 商戶歸咎補貼戰**
- 每月數萬家餐廳倒閉

**為何被低估**：商家維權缺情感衝擊力，但**商家 = 稅源+就業源**，地方政府最關心。

**可能觸發**：大規模集體維權 + 人大代表提案 + 央視《經濟半小時》曝光

**政策抓手**：最低佣金率、補貼上限、T+3 結算、禁止二選一

### 問題五：未成年人過度依賴
**已發生現象**：中學生/大學生外賣比重升高、肥胖率

**為何潛伏**：**2021 遊戲防沉迷已開先例**，衛健委+教育部+市監總局跨部委聯動模式已成熟。

**可能觸發**：青少年健康白皮書 + 家長投訴 + 衛健委專項調研

**政策抓手**：校園 500 米禁入、未成年人實名限額、深夜 23 點後限制
