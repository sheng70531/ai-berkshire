# 騰訊派息減持美團：事件全景研究

**整理日期：2026-04-22**

> 騰訊作為美團早期核心股東，選擇以"派息"而非市場拋售的方式退出，這一決策背後的邏輯與影響值得深入剖析。

---

## 一、背景：騰訊與美團的股權淵源

### 1.1 投資歷史

| 時間 | 事件 |
|------|------|
| 2014年 | 騰訊戰略投資大眾點評，出資約4億美元，獲得約20%股權 |
| 2015年10月 | 騰訊主導推動美團與大眾點評合併，新公司成立 |
| 2016年1月 | 騰訊領投美團點評E輪融資，出資約15億美元 |
| 2018年9月 | 美團點評在香港聯交所上市（股票代碼：3690.HK） |
| 2018年上市前後 | 騰訊持股約20%，為第一大機構股東 |
| 2022年11月16日 | 騰訊宣佈以"派息"方式分派約90.9%美團持股 |
| 2023年1月4日 | 享有美團股票分派權利的騰訊股份最後交易日 |
| 2023年3月24日 | 騰訊股東正式收到美團股票，派息完成 |

騰訊在美團身上累計投資超過40億美元，以派息時美團股價估算，騰訊的內部投資回報率（IRR）約為30%，總價值約為217億美元，浮盈超過5倍。

### 1.2 騰訊是"投資型股東"而非"控制型股東"

騰訊與美團的關係並非控股子公司，而是戰略投資+流量協同。騰訊為美團提供：
- **微信"錢包"入口**：外賣、團購業務直接嵌入微信支付頁面
- **微信小程序流量**：美團在微信生態內獲得巨大自然流量
- **微信支付深度合作**：美團是微信支付在線下餐飲領域最大的合作方

騰訊總裁劉熾平同時擔任美團非執行董事，標誌著雙方的"戰略綁定"關係。

## 二、事件經過：詳細時間線

### 2.1 先例：2021年12月派息京東

2021年12月23日，騰訊宣佈將其持有的約4.6億股京東股份（約17%股權）以"中期派息"方式分發給騰訊股東，分派比例為每持有10股騰訊股獲發1股京東股。派息完成後，騰訊對京東的持股比例由17%降至約2.3%。

這一操作開創了"派息式減持"的先例，騰訊因此成功在不引發市場恐慌性拋售的前提下，完成了對京東大規模持股的退出。

### 2.2 美團派息：完整時間線

| 日期 | 事件 |
|------|------|
| 2022年11月15日 | 消息傳出，美團股價盤中下跌約10% |
| 2022年11月16日 | 騰訊董事會正式宣佈中期派息決議；劉熾平辭任美團非執行董事（即日生效） |
| 2022年11月16日收盤 | 美團股價下跌2.46%，收於162.3港元/股 |
| 2023年1月4日 | 騰訊股東享有分派權利的最後交易日（登記日） |
| 2023年1月5日 | 騰訊股票除權日 |
| 2023年3月24日 | 騰訊股東正式收到美團B類普通股，派息完成 |

| 項目 | 數據 |

| 總市值 | 約1,594億港元（約203億美元） |

| 派息前騰訊持股比例 | 約17%（約10.55億股） |
| 派息後騰訊保留持股 | 約9,700萬股，佔比約1.5%~1.7% |
| Naspers/Prosus可獲美團股份估算 | 約2.61億股（按彼時約27.2%騰訊持股權益測算） |

**注**：Naspers（南非報業）旗下Prosus為騰訊最大股東，宣佈計劃在收到美團股票後予以出售。

## 三、騰訊為什麼這樣做？——多重驅動因素分析

### 3.1 監管壓力（最重要驅動因素）

2020年底起，中國監管部門對互聯網平臺經濟展開全面整頓：

- **反壟斷執法升級**：2021年4月，阿里巴巴被罰182億元，開創互聯網反壟斷先河；同期美團因"二選一"行為被立案調查，最終於2021年10月被罰34.42億元。
- **"禁止資本無序擴張"**：2021年起，"防止資本無序擴張"成為官方政策導向，互聯網巨頭在金融、媒體、教育等領域的擴張受到直接限制。
- **騰訊投資帝國的隱患**：騰訊持有超過800家公司的股權，覆蓋電商（京東、拼多多）、外賣（美團）、社區團購、本地生活等幾乎所有消費互聯網賽道，形成了實質性的"平臺控制平臺"格局，面臨壟斷聯結的政策風險。
- **主動"瘦身"降低監管風險**：外界分析認為，騰訊通過減持競爭性賽道的股權，向監管層傳遞"我不控制這些平臺"的信號，是一種主動合規動作（分析人士將其稱為"神操作規避反壟斷"）。

### 3.2 財務壓力：騰訊自身業績持續下滑

2021年下半年至2022年，騰訊遭遇有史以來最嚴峻的業績寒冬：
- 2022年Q2營收同比下滑3%（騰訊上市以來首次季度營收負增長），非IFRS淨利潤同比下滑17%；
- 2022年全年營收約為5,545億元人民幣，同比下滑約1%；
- 聯營公司（含美團）虧損大幅拖累利潤：2022年前三季度累計分佔聯營公司虧損約144億元；
- 騰訊投資組合公允價值大幅縮水：截至2022年9月30日，上市投資公允價值3,761億元，較2021年底的6,347億元縮水約40%；
- 遊戲審批收緊、廣告市場萎縮，主營業務均承壓，公司需要通過出售投資來改善賬面。

### 3.3 戰略轉型：從"投資型騰訊"迴歸"產品型騰訊"

2021年開始，騰訊明確戰略收縮：
- 對外投資從2021年約300起大幅壓縮至2023年約40起、2024年約20起；
- 將資源重新聚焦於核心的遊戲、社交（微信）、企業服務（雲、企業微信）以及AI等方向；
- 管理層將騰訊定位為"科技公司"而非"投資控股公司"；
- 騰訊高管在派息後表示："騰訊將繼續專注投資遊戲、短視頻等核心領域。"

### 3.4 為什麼選擇"派息"而非"市場減持"？

這是理解本次操作的關鍵點：

| 對比維度 | 市場二級拋售 | 派息分發 |
|----------|------------|---------|
| 對美團股價衝擊 | 極大，大宗減持會觸發市場恐慌 | 較小，相當於把拋壓分散給全體騰訊股東 |
| 騰訊承擔稅務 | 在港股層面處置收益需披露 | 以實物分配方式，遞延稅務影響 |
| 股東利益 | 騰訊直接變現，股東得到現金回報 | 股東直接獲得美團股票，可自行決策持有或賣出 |
| 監管觀感 | 大宗減持容易被解讀為"撤資" | 派息形式更"正當"，回報股東的名義更合規 |
| 速度 | 大宗交易需要找接盤方，耗時長 | 一次性完成，行政效率高 |
| 控制權表態 | — | 同步辭去董事席位，徹底表明"不控制"立場 |

**核心邏輯**：派息是對美團、對市場、對監管層"傷害最小、信號最清晰"的退出方式。

## 四、對騰訊的影響

### 4.1 財務影響

**利好方面：**
- 騰訊在美團投資上賬面獲利約1,066億元人民幣（在2022年Q4確認，來源：新浪財經報道，基於騰訊管理層披露的視同處置收益）；
- 騰訊2022年全年淨利潤（Non-IFRS）約為2,271億元，美團處置收益是少數亮點之一；
- 消除了未來美團業績波動對騰訊聯營公司損益的持續拖累（2022年美團全年經營虧損達105億元）。

**利空方面：**
- 騰訊永久失去了對美團股票未來升值的參與權；
- 美團股價在2022年底至2023年後大幅反彈，騰訊未能享有此後的資本增值；
- 派息行為使騰訊股東被動獲得了不同公司的股票，部分機構股東（如Prosus）隨即選擇出售，形成對美團股價的持續賣壓。

### 4.2 戰略影響

- **"騰訊系"版圖收縮**：騰訊從名義上的"生態系平臺"角色退出，"騰訊系"概念逐漸解體；
- **與美團關係從"股東+合作"變為純"流量合作"**：騰訊失去通過董事會參與美團治理的渠道；
- **樹立減持方法論先例**：繼京東、美團後，2023年4月騰訊又以類似方式處置了旗下部分快手股份（5,115萬股），"分紅式減持"成為騰訊處理成熟被投企業的標準工具。

### 4.3 股價影響

- 2022年11月16日公告當日，騰訊股價在港股市場上漲約4%（登記日2023年1月4日當天亦有明顯拉昇），市場將派息解讀為騰訊聚焦主業、優化資產負債表的積極信號；
- 騰訊股價在2022年底隨香港市場整體反彈，派息帶來的"輕裝上陣"敘事助推了情緒修復。

## 五、對美團的影響

### 5.1 短期股價衝擊

| 時間節點 | 美團股價表現 |
|----------|------------|
| 2022年11月15日（消息洩露） | 盤中最大跌幅約10% |
| 2022年11月16日（公告後收盤） | 下跌2.46%，收於162.3港元 |
| 2023年1月4日（登記日） | 股價承壓，但整體處於港股反彈大背景中 |
| 2023年3月24日（實際分配完成） | 騰訊股東陸續收到美團股票，部分機構賣出形成賣壓 |

整體而言，由於派息方式對股價衝擊遠小於大宗減持，加之香港市場在2022年底受防控政策優化利好整體反彈，美團股價受到的衝擊相對可控。

### 5.2 股權結構變化

| 股東 | 派息前持股 | 派息後持股 |
|------|-----------|----------|
| 騰訊 | 約17%（約10.55億股） | 約1.5%~1.7%（約9,700萬股） |
| 王興（創始人） | 約8.9% | 無變化，約9.3%~9.6%（截至2024年） |
| Prosus/Naspers | — | 被動獲得約2.61億股美團（後陸續出售） |
| 國際散戶/機構 | — | 大量騰訊股東被動持有美團 |

**關鍵變化**：騰訊從"第一大機構股東（17%）"降至"象徵性持股（<2%）"，美團不再是騰訊的聯營公司，改為以公允價值計量的金融資產。

### 5.3 治理層面影響

- 劉熾平辭任美團非執行董事，美團董事會騰訊席位清零；
- 王興通過A類股擁有約44%~46%的投票權，公司控制權始終在創始團隊手中，此次變動對公司決策無實質影響；
- 美團對騰訊"戰略依附"的敘事終結，市場開始重新評估美團的獨立性。

### 5.4 Prosus後續處置美團股份

騰訊最大股東Naspers/Prosus在收到美團股份後，明確表示計劃出售。此後：
- Prosus陸續在二級市場減持美團股份；
- 2025年7月，Prosus出售部分美團股權，套現約2.5億美元（來源：新浪財經）；
- Prosus的持續賣出對美團股價形成了較長時間的"懸劍"壓力，但由於分批出售，整體衝擊有限。

## 六、騰訊與美團關係的後續演變

### 6.1 商業合作：維持且深化

儘管股權關係大幅弱化，騰訊與美團的商業合作不僅保留，在某些方面還進一步深化：

- **微信入口維持**：美團外賣（2016年起）、美團團購（2020年起）持續佔據微信"錢包-購物消費"板塊的核心位置；
- **小程序深度整合**：美團在微信小程序體系內運營，微信月活用戶超過13億，是美團最重要的外部流量來源之一；
- **2024-2025年社交電商新合作**：2024年9月，美團推出與微信朋友圈無縫跳轉的評價分享功能；2025年7月美團宣佈即時零售日訂單量達1.5億單，其中微信禮贈量突破千萬單；
- **本質邏輯**：對美團而言，微信流量的價值與騰訊是否持股無關，商業合作是雙方互利的，騰訊退出股東角色反而降低了談判中的權力不對稱。

### 6.2 "騰訊系"解體：互聯網格局重構

騰訊陸續退出京東、美團等核心資產，標誌著"騰訊系"這一通過交叉持股形成的互聯網聯盟正式瓦解：

| 操作 | 時間 | 騰訊持股變化 |
|------|------|------------|
| 派息京東 | 2021年12月 | 17% → 2.3% |
| 派息美團 | 2022年11月（完成2023年3月） | 17% → 1.5% |
| 部分處置快手（外部投資夥伴要求） | 2023年4月 | 20.46% → 19.02% |
| Prosus持續減持騰訊 | 2022年至今 | 持續出售，2023年Prosus持騰訊約27.2% |

### 6.3 騰訊的新投資方向

騰訊將從被投公司退出所得的資金和精力，重新配置於：
- **AI與大模型**（混元大模型、騰訊雲AI）
- **遊戲**（核心主業強化）
- **企業服務與雲**（騰訊雲、企業微信）
- **機器人與硬科技**（選擇性佈局）

## 八、投資啟示

### 8.1 "派息式減持"的方法論價值

騰訊首創並兩次執行的"派息式減持"，為大股東退出提供了一套經典方法論：
- **拋壓分散化**：將集中賣壓轉化為數十萬股東的分散決策，單日市場衝擊極小；
- **股東利益最大化**：相比大宗減持往往有折扣，派息使騰訊股東直接以市價獲得被投公司股票；
- **監管信號清晰**：以分紅名義退出，合規形象良好，不觸發"減持"的負面解讀。

**對投資者的啟示**：當大型機構股東選擇"派息分發"而非"市場拋售"時，是比較溫和的退出信號，短期衝擊可控，被分發方股票未必是賣出時機。

### 8.2 "被動股東"的風險：以Prosus為例

Prosus作為騰訊最大股東，被動收到約2.61億股美團股份，但Prosus自身的投資組合策略並不需要持有美團，因此選擇陸續出售——這形成了一種"套娃式賣壓"：騰訊減持→Prosus獲得美團→Prosus再減持美團。

**啟示**：關注一家公司的股權結構時，要識別哪些股東是"主動持有者"（因認可業務而持股），哪些是"被動持有者"（因其他原因被動獲得），後者是隱性的賣出壓力來源。

### 8.3 監管環境與互聯網巨頭投資邏輯的轉變

2020~2022年的監管週期深刻改變了中國互聯網的投資邏輯：
- 互聯網"生態帝國"敘事（通過交叉持股控制多個賽道）從資產變成了風險；
- 監管壓力使騰訊、阿里被迫"收縮版圖"，客觀上降低了被投公司的估值溢價（"騰訊背書"折價）；
- 對於美團這類有強獨立能力的公司，脫離大股東羽翼反而利於市場重新發現其獨立價值。

### 8.4 騰訊作為價值投資標的的再思考

騰訊本次操作確認的約1,066億元收益，提醒投資者：**騰訊的賬面淨資產中包含了大量隱藏價值**（被低估的投資組合），這是騰訊估值的一個重要維度。隨著騰訊陸續出售成熟投資、聚焦核心業務，其"投資控股公司折價"有望逐步收窄。
