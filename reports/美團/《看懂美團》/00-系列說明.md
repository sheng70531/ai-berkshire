# 《看懂美團》系列說明

> 5 篇正文，把美團一層一層拆開，看見它真正的結構。
>
> 系列閱讀時間約 45 分鐘；建議按順序閱讀。

---

## 系列定位

美團不是一家"看不懂"的公司——它是一家**所有人都覺得自己看懂了但判斷完全相反**的公司。

- 看多派說：PS 1.29x 歷史最低、現金儲備 1,669 億、外賣份額仍在 50%+、補貼戰終將結束
- 看空派說：護城河已被阿里攻破、一年虧 234 億、騎手社保是定時炸彈、可能永遠淪為微利配送公司

**兩派看的是同一份年報，結論卻完全相反。** 核心分歧只有一個：2025 年的虧損是暫時的戰場傷口，還是永久的商業模式缺陷？

這個系列要做的，是把"暫時還是永久"這個判斷拆成可驗證的子問題，讓你自己得出結論。

---

## 系列寫作原則

1. **先擺數據、再推邏輯、最後得結論**——不預設看多看空
2. **每個核心判斷都附反方觀點**——讓讀者自己權衡
3. **區分官方數據和賣方測算**——美團自 2022Q1 起停止披露外賣/到店/閃購子分部財務，本系列嚴格標註數據口徑
4. **不構成投資建議**——所有篇章末尾免責聲明

## 與《看懂拼多多》對比

| 維度 | 拼多多 | 美團 |
|------|--------|------|
| 核心矛盾 | 極度便宜但看不清（管理層黑箱 + Temu 不確定性） | 看得很清楚但正在流血（外賣大戰 + 利潤清零） |
| 估值 | PE 10x，扣現金 6x | PS 1.29x，PE 虧損不適用 |
| 護城河 | 中等強度（算法 + 白牌生態），正在被侵蝕 | 寬但淺（配送網絡 + 商家生態），正在被挑戰 |
| 管理層 | 黑箱（黃崢消失、零溝通、零回饋） | 透明（王興活躍、戰略清晰，但資本紀律是短板） |
| 核心賭注 | Temu 的終局 | 外賣大戰的終局 |
| **讀者畫像** | 能接受"看不清"的高不確定性投資者 | 能接受"短期流血"的逆向投資者 |
