美團管理層明確表態：**以股票回購作為對沖股權激勵攤薄的主要工具**，而非以派發現金股息為主。CEO王興在電話會上稱："美團的目標是通過股票回購來抵消每年員工股權激勵的攤薄影響。"公司認為，在建立穩定充足的離岸現金儲備之前，回購優先於分紅。

## 二、分紅歷史

### 2.1 美團自身從未派發現金紅利

自2018年9月上市至今（2026年4月），美團**從未**向普通股股東派發過現金股息或特別股息。

**官方立場**：管理層表示，在離岸現金儲備充足之前，將優先以回購而非分紅回饋股東。

### 2.2 騰訊的"派息式減持"（間接影響美團股價）

這不是美團自身的分紅，但對美團股東結構產生重大影響：

| 時間 | 事件 | 金額/規模 | 影響 |
|-----|------|----------|------|
| 2022年11月16日 | 騰訊宣佈將持有的約90.9%美團B類股份（約9.58億股）作為特別中期股息派發給騰訊股東 | 總市值約1,594億港元（按2022年11月15日收盤價166.4港元/股） | 騰訊持股從約17%驟降至約1.5%；劉熾平辭任美團非執行董事；美團失去騰訊系背書，短期股價承壓 |

## 三、對股東有利的事件

### 3.1 股票回購（2024年至今）

如第一節所述，美團自2024年起開始系統性回購，態度從無到有，規模持續擴大（10億→20億→10億美元），是近年來最實質性的回饋股東舉措。

**正面評價**：
- 回購價位（70-140港元區間）大幅低於歷史高點（460港元，2021年2月），客觀上具有較高性價比
- 規模相對股本約2.5%，有實質性的減少流通盤效果
- 回購節奏較為連續穩定，非一次性操作

**侷限**：
- 回購金額（約220億港元）仍低於同期股權激勵費用（估算每年約60-90億元人民幣），淨抵消效果有限
- 首次回購時間點（上市後第六年）明顯滯後，過去五年股東未曾享受任何現金回報

### 3.2 管理層持股穩定（王興未減持美團股份）

| 時間節點 | 王興持股比例 | 投票權 |
|---------|-------------|-------|
| 2018年上市 | 約11.4% | 約48%（AB股結構） |
| 2023年3月 | 8.33% | 43.13% |
| 2024年3月 | 9.6% | 44.33% |
| 2025年初 | 9.3% | 約46% |

**說明**：王興持股比例略有下降（主要因公司整體股本因融資和激勵擴大所致），但**未見王興主動減持美團股票的公開記錄**。王興減持的是個人持有的理想汽車股票（2023-2025年累計套現約28億港元），與美團持股無關。

**正面解讀**：控股股東與公眾股東利益相對綁定，無"大股東套現走人"的行為。

### 3.3 盈利能力改善（2019-2024）

| 年份 | 核心業務經營利潤（億元人民幣） | 調整後淨利潤（億元人民幣） |
|-----|-------------------------|------------------------|
| 2018 | 虧損 | -85（調整後） |
| 2019 | 略虧 | -22 |
| 2020 | 正轉 | 31 |
| 2021 | 承壓 | -68（因社區團購） |
| 2022 | 改善 | 28 |
| 2023 | 顯著改善 | 232 |
| 2024 | 峰值 | 358 |

2023-2024年的盈利大幅改善，證明核心商業模式（外賣+到店）的盈利能力得到驗證，股價從低谷（約55港元，2023年1月）回升至約180港元（2024年中），帶給持有股東約3倍的賬面回報。

### 3.4 資本配置趨於理性（2022年後）

- 2022年前後大幅收縮社區團購（美團優選）虧損規模
- 2023年起新業務虧損從峰值384億元/年（2021年）壓縮至約73億元（2023年）
- 2024年進一步壓縮至約47億元
- 砍掉快驢、收縮摩拜等戰略失誤業務

### 3.5 2024年發行優先票據（債務結構優化）

2024年9月，美團發行25億美元優先票據（4.5%，2028年到期12億美元；4.625%，2029年到期13億美元），主要用於**現有離岸債務再融資**，優化債務結構，而非盲目加槓桿擴張，被惠譽評為"BBB"級別。

## 四、對股東有害的事件

### 4.1 大規模股權稀釋

#### 4.1.1 2021年歷史性鉅額增發（最重要的稀釋事件）

| 項目 | 詳情 |
|-----|------|
| 公告日期 | 2021年4月19日 |
| 融資規模 | 約100億美元（約合650億元人民幣） |
| 配股規模 | 約1.87億股B類普通股，佔當時已發行股本約3.2% |
| 配售價格 | 265-274港元/股（較收盤價289.2港元折價5.3%-8.4%） |
| 可轉換債券 | 約29.8億美元零息可轉換債券 |
| 騰訊認購 | 按273.80港元/股認購1,135.26萬股（約3.1億美元） |
| 創紀錄 | 創港交所上市公司配售融資歷史之最 |
| 資金用途 | 科技研發（無人車、無人機）、拓展生鮮超市（應對阿里盒馬） |

### 4.2 重大戰略失誤與資本損毀

#### 4.2.1 摩拜單車收購（2018年4月）

| 項目 | 詳情 |
|-----|------|
| 收購時間 | 2018年4月 |
| 收購價格 | 實際價值約27億美元（總交易價含債務約37億美元） |
| 2018年摩拜虧損 | 45.5億元人民幣（當年貢獻收入僅15.07億元） |
| 商標減值撥備 | 13.46億元（更名為"美團單車"後） |
| 其他運營拖累 | 單車調度+維修費36億元（同比+260%） |

**背景**：美團收購摩拜時，摩拜已挪用用戶押金約60億元、債務超過10億美元。此次收購被普遍認為是"接盤"，以高於市場合理估值的價格介入了一個持續虧損的商業模式，嚴重拖累上市首年財報。

#### 4.2.2 社區團購（美團優選）——千億虧損黑洞

| 時間段 | 事件 | 虧損規模 |
|--------|-----|---------|
| 2020年下半年 | 美團優選上線，燒錢圈市場份額 | — |
| 2021年 | 新業務（含優選）虧損峰值 | 約384億元人民幣 |
| 2022年 | 持續虧損，開始收縮城市 | 約282億元 |
| 2023年 | 大幅削減 | 約202億元 |
| 2024年 | 繼續壓縮 | 約47億元 |
| 2025年12月 | 美團優選全面關停，五年合計虧損超1,000億元 | 估算累計逾1,051億元 |

**點評**：美團2021年在全行業高呼"社區團購將改變零售格局"時，選擇以極高代價入場燒錢，最終被拼多多低價優勢碾壓，無法突圍，落得五年燒光超千億而全面退出的結局。此決策被眾多分析師視為美團歷史上最大的戰略失誤之一，直接損毀了大量股東價值。

#### 4.2.3 美團打車戰略失誤（2018-2019年）

美團2018年進入網約車市場（與滴滴正面交戰），最終因燒錢無法持續，2019年從自營模式退為聚合模式，無功而返，徒耗資本。

#### 4.2.4 快驢B2B餐飲供應鏈失敗（2021-2024年）

美團旗下為餐飲商家供貨的B2B業務"快驢"於2021年提出"百城攻堅戰"，大舉擴張後因效率低下大幅收縮，最終從百餘城市退至一二線城市。

### 4.3 反壟斷罰款（2021年）

| 項目 | 詳情 |
|-----|------|
| 處罰決定日期 | 2021年10月8日 |
| 處罰機構 | 國家市場監督管理總局 |
| 違法行為 | 自2018年起對餐飲商家實施"二選一"獨家合作，濫用市場支配地位 |
| 罰款金額 | 34.42億元人民幣（相當於2020年中國境內銷售額的3%） |
| 附加要求 | 全額退還163萬家商戶保證金12.89億元 |
| 整改要求 | 連續三年向監管提交合規自查報告 |
| 合計直接經濟損失 | 約47.3億元人民幣 |

**背景**：此事件也暴露出美團在信息披露和合規層面的不透明問題——"二選一"策略在很長時間內並未被公開披露為經營風險，直至監管介入才曝光。

### 4.4 雙重股權結構（持續損害中小股東治理權）

美團採用A/B雙重股權結構（A類股：10票投票權；B類股：1票投票權）。王興持股約9.3%卻控制約46%投票權，中小公眾股東實際上幾乎無法對重大決策施加影響。

**治理缺陷案例**：
- 2021年的百億美元融資決策、社區團購鉅額投入均由管理層主導，股東無實質制衡
- 重大戰略失誤（摩拜、社區團購）沒有受到股東層面的有效問責機制

### 4.5 關鍵股東相繼減持退出

| 時間 | 股東 | 減持事件 | 影響 |
|-----|------|---------|------|
| 2022年5-11月 | 紅杉（沈南鵬） | 陸續減持，年內套現超百億港元 | 持股從IPO時約12%降至約1.86%（2023年底） |
| 2022年11月 | 騰訊（劉熾平） | 通過派息方式將9.58億股（佔總股本約15.5%）分發給騰訊股東，持股從17%降至1.5% | 美團失去最重要戰略盟友；劉熾平辭任非執行董事；短期引發拋售 |
| 2024年6月 | 紅杉（沈南鵬） | 正式辭任美團非執行董事 | 標誌早期VC投資人完全退出 |

**解讀**：騰訊的退出雖非直接"套現"，但以派息方式減持等同於將拋壓轉嫁給騰訊全體股東，對美團市場價格形成巨大壓力（2022年美團股價區間一度跌至約80港元）。

### 4.6 2025-2026年外賣大戰重燃——新一輪資本損毀風險

| 時間 | 事件 |
|-----|------|
| 2025年全年 | 阿里（淘寶閃購）、京東發動外賣補貼大戰 |
| 2025年三季度單季 | 美團經營虧損達198億元（外賣大戰衝擊） |
| 2025年全年 | 美團預計淨虧損約233-243億元（對比2024年淨利潤358億元，差額約600億元） |
| 2025年三方合計 | 美團+阿里+京東三方合計燒錢超1,730億元（據媒體估算） |
| 2026年2月 | 阿里內部會議稱"三年不懼虧損，直至絕對第一" |
| 2026年1月 | 美團宣佈以約50億元收購叮咚買菜，加速自營供應鏈 |

**評估**：這一輪外賣大戰仍在進行中，尚不清楚最終結局。對美團股東而言，2025年已造成重大賬面價值損失，且競爭烈度短期內難以消退。


### 整體結論

美團上市以來的股東回報歷史可分為三個階段：

**第一階段（2018-2020）**：擴張期，持續虧損但可以理解；摩拜收購是主要減分項。

**第二階段（2021-2022）**：戰略失誤最密集期。歷史高位鉅額增發、社區團購千億虧損、反壟斷罰款、騰訊退出，多重利空疊加，股價從460港元峰值跌至約80港元，市值蒸發逾90%。這是美團股東利益損害最嚴重的階段。

**第三階段（2023-2024）**：理性迴歸期。大幅削減虧損業務、核心盈利創歷史新高、首次啟動回購。這是美團歷史上對股東最友好的時期，股價從低谷反彈至約180港元（漲幅超3倍）。

**2025年至今（第四階段）**：外部衝擊期。新一輪外賣大戰導致盈利急劇惡化，全年預計大幅虧損，是否為戰略主動防禦還是被動失血，仍有爭議。
