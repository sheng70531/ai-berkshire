## 問題1：騎手社保強制化風險

**狀態：✅ 已研究**

### 會不會強制全額社保？

當前政策路徑是**漸進式**的，短期內不會一刀切：

| 事實信號 | 內容 |
|---------|------|
| 現行路徑 | 職業傷害保障試點（7省）→ 逐步擴面，按單計費每單幾角錢 |
| 人社部表態 | 多次強調"分類施策"，從未表態"一刀切"全額社保 |
| 2021年指導意見發佈至今 | 4年未升級為強制全額社保 |
| 2億靈活就業人員 | 政策需極為謹慎，保就業優先 |
| 京東外賣 | 僅全職騎手（15萬人）五險一金，與美團745萬量級不可比 |
| 美團自身舉措 | 2025年10月騎手養老保險補貼覆蓋全國（行業首個） |

### 如果強制，利潤影響多大？

| 情景 | 年成本增量 | 佔2023年經調整淨利潤(233億)比 |
|------|-----------|---------------------------|
| 僅職業傷害保障全國推廣 | 50-110億 | 21-47% |
| 全職騎手(250萬)社保 | ~567億 | **243%** |
| 全職騎手社保+公積金 | ~735億 | **315%** |
| 全部騎手按實際月份 | ~845億 | **363%** |

**關鍵結論**：若強制全額社保，成本增量將超過美團全部利潤。但當前政策路徑是"職業傷害保障"（成本約50-110億），而非全額社保。

數據來源：人社部政策文件、中金/高盛研報測算、美團年報

## 問題2：抖音對美團酒旅利潤的衝擊

**狀態：✅ 已研究**

### 核心數據

| 指標 | 美團到店 | 抖音本地生活 |
|------|---------|------------|
| 2024年GTV | ~10,000億 | ~5,600億 |
| 2025年GTV | — | ~8,500億(+59%) |
| 核銷率 | 80-90% | 50-60% |
| 實際核銷後規模 | 8,000-9,000億 | 4,250-5,100億 |
| 佣金率 | ~4.5% | 2.5-3% |

### 利潤維度的衝擊量化

1. **貨幣化率下降**：美團到店貨幣化率從2022Q4的9.3%降至2023Q4的約6%，下降3.3個百分點，按7,000億GTV約損失230億收入（部分歸因抖音競爭，部分歸因疫後補貼）
2. **利潤率下降**：到店OPM從2021年43.3%降至2024年約34.5%，下降約9個百分點，按566億收入約50億利潤損失
3. **但到店業務本身仍在盈利**：2025年核心本地商業虧損69億主要是外賣大戰導致，非到店拖累。華創證券測算2024年到店經營利潤約195億

### 抖音減速信號

- 2025Q4 GTV增速80% → 2026Q1降至不足25%
- 商家ROI下降，部分商家減少投放
- 抖音自身從補貼換增長轉向追求盈利

### 酒旅份額

| 平臺 | OTA份額(2024) |
|------|-------------|
| 攜程 | 56-57% |
| 美團 | 13-15% |
| 同程 | 13-15% |
| 飛豬 | ~8% |
| 抖音 | ~3% |

抖音酒旅份額僅3%，酒店供給量僅美團/攜程的10%，履約率僅30%（攜程90%）。

數據來源：華創證券研報、久謙中臺、界面新聞、環球旅訊

## 問題3：國家允許美團賺很多錢嗎？

**狀態：✅ 已研究**

### 政策演變三階段

| 階段 | 時間 | 關鍵信號 |
|------|------|---------|
| 強監管 | 2020底-2022 | 反壟斷罰款34.42億、要求降傭、騎手權益指導意見 |
| 政策轉暖 | 2022底-2024 | "支持平臺企業大顯身手"、"專項整改完成"、反壟斷驗收通過 |
| 常態化監管 | 2024-至今 | 樂見競爭、未乾預京東入局外賣、未限制利潤率 |

### 關鍵事實

| 維度 | 事實 |
|------|------|
| 佣金率管控 | 要求"透明化"和"引導降費"，**無硬性上限** |
| 行業定位 | **市場化服務**，未被定義為"民生基礎設施"（區別於水電氣） |
| 利潤率容忍度 | 2023年利潤大幅回升（經調整淨利233億），監管未發表負面評論 |
| 競爭態度 | 2025年京東入局外賣，監管未乾預，樂見市場競爭 |
| 與教培對比 | 教培"不得營利"，但外賣**從未被賦予類似定性** |
| 價格管控 | 當前無外賣終端價格管控政策，網約車有抽成上限但外賣沒有 |

### 結構性約束（不是限制賺錢，是增加成本）

監管不是直接限制美團利潤率，而是通過以下渠道增加成本：
- 騎手社保/職業傷害保障→成本增加
- 佣金透明化→降費壓力
- 反壟斷合規→限制部分競爭手段

數據來源：國務院政策文件、市場監管總局公告、人社部表態

## 問題4：KeeTa能夠成功嗎？

**狀態：✅ 已研究**

### 各市場競爭格局

#### 香港（已成功）
| 指標 | 數據 |
|------|------|
| 上線時間 | 2023年5月 |
| 盈利時間 | 2025年10月（上線29個月） |
| 當前份額 | 50%+（Deliveroo 2025年初退出後） |
| 主要對手 | Foodpanda（僅剩一個對手） |
| 盈利策略 | 騎手高薪→供給充足→配送快→用戶增長→商家跟進 |

#### 中東（進行中）
| 國家 | 進入時間 | 份額 | 格局 |
|------|---------|------|------|
| 沙特 | 2024年9月 | ~10%（第3位） | HungerStation(Delivery Hero)+Jahez主導 |
| 卡塔爾 | 2025年8月 | 早期 | Talabat(Delivery Hero)主導 |
| 科威特 | 2025年9月 | 早期 | Talabat主導 |
| 阿聯酋 | 2025年9月 | 早期 | Talabat主導(50-70%) |

**中東主要對手**：
- **Talabat**（Delivery Hero旗下）：UAE/Qatar/Kuwait份額50-70%，絕對主導
- **HungerStation**（Delivery Hero旗下）：沙特主導
- **Careem**（Uber旗下）：超級App，整合出行+外賣+支付
- Uber Eats已退出沙特（競爭失敗）

**中東市場數據**：
- 2025年11月中東日單量約70萬單
- 摩根士丹利預測：2028年GCC外賣市場達3000億美元，年增15%
- 沙特單位經濟效益：預計2026年底轉正

#### 巴西（剛起步）
| 對手 | 份額 |
|------|------|
| iFood | 80-86% |
| Rappi | ~9% |
| 99Food（滴滴，2025年重新進入） | 新進入 |
| KeeTa | 新進入（2025年底） |

- 巴西市場規模：1400億雷亞爾
- 滴滴同期投入R$10億重啟99Food，兩家中國公司直接競爭
- KeeTa計劃：2026年6月覆蓋15個主要都市區，5年覆蓋1000城

### 香港模型能否複製？

| 維度 | 香港 | 中東 | 巴西 |
|------|------|------|------|
| 競爭格局 | 兩強→KeeTa+Foodpanda | Delivery Hero深根多年 | iFood絕對壟斷 |
| 市場成熟度 | 高（APP滲透率高） | 中（高消費力但習慣差異） | 中（人口多但分散） |
| 勝率 | 已驗證 ✅ | 中（Delivery Hero更難打） | 低（iFood86%鐵板一塊） |
| 差異化 | 配送速度+補貼 | 同上，但Talabat已經很強 | 需要極大投入 |

**香港成功的特殊性**：香港市場小、密度高、Foodpanda服務差、用戶對補貼敏感——這些條件在中東/巴西未必同時成立。

### 海外業務盈利時間線

| 市場 | 預計轉正 |
|------|---------|
| 香港 | 已盈利（2025年10月） |
| 沙特 | 2026年底單位經濟效益轉正 |
| 其他中東國家 | 2027年以後 |
| 巴西 | 2028年以後（保守估計） |
| 整體海外 | 2027年以後 |

美團管理層表態：2026年海外業務整體虧損不超過2025年。

### 美團中國經驗的適用性

**優勢**（可遷移）：
1. **算法調度**：中國9000萬單/天的極限優化，配送效率領先全球
2. **騎手管理**：精細化運營，即時反饋系統，騎手收入管理
3. **商家運營**：SaaS工具+數據分析，中國已驗證

**劣勢**（難遷移）：
1. **語言/文化**：阿拉伯語、葡萄牙語運營團隊需從零建立
2. **監管**：各國勞工法、數據本地化、騎手法律地位差異大
3. **支付體系**：中國微信/支付寶生態不適用，需對接本地支付
4. **消費習慣**：中東齋月、巴西宗教節日等特殊因素

### 核心結論

**短期（3年）**：中東可能複製香港模式，在1-2個國家站穩腳跟，但Talabat不是Foodpanda，難度更高。

**長期（5-10年）**：巴西是真正的大機會（2.1億人口），但iFood護城河極深，需要極大資本+時間，勝負未定。

**對美團估值的影響**：即使KeeTa成功佔中東5%+巴西10%，當前階段是純成本中心。2026年海外虧損仍是拖累，但作為"遠期期權"估值意義大於當前利潤貢獻。

**類比**：KeeTa在海外的處境，像極了美團2013年在中國打百團大戰——方向對，但還需要3-5年才能看清誰贏。

數據來源：TechBuzz China、KR Asia、Rest of World、Morgan Stanley預測、美團財報電話會
