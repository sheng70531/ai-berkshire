# 智譜和 MiniMax，半年燒掉了幾乎一樣多的錢

8 月 26 日和 8 月 31 日，MiniMax 和智譜先後交出上市後第一份完整中報。兩家同一個月在港交所敲鐘，同一個報告期，同一條賽道。

把兩份報表換算到同一個貨幣口徑，會看到一組幾乎重疊的數字。

## 一、四個幾乎重疊的數字

| 1H2026 | 智譜 | MiniMax | 差異 |
|---|---|---|---|
| 研發開支 | 21.31 億元 = **3.17 億美元** | **2.97 億美元** | 智譜多 6.8% |
| 經調整淨虧損 | 19.64 億元 = **2.923 億美元** | **2.930 億美元** | **差 0.26%** |
| 員工薪酬（含股份支付） | 4.82 億元 = **0.717 億美元** | **0.689 億美元** | 智譜多 4.1% |
| 經營現金淨流出（推算） | 約 32 億元 = **約 4.8 億美元** | **約 4.3 億美元** | 同一量級 |

剔除股份支付和金融工具重估之後，兩家在同一個半年裡的真實虧損差 0.26%。不是挑出來的巧合，研發、薪酬、燒錢三項也全部落在 ±7% 以內。

2026 年上半年做一家前沿大模型公司的門檻因此很清楚： **每半年 3 億美元研發、3 億美元經調整虧損、4 至 5 億美元現金消耗** 。兩家路徑完全不同的公司，被同一條成本曲線約束到了同一個數量級。

差別在於這筆一樣的錢換回了什麼。

## 二、一樣的錢，智譜換回了更多

| 1H2026 | 智譜 | MiniMax | 智譜 / MiniMax |
|---|---|---|---|
| 收入 | **1.420 億美元** | **1.166 億美元** | 1.22 倍 |
| 毛利 | **0.374 億美元** | **0.208 億美元** | **1.80 倍** |
| 毛利率 | **26.4%** | **17.9%** | +8.5pp |
| 增量毛利率（對 2H2025） | **12.0%** | **6.5%** | 1.85 倍 |

增量毛利率是把最近半年新增的收入和新增的毛利相除，看新錢的賺錢效率。兩家都遠低於各自的報表毛利率，說明新增收入比存量更不賺錢。但智譜的新錢效率是 MiniMax 的 1.85 倍。

再看兩家貼身競爭的那條賽道，B 端開放平臺／API：

| B 端 API | 智譜 | MiniMax |
|---|---|---|
| 1H2026 收入 | **1.228 億美元** | **0.739 億美元** |
| 佔總收入 | **86.5%** | **63.4%** |
| 半年環比 | **+411.6%** | **+341.1%** |
| 2H2025 基數 | 約 0.23 億美元 | 0.168 億美元 |

起跑線接近，半年後智譜是 MiniMax 的 1.66 倍，增速還更快。

**總收入的環比斜率反而是 MiniMax 更陡（+139.8% 對 +78.8%）** ，原因是智譜主動砍掉了本地化部署業務，該分部環比下滑 65.4%。MiniMax 的非 API 業務（海螺 AI 等 C 端產品）環比只增長 33.9%，同比 +100.9% 靠的是低基數，高毛利的 C 端已經明顯失速。

兩家的結構變化是同一個方向、不同的起點：智譜從賣私有化部署轉向賣 API，MiniMax 從賣 C 端訂閱轉向賣 API。智譜轉得更徹底。

## 三、共同的病：毛利率在同一個半年裡同時塌陷

| 毛利率 | 2H2025 | 1H2026 | 變動 |
|---|---|---|---|
| 智譜 | 37.7% | 26.4% | **-11.3pp** |
| MiniMax | 33.7% | 17.9% | **-15.9pp** |

智譜這邊有一組細節值得單獨看。雲端毛利率從 2H2025 的 22.4% 只提升到 1H2026 的 24.6%， **在收入環比增長 4.1 倍的條件下，只多了 2.2 個百分點** 。同期公司披露 API 平均售價上調了約 101%。

**收入翻了四倍、價格翻了一倍，雲端毛利率只挪動 2.2 個百分點。** 反推成本：收入環比 +411.6%，成本環比 +397.2%。 **成本幾乎與收入等比例擴張，規模效應在環比維度上基本沒有出現。**

兩家公司、兩套技術路線、兩個客戶結構，得到同一個結果。這就不是公司問題了，是行業問題：

**Token 單價下行 + 推理算力成本剛性 + 調用結構向更長更復雜的任務遷移，三股力量把這門生意的毛利率壓在 20% 上下。**

做個參照：成熟的雲計算業務毛利率在 60% 以上，SaaS 在 70% 以上。 **今天的大模型 API 生意，毛利結構更接近算力轉售，而不是軟件。**

## 四、共同的動作：把現金變成預付算力

兩張資產負債表上金額異動最大的科目是同一個。

| | 智譜 | MiniMax |
|---|---|---|
| 期末餘額 | 預付計算服務費 **12.44 億元** （另有其他非流動資產 9.12 億元） | 預付款項等 **2.66 億美元** |
| 半年增幅 | **+969.5%** | 流動 **+913.7%** ／非流動 **+11,266%** |
| 相當於半年收入 | 約 2.3 倍 | **2.1 倍** |
| 明細披露 | **無** | **無** |

兩家在同一個半年裡，把相當於兩倍多半年收入的現金提前付給了算力供應商，而且都沒有披露任何構成明細。

**2026 年上半年，算力供給緊張到了模型公司必須先付錢才能鎖產能的程度。** 這筆錢是成本前置，今天不進損益表，未來以成本和折舊的形式壓在後續期間的毛利率上。

路徑選擇不同。智譜內生資本開支僅約 0.29 億元，公告明示"無任何未履行的資本承擔"，算力全部走服務採購，同時往國產芯片走，自述已實現 10 萬級國產芯片規模化推理。MiniMax 開始自建，物業廠房設備從 157 萬美元增至 7,491 萬美元，半年增長 46.7 倍，同時深度綁定阿里雲，採購年度上限從 1.15 億美元上調至 3.00 億美元。

有一個對 MiniMax 有利的細節要替它說清楚： **開放平臺 7,393 萬美元收入裡，來自關連方阿里巴巴的只有約 50 萬美元（0.7%）** ，其餘全是真實第三方需求。

## 五、跑道，最實質的一處差異

| 換算為美元 | 智譜 | MiniMax |
|---|---|---|
| 2026-06-30 類現金 | **6.70 億** | **13.23 億** |
| 七月融資 | 配售淨額 **40.0 億** | 配售 12.05 億 + 可轉債 8.21 億 = **20.26 億** |
| **備考流動性** | **約 46.7 億** | **約 33.5 億** |
| 年化經營燒錢（推算） | 約 9.5 億 | 約 8.6 億 |
| 已知剛性償付 | 銀行貸款 3.31 億（無擔保，可續） | **2027 年到期可轉債 8.29 億（零息）** |
| **扣除後跑道** | **約 4.6 年** | **約 2.9 年** |

智譜期末現金只有 MiniMax 的一半，七月那筆配售改變了全局： **19,780,000 股新 H 股，每股 1,588 港元，淨額 313.75 億港元** ，是它 6 月 30 日賬上現金的 6.8 倍、上半年收入的 28.5 倍，攤薄只有 4.4%。此外 A 股科創板擬募資不超過 150 億元仍在推進。

MiniMax 七月同樣融了兩筆，但 **可轉債 2027 年到期、期限不足 18 個月、轉換價 335 港元** 。若屆時不能轉股，就是 8.29 億美元的現金流出。已知金額、已知時點的硬約束，智譜沒有對應項。

補一句自我修正。七月之前包括我們自己在內的判斷是"智譜跑道不足 2 年，回 A 融資是生存必需"。 **七月這筆 272 億元人民幣的配售把這個判斷推翻了。** 對處在融資窗口開啟期的公司，用現金跑道做核心風險指標是脆弱的。

## 六、收入質量與組織效率，各佔一半

| | 智譜 | MiniMax | 誰更好 |
|---|---|---|---|
| 應收週轉天數 | 約 149 天 | **60.8 天** | MiniMax |
| 減值損失／收入 | 2.9% | **0.95%** | MiniMax |
| 合約負債／半年收入 | **31.7%** | 15.7% | 智譜 |
| 按時點確認收入佔比 | 89.6% | **70.7%** | MiniMax |
| 人均年化創收 | 28.9 萬美元 | **41.0 萬美元** | MiniMax |
| 人均年化薪酬 | 14.6 萬美元 | 24.3 萬美元 | 各有取捨 |

MiniMax 回款明顯更好。智譜揹著歷史本地化項目制應收的包袱，新增應收又主要來自雲端大客戶賬期：本報告期本地化收入只有 1.29 億元，應收賬款淨額卻增加 4.80 億元，增量必然來自 API 業務的大客戶信用。智譜這裡還有一處沒解釋的矛盾， **6 個月以上賬齡桶半年增長 248.6%，壞賬撥備率卻從 10.6% 降到 7.3%** 。

智譜的收入能見度更好，訂閱預收佔半年收入 31.7%，是 MiniMax 的兩倍厚。

組織上 MiniMax 是 568 人，智譜 981 人。但兩家有一個完全一致的結構： **研發開支的絕大部分不是人，是算力。** 智譜研發 21.31 億元對全公司薪酬 4.82 億元，非人力佔比約 84%；MiniMax 約 77%。用互聯網軟件公司的人效框架看這兩家，會得到錯誤結論。

## 七、估值：市值差 4.57 倍，收入差 1.22 倍

按 2026 年 8 月 31 日收盤市值，兩家均為港股，可直接比較：

| | 智譜 | MiniMax | 倍數 |
|---|---|---|---|
| 市值 | **5,564 億港元** | **1,219 億港元** | **4.57 倍** |
| 1H2026 收入 | 1.420 億美元 | 1.166 億美元 | 1.22 倍 |
| **市銷率（滾動 12 個月）** | **約 324 倍** | **約 94 倍** | **3.44 倍** |

上面六節呈現的事實是：智譜在收入規模、毛利率、增量毛利率、B 端賽道份額、資金跑道上佔優；MiniMax 在回款質量、人均效率、總收入環比斜率上佔優；兩家在燒錢強度、研發投入、毛利率塌陷方向、預付算力的黑箱、披露完整性上高度雷同。

這些差異能否支撐 3.44 倍的市銷率差距，本文不給答案。

## 八、結論與檢驗點

**這是兩家被同一條成本曲線約束、正在向同一條 B 端賽道收斂、同時遭遇毛利率塌陷的公司。** 上半年它們花掉了幾乎一樣多的錢，智譜換回了多 22% 的收入、多 80% 的毛利和多 66% 的 B 端 API 份額，MiniMax 換回了更好的回款質量和更高的人均效率。智譜的資金安全墊是當下最實質的質地差異，MiniMax 的 2027 年可轉債是最實質的時間約束。

但比兩家相對優劣更重要的，是兩份報表共同指向的那個事實：大模型 API 生意目前的毛利結構更接近算力轉售，不是軟件。在毛利率結構穩定下來之前，這門生意還不具備可估值的條件。

2026 年報（2027 年 3 月）要盯的四個數字：

1. **毛利率能否止跌** 。智譜看雲端能否突破 30%（現 24.6%），MiniMax 看能否在 17% 至 18% 站住。兩家繼續同向下滑，行業結論成立。
2. **預付算力科目的明細** 。智譜 12.44 億元加 9.12 億元，MiniMax 2.66 億美元，兩家都是黑箱，中期報告附註就能驗證。
3. **經營現金流出／經調整淨虧損的倍數** 。MiniMax 1H2026 為 1.47 倍，智譜推算約 1.63 倍。持續高於 1.4，說明預付算力的現金前置是常態。
4. **智譜的合約負債佔比與應收撥備率，MiniMax 的阿里雲實際採購額** 。前者驗證訂閱轉型和收入質量，後者決定 FY2026 虧損的量級。
