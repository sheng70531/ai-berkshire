# 兩家公司在同一個半年裡燒掉了幾乎一樣多的錢

## 智譜與 MiniMax 2026 年中報的質地對比

2026 年 8 月 26 日和 8 月 31 日，MiniMax 和智譜先後交出了上市後的第一份完整中報。兩家公司同一個月在港交所敲鐘（MiniMax 1 月 9 日，智譜 1 月 8 日），同一個報告期，同一個賽道，同一批投資人在看。

把這兩份報表換算到同一個貨幣口徑之後，會看到一組幾乎重疊的數字。

---

## 一、口徑統一：這兩份中報為什麼可以直接比

口徑不統一，後面所有的數字都是沙子。

**時間窗完全一致**：都是 2026 年 1 月 1 日至 6 月 30 日，都是未經審計、由核數師按《香港審閱準則第 2410 號》審閱（智譜畢馬威、MiniMax 安永），都出具無修改結論。

**匯率**：智譜以人民幣列示，MiniMax 以美元列示。本文換算全部採用兩家公司自己公告裡用過的匯率：**1 美元 = 6.72 元人民幣** （智譜中報正文自用，如"總收入約 9.54 億人民幣，約 1.42 億美元"）、 **1 美元 = 7.837 港元** （MiniMax 公告自用）。兩條匯率隱含的港元兌人民幣約為 0.775，與智譜七月配售公告裡的實際結算匯率 0.867 存在約 1% 的口徑差，源於取數時點不同。 **1% 的誤差不影響任何一個量級判斷，但它存在。**

**市值直接可比**：兩家都在港交所主板上市，市值均以港元計價，無需換算。

**一處共同的披露缺口** ：兩家的中期業績公告 **都沒有附現金流量表** （港股中期業績公告非強制披露）。本文所有涉及現金流的數字，均由資產負債表變動與損益表非現金項目推算得出，已逐處標註。這是兩家公司共同的問題，不是某一家的問題。

## 二、四個幾乎重疊的數字

| 指標（1H2026） | 智譜 | MiniMax | 差異 |
|---|---|---|---|
| 研發開支 | 21.31 億元 = **3.17 億美元** | **2.97 億美元** | 智譜多 6.8% |
| 經調整淨虧損 | 19.64 億元 = **2.923 億美元** | **2.930 億美元** | **差 0.26%** |
| 員工薪酬（含股份支付） | 4.82 億元 = **0.717 億美元** | **0.689 億美元** | 智譜多 4.1% |
| 經營現金淨流出（推算） | 約 32 億元 = **約 4.8 億美元** | **約 4.3 億美元** | 同一量級 |

經調整淨虧損 2.923 億美元對 2.930 億美元，兩家公司在同一個半年裡，剔除股份支付和金融工具重估之後的真實虧損，差距是 0.26%。不是挑出來的巧合。研發、薪酬、燒錢三項也全部落在 ±7% 以內。

2026 年上半年做一家前沿大模型公司的門檻因此很清楚： **每半年 3 億美元的研發投入、3 億美元的經調整虧損、4 至 5 億美元的現金消耗** 。兩家路徑完全不同的公司，被同一條成本曲線約束到了同一個數量級。

差別在於這筆一樣的錢換回了什麼。

## 三、分野一：同樣的投入，智譜換回了更多收入和毛利

| 指標（1H2026） | 智譜 | MiniMax | 智譜 / MiniMax |
|---|---|---|---|
| 收入 | 9.54 億元 = **1.420 億美元** | **1.166 億美元** | **1.22 倍** |
| 毛利 | 2.52 億元 = **0.374 億美元** | **0.208 億美元** | **1.80 倍** |
| 毛利率 | **26.4%** | **17.9%** | +8.5pp |
| 增量毛利率（對 2H2025） | **12.0%** | **6.5%** | 1.85 倍 |

增量毛利率的算法是把最近半年新增的收入和新增的毛利相除，看新錢的賺錢效率。

- 智譜：增量收入 4.204 億元，增量毛利 0.504 億元 → **12.0%**
- MiniMax：增量收入 6,796 萬美元，增量毛利 442 萬美元 → **6.5%**

兩家都遠低於各自的報表毛利率，說明 **兩家新增的收入都比存量收入更不賺錢** 。但智譜的新錢效率是 MiniMax 的 1.85 倍。

再單獨看兩家貼身競爭的那條賽道，**B 端開放平臺/API**：

| B 端 API 業務 | 智譜（開放平臺及 API） | MiniMax（開放平臺及其他企業服務） |
|---|---|---|
| 1H2026 收入 | 8.25 億元 = **1.228 億美元** | **0.739 億美元** |
| 佔總收入 | **86.5%** | **63.4%** |
| 半年環比增速 | **+411.6%** | **+341.1%** |
| 2H2025 基數 | 1.61 億元 ≈ 0.23 億美元 | 0.168 億美元 |

**起跑線接近（2H2025 分別約 2,300 萬和 1,680 萬美元），半年後智譜跑到 1.23 億美元，MiniMax 跑到 0.74 億美元，智譜是 MiniMax 的 1.66 倍，且增速更快。** 在兩家正面相撞的這條賽道上，智譜上半年贏了。

## 四、分野二：總收入的增長斜率，MiniMax 更陡，但要拆開看

| 增速口徑 | 智譜 | MiniMax |
|---|---|---|
| 總收入同比 | **+399.7%** | +283.1% |
| 總收入 **半年環比** | +78.8% | **+139.8%** |

同比智譜快，環比 MiniMax 快。 **同比是失真的**。智譜 1H2025 的雲端收入只有 2,910 萬元，任何數除以這個基數都會得到誇張的倍數。環比才是最近半年的真實斜率。

但環比也要拆開：

| 業務拆分（半年環比） | 智譜 | MiniMax |
|---|---|---|
| B 端 API | **+411.6%** | +341.1% |
| 非 API 業務 | 本地化部署 **-65.4%** | AI 原生產品（C 端） **+33.9%** |

智譜總收入環比慢，是因為它 **主動砍掉了本地化部署業務** ：企業級通用大模型收入同比腰斬 54.6%，本地化部署環比下滑 65.4%。公司的解釋是"更強調質量和行業選擇"。

MiniMax 的非 API 業務（海螺 AI 等 C 端產品）環比只增長 33.9%，同比 +100.9% 靠的是低基數。**高毛利的 C 端業務已經明顯失速。**

**所以兩家的結構變化是同一個方向、不同的起點** ：智譜從"賣私有化部署"轉向"賣 API 調用"，MiniMax 從"賣 C 端訂閱"轉向"賣 API 調用"。兩家都在把身家押到同一條 B 端賽道上。智譜轉得更徹底（86.5% 對 63.4%）。

這裡有個說不通的地方。**智譜本地化業務的毛利率在下滑** （環比 44.4% → 37.9%，其中企業級通用大模型從 58.5% 掉到 42.3%）。如果真是"主動選擇高質量客戶"，毛利率應該上升而不是下降。看上去是需求側確實在往雲端遷移，公司在被動追認。

## 五、共同的病：毛利率在同一個半年裡同時塌陷

| 毛利率 | 2H2025 | 1H2026 | 變動 |
|---|---|---|---|
| 智譜 | 37.7% | 26.4% | **-11.3pp** |
| MiniMax | 33.7% | 17.9% | **-15.9pp** |

**兩家公司在同一個半年裡，毛利率同時出現兩位數百分點的塌陷。**

智譜這邊還有一組細節。雲端毛利率從 2H2025 的 22.4% 只提升到 1H2026 的 24.6%， **在收入環比增長 4.1 倍的條件下，只多了 2.2 個百分點** 。同期公司披露 API 平均售價上調了約 101%。

**收入翻了四倍、價格翻了一倍，雲端毛利率只挪動了 2.2 個百分點。** 反推雲端成本：收入環比 +411.6%，成本環比 +397.2%。**成本幾乎與收入等比例擴張，規模效應在環比維度上基本沒有出現。**

兩家公司、兩套技術路線、兩個客戶結構，得到同一個結果。這就不是公司問題了，這是行業問題：

**Token 單價下行 + 推理算力成本剛性 + 調用結構向更長更復雜的任務遷移，三股力量夾在中間，把這門生意的毛利率壓在 20% 上下。**

做個參照：成熟的雲計算業務毛利率在 60% 以上，SaaS 在 70% 以上。 **今天的大模型 API 生意，毛利結構更接近算力轉售，而不是軟件。**

## 六、共同的動作：把現金變成"預付算力"

兩張資產負債表上金額異動最大的科目是同一個。

| 預付算力類科目 | 智譜 | MiniMax |
|---|---|---|
| 科目名稱 | 預付計算服務費及其他 | 預付款項、其他應收款及其他資產 |
| 期末餘額 | **12.44 億元** （另有"其他非流動資產"9.12 億元） | **2.66 億美元** （流動 1.65 億 + 非流動 1.01 億） |
| 半年增幅 | **+969.5%** | 流動 **+913.7%** ／非流動 **+11,266%** |
| 相當於半年收入的 | 約 2.3 倍（含其他非流動資產口徑） | **2.1 倍** |
| 明細披露 | **無** | **無** |

兩家公司在同一個半年裡，把相當於兩倍多半年收入的現金，提前付給了算力供應商，而且 **兩家都沒有披露任何構成明細** 。

**2026 年上半年，算力供給緊張到了模型公司必須先付錢才能鎖產能的程度。** 這筆錢的性質是成本前置：今天不進損益表，未來以成本和折舊的形式壓在後續期間的毛利率上。

兩家在算力上的路徑選擇不同：

| | 智譜 | MiniMax |
|---|---|---|
| 自建算力 | 物業廠房設備 8.55 億元，但半年增量 1.99 億元中 **3.61 億元來自兩筆收購** ，內生資本開支僅約 **0.29 億元** | 物業廠房設備從 157 萬美元增至 **7,491 萬美元，半年增長 46.7 倍** |
| 資本承擔 | 公告明示 **"無任何未履行的資本承擔"** | 未單獨披露 |
| 算力供應結構 | 走國產芯片路線，自述已實現 10 萬級國產芯片規模化推理，單 token 推理成本較年初降 80% | 高度綁定阿里雲 |
| 關連方算力 | 聯營公司北京數道智算（持股 7.31%，提供算力服務） | 阿里巴巴持股 **11.36%** ，同時是最大單一供應商 |

**智譜是"全租、零資本承諾、往國產芯片走"。** 好處是靈活、可隨時縮量；壞處是量價未鎖定，第三方算力中斷或漲價的敞口完全開放（公司自己在風險提示裡單列了這一條）。

**MiniMax 是"開始自建 + 深度綁定阿里"** 。8 月 26 日與中報同日發佈的關連交易公告披露：阿里雲採購年度上限從 1.15 億美元上調至 **3.00 億美元** （2027 年 4.00 億、2028 年 5.00 億）；1H2026 已採購 7,560 萬美元，而同期向阿里巴巴銷售 API 只有約 50 萬美元，**淨支出關係 151 比 1**。

有一個對 MiniMax 有利的細節要替它說清楚： **開放平臺 7,393 萬美元收入裡，來自關連方阿里巴巴的只有約 50 萬美元（0.7%）** 。它的 B 端增長是真實第三方需求，不是關聯方輸血。這一條把收入質量的可信度提上去了不少。

## 七、分野三：跑道，這是最實質的質地差異

| 流動性（換算為美元） | 智譜 | MiniMax |
|---|---|---|
| 2026-06-30 類現金 | 44.99 億元 = **6.70 億美元** | **13.23 億美元** |
| 期後融資（7 月） | 配售淨額 313.75 億港元 = **40.0 億美元** | 配售 12.05 億 + 可轉債 8.21 億 = **20.26 億美元** |
| **備考流動性** | **約 46.7 億美元** | **約 33.5 億美元** |
| 年化經營燒錢（推算） | 約 9.5 億美元 | 約 8.6 億美元 |
| 已知剛性償付 | 銀行貸款 22.25 億元 = 3.31 億美元（無擔保，可續） | **2027 年到期可轉債 8.29 億美元（零息，硬約束）** |
| **扣除後跑道** | **約 4.6 年** | **約 2.9 年** |
| 還在路上的錢 | A 股科創板擬募 **不超過 150 億元（約 22.3 億美元）** | 股東特別大會再次刷新一般授權 |

智譜期末現金只有 MiniMax 的一半，但七月那一筆配售改變了全局： **19,780,000 股新 H 股，每股 1,588.00 港元，淨額 313.75 億港元** 。這筆錢是它 6 月 30 日賬上現金的 6.8 倍、上半年收入的 28.5 倍，攤薄只有 4.4%。

MiniMax 七月同樣融了兩筆（配售 3,560 萬股 A 類股 @268 港元 + 65 億港元零息可轉債），但 **可轉債 2027 年到期、期限不足 18 個月、轉換價 335 港元** 。若屆時不能轉股，就是 8.29 億美元的現金流出。已知金額、已知時點的硬約束，智譜沒有對應項。

**兩家都不存在短期生存問題，但智譜的資金安全墊明顯更厚。**七月之前的市場共識（包括我們自己在 7 月 6 日那份對比裡的判斷）是"智譜跑道不足 2 年，回 A 融資是生存必需"。 **七月這筆 272 億元人民幣的配售，把這個判斷徹底推翻了。**

同時也要指出： **兩家下半年都確定提速** 。MiniMax 自述七月兩筆募資淨額的約 80%（約 16.2 億美元）將在 2027 年底前投入 AI 基礎設施與研發，"月均額外支出約 9,260 萬美元"；智譜的算力表內敞口（預付 21.6 億元 + 應付 14.27 億元 = 35.8 億元）仍在膨脹。上表的跑道年數按上半年速度線性外推，實際都會更短。

## 八、分野四：收入質量，各有各的短板

| 收入質量指標 | 智譜 | MiniMax | 誰更好 |
|---|---|---|---|
| 應收週轉天數 | **約 149 天** | **60.8 天** | MiniMax |
| 應收賬款 / 半年收入 | 82.1% | 33.6% | MiniMax |
| 金融資產減值損失 / 收入 | **2.9%** | 0.95% | MiniMax |
| 壞賬撥備率變動 | 10.6% → **7.3%（下降）** | 減值同比放大 17 倍 | 都在惡化方向 |
| 合約負債 / 半年收入 | **31.7%** | 15.7% | 智譜 |
| 按時點確認收入佔比 | **89.6%** | 70.7% | MiniMax |

這一欄沒有贏家，兩家各有一半。

**MiniMax 的回款質量明顯更好** ：應收週轉 61 天對智譜的 149 天。智譜揹著歷史本地化項目制應收的包袱，同時新增的應收又主要來自雲端大客戶賬期。本報告期智譜本地化收入只有 1.29 億元，應收賬款淨額卻增加了 4.80 億元， **增量必然來自 API 業務的大客戶信用** 。這說明它 8.25 億元 API 收入裡，有相當比例不是開發者預付，而是給大企業的賬期。

智譜這裡還有一處需要在年報追問的矛盾： **6 個月至 1 年的賬齡桶半年增長 248.6%、1 至 2 年增長 179.7%，而壞賬撥備率反而從 10.6% 降到 7.3%** 。長賬齡在放大而撥備在下降，兩個方向相反。

**智譜的收入能見度更好** ：合約負債（訂閱預收）佔半年收入 31.7%，是 MiniMax 的兩倍厚。這是 Coding Plan 訂閱制在報表上的硬證據。MiniMax 的合約負債只有 1,829 萬美元、佔半年收入 15.7%，幾乎沒有遞延收入蓄水池。

**但智譜按時點確認的收入佔比更高（89.6% 對 70.7%）** ，意味著它的收入更依賴按量計費的瞬時消耗，受客戶模型選型、價格戰、單個大客戶調用波動的影響更直接。

## 九、分野五：組織形態，人少錢多 vs 人多錢少

| 組織指標（1H2026 年化） | 智譜 | MiniMax |
|---|---|---|
| 員工數 | **981 人** | **568 人** |
| 半年員工增幅 | +11.1%（對 1H2025 的 883 人） | **+32.7%** （對 2025 年末 428 人） |
| 人均年化薪酬（含股份支付） | **約 14.6 萬美元** | **約 24.3 萬美元** |
| 人均年化創收 | 約 28.9 萬美元 | **約 41.0 萬美元** |
| 薪酬 / 收入 | 50.5% | 59.1% |
| 研發開支 / 收入 | 223.4% | **254.7%** |

**MiniMax 人少、人貴、人均創收高；智譜人多、人便宜、人均創收低。** MiniMax 的人均年化薪酬是智譜的 1.66 倍，人均創收是智譜的 1.42 倍。

但兩家有一個完全一致的結構： **研發開支的絕大部分不是人，是算力。**

- 智譜：研發開支 21.31 億元，全公司總薪酬（含股份支付）只有 4.82 億元。即便假設研發人員拿走全公司七成薪酬（約 3.4 億元），研發開支裡仍有約 **17.9 億元（84%）是訓練算力**
- MiniMax：研發開支 2.97 億美元，全公司薪酬 0.689 億美元，非人力佔比約 **77%**

**這兩家都不是人力密集型公司，是算力密集型公司。** 用互聯網軟件公司的"人效"框架去看它們，會得到錯誤的結論。

## 十、估值：市值差 4.6 倍，收入差 1.2 倍

## 十二、一句話定性

**這是兩家被同一條成本曲線約束、正在向同一條 B 端賽道收斂、同時遭遇毛利率塌陷的公司。** 上半年它們花掉了幾乎一樣多的錢（經調整淨虧損差 0.26%），智譜用這筆錢換回了多 22% 的收入、多 80% 的毛利和多 66% 的 B 端 API 份額，MiniMax 換回了更好的回款質量和更高的人均效率。 **智譜的資金安全墊（4.6 年對 2.9 年）是當下最實質的質地差異，MiniMax 的 2027 年可轉債是最實質的時間約束。** 但比兩家相對優劣更重要的，是兩份報表共同指向的那個事實：大模型 API 生意的毛利結構更接近算力轉售，不是軟件。

## 十三、下一份財報（2026 年報，2027 年 3 月）該盯什麼

**共同的三個** ：

1. **毛利率能否止跌** 。智譜看雲端能否突破 30%（現 24.6%，兩個半年只走了 2.2pp）；MiniMax 看能否在 17%-18% 止跌（現 17.9%）。若兩家繼續同向下滑，行業結論成立；若一家止跌一家繼續跌，才是公司層面的差異。
2. **預付算力科目的明細** 。智譜 12.44 億元 + 9.12 億元"其他非流動資產"，MiniMax 2.66 億美元，兩家都是黑箱。中期報告（不是業績公告）的附註裡會披露，這是最先能驗證的一項。
3. **經營現金流出與經調整淨虧損的倍數** 。MiniMax 1H2026 為 1.47 倍，智譜推算約 1.63 倍。倍數持續高於 1.4，說明預付算力的現金前置是常態而非一次性，實際燒錢要按經調整虧損乘以 1.5 左右來估。

**智譜單獨的兩個** ：

4. **合約負債 / 收入能否守住 30%** （現 31.7%）。上升則訂閱制轉型成立，回落至 20% 以下則說明增長仍靠一次性調用堆量。
5. **應收撥備率與 1 年以上賬齡** 。撥備率繼續降而長賬齡繼續漲，需要直接質疑收入質量。

**MiniMax 單獨的兩個** ：

6. **阿里雲 2026 全年實際採購額對 3.00 億美元上限** 。若逼近上限（即下半年達 2.24 億、為上半年 3 倍），FY2026 經調整淨虧損可能超過 8 億美元。
7. **2027 年可轉債的處置路徑** ，以及 7,491 萬美元設備轉固後的折舊臺階（1H2026 折舊僅 233 萬美元，明顯未滿期計提）。

## 十四、如果只能選一個

### 結論

**兩家都不該買。若必須在兩者之間選一個，選 MiniMax。理由是價格，不是生意。**

生意質量上智譜更好，前面十三節的數據在這一點上是一致的。但投資決策不是評選優秀企業，是拿價格換未來的現金流。 **智譜今天的市銷率是 MiniMax 的 3.44 倍，而它的生意好不到 3.44 倍。**

### 一、為什麼說兩家都不該買

買入門檻繞不開三件事：生意的經濟特徵看得懂、護城河可驗證、價格留出安全邊際。這兩家在第一條就卡住了。

**看不懂的不是技術，是毛利率。** 一門生意最基本的經濟特徵是它賺多少毛利。這兩家的毛利率在最近半年分別移動了 -11.3 和 -15.9 個百分點，增量毛利率一個 12.0% 一個 6.5%，都只有報表毛利率的一半。 **一門每半年毛利率結構變動超過 10 個百分點、且新增收入賺錢效率只有存量一半的生意，是無法估值的**。不是估值高低的問題，是分母還沒穩定下來。

**自由現金流都是深度負數，且在加速。** 智譜推算年化經營現金流出約 9.5 億美元（FY2025 的 3.1 倍），MiniMax 約 8.6 億美元（同樣是 3.1 倍）。兩家的內生資本開支都極低，但這個數字是誤導：算力全部租用，資本開支偽裝成了經營開支。

**盈虧平衡的路徑不在視野內。** 智譜毛利率 26.4%、研發佔收入 223.4%；MiniMax 毛利率 17.9%、研發佔收入 254.7%。要走到打平，收入需要在毛利率不下滑的前提下再漲一個數量級。過去半年的數據說的正好相反：收入漲得越快，毛利率掉得越快。

**這不是"貴不貴"的問題，是"能不能算"的問題。** 兩家現在都該在觀察名單上，不在買入名單上。

### 二、同一套假設下的三年推演

既然要選，就用完全一致的增長假設和退出倍數，把價格的差異單獨隔離出來。

假設（對兩家完全相同，且已經相當樂觀）：2H2026 環比 +60%，2027 全年 +120%，2028 +80%，2029 +50%。這條曲線意味著三年後收入約為今天的 6 倍。

| | 智譜 | MiniMax |
|---|---|---|
| FY2026 收入（推演） | 約 24.8 億元 | 約 3.03 億美元 |
| FY2029 收入（推演） | 約 147 億元 | 約 18.0 億美元 |
| 今日市值 | 5,564 億港元 | 1,219 億港元 |
| 2029 年給 10 倍市銷率 | 1,699 億港元 → **-69%** | 1,411 億港元 → **+16%** |
| 2029 年給 20 倍市銷率 | 3,399 億港元 → **-39%** | 2,822 億港元 → **+132%** |
| 2029 年給 30 倍市銷率 | 5,098 億港元 → **-8%** | 4,233 億港元 → **+247%** |

**在完全相同的經營假設下，三年後無論給什麼退出倍數，MiniMax 的回報都高出一個量級。因為你為同樣的東西少付了 3.44 倍的錢。**

注意最後一行：智譜需要在 2029 年、收入做到 147 億元時 **仍然維持 30 倍市銷率** ，才勉強做到不虧錢。這等於要求市場三年後對一家收入體量已經不小的公司，繼續給出今天的成長股定價。

反過來算：**智譜要在三年裡跑贏 MiniMax，收入增速需要比它快 3.45 倍。** 目前的數據是反的，總收入半年環比智譜 78.8%、MiniMax 139.8%。即便只比兩家正面相撞的 B 端 API 業務（智譜 411.6% 對 341.1%），這 1.21 倍的增速優勢，離 3.45 倍的價格差距還差得遠。

### 三、選 MiniMax 的四條理由

**第一，價格差距遠大於生意質量差距。** 智譜在毛利率上領先 8.5 個百分點、增量毛利率領先 1.85 倍、B 端 API 規模領先 1.66 倍。這些差距都是真實的，但加總起來不到 2 倍。價格差 3.44 倍。

**第二，最近半年的增長斜率在 MiniMax 一側。** 智譜 399.7% 的同比來自 2,910 萬元的低基數，環比才是真實斜率：78.8% 對 139.8%。

**第三，收入質量在幾個具體項上 MiniMax 更硬。** 應收週轉 61 天對 149 天；減值損失佔收入 0.95% 對 2.9%；開放平臺收入裡來自關連方阿里巴巴的只有 0.7%，其餘全是真實第三方需求。而智譜有一處矛盾至今沒有解釋： **長賬齡桶半年增長 248.6%，壞賬撥備率卻從 10.6% 降到 7.3%** 。

**第四，人均效率是組織能力的代理變量。** MiniMax 568 人做出 1.166 億美元收入，智譜 981 人做出 1.420 億美元；人均年化創收 41.0 萬對 28.9 萬美元。在技術迭代速度決定生死的行業裡，小而貴的團隊通常比大而便宜的團隊跑得快。

### 四、我拒絕的那條多頭邏輯，以及為什麼

智譜最強的一條：**它是這兩家裡唯一有可能形成結構性護城河的。**

國產基座模型 + 10 萬級國產芯片規模化推理跑通 + 政企私有化交付的行業積累 + A 股科創板通道，這四件事疊加，意味著在技術脫鉤的路徑下，智譜在"國產可控 AI 基礎設施"這個生態位上幾乎無人可替。MiniMax 沒有對應的東西。它在全球市場用 1/50 的資本對抗 OpenAI 和 Google，在國內對抗字節、阿里和 DeepSeek，找不到一條結構性的防守線。另外兩條：資金安全墊 4.6 年對 2.9 年；A 股歷史上給 AI 龍頭的估值體系確實顯著高於港股，回 A 可能延長高倍數的持續時間。

**為什麼這些不足以讓我選智譜：**

護城河的價值最終要體現為超額的資本回報率。 **今天沒有任何證據表明這條護城河能帶來更高的毛利率。** 智譜雲端毛利率 24.6%，是在 API 提價 101% 之後，只比半年前多了 2.2 個百分點。 **一條不能轉化為定價權的護城河，在報表上和沒有護城河是一樣的。** 它可能會兌現，但那是未來的事，而 324 倍市銷率已經按既成事實付了錢。

資金跑道的優勢有一個循環論證問題： **智譜七月能以每股 1,588 港元融到 272 億元，本身就是極高估值的產物。** 它的跑道是估值的函數，不是獨立於估值的安全墊。倍數一旦正常化，這個優勢會同步收縮。

A 股估值體系的論證是流動性和情緒論證，不是生意論證。用它支撐一個 324 倍市銷率的買入決策，等於把判斷權交給下一個買家。

### 五、可證偽的改判條件

判斷要能被推翻才有價值。以下條件出現，我會改變上面的排序。

**會讓我改選智譜的：**

1. 雲端毛利率連續兩個半年上行且突破 35%（現 24.6%），說明規模效應真實存在、護城河開始轉化為定價權
2. 智譜市值回落到 MiniMax 的 2 倍以內（約 2,438 億港元），價格差距縮小到與生意質量差距匹配
3. 經營現金流出／經調整淨虧損降到 1.2 倍以下（現推算約 1.63 倍），說明預付算力不是無底洞
4. MiniMax 的知識產權訴訟出現實質性不利進展，或阿里雲採購上限被實際用滿導致虧損失控

**會讓我放棄 MiniMax 的：**

1. 毛利率跌破 15%（現 17.9%），單位推理經濟持續惡化，"規模換效率"證偽
2. 2.66 億美元預付款項在中期報告披露後，被證明含大額關聯方往來或性質不明項目
3. 2027 年可轉債無法轉股也無法再融資（現價 349 港元高於轉換價 335 港元，暫時不構成壓力，但這依賴股價）
4. AI 原生產品全年收入低於 9,000 萬美元，高毛利 C 端業務進入停滯

**會讓我兩家都長期迴避的：** 2026 年報裡兩家毛利率繼續同向下滑。那意味著這門生意的終局形態就是低毛利算力轉售，此時任何一家的市銷率都不該超過 10 倍。

### 六、更誠實的一句話

**選 MiniMax，是"兩個都不想要時選便宜的那個"，不是"找到了好生意"。**

真正符合買入標準的做法是兩家都不碰，放進觀察名單，等兩件事同時發生：毛利率結構穩定下來（連續兩個半年不再出現兩位數百分點的變動），以及價格回到能用現金流折現算得出來的區間。在此之前，這兩隻股票的定價靠的是敘事和資金，不是報表。

報表能說的，前十三節已經說完了： **兩家公司在同一個半年裡花掉了幾乎一樣多的錢，一家換回了更多的收入和毛利，另一家換回了更好的回款和更高的人效。它們共同證明的是，這門生意目前的毛利結構更接近算力轉售，而不是軟件。**
