# 老鋪黃金（6181.HK）投資研究

## 公司概況

老鋪黃金是中國高端古法黃金珠寶品牌，2024年6月在港交所上市。公司由徐高明、徐東波父子創立，專注於"古法黃金"工藝製品，定位高端消費市場，僅進駐SKP、萬象城等頂級商業中心。

## 研究背景

老鋪黃金是近兩年港股最具爭議的消費股之一。看多者認為這是"中國版愛馬仕"的崛起——45家店創造273億營收、單店年銷近10億、ROE超60%、2026Q1單季淨利已達2025全年七成。看空者則質疑——增長是否只是金價暴漲週期的副產品？"零對沖"策略下160億存貨是否是定時炸彈？古法黃金的壁壘是否經得住時間檢驗？

本研究試圖回答一個核心問題：**老鋪黃金的超級增長，有多少歸因於品牌力，有多少歸因於金價週期？**
