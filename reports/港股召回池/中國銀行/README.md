# 中國銀行（3988.HK）投資研究

## 基本信息
- **公司名稱**：中國銀行股份有限公司
- **股票代碼**：3988.HK
- **行業**：國有大行
- **PE（TTM）**：~6倍
- **ROE**：~9%

## 2025年度核心財務數據
| 指標 | 數值 | 同比變化 |
|------|------|----------|
| 營業收入 | 6,583億元 | +4.48% |
| 歸母淨利潤 | 2,430億元 | +2.18% |
| 淨息差 | 1.26% | -14BP |
| 非利息收入佔比 | 33.06% | 提升 |
| 全年股息 | 每10股2.263元 | - |

## 投資亮點
1. PE僅6倍——極度低估的大型銀行
2. ROE 9%——在低PE公司中屬於優秀
3. 國際化程度最高的中資銀行
4. 穩定的股息回報

## 核心風險
1. 淨息差持續收窄（-14BP），核心盈利能力下降
2. 地產相關不良貸款風險
3. 國有大行受政策任務影響（讓利實體經濟）
4. 利潤增速偏慢（+2.18%）
