## 研究框架

本研究採用四維度分析框架：

1. **商業模式分析** — 生意本質、護城河、定價權
2. **財務估值分析** — 盈利質量、資本配置、安全邊際
3. **行業競爭分析** — 產業格局、競爭壁壘、變化趨勢
4. **風險與管理層評估** — 核心風險、治理結構、資本配置能力

## 研究背景

信義玻璃是中國最大的綜合玻璃製造商之一，浮法玻璃日熔量近30000噸，位居全球前列。當前處於浮法玻璃行業下行週期尾部（始於2023Q4），汽車玻璃業務逆勢增長，已成為利潤核心支柱。公司正通過馬來西亞、印尼、沙特等海外產能佈局實現國際化突破。
