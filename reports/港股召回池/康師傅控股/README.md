## 公司簡介

康師傅控股有限公司由臺灣魏應州家族於1992年在天津創立，是中國最大的方便麵和飲料企業之一。核心品牌"康師傅"在中國家喻戶曉。2018年創始人魏應州退休，長子魏宏名接任董事會主席；2026年1月三子魏宏丞接任CEO。

## 核心業務結構（2025年）

1. **飲品業務**：營收約501億元（佔比63%），包括茶飲料、果汁、包裝水
2. **方便麵業務**：營收約284億元（佔比36%），包括容器面、袋面
3. **其他**：約1%
