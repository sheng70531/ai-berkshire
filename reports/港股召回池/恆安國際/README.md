## 公司簡介

恆安國際集團由施文博和許連捷於1985年在福建晉江創立，是中國領先的衛生用品和生活用紙製造商。主要品牌包括"七度空間"（衛生巾）、"心相印"（生活用紙）、"安兒樂/Q·MO"（紙尿褲）。1998年在港交所上市。

## 核心業務結構

1. **生活用紙**（心相印等）：營收佔比約58%，毛利率約22%
2. **衛生巾**（七度空間等）：營收佔比約30%，毛利率約60%+
3. **紙尿褲**（安兒樂/Q·MO）：營收佔比約10%，毛利率中等
