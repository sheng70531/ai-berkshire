## 研究背景

信義光能是全球最大的光伏玻璃製造商，與福萊特共同構成行業"雙寡頭"格局，兩家合計市佔率超過50%。公司當前處於行業週期底部，2024-2025年因光伏玻璃價格下跌和資產減值導致利潤大幅承壓，但成本優勢突出，海外佈局加速，行業供給側收緊跡象初現。

## 研究框架

本研究採用四位投資大師的分析視角，從不同維度對信義光能進行全面評估：

| 文件 | 分析維度 | 核心關注 |
|------|----------|----------|
| 01-商業模式分析-段永平視角.md | 商業模式質量 | 護城河、用戶價值、長期競爭力 |
| 02-財務估值分析-巴菲特視角.md | 財務健康與估值 | 盈利能力、資產負債表、內在價值 |
| 03-行業競爭分析-芒格視角.md | 行業格局與競爭 | 產業鏈定位、競爭優勢、行業趨勢 |
| 04-風險管理層評估-李錄視角.md | 風險與管理層 | 關鍵風險、管理層品質、安全邊際 |
| 最終報告.md | 綜合評估 | 投資結論、倉位建議、跟蹤要點 |

## 關鍵數據速覽（FY2025）

- 營收：208.6億元人民幣（同比-4.8%）
- 歸母淨利潤：8.45億元（同比-16.2%）
- 剔除減值後淨利潤：約22-23億元（同比+57%）
- 光伏玻璃毛利率：14.1%（2024年為9.7%，顯著改善）
- 海外銷售佔比：33.5%（同比大幅提升）
- 淨負債率（剔除信義能源）：2.8%
- 在產產能：約23,200噸/日
- 單窯平均規模：1,009噸/日（行業領先）
