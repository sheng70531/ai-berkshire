# 信義光能（0968.HK）行業競爭分析

> 分析維度：行業格局、產業鏈定位、競爭動態、長期趨勢
> 研究日期：2026年5月16日

---

## 一、行業全景：光伏玻璃處於什麼位置？

### 1.1 產業鏈定位

光伏產業鏈的簡化結構：

```
硅料 → 硅片 → 電池片 → 組件 → 電站
                           ↑
                      光伏玻璃（封裝輔材）
```

光伏玻璃是組件封裝的核心材料，起到保護電池片、透光發電的作用。每塊組件正面必須使用一片光伏玻璃，雙面組件還需要背面再加一片。光伏玻璃佔組件總成本約6-8%。

### 1.2 需求驅動力

光伏玻璃的需求量直接取決於光伏組件的出貨量。全球光伏新增裝機量的長期增長趨勢是確定性的——不受短期經濟波動影響的少數行業之一。

2025年全球光伏新增裝機約550-600GW，預計2030年達到800-1000GW。假設年均增長10-15%，光伏玻璃的需求量將持續增長。

**關鍵變量：雙玻組件滲透率。** 雙面發電組件每塊需要兩片光伏玻璃（正面+背面），滲透率從2020年的約30%提升至2025年的約50%+。這意味著光伏玻璃需求增速快於裝機量增速。

### 1.3 供給端格局

這是分析的核心。光伏玻璃行業的供給端經歷了從"無序擴張"到"產能管控"的轉變。

**2020-2022年：擴產潮。** 2020年光伏玻璃價格暴漲（一度突破50元/平方米），觸發大量新進入者投建產線。

**2023-2025年：產能過剩，價格暴跌。** 新產能集中投產，疊加2024年光伏主鏈（硅料、電池）產能過剩導致組件廠商壓價，光伏玻璃價格腰斬至約20元/平方米。

**2025年至今：產能管控趨嚴，出清加速。** 六部門印發產能管控政策，新產線審批收緊。二三線小企業虧損停產。信義光能自身也停掉了馬來西亞產線、計提了大額減值。

## 二、競爭格局分析：雙寡頭是怎樣形成的？

### 2.1 市場集中度

信義光能和福萊特合計在產產能約佔行業總產能的50%+。這個集中度在大宗工業品中屬於較高水平。

| 企業 | 在產產能（噸/日） | 市場份額 | 梯隊 |
|------|-------------------|---------|------|
| 信義光能 | ~23,200 | ~28% | 第一梯隊 |
| 福萊特 | ~20,600 | ~24% | 第一梯隊 |
| 南玻A | ~5,000 | ~6% | 第二梯隊 |
| 彩虹新能 | ~4,000 | ~5% | 第二梯隊 |
| 其他 | ~30,000 | ~37% | 第三梯隊（分散） |

### 2.2 雙寡頭形成的結構性原因

**第一，窯爐規模經濟。** 光伏玻璃窯爐存在顯著的規模效應：千噸級窯爐的單位成本遠低於三五百噸的小窯爐。信義光能千噸窯爐佔比91%，而行業平均遠低於此。規模經濟構成了天然的進入壁壘。

**第二，學習曲線效應。** 大窯爐的點火、調試、穩定運行需要豐富的技術積累。新進入者的良品率和能源效率在投產初期明顯低於老玩家。信義從1988年做玻璃到現在近40年，福萊特也有20年以上經驗。

**第三，資金壁壘。** 一條千噸產線投資10-15億元，從動工到達產需要2年。在當前行業低迷期，新進入者的融資成本和意願都大幅下降。

**第四，政策壁壘。** 光伏玻璃產能置換政策和審批管控使得新增產能的門檻進一步提高。這對在位龍頭有利。

### 2.3 芒格視角的關鍵判斷：雙寡頭格局會被打破嗎？

**短期（1-3年）：不太可能。** 行業處於產能過剩、盈利低迷的階段，沒有企業有動力大規模新建產能。相反，出清仍在繼續。

**中期（3-5年）：格局趨於加強。** 行業低谷淘汰的主要是二三線小企業，龍頭的份額在"不擴張"的情況下也會被動提升。歷史上，每一輪週期低谷之後，行業集中度都有提升。

**長期（5年+）：需要關注技術變量。** 如果鈣鈦礦等新技術路線商業化成功，光伏玻璃的需求特性可能發生根本性變化。但即使發生，現有龍頭也最有能力和資源去適應。

## 三、競爭對手深度對比

### 3.1 信義光能 vs 福萊特

這是投資者最關心的對比。

| 維度 | 信義光能 | 福萊特 | 判斷 |
|------|----------|--------|------|
| 產能規模 | ~23,200噸/日 | ~20,600噸/日 | 信義略勝 |
| 單窯規模 | 平均1,009噸 | 平均~800噸 | 信義明顯領先 |
| 成本水平 | 行業最低 | 接近信義 | 信義略優 |
| 海外產能 | 馬來+印尼 | 越南 | 各有佈局 |
| 財務穩健 | 淨負債率2.8% | 較高 | 信義優勢明顯 |
| 業務多元 | 玻璃+電站 | 純玻璃 | 各有利弊 |
| 上市地 | 港股 | A股 | 福萊特流動性好 |
| 估值 | ~12倍PE | ~15-18倍PE | 信義更便宜 |

**核心差異：** 信義光能在產能規模、窯爐技術、財務狀況上均略優。但福萊特的A股平臺給了它更低的融資成本和更高的估值。

### 3.2 二三線競爭者的處境

南玻A、彩虹新能等第二梯隊企業面臨嚴峻挑戰：
- 窯爐規模偏小，單位成本高於雙寡頭
- 缺乏海外產能佈局
- 財務壓力較大
- 在行業低谷中虧損程度更嚴重

大量第三梯隊小企業已經停產或退出。這正是行業出清的過程。

## 四、產業鏈博弈關係

### 4.1 上游：原材料供應

光伏玻璃的主要原材料是純鹼（~15%）、石英砂（~15%）和天然氣（~25-30%）。

- **純鹼：** 大宗化工品，供應充足，龍頭的大規模採購具有議價優勢
- **石英砂（低鐵砂）：** 優質低鐵砂資源集中在特定區域（廣西北海等），信義光能在產能佈局上已靠近資源產地
- **天然氣：** 管道直供是關鍵優勢，避免了中間商加價和供應不穩定

信義光能對上游的議價能力較強。

### 4.2 下游：組件廠商

光伏組件行業的集中度也在提升（隆基、晶科、天合、晶澳等），大客戶的議價能力不弱。但光伏玻璃供應高度集中（雙寡頭佔50%+），且切換供應商有認證成本和供應風險，因此議價關係相對均衡。

在行業產能過剩時，下游對上游壓價嚴重；在供應緊張時（如2020-2021年），上游具有明顯的定價權。這種週期性的議價權轉換是行業波動的核心原因。

## 五、關鍵行業趨勢

### 5.1 海外市場溢價——逆全球化的受益者

2025年信義光能海外銷售佔比從約25%提升至33.5%，海外玻璃銷售額增長約36%。這背後的驅動力是：

- 各國推動光伏供應鏈本地化，海外產能供不應求
- 貿易壁壘導致中國產光伏玻璃出口成本上升，本地化產能享有溢價
- 美國、印度等市場光伏裝機加速

信義光能在馬來西亞和印尼的產能佈局使其成為逆全球化趨勢的受益者。這可能是未來3-5年最重要的增量來源。

### 5.2 產能管控政策——行業底部的催化劑

中國六部門2025年印發的建材行業方案明確加強光伏玻璃產能管控。這意味著：
- 新建產能更難獲批
- 存量落後產能加速退出
- 有利於在位龍頭的市場份額提升

### 5.3 技術迭代——雙面組件與薄片化

光伏玻璃正朝著更薄、更大、更透光的方向發展。這對製造工藝提出更高要求，進一步拉開龍頭與小企業的差距。

### 5.4 鈣鈦礦——遠期變量

鈣鈦礦電池對封裝要求更高（抗水氧滲透），可能需要TCO導電玻璃替代傳統光伏玻璃。如果鈣鈦礦5-10年內大規模商業化，現有產線可能需要改造。

**但需要客觀評估：** 鈣鈦礦目前仍處於中試階段，距離大規模商業化可能還有5-10年。而且技術迭代往往是漸進的，龍頭企業最有資源去適應。

```
              ↓                           ↓

              |                           |
              |    2022-2023              |
              |       ↓                   |
              |    產能過剩加劇           |
              |       |                   |
              |       |    2024-2025      |
              |       |       ↓           |

```

多數跡象表明，行業正處於出清的中後期階段：
- 二三線企業持續虧損退出
- 政策開始管控產能
- 龍頭毛利率已開始回升
- 海外市場提供結構性增量

但"底部"不等於"馬上反轉"。供需平衡的恢復可能還需要6-18個月。

## 八、核心結論

用芒格的"反過來想"——什麼情況下信義光能的競爭地位會顯著惡化？

1. **某家企業突破千噸窯爐技術並大規模投產** ——可能性低，技術壁壘和審批限制使得這很難發生
2. **光伏組件技術路線發生根本性變革，不再需要光伏玻璃** ——鈣鈦礦可能改變需求特性，但完全替代玻璃封裝在可預見的未來不太可能
3. **雙寡頭之間爆發惡性價格戰** ——這會傷害雙方，歷史上未發生過，兩家的默契競爭是行業穩定的基石
4. **海外市場出現強有力的本地競爭者** ——短期內缺乏技術和規模積累，但長期需要關注

綜合來看，信義光能的行業競爭地位是穩固的，且仍在慢慢加強。核心變量不是"競爭對手會不會打敗它"，而是"行業週期什麼時候回暖"。
