# 中國神華（1088.HK）投資研究

> 研究日期：2026年5月16日
> 研究框架：四維度並行深度分析

## 公司概況

中國神華能源股份有限公司（1088.HK / 601088.SH），隸屬於國家能源集團，是全球最大的煤炭上市公司。公司構建了"煤-電-路-港-航-化"六位一體的全產業鏈閉環，是中國能源行業絕對的龍頭企業。

## 重大事件：千億資產重組收官

2025年8月至2026年4月，中國神華完成了近年來規模最大的央企資產重組——以1336億元對價收購國家能源集團旗下13家企業股權，涵蓋煤炭、電力、化工、航運等領域。重組後公司煤炭產能提升57%，電力裝機提升28%，煤炭儲量幾乎翻倍。

## 研究背景

煤炭作為中國能源安全的壓艙石，短期內不可替代。中國神華憑藉全產業鏈佈局、極低的資產負債率和穩定的分紅政策，被市場視為"類債券"資產。但煤炭行業面臨長期需求見頂、新能源替代、碳中和政策等結構性挑戰。本研究試圖回答：在能源轉型的大背景下，中國神華是否仍然是一筆好投資？
