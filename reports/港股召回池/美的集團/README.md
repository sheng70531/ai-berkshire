## 公司概況

美的集團是中國最大的家電製造企業，業務覆蓋智能家居（空調、冰箱、洗衣機、廚電等）和商業及工業解決方案（樓宇科技、機器人與自動化、新能源及工業技術）兩大板塊。公司在全球200多個國家和地區擁有約400家子公司，海外營收佔比超40%。
