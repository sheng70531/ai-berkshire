## 研究背景

中通快遞是中國快遞行業業務量第一、盈利能力最強的企業，連續十年保持市場份額領先。公司採用"終端加盟+分揀直營"的模式，以成本優勢構建競爭壁壘。當前PE約13倍，ROE約17%，同時推出35億美元累計回購計劃。核心隱憂在於快遞行業價格戰的持續性以及市場份額的波動。
