## 公司概況

蔚來是中國高端智能電動汽車品牌，目前運營三大品牌矩陣：

- **蔚來（NIO）**：定位豪華智能電動車，均價30萬元以上
- **樂道（ONVO）**：聚焦20-30萬元主流市場，2025年首個完整交付年交付107,808輛
- **螢火蟲（Firefly）**：聚焦10萬元以上高端小車市場，市佔率連續7個月蟬聯第一

核心差異化競爭力在於換電體系（BaaS模式）和用戶社區生態。

## 核心矛盾

蔚來是中國新能源汽車行業最具爭議的公司之一。看多者認為其換電生態、用戶社區和多品牌戰略構建了獨特壁壘；看空者指出其累計虧損超千億、商業模式重資產、競爭格局日益惡化。2025年Q4首次季度盈利是拐點還是曇花一現，是本次研究的核心問題。
