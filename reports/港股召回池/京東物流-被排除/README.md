# 京東物流（2618.HK）投資研究

## 基本信息
- **公司名稱**：京東物流股份有限公司
- **股票代碼**：2618.HK
- **行業**：供應鏈物流
- **PE（TTM）**：~15倍
- **ROE**：~12%

## 2025年度核心財務數據
| 指標 | 數值 | 同比變化 |
|------|------|----------|
| 營業收入 | 2,171億元 | +18.8% |
| 經調整淨利潤 | 77.1億元 | 大幅增長 |
| 上半年一體化供應鏈收入 | 501億元 | +19.9% |
| 外部客戶收入佔比 | 67.1% | 持續提升 |
| 一線員工數 | 超66萬人 | - |

## 投資亮點
1. 收入增速強勁（18.8%），突破2000億元
2. 一體化供應鏈模式形成競爭壁壘
3. 外部客戶收入佔比持續提升，去京東化
4. AI/自動化降本增效空間大

## 核心風險
1. 人力密集型企業，66萬+員工，成本剛性
2. 毛利率偏低（~9-10%），利潤薄
3. 與京東集團關聯交易依賴
4. 快遞行業價格戰風險
