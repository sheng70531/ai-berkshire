## 研究背景

石藥集團是中國頭部綜合製藥企業，正處於從仿製藥向創新藥轉型的關鍵階段。公司業績連續三年下滑（2023-2025年歸母淨利潤分別為58.73億、43.28億、38.82億元），主要受集採政策衝擊傳統仿製藥業務所致。當前估值處於歷史低位，PE僅8.7倍，市場定價已充分反映悲觀預期。

## 核心矛盾

**看多邏輯：**
- 估值極低，PE 8.7倍為歷史底部區域
- 創新藥管線步入兌現期，全球管線規模排名第15位
- BD授權爆發，2025年合同累計金額超282億美元
- 2026年業績拐點預期（券商預測淨利潤同比+47%）
- 司美格魯肽仿製藥獲批在即，打開減重賽道

**看空邏輯：**
- 業績連續三年下滑，基本面尚未企穩
- 管理層動盪，執行總裁黑永疆任職僅1.5年即離職
- 二代蔡磊接班，能否駕馭複雜轉型存疑
- 集採續標風險仍在，恩必普等核心品種持續承壓
- 創新藥商業化能力尚未經過充分驗證
