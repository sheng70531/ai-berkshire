# 金沙中國（1928.HK）投資研究

## 基本信息
- **公司名稱**：金沙中國有限公司
- **股票代碼**：1928.HK
- **行業**：博彩/度假村
- **PE（TTM）**：15-18倍
- **ROE**：20-25%

## 核心財務數據
| 指標 | 數值 | 說明 |
|------|------|------|
| 2025年淨收入 | ~78億美元 | 四季度同比+16% |
| 淨利潤 | ~10億美元 | 同比-3.3% |
| EBITDA利潤率 | ~29-33% | 運氣調整後~29% |
| 物業 | 5大綜合度假村 | 10,829間客房 |
| 賭檯/角子機 | ~1,680張/3,700臺 | - |
| 2025股息 | 每股3.7美仙 | 股息率~1.6% |

## 投資亮點
1. ROE 20-25%——13家公司中最高
2. 澳門博彩牌照壟斷（6家之一）
3. 旅遊/消費復甦利好
4. 母公司LVS全球運營經驗

## 核心風險
1. 博彩監管政策突變風險
2. 中國經濟放緩壓制貴賓廳收入
3. 新加坡/東南亞競爭分流
4. 資本密集——物業維護/翻新需持續投入
