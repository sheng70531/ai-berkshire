## 核心業務

中升控股是中國最大的豪華汽車經銷商集團之一，主要經營：

1. **新車銷售**：梅賽德斯-奔馳、寶馬、奧迪、雷克薩斯等豪華品牌，以及豐田、本田、日產等中高端品牌；2024年底新增問界（AITO/鴻蒙智行）新能源品牌
2. **售後服務**：維修保養、零配件銷售、延保服務
3. **二手車業務**：二手車交易及置換
4. **汽車金融及保險**：汽車貸款佣金、保險代理

## 研究背景

- **行業劇變**：新能源汽車滲透率突破50%，傳統豪華品牌經銷商遭遇價格倒掛、利潤坍塌
- **業績轉折**：2025年首次錄得淨虧損16.73億元，其中商譽減值22.91億元
- **估值窪地**：2026E PE約4.3倍，市場對傳統經銷商模式的估值嚴重摺價
- **轉型關鍵期**：加速佈局華為問界、吉利系等新能源品牌，目標2026年末新能源門店數量倍增
