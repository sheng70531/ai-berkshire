# 長和（0001.HK）投資研究

## 基本信息
- **公司名稱**：長和實業集團有限公司
- **股票代碼**：0001.HK
- **行業**：綜合集團
- **PE（TTM）**：~19倍
- **ROE**：2-3%

## 2025年度核心財務數據
| 指標 | 數值 | 同比變化 |
|------|------|----------|
| 呈報淨利潤 | 118.4億港元 | （含3UK合併虧損105億） |
| 基本淨利潤（剔除一次性） | 223億港元 | +7% |
| 港口收益 | 489億港元 | +8% |
| 零售收益 | 2,093億港元 | +10% |

## 投資亮點
1. 全球多元化集團——港口、零售、基建、能源、電訊
2. 資產出售釋放價值（3UK合併、UKPN出售等）
3. 淨負債率極低（降至7%）
4. 李嘉誠家族長期資本配置能力

## 核心風險
1. ROE僅2-3%——13家中最低
2. 綜合折讓嚴重（市場厭惡複雜集團）
3. 3UK合併產生105億港元一次性虧損
4. 業務過於分散，難以形成合力
