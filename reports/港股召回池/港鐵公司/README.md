## 研究背景

港鐵公司是全球少數能夠實現鐵路業務盈利的地鐵運營商，其獨創的"鐵路+物業"（R+P）模式被麥肯錫等諮詢機構作為全球公共交通可持續運營的標杆案例。公司由香港特區政府控股（74.4%），同時以商業化方式運營，兼具公用事業的穩定性和商業企業的盈利能力。

**研究觸發因素：**
- R+P模式全球獨創，商業模式值得深入理解
- 靜態PE約10.7倍，PB約0.91倍，股息率約4.85%，估值處於歷史低位區間
- 六大新鐵路項目投資約1,400億港元，未來十年處於重大資本開支週期
- 管理層換屆（楊美珍2026年1月接任CEO），戰略方向值得關注
- 海外業務收縮（英國、瑞典），業務版圖正在重塑
