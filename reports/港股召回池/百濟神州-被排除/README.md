## 核心業務

百濟神州是一家全球性生物科技公司，專注於腫瘤創新藥物的研發、生產和商業化。核心產品澤布替尼（百悅澤/BRUKINSA）已成為全球BTK抑制劑市場領導者，2025年全球銷售額約39億美元。公司同時擁有替雷利珠單抗（百澤安）等多款自研產品，並代理安進公司授權產品。

## 研究背景

百濟神州是中國創新藥全球化的標杆企業。2025年首次實現全年盈利，標誌著從"燒錢研發"向"商業造血"的歷史性轉變。澤布替尼已超越阿卡替尼成為全球第二大BTK抑制劑，並在新患者市場份額上持續追趕伊布替尼。公司三地上市（港交所、科創板、納斯達克），在全球擁有超過10,000名員工，管線覆蓋30款臨床階段產品、96項臨床試驗。

本研究力求客觀，不預設立場，正反兩面充分討論。
