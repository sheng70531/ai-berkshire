# 長實集團（1113.HK）投資研究

## 基本信息
- **公司名稱**：長實集團有限公司
- **股票代碼**：1113.HK
- **行業**：地產/投資
- **PE（TTM）**：5-6倍
- **ROE**：3-4%

## 核心財務數據
| 指標 | 數值 | 同比變化 |
|------|------|----------|
| 2025上半年淨利潤 | 63億港元 | -26.75% |
| 物業銷售確認收入（上半年） | 73.7億港元 | +58.9% |
| 負債淨額/總資本 | ~5.0% | 行業極低 |
| 信用評級 | A/穩定（標普）、A2（穆迪）| - |

## 投資亮點
1. PE僅5-6倍——13家中最低
2. 負債率極低（5%），財務極為安全
3. 大量低成本土地儲備（早期獲取）
4. 多元化佈局（地產+基建+酒店+飛機租賃）

## 核心風險
1. ROE僅3-4%——極低資本回報率
2. 香港/內地房地產市場持續低迷
3. 利潤大幅下滑26.75%
4. 物業重估價值下降
