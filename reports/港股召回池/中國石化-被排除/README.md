# 中國石化（0386.HK）投資研究

## 基本信息
- **公司名稱**：中國石油化工股份有限公司
- **股票代碼**：0386.HK
- **行業**：石油煉化
- **市值**：約4,500億港元
- **PE（TTM）**：15-17倍
- **ROE**：6-7%

## 2025年度核心財務數據
| 指標 | 數值 | 同比變化 |
|------|------|----------|
| 營業收入 | 2,784億元 | -9.4% |
| 歸母淨利潤 | 318億元 | -36.8% |
| 基本每股收益 | 0.26元 | - |
| 全年股息 | 每股0.2元 | 派息率81% |
| 經營現金流淨額 | 162.5億元 | +8.8% |

## 投資亮點
1. 國內最大煉化企業，產業鏈一體化優勢
2. 高派息率（81%），股息收益率可觀
3. 加油站網絡形成天然護城河
4. 向新能源轉型積極佈局（充電樁、氫能）

## 核心風險
1. 國際油價波動直接影響盈利
2. 成品油需求見頂（新能源車替代）
3. 化工產品價格週期性強
4. 國企治理效率待提升
