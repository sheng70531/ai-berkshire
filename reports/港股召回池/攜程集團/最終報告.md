> 研究日期：2026年5月16日
> 狀態：召回池觀察，暫不建倉

## 一、一句話總結

攜程是一家在好行業中佔據領導位置的好公司，財務極其健康，但反壟斷調查懸而未決構成最大不確定性——當前是"好公司等待好價格"的階段，不是出手的最佳時機。

## 三、投資論點的正反兩面

### 看多論點（為什麼可能值得買）

**1. 行業龍頭地位短期不可撼動**
56%的市場份額、26年的供應鏈積累、中高端用戶的品牌心智。即便反壟斷處罰落地，參考阿里和美團的先例，龍頭的市場地位不會根本改變。

**2. 財務質量堪稱一流**
81%毛利率、淨現金狀態、充沛的經營現金流。即使面對最嚴厲的罰款（65億元），公司的財務安全不會受到實質威脅。

**3. 國際化和入境遊是真實的增長引擎**
2025年國際OTA預訂增長60%，入境遊翻倍。中國免籤政策的擴大為攜程創造了競爭對手難以複製的獨特機遇。

**4. 估值已部分反映悲觀預期**
14-17倍PE對於一家年增15%、毛利率80%+的公司來說，是偏低的。如果反壟斷利空出盡，估值修復的空間是存在的。

**5. 管理層在積極應對**
AI戰略（TripGenie）的推進、組織架構的調整（新設CPO和首席科學家）、50億美元的回購計劃，都說明管理層在主動求變。

### 看空論點（為什麼可能不該買）

**1. 反壟斷調查是不可控的"黑箱"**
罰款金額（6-65億元）和行為限制的嚴厲程度完全無法預判。如果被要求大幅降低佣金率或廢除核心商業工具（調價助手），長期盈利能力的天花板會被壓低。

**2. 流量入口的結構性遷移不可逆**
抖音和美團正在改變用戶的旅行決策路徑。攜程可能從"用戶第一觸點"退化為"後端供應鏈服務商"，這會侵蝕其定價權和品牌溢價。

**3. 兩位聯合創始人同時辭任，信號不佳**
範敏和季琦在反壟斷立案後一個多月雙雙辭任，無論實際原因如何，這在市場看來不是積極信號。疊加百度持續減持，內部人的動作讓人不安。

**4. 國際化回報週期長且不確定**
在Booking和Expedia的主場與其競爭，需要的投入可能遠超預期。如果國際化進展不及預期，高額投入可能拖累利潤率。

**5. 81%的毛利率可能不可持續**
監管壓力+競爭加劇+供應商反抗，三重因素可能在中期壓低毛利率。美團、抖音的低佣金策略也在倒逼行業佣金率下行。

## 四、關鍵假設與催化劑

### 正面催化劑（可能推動股價上漲）
1. 反壟斷處罰結果溫和（罰款<30億，行為限制溫和），利空出盡
2. 國際化業務實現盈虧平衡或盈利
3. TripGenie等AI產品顯著提升轉化率和用戶粘性
4. 大規模回購持續執行

### 負面催化劑（可能推動股價下跌）
1. 反壟斷處罰嚴厲（罰款>50億 + 嚴格行為限制）
2. 美團或抖音酒旅份額加速增長
3. 宏觀經濟超預期惡化
4. 百度進一步大幅減持

## 五、投資策略建議

### 當前結論：等待，不出手

**核心邏輯**：反壟斷調查是一個有明確時間窗口的事件（預計2026年下半年出結果）。在結果公佈前，投資者面對的是一個概率分佈極寬的"賭博"——可能大賺也可能大虧。這不是價值投資的做法。

### 觸發條件：什麼情況下重新評估？

**買入考慮的觸發條件：**

| 條件 | 說明 |
|------|------|
| 反壟斷結果公佈且溫和 | 罰款<30億元，行為限制不涉及佣金率大幅下調 |
| 股價跌至350港元以下 | 對應約10-12倍經營PE，安全邊際充足 |
| 管理層展現危機處理能力 | 在反壟斷後迅速調整策略、穩定供應商關係 |
| 國際化業務數據持續亮眼 | 連續2-3個季度國際OTA預訂增速>40% |

**繼續觀望的條件：**

| 條件 | 說明 |
|------|------|
| 反壟斷處罰嚴厲 | 罰款>50億元，或被要求大幅降低佣金率 |
| 管理層動盪繼續 | 更多核心高管離職 |
| 美團/抖音份額加速增長 | OTA格局發生實質性變化 |
| 毛利率開始下滑 | 從81%降至75%以下 |

## 八、最終判斷

攜程是一家**值得放入觀察池持續跟蹤**的公司。它的商業模式質量、財務健康度和行業地位都屬上乘，是"好公司"沒有疑問。

但"好公司"不等於"現在就該買"。反壟斷調查的懸劍未落，這是一個可以等待的、有時間窗口的風險事件。等待的成本是可能錯過一波反彈，但等待的收益是避免在最大不確定性時刻下注。

**操作建議：放入召回池，等待反壟斷結果明確後重新評估。如果處罰溫和+股價回調至350港元以下，可以考慮建倉。**
