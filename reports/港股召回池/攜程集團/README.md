## 研究背景

攜程是中國在線旅遊行業絕對龍頭，國內OTA市場佔有率約56%，遠超第二名同程旅行（15%）和美團（13%）。公司擁有攜程、去哪兒、Trip.com、天巡（Skyscanner）四大品牌矩陣，覆蓋住宿預訂、交通票務、旅遊度假、商旅管理四大業務板塊。

**當前核心矛盾：**

1. **反壟斷調查懸而未決**：2026年1月14日，市場監管總局以涉嫌濫用市場支配地位立案調查，調查仍在進行中，罰款金額可能在6-65億元之間
2. **估值是否已充分反映風險**：港股PE約14倍，較歷史中樞有折價，但需判斷這是價值陷阱還是買入窗口
3. **國際化能否打開第二曲線**：海外業務增速60%，入境遊翻倍增長，但能否持續存疑
4. **AI重構能否鞏固護城河**：TripGenie等產品能否在抖音、美團的流量衝擊下維持競爭壁壘
