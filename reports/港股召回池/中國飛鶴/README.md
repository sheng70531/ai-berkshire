## 研究背景

中國飛鶴是國內嬰幼兒配方奶粉市場龍頭，連續多年市佔率第一。公司面臨出生人口持續下降的結構性逆風，2025年營收181.1億元（同比-12.7%），淨利潤19.4億元（同比-45.7%），為近六年最差業績。當前PE約13-15倍，股息率超6%，正處於"高分紅+強回購"階段。核心問題：第二曲線能否承接主業下滑？低估值是價值陷阱還是機會？
