# 中國飛鶴：商業模式分析

> 分析維度：生意本質、用戶價值、護城河深度、商業模式可持續性

---

## 一、這是一門什麼樣的生意？

### 1.1 生意本質

嬰幼兒配方奶粉本質上是一門**高信任度消費品**生意。與普通快消品不同，奶粉的購買決策具有以下特徵：

- **極高的品牌忠誠度**：媽媽一旦選定品牌，除非出現問題，極少更換（轉換成本高）
- **價格敏感度低**：家長願意為"安全""營養"支付溢價，很少因便宜幾十塊而換品牌
- **信息不對稱**：消費者無法直接驗證奶粉質量，極度依賴品牌信任
- **消費頻次有限但單價高**：0-3歲用戶生命週期約3年，年消費約6000-12000元

這些特徵意味著：一旦建立品牌信任，企業可以獲得高毛利和高復購，但用戶池本身是有限且不斷流失的（孩子長大就不再消費）。

### 1.2 飛鶴的用戶價值主張

飛鶴的核心定位是"更適閤中國寶寶體質"，這一slogan雖然在科學上存在爭議，但在營銷層面極為有效：

- 利用了2008年三聚氰胺事件後國產奶粉的信任重建窗口
- 用"中國人體質"概念區隔國際品牌
- 通過高端定價（星飛帆卓睿單罐約400-500元）傳遞品質信號

**核心判斷**：飛鶴的用戶價值更多建立在品牌心智和情感信任上，而非技術壁壘。這既是優勢（難以被短期攻破），也是風險（一旦信任崩塌將非常迅速）。

## 二、護城河分析

### 2.1 品牌護城河 ★★★★☆

**正面**：
- 國產嬰配粉第一品牌，連續多年全渠道銷量第一
- 品牌認知度極高，尤其在二三線城市和下沉市場
- "三聚氰胺"後十餘年持續投入建立的信任資產

**隱憂**：
- 品牌溢價建立在"國產安全"敘事上，但隨著時間推移，這一敘事的差異化價值在遞減
- 伊利憑藉更強的全渠道覆蓋能力和更低價格快速追趕
- 年輕一代消費者（95後/00後媽媽）品牌偏好可能與前一代不同

### 2.2 渠道護城河 ★★★☆☆

**正面**：
- 建立了覆蓋全國的單層經銷商體系，約2700家經銷商
- 深耕母嬰店渠道，通過"面對面"營銷建立信任
- 掃碼系統、電子圍欄等技術手段管控竄貨

**隱憂**：
- 母嬰店渠道正在萎縮（線下佔比從69%降至60%以下）
- 線上渠道飛鶴並不佔優勢，電商玩法與其傳統打法不同
- 12億奶粉補貼（以舊換新等）雖短期保量，但破壞了價格體系和經銷商信心
- 經銷商數量已從2800降至2700，渠道生態承壓

### 2.3 產品/技術護城河 ★★★☆☆

**正面**：
- 全產業鏈佈局：自有牧場+工廠，從奶源到成品全程可控
- 2025年推出"乳蛋白鮮萃提取科技"，實現11種關鍵乳蛋白原料自主生產
- 超高端產品星飛帆卓睿2024年銷售67億（同比+60%），產品升級能力得到驗證

**隱憂**：
- 嬰配粉配方同質化嚴重，技術差異消費者難以感知
- 研發費用佔比低（約3%），遠低於銷售費用（35%）
- 全產業鏈在行業下行期反而成為負擔（產能過剩、生物資產減值）

### 2.4 規模經濟護城河 ★★☆☆☆

嬰配粉行業的規模經濟效應有限。飛鶴雖然是行業老大，但規模優勢主要體現在廣告投放的均攤效應上，生產端的規模優勢並不顯著（行業毛利率普遍較高）。

## 三、商業模式的關鍵矛盾

### 3.1 高營銷依賴

飛鶴的商業模式本質是"重營銷驅動"：

- 2024年銷售費用率34.6%（約72億元）
- 2025年在營收下降12.7%的情況下，銷售費用並未等比下降
- 大量投入在地推活動、媽媽班、KOL合作等

**對比**：貴州茅臺的銷售費用率約3%，海天味業約7%。真正擁有深厚品牌護城河的消費品，不需要持續高強度營銷維持份額。飛鶴的高營銷費用暗示其品牌忠誠度可能沒有表面看起來那麼強。

### 3.2 市場規模持續萎縮

這是飛鶴面臨的最根本性問題：

- 中國新生兒從2016年的1786萬降至2024年的約900萬
- 0-3歲兒童存量從4190萬縮減至約2650萬
- 即便飛鶴市佔率從17%提升到25%，總量仍然是下降的

**關鍵問題**：在一個持續萎縮的市場中，龍頭的"份額提升"能否對沖"蛋糕縮小"？從2025年-12.7%的營收增速看，答案暫時是否定的。

### 3.3 第二曲線的可行性

飛鶴正在嘗試的第二曲線包括：

- **成人奶粉**：愛本躍動蛋白系列，面向35+中年人群
- **兒童奶粉/零食**：愛上吃菜乳酪系列
- **海外市場**：加拿大等地佈局

2025年"其他乳製品"收入20.6億元（佔比11.4%，同比+36%），但毛利率僅1%——這意味著第二曲線目前還處於"燒錢換規模"階段，遠未證明商業可行性。

## 四、段永平視角的核心追問

### "如果不看股價，你願意100%買下這家公司嗎？"

**猶豫點**：
1. 主業處於結構性下行通道，這不是週期性波動
2. 高營銷費用說明"護城河"需要持續維護，不夠深
3. 第二曲線尚未跑通，且成人奶粉是一個競爭激烈的紅海市場
4. 管理層在利潤腰斬時仍維持高薪高分紅，股東利益對齊存疑

**吸引點**：
1. 嬰配粉確實是好生意（高毛利、強現金流、剛需）
2. 行業集中度仍在提升，飛鶴有望獲得退出者份額
3. 75億現金在手，財務安全
4. 若2026-2028年出生人口企穩回升（政策推動），飛鶴將是最大受益者

## 五、綜合評估

| 維度 | 評分 | 說明 |
|------|------|------|
| 生意質量 | ★★★★☆ | 嬰配粉本身是好生意，但市場萎縮拖累 |
| 品牌護城河 | ★★★★☆ | 強但非不可撼動，伊利在逼近 |
| 渠道護城河 | ★★★☆☆ | 線下優勢在弱化，線上不突出 |
| 商業模式可持續性 | ★★★☆☆ | 主業天花板明確，第二曲線未證明 |
| 用戶價值創造 | ★★★★☆ | 產品品質可靠，但溢價來自營銷而非技術 |

**總體商業模式評分：★★★☆☆（3.5/5）**

飛鶴是一門正在變差的好生意。護城河仍在，但在緩慢變淺。關鍵觀察點：第二曲線何時貢獻有意義的利潤，以及伊利是否在未來1-2年完成對飛鶴的超越。
