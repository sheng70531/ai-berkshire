# 中國飛鶴：行業競爭分析

> 分析維度：行業結構演變、競爭格局、終局推演、逆向思維

---

## 一、行業宏觀環境——一個正在萎縮的市場

### 1.1 需求端：結構性下行

中國嬰幼兒配方奶粉市場正經歷前所未有的收縮：

| 指標 | 數據 |
|------|------|
| 2016年新生兒 | 1786萬 |
| 2020年新生兒 | 1200萬 |
| 2023年新生兒 | 902萬 |
| 2024年新生兒 | 約900萬（持平或微降） |
| 0-3歲存量人口 | 從4190萬縮至約2650萬 |
| 市場規模 | 從約1600億元向1200-1300億元收縮 |

**關鍵判斷**：出生人口下降不是週期性波動，而是結構性趨勢。即便各地生育補貼政策落地，樂觀估計2026-2028年新生兒數量也只是從下降轉為"低位企穩"（800-950萬），而非反轉。

### 1.2 供給端：產能嚴重過剩

嬰配粉行業當前產能利用率不足50%。大量中小品牌面臨退出壓力，行業正進入"清退期"：

- 2023年嬰配粉品牌數量約400個，預計到2027年將縮減至200個以下
- 新國標（2023年實施）提高了註冊門檻，加速了中小品牌退出
- 但退出者的份額釋放速度<行業萎縮速度，龍頭也未必能從中受益

### 1.3 價格端：高端化遇到天花板

過去幾年行業的增長邏輯是"量減價增"——出生人口減少但客單價提升。但這一邏輯在2025年開始失效：

- 超高端奶粉（400元+/罐）滲透率已接近極限
- 消費降級趨勢下，部分消費者開始"降段"或選擇性價比品牌
- 飛鶴的12億補貼本質上是變相降價，說明高端定價策略承壓

## 二、競爭格局分析

### 2.1 主要競爭對手

| 品牌 | 市佔率（2024） | 特點 | 威脅程度 |
|------|---------------|------|----------|
| 飛鶴 | ~17.5% | 高端定位，線下強 | — |
| 伊利（金領冠） | ~16.3% | 全渠道覆蓋，價格帶寬 | ★★★★★ |
| 君樂寶 | ~8% | 性價比路線，增速快 | ★★★★☆ |
| 達能（愛他美） | ~7% | 國際品牌，高端 | ★★★☆☆ |
| a2 | ~4% | 差異化定位 | ★★☆☆☆ |
| 惠氏 | ~5% | 式微中，降價促銷 | ★★☆☆☆ |

### 2.2 最大威脅：伊利

伊利與飛鶴的差距已從"明顯領先"縮小到"毫釐之間"（17.5% vs 16.3%）。伊利的競爭優勢：

- **渠道更廣**：伊利擁有500萬+終端網點，覆蓋遠超飛鶴
- **價格帶更寬**：從大眾到超高端全覆蓋，飛鶴主要聚焦中高端以上
- **品類協同**：液態奶+奶粉+奶酪，品牌觸達頻次更高
- **資源更厚**：伊利整體營收超千億，可以承受嬰配粉的價格戰

2025年上半年，伊利已宣稱其"整體嬰幼兒奶粉零售額市場份額躍居全國第一"——雖然統計口徑有爭議，但趨勢不容忽視。

### 2.3 君樂寶的低價衝擊

君樂寶以"優質平價"定位快速上量，在消費降級趨勢下具有結構性優勢。其對飛鶴的威脅主要體現在三四線城市的爭奪。

### 2.4 國際品牌的策略轉變

惠氏、達能等國際品牌在市佔率下滑後選擇降價促銷，進一步擠壓市場空間。這種"寧可虧損也不退出"的策略增加了行業整合的複雜性。

## 三、飛鶴的競爭地位變化

### 3.1 份額變化趨勢

飛鶴市佔率在2022年達到峰值後開始鬆動：
- 2020-2022：快速提升至20%+
- 2023-2024：維持在17-18%
- 2025：面臨伊利的直接挑戰

### 3.2 飛鶴的競爭策略及其代價

**補貼戰（12億以舊換新）**：
- 短期保住了銷量，但毛利率被侵蝕
- 破壞了經銷商的價格體系
- 部分補貼產品流入二級市場低價轉賣
- 本質上是用利潤換份額，這在萎縮市場中是危險的

**超高端升級（星飛帆卓睿）**：
- 2024年卓睿銷售67億（+60%），取代經典星飛帆成為第一大單品
- 說明飛鶴仍有產品升級能力
- 但能否持續？消費降級大趨勢下超高端空間有限

**全齡化轉型**：
- 切入成人奶粉、兒童食品
- 邏輯正確但競爭更激烈——伊利、蒙牛、雀巢都在這個市場
- 毛利率僅1%，說明目前是虧本搶市場

## 四、行業終局推演

### 4.1 芒格式思考：10年後這個行業會怎樣？

**情景一：寡頭壟斷（概率30%）**

- 行業集中度大幅提升至CR3 > 60%
- 飛鶴、伊利、君樂寶三分天下
- 價格戰結束，倖存者享受更高利潤率
- 飛鶴維持15-18%市佔率

**情景二：溫和集中（概率45%）**

- 行業集中度提升但緩慢，CR3約50%
- 飛鶴保持第一但份額下滑至15%左右
- 伊利追平或超越飛鶴
- 行業規模穩定在1000-1200億元
- 飛鶴營收降至120-150億元區間

**情景三：飛鶴被超越（概率25%）**

- 伊利憑藉全渠道優勢超越飛鶴
- 飛鶴市佔率降至12-15%
- 線上渠道重塑競爭格局，新玩家湧入
- 飛鶴逐步"惠氏化"——從行業領導者變為跟隨者

### 4.2 關鍵勝負手

決定飛鶴未來的幾個關鍵因素：

1. **線上渠道能力**：母嬰店渠道萎縮不可逆，線上增長12.3%。飛鶴能否在線上建立與線下同等的競爭力？
2. **年輕消費者心智**：00後媽媽是否仍認可"飛鶴=國產第一"？
3. **伊利的進攻力度**：伊利是否會將嬰配粉作為戰略級投入？
4. **出生人口走勢**：如果2026-2028年企穩回升，飛鶴將獲得喘息空間

## 五、逆向思維：為什麼市場可能錯了？

### 5.1 市場可能過度悲觀的理由

- 行業整合終將到來，退出者的份額會被龍頭瓜分
- 出生人口即便降至750萬/年，每年新增嬰配粉消費仍達600-700億元
- 飛鶴的品牌心智在母嬰人群中仍是第一提及率
- 75億現金+零負債=極強的生存能力，可以"熬死"競爭對手

### 5.2 市場可能還不夠悲觀的理由

- 2025年10.7%的淨利率可能不是底部——如果2026年繼續下滑呢？
- 伊利超越飛鶴的概率可能被低估
- 第二曲線1%毛利率說明多元化並不成功
- 管理層的利益訴求（高薪+分紅）可能與小股東不一致

## 六、芒格式檢查清單

### "告訴我會死在哪裡，我就不去那裡"

飛鶴可能"死掉"（永久性資本損失）的情景：
1. ❌ 食品安全事件——品牌信任一夜崩塌（低概率但災難性）
2. ⚠️ 伊利持續壓制+消費降級——市佔率和利潤率雙降
3. ⚠️ 管理層揮霍現金——錯誤的多元化或過度分紅耗盡現金
4. ❌ 政策風險——如政府強推母乳餵養導致奶粉需求銳降

### "反過來想"

要讓飛鶴成為好投資，需要什麼？
1. 利潤率觸底回升（銷售費用率下降或營收企穩）
2. 第二曲線出現盈利拐點
3. 出生人口數據出現意外回升
4. 競爭對手退出加速

目前這4個條件均未滿足。

## 七、綜合評估

| 維度 | 評分 | 說明 |

| 行業吸引力 | ★★☆☆☆ | 萎縮市場，產能過剩，價格戰 |
| 競爭地位穩固性 | ★★★☆☆ | 仍是第一但優勢在縮小 |
| 行業終局確定性 | ★★★☆☆ | 集中度會提升，但飛鶴未必是最終贏家 |
| 護城河加深/變淺 | ★★☆☆☆ | 多項指標顯示護城河在變淺 |

**總體行業競爭評分：★★★☆☆（2.8/5）**

從芒格的視角看，飛鶴處於一個"好公司在壞行業"的經典困境中。行業蛋糕在萎縮，競爭對手在逼近，而飛鶴的應對策略（補貼保量、第二曲線）目前的代價大於收益。等待行業出清信號或利潤率企穩可能更為明智。
