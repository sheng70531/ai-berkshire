## 投資論點預覽

**看多邏輯：** 汽車業務從0到千億僅用2年，"人車家"生態協同開始兌現，2026年YU7放量有望推動利潤跳升。

**看空邏輯：** 手機毛利率承壓（8.3%），汽車競爭白熱化，嚴重依賴雷軍個人，印度市場萎縮，估值已部分反映樂觀預期。
