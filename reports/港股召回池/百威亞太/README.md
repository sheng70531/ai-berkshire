## 公司簡介

百威亞太是全球最大啤酒集團百威英博（AB InBev）的亞太區業務平臺，2019年在港交所上市。公司運營百威、科羅娜、哈爾濱、福佳等多個啤酒品牌，業務覆蓋中國、韓國、印度、越南等亞太市場。

## 核心業務結構（2025年）

1. **亞太西部（含中國）**：收入佔比約65%，中國為最大單一市場
2. **亞太東部（韓國、日本）**：收入佔比約15%
3. **南亞（印度、越南）**：收入佔比約20%，增長最快

## 關鍵財務數據（2025年）

- 全年收入：57.6億美元，同比-6.1%
- 正常化EBITDA：15.9億美元，同比-9.8%
- 歸母淨利潤：4.89億美元，同比-32.6%
- 分紅：7.5億美元（派息率153%）
- 中國區銷量：同比-3.9%，噸價同比-7.7%
