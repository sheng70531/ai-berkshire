# 萬洲國際（0288.HK）深度研究框架

> 研究日期：2026年5月16日 | 貨幣單位：美元（除港股股價為港元，雙匯數據為人民幣）

## 研究框架

本研究採用四維度並行分析框架，從商業模式、財務估值、行業競爭、風險管理四個角度對萬洲國際進行全方位評估：

| 文件 | 分析維度 | 核心問題 |
|------|---------|---------|
| 01-商業模式分析 | 好生意視角 | "雙匯+Smithfield"的全球豬肉帝國是否具備持續創造價值的能力？ |
| 02-財務估值分析 | 價值投資視角 | PE 5-6倍、股息率超8%，是價值陷阱還是撿便宜的機會？ |
| 03-行業競爭分析 | 護城河視角 | 全球最大豬肉公司的競爭壁壘是在加寬還是在消解？ |
| 04-風險管理層評估 | 風險視角 | 豬週期、中美關係、管理層傳承——哪個風險最值得警惕？ |

## 核心結論

**綜合評級：★★★★☆（4/5）— 全球豬肉龍頭，估值具備吸引力，但需關注豬週期下行風險**

萬洲國際是全球最大的豬肉食品公司，旗下擁有中國雙匯和美國Smithfield兩大核心資產。2025年全年收入280.26億美元（同比+8.0%），經營利潤26.12億美元（同比+8.7%）。Smithfield於2025年1月在納斯達克獨立上市（SFD），IPO後股價已上漲約55%，部分釋放了估值折價。

但挑戰同樣不可忽視：2026年豬價進入下行週期，4月現貨價一度跌破9元/公斤刷新歷史低點；中美貿易關係仍有不確定性；創始人萬隆已86歲，管理層代際交接仍在進行中。

**核心判斷**：萬洲國際是全球肉類行業中罕見的"中國+北美+歐洲"三大市場均有佈局的公司，Smithfield分拆上市後業務透明度顯著提升。當前港股股價約10.8港元，總市值約1,334億港元，對應2025年PE約10倍（分拆前口徑），若僅看萬洲國際剩餘的中國+歐洲業務，隱含估值更低。高股息（2024年合計派息每股0.5港元，含特別股息）提供一定安全墊。關鍵觀察點：（1）豬週期底部何時確認；（2）雙匯"四化"轉型成效；（3）Smithfield持股比例後續變化及估值聯動效應。

## 公司簡介

萬洲國際有限公司（WH Group Limited）是全球最大的豬肉食品公司，2014年在香港聯交所主板上市。公司通過2013年以47億美元收購Smithfield Foods完成全球化佈局，形成了覆蓋中國、北美、歐洲三大市場的豬肉全產業鏈體系。

**核心資產**：
- **雙匯發展**（000895.SZ）：持股70.33%，亞洲最大肉製品加工企業，2025年營收594.6億元
- **Smithfield Foods**（SFD，納斯達克）：持股約80%，美國最大豬肉食品企業，2025年1月獨立上市
- **歐洲業務**：包括Argal集團（持股50.1%）及波蘭、羅馬尼亞、斯洛伐克、匈牙利等多國肉類加工資產
