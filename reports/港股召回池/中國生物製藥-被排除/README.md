## 研究概要

中國生物製藥是中國領先的製藥企業，正處於從仿製藥向創新藥全面轉型的關鍵階段。公司由謝氏家族第三代/第四代掌舵，2025年創新產品收入佔比已接近50%，集採對仿製藥業務的衝擊接近出清。

## 核心投資邏輯

**看多理由：**
- 創新轉型成效顯著，創新產品收入年增26%+
- 2025-2027年近20款創新產品待獲批，多個重磅品種
- 集採影響接近出清，利潤拐點已至
- 估值相對恆瑞醫藥有明顯折價

**看空理由：**
- ROE仍偏低（8%），資本效率待提升
- 24倍PE對應當前盈利能力並不便宜
- 創新藥競爭激烈，管線兌現存在不確定性
- 家族企業治理結構，年輕管理層經驗有限
