## 研究背景

港交所是教科書級的壟斷生意——香港唯一的交易所集團，同時是中國內地與全球資本市場之間最核心的連接節點。互聯互通機制（滬深港通）使其在全球資本配置中國資產的大趨勢中處於不可替代的位置。

2025年港交所業績創歷史新高：IPO融資額重回全球第一（2869億港元，同比+227%），現貨市場日均成交額達2315億港元（同比+89.5%），衍生品和商品市場同步創紀錄。

核心問題是：30倍PE買入一個增長中樞在10%-15%的壟斷資產，這個價格是否合理？
