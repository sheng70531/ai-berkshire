## 研究背景

金蝶國際是中國企業級SaaS領域的龍頭公司之一，經歷了從財務軟件到ERP再到雲SaaS的三次戰略轉型。公司於2025年首次實現扭虧為盈，標誌著雲轉型進入收穫期。當前市值約293億港元，對應2025年歸母淨利潤PE約150倍+。公司提出"AI優先、訂閱優先、全球化"三大核心戰略，2026年AI套件收入目標10億元。
