# 中國電信（0728.HK）投資研究

## 基本信息
- **公司名稱**：中國電信股份有限公司
- **股票代碼**：0728.HK
- **行業**：固網/移動通信
- **PE（TTM）**：~16倍
- **ROE**：~7%

## 2025年度核心財務數據
| 指標 | 數值 | 同比變化 |
|------|------|----------|
| 營業收入 | 5,239億元 | +0.7% |
| 服務收入 | 4,854億元 | +0.7% |
| 歸母淨利潤 | 332億元 | +0.5% |
| 天翼雲收入 | 1,207億元 | 快速增長 |
| 全年股息 | 每股0.272元 | 派息率75% |

## 投資亮點
1. 天翼雲/AI數據中心增長強勁（AIDC收入345億元）
2. 75%高派息率，股息收益率可觀
3. 從傳統運營商向"科技型企業"轉型
4. 低估值+穩定現金流

## 核心風險
1. 傳統通信業務增速見頂
2. 雲業務面臨阿里雲、華為雲激烈競爭
3. 5G大規模投資但ARPU提升有限
4. ROE僅7%，資本回報率偏低
