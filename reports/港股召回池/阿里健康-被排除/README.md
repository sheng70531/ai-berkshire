## 研究概要

阿里健康是阿里巴巴集團旗下的大健康平臺，依託天貓和淘寶的流量入口運營醫藥電商業務。公司營收突破300億但利潤率仍低，39倍PE反映了市場對增長的預期但也暗示了高估值風險。核心問題是：阿里健康的護城河到底有多深？

## 核心投資邏輯

**看多理由：**
- 醫藥電商滲透率仍在提升，行業空間廣闊
- 阿里生態流量入口是天然優勢
- 盈利拐點已至，淨利潤年增62%
- 服務化轉型（在線問診、慢病管理）打開第二增長曲線

**看空理由：**
- 39倍PE估值偏高，對應當前8%的ROE
- 護城河不深，京東健康在多維度勝出
- 依賴阿里生態，自身獨立價值有限
- 醫藥電商競爭激烈，盈利能力天花板不高
