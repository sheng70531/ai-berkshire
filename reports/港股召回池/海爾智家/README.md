# 海爾智家（6690.HK / 600690.SH）投資研究框架

> 研究日期：2026年5月16日 | 貨幣單位：人民幣（除特別註明）

## 研究對象概覽

海爾智家是全球化程度最深的中國家電企業，2025年營收首次突破3000億元（3023.47億元），海外收入1545.45億元，佔比51.1%，首次超過國內市場。公司旗下擁有海爾、卡薩帝、Leader、GE Appliances、Fisher & Paykel、Candy、AQUA七大全球品牌，在全球163個製造中心和126個營銷中心運營。港股當前PE約9.1倍，ROE 16.97%，股息率約5-6.5%（取決於H/A股及計算口徑）。

## 核心結論

**綜合評級：值得深入跟蹤，可逐步建倉 ★★★★☆（4/5）**

海爾智家是少數真正實現全球化自主品牌運營的中國製造企業。其優勢在於：全球七品牌矩陣覆蓋多元市場、本土化製造體繫有效對沖地緣風險、冰洗品類國內份額接近50%構成強壁壘、現金流紮實（經營現金流為淨利潤1.33倍）、股東回報持續提升（分紅比例從48%提至55%，規劃2028年不低於60%）。

主要顧慮包括：北美關稅政策不確定性對GE Appliances利潤的衝擊、國內白電市場弱復甦背景下增長動能放緩、"人單合一"模式在組織效率方面的爭議、以及港股流動性折價問題。

9倍PE買入一個全球化家電龍頭，安全邊際相對充足，但需密切關注北美關稅演進和國內需求恢復節奏。
