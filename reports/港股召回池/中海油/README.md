## 公司簡介

中國海洋石油有限公司是中國最大的海上油氣生產商，也是全球最大的獨立油氣勘探及生產公司之一。公司主要從事海上原油及天然氣的勘探、開發、生產及銷售，業務遍及中國海域及海外多個國家和地區。母公司為中國海洋石油集團有限公司（國務院國資委直屬央企）。

## 研究框架

本研究採用四維度並行分析：

1. **商業模式分析** — 聚焦生意本質、護城河、商業邏輯
2. **財務估值分析** — 聚焦盈利質量、資產負債表、估值安全邊際
3. **行業競爭分析** — 聚焦產業格局、競爭優勢、行業趨勢
4. **風險與管理層評估** — 聚焦核心風險、管理層能力、公司治理
