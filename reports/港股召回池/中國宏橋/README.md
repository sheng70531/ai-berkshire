## 公司簡介

中國宏橋是全球規模最大的電解鋁生產商之一，由"山東首富"張士平創立，現由其子張波掌舵。公司構建了從鋁土礦開採、氧化鋁生產、自備電力到電解鋁冶煉的完整一體化產業鏈，電解鋁產能約646萬噸，氧化鋁產能約2100萬噸。2025年實現營收1623.54億元，淨利潤226.36億元。

## 核心投資論點

- **全球最低成本電解鋁生產商之一**：2024年噸鋁成本約13232元，遠低於行業平均
- **產能天花板政策賦予稀缺性**：中國電解鋁產能上限4500萬噸，運行產能已達4410萬噸，新增空間極小
- **需求端結構性增長**：新能源汽車、光伏、儲能、AI數據中心帶來新增鋁需求
- **高分紅屬性**：2025年分紅比率約65%，末期股息每股1.65港元
- **海外資源儲備深厚**：幾內亞鋁土礦+西芒杜鐵礦+印尼氧化鋁
