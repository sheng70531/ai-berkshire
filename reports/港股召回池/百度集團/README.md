## 研究背景

百度處於一個關鍵的戰略轉折點：傳統搜索廣告業務持續下滑，AI新業務（智能雲、自動駕駛、大模型）快速增長但尚未完全彌補缺口。公司坐擁1590億淨現金，推出50億美元回購計劃和首次股息政策，同時推進崑崙芯分拆上市。

核心矛盾在於：這是一家擁有頂級AI技術儲備的公司，但在C端應用競爭中被字節、阿里超越，搜索基本盤被抖音/微信/小紅書蠶食，ROE長期低迷。投資者需要判斷的是：AI轉型能否在未來2-3年兌現為可持續的利潤增長。

## 關鍵數據速覽

**業務結構（2025年）：**
- 在線營銷服務（搜索廣告）：約770億元，同比下滑約15%
- AI雲業務：約280億元，同比增長34%
- 自動駕駛及其他AI：約120億元
- AI業務總收入佔比Q4達43%

**AI競爭位次（2026年5月）：**
- AI大模型應用：文心一言MAU約2億，落後於豆包（3.15億）和千問（2.03億）
- AI雲市場：百度智能雲以16.6%份額位居AI大模型解決方案第一
- 自動駕駛：蘿蔔快跑累計訂單超2000萬，全球第一梯隊
- AI芯片：崑崙芯國產第三（華為昇騰之後），啟動科創板+港股雙上市

**股東回報：**
- 50億美元回購計劃（約佔市值10%），有效期至2028年底
- 2026年首次派發股息
- 崑崙芯分拆上市（估值約210億元）
