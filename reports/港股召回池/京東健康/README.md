## 研究概要

京東健康是中國最大的醫藥電商和互聯網醫療平臺，依託京東自建物流體系和品質信任背書，收入規模遙遙領先。23倍PE對應26%的增速，PEG不到1，估值相對合理。核心問題是：高增長能否持續？互聯網醫療的護城河有多深？

## 核心投資邏輯

**看多理由：**
- 收入增速26%+利潤增速36%，增長強勁且加速
- 京東物流和品質口碑構成差異化壁壘
- 23倍PE對應高增速，PEG<1，估值合理
- 醫藥電商滲透率仍在提升，行業紅利期未結束

**看空理由：**
- ROE僅6%，資本效率偏低
- 自營重模式利潤率天花板不高
- 美團即時配送構成新威脅
- 依賴京東集團生態
