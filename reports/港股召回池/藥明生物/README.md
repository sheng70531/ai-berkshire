## 核心投資邏輯速覽

**看多理由**：
1. 全球生物藥CDMO行業長期增長確定性高（CAGR 10%+）
2. "跟隨並贏得分子"策略持續驗證，在手訂單237億美元提供強收入可見性
3. 複雜生物藥（雙抗、ADC）佔比超半數，技術壁壘持續提升
4. 2025年業績拐點確認，收入增長重回雙位數，毛利率顯著改善

**看空理由**：
1. 美國《生物安全法案》（BIOSECURE Act）2025年12月簽署，限制美國政府與中國CDMO合作
2. 創始人李革持續大額減持（持股從73.5%降至約12%），市場信心受損
3. 三星生物產能擴張激進（84.5萬升 vs 藥明58萬升），競爭格局惡化
4. ROE僅10.5%，資本回報率偏低，重資產模式的固有挑戰
