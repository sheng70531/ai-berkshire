## 公司簡介

聯想集團成立於1984年，由中國科學院計算技術研究所投資創辦。2004年收購IBM全球PC業務，成為全球化企業。目前是全球最大的PC廠商（市佔率25.4%），同時在服務器/基礎設施（ISG）和解決方案/服務（SSG）領域持續擴張。

三大業務板塊：
- **IDG（智能設備業務集團）**：PC、平板、手機等，核心利潤來源
- **ISG（基礎設施方案業務集團）**：服務器、存儲、AI基礎設施，高速增長但尚未穩定盈利
- **SSG（方案服務業務集團）**：IT服務與解決方案，高利潤率（22%+運營利潤率）

## 研究背景

全球PC龍頭，PE 10-12倍，ROE約20%（高槓桿驅動），低利潤率的組裝生意。近年AI浪潮下，ISG服務器業務高速增長，AI營收佔比升至32%。公司提出兩年內營收破1000億美元、淨利潤率超5%的目標。值得深入研究其商業模式的可持續性、AI轉型的真實含金量、以及當前估值是否充分反映了基本面。
