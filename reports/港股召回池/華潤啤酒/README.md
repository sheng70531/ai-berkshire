## 研究背景

華潤啤酒是中國啤酒行業銷量第一的龍頭企業，旗下擁有"雪花"品牌及喜力中國運營權。公司正處於高端化轉型的收穫期，中檔及以上產品銷量佔比已超過50%。

2025年年報是新任董事會主席趙春武接棒侯孝海後的首份年報。公司對白酒業務（金沙酒業）計提28.77億元商譽減值，一次性出清，導致報表淨利潤同比下降28.87%。但扣除減值後，歸母淨利潤57.24億元，同比增長19.6%，啤酒主業持續向好。

## 核心投資邏輯

1. **啤酒高端化進入收穫期**：次高檔及以上產品銷量持續中高單位數增長，喜力+老雪+紅爵增速強勁
2. **白酒減值出清後輕裝上陣**：28.77億商譽一次性減值，2026年白酒業務有望企穩
3. **強勁現金流+高分紅**：2024年經營現金流69.28億元（+67%），2025年派息率98.2%
4. **估值合理**：扣非PE約15倍，對應19-20% ROE，在消費龍頭中具備性價比
