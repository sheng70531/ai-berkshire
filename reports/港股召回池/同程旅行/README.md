## 投資背景

同程旅行是中國第三大OTA平臺（按GMV計約15%市場份額），獨佔微信錢包火車票/機票和酒店兩大入口，在非一線城市擁有超87%的用戶佔比。公司正從"下沉市場OTA"向"全場景旅行平臺"轉型，同時推進國際化和AI智能化佈局。

## 研究框架

本研究採用四大師分析框架，從不同投資視角進行深度研究：

1. **[商業模式分析 - 段永平視角](01-商業模式分析-段永平視角.md)**：聚焦商業本質、用戶價值、長期競爭力
2. **[財務估值分析 - 巴菲特視角](02-財務估值分析-巴菲特視角.md)**：聚焦財務質量、盈利能力、估值安全邊際
3. **[行業競爭分析 - 芒格視角](03-行業競爭分析-芒格視角.md)**：聚焦競爭格局、行業演變、逆向思維
4. **[風險管理層評估 - 李錄視角](04-風險管理層評估-李錄視角.md)**：聚焦管理層品質、風險敞口、長期結構性因素
