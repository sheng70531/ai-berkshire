## 研究背景

新奧能源是港股燃氣板塊的標杆民企，PE 9.9倍、ROE 15%的組合在公用事業中屬於優質水平。當前最大變量是新奧股份（600803.SH）對其發起的私有化收購：每股80港元對價（24.5港元現金+2.94股新奧股份H股），交易總規模約599億港元。私有化完成與否、完成後的整合效果，將深刻改變公司的投資邏輯。

本研究以"正反兩面、客觀不預設"為原則，逐一拆解商業模式、財務估值、行業競爭、風險管理層四個維度。
