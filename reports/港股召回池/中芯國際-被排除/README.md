## 研究背景

中芯國際是中國大陸規模最大、技術最先進的集成電路晶圓代工企業，2025年銷售收入93.27億美元（673億元人民幣），全球晶圓代工市場份額約4.8%，位居全球第二（僅次於臺積電）。公司處於美國實體清單制裁之下，同時受益於中國半導體國產替代大潮。當前估值處於歷史高位，市場給予大量"國產替代溢價"。

## 核心矛盾

1. **估值與盈利的巨大落差**：PE超100倍，ROE僅3%，市場定價隱含的增長預期極高
2. **戰略價值與財務回報的矛盾**：國家戰略資產 vs 股東實際回報為零
3. **擴產必要性與資本效率的矛盾**：每年80億美元資本開支 vs 50億元淨利潤
4. **技術突破敘事與商業化現實**：7nm良率突破 vs DUV多重曝光的高成本
