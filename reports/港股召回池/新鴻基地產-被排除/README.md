## 研究背景

**為什麼關注新鴻基地產？**

1. **極度折價**：PB約0.32倍，相當於用約三折買入淨資產，歷史罕見
2. **財務極保守**：淨負債率僅13.5%，遠低於行業平均，幾乎不存在財務風險
3. **穩定現金流**：年租金收入超120億港元，提供下行保護
4. **行業龍頭**：香港最大地產發展商，土地儲備在港約5,730萬平方呎
5. **宏觀拐點**：香港樓市撤辣後復甦，降息週期啟動，行業基本面改善

**核心疑問：**

- 深度折價是價值陷阱還是價值窪地？
- 香港樓市復甦能持續多久？
- 內地業務風險（貪腐事件、商業地產承壓）如何評估？
- 家族治理與接班問題是否構成長期隱患？
