## 核心觀察

**正面因素：** 全球化擴張勢頭強勁，IP戰略轉型成效顯著，供應鏈優勢深厚，高ROE+高股東回報。

**負面因素：** 永輝投資拖累報告利潤，資產負債率因收購大幅攀升，國內同店增長承壓，加盟模式爭議。
