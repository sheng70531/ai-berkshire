## 核心結論

**綜合評分：★★★★☆（4/5）**

**判斷：觀望，等待更好買入價格**

寧德時代是全球動力電池領域的絕對龍頭，2025年營收4237億元人民幣，歸母淨利潤722億元，ROE連續4年超24%，經營現金流達1332億元。公司在技術（6萬+專利）、規模（772GWh產能）、客戶（綁定全球主流車企）三個維度構建了極深的護城河。2026年Q1更以50.1%的國內市佔率重返巔峰。

**核心優勢**：技術領先（麒麟電池、神行超充、鈉離子電池）、規模效應顯著、客戶粘性極強、自由現金流充沛（年分紅率50%+回購）。

**核心風險**：曾毓群"關鍵人依賴"（接班人尚未明確）、美國CMC清單帶來的地緣政治不確定性、電池技術路線變革風險（固態電池）、行業產能過剩壓力。

**估值判斷**：當前A股PE約29倍（對應2025年利潤），若以2026年預期淨利潤960-980億元計算，動態PE約19-20倍，處於合理區間。但考慮到地緣風險和行業競爭加劇，理想買入價位應在15-17倍動態PE，即A股350-380元人民幣區間，對應港股需折價約15-20%。
