## 研究背景

紫金礦業是中國最大的金屬礦業企業，也是全球成長最快的礦業公司之一。公司以金、銅、鋅為核心，輔以銀、鋰、鉬等礦種，在全球十餘個國家擁有重要礦業投資。2025年歸母淨利潤首次突破500億元，達518億元，同比增長62%；ROE位居全球金屬礦企第一。

研究切入點：公司處於"創始人交班+產能擴張+金銅價高位"的三重疊加期，估值21倍PE看似不貴，但礦業股的週期屬性要求更審慎的評估框架。

## 研究框架

本研究採用四維度並行分析法：

| 文件 | 分析維度 | 核心問題 |
|------|----------|----------|
| 01-商業模式分析 | 生意本質與護城河 | 這門生意好不好？能不能持續？ |
| 02-財務估值分析 | 數字驗證與估值 | 賺的錢是不是真金白銀？貴不貴？ |
| 03-行業競爭分析 | 競爭格局與產業鏈 | 行業結構對誰有利？壁壘在哪裡？ |
| 04-風險管理層評估 | 風險與人的因素 | 最大的風險是什麼？管理層值不值得信任？ |
| 最終報告 | 綜合判斷 | 值不值得長期持有？ |
