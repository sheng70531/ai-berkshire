# 華潤電力（0836.HK）：財務與估值分析

> 分析維度：盈利質量、資產負債、現金流、估值與安全邊際
> 研究日期：2026年5月16日

---

## 一、盈利能力分析

### 1.1 收入與利潤趨勢

華潤電力近三年的財務表現呈現"先揚後穩"的特徵：

| 指標 | 2023年 | 2024年 | 2025年 |
|------|--------|--------|--------|
| 營業額（億港元） | 1,033 | 1,052.8 | 1,020.1 |
| 歸母淨利潤（億港元） | 110 | 143.9 | 145.2 |
| 核心業務利潤（億港元） | — | 138.7 | 152.4 |
| 火電核心利潤（億港元） | 36 | 46.4 | 76.4 |
| 新能源核心利潤（億港元） | 97 | 92.3 | 76.0 |
| 每股盈利（港元） | 2.11 | 2.77 | 2.80 |

幾個關鍵觀察：

**正面信號**：
- 核心業務利潤增長9.9%至152.4億港元，說明經營質量在提升
- 火電盈利大幅修復（+64.7%），煤價下行紅利充分體現
- 整體盈利保持了穩定性，沒有出現大幅波動

**負面信號**：
- 營業額同比下降3.1%，上網電價下行（綜合均價降幅7.9%）抵消了發電量增長（+7.0%）
- 新能源利潤下滑17.6%，這是一個值得警惕的信號——裝機在增長，利潤在萎縮
- 歸母淨利潤僅增長0.9%，扣除火電的週期性修復後，增長質量堪憂

### 1.2 盈利能力指標

| 指標 | 2023年 | 2024年 | 2025年（估） |
|------|--------|--------|-------------|
| ROE | 13.2% | ~14% | ~12% |
| EBITDA（億港元） | — | 389.6 | ~400 |
| 淨利率 | 10.7% | 13.7% | 14.2% |
| 毛利率（新能源） | — | ~58% | ~56% |

ROE維持在12-14%的水平，在公用事業板塊屬於中上，但遠不及優秀消費或科技企業的20%+。問題在於，ROE的提升很大程度上依賴於槓桿——67%以上的資產負債率意味著股東權益只佔三成，放大了權益回報。如果用"真實資產回報率"（ROA）來看，畫面遠沒有那麼好看。

新能源業務近60%的毛利率看起來很漂亮，但要注意這是"會計毛利率"——新能源的成本主要在折舊而非變動成本，高毛利率並不代表高現金回報。

### 1.3 利潤的"含金量"

2025年有一個重要的會計調整影響：新能源補貼相關的一次性會計估計調整拖累了新能源利潤。剔除這一因素後，新能源的經營利潤下滑幅度會小一些，但電價下行和棄風棄光的影響是實實在在的。

火電利潤的大幅增長（+64.7%）更多是週期性的——2022-2023年煤價高位時火電利潤被壓縮，2024-2025年煤價回落後利潤彈性釋放。這種"均值迴歸"式的增長不應被外推。

## 二、資產負債表分析

### 2.1 資產結構

華潤電力是典型的重資產企業。截至2023年末（最近完整披露數據），總資產約3,200億港元，其中固定資產和在建工程佔據絕大部分。2025年中期總資產已增至3,468億港元。

資產端的核心關注點：

**新能源資產質量**：2025年上半年，新能源資本開支約158億港元，全年預計420億港元。這些資產能否在電價持續下行的環境中產生足夠回報？如果未來電價進一步下降10-15%，部分項目的IRR可能跌破資金成本。

**可再生能源補貼應收款**：這是電力行業的一個"暗雷"。雖然華潤的補貼欠款數據未單獨披露，但整個行業的補貼拖欠問題由來已久，華潤新能源IPO審核中也被問及此問題。補貼應收款如果出現減值，將直接衝擊利潤和資產。

### 2.2 負債結構

| 指標 | 數據 |
|------|------|
| 總負債 | ~2,178億港元（2023年末） |
| 資產負債率 | ~67.4% |
| 歸母淨資產 | ~850億港元 |

67%以上的資產負債率在電力行業屬於正常水平，但絕對水平不低。華潤電力每年568億港元的資本開支，大部分依賴債務融資，槓桿率有進一步上升的壓力。

**積極因素**：央企AAA信用評級，融資成本遠低於行業平均。這是華潤電力相對於民營新能源企業的核心競爭優勢之一。

**風險因素**：如果利率環境變化或信用市場收緊，高槓桿將放大財務風險。不過，考慮到當前中國處於降息週期，短期內這個風險可控。

### 2.3 資本效率

華潤電力的"資本回收週期"較長。以新能源項目為例：假設一個風電項目投資10億，年發電收入1.5億，扣除運維和利息後淨收入約0.5億，簡單回收期約20年。這意味著公司需要不斷投入新資本才能維持增長，而舊項目的回報在電價下行環境中可能不斷被侵蝕。

這種"跑步機效應"是重資產行業的通病：你不能停下來，因為折舊在消耗存量資產價值；但你越跑越快，資本需求越來越大。

## 三、現金流分析

### 3.1 經營現金流

華潤電力的經營現金流相對穩健，EBITDA約400億港元，經營現金流大致在250-300億港元區間（扣除營運資金變動和稅費後）。

### 3.2 自由現金流

這是巴菲特最關注的指標——自由現金流 = 經營現金流 - 資本開支。

以2025年為例：
- 經營現金流：約250-300億港元
- 資本開支：約568億港元
- **自由現金流：約-270至-320億港元**

沒錯，華潤電力目前是**自由現金流為負**的。公司賺的錢不夠投的，缺口靠借錢來填補。這是"成長型公用事業"的典型困境——為了未來的裝機增長，當前在大量燒錢。

**這對估值意味著什麼？**

如果按DCF（現金流折現）模型來估值，華潤電力在未來5-8年內的自由現金流可能持續為負或極低。公司的價值更多依賴於"未來某一天資本開支放緩後釋放出來的現金流"。這使得DCF估值對假設極度敏感，不確定性很大。

### 3.3 股息可持續性

2025年每股派息1.127港元，派息率40.2%，股息率5.7%。在自由現金流為負的情況下，股息本質上是通過"借錢分紅"來實現的。這並非不可持續——只要公司能持續融資，就能持續分紅——但它依賴於資本市場的持續支持和信用評級的維持。

## 四、估值分析

### 4.1 當前估值水平

| 指標 | 數據 |
|------|------|
| 股價 | 18.26港元 |
| 市值 | 941億港元 |
| PE（TTM） | ~7.1倍 |
| PB | ~1.0倍 |
| 股息率 | 5.7% |
| EV/EBITDA | ~6倍 |

### 4.2 估值是否便宜？

**看起來便宜的理由**：
- PE 7倍在全球公用事業板塊中屬於偏低水平
- 股息率5.7%顯著高於港股平均和國債收益率
- PB約1倍，接近淨資產
- 分析師目標價均值21.3港元，隱含17%上漲空間

**可能不便宜的理由**：
- 自由現金流為負，PE的"分母"（利潤）並不完全屬於股東
- 火電利潤中有較大週期性成分，如果煤價回升，利潤可能回落
- 新能源利潤增速在放緩，電價下行趨勢尚未見底
- 中國電力行業整體PE中樞偏低，7倍PE在同行中並不算特別便宜

### 4.3 華潤新能源分拆的估值影響

華潤新能源A股IPO募資245億元，已獲證監會註冊。分拆上市對母公司華潤電力有幾層影響：

**正面**：
- A股給新能源資產的估值通常遠高於港股，分拆可以釋放被港股低估的價值
- 245億募資將直接降低華潤新能源的資產負債率，改善財務結構
- 母公司仍持有控股權，可以並表

**風險**：
- 分拆後母公司剩餘資產主要是火電，可能面臨"好資產被拿走"的估值折價
- 新能源業務獨立後與火電的協同效應可能削弱
- A股IPO市場變數仍多，發行定價和節奏可能不及預期

### 4.4 安全邊際評估

按巴菲特的"安全邊際"框架：

**樂觀情景**（30%概率）：煤價持續低位、電價企穩、新能源消納改善，2026年利潤增長15-20%，對應PE 6倍，加上分拆催化，股價有30-40%上漲空間。

**基準情景**（50%概率）：煤價小幅回升、電價溫和下行、新能源利潤持平，2026年利潤持平或微增，股價在當前水平附近波動，賺取5-6%的股息收益。

**悲觀情景**（20%概率）：煤價大幅反彈、電價加速下跌、棄風棄光惡化，2026年利潤下滑15-20%，股價可能回落至15-16港元區間。

綜合來看，當前估值提供了"有限的安全邊際"——不是特別便宜，但也不貴。下行空間約10-15%，上行空間約20-30%，風險收益比尚可。

## 六、小結

華潤電力的財務畫面是一個"矛盾體"：利潤表看起來還不錯（145億利潤，12%的ROE），但現金流量表暴露了問題（自由現金流為負，大量資本開支）。資產負債表處於可控但不算舒適的狀態（67%負債率）。

從巴菲特的視角看，華潤電力不是一家"優秀"的企業——它賺的錢幾乎全部（甚至更多）要重新投入到生意中去，股東拿到的真實回報遠低於賬面利潤所暗示的。但在7倍PE和5.7%股息率的估值下，它可能是一個"合理價格買合理企業"的機會——前提是投資者對電力行業的長期需求增長和華潤的運營效率有足夠信心。
