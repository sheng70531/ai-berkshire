## 公司簡介

華潤電力是華潤集團旗下電力業務旗艦上市平臺，業務涵蓋火力發電、風電、光伏發電、水電、分佈式能源、售電、綜合能源服務及煤炭等領域。截至2025年底，公司管理併網裝機規模突破1億千瓦，可再生能源裝機佔比超過50%，標誌著公司從傳統火電企業向綜合清潔能源運營商的戰略轉型取得里程碑式進展。

## 核心投資邏輯

**看多理由**：
1. 火電盈利修復 + 容量電價機制保障基本收益
2. 新能源裝機快速增長，規模效應逐步顯現
3. 華潤新能源分拆A股上市（245億募資已獲註冊），釋放價值
4. PE 7倍、股息率5.7%，估值具備安全邊際
5. 央企背景，融資成本優勢明顯

**看空理由**：
1. 綠電電價持續下行，新能源利潤增速承壓
2. 棄風棄光率上升，消納問題日益突出
3. 大規模資本開支推高負債率，自由現金流承壓
4. 電力市場化改革深化，電價不確定性增加
5. 新能源補貼欠款風險尚未完全消除
