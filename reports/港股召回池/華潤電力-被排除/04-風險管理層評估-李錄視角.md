# 華潤電力（0836.HK）：風險與管理層評估

> 分析維度：下行風險、管理層能力、治理結構、央企特殊性
> 研究日期：2026年5月16日

---

## 一、風險全景掃描

李錄的投資框架強調"先看風險，再看機會"。對華潤電力而言，風險可以分為三個層次：致命風險、重大風險和可控風險。

### 1.1 致命風險：有沒有能讓公司"死掉"的因素？

**答案：沒有。**

華潤電力作為央企控股的大型電力企業，幾乎不存在破產風險。理由如下：
- 電力是國家安全和經濟運行的基礎設施，不可能被允許倒閉
- 華潤集團（母公司）總資產超2萬億港元，有充足的資源支持
- 央企AAA信用評級，融資渠道暢通
- 電力資產有實物價值託底

但"不會死"不等於"投資者不會虧錢"。公司可以不倒閉，股價卻可以長期低迷。

### 1.2 重大風險：可能導致利潤大幅下滑的因素

**風險一：綠電電價持續下行 [影響程度：★★★★★]**

這是當前華潤電力面臨的最核心風險。數據觸目驚心：
- 風電均價：從0.45元 -> 0.44元 -> 0.35元/千瓦時（兩年降幅22%）
- 光伏均價：從0.37元 -> 0.32元 -> 0.28元/千瓦時（兩年降幅24%）

136號文要求新能源全面參與市場化交易後，綠電定價的"保護傘"正式消失。在新能源裝機增速遠超需求增速的背景下，電價下行的壓力是結構性的，不是週期性的。

華潤電力2025年新能源核心利潤已經同比下滑17.6%。如果電價再跌15-20%，新能源業務的利潤可能腰斬。

**風險二：棄風棄光問題加劇 [影響程度：★★★★☆]**

華潤新能源的棄風棄光率數據令人擔憂：
- 棄風率：2.80% -> 4.16% -> 5.26%（逐年上升）
- 棄光率：1.52% -> 6.59% -> 12.73%（急劇惡化）

棄光率在兩年內從1.52%飆升至12.73%，意味著每100度光伏發電有近13度被浪費。這直接降低了光伏項目的實際收益率。

消納問題的根源在於電網建設滯後於新能源裝機。解決這個問題需要鉅額電網投資和儲能配置，這不是華潤電力單方面能解決的。

**風險三：煤價反彈風險 [影響程度：★★★☆☆]**

2025年火電利潤大增64.7%，主要受益於煤價下行。2026年行業預判動力煤價格中樞可能"小幅上移"。火電業務的利潤對煤價極度敏感——煤價每上漲50元/噸，可能吃掉十幾億的利潤。

不過，容量電價政策的調整（回收比例提至50%）為火電利潤提供了一定緩衝。即使煤價回升，火電也不太可能重演2021-2022年的大幅虧損。

**風險四：新能源補貼減值 [影響程度：★★★☆☆]**

可再生能源補貼欠款是整個行業的歷史遺留問題。華潤新能源IPO審核中，監管部門對此進行了重點問詢。如果部分項目最終無法納入補貼清單或補貼政策進一步變化，公司面臨確認部分收入減值或退回補貼款的風險。

具體金額未完全披露，但考慮到華潤新能源的規模，潛在影響可能達數十億級別。

**風險五：資本開支失控 [影響程度：★★★☆☆]**

2025年全年資本開支568億港元，其中420億用於新能源。在電價下行、消納困難的環境下，大規模資本開支是否理性？

這涉及到一個根本問題：華潤是在"理性投資"還是在"完成任務"？央企的裝機指標有一定的政治任務屬性，管理層可能在明知回報率下降的情況下仍需推進項目。

### 1.3 可控風險

**利率風險**：高槓桿企業天然對利率敏感。但當前中國處於降息週期，短期利率風險偏低。

**政策變動風險**：電力行業政策頻繁調整，但總體方向（市場化+清潔化）是明確的。政策風險更多是"節奏"和"力度"的問題，而非方向性逆轉。

**匯率風險**：港元計價資產，人民幣收入，存在一定匯率錯配。但華潤的大部分資產和負債都在境內，匯率影響有限。

## 二、管理層評估

### 2.1 管理層架構

華潤電力的管理架構為"集團控股 + 職業經理人"模式：
- **控股方**：華潤（集團）有限公司，國務院國資委直管央企
- **集團董事長**：王祥明
- **華潤電力總裁**：王波（2024年12月獲委任）

王波作為新任總裁，在2025年3月工作會議上提出了"十五五"規劃方向，聚焦清潔高效發電、綜合能源服務、能源科技創新三大板塊。

### 2.2 央企管理層的特殊性

從李錄的視角看，管理層評估需要特別關注"管理層與股東利益是否一致"。央企管理層有其獨特性：

**優勢**：
- **職業化程度高**：央企高管通常有豐富的行業經驗和專業背景
- **長期視角**：不像民企創始人可能有套現衝動，央企管理層考核注重長期可持續發展
- **資源調動能力強**：能夠通過集團和政府關係獲取優質資源

**劣勢**：
- **激勵不足**：央企高管的薪酬與市場化企業相比偏低，股權激勵有限，缺乏"做大蛋糕"的強烈動力
- **輪崗制度**：央企高管通常3-5年輪崗一次，"鐵打的公司流水的管理層"導致戰略的連續性和深度執行存在不確定性
- **多目標約束**：管理層需要同時滿足國資委考核（利潤、安全、社會責任）、政治要求（裝機指標、碳達峰任務）和市場預期（股價、分紅），多目標之間可能衝突
- **決策效率**：重大投資決策需要層層審批，反應速度不及民企

### 2.3 管理層的戰略判斷力

華潤電力過去幾年的幾個關鍵戰略決策值得覆盤：

**做對的事情**：
1. **提前佈局新能源**：2019年就開始加速風光佈局，先發優勢明顯，搶佔了較多優質風光資源
2. **分拆新能源上市**：在A股市場對新能源資產高估值的窗口期推進IPO，時機選擇不錯
3. **保留火電底倉**：沒有像某些企業那樣"all in"新能源，保持了火電+新能源的均衡配置

**值得商榷的**：
1. **裝機速度是否過快**：在棄風棄光率快速上升的背景下，2025年仍規劃新增10GW風光裝機，是否存在"為增長而增長"的傾向？
2. **資本開支管理**：568億年度資本開支對應145億利潤，資本投入產出比偏低
3. **電價風險對沖**：面對綠電電價持續下行，公司似乎缺乏有效的風險對沖手段

### 2.4 資本配置能力

這是李錄最關注的管理層能力之一——公司賺了錢後怎麼花？

華潤電力的資本配置優先級大致是：
1. **新能源投資**（約420億/年）：最大的資金去向
2. **分紅**（約58億港元）：派息率40.2%
3. **火電運維和升級**（約100-150億/年）
4. **債務償還**：淨負債實際在增加

問題在於：在新能源回報率下行的趨勢中，將70%以上的資本開支投向新能源是否是最優選擇？是否應該提高分紅比例、回購股份或減緩投資節奏？

央企的回答往往是"這是國家戰略，必須投"。但對小股東而言，"國家利益"和"股東利益"不總是一回事。

## 三、治理結構評估

### 3.1 股權結構

華潤（集團）有限公司持有華潤電力約62.95%的股權，處於絕對控股地位。這種高度集中的股權結構有利有弊：

**利**：大股東利益與公司利益高度綁定，不存在"野蠻人"入侵的風險，戰略方向明確。

**弊**：小股東話語權有限，大股東可能通過關聯交易、資源調配等方式影響上市公司利益。

### 3.2 關聯交易風險

作為華潤集團旗下的上市平臺，華潤電力與集團之間存在大量關聯交易（煤炭採購、資產注入、管理費等）。需要持續關注關聯交易是否公允。

### 3.3 信息披露質量

華潤電力的信息披露總體規範，作為港股上市公司，需遵守港交所的披露規則。但與A股公司相比，港股在季度數據披露頻率和細度上有所不足。

### 3.4 華潤新能源IPO相關風險

華潤新能源IPO審核中，深交所提出了兩輪問詢，關注點包括：
- 200+條行政處罰記錄
- 可再生能源補貼確認的合規性
- 關聯交易的公允性
- 盈利可持續性（2025年淨利潤同比下滑23.27%至61.02億元）

這些問詢揭示了一些此前在港股財報中不夠透明的風險點，值得投資者重視。

## 四、"買股票就是買人"——綜合評判

李錄強調"買股票就是買人"，但對央企而言，"人"的因素既重要又有限：

**重要的是**：管理層的戰略方向、執行效率和資本配置能力
**有限的是**：個人能力在央企體制中的發揮空間受限於制度框架

華潤電力的管理層在戰略方向上沒有犯大錯——提前佈局新能源、推進分拆上市、保持均衡配置。但在"為股東創造價值"方面，央企管理層天然缺乏足夠的激勵去最大化股東回報。

對於華潤電力這樣的央企，投資者不應期望管理層有"創業者"般的激情和魄力。合理的期望是：管理層能夠（1）避免重大戰略失誤，（2）保持運營效率在行業前列，（3）維持合理的分紅水平。從目前的表現看，這三點大體滿足。

## 六、小結

從李錄的投資哲學出發，投資華潤電力的核心問題是：**在這個價格下，風險是否被充分補償？**

**風險端**：電價下行、消納困難、資本開支過大是三個切實的威脅，可能導致未來2-3年利潤增速低於預期甚至下滑。央企管理層的激勵機制也意味著"為股東利益最大化"不是第一優先級。

**補償端**：7倍PE和5.7%股息率提供了一定的緩衝。更重要的是，華潤電力不會"死"——最壞的情況是利潤下滑20-30%，對應PE也只是從7倍上升到9-10倍，仍在合理範圍內。

**結論**：華潤電力是一個"風險有限、回報也有限"的標的。它適合追求穩定收益（股息+溫和增長）的投資者，但不太適合追求高成長、高彈性的投資者。關鍵的決策變量是——你對中國電力行業電價走勢的判斷，以及你對"央企治理折價"的容忍程度。
