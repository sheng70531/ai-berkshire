## 投資背景

理想汽車是中國領先的新能源汽車企業，以增程式電動SUV起家，憑藉精準的產品定義和家庭用戶定位，在2023-2024年實現高速增長。但2025年遭遇重大挫折：MEGA純電旗艦失利、增程市場競爭加劇、全年交付同比下滑近19%，淨利潤暴跌86%。2026年公司正處於"增程+純電"雙輪驅動轉型期，面臨激烈競爭和盈利能力修復的雙重挑戰。
