# 中國平安：財務估值分析——價值投資視角

> 核心問題：當前價格是否提供了足夠的安全邊際？內在價值幾何？

### ROE分析

中國平安的ROE長期維持在較高水平：

| 年份 | 估算ROE | 說明 |
|------|--------|------|
| 2016-2018 | 18%-22% | 行業景氣高峰期 |
| 2019-2020 | 16%-20% | 疫情前維持高位 |
| 2021-2022 | 10%-13% | 華夏幸福減值+疫情衝擊 |
| 2023 | ~14% | 開始修復 |
| 2024 | ~16% | 持續改善 |
| 2025 | ~14% | 歸母淨利潤1,348億/歸母權益10,004億 |

**評價：** 即使在最困難的2021-2022年（華夏幸福減值+疫情），ROE仍在10%以上。2025年ROE約14%，考慮到淨資產首破萬億的高基數，這個水平相當不錯。券商預測2026-2031年平均ROE大概率在13.5%-16.5%區間。

### 資產負債分析

保險公司的資產負債結構與一般企業截然不同——高槓桿是行業特徵，關鍵看償付能力和資產質量：

- **保險資金投資規模：** 6.49萬億元人民幣，較年初增長13.2%
- **償付能力充足率：** 滿足監管要求（具體數字需查年報詳細披露）
- **華夏幸福風險敞口：** 累計約540億元人民幣，已減值約432億元人民幣，剩餘敞口約108億元人民幣——這顆"雷"已基本消化

## 二、10年財務趨勢

### 利潤增長軌跡

| 階段 | 時期 | 特徵 | 驅動力 |
|------|------|------|--------|
| 高速增長期 | 2015-2018 | 淨利潤從542億增至1,074億元人民幣 | 代理人擴張+投資牛市 |
| 見頂回落期 | 2019-2020 | 淨利潤維持在1,400-1,600億元人民幣 | 代理人紅利見頂 |
| 陣痛調整期 | 2021-2022 | 淨利潤降至700-1,000億元人民幣 | 華夏幸福減值+壽險改革+疫情 |
| 修復回升期 | 2023-2025 | 淨利潤從856億回升至1,348億元人民幣 | 改革紅利+投資收益改善 |

**關鍵轉折點：** 2021年是分水嶺。華夏幸福爆雷導致約540億元人民幣減值，疊加行業代理人大規模出清（平安代理人從120萬+降至約35萬），利潤大幅下滑。但從2023年開始，"減員增效"的效果開始顯現——代理人人均產能大幅提升，NBV重回增長軌道。

### NBV增長趨勢（關鍵指標）

NBV（新業務價值）是衡量壽險公司未來盈利能力的領先指標：

- 2020年：NBV 495億元人民幣（高點）
- 2021-2022年：持續下滑
- 2023年：觸底回升
- 2024年：NBV 286億元人民幣，+28.8%
- 2025年：NBV 369億元人民幣，+29.3%
- 2026Q1：NBV 156億元人民幣，+20.8%

**評價：** NBV已連續兩年以接近30%的速度增長，2026Q1保持20%以上增速。這是壽險改革成效最硬核的證據。

## 三、內在價值估算

### 方法一：內含價值法（P/EV）

內含價值（Embedded Value, EV）是保險公司最核心的估值錨點。

| 指標 | 數值 |
|------|------|
| 2025年集團EV | 約1.5萬億元人民幣（EV同比+5.7%，壽險EV同比+11.2%） |
| 當前市值（港股） | 約8,400億元人民幣 |
| P/EV | 約0.56-0.60倍 |
| 歷史P/EV中樞 | 1.0-1.2倍（近5年） |
| 如果迴歸0.8倍P/EV | 對應市值約1.2萬億元人民幣，較當前上漲約43% |
| 如果迴歸1.0倍P/EV | 對應市值約1.5萬億元人民幣，較當前上漲約79% |

**關鍵假設風險：** EV的計算依賴精算假設。2025年平安已審慎下調長期投資回報率假設至4.5%、風險貼現率至9.5%。假設下調後的EV更加可靠——這反而是利好，因為說明當前EV的"水分"已被擠出。

### 方法二：分部估值法（SOTP）

將中國平安拆分為各業務板塊單獨估值：

| 業務板塊 | 估值依據 | 保守估值 | 合理估值 |
|---------|---------|---------|---------|
| 壽險及健康險 | 0.6-0.8倍壽險EV | ~6,000億元 | ~8,000億元 |
| 財產保險 | 10-12倍淨利潤 | ~1,500億元 | ~2,000億元 |
| 平安銀行 | 0.5-0.6倍PB | ~1,500億元 | ~1,800億元 |
| 資管+科技+其他 | 參考可比公司 | ~500億元 | ~1,000億元 |
| **集團合計** | | **~9,500億元** | **~12,800億元** |
| 減：集團折價（10-15%） | | **~8,100億元** | **~11,500億元** |

*注：以上為人民幣估值，均為粗略估算*

**對比當前市值約8,400億元人民幣：** 保守情景下接近當前市值，合理情景下有37%上行空間。

### 方法三：股息貼現模型（DDM）

| 假設 | 數值 |
|------|------|
| 2025年每股分紅 | 2.70元人民幣 |
| 未來5年分紅增速假設 | 5%（保守） |
| 之後永續增速 | 3% |
| 貼現率 | 10% |
| 每股內在價值 | 約38-42元人民幣（A股） |
| 對應港股（按0.9折算） | 約34-38港幣 |

**對比當前港股股價（約46港幣）：** DDM方法下，當前股價略高於純股息價值——但這是極保守的假設（僅5%分紅增速），如果分紅增速達到8%，內在價值將顯著提升。

### 方法四：簡單PE估值

| 指標 | 數值 |
|------|------|
| 2025年歸母淨利潤 | 1,348億元人民幣 |
| 2025年營運利潤 | 1,344億元人民幣 |
| 當前港股市值 | ~8,400億元人民幣 |

## 四、安全邊際判斷

### 多維度安全邊際檢驗

| 維度 | 當前值 | 歷史均值 | 安全邊際 |
|------|--------|---------|---------|
| P/EV | 0.56-0.60x | 1.0-1.2x | 有較大安全邊際 |
| PE | 6-9x | 8-10x | 有一定安全邊際 |
| PB | ~0.75x | 1.2-1.5x | 有較大安全邊際 |
| 股息率 | ~6%+ | 3-4% | 高股息提供下行保護 |

### 正面論據（支持安全邊際充足）：

1. **P/EV處於歷史極值區域。** 0.6倍P/EV意味著市場認為平安的內含價值要打6折才值得買——這隱含了"永久性價值毀滅"的預期。只要這個預期不成真，估值就有修復空間。

2. **6%+的股息率提供了"安全墊"。** 即使股價不漲，6%以上的股息率也遠超存款利率和國債收益率。在中國資產荒的大背景下，這個收益率具有吸引力。

3. **NBV高增長尚未在估值中體現。** NBV連續兩年增長近30%，說明公司"新增的"價值創造能力在快速恢復，但P/EV仍在歷史低位——這是錯配。

4. **華夏幸福減值已基本消化。** 540億元人民幣的減值中已完成432億元人民幣，剩餘108億元人民幣對萬億級淨資產的影響已經可控。

### 負面論據（安全邊際可能不如看上去那麼大）：

1. **低利率可能是"永久性"的。** 如果中國長期利率持續走低（類似日本），保險公司的投資收益率將長期承壓。2026Q1綜合投資收益率已降至0.2%（非年化），同比大幅下降1.1個百分點。

2. **EV的可信度本身有爭議。** 內含價值的計算依賴大量精算假設，如果實際投資收益率長期低於4.5%的假設，EV就需要下調——P/EV的"安全邊際"就是鏡花水月。

3. **銀行子公司拖累估值。** 平安銀行淨利潤已連續下降，如果銀行業務持續惡化，可能需要從集團層面補充資本，稀釋股東回報。

4. **淨利潤vs營運利潤的差異。** 2026Q1淨利潤下降7.4%但營運利潤增長7.6%——短期無礙，但如果投資端長期承壓，兩者最終會趨同。

## 五、財務估值總結

| 維度 | 評分 | 說明 |
|------|------|------|
| 盈利能力 | ★★★★ | ROE 14%，營運利潤雙位數增長 |
| 成長性 | ★★★★ | NBV增速近30%，改革紅利持續 |
| 資產質量 | ★★★ | 華夏幸福基本消化，但低利率風險持續 |
| 估值水平 | ★★★★★ | P/EV 0.6倍、PE 6倍，處於歷史極值 |
| 股東回報 | ★★★★★ | 股息率6%+，連續14年增長 |
| **綜合評分** | **★★★★** | **估值具有較大安全邊際，但需關注利率風險** |

**核心判斷：** 用巴菲特的話說，"以合理的價格買入優秀的公司，遠好於以優秀的價格買入合理的公司。" 中國平安當前的情況是——以優秀的價格買入優秀的公司。0.6倍P/EV、6倍PE、6%+股息率，這個價格已經為大部分風險買了單。關鍵變量是：低利率環境是否會長期化到足以實質性侵蝕內含價值的程度。
