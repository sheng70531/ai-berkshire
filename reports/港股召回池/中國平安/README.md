## 核心結論

**綜合評分：★★★★（4/5）**

中國平安是中國最大的綜合金融集團，坐擁2.51億個人客戶、13張核心金融牌照、6.49萬億元保險資金。2025年歸母淨利潤1,348億元人民幣，歸母權益首破萬億。壽險新業務價值（NBV）同比增長29.3%，改革紅利正在兌現。

**核心矛盾：估值折價vs經營改善。** 港股當前交易於約0.6-0.75倍P/EV（內含價值），靜態PE約5-9倍，PB約0.75倍——這是一個隱含了"永久性價值毀滅"預期的價格。但事實是：公司連續14年提升分紅，2025年現金分紅489億元人民幣；壽險改革已見成效，NBV增速領跑行業；利差損風險管理層明確表示不存在。

**關鍵判斷：** 當前估值更接近"世紀機會"而非"價值陷阱"，但需密切關注低利率環境下投資端壓力和地產敞口消化進展。建議在當前估值區間分批建倉，核心假設是壽險改革持續兌現+估值從極端低位向均值迴歸。

**主要風險：** 長期低利率侵蝕投資收益、地產敞口殘餘風險、管理層接班過渡期不確定性。
