# 中國聯通（0762.HK）投資研究

## 基本信息
- **公司名稱**：中國聯合網絡通信股份有限公司
- **股票代碼**：0762.HK
- **行業**：移動通信
- **PE（TTM）**：~15倍
- **ROE**：~5.7%

## 2025年度核心財務數據
| 指標 | 數值 | 同比變化 |
|------|------|----------|
| 營業收入 | 3,922億元 | +0.7% |
| 服務收入 | 3,477億元 | +0.5% |
| 歸母淨利潤 | 91.3億元（A股）/ 股東應佔208億元（港股） | +1.0-1.1% |
| 淨資產收益率 | 5.7% | 穩定 |
| 5G專網收入 | 123億元 | +51% |

## 投資亮點
1. 混改紅利尚存，與BAT深度合作
2. 5G專網/物聯網/車聯網高速增長
3. 算力投資佔比提升至35%+
4. 估值在三大運營商中相對合理

## 核心風險
1. ROE僅5.7%，三大運營商中最低
2. 移動用戶規模最小（3.4億），規模劣勢明顯
3. 營收增速幾乎停滯（+0.7%）
4. 核心利潤偏薄，增長動力不足
