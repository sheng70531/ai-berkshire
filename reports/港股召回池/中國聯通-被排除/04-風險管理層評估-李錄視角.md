# 中國聯通（0762.HK）風險與管理層評估

## 一、核心風險識別

### 風險矩陣

| 風險類型 | 嚴重程度 | 發生概率 | 綜合評級 |
|----------|----------|----------|----------|
| 規模差距持續擴大 | 高 | 高 | ★★★★☆ |
| 資本開支壓力（6G到來） | 高 | 高 | ★★★★☆ |
| 利潤增長持續停滯 | 中 | 高 | ★★★☆☆ |
| 混改投資者退出壓力 | 中 | 中 | ★★★☆☆ |
| 物聯網商業化不及預期 | 中 | 中 | ★★★☆☆ |
| C端用戶流失加速 | 中 | 低 | ★★☆☆☆ |

### 關鍵風險詳解

**1. 規模劣勢的惡性循環**
規模最小→單位成本最高→利潤最薄→投資能力最弱→網絡質量進一步落後→用戶更傾向選擇移動/電信。這個循環很難打破。

**2. 技術迭代投資負擔**
每一代通信技術升級（5G→5.5G→6G）都需要數千億投資。對於利潤最薄的聯通，這是持續的財務壓力。2026年資本開支雖降至500億元，但仍佔收入12%+。

**3. 增長停滯的深層原因**
營收增速0.7%、利潤增速1%，在通脹背景下實際上是負增長。深層原因是：
- C端用戶增長見頂
- ARPU值提升受"提速降費"政策制約
- 新業務（物聯網、算力）規模不夠大

## 二、管理層評估

### 戰略判斷力
**評分：★★★☆☆（3/5）**

正面：
1. 明確聚焦四大賽道（連接、算力、服務、安全）
2. 在物聯網/車聯網領域建立差異化定位
3. 獲得衛星移動通信牌照，佈局手機直連衛星
4. 算力投資佔比提升方向正確

負面：
1. 利潤增長極慢說明戰略執行效率不高
2. 混改多年但體制活力釋放有限
3. "四大賽道"與電信/移動高度重疊，差異化不夠

### 混改治理評估
**評分：★★★☆☆（3/5）**

混改引入了騰訊、阿里、百度等作為戰略投資者，理論上應該帶來：
- 互聯網思維和用戶運營能力
- 市場化的管理機制
- 技術協同和業務合作

實際效果：
- 用戶獲取確實有幫助（互聯網套餐）
- 但深層治理變革有限（核心管理層仍是組織部任命）
- BAT的實際參與度在減弱（聯通對其的戰略優先級下降）

### 資本回報意識
**評分：★★☆☆☆（2.5/5）**

- 派息率約50%，低於電信（75%）和移動
- 股息率約4%，三家最低
- 管理層似乎更傾向於保留資金投入新業務，而非回報股東
- 這在ROE僅5.7%的情況下，說明管理層對再投資回報率過於樂觀

## 三、李錄式"不對稱"分析

### 下行保護因素
1. **寡頭地位**：三家牌照壟斷，不會被淘汰
2. **PB < 1**：約0.85倍PB提供資產底
3. **穩定的經營現金流**：即使利潤不增長，現金流仍可維持
4. **政策保護**：國家不會讓運營商之間差距過大

### 上行驅動因素
1. 物聯網/車聯網從連接到服務的價值躍升
2. 管理層大幅提高派息率
3. 算力業務爆發
4. 行業整合（聯通+電信合併的可能性——極小概率）

### 不對稱性評估
- **下行空間**：有限（寡頭保護+資產底），但低ROE意味著"慢性失血"
- **上行空間**：取決於物聯網變現和利潤率改善，目前看可能性中等
- **整體判斷**：不對稱性不夠吸引人——下行雖有保護但不是完全安全（ROE < 資本成本意味著價值在消耗），上行又缺乏明確催化劑

## 四、情景分析

### 樂觀情景（概率20%）
- 物聯網/車聯網業務爆發式增長
- ROE提升至7%+
- 管理層提高派息率至60%+
- 股價上漲30%+

### 基準情景（概率55%）
- 業務維持低增長（1-3%）
- ROE維持5.5-6%
- 投資者獲取4%股息回報
- 股價在當前水平震盪

### 悲觀情景（概率25%）
- 與移動/電信的差距繼續擴大
- 資本開支壓力侵蝕利潤
- ROE下滑至5%以下
- 股價下跌15-20%

## 五、核心結論

**風險管理評分：★★☆☆☆（2.5/5）**

中國聯通是三大運營商中"最不值得投資"的選擇。從李錄的框架來看：
1. **不是最優選擇**：同行業中國移動在幾乎所有維度都更優
2. **缺乏安全邊際**：PE 15倍 / ROE 5.7% 的組合不便宜
3. **缺乏增長引擎**：核心業務停滯，新業務貢獻不夠
4. **管理層對股東不夠慷慨**：50%派息率和4%股息率

如果必須在通信行業配置，優先級應該是：中國移動 >> 中國電信 > 中國聯通。聯通只在PE降至10倍以下時才值得考慮。
