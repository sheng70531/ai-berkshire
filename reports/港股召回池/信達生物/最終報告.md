## 二、投資論文

### 2.1 核心論點

**信達生物是中國創新藥從"跟隨"到"引領"時代的最佳載體之一，但當前估值需要核心管線成功來支撐。**

具體展開：

**看多的理由（按重要性排序）：**

（1）**IBI363是全球IO賽道的潛在遊戲規則改變者**
作為全球首創PD-1/IL-2雙特異性融合蛋白，在"冷腫瘤"（IO經治肺鱗癌ORR 50%、黑色素瘤、MSS結直腸癌）中展現的數據是目前全球同類最佳。如果三期成功，峰值銷售可能達50-100億美元。信達保留40%美國利潤分享 + 大中華區全部權利。

（2）**從Biotech到Biopharma的轉型已過拐點**
2025年營收130億、IFRS盈利8億、正向經營現金流、243億現金儲備——這些數據表明信達已經擺脫了對融資的依賴，具備了自我造血能力。

（3）**BD授權模式的進化打開了價值天花板**
從傳統授權到Co-Co模式（武田114億美元）再到平臺級早期合作（禮來88.5億美元），信達的創新平臺正在被全球頂級藥企反覆驗證和買單。

（4）**第二增長曲線明確**
瑪仕度肽（全球首個雙靶點GLP-1獲批減重+糖尿病）+ 非腫瘤管線快速增長（預計2026年32.7億元），降低了對PD-1的單一依賴。

（5）**行業Beta仍在**
中國創新藥產業正處於全球化加速期，2025年BD出海金額1356億美元創紀錄。這個行業級別的順風對信達是持續利好。

**看空的理由（按風險排序）：**

（1）**IBI363三期失敗概率約40-50%**
腫瘤三期的歷史失敗率很高，且全球啟動已延遲超過6個月。一旦失敗，估值可能打七折。

（2）**核心產品面臨集採和同質化**
貝伐珠單抗幾乎確定會被集採，信迪利單抗增速將放緩。這些"現金牛"的逐步衰退需要新產品及時補位。

（3）**GLP-1賽道競爭極度激烈**
13款NDA受理+35款三期進行中。瑪仕度肽雖然數據好，但獲批晚、渠道受限，能否在紅海中殺出來存在不確定性。

（4）**41倍PE隱含的容錯空間有限**
當前價格已充分反映了"樂觀但非極度樂觀"的預期。如果增速放緩或管線出現負面消息，估值回調的空間不小。

（5）**管理團隊深度存疑**
劉勇軍離職後研發領導力的延續性、200億目標的可實現性——這些軟性因素會影響長期投資者的信心。

## 五、與"理想投資"的差距

### 5.1 信達的優秀之處

- 創始人具備"科學家 + 企業家"的稀缺組合能力
- 商業模式在快速進化，從賣產品到賣平臺能力
- 財務狀況跨過盈利拐點，已具備自我造血能力
- 處於一個確定性高增長的行業中

### 5.2 信達與"理想投資"的差距

| "理想投資"特徵 | 信達的現狀 | 差距 |
|---------------|-----------|------|
| 簡單易懂的生意 | 創新藥研發複雜度高 | 較大 |
| 可預測的收入 | 依賴管線成敗，不確定性高 | 較大 |
| 持久的競爭優勢 | 平臺優勢明確但單品壁壘弱 | 中等 |
| 優秀的管理層 | 創始人優秀但團隊深度待加強 | 較小 |
| 合理的價格 | 41x PE安全邊際一般 | 中等 |
| 長期確定性 | 高度依賴臨床結果 | 較大 |

信達不是一個"確定性極高的簡單生意"——它是一個"優質但複雜、高增長但高不確定性"的投資機會。這決定了它更適合作為組閤中的"攻擊性倉位"而非"核心底倉"。

## 六、最終結論

### 投資評級：觀察 / 候選

**一句話總結**：信達生物是中國創新藥行業最具全球化潛力的企業之一，基本面正處於從量變到質變的關鍵期，但當前估值需要核心管線成功來兌現，安全邊際一般。

**操作建議**：

- 當前不急於大幅建倉。87.70港元的價格處於合理區間中段，沒有明顯的低估機會
- 可以小倉位（1-2%）開始關注，建立跟蹤和認知積累
- 關鍵買入時機：（1）股價回調至65-70港元區間；（2）IBI363三期啟動並有積極進展信號；（3）兩者同時出現時為最佳建倉窗口
- 關鍵賣出/迴避信號：（1）IBI363三期數據負面；（2）管理層大規模減持；（3）連續兩個季度產品銷售增速低於15%

### 需要持續跟蹤的問題

1. IBI363全球三期的啟動時間和入組進度——這是最核心的變量
2. 瑪仕度肽的季度銷售數據——驗證第二曲線的爬坡速度
3. 貝伐珠單抗集採的時間和降價幅度——量化下行風險
4. 管理團隊的穩定性——尤其是研發核心崗位的人才留存
5. 新BD交易的質量——驗證創新平臺能力的可持續性
