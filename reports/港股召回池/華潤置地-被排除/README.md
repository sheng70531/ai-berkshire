## 研究背景

華潤置地是港股地產央企中最具"類REIT"屬性的標的。公司正從傳統住宅開發商向"城市投資開發運營商"轉型，經常性業務利潤貢獻已超過50%。在行業深度調整期，華潤置地憑藉央企信用、低融資成本、優質商業資產組合，展現出穿越週期的能力。PE約6-8倍，股息率約4.7%，是地產板塊中少數兼具成長性和防禦性的標的。
