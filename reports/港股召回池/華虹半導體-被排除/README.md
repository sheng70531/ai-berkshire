## 公司簡介

華虹半導體是全球領先的特色工藝純晶圓代工企業，中國大陸第二大、全球第六大純晶圓代工廠。公司專注於55nm及以上成熟製程的特色工藝，提供嵌入式/獨立式非易失性存儲器、模擬與電源管理、邏輯與射頻、功率器件等多元化特色工藝平臺的晶圓代工及配套服務。

## 研究背景

- 特色工藝晶圓代工龍頭，差異化定位避開與臺積電/中芯國際的正面競爭
- 當前PE約52倍（動態），ROE處於低位（約1-2%），處於產能爬坡期
- FAB9（無錫12英寸線）大規模擴產帶來折舊壓力，短期利潤承壓
- 2026年4月美國商務部要求暫停對華虹部分工廠設備供貨，地緣風險加劇
- 管理層換帥：前英特爾全球副總裁白鵬2025年1月接任總裁

## 研究框架

本研究從四個維度對華虹半導體進行深度分析：

1. **商業模式分析** — 生意的本質、護城河與定價權
2. **財務估值分析** — 數字背後的真相、安全邊際與回報預期
3. **行業競爭分析** — 產業鏈位置、競爭格局與長期趨勢
4. **風險管理層評估** — 人的因素、制度風險與不確定性

## 研究結論預覽

華虹半導體是一家處於關鍵轉型期的特色工藝代工企業。其差異化定位具有戰略價值，但當前估值隱含了較高的成長預期。投資者需要權衡國產替代的確定性與地緣風險、折舊壓力、盈利能力恢復節奏之間的矛盾。
