# 比亞迪電子（0285.HK）行業競爭分析

## 一、EMS行業全景

### 1.1 全球EMS市場格局

2024年全球Top 50 EMS企業總收入達到4770億美元，同比增長12.7%。市場高度集中：前10名企業佔總收入的87.6%。

| 2 | 和碩 | 中國臺灣 | 蘋果iPhone代工 |
| 3 | 立訊精密 | 中國大陸 | 蘋果核心供應商，利潤率高 |

### 1.2 行業特徵

芒格強調理解行業的"生態位"。EMS行業的生態特徵：

1. **規模效應遞減**：收入規模增長並不能線性提升利潤率，邊際效益有限
2. **客戶議價權極強**：蘋果、三星等品牌商佔據絕對話語權
3. **技術迭代快**：需持續投入跟進新工藝（如AI服務器液冷）
4. **地緣政治敏感**：中美博弈下產能佈局全球化成必選項
5. **贏家通吃趨勢**：前10名佔比87.6%，中小企業生存空間壓縮

## 二、競爭對手深度對比

### 2.1 立訊精密：最直接的競爭者

立訊精密與比亞迪電子在多個維度直接競爭：

| 維度 | 立訊精密 | 比亞迪電子 |
|------|----------|-----------|
| 蘋果業務 | iPhone組裝+AirPods | iPhone組裝（收購捷普後） |
| 毛利率 | ~12% | ~6% |
| 汽車電子 | 加速佈局中 | 深度綁定比亞迪汽車 |
| AI服務器 | 佈局中 | 英偉達認證供應商 |
| 管理風格 | 創始人王來春，強執行力 | 背靠比亞迪集團資源 |

**芒格式判斷**：立訊精密在利潤率和獨立客戶拓展方面優於比亞迪電子；但比亞迪電子在汽車電子賽道有立訊難以複製的生態優勢。兩者並非零和競爭，而是在不同子賽道各有所長。

### 2.2 富士康：規模霸主

富士康年營收超過2萬億人民幣，是比亞迪電子的10倍以上。但近年增長乏力，正積極轉型AI服務器和電動車代工。

- 富士康在AI服務器領域進展快於比亞迪電子（已是英偉達最大組裝夥伴之一）
- 電動車代工（MIH平臺）發展不及預期
- PE僅10倍左右，市場已按成熟企業給估值

## 三、產業趨勢分析

### 3.1 趨勢一：AI算力基礎設施爆發

這是比亞迪電子最大的結構性機遇。

- 英偉達GB200/GB300系列需要大量液冷散熱、電源管理、精密連接器
- 比亞迪電子已獲英偉達認證，2025年AI服務器收入9.4億元
- 管理層2026年指引100億元（增長10倍），字節跳動訂單月產能擴至2000櫃
- 浸沒式液冷ASP約80萬元/櫃，毛利率約30%

**芒格的"心理模型"應用**：這是典型的"鏟子生意"——AI淘金熱中賣鏟子的人往往賺得更穩。但需警惕：賣鏟子的人太多時，鏟子也會變成商品。富士康、緯創、Celestica都在搶這塊蛋糕。

### 3.2 趨勢二：汽車電子智能化

新能源汽車的電子含量遠超燃油車。比亞迪汽車每輛車的電子零部件價值量持續提升：
- 域控制器、智能駕駛硬件
- 熱管理系統
- 車載屏幕與人機交互

比亞迪電子作為集團內部核心供應商，這部分收入增長確定性高（2025年增速27.7%）。芒格會認為這是"確定性最高的部分"。

### 3.3 趨勢三：消費電子EMS見頂

全球智能手機出貨量已從2016年峰值15億部下降至11-12億部，且增長動力不足。AI手機可能帶來換機潮，但對代工量的邊際提升有限。

這意味著比亞迪電子消費電子業務（佔收入84%）很難再有大的增量，只能靠份額提升和產品結構優化。

### 3.4 趨勢四：地緣政治重塑供應鏈

中美科技脫鉤背景下：
- **風險**：如果中美關係惡化，蘋果可能減少中國代工佔比
- **機會**：中國品牌（華為、小米等）更傾向使用國內代工商
- 比亞迪電子的全球化產能佈局（印度、越南等）有助於對沖地緣風險

## 四、多元思維模型應用

### 4.1 生物學模型：生態位競爭

在EMS行業的生態系統中，比亞迪電子的獨特生態位是：**汽車電子+消費電子+AI的跨界製造平臺**。

- 富士康的生態位：超大規模消費電子代工
- 立訊精密的生態位：高精度消費電子+快速擴品類
- 比亞迪電子的生態位：汽車產業鏈內生+外部EMS

這種跨界生態位的優勢在於"交叉補貼"——汽車電子的技術積累可以遷移到AI服務器（液冷、電源管理、熱管理）。但風險在於資源分散。

### 4.2 物理學模型：臨界點思維

比亞迪電子的新業務正在接近一個臨界點：
- AI服務器從9.4億元到100億元是10倍增長
- 一旦AI+汽車電子佔比超過30%，整體毛利率將出現質變（從6%向8-10%躍升）
- 這個臨界點可能在2027-2028年到來

如果臨界點未到來（AI服務器增速低於預期），公司將長期困在"大而不強"的狀態。

### 4.3 心理學模型：敘事謬誤

市場對比亞迪電子存在兩種極端敘事：
- **看多敘事**："AI服務器+機器人+汽車電子三輪驅動，估值重塑"
- **看空敘事**："代工廠就是代工廠，6%毛利率的本質不會變"

芒格會提醒我們：不要被任何一種敘事綁架。要看實際數據——2026年AI服務器能否真正做到100億？汽車電子毛利率是多少？這些是可驗證的。

### 4.4 經濟學模型：規模不經濟

EMS行業存在"規模不經濟"現象：收入從1773億增長到1795億（+1.2%），利潤反而從42.7億下降到35.2億（-17.6%）。這說明邊際收入的利潤貢獻為負——新增業務實際在"稀釋"盈利能力。

原因：為爭取大客戶訂單，必須接受更低的代工費率。規模擴大不代表利潤改善，反而可能惡化。

## 五、逆向思考

### 5.1 如果看空，最強論據是什麼？

1. **結構性陷阱**：84%收入來自5-6%毛利率的消費電子代工，新業務體量太小（AI僅0.5%），即使翻10倍也難以改變全局
2. **關聯交易質疑**：汽車電子高增長背後是母公司"輸血"，非市場化競爭獲得
3. **歷史證明**：收購捷普後收入大增36%但利潤率不升反降，說明規模擴張不創造價值
4. **競爭加劇**：AI服務器賽道所有EMS巨頭都在進入，利潤率會快速被競爭拉平

### 5.2 如果看多，最強論據是什麼？

1. **汽車電子不可替代性**：比亞迪汽車全球月銷40萬輛+，電子零部件價值量持續提升，這是其他EMS企業幾乎無法複製的綁定
2. **AI液冷技術壁壘**：英偉達認證+LFP儲能+液冷垂直整合，成本低15-20%，不是誰都能做
3. **估值底部**：股價接近52周低位，PE 16倍對應的是利潤低谷年份，2026年利潤恢復後PE可能回到12倍
4. **平臺化潛力**：如果2027年AI+汽車佔比超過30%，整體毛利率躍升將帶來戴維斯雙擊

## 六、行業週期判斷

### 6.1 消費電子週期

2023-2025年是智能手機的低迷週期。AI手機換機潮可能在2026-2027年推動溫和復甦，但難以回到2016年峰值。對比亞迪電子消費電子業務而言，是"維持"而非"增長"。

### 6.2 汽車電子週期

新能源汽車仍處於滲透率提升的黃金期（全球滲透率約25-30%），比亞迪汽車持續放量。汽車電子處於上升週期，預計還有3-5年高增長期。

### 6.3 AI算力週期

2024-2026年是AI基礎設施投資的爆發期。但市場已有擔憂：大模型投資回報率不明確，如果AI投資放緩（類似2000年互聯網泡沫後的網絡設備投資收縮），AI服務器需求可能出現週期性回落。

**核心結論**：從芒格的多元思維角度看，比亞迪電子在行業中的競爭位置具有獨特性——它是唯一一家同時深耕汽車電子（背靠全球新能源車龍頭）和AI服務器（英偉達認證+液冷技術）的大型EMS企業。這種跨界能力是競爭對手短期內難以複製的。但行業本身（EMS代工）的利潤率天花板很低，即使位置再好，也很難成為"偉大企業"。給予四星評價是因為行業位置好、趨勢方向正確，但需要扣除行業本身吸引力不足的因素。
