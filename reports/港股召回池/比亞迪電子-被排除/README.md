## 研究背景

比亞迪電子是全球第七大EMS企業，2023年通過158億元收購捷普（Jabil）在華業務後，一躍成為蘋果供應鏈核心代工商。公司業務覆蓋智能終端（手機/筆電組裝及零部件）、新能源汽車電子、AI算力基礎設施三大板塊。

**核心矛盾**：公司擁有母公司比亞迪汽車的確定性增量（汽車電子年增40%+），同時切入AI服務器/機器人等高毛利新賽道，但主業消費電子代工毛利率僅6%左右，且2025年出現增收不增利（營收1795億元微增1.2%，淨利潤35億元下降17.6%）。投資者需判斷：新業務能否改變代工本質？

## 研究框架

本研究採用四維分析框架，從不同投資大師視角審視該標的：

1. **商業模式分析（段永平視角）** - 聚焦生意本質、護城河與用戶價值
2. **財務估值分析（巴菲特視角）** - 聚焦盈利質量、資本回報與安全邊際
3. **行業競爭分析（芒格視角）** - 聚焦競爭格局、產業趨勢與多元思維
4. **風險與管理層評估（李錄視角）** - 聚焦管理層品質、風險因素與長期價值
