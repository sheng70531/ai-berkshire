## 核心結論

**綜合評分：★★★★（4/5）**

友邦保險是泛亞洲地區最大的獨立上市壽險集團，業務覆蓋18個市場。2025年全年新業務價值（VONB）55.16億美元，創歷史新高，同比增長15%；稅後營運利潤（OPAT）71.36億美元，同比每股增長12%；基本自由盈餘67.65億美元，同比每股增長11%。EV權益增長18%至843.84億美元，股東資本比率221%，資本實力雄厚。

**核心矛盾：內地增速放緩vs區域增長韌性。** 2025年中國內地全年NBV僅同比增長2%，下半年增速回暖至14%，增長動能有所波動。但香港市場NBV增長28%至22.56億美元表現強勁，泰國NBV增長35%至5.22億美元。P/EV約1.0倍、PE約14倍，估值處於歷史中位偏低水平，不算極端便宜但也不貴。

**關鍵判斷：** 友邦保險是泛亞壽險賽道的稀缺龍頭，商業模式優秀，管理層能力突出，資本回報紀律嚴格。當前估值合理偏低，具備長期持有價值。核心變量是中國內地擴張的兌現節奏和亞洲低利率環境的演化。

**主要風險：** 中國內地增速不及預期、亞洲各市場利率下行侵蝕投資收益、全球最低稅率（Pillar Two）提升有效稅率、泰國等新興市場資本市場波動。
