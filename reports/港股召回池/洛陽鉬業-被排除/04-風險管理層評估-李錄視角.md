# 洛陽鉬業：風險與管理層評估

> 分析維度：李錄安全邊際視角 | 日期：2026年5月16日 | 貨幣：人民幣（除特別標註）

---

## 一、管理層評估：買股票就是買人

### 1.1 實際控制人：於泳與鴻商集團

洛陽鉬業的實際控制人是**於泳**，通過鴻商產業控股集團持有公司約24.93%的股份。於泳今年64歲，大連瓦房店人，2003年在上海創建鴻商集團，2009年至今擔任董事長兼總裁。

**於泳的特點**：

1. **極度低調**：不在洛陽鉬業任職，不領工資，不出席公開場合。2007年公司港股上市時，他本人都沒有出現在敲鐘儀式上。公開信息極少，幾乎不接受媒體採訪。

2. **資本運作高手**：2004年以約1.78億元入股洛陽鉬業（混改），到2026年其間接持股市值超過950億元，增值超過500倍。這在中國資本市場歷史上極為罕見。

3. **長期持有、不減持**：於泳入股超過20年，未進行大規模減持，說明其對公司長期價值的信心。

4. **戰略眼光出眾**：推動了一系列改變公司命運的收購——2016年收購TFM、2019年收購IXM、2020年收購KFM，每一次都是在低價時出手買入世界級資產。

**李錄視角的評價**：李錄非常看重實際控制人是否"與股東利益一致"。於泳持股24.93%且長期不減持，利益綁定充分。其不擔任管理職務，說明他信任職業經理人團隊並保持適度距離。但過度神秘也帶來信息不透明的風險——投資者難以直接評估其真實想法和意圖。

### 1.2 管理團隊

**核心變動**：2025年10月，原總裁兼CEO孫瑞文因個人原因辭職，由彭旭輝接任。這是一次重要的管理層交接。

**彭旭輝**：此前曾擔任深天馬A的董事長，是職業經理人背景。其任命說明洛陽鉬業在向更加職業化、規範化的治理方向發展。

**管理團隊的正面信號**：
- 過去幾年的併購整合執行力強：TFM混合礦項目按期達產，KFM從"全球最大未開發鈷礦"到全面投產，均如期完成
- 2025年全年產量超額完成指引（銅完成度118%），說明運營管理能力紮實
- 資產負債率從59%降至50%，體現了審慎的財務管理

**管理團隊的擔憂信號**：
- CEO更換髮生在公司高速成長期，管理層穩定性需要觀察
- 連續大型併購（2025年兩筆金礦收購合計超15億美元），對新管理層的整合能力是考驗
- 高管薪酬和股權激勵信息不夠透明

### 1.3 第二大股東：寧德時代

2022年9月，寧德時代通過四川時代間接持有洛陽鉬業約24.68%的股份，成為第二大股東。

**這是一個重要的戰略信號**：
- 寧德時代作為全球最大電池製造商，持股洛陽鉬業是為了鎖定上游資源（鈷、銅、鋰）
- 產業資本的深度綁定增強了洛陽鉬業的戰略價值
- 但也意味著公司可能需要平衡兩大股東的不同訴求

## 二、風險全景圖

### 2.1 最大風險：剛果（金）國家風險 ★★★★★（極高）

**這是決定洛陽鉬業投資命運的核心變量。**

**風險事實清單**：

1. **2021-2023年糾紛事件**：剛果國家礦業公司（Gecamines）對TFM發起調查，最終洛陽鉬業被迫支付8億美元和解金。這不是罰款，而是"保護費"的性質。

2. **強制轉股要求**：2025年1月，剛果礦籍管理局要求58家礦企在45天內轉讓10%股份給剛果政府，否則面臨礦權吊銷風險。

3. **鈷出口配額制**：2025年10月起實施，雖然短期利好（限制競爭對手出口），但也意味著剛果政府對礦業的控制力在增強。

4. **安全環境**：剛果東部長期武裝衝突，雖然TFM和KFM位於相對穩定的加丹加省，但全國政治局勢不確定。

5. **大國博弈**：中美在關鍵礦產供應鏈上的競爭，可能使中國礦企在剛果成為政治博弈的籌碼。

**最壞情景推演**：
- 剛果政府將強制轉股比例從10%提高到20-30%
- 或對銅鈷出口徵收更高的特許權使用費（從當前的約6%提高到10-15%）
- 極端情況下，部分或全部礦權被撤銷或國有化

**發生概率評估**：全面國有化的概率低（5%以下），但持續性的"薅羊毛"（加稅、轉股、配額限制）概率高（50%以上）。每次"薅羊毛"可能帶來數十億元的價值損失。

### 2.2 大宗商品價格風險 ★★★★☆（高）

**銅價敏感性分析**：

| LME銅價（美元/噸） | 預計年淨利潤 | 影響 |
|---------------------|-------------|------|
| 12,000+ | 400億+ | 極度樂觀 |
| 10,000 | 320-350億 | 基準 |
| 8,500 | 200-230億 | 利潤下降30-35% |
| 7,000 | 100-140億 | 利潤腰斬 |
| 5,500 | 30-60億 | 接近盈虧平衡 |

銅價每波動10%，對利潤的影響約為20-30%，這是典型的經營槓桿效應。

**鈷價風險**：雖然鈷的利潤佔比在下降（銅是主角），但如果配額制被取消導致鈷價再次暴跌，仍會對利潤造成顯著影響。

### 2.3 擴產執行風險 ★★★☆☆（中等）

- KFM二期和TFM三期規劃中，預計2027年投產後銅年產能突破80萬噸
- 在剛果（金）進行大規模基建面臨基礎設施薄弱、電力不足、物流困難等挑戰
- Heshima水電站（200MW）已簽約，但建設進度可能受當地條件影響

### 2.4 併購整合風險 ★★★☆☆（中等）

- 2025-2026年連續完成三筆金礦收購（厄瓜多爾+巴西），合計投資超15億美元
- 巴西金礦是成熟運營資產，整合風險相對可控
- 厄瓜多爾Cangrejos金礦尚未投產（預計2029年），存在建設和審批風險
- 在金價歷史高位買入金礦資產，如果金價回落，收購回報率可能不達預期

### 2.5 匯率風險 ★★★☆☆（中等）

- 收入主要以美元計價（銅、鈷國際定價），成本部分以人民幣和剛果法郎計價
- 人民幣升值對利潤有負面影響
- 公司通過IXM進行一定程度的對沖

### 2.6 ESG與合規風險 ★★☆☆☆（較低）

- MSCI ESG評級AA，全球有色行業前13%
- 入選FTSE4Good指數、標普可持續發展年鑑
- 在剛果社區投入累計超3.25億美元
- 但非法手採礦問題、人口湧入壓力仍然存在
- 全球對剛果鈷"血鈷"問題的關注可能影響下游客戶的採購偏好

## 三、李錄"安全邊際"評估

### 3.1 李錄會如何思考這筆投資？

李錄的核心理念是：**以大幅低於內在價值的價格買入，留出充足的安全邊際來應對不確定性。**

**安全邊際的計算**：

以保守假設計算內在價值：
- 假設週期中樞淨利潤200-250億元（銅價8500-9000美元/噸）
- 給予10倍PE（考慮週期性和地緣風險折價）
- 保守估值 = 2000-2500億人民幣

當前H股市值約1850億人民幣：
- 相對保守估值的安全邊際 = 8%-35%
- 相對基準估值（3000億+）的安全邊際 = 60%+

**李錄可能的判斷**：安全邊際存在但不算充裕——保守情景下僅有8-35%的折價，這對於面臨國家風險的資產來說不夠寬。李錄通常要求40-50%的安全邊際。

### 3.2 "10年持有"測試

如果買入後被迫持有10年不能賣出，投資者面臨的情景：

**樂觀路徑（概率30%）**：
- 銅價長期上行至12000-15000美元/噸
- 剛果局勢穩定，公司順利擴產至100萬噸銅
- 10年後市值可達5000-8000億元，年化回報15-20%

**基準路徑（概率40%）**：
- 銅價在8000-10000美元/噸區間波動
- 剛果偶有摩擦但可控
- 10年後市值3000-5000億元，年化回報8-12%

**悲觀路徑（概率25%）**：
- 銅價大幅回落至6000-7000美元/噸
- 剛果持續加稅加費，侵蝕利潤
- 10年後市值1500-2000億元，年化回報0-3%

**極端路徑（概率5%）**：
- 剛果發生礦權糾紛或國有化
- 公司被迫出售資產或支付鉅額賠償
- 10年後市值500-1000億元，虧損50%+

**期望回報率**：約9-13%，扣除極端風險後，長期回報預期尚可但不突出。

### 3.3 "最大回撤"容忍度

歷史上洛陽鉬業的最大回撤：
- 2018年（貿易戰+週期下行）：跌幅超過60%
- 2022年（剛果糾紛+商品下跌）：跌幅約50%

未來如果出現類似事件（銅價暴跌+剛果風波），H股可能再次出現40-60%的回撤。投資者需要對此有心理準備。

## 四、李錄框架下的綜合評估

### 正面因素

1. **處於文明發展的正確方向**：銅是電氣化和AI時代的核心金屬，需求增長幾乎確定
2. **管理層利益綁定**：實控人持股25%、不減持，與小股東利益一致
3. **資產質量優秀**：TFM+KFM是全球頂級礦山，資源壁壘極高
4. **估值不貴**：11-12倍PE，如果剛果局勢穩定，安全邊際充足

### 反面因素

1. **國家風險是"不可知"風險**：不是經營上的困難（可克服），而是政治上的不確定性（不可控）。這是李錄最不喜歡的風險類型
2. **週期股估值陷阱**：當前可能正處於週期高位，"便宜"可能是幻覺
3. **集中度過高**：單一國家（剛果）貢獻70%+利潤，缺乏地理分散
4. **併購依賴型增長**：如果管理層在高位繼續大舉併購，可能毀滅價值

## 六、關鍵跟蹤指標

1. **剛果（金）政治局勢**：總統選舉、礦業法修訂、對外資政策
2. **強制轉股進展**：10%股權轉讓是否執行、是否進一步擴大
3. **管理層交接**：新CEO彭旭輝的執行力和戰略決策
4. **併購節奏**：是否繼續大舉收購，還是轉向內生增長
5. **分紅回購**：自由現金流如何分配——分紅、回購還是再投資
