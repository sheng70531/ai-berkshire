## 核心結論

**綜合評級：★★★★☆（4/5）— 具備投資價值但需折價補償國家風險**

洛陽鉬業已從一家河南鉬礦企業蛻變為全球資源巨頭：全球第一鈷生產商、前十大銅生產商，2025年歸母淨利潤203億元（同比+50%），2026年一季度淨利78億元（同比+97%）。銅金雙極戰略清晰，2027-2028年銅產能劍指80-100萬噸。全球銅供需缺口持續擴大（S&P Global預計2040年缺口達1000萬噸），公司處於最佳賽道。

**核心矛盾**：70%以上利潤來源於剛果（金），國家風險是硬傷。2023年已被迫支付8億美元和解金。剛果政府的礦業政策（強制轉股10%、鈷出口配額制）持續構成不確定性。11-13倍PE看似便宜，但部分反映了地緣折價的合理性。

**關鍵判斷**：若銅價維持高位且剛果局勢穩定，當前估值具有吸引力；若出現地緣黑天鵝，下行風險不可忽視。建議關注但需耐心等待更大安全邊際。
