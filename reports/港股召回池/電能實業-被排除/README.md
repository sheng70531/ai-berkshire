# 電能實業（0006.HK）投資研究

## 基本信息
- **公司名稱**：電能實業有限公司
- **股票代碼**：0006.HK
- **行業**：電力/公用事業
- **PE（TTM）**：~22倍
- **ROE**：5-6%

## 2025年度核心財務數據
| 指標 | 數值 | 同比變化 |
|------|------|----------|
| 收入 | 7.71億港元 | -16.1% |
| 股東應佔溢利 | 62.36億港元 | +2% |
| 全年每股派息 | 2.82港元 | 維持穩定 |
| 末期股息 | 每股2.04港元 | - |
| 股息率 | ~4.6% | - |

## 投資亮點
1. 與長江基建高度關聯，資產質量穩定
2. 派息率極高（>90%），收息確定性好
3. 全球公用事業資產組合
4. 高評級信用，融資成本低

## 核心風險
1. PE 22倍對ROE 5-6%極貴
2. 收入大幅下滑16%
3. 增長接近停滯
4. 與長江基建高度重疊，缺乏獨立投資價值
