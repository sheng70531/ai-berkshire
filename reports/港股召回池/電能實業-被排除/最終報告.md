# 電能實業（0006.HK）投資研究最終報告

## 綜合評分

| 維度 | 評分 | 核心判斷 |
|------|------|----------|
| 商業模式 | ★★★☆☆ | 純投資控股，穩定但無增長 |
| 財務估值 | ★★☆☆☆ | PE 22倍對ROE 5-6%明顯偏貴 |
| 行業競爭 | ★★★☆☆ | 資產質量好，但獨立價值有限 |
| 風險管理層 | ★★★☆☆ | 高派息誠實，但缺乏增長動力 |
| **綜合評分** | **★★½☆☆** | **昂貴的公用事業債券，不如長江基建** |

## 一句話結論

電能實業是一隻估值過高的"超級收息股"——4.6%股息率+2%增長的組合在PE 22倍下缺乏安全邊際。如果要配置長江系公用事業，長江基建是更優選擇。

## 投資論點

### 看多邏輯
1. 派息率>90%，股息極為確定
2. 全球公用事業資產組合，分散化優秀
3. 長江系運營管理經驗保障
4. 若與長江基建合併，小股東獲溢價空間

### 看空邏輯
1. PE 22倍對ROE 5-6%明顯偏貴
2. 利潤增長僅2%/年，實際零增長
3. 與長江基建高度重疊，獨立投資價值存疑
4. 高利率環境下4.6%股息率缺乏相對吸引力
5. 收入大幅下滑16%引發運營擔憂

## 電能實業 vs 長江基建

| 指標 | 電能實業 | 長江基建 | 推薦 |
|------|----------|----------|------|
| PE | 22x | 20x | 長基更優 |
| 股息率 | 4.6% | 4.0% | 電能略高 |
| 增長率 | 2% | 3% | 長基更優 |
| 資產多元性 | 純公用事業 | 公用+交通+環保 | 長基更優 |
| 連續增派 | 穩定 | 28年連增 | 長基更優 |
| **結論** | | | **優先選長江基建** |

## 買入條件

1. **PE降至18倍以下**（對應股息率5.5%+）
2. **或長江基建/電能實業宣佈合併方案**（博弈溢價）
3. **或全球進入降息週期**（利好公用事業估值）

## 倉位建議

- **當前價位**：不建議配置（長江基建性價比更優）
- **理想買入區間**：港股48-50元（對應PE 17-18倍）
- **替代選擇**：長江基建（1038.HK）

## 持續跟蹤要點

1. 與長江基建合併可能性的進展
2. 派息政策變化
3. 配氣資產的去碳化影響
4. 全球利率變化趨勢
