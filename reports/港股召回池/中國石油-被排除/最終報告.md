# 中國石油（0857.HK）投資研究最終報告

## 一句話結論

中國石油是一個"買油價"的代理標的——如果看多油價就值得持有，如果對油價無判斷則沒有特別理由買入。在同行業中，中海油的性價比優於中石油。

## 投資論點

### 看多邏輯
1. PE 10-11倍在大型能源公司中偏低，估值有安全邊際
2. 天然氣業務增長確定（佔國內產量65%+），提供增長引擎
3. 分紅率54.7%，股息率~5%，在低利率環境有吸引力
4. PB僅0.5倍，極端情況下有資產底支撐
5. 地緣衝突可能推高油價，帶來利潤彈性

### 看空邏輯
1. ROE僅5%，遠低於資本成本，價值在持續毀滅
2. 油價不可預測，2025年利潤已同比下降4.5%
3. 全球能源轉型大趨勢下，化石能源資產面臨"擱淺"風險
4. 央企治理效率低，100萬+員工的組織效率難以提升
5. 同行業中海油（ROE 15%+，PE 7-8倍）明顯更優

## 與中海油的直接對比

| 指標 | 中國石油 | 中海油 |
|------|----------|--------|
| PE | 10-11x | 7-8x |
| ROE | ~5% | 15%+ |
| 股息率 | ~5% | ~7% |
| 資產質量 | 老油田多，成本高 | 海洋新油田，成本低 |
| 管理效率 | 央企，100萬+人 | 相對市場化 |
| 結論 | 中等 | 更優 |

## 買入條件（若考慮配置）

1. **明確看多油價**（布倫特80美元+/桶預期）
2. **PE降至8倍以下**，對應股息率7%+
3. **天然氣價改出現實質性利好**
4. 否則應優先考慮中海油

## 倉位建議

- **當前價位**：不優先推薦（同賽道中海油更優）
- **合理買入價**：港股4.5-5.0元區間（對應PE 8-9倍）
- **倉位上限**：不超過組合3%（若為油價對沖配置）

## 持續跟蹤要點

1. 國際油價走勢（布倫特原油）
2. 天然氣產量和售價變化
3. 分紅比例是否繼續提升
4. 海外資產減值風險
5. 資本開支計劃變化
