# 中國石油（0857.HK）投資研究

## 基本信息
- **公司名稱**：中國石油天然氣股份有限公司
- **股票代碼**：0857.HK
- **行業**：油氣勘探/煉化
- **PE（TTM）**：10-11倍
- **ROE**：~5%

## 2025年度核心財務數據
| 指標 | 數值 | 同比變化 |
|------|------|----------|
| 營業收入 | 28,645億元 | -2.5% |
| 歸母淨利潤 | 1,573億元 | -4.5% |
| 末期股息 | 每股0.25元 | 派息率54.7% |

## 投資亮點
1. 國內最大油氣生產商，上游資源稟賦強
2. 天然氣業務高速增長，符合能源轉型方向
3. 估值相對便宜（PE 10-11倍）
4. 穩定分紅，股息率約5%

## 核心風險
1. 油價下行影響上游利潤
2. 煉化板塊盈利能力弱
3. ROE偏低（~5%），資本效率不高
4. 海外資產面臨地緣政治風險
