## 研究背景

舜宇光學是中國光學產業龍頭，全球手機鏡頭及攝像模組出貨量第一。當前正處於從手機光學向車載光學、AR/XR光學轉型的關鍵節點。2026年被市場視為"過渡之年"——舊動能（手機）承壓，新動能（車載、AR）尚未全面放量。

**關鍵催化劑：**
- 車載光學子公司（舜宇智能光電）擬分拆港股上市
- AI眼鏡產業鏈2026年進入千萬級出貨量階段
- 與歌爾光學戰略合作切入Meta等全球AR供應鏈
- 玻塑混合鏡頭、潛望式鏡頭等高端產品放量

**關鍵風險：**
- 2026年全球智能手機出貨量可能同比下降15%（大摩預測）
- 存儲漲價擠壓中低端手機產量，影響光學模組需求
- 新舊動能切換的"時間差"風險
- 車載業務分拆上市的不確定性
