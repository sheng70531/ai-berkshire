## 核心結論

**綜合評級：★★★★☆（4/5）— 值得重點跟蹤，但需等待整合落地驗證**

吉利汽車是當前港股最便宜的大型車企之一。2025年全年銷量突破302萬輛（同比+39%），收入3452億元（同比+25%），核心歸母淨利潤144億元（同比+36%），現金儲備682億元（同比+46%）。以當前約22港元的股價計算，靜態PE約5-6倍，ROE約17.7%，屬於典型的"低估值+高成長"組合。

**核心看點：**
- "一個吉利"戰略整合正在落地：極氪私有化完成，品牌從6個縮減至4個，預計研發節省10億元、採購節省數十億元
- 新能源轉型加速：2025年新能源銷量169萬輛（同比+90%），佔比已超55%
- 銀河品牌爆發：全年124萬輛（同比+150%），超額完成百萬目標
- 分析師一致看好：37家投行給出買入評級，目標均價27.93港元（約25%上行空間）

**核心風險：**
- 增收不增利隱憂：歸母淨利潤168.5億元僅微增0.2%，低於核心淨利潤增速，說明非經常性損益存在波動
- 海外出口增速墊底：全年出口42萬輛，同比僅增0.4%，遠落後於奇瑞（129萬輛）和比亞迪（104萬輛）
- 行業價格戰持續：2026年競爭預計更加激烈，利潤率面臨擠壓
- 多品牌整合執行風險：整合效果尚需時間驗證

**投資判斷：** 吉利汽車具備"好價格"的條件，但"好生意"和"好管理"仍需觀察整合後的運營數據。建議密切跟蹤2026年上半年的毛利率、單車利潤、出口增速三個關鍵指標。
