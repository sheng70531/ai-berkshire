# 吉利汽車（0175.HK）財務估值分析

> 分析維度：財務質量與內在價值 | 研究日期：2026年5月16日
> 貨幣單位：人民幣（除特別註明為港元）

---

## 一、財務全景：一張"增長但複雜"的成績單

### 1.1 核心財務指標總覽（2025年全年）

| 指標 | 2025年 | 同比變化 | 備註 |
|------|--------|---------|------|
| 總收入 | 3452億元 | +25% | 創歷史新高 |
| 毛利 | 573億元 | +25% | 毛利率約16.6% |
| 核心歸母淨利潤 | 144.1億元 | +36% | 剔除非經常性損益後 |
| 歸母淨利潤 | 168.5億元 | +0.2% | 非核心因素拖累增速 |
| 研發投入 | 176.2億元 | — | 佔收入約5.1% |
| 總現金 | 682億元 | +46% | 含銀行存款及現金 |
| 總資產 | ~2744億元 | +1%（截至Q3） | — |
| 股東權益 | ~935億元 | +8%（截至Q3） | — |
| 每股派息 | 0.50港元 | +51.5% | 創歷史新高 |
| 銷量 | 302萬輛 | +39% | 超額完成目標 |
| 單車核心歸母淨利潤 | ~5200元 | — | 管理層披露 |

### 1.2 幾個值得注意的數字

**核心淨利 vs 歸母淨利的差異**

核心歸母淨利潤144.1億元（同比+36%），但歸母淨利潤168.5億元僅微增0.2%。兩者差異約24億元，主要來自外匯匯兌損益、資產減值、投資收益等非經常性項目。這說明：

- 核心經營能力確實在改善
- 但利潤的質量和可預測性受到非核心因素的顯著幹擾
- 投資者不能簡單地看歸母淨利潤來判斷公司經營狀況

**增收不增利的隱憂**

另一組數據更值得關注：按另一口徑計算，營收同比增長43.73%，但淨利潤僅增長1.32%。這意味著收入每增加1元，淨利潤幾乎沒有增加。可能的原因包括：

- 銀河品牌走量，但單車利潤較低
- 價格戰環境下終端讓利增加
- 極氪私有化過程中產生的一次性費用
- 研發投入高企（176億元）

## 二、盈利能力分析：利潤率是關鍵戰場

### 2.1 毛利率

2025年毛利率約16.6%，在國內車企中處於中上水平。作為參考：

| 車企 | 毛利率（近期） |
|------|-------------|
| 比亞迪 | ~22-25% |
| 吉利汽車 | ~16.6% |
| 長城汽車 | ~19-20% |
| 理想汽車 | ~20-22% |

吉利的毛利率低於比亞迪和長城，核心原因在於：銀河品牌以性價比取勝，單車售價較低；同時吉利的垂直整合程度不如比亞迪（比亞迪自產電池、芯片、電機等核心零部件）。

### 2.2 淨利率

以核心歸母淨利潤144.1億元 / 收入3452億元計算，核心淨利率約4.2%。這個水平在全球車企中屬於中等偏下，但考慮到：

- 吉利正處於新能源轉型投入期
- 極氪品牌2025年才首次扭虧為盈
- 行業整體面臨價格戰壓力

4.2%的核心淨利率是可以接受的起點，關鍵是看趨勢能否改善。

### 2.3 ROE

以用戶提供的ROE 17.7%來看，這是一個不錯的數字。說明即使在利潤率不高的情況下，吉利通過較高的資產週轉率和適度的槓桿維持了不錯的股東回報率。

## 三、資產負債表：是否安全？

### 3.1 現金充裕度

總現金682億元（同比+46%）是吉利財務健康的最大亮點。按照2025年的經營規模，682億元現金約等於：

- 約2.4個月的收入
- 約4.7倍的年度核心淨利潤
- 遠超一般車企的現金儲備水平

充裕的現金意味著：即使行業繼續惡化，吉利也有足夠的"子彈"挺過寒冬。

### 3.2 資產質量

截至2025年Q3，總資產2744億元，股東權益935億元。粗略計算：

- 資產負債率約 66%（(2744-935)/2744）
- 權益乘數約 2.93

對於汽車製造業來說，66%的資產負債率處於正常偏高水平。需要關注的是負債的結構——如果主要是經營性負債（應付賬款、預收款等），問題不大；如果有息負債比例過高，則需要警惕。

### 3.3 信用評級

東方金誠對吉利控股集團維持了較高的信用評級，這從側面驗證了吉利的財務穩健性。

## 四、現金流分析：利潤的含金量

### 4.1 經營現金流

銀行結餘及現金從年初430.6億元增加到年底562.2億元（另一數據顯示總現金682億元，可能包含短期理財），說明經營活動確實在產生正現金流。

### 4.2 資本開支

汽車行業的特點是資本開支巨大。吉利每年需要在以下方面持續投入：

- 新車型研發：176億元/年
- 工廠建設和改造
- 銷售網絡擴張
- 智能化和自動駕駛技術

高資本開支意味著自由現金流（經營現金流-資本開支）可能顯著低於淨利潤。這是汽車行業"利潤好看但現金有限"的通病。

### 4.3 分紅

每股派息0.50港元（同比+51.5%），按總股本約101億股計算，總派息約50.5億港元（約46億元），佔核心淨利潤的比例約32%。

- 派息率32%在港股車企中屬於中等偏上
- 按當前股價22港元計算，股息率約2.3%
- 派息增速（+51.5%）顯著超過利潤增速，體現管理層對未來的信心

## 五、估值分析：當前價格是否低於價值？

### 5.1 相對估值

按當前股價約22港元，總股本約101億股計算：

- **市值**：約2222億港元（約2050億元）
- **PE（核心淨利潤）**：約14.2倍（2050/144.1）
- **PE（歸母淨利潤）**：約12.2倍（2050/168.5）

用戶提供的PE 5.9倍可能基於不同時間點的股價或採用預期利潤，市場也存在按吉利控股口徑（包含更多資產）計算的版本。但無論哪種口徑，吉利的估值在全球車企中都處於較低水平：

| 車企 | PE（大致） |
|------|----------|
| 比亞迪 | ~20-25倍 |
| 特斯拉 | ~50-80倍 |
| 豐田 | ~10-12倍 |
| 吉利汽車 | ~6-14倍 |
| 長城汽車 | ~10-15倍 |

### 5.2 低估值的原因

吉利估值長期偏低，可能的原因包括：

1. **港股折價**：港股整體估值低於A股和美股
2. **多品牌複雜性**：市場對"一個吉利"整合的效果持觀望態度
3. **利潤質量擔憂**：增收不增利讓市場對未來盈利能力打了折扣
4. **行業悲觀預期**：價格戰的持續讓市場給予整個汽車板塊較低估值

### 5.3 內在價值的粗略估算

**場景一：保守估計**
- 假設2026年核心淨利潤增長15%至166億元
- 給予10倍PE
- 合理市值約1660億元（約1800億港元）
- 對應股價約17.8港元（當前有下行風險）

**場景二：中性估計**
- 假設2026年核心淨利潤增長25%至180億元
- 給予12倍PE（整合效果初步顯現）
- 合理市值約2160億元（約2340億港元）
- 對應股價約23.2港元（與當前價格接近）

**場景三：樂觀估計**
- 假設2026年核心淨利潤增長35%至195億元
- 給予15倍PE（整合成功+出海放量）
- 合理市值約2925億元（約3168億港元）
- 對應股價約31.4港元（約43%上行空間）

分析師一致目標均價27.93港元，介於中性和樂觀場景之間。

### 5.4 安全邊際評估

- 當前股價22港元，在中性場景下幾乎沒有安全邊際
- 在樂觀場景下有約43%的上行空間
- 在保守場景下有約19%的下行風險
- 682億元現金提供了一定的"地板價"支撐

## 六、綜合評分與判斷

| 維度 | 評分 | 說明 |
|------|------|------|
| 收入增長 | ★★★★★ | 25-44%的增速在大型車企中屬於頂級 |
| 盈利質量 | ★★★☆☆ | 核心淨利增長不錯，但總利潤增速極低，非核心因素幹擾大 |
| 資產負債表 | ★★★★☆ | 現金充裕，但負債率偏高 |
| 現金流 | ★★★☆☆ | 經營現金流正向，但高資本開支壓縮自由現金流 |
| 估值水平 | ★★★★☆ | 相對便宜，但低估值有其合理原因 |
| 分紅能力 | ★★★☆☆ | 派息率和股息率中等，增速快但基數低 |

**核心結論：**

吉利汽車的財務狀況可以用"增長強勁但盈利質量待改善"來概括。682億元的現金儲備和302萬輛的銷量規模提供了紮實的安全墊，但4.2%的核心淨利率和幾乎為零的歸母淨利增速暴露出"以量換價"的隱患。

從估值角度看，當前價格大概率沒有被高估，但是否被低估取決於兩個關鍵假設：

1. "一個吉利"整合能否在2026-2027年兌現利潤率改善？
2. 海外出口能否從目前的墊底位置迎頭趕上？

如果兩個假設都能兌現，當前價格具有不錯的安全邊際；如果整合不及預期或出口持續落後，當前估值可能只是"合理"而非"便宜"。
