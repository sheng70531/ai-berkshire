# 海底撈（6862.HK）商業模式分析

> 分析維度：用戶價值、商業本質、差異化定位、長期競爭力
> 核心問題：這家公司是否在做"對的事情"？用戶是否真正需要它？

---

## 一、公司在做什麼生意？

海底撈的核心生意是**經營火鍋連鎖餐廳**，通過標準化的服務體驗和供應鏈管理，在全國乃至全球範圍內複製火鍋門店。當前業務結構：

1. **核心業務**：海底撈品牌火鍋餐廳（佔營收90%+）
2. **外賣業務**：2025年收入26.58億元（+112%），高速增長
3. **多品牌矩陣**：運營20個餐飲品牌（燒烤、麵食、快餐等），合計207家門店
4. **加盟業務**：2024年開放加盟，已有79家加盟門店

本質上，海底撈做的是 **"將服務體驗標準化並規模化複製"** 的生意。

## 二、用戶價值分析：消費者為什麼去海底撈？

### 消費者選擇海底撈的核心原因

1. **服務體驗**：海底撈的服務是中國餐飲業的標杆。從排隊時美甲、擦鞋，到用餐中的貼心服務，創造了遠超行業平均的用餐體驗。

2. **品質信任**：大品牌提供食品安全保障。消費者去海底撈，不會擔心食材問題。這在食品安全事件頻發的中國市場是巨大的信任溢價。

3. **社交場景**：火鍋天然適合聚會/社交，海底撈的大店模式可以容納各種人數組合。

4. **穩定的期望管理**：全國任何一家海底撈，品質和服務都高度一致。消費者知道自己會獲得什麼——這種"確定性"本身就是價值。

### 用戶願意付的溢價

海底撈客單價約100-120元，高於多數本土火鍋品牌（60-80元）但低於高端餐飲。消費者為"服務+品質+確定性"支付了約30-50%的溢價。

### 關鍵質疑

1. **服務溢價能否持續？** 隨著海底撈規模擴大、翻檯壓力增加，服務質量是否會下降？
2. **年輕消費者是否仍然買單？** 新一代消費者可能更追求性價比或新鮮感，而非"極致服務"。
3. **火鍋品類本身的天花板？** 中國火鍋市場規模巨大但已趨於飽和。

## 三、商業模式的"對"與"不對"

### 做對的事情 ★★★★☆

**對的方面：**

1. **服務為核心競爭力**：在一個"內卷"的餐飲市場，海底撈通過服務建立了獨特的品牌認知。多數競爭對手學不會這種以服務為核心的管理體系——因為這不僅是培訓問題，更是組織文化和激勵機制的問題。

2. **供應鏈優勢**：頤海國際提供標準化底料，蜀海供應鏈提供食材配送。這種"後臺標準化"能力使得千店一味成為可能。

3. **組織能力**：海底撈獨創的"師徒制"管理模式，解決了餐飲業最難的問題——人的管理。店長培養系統化，使得快速擴張時品質可控。

4. **品牌延伸（多品牌+外賣）**：2025年外賣收入翻倍至26.58億，多品牌收入增214%。這說明海底撈的能力正在向更多場景溢出。

**存疑的方面：**

1. **增長見頂**：營收僅增長1.1%，翻檯率回升到4.0但進一步提升空間有限。單店模型已經非常成熟，但增量來自哪裡？

2. **加盟制的雙刃劍**：開放加盟可以加速擴張，但也可能稀釋服務品質。火鍋品牌最怕的就是"加盟做爛了品牌"。

3. **多品牌驗證不足**：20個品牌、207家門店看起來熱鬧，但多數品牌規模極小，能否獨立成長為另一個"海底撈"存疑。

4. **人工成本壓力**：海底撈的服務密度意味著極高的人工成本。隨著勞動力成本上升，利潤率可能承壓。

## 四、差異化定位與護城河評估

### 護城河分析 ★★★★☆

| 護城河類型 | 評估 |
|-----------|------|
| 品牌價值 | ★★★★★ 中國餐飲第一品牌，全民認知 |
| 組織能力 | ★★★★★ 師徒制+激勵體系，極難複製 |
| 供應鏈 | ★★★★☆ 頤海+蜀海構建了高效後臺 |
| 規模效應 | ★★★★☆ 1383家門店帶來採購和品牌優勢 |
| 轉換成本 | ★★☆☆ 消費者隨時可以去其他火鍋店 |

**海底撈最大的護城河不是產品（火鍋本身不難複製），而是組織能力——將數萬名員工管理成能夠提供一致高水平服務的團隊。這是一個"系統性能力"，不是單點技術可以破解的。**

### 段永平式的追問

**"這個生意十年後會怎樣？"**

- 人們十年後仍然會吃火鍋 ✓
- 海底撈品牌十年後大概率仍然存在 ✓
- 但能否繼續增長？不確定
- 翻檯率和門店數的天花板在哪裡？

**"消費者真的需要海底撈嗎？"**

需要，但不是"非它不可"。火鍋是一個極度分散的市場——消費者有大量替代選擇。海底撈的優勢是"確定性好"（不會踩雷），但如果消費者追求新鮮感、性價比或其他口味，隨時可以選擇其他品牌。

**"管理層是否在做最重要的事？"**

張勇/苟軼群做了兩件重要的事：
1. 開放加盟——承認自營擴張速度的極限，用加盟獲得增量
2. 多品牌探索——試圖尋找第二增長曲線

但核心問題沒變：火鍋賽道的天花板。無論自營還是加盟，中國市場能容納多少家火鍋店是有上限的。

## 五、商業模式的終極拷問

### "好生意"還是"好公司"？

**好生意的特徵**：
- ✓ 高頻消費（每月1-2次）
- ✓ 品牌溢價（客單價高於行業）
- ✓ 可複製的模型
- ✓ 高現金流（預收+快週轉）
- ✗ 低資本支出（開新店需要大量資本）
- ✗ 高增長（已見頂）

**結論**：海底撈是一個"好但不完美"的生意——高ROE、強現金流、有護城河，但增長空間受限，且開新店需要持續資本投入。

## 六、綜合評估

| 維度 | 評分 | 說明 |
|------|------|------|
| 用戶價值 | ★★★★★ | 服務體驗在中國餐飲業無可匹敵 |
| 商業邏輯 | ★★★★☆ | 高ROE+強現金流，但增長見頂 |
| 定位差異化 | ★★★★★ | "服務"標籤深入人心 |
| 護城河深度 | ★★★★☆ | 組織能力是真護城河，但消費者無鎖定 |
| 長期確定性 | ★★★★☆ | 品牌和生意可持續，增速不確定 |

**總體商業模式評分：★★★★☆（4/5）**

海底撈擁有五家公司中最強的護城河和最高的ROE。它的服務體驗和組織能力確實構成了競爭壁壘。主要的隱憂是增長見頂——在一個已經非常成功的業務上繼續增長，難度遠大於從零到一。但即使不增長，這仍然是一個高質量的"現金牛"生意。
