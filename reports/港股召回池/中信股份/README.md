# 中信股份（0267.HK）投資研究

## 基本信息
- **公司名稱**：中國中信股份有限公司
- **股票代碼**：0267.HK
- **行業**：綜合集團（金融+實業）
- **PE（TTM）**：5-6倍
- **ROE**：8-9%

## 2025年度核心財務數據
| 指標 | 數值 | 同比變化 |
|------|------|----------|
| 收入 | 7,693億元 | +3.0% |
| 歸母淨利潤 | 587億元 | +0.9% |
| 末期股息 | 每股0.385元 | - |

## 投資亮點
1. PE僅5-6倍——與長實並列最低估值
2. ROE 8-9%——在低PE公司中相對較好
3. 中信銀行+中信證券+中信建投=強綜合金融
4. 政策紅利（央企改革+市值管理）

## 核心風險
1. 綜合集團折讓嚴重
2. 銀行業淨息差持續收窄
3. 業務過於分散（金融+地產+製造+資源等）
4. 利潤增速極慢（+0.9%）
