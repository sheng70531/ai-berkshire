# 小鵬汽車（9868.HK）行業競爭分析

> 分析維度：競爭格局、護城河、行業終局、逆向思考
> 分析日期：2026年5月16日

---

## 一、行業全景：中國新能源汽車的殘酷競技場

### 1.1 市場格局

中國新能源汽車市場已經形成清晰的梯隊分層：

**第一梯隊：百萬輛級**
- 比亞迪：絕對王者，年銷超400萬輛，從低端到高端全覆蓋

**第二梯隊：50-80萬輛級**
- 吉利/長安等傳統車企的新能源板塊

**第三梯隊：30-50萬輛級**
- 理想汽車：家庭增程SUV細分市場龍頭
- 零跑汽車：2026年Q1新勢力銷量冠軍
- 小鵬汽車：2025年交付43萬輛

**第四梯隊：20-40萬輛級**
- 蔚來汽車：高端服務+換電生態
- 小米汽車：生態鏈跨界

造車新勢力中，零跑、小鵬、理想、蔚來是碩果僅存的四家。但2026年Q1的格局發生了微妙變化：零跑站上榜首，理想和蔚來反超小鵬。小鵬3月交付27,415輛，單月和季度都在下滑。

### 1.2 競爭維度

當前新能源汽車競爭已從單一的"三電技術"維度，演變為多維立體競爭：

| 競爭維度 | 領先者 | 小鵬位置 |
|----------|--------|----------|
| 智能駕駛 | 小鵬/華為 | 第一梯隊 |
| 成本控制 | 比亞迪 | 中游 |
| 品牌溢價 | 蔚來/特斯拉 | 偏弱 |
| 產品定義 | 理想 | 中游偏上 |
| 生態協同 | 小米/華為 | 弱 |
| 全球化 | 比亞迪 | 積極推進中 |
| 渠道效率 | 比亞迪/理想 | 中游 |

## 二、小鵬的競爭優勢：智能駕駛這條護城河有多深？

### 2.1 技術領先性

小鵬在智能駕駛領域的領先體現在多個層面：

**算法層**
- 行業首批實現"端到端"大模型上車
- 第二代VLA（視覺-語言-動作）模型即將量產
- XNGP覆蓋全國2595個城市，累計測試756萬公里

**芯片層**
- 自研圖靈AI智駕芯片，已獲大眾定點
- 從"用別人的芯片跑自己的算法"轉向"用自己的芯片跑自己的算法"

**數據層**
- 43萬輛在路上跑的車輛每天產生海量駕駛數據
- 數據飛輪效應：更多車 -> 更多數據 -> 更好的模型 -> 更好的體驗 -> 更多用戶

**工程化能力**
- 70天內5次全量推送，35個版本迭代
- AI天璣系統已成為業內迭代最快的智駕系統之一

### 2.2 但護城河有多深？——逆向思考

**反面論點一：技術差距在縮小**

2024-2025年，多家車企智駕能力快速追趕：
- 華為ADS 3.0在部分場景已與小鵬不相上下
- 比亞迪"天神之眼"高階智駕開始全系標配
- 蔚來、理想均推出端到端方案
- 特斯拉FSD在海外市場積累了更多數據

智駕不像社交網絡那樣具有網絡效應——用戶不會因為"別人也用小鵬"而選擇小鵬。技術領先是暫時的，不是永久的。

**反面論點二：智駕不是購車的唯一決策因素**

消費者買車考慮的因素包括：價格、外觀、空間、品牌、服務、續航等。智駕在決策權重中通常排在前三之後。MONA M03的成功更多靠的是"11.98萬有高階智駕"的極致性價比，而非單純的技術領先。

**反面論點三：大模型時代技術趨同**

端到端大模型的底層架構趨同（都是Transformer），差異化越來越依賴數據量和算力。而算力可以用錢買，數據可以隨銷量增長——這意味著比亞迪（年銷400萬輛）一旦認真做智駕，數據量將遠超小鵬。

### 2.3 護城河深度評估

| 護城河類型 | 適用性 | 評估 |
|------------|--------|------|
| 品牌護城河 | 弱 | "智駕=小鵬"的心智尚未穩固建立 |
| 網絡效應 | 中 | 數據飛輪存在但非排他性 |
| 轉換成本 | 弱 | 用戶可以隨時換品牌 |
| 成本優勢 | 中 | 平臺化降本，但不如比亞迪垂直整合 |
| 技術專利 | 中強 | 自研芯片+算法，但大模型時代壁壘降低 |
| 規模經濟 | 中 | 43萬輛有一定規模，但遠不及比亞迪 |

**綜合判斷：小鵬有護城河，但不是寬闊的護城河。更準確地說，是一條"正在挖掘中"的護城河——技術授權如果能持續擴展客戶，才能將技術優勢轉化為真正的結構性壁壘。**

## 三、技術授權：改變遊戲規則的可能性

### 3.1 從"賣車"到"賣鏟子"

如果把智能駕駛看作"淘金熱"，那麼：
- 賣車 = 自己去淘金（高風險、高資本、週期性）
- 技術授權 = 賣鏟子（低風險、高利潤、可複製）

小鵬與大眾的合作本質上是從淘金者向賣鏟子者的轉型嘗試：

- 大眾是全球最大的汽車集團，年銷近900萬輛
- 如果合作成功，大眾的數百萬輛車都將搭載小鵬技術
- 這比小鵬自己賣43萬輛車產生的數據和收入都要大得多

### 3.2 競爭對手的類似路徑

| 公司 | 技術授權模式 | 進展 |
|------|-------------|------|
| 華為（智選車模式） | 向問界/智界/享界提供HI方案 | 最成功，但華為不造整車 |
| Mobileye | 向多家OEM提供ADAS方案 | 被Intel收購，但增速放緩 |
| 大疆車載 | 向多家車企提供中低端方案 | 成本優勢明顯 |
| 小鵬 | 向大眾提供EEA/VLA/芯片 | 深度綁定，但客戶單一 |

小鵬的問題在於：目前只有大眾一個技術授權客戶。如果能在2-3年內拓展至3-5家OEM，技術授權的護城河效應將指數級增強。

## 四、行業終局思考

### 4.1 新能源汽車行業會像手機行業一樣嗎？

一個值得思考的類比：

| 維度 | 手機行業終局 | 汽車行業可能的終局 |
|------|-------------|-------------------|
| 市場集中度 | 高（蘋果+三星+華米OV） | 可能中高（比亞迪+3-5家） |
| 利潤分配 | 極度集中（蘋果拿80%利潤） | 可能類似（比亞迪/特斯拉拿大頭） |
| 差異化來源 | 生態系統 > 硬件 | 智能化 > 三電 > 機械素質 |
| 價格戰終局 | 中低端無利潤 | 正在發生 |

如果汽車行業走向手機化終局，那麼：
- 比亞迪可能是三星（全產業鏈+規模優勢）
- 特斯拉可能是蘋果（品牌+生態+溢價）
- 小鵬可能是... 高通？（技術授權+自有品牌）

這是一個有趣但不確定的類比。如果小鵬能成為"智駕領域的高通"，其價值將遠超一家年銷40萬輛的車企。

### 4.2 價格戰何時結束？

當前中國新能源汽車行業的價格戰已持續超過2年，核心原因是：
- 產能過剩——全行業產能利用率不足60%
- 玩家過多——仍有數十個品牌在運營
- 消費降級——經濟環境壓制購買力

價格戰的終局通常是淘汰賽：當足夠多的弱勢品牌退出後，倖存者才能恢復合理利潤。

小鵬的位置：處於安全區但不是舒適區。476億現金和轉正的現金流意味著不會在這輪淘汰賽中出局，但持續的價格戰會壓制盈利改善的速度。

## 五、全球化競爭分析

### 5.1 海外市場進展

| 市場 | 進展 | 策略 |
|------|------|------|
| 歐洲 | Q1交付6,968輛（+179%），與麥格納合作本地化生產 | 本地生產規避關稅 |
| 東南亞 | 馬來西亞工廠投產（G6+X9） | 製造基地輻射區域 |
| 中東/拉美 | 渠道建設中 | 2026年擴至60國 |

2025年海外交付45,008輛（+96%），佔總交付約10%。目標2026年海外銷量翻番。

### 5.2 全球化競爭格局

- 比亞迪在海外已建立先發優勢（泰國、巴西、匈牙利建廠）
- 歐盟36%關稅是最大挑戰，本地化生產成為必選項
- 小鵬正在洽購大眾在歐洲的閒置工廠，如果成功將是一步好棋
- 智駕功能在海外的競爭力可能更強（歐美對手智駕能力普遍弱於中國車企）

### 核心判斷

用逆向思維來問：**什麼情況下小鵬會輸？**

1. 智駕技術差距被抹平，小鵬失去最核心的差異化——**可能性中等**
2. 價格戰持續3年以上，小鵬的現金儲備被消耗殆盡——**可能性低**（476億現金+正現金流）
3. 大眾合作終止或不再擴展——**可能性中低**（已進入深度綁定階段）
4. 何小鵬同時開多條戰線導致執行力崩潰——**可能性中等**
5. 政策突變（如限制L4、智駕事故立法等）——**可能性低但影響大**

**用反過來的方式想**：如果上述五個風險都沒有發生，3年後的小鵬會是什麼樣？大概率是一家年交付60-80萬輛、技術授權覆蓋3-5家OEM、物理AI開始產生收入的科技型汽車公司。這樣的公司值多少錢？遠超當前1200億港元市值。

關鍵在於，你是否願意為這個"大概率"承擔那些"中等概率"的風險。
