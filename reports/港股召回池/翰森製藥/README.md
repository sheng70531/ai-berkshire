# 翰森製藥（3692.HK）投資研究

## 公司概況

翰森製藥集團有限公司（Hansoh Pharmaceutical Group Company Limited），港交所代碼 3692.HK，是中國領先的創新驅動型製藥企業。公司 2019 年 6 月在香港上市，由鍾慧娟創立並擔任主席兼首席執行官。

**核心業務領域：** 抗腫瘤、中樞神經系統、抗感染、代謝性疾病、自身免疫等五大治療領域。
