## 研究背景

銀河娛樂是澳門六大博彩持牌商之一，以財務健康著稱——零淨負債、現金儲備充裕（363億港元現金及流動投資）。公司由呂志和家族控制，2024年11月創始人呂志和逝世後，其子呂耀東接任董事會主席。

**研究觸發因素：**
- 澳門博彩股中財務最健康的標的
- PE 13-14倍，處於歷史估值中樞偏低位置
- ROE 13-14%，穩定且有提升空間
- 牌照壟斷（澳門僅6張博彩牌照，有效期至2032年）
- 第四期項目2027年完工將帶來增長
