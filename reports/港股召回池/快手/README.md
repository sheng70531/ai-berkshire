## 研究背景

快手是中國第二大短視頻平臺，僅次於抖音。公司在2025年實現了營收1428億元、經調整淨利潤206億元的歷史最佳業績，但股價在年報發佈後反而暴跌14%，市場給出的信號非常明確：**利潤的質量不如利潤的增長重要**。

核心矛盾在於：
- **用戶增長見頂**：MAU增速降至2%以下，Q4環比流失800萬DAU
- **電商增速下行**：GMV增速從2021年的78%降至2025年的15%，公司宣佈不再披露GMV
- **可靈AI是唯一亮點**：ARR從2025年底的2.4億美元飆升至2026年4月的5億美元，傳聞分拆估值200億美元
- **估值便宜但有原因**：PE 11-12倍，低於抖音集團和騰訊，但增長敘事面臨挑戰
