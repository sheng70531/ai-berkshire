## 投資背景

比亞迪是全球新能源汽車龍頭，2025年純電動車銷量超越特斯拉成為全球第一。公司採用垂直整合模式，覆蓋電池、電機、電控、半導體等核心零部件。當前處於全球化擴張期，2026年海外銷量目標130萬輛。主要風險包括價格戰壓制利潤率、歐盟關稅壁壘、地緣政治不確定性。
