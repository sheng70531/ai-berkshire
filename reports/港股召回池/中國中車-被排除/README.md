# 中國中車（1766.HK）投資研究

## 基本信息
- **公司名稱**：中國中車股份有限公司
- **股票代碼**：1766.HK
- **行業**：軌道交通裝備
- **PE（TTM）**：8-9倍
- **ROE**：~8%

## 2025年度核心財務數據
| 指標 | 數值 | 同比變化 |
|------|------|----------|
| 營業收入 | 2,731億元 | +10.79% |
| 歸母淨利潤 | 131.8億元 | +6.40% |
| 新簽訂單 | 3,461億元 | 強勁 |
| 海外收入 | 348億元 | +22.88% |
| 海外收入佔比 | 12.75% | 持續提升 |

## 業務結構
| 板塊 | 收入 | 同比 |
|------|------|------|
| 鐵路裝備 | 1,236億元 | +11.9% |
| 新產業 | 1,031億元 | +19.4% |
| 城軌與基礎設施 | 421億元 | -7.4% |

## 投資亮點
1. 全球軌交裝備龍頭——市場份額全球第一
2. 新產業收入突破千億——第二增長曲線成型
3. 海外收入增長23%——國際化加速
4. PE僅8-9倍——對增長性而言便宜

## 核心風險
1. 國內鐵路投資高峰已過
2. 淨利率偏低（~4.8%），利潤薄
3. 海外業務面臨地緣政治阻力
4. 城軌業務下滑7.4%
