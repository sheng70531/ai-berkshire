# 藥明康德（2359.HK / 603259.SH）投資研究框架

> 研究日期：2026年5月16日 | 團隊：投研四大師框架 | 貨幣：人民幣（除非特別標註）

---

## 研究框架

本研究從四個維度對藥明康德進行深度分析：

| 維度 | 分析師視角 | 核心關注 |
|------|-----------|---------|
| 商業模式 | 段永平"好生意"視角 | CRDMO一體化平臺是否具備長期可持續性 |
| 財務估值 | 巴菲特價值投資視角 | 盈利質量、現金流、估值合理性 |
| 行業競爭 | 芒格"護城河"視角 | 競爭壁壘的深度與持久性 |
| 風險管理層 | 李錄中國視角 | 政策風險、管理層信任度、治理結構 |

---

## 核心結論

**綜合評級：★★★☆☆（3.5/5）— 優質生意，但治理與政策風險壓制估值**

藥明康德是全球少有的"一體化CRDMO"平臺型公司，2025年營收454.6億元（同比+15.8%），歸母淨利潤191.5億元（同比+102.6%），在手訂單580億元創歷史新高。化學業務佔比超80%，TIDES業務（多肽+寡核苷酸）全年收入113.7億元同比增長96%，受益於GLP-1減肥藥浪潮。公司ROE約17%，毛利率46.6%，賬面現金351億元，財務狀況健康。

**核心矛盾在於**：（1）美國BIOSECURE法案已於2025年12月簽署成法，雖未點名藥明康德，但OMB須於2026年12月前公佈"受關注生物技術公司"名單，若被列入，對美國聯邦業務的影響將在2027年後逐步顯現；（2）實控人李革團隊自2022年以來累計減持套現近200億元，管理層與股東利益一致性存疑；（3）研發費用連續三年下滑，員工人數淨減少5,580人，"降本增效"還是"透支未來"需持續觀察。

**買入條件**：港股PE回落至15倍以下（對應股價約75港元），或BIOSECURE名單明確排除藥明康德。當前25倍PE已充分反映樂觀預期，安全邊際不足。
