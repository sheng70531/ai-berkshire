## 研究背景

中電控股是香港兩大電力供應商之一，為九龍、新界及大部分離島約283萬客戶供電，供電可靠性達99.999%。香港電力業務受《管制計劃協議》保障，準許回報率為固定資產淨值的8%，協議有效期至2033年。

公司業務遍及香港、中國內地、澳洲、印度及東南亞，是亞太區領先的電力企業。控股股東為嘉道理家族，持股約35%，家族經營超過百年。
