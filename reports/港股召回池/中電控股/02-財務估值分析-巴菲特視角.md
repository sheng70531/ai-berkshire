# 中電控股（0002.HK）財務估值分析

> 分析維度：財務健康度、盈利質量、資本配置、內在價值
> 核心問題：財務數據是否支撐長期持有？當前價格是否合理？

---

## 一、盈利能力分析

### 1.1 收入與利潤趨勢

| 指標 | 2023年 | 2024年 | 2025年 | 趨勢 |
|------|--------|--------|--------|------|
| 營業收入 | 約930億 | 909.6億 | 880.2億 | 連續下降 |
| 經營溢利（不含公允價值變動） | — | 109.5億 | 106.9億 | -2.4% |
| 歸母淨利潤 | — | 117.4億 | 104.7億 | -10.8% |
| 每股盈利 | — | 約4.64港元 | 約4.14港元 | 下降 |

*單位：港元*

2025年營收同比下降3.2%，歸母淨利下降10.8%，但經營溢利（剔除公允價值變動後的"核心利潤"）僅下降2.4%。這個差距說明：**核心運營實際上比較穩定，利潤大幅下降更多是由非經常性項目和公允價值波動造成的。**

關注經營溢利而非歸母淨利潤，是評估公用事業公司更合理的方式。

### 1.2 分部盈利質量

2025年經營溢利106.9億港元的構成：

| 板塊 | 金額（億港元） | 佔比 | 同比 |
|------|---------------|------|------|
| 香港 | ~95 | ~89% | +7% |
| 中國內地 | 16.0 | ~15% | -13.7% |
| 澳洲 | 0.85 | ~1% | -85.6% |
| 印度 | 2.2 | ~2% | -32.8% |
| 其他/調整 | ~-7 | — | — |

**核心發現**：香港業務貢獻了約89%的經營溢利，且同比增長7%。這是整個利潤結構的"定海神針"。如果只看香港業務，中電的盈利實際上是在改善的。

但反過來說，這也意味著海外三個市場（中國內地、澳洲、印度）合計投入了大量資本，卻只貢獻了約11%的利潤。**資本配置效率存在明顯問題。**

### 1.3 ROE分析

| 指標 | 數據 |
|------|------|
| ROE（TTM） | ~10.2% |
| 股東權益 | ~1,174億港元 |
| 歸母淨利 | ~104.7億港元 |

10.2%的ROE對公用事業公司來說處於中等偏上水平。但要注意幾個結構性因素：

- 香港業務的準許回報率是固定資產淨值的8%，但由於槓桿效應（用債務為部分固定資產融資），實際ROE可以高於8%
- 海外業務ROE顯著低於香港業務，整體ROE被拉低
- 如果澳洲業務能恢復到正常盈利水平，整體ROE可能回升到11-12%

## 二、資產負債表健康度

### 2.1 資產質量

| 指標 | 數據 |

| 總資產 | ~2,386億港元 |
| 固定資產 | 佔比高（電力行業特徵） |
| 總負債 | ~1,212億港元 |
| 有息負債 | ~620億港元 |
| 淨負債 | ~620億港元 |
| 股東權益 | ~1,174億港元 |

### 2.2 槓桿水平

| 指標 | 數據 | 評價 |
|------|------|------|
| 負債權益比 | 52.8% | 公用事業中屬於適中 |
| 經營現金流覆蓋債務 | 39.3% | 尚可 |
| 流動性儲備 | ~300億港元 | 充裕 |

**評價**：公用事業公司天然適合適度槓桿經營，因為收入高度確定。52.8%的負債權益比在行業中屬於保守一側。中電的資產負債表是健康的。

但需要關注的是，未來幾年脫碳投資（新建可再生能源、淘汰煤電）可能導致資本開支上升，進而推高負債率。

### 2.3 現金流質量

2025年上半年集團投入約70億港元資本開支，其中香港約45億港元。全年資本開支預計在130-150億港元水平。

電力行業的特點是"重資本、穩現金流"。中電的經營現金流長期穩定，足以覆蓋日常運營和股息支出，但大型資本開支項目仍需藉助外部融資。

## 三、股息政策分析

### 3.1 股息歷史

|------|-----------------|---------|
| 2021年 | 3.10 | — |

### 3.2 派息率與可持續性

| 指標 | 數據 |
|------|------|
| 2025年每股股息 | 3.20港元 |
| 2025年每股盈利 | ~4.14港元 |
| 派息率 | ~77% |
| 當前股息率（以74港元股價計） | ~4.3% |

77%的派息率對公用事業公司來說屬於正常範圍，但已經不算低了。如果未來利潤進一步下滑（比如澳洲持續虧損或管制回報率下調），維持當前股息水平可能面臨壓力。

**正面信號**：即使2025年利潤下降10.8%，管理層仍選擇小幅加息，說明對未來現金流有信心。中電連續多年維持或增加股息，體現了穩定的股息文化。

**需要警惕**：如果未來要大幅增加脫碳投資，可能面臨"資本開支 vs 股息"的兩難選擇。

## 四、資本配置評估

### 4.1 過去的資本配置

中電的資本配置邏輯一直是：**以香港為根基，向海外拓展以尋求增長**。

從結果看，這一策略的成效參差不齊：

| 市場 | 資本投入 | 回報評價 |
|------|---------|---------|
| 香港 | 持續穩定投入 | ★★★★★ 受監管保護，回報確定 |
| 中國內地 | 大量投入（核電、風電、光伏） | ★★★☆☆ 有戰略價值，但政策風險上升 |
| 澳洲 | 大量投入 | ★☆☆☆☆ 長期表現不佳，2025年幾乎無利潤 |
| 印度 | 中等投入 | ★★☆☆☆ 規模不足以形成競爭力 |

**核心問題**：中電在海外市場的資本配置效率低下。如果將投入澳洲和印度的資本回收，全部投入香港（在管制框架允許的範圍內）或以特別股息返還股東，整體回報率可能更高。

### 4.2 未來資本開支方向

管理層已表示將資本重點放在香港和中國內地，澳洲和印度的項目需要自負盈虧。這是一個正確的方向調整，但關鍵在於執行。

脫碳投資是未來十年最大的資本開支驅動力：
- 2040年前淘汰煤電需要大量替代投資
- 可再生能源和儲能設施建設
- 天然氣過渡方案

這些投入在香港可以通過管制框架獲得8%回報，但在海外市場則面臨市場化的競爭壓力。

## 五、估值分析

### 5.1 當前估值水平

| 指標 | 數據 |

| PE（TTM） | ~18.6倍 |
| PE（Forward） | ~17.3倍 |
| EV/EBITDA | ~10.3倍 |
| PB | ~1.6倍 |
| 股息率 | ~4.3% |

### 5.2 估值合理性評估

**與歷史比較**：
中電的PE歷史波動範圍大致在14-20倍之間。當前18.6倍處於中等偏高位置，不算便宜，但也談不上泡沫。

**與同類比較**：
- 港燈（2638.HK）：PE約14-15倍，股息率約6-7%，純香港業務
- 長江基建：PE約12倍
- 全球公用事業龍頭：PE通常15-20倍

中電的估值高於港燈，部分反因為市場給予其"增長溢價"（海外業務的可能性）。但從實際表現看，這個溢價是否合理值得商榷。

### 5.3 內在價值測算

**方法一：股息折現模型（DDM）**

假設：
- 當前每股股息：3.20港元
- 股息增長率：2%（保守估計，接近通脹率）
- 折現率：7%（考慮香港無風險利率+股權風險溢價）

內在價值 = 3.20 / (7% - 2%) = 64港元

**方法二：調整後DDM（樂觀情景）**

假設：
- 股息增長率：3%（管制框架下固定資產增長+小幅電價調整）
- 折現率：6.5%

內在價值 = 3.20 / (6.5% - 3%) = 91.4港元

**方法三：盈利估值法**

假設中電的合理PE為15-18倍（公用事業合理區間），2025年每股盈利約4.14港元：
- 保守估值：4.14 x 15 = 62港元
- 中性估值：4.14 x 17 = 70港元
- 樂觀估值：4.14 x 18 = 74.5港元

### 5.4 估值結論

| 情景 | 估值區間 | 說明 |
|------|---------|------|
| 保守 | 62-64港元 | 假設增長停滯，海外業務持續低迷 |
| 中性 | 70-74港元 | 假設當前狀態延續，股息溫和增長 |
| 樂觀 | 85-91港元 | 假設澳洲轉好，內地穩定，股息增長加速 |

**當前股價74港元處於中性估值的上沿**，安全邊際不足。

## 七、關鍵結論

**財務上的確定性**：
- 香港業務受管制保護，利潤確定性極高
- 資產負債表健康，債務可控
- 股息政策穩健，連續多年增長或維持

**財務上的隱憂**：
- 澳洲業務2025年幾乎"歸零"，大量資本無法產生回報
- 海外業務整體資本回報率遠低於香港業務
- 未來脫碳投資可能推高負債或壓縮分紅空間

**估值判斷**：
當前74港元的股價，對應約4.3%的股息率和18.6倍PE，提供的回報率約為"股息率4.3% + 增長率2% = 年化6.3%"。對於一隻公用事業股來說，這個回報預期不算差，但也稱不上便宜。

如果追求安全邊際，更合理的買入價格應在60-65港元區間（對應5%以上股息率），屆時將提供更充足的下行保護。
