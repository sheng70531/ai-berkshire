## 研究框架

本研究採用四維並行分析框架，分別從商業模式、財務估值、行業競爭和風險管理層四個維度對創科實業進行深度剖析：

## 核心結論

**綜合評分：★★★★☆（4/5）**

創科實業是港股最稀缺的全球製造業龍頭之一。Milwaukee品牌定位專業級市場，形成了"電池平臺鎖定+持續新品擴展"的飛輪效應；Ryobi覆蓋消費級市場，通過Home Depot獨家渠道穩定增長。公司2025年營收153億美元，自由現金流14億美元，淨現金7億美元，資產負債表極為健康。毛利率從2015年的35.7%穩步提升至2025年的41.2%，體現品牌溢價能力持續增強。

主要風險在於：（1）美國關稅政策的不確定性，雖已基本完成中國對美出口的產能轉移，但局勢仍在變化；（2）美國住房市場週期性波動對需求的影響；（3）新CEO Steven Richman上任不足兩年，需觀察執行力。

當前股價約124.5港元（2026年5月），對應2025年PE約23倍。考慮到公司的龍頭地位、持續的利潤率改善和強勁的自由現金流，估值合理但談不上便宜。建議**觀望等待更好價格，或在100港元以下積極買入**。

**投資建議：觀望（等待安全邊際）**
