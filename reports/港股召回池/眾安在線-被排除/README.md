## 研究框架

1. **商業模式分析**（段永平視角）：互聯網保險的本質、差異化
2. **財務估值分析**（巴菲特視角）：盈利質量、成長性、估值
3. **行業競爭分析**（芒格視角）：保險科技格局、護城河
4. **風險管理層評估**（李錄視角）：管理層、科技風險

- 總保費：357.35億元（+6.9% YoY）
- 經調整歸母淨利潤：18.00億元（+198.3% YoY）
- 承保利潤：連續第五年盈利
- 綜合成本率：~96%（H1為95.6%）
- 四大業務板塊：健康險、數字生活險、汽車險、消費金融險

- 自營渠道保費：75.57億元（佔比21.1%）
- AI平臺調用：超20億次
