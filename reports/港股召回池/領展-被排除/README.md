## 核心定位

亞太區最大的房地產投資信託基金，以香港社區零售商場為核心，輔以中國內地、澳大利亞、新加坡及英國的零售、辦公及物流資產。物業組合地理分佈：香港74.4%、中國內地13.8%、海外11.8%。
