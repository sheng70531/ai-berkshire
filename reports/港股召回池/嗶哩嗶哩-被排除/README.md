## 研究背景

嗶哩嗶哩是中國Z世代視頻社區平臺，以彈幕文化和PUGV（專業用戶生成視頻）內容為核心。2025年首次實現全年盈利，但商業化效率相比抖音、快手仍有較大差距。當前PE約30倍（調整後淨利潤口徑），市場分歧在於：B站的社區屬性是商業化的天花板，還是尚未釋放的價值金礦？
