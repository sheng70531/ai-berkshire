# 嗶哩嗶哩：財務與估值分析

> 分析維度：財務質量、盈利能力、資本配置、內在價值
> 核心問題：首次盈利後，這個"賺錢能力"能持續嗎？當前價格便宜還是貴？

---

## 一、財務概覽：從鉅虧到微利的轉折

嗶哩嗶哩2025年首次實現全年GAAP盈利，這是一個里程碑事件。但我們需要冷靜地看待這個"盈利"——它是微利，還遠談不上"賺錢能力強"。

**2025年關鍵財務數據：**

| 指標 | 2025年 | 2024年 | 同比變化 |
|------|--------|--------|---------|
| 總營收 | 303.5億 | 268.3億 | +13.1% |
| 毛利潤 | 111.1億 | 87.7億 | +26.7% |
| 毛利率 | 36.6% | 32.7% | +3.9pp |
| GAAP淨利潤 | 11.9億 | 虧損 | 扭虧 |
| 調整後淨利潤 | 25.9億 | ~5.4億 | +約380% |
| 經營現金流 | 71億 | ~55億 | +約29% |

從數據看，B站的財務狀況確實在快速改善。毛利率從32.7%提升到36.6%，說明收入質量在提高——廣告業務佔比提升（廣告是高毛利業務）和成本控制見效。但11.9億的GAAP淨利潤對應303.5億的營收，淨利率僅3.9%。即使用調整後口徑的25.9億，淨利率也只有8.5%。與騰訊、網易等成熟互聯網公司20-30%的淨利率相比，差距很大。

## 二、收入質量分析

**收入增長的可持續性：**

2025年營收增速13.1%，相比前幾年30%以上的高增速已經明顯放緩。拆分來看：

- **廣告（+23%）：** 增速最快，是核心驅動力。但100.6億的體量在中國互聯網廣告市場中仍然很小（抖音廣告收入超過3,000億），增長空間大但競爭激烈。
- **增值服務（+8%）：** 增速在放緩，大會員滲透率提升困難，這個板塊未來很難成為增長引擎。
- **遊戲（+14%）：** 受益於《三國：謀定天下》和《逃離鴨科夫》，但遊戲收入的波動性大，不能線性外推。
- **IP衍生（-3%）：** 在萎縮，尚未找到有效模式。

一個值得關注的結構性變化是：廣告收入佔比從2023年的約28%提升到2025年的33%，而增值服務從約43%降到39%。這意味著B站的收入結構正在從"向用戶收費"轉向"向廣告主收費"，這是一個更可持續的方向——因為廣告主為觸達高價值年輕用戶願意付費，而用戶的付費意願相對有限。

**收入質量評分：★★★☆☆（3/5）**

收入在增長且結構在優化，但增速放緩、遊戲業務波動大、IP衍生在下滑，整體收入質量中等。

## 三、利潤率與成本結構

毛利率36.6%在互聯網公司中偏低。主要成本構成包括：

- **收入分成成本：** 向UP主、主播的分成是最大的成本項，隨著創作者生態壯大，這部分成本有剛性。
- **內容成本：** 自制內容、版權採購的投入。
- **帶寬與服務器成本：** 視頻平臺的固有成本，隨用戶增長而增加。

好消息是毛利率在快速改善（2023年約28%，2024年32.7%，2025年36.6%），說明B站在控制成本方面取得了進展。AI技術的應用（超50%效果廣告素材由AIGC生成）有望進一步降低運營成本。

**經營槓桿：** B站已過了大規模投入期，研發和銷售費用的增速低於收入增速，經營槓桿開始釋放。管理層表示2026年將額外投入5-10億用於AI研發，這可能短期壓制利潤率，但如果產出有效，中長期有利於效率提升。

**利潤率趨勢評分：★★★★☆（4/5）**

利潤率改善趨勢明確，但絕對水平仍然偏低，需要持續跟蹤。

## 四、現金流與資產負債表

**現金流：**

2025年經營現金流71億元，這是一個比淨利潤更有說服力的數字。71億的經營現金流意味著B站的業務在真實地產生現金，不依賴會計調整。自由現金流（經營現金流減去資本開支）也應該是正的，這是財務健康的重要標誌。

**資產負債表：**

截至2025年Q3，B站持有現金、定期存款和短期投資合計234.9億元（約33億美元）。考慮到公司市值約735億港元（約94億美元），現金佔市值的比例約35%，這是一個非常厚實的現金墊。

B站還有可轉債等債務，但整體負債水平可控。重要的是，公司手裡有錢——不需要再融資，不會稀釋股東。

**股份回購：** 2024年11月批准2億美元回購計劃，截至2025年Q3已回購1.164億美元。2025年5月單日回購7.83億港元。此外，2026年初管理層宣佈至多5億美元的新回購計劃，港股一度漲超10%。回購的積極信號是：管理層認為股價被低估，且願意用真金白銀回報股東。

**資產負債表評分：★★★★☆（4/5）**

現金充裕、負債可控、有積極的股東回報政策，財務安全邊際高。

## 五、估值分析

**當前估值水平：**

| 估值指標 | 數據 |
|----------|------|
| 港股股價 | ~176.60港元 |
| 市值 | ~735億港元 / ~94億美元 |
| 2025年調整後PE | ~28倍（735億港元 / 25.9億調整後淨利） |
| 2025年GAAP PE | ~62倍（735億港元 / 11.9億淨利） |
| PS（市銷率） | ~2.4倍（735億港元 / 303.5億營收） |
| 扣除淨現金後EV | ~500億港元 |
| EV/調整後淨利 | ~19倍 |

注：以上為粗略估算，匯率按1美元=7.8港元計算。

**估值討論：**

28倍調整後PE對於一個剛實現盈利、利潤率還在上升通道的互聯網公司來說，不算離譜，但也談不上便宜。關鍵問題是：未來利潤能增長到什麼水平？

如果用更樂觀的假設——2026年調整後淨利潤增長40-50%至36-39億元，對應的前瞻PE約19-20倍。加上手裡235億現金，扣除現金後的EV/利潤約14-15倍。這個估值在中國互聯網中有一定吸引力。

但如果利潤增長不及預期（比如遊戲業務掉速、廣告增長放緩），PE可能看起來就貴了。分析師給出的目標價中位數約242港元（+37%上行空間），高盛目標價240港元，多數給"買入"評級。

**與同行對比：**

| 公司 | PE（調整後） | PS | 增速 |
|------|-------------|-----|------|
| 嗶哩嗶哩 | ~28x | ~2.4x | 13% |
| 快手 | ~15x | ~2.5x | 12% |
| 騰訊 | ~20x | ~7x | 8% |
| 網易 | ~14x | ~3.5x | 7% |

對比來看，B站的PE高於快手和網易，主要因為市場對其利潤率提升空間給予了溢價。但如果增速不能維持在15%以上，這個溢價很難持續。

## 六、內在價值估算

用簡化的DCF思路做一個粗略估算：

**假設條件：**
- 2026-2028年營收增速：15%、12%、10%
- 2028年調整後淨利率：12%（從2025年的8.5%持續提升）
- 2028年調整後淨利潤：約47億元
- 給予20倍PE，對應市值約940億元
- 加上淨現金約200億元，總價值約1,140億元
- 折現到當前（8%折現率，2.5年），約950億元
- 對應每股約240港元

這與分析師目標價中位數接近。但這個估算基於利潤率持續提升的樂觀假設，任何執行上的偏差都會顯著影響結果。

**保守情景（利潤率提升受阻）：**
- 2028年調整後淨利率：9%
- 2028年淨利：約36億元
- 15倍PE + 淨現金，總價值約740億元
- 對應約每股190港元

**估值評分：★★★☆☆（3/5）**

當前估值不貴也不便宜，處於合理區間偏上。如果看好利潤率持續提升的故事，有30-40%的上行空間；如果持審慎態度，安全邊際不足。

## 七、財務綜合評分

| 維度 | 評分 | 說明 |
|------|------|------|
| 收入質量 | ★★★☆☆ | 結構優化中但增速放緩 |
| 利潤率趨勢 | ★★★★☆ | 改善趨勢明確 |
| 現金流 | ★★★★☆ | 71億經營現金流，質量高 |
| 資產負債表 | ★★★★☆ | 235億現金，安全邊際厚 |
| 股東回報 | ★★★★☆ | 積極回購，最高7億美元計劃 |
| 估值合理性 | ★★★☆☆ | 合理偏上，安全邊際不充分 |

**財務綜合評分：★★★☆☆（3.5/5）**

B站的財務正在從"燒錢求增長"轉向"盈利並改善"的階段。現金流和資產負債表是亮點，估值是需要謹慎的地方。對於價值投資者來說，最大的問題不是B站能不能賺錢——它已經證明能賺了——而是它能賺多少錢、利潤率的天花板在哪裡。如果最終穩態淨利率只有8-10%，當前估值並不便宜；如果能提升到12-15%，則有較好的回報空間。
