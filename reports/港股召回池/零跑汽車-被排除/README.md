## 核心投資論點

**多頭論點：**
- 全域自研帶來的成本優勢（自研零部件佔整車成本65%）
- 2025年首次全年盈利，驗證了商業模式
- Stellantis戰略合作打開海外市場
- 新勢力銷冠地位，規模效應持續釋放
- 2026年目標100萬輛/50億淨利潤

**空頭論點：**
- 2026年Q1毛利率跌至9.4%，淨虧損3.9億
- 單車利潤極薄（2025年單車僅賺905元）
- 100萬輛目標激進，執行壓力大
- 價格戰持續，比亞迪/吉利等競爭加劇
- 智駕能力相對落後第一梯隊

| 最終報告 | 綜合評估 | 是否值得投資？在什麼價位？ |
