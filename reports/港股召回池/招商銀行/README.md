# 招商銀行（3968.HK / 600036.SH）深度研究框架

> 研究日期：2026年5月16日 | 貨幣單位：人民幣（除港股股價為港元）

## 研究框架

本研究採用四維度並行分析框架，從商業模式、財務估值、行業競爭、風險管理四個角度對招商銀行進行全方位評估：

| 文件 | 分析維度 | 核心問題 |
|------|---------|---------|
| 01-商業模式分析 | 好生意視角 | 招行的零售銀行模式是否具備持續創造價值的能力？ |
| 02-財務估值分析 | 價值投資視角 | 當前估值是否提供足夠安全邊際？ |
| 03-行業競爭分析 | 護城河視角 | 零售之王的護城河是在加寬還是在收窄？ |
| 04-風險管理層評估 | 風險視角 | 換帥之際，管理層能否帶領招行穿越週期？ |

## 核心結論

**綜合評級：★★★★☆（4/5）— 優質資產，等待更好價格**

招商銀行是中國銀行業中罕見的具備"好生意"特徵的標的。零售AUM突破17萬億元，私人銀行客戶超19萬戶，不良率持續保持在0.94%的行業低位，撥備覆蓋率近388%，這些數據構成了堅實的基本面底座。

但挑戰同樣清晰：淨息差從2023年的2.15%收窄至2026Q1的1.83%，營收已連續三年近零增長，信用卡業務承壓，換帥帶來的戰略不確定性尚待觀察。港股PE約6.5倍、PB約0.92倍、股息率約6.5%，估值已反映了相當程度的悲觀預期。

**核心判斷**：招行是"對的公司"，但當前並非"完美的價格"。淨息差見底信號尚不明確，管理層換屆過渡期增加短期不確定性。建議持續跟蹤，重點觀察：（1）淨息差企穩拐點；（2）新管理層戰略方向；（3）信用卡及零售信貸風險演化。若港股PB回落至0.8倍以下（對應股價約44港元），安全邊際將顯著提升。
