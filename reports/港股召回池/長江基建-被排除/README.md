# 長江基建（1038.HK）投資研究

## 基本信息
- **公司名稱**：長江基建集團有限公司
- **股票代碼**：1038.HK
- **行業**：基礎設施
- **PE（TTM）**：~20倍
- **ROE**：~6%

## 核心財務數據
| 指標 | 數值 | 說明 |
|------|------|------|
| 收入 | ~48億港元 | 同比+7.2% |
| 歸母淨利潤 | ~86億港元（預期） | 穩健增長 |
| 中期股息 | 每股0.73港元 | +1.4% |
| 派息連續增長 | 28年 | 自上市以來從未減派 |

## 利潤地理分佈
| 地區 | 溢利貢獻 | 佔比 |
|------|----------|------|
| 英國 | 39.8億港元 | 42.3% |
| 電能實業 | 22.0億港元 | 23.4% |
| 澳洲 | 17.8億港元 | 18.9% |
| 歐洲大陸 | 6.0億港元 | 6.4% |
| 加拿大 | 5.3億港元 | 5.6% |

## 投資亮點
1. 28年連續股息增長——港股最長連增紀錄之一
2. 全球化基建資產組合，分散地理風險
3. 受監管資產提供可預測的穩定收益
4. 李嘉誠家族長期管理經驗

## 核心風險
1. PE 20倍對ROE 6%偏貴
2. 英國資產佔比過高（42%），脫歐/政策風險
3. 利率上升增加融資成本
4. 海外監管政策變動風險
