## 研究背景

蒙牛是中國乳製品行業雙寡頭之一（另一家為伊利股份），2025年實現收入822.4億元。公司正處於管理層換代後的戰略調整期：前任留下的併購減值包袱（貝拉米43.3億商譽減值、現代牧業聯營虧損等）正在出清，新任總裁高飛推行"一體兩翼"戰略，從規模擴張轉向利潤質量提升。當前PE約15倍，市場等待2026年利潤拐點確認。

## 核心矛盾

1. **利潤拐點何時確認？** 2025年經營現金流創歷史新高（87.5億），但收入同比下滑7.3%，減值出清尚未完成
2. **與伊利差距是否可逆？** 營收差距已擴大至334億，市值差距近3倍
3. **原奶週期能否助力？** 行業預計2026年供需再平衡，對下游有利
4. **管理層能力是否匹配？** 高飛"老懞牛"出身，但尚未證明扭轉能力
