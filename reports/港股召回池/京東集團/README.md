## 研究框架

本研究採用四維度並行分析框架：

1. **商業模式分析** — 生意本質、護城河、用戶價值
2. **財務估值分析** — 盈利質量、資本配置、安全邊際
3. **行業競爭分析** — 競爭格局、產業趨勢、生態位
4. **風險管理層評估** — 核心風險、管理層能力、治理結構

## 核心投資變量

- 外賣業務：2025年投入近300億，目標2026年市佔率30%，是利潤最大變量
- 物流壁壘：京東物流2025年營收2171億（+18.8%），一體化供應鏈客戶超9萬家
- 股東回報：2025年回購30億美元+分紅14億美元，總回報率~10%
- 競爭格局：電商份額被抖音侵蝕，從第二滑至第三（GMV口徑）
- 增長放緩：2026Q1營收增速降至4.9%，家電國補退坡影響顯現
