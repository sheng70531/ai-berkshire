# 模型排第25，卻最像一家公司：拆解 MiniMax 的護城河

在中國大模型"六小虎"裡，MiniMax 的模型綜合分不算高。最新的實時榜上，它的旗艦隻排到全球第 25。

但它同時是這幾家裡最像一家產品公司、而不是純模型實驗室的一個：產品線最寬，出海變現最徹底，語音還是它唯一衝到過世界第一的模態。

這篇不聊解禁、融資和股價，那些是會過期的熱點。這篇只回答兩個能放很久的問題——它的模型到底排第幾，護城河到底是什麼。文中榜單分數、排名、定價都來自一手來源（Artificial Analysis 實時榜、官方文檔、arXiv、港交所披露），凡是我自己的判斷，會單獨點明。

## 先認清現役陣容

很多人對 MiniMax 的第一印象還停在 M2。那是 2025 年 10 月那款點燃它存在感的編程與 Agent 爆款，開放權重、架構極稀疏、價格便宜，一度是開發者圈的熱門。

但 M2 早已被一路迭代取代。截至 2026 年 7 月，家族現役主力是 5 月發佈的 M3：原生多模態，支持文、圖、視頻輸入，上下文 105 萬 token，官方定價輸入每百萬 token 0.30 美元、輸出 1.20 美元。

這個價格約為 Claude Sonnet 的 8%。換個說法：同樣一批活，別人收一塊，它收八分。便宜到這個程度，是理解它後面一切打法的起點。

所以談"文本能力"時要分清：M2 是那款點燃聲量的爆款，M3 才是現在扛榜的主力，兩者不能混為一談。

## 各模態到底什麼水平

大模型公司很容易被籠統評價，但 MiniMax 各條產品線的水平差得很遠。逐個模態看，才看得清它強在哪、弱在哪。

### 語音：唯一衝到過世界第一的模態

這是最亮的一塊。在 Artificial Analysis 的語音合成競技場（約 2026 年 7 月實時榜），它的 Speech 2.8 HD 拿到 Elo 1185、全球第 8，明顯壓過 ElevenLabs v3（1174，第 12）和 OpenAI 的 TTS。更早的 Speech-02-HD 在 2025 年上半年還曾登頂全球第一。

榜首是 Speechify 的 Simba 3.2，前列還有 Gemini、Cartesia 和阿里的產品。MiniMax 不在最頂端，但穩居第一梯隊——這是它唯一衝到過世界第一、至今仍在第一梯隊的模態，在六小虎裡獨一份。

### 文本、推理與 Agent：第二梯隊，靠錯位競爭

這是外界最關心、也最容易被高估的一塊。

綜合分上，M3 得 44 分、全球第 25。作為參照，頭部是 Claude、GPT、Gemini 的 53 到 60 分檔，國產開源的智譜 GLM-5.2 是 51。M3 落後頭部約 10 到 16 分，也落後 GLM-5.2。這不是貶低，是事實：它就是第二梯隊。（順帶打個假：網上有博客稱"M2.7 以 50 分排第一"，與官方實時榜 M2.7 得 38 分、第 39 名嚴重矛盾，屬杜撰，本文不採用。）

但拆到單項，會看到一個有意思的結構。

越是需要真本事從零推演的活，它越吃虧：SWE-bench、AIME、GPQA 這類硬推理硬編程，M3、M2 穩定落後頭部數分到十幾分。反過來，越是"調工具、拼產物"的活，它越能打平甚至反超：檢索、前端產物、LiveCodeBench 這幾項，它能追平乃至超過 Claude Sonnet。（其中檢索項差距懸殊，可能與各家評測側重不同有關，別單看一個數字下結論。）

這個結構說明一件事，這是我的判斷：MiniMax 的文本能力不是靠"絕對更強"贏，是靠"夠用，再便宜一個數量級"做錯位競爭。活幹得夠好、價格只有頭部的十分之一檔，很多場景就夠了。

但要清醒：這是價格差異化，不是能力差異化。而價格差異化最容易被跟進——對手一降價，或者乾脆開源免費，這道差就抹平了。講護城河時會回到這一點。

### 視頻：掉隊的一環，只剩中游加便宜

海螺（Hailuo）是它的視頻線，曾有過高光——2025 年 6 月，Hailuo 02 一度衝到圖生視頻全球第二。

但一年之內被全面反超。現役旗艦 Hailuo 2.3 在 Artificial Analysis 視頻競技場裡，文生視頻前 25、圖生視頻前 12 都沒進。榜前是字節 Seedance 2.0、快手可靈 Kling 3.0、Google Veo 3.1、阿里 Wan 2.7 這些名字。

官方現在主打兩點：物理表現和成本——每條約 0.28 到 0.30 美元，對比 Runway 約 1.20、Sora 約 3.50。但它沒有原生音軌，榜單也確實掉了隊。視頻是個三個月換一次王座的紅海，海螺在其中只剩"中游加便宜"這一個賣點。

三個模態擺一起，畫像就清楚了：語音最強、文本靠低價錯位、視頻落後頭部。這不是一個靠單點最強取勝的選手，是一個走性價比和開放權重路線的第二梯隊全能選手。

## OpenRouter 上的真實分量：一個反差

榜單是評測環境，OpenRouter 才是開發者用真金白銀投票的地方，最能反映真實調用量。

先說一句必要的提醒：OpenRouter 的用量和花費數字都是二手彙總、來源互相沖突，只能看個量級，不能當硬數據。真正能硬引的只有官方定價。

在這個前提下，量級大致是：M3 的月 token 吞吐約 4.5 萬億，在編程類裡約排第二，MiniMax 家族合計約佔全站 3.8%。作為參照，按 token 榜首是 DeepSeek，單家約佔全站 17.6%。MiniMax 不是那種統治級第一，也不是長尾，是靠編程和 Agent 場景加低價撐起的次頭部。

真正值得講透的是這個反差：按 token 用量，它是準頭部；按美元花費，它只是中游。

原因就在它的打法本身——量大、價低、毛利薄。對照頭部：全站按美元花費第一的是 Anthropic，佔了約六成七，靠的是量少價高。MiniMax 恰好相反。這個"token 份額很高、卻換不成同等比例收入"的結構，既是它的打法，也是它的軟肋。用量榜上好看，不等於收入榜上好看。

## 護城河逐條盤點

現在回到第二個問題：MiniMax 的護城河到底是什麼。

先給我的結論：它沒有一條又寬又深的河。它的壁壘是多箇中等深度差異點的疊加，外加早期形成的出海消費數據和分發飛輪。逐條看證據強弱，正反兩面都擺出來。

**成本與長上下文經濟學，★★★★。** 證據最硬的一條。M1 的全流程強化學習訓練只用了 512 張 H800、約三週、成本約 53 萬美元；支持百萬級上下文，算力開銷約為對手的三成；M2 價格做到 Claude 的 8%。反面：架構優勢可以被複制，DeepSeek、Qwen 也在做稀疏和線性注意力，這條河會被跟進。

**出海收入佔比超過 70%，★★★★。** 六小虎裡最徹底的一家，是真差異化。反面：高出海佔比把公司暴露在地緣和合規風險下，海外陪伴產品 Talkie 就曾在美區應用商店被下架。

**多模態全棧廣度，★★★。** 文本、視頻、語音、音樂、Agent、C 端陪伴 App 一家做齊，產品線是這幾家創業公司裡最寬的。反面：寬不等於深，每條線都有更專的對手，視頻掉隊就是證據。

**AI 陪伴 App 的數據和分發，★★★。** Talkie 曾有過半用戶在美國，有真實收入和用戶資產，這是純 API 型對手不具備的。反面：留存下滑加監管下架風險，陪伴類的忠誠度和合規風險雙高。

**Agent 與編程的極致性價比，★★。** OpenRouter 編程類前二是硬數據。反面：低價本身就容易被商品化，DeepSeek、GLM 更便宜、甚至免費開源。

**開放權重的開發者生態，★★。** 有一定號召力。反面：開源不是它獨佔的打法，DeepSeek、Qwen、GLM 更徹底，它在這條上並不佔先。

把這六條連起來，有一個值得警惕的隱憂，也是我認為全篇最關鍵的一句：證據最強的兩條是成本經濟學和出海佔比，最弱、最容易被侵蝕的兩條是開放權重和 Agent 低價——而恰恰是後兩條，撐起了它當下在 OpenRouter 上的聲量。讓它今天顯得熱鬧的那部分，護城河反而最淺。

## 四條反面風險

護城河講能守住什麼，風險講可能被什麼擊穿。有四條要擺在桌面上。

一是財務還沒自我造血。2025 全年收入 7900 萬美元，同期經調整淨虧損約 2.5 億美元，收入高速增長但離盈虧平衡還遠。好在賬上有約 10 億美元現金，加上今年的再融資，按一年燒 2.5 億算，跑道還有幾年——不緊迫，但也談不上寬裕。

二是開源等於零遷移成本，會催生持續的價格戰通縮。客戶換供應商幾乎沒成本，DeepSeek、GLM 的免費開源會一直往下壓它的 API 變現空間。

三是投資人本身就是對手。阿里既是它重要的機構股東，又用 Qwen 正面競爭；字節和騰訊的資本加分發是碾壓級投入。這是創業公司在巨頭夾縫裡做全棧的結構性困境。

四是消費 App 的監管與地緣風險。Talkie 美區下架、陪伴類的隱私審查，都會因為它超過 70% 的高出海佔比而被放大。

## 和六小虎其他家比，它贏在哪

把它和 DeepSeek、Kimi、Qwen、GLM 放一起：論絕對模型分，它落後 GLM-5.2 和 DeepSeek；論 OpenRouter 的 token 統治力，它 3.8% 遠不及 DeepSeek 的 17.6%。單看這兩個維度，它都不是最強的。

但換個維度就不一樣，這是我的判斷：論"產品公司氣質"，MiniMax 是這幾家裡最獨特的一個。多模態全棧做齊、出海消費 App 有真實付費用戶、已經跑通商業化閉環——這三件同時做到規模的，只有它。DeepSeek 長在純推理和開源影響力，Kimi 長在 Agent 和編程，Qwen 長在阿里雲生態，GLM 走企業加開源。產品形態的完整度上，MiniMax 最像一家公司、而不是一個實驗室。

所以它贏的不是模型分，是商業形態的完整度。用模型排行榜衡量它，會低估它；用它的模型排名追捧它，又會高估它。

## 結尾：一場和時間賽跑的生意

把兩個答案收攏。

模型水平：第二梯隊。語音第一梯隊，文本靠低價錯位、夠用但不領先，視頻掉隊。護城河：不是一條深塹，是幾道中等深度差異點的疊加，加上一個早期跑起來的出海消費飛輪；最強的是成本效率和出海佔比，最容易被填平的是開放權重和低價——而後者正是它當下聲量的來源。

所以對 MiniMax 最經得起推敲的判斷是：它做的是一門和時間賽跑的生意。它賭的不是模型永遠領先，因為在一個技術每隔幾個月就換一次王座的行業裡，模型領先本就留不住。它真正賭的，是能不能在自己的低價和開放權重被徹底商品化之前，先用多模態的寬度和出海的分發，把用戶的使用習慣鎖住。

值得盯的就兩個變量：出海的消費飛輪能不能在壁壘被填平之前轉到自我造血，以及高出海佔比下的合規會不會失控。前者去看它的 ARR 增速能否持續跑贏燒錢，後者去看新規落地後海外那塊營收掉多少。

在一個王座頻繁易主的行業裡，唯一不太貶值的資產，是客戶改不掉的習慣。MiniMax 能不能守住它，答案不在模型榜上，在時間裡。
