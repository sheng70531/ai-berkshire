# MiniMax：表面出海公司，利潤表上是 B 端 API 公司

MiniMax（稀宇科技，港股 00100.HK）是"AI 六小虎"裡第一家上市、也是最容易被看錯的一家。

看錯的地方，恰好是兩個數字：一個 67% 收入來自 C 端的身份，一個衝到 3 億美元的 ARR。這兩個數字，單看每一個都會把人帶偏。這篇文章只做一件事——把它們拆開，看清底下真實的生意。

先把結論擺上桌：MiniMax 表面是家 C 端出海公司，利潤表上其實是家 B 端 API 公司；它的模型只在第二梯隊，但商業形態是六小虎裡最完整的；而它和智譜 9 倍的市值差，恰好照出了它最深的那道軟肋。

## 誤讀一：它不是 C 端公司，是 B 端公司

MiniMax 2025 年總收入 7904 萬美元、同比增長 159%，整體毛利率 25.4%。但這個 25.4% 是個平均數——把收入拆開，是兩門完全不同的生意：

| 分部 | 2025 收入 | 佔比 | 增速 | 毛利率 |
|---|---|---|---|---|
| AI 原生產品（C 端：Talkie、星野、海螺 App） | 5308 萬美元 | 67.2% | +143% | 僅 4.7% |
| 開放平臺/企業服務（B 端：MaaS、API） | 2596 萬美元 | 32.8% | +198% | 69.4% |
| 合計 | 7904 萬美元 | 100% | +159% | 25.4% |

看出問題了嗎？佔三分之二收入的 C 端，毛利率只有 4.7%，幾乎白乾；佔三分之一的 B 端，毛利率高達 69.4%。

算一筆賬：B 端毛利約 1800 萬美元，而全公司總毛利才 2010 萬美元。也就是說——B 端貢獻了全公司約 90% 的毛利，卻只佔 33% 的收入。反過來，佔 67% 收入的 C 端，只貢獻了約 10% 的毛利。

所以 MiniMax 真實的樣子是：C 端 App 負責走量、講故事、攢用戶和數據；B 端 API 負責賺錢。它表面是家出海陪伴公司，利潤表上是家 B 端 API 公司。

更值得注意的是，這條真正賺錢的腿，還在加速：

| B 端（開放平臺/企業服務） | 2024 | 2025 | 2025 Q4 單季 |
|---|---|---|---|
| 收入 | 872 萬美元 | 2596 萬美元 | 1054 萬美元 |
| 佔總收入 | 28.6% | 32.8% | 躍升至 41% |
| 毛利率 | 63.2% | 69.4% | 約 69% |
| 增速 | — | +198% | +278% |

B 端佔比從前三季度的 29%，到第四季度單季直接跳到 41%；增速從全年的 198%，到 Q4 加快到 278%。新增收入幾乎全靠這條腿在拉，而且是它質地最好的一條腿。

一句話：MiniMax 值不值錢，不看 C 端有多少用戶，看這條 69% 毛利、翻倍增長的 B 端曲線，能不能在價格戰裡守住毛利、把佔比從 41% 頂上 50%。

## 誤讀二：ARR 衝到 3 億，不等於它有多強

2026 年 MiniMax 最亮眼的數字，是 ARR（年化經常性收入，即最新月收入乘以 12）一路狂飆：2 月突破 1.5 億美元（創始人閆俊傑在業績電話會披露），5 月衝到 3 億美元、兩個月翻倍（彭博社報道，隨 A 股上市輔導披露）。券商測算年底可能到 8—10 億美元。

數字很猛，但有兩個坑，不填清楚就會高估它。

第一個坑：ARR 不是全年收入。ARR 是"當前這個月的掙錢速度 ×12"的瞬時值，天然比累計入賬的全年收入大。5 月 ARR 已 3 億，但分析師給 2026 全年確認收入才 2.2—3.0 億美元（標普全球共識 2.19 億、高盛 3.0 億）。要提醒的是，官方並沒有給 2026 收入指引，這些全年數字都是券商預測。誰把"ARR 3 億"當成"2026 營收 3 億"，就會高估。

第二個坑，也是關鍵：這 3 億 ARR 是全公司總口徑，含 C 端訂閱，不是純 API。這一點，在和智譜對比時會要命。

把兩家最可比的港股 AI 公司並排看：

| 指標 | MiniMax | 智譜 GLM |
|---|---|---|
| 2025 收入 | 7904 萬美元，+159% | 7.24 億人民幣（約 1.02 億美元），+132% |
| 毛利率 | 25.4%（B 端 69%/C 端 4.7%） | 約 50%（整體更高） |
| 最新 ARR | 3 億美元（總口徑，含 C 端） | 17 億人民幣（約 2.5 億美元，純 API） |
| 2026 營收預測 | 2.2—3.0 億美元 | 25—46 億人民幣（約 3.5—6.5 億美元） |
| 市值（2026 年 7 月） | 約 910 億港元（約 117 億美元） | 約 8000 億港元（約 1050 億美元） |
| 業務重心 | C 端出海陪伴+視頻+API | 企業級 MaaS/政企，國內為主 |

三個信號：

一，論基本面，智譜佔優。2026 營收預測約是 MiniMax 的 1.5 到 2 倍，毛利率高一倍，而且智譜的 2.5 億 ARR 是純 API 口徑——含金量比 MiniMax 摻了 C 端訂閱的 3 億更"經常性"。單論 B 端這門最值錢的生意，智譜大概是 MiniMax 的 2 到 4 倍。

二，但估值差（9 倍）遠遠超過基本面差（約 2 倍）。這多出來的溢價，買的不是當期業績，是智譜 GLM-5.2 帶來的"模型前沿定價權"敘事——智譜市銷率一度到 1256 倍，那是信仰投票。

三，這恰好照出 MiniMax 的軟肋：市場願意為"模型領先"付高價，而模型領先，正是 MiniMax 最不佔優的一環。

## 那 MiniMax 的模型，到底什麼水平

市場願意為"模型領先"付高價，那 MiniMax 的模型到底領不領先？攤開四個模態的榜單，答案很清楚：語音最強，文本第二梯隊靠錯位，視頻掉隊，全靠低價換量。

**文本/推理：綜合第二梯隊。** 在海外權威盲測機構 Artificial Analysis 的綜合智能榜上，MiniMax 最新的 M3 只有 44 分、全球第 25，落後頭部一個身位，連國產的智譜 GLM-5.2 都沒追上：

| 模型 | 綜合智能分 | 位置 |
|---|---|---|
| Claude Fable 5 | 60 | 頭部 |
| GPT-5.6 | 59 | 頭部 |
| Claude Opus 4.8 | 56 | 頭部 |
| 智譜 GLM-5.2 | 51 | 國產第一梯隊 |
| Gemini 3.5 Flash | 50 | 第一梯隊 |
| **MiniMax M3** | **44** | **第 25** |

**但拆到單項，MiniMax 是"有輸有贏"的錯位打法。** 用它的開放權重旗艦 M2 跑主流基準，硬推理、硬編程穩定落後頭部，可在檢索、代碼、前端產物這些"幹活型"任務上，反而追平甚至超過 Claude Sonnet：

| 基準（能力） | MiniMax M2 | Claude Sonnet 4.5 | Claude Opus 4.5 | GPT-5.2 |
|---|---|---|---|---|
| SWE-bench（編程） | 69.4 | 77.2 | 80.9 | 80.0 |
| Terminal-Bench（終端） | 46.3 | 50.0 | 57.8 | 54.0 |
| AIME25（數學推理） | 78 | 88 | — | 94 |
| BrowseComp（檢索） | **44.0** | 19.6 | 37.0 | 65.8 |
| LiveCodeBench（代碼） | **83** | 71 | — | 85 |
| ArtifactsBench（前端產物） | **66.8** | 61.5 | — | 73 |

翻譯一下：論硬碰硬的推理和編程，它落後頭部數分到十幾分（後續的 M2.1 把 SWE-bench 提到了 74，仍沒進頭部）；但在"檢索+工具+出活"這類實用場景，它用只有 Claude 8% 的價格，做到了"夠用還便宜"。它贏的不是絕對能力，是性價比。

**語音：唯一衝到過世界第一的模態。** MiniMax 的 Speech 系列 2025 年上半年曾登頂全球 TTS 盲測榜，如今仍穩在第一梯隊，明顯壓過 ElevenLabs 和 OpenAI：

| 語音合成模型 | 質量 Elo | 排名 |
|---|---|---|
| Simba 3.2（Speechify） | 1234 | 1 |
| Gemini 3.1 Flash TTS | 1214 | 2 |
| **MiniMax Speech 2.8 HD** | **1185** | **8** |
| ElevenLabs v3 | 1174 | 12 |
| OpenAI TTS | 約 1100 | 28+ |

**視頻海螺：掉隊最明顯。** 現役旗艦 Hailuo 2.3 已跌出 Artificial Analysis 視頻榜的可見前列——文生視頻前 25、圖生視頻前 12 都進不去，被字節 Seedance 2.0、阿里 Wan/HappyHorse、快手可靈 3.0、谷歌 Veo 3.1 全面反超。它 2025 年 6 月曾衝到圖生視頻全球第 2，一年就被擠下來。官方主打"物理效果好、每條約 0.3 美元便宜"，但沒有原生音軌，只剩"中游 + 低價"。

**商業落地：靠低價在 OpenRouter 換量。** M2 是開放權重（MIT 許可）、極稀疏的 MoE 架構（2300 億總參、100 億激活），價格只有 Claude 的 8%、速度約兩倍。憑這個，MiniMax 在全球開發者用真金白銀投票的 OpenRouter 上，編程類調用量做到第二、全站佔比約 3.8%，M3 單月調用約 4.5 萬億 token。但注意：它按 token 量是準頭部，按美元花費只是中游——因為定價太低，量大、價低、毛利薄。

一句話：MiniMax 是性價比路線的第二梯隊全能選手——語音最強，文本靠低價錯位，純推理和視頻落後頭部。它的模型不領先，而市場恰恰在為"領先"付溢價，這就是它估值追不上智譜的根本原因。

## 護城河，和最後的落點

把上面這兩個數字連起來，MiniMax 的護城河其實很清楚，也很尷尬：它沒有一條又寬又深的河，壁壘是幾個中等深度差異點的疊加——極致的成本效率（M1 訓練成本僅約 53 萬美元）、出海佔比超 70%、多模態全棧、開放權重。這些能帶來先發和規模優勢，但每一條都能被複制，抵禦不了巨頭的資本和分發碾壓。

而且它面臨三重擠壓：一，模型開源意味著客戶零遷移成本，DeepSeek、智譜的免費策略會持續壓它的 API 變現；二，阿里既是它最大的機構股東，又用通義千問正面競爭；三，C 端賴以生存的陪伴 App 踩在監管紅線上，Talkie 已兩度被下架。

所以落點是這樣的：MiniMax 真正值錢、也真正該盯的，是那條 33% 佔比、69% 毛利、翻倍增長的 B 端曲線——它是當期的利潤和估值錨。C 端是流量和數據的護城河候選，B 端才是眼下賺錢的引擎。

它能不能成，取決於一件事：在護城河被開源和價格戰填平之前，能不能把這條 B 端曲線轉到自我造血。這是一場和時間賽跑的生意。

在一個模型三個月換一次王座的行業裡，唯一不貶值的資產，是客戶改不掉的習慣。而習慣，恰恰長在那條 69% 毛利的 B 端上。
