## 一、宇視科技自身財務數據（從千方科技年報拆分）

宇視科技作為千方科技全資子公司，其財務數據需從母公司年報中拆分。以下為歷年關鍵數據：

| 年份 | 營收（億元） | 淨利潤（億元） | 淨利率 | 備註 |
|------|-------------|---------------|--------|------|
| 2019 | ~47（估計） | 5.4 | ~11.5% | 業績承諾期 |
| 2020 | 52.7 | ~6.0（估計） | ~11.4% | 完成對賭承諾 |
| 2021 | 60.74 | 5.72 | 9.4% | 營收峰值 |
| 2022 | ~51.3（估計） | ~3.5（估計） | ~6.8% | 行業下行 |
| 2023 | 52.35 | 3.36 | 6.4% | 總資產62.37億 |
| 2024 | 54.82 | 3.15 | 5.7% | 營業利潤3.19億 |

**關鍵發現**：

1. **營收見頂回落**：2021年達到峰值60.74億後連續下滑，2024年僅恢復至54.82億，距峰值仍差10%
2. **淨利率持續收窄**：從2019年約11.5%降至2024年的5.7%，反映行業競爭加劇、價格戰侵蝕盈利
3. **淨利潤絕對值縮水**：從2021年的5.72億降至2024年的3.15億，下降45%
4. 宇視科技貢獻了千方科技2024年75.6%的營收，是絕對核心資產

> **巴菲特視角**："利潤率持續下降的公司很難擁有持久的競爭優勢。宇視科技的淨利率從11%滑落到5.7%，說明它的'護城河'正在被侵蝕。"

> **驗算校驗**（financial_rigor.py）：
> - 海康威視 ROE = EPS 1.55 / BVPS 9.14 = 16.96%，與年報17.30%基本一致
> - 千方科技 ROE = EPS 0.17 / BVPS 8.66 = 1.96%，低至可忽略的水平

### 3.2 盈利能力差距定性分析

**第一梯隊：海康威視** -- 毛利率46%、淨利率15%、ROE 17%，現金流充沛（淨現比1.78x），是教科書級的好生意

**第二梯隊：大華股份** -- 毛利率40%、淨利率12%、ROE 10%，規模不及海康但仍有可觀盈利

**第三梯隊：宇視科技/千方科技** -- 毛利率30-32%、淨利率3-6%、ROE不到2%（合併口徑），盈利能力遠遜於前兩者

**差距量化**：
- 海康威視毛利率比宇視高約15個百分點，這意味著同樣賣100元的產品，海康多賺15元
- 海康淨利率是千方科技的近5倍，ROE是千方科技的近9倍
- 即使只看宇視科技自身（淨利率5.7%），仍不及海康的1/3

> **巴菲特視角**："如果一個行業的老大毛利率46%、老三毛利率30%，說明老三缺乏定價權。沒有定價權的企業，長期來看很難為股東創造超額回報。"

## 六、估值分析

### 6.1 千方科技當前估值（2026年5月，基於近期數據）

> **驗算基準**（financial_rigor.py）：
> 股價 11.85元 x 總股本 15.8億股 = 市值 187.2億元（與實際~187億偏差0.12%，驗證通過）

| 估值指標 | 千方科技 | 計算過程 |
|---------|---------|---------|
| PE（TTM, 2025歸母利） | 69.7x | 11.85 / 0.17 = 69.7x |
| PE（2026E, 機構預測） | ~41x | 11.85 / 0.29 = 40.9x |
| PB | 1.37x | 11.85 / 8.66 = 1.37x |
| PS（TTM） | 2.28x | 187億 / 82.17億 = 2.28x |
| 盈利收益率 | 1.43% | 0.17 / 11.85 = 1.43% |

### 6.2 隱含的宇視科技估值

千方科技市值187億，其中宇視科技貢獻了約76%的營收和幾乎全部利潤。粗略拆分：

- 假設智慧交通業務估值 = 收入22億 x 1.0x PS = 22億（考慮到虧損，給予保守估值）
- 剩餘商譽+現金等淨資產價值 = ~30-40億
- **隱含宇視科技估值 = 187 - 22 - 35 = ~130億**
- 對應宇視科技 PE = 130 / 3.15 = 41x
- 對應宇視科技 PS = 130 / 54.82 = 2.4x

## 八、宇視科技獨立上市估值（SOTP分析）

### 8.1 估值方法論

| 估值方法 | 假設 | 估值範圍（億元） |
|---------|------|---------------|
| **PE法（可比公司）** | 給予大華股份PE折價30%，即~11x PE | 3.15 x 11 = **35億** |
| **PE法（行業平均）** | 給予20-30x PE | **63-95億** |
| **PS法（可比公司）** | 大華PS 1.78x，宇視折價給1.5x | 54.82 x 1.5 = **82億** |
| **PS法（樂觀）** | 給予2.0-2.5x PS | **110-137億** |
| **DCF法（簡化）** | FCF ~2億, 增長5%, 折現率10% | 2 / (0.10-0.05) = **40億** |

### 8.2 綜合估值判斷

| 情景 | 估值範圍（億元） | 邏輯 |
|------|---------------|------|
| **悲觀** | 40-65億 | 按DCF或折價PE，考慮實體清單風險、利潤率下滑 |
| **中性** | 80-110億 | 按可比公司PS 1.5-2.0x，行業正常化 |
| **樂觀** | 120-150億 | 按行業平均PE 25-30x，假設利潤回升至4-5億 |

### 8.3 為什麼宇視難以獨立獲得高估值

1. **淨利率僅5.7%**：遠低於海康（15%）和大華（12%），定價權弱
2. **美國實體清單**：2024年12月被列入，雖然公司稱"影響可控"，但海外拓展必然受限
3. **行業老三困境**：安防行業集中度不斷提升，老三的生存空間被壓縮
4. **缺乏獨立融資渠道**：作為有限責任公司（非股份制），獨立上市需要先改制
5. **母公司依賴**：宇視的利潤是千方科技唯一可靠的利潤來源，分拆可能性低

### 8.4 SOTP -- 千方科技的隱含折價/溢價

| 組成部分 | 估值（億元） | 估值方法 |
|---------|-------------|---------|
| 宇視科技 | 80-110（中性） | PS 1.5-2.0x |
| 智慧交通業務 | 15-25 | PS 0.7-1.0x（持續虧損） |
| 商譽（扣除宇視） | -10至0 | 潛在減值風險 |
| 淨現金/淨負債 | ~5 | 資產負債表 |
| **SOTP合計** | **90-140** | |
| **當前市值** | **187** | |
| **溢價率** | **34-108%** | 市場給予顯著溢價 |

**結論**：按SOTP估算，千方科技當前市值187億元相對於分部估值90-140億存在34%-108%的溢價。市場可能在定價中包含了"車路雲一體化"概念和AI交通的未來預期。

## 九、巴菲特視角總結

### 9.1 四大關鍵問題

| 問題 | 評估 | 評分 |
|------|------|------|
| 能否理解這個生意？ | 安防/智能物聯業務可理解，但智慧交通項目制收入難預測 | ★★★ |
| 是否有持久競爭優勢？ | 行業老三，毛利率30%遠低於龍頭，護城河薄弱 | ★★ |
| 管理層是否誠實能幹？ | 商譽大額減值暴露前期收購決策問題 | ★★ |
| 價格是否合理？ | PE 70x（TTM）或41x（2026E），對比ROE 2%，明顯高估 | ★ |

### 9.2 最終判斷

**從巴菲特投資框架來看，宇視科技/千方科技不具備投資吸引力**。核心原因：

1. **盈利質量差**：5年兩次鉅虧，ROE僅2%，自由現金流可能為負
2. **護城河薄弱**：毛利率30%，遠低於行業龍頭，定價權不足
3. **估值不便宜**：PE 70x對應ROE 2%的企業，沒有安全邊際
4. **隱患未消**：商譽34億+實體清單+智慧交通持續虧損
5. **但另一方面**：宇視科技本身仍保持3億+的穩定盈利，如果安防行業回暖、海外業務恢復、車路雲業務放量，估值有修復空間

> **巴菲特會說**："在安防行業，我寧願以合理價格買海康威視這樣的卓越企業，也不願以便宜價格買千方科技這樣的困境企業。而現在千方科技的價格甚至談不上便宜。"
