## 估值審查

- 區分已披露歷史數據、正常化調整與未來假設。正常化盈利必須有可追溯橋接，不能把希望實現的利潤當作已實現利潤。
- 三年目標價是未來情景價值；今天的價值需要折現，並考慮期間現金分紅。不能用未折現目標價直接宣佈當前安全邊際。
- 報告中的含分紅年化若按末期彙總計算，屬於終值財富的等效年化，不是逐筆分紅現金流IRR；期間分紅不預設再投資回報。
- 整體PE模型與經營價值加富餘淨現金的分部估值是交叉校核方法，不能相加。既給利息收入估值又全額加入同一現金，需要剔除重複。
- 回購提升每股收益後，不再加一次回購收益率；股份薪酬、融資與可轉債需在費用、股數或債務中一致反映，不能遺漏或重複扣減。
- AI運行率收入不等於已實現全年收入，AI融資金額不等於經營創造現金。虧損公司不使用負PE推斷便宜。
- 悲觀情景允許盈利下降、估值壓縮及融資困難，不是隻把樂觀增速調低。基準情景的利潤率恢復、收入增長與股本變化都必須說明經濟條件。
- 情景價格和主觀概率不能直接輸出“最優倉位”。公司研究先判斷價格吸引力，賬戶現金、期權、資金期限與可承受損失決定實際倉位。
