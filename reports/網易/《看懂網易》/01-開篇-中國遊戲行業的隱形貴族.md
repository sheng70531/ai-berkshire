# 中國遊戲行業的隱形貴族

> 《看懂網易》系列 · 第 01 篇 · 開篇
> 閱讀時間約 6 分鐘

---

## 一組讓你重新審視網易的數據

2025年，網易交出了一份成色極好的成績單：

| 指標 | 2025年數據 | 意味著什麼 |
|------|-----------|----------|
| 總營收 | 1,126億元 | 千億級互聯網公司 |
| 遊戲收入 | 921億元（+11%） | 中國第二大遊戲公司 |
| Non-GAAP淨利潤 | 373億元（淨利率33%） | 每賺3塊錢就有1塊是淨利潤 |
| 毛利率 | 64.3% | 接近奢侈品公司的水平 |
| 自由現金流 | ~496億元（資本支出僅11億） | 賺到的錢幾乎不需要再投入 |
| 淨現金 | 1,635億元 | 佔市值的31% |
| 研發投入 | 177億元（佔營收15.7%） | 比絕大多數中國互聯網公司都高 |

33%的淨利率、496億的自由現金流、僅11億的資本支出——這組數字翻譯成大白話就是：**網易是一臺幾乎不需要"加油"就能持續"印鈔"的機器。**

但市場給它的定價是什麼水平？

| 估值指標 | 數值 | 意味著什麼 |
|----------|------|----------|
| 股價 | $113.61 | — |
| 市值 | $729億（約5,300億人民幣） | — |
| PE（GAAP） | ~15倍 | 中國互聯網平均偏下 |
| PE（Non-GAAP） | ~13倍 | 更接近實際盈利能力 |
| 前瞻PE | ~12.3倍 | 基於分析師一致預期 |
| EV/EBITDA | 9.35倍 | 扣除現金後更便宜 |
| P/FCF | 9.9倍 | 約10年自由現金流買下整家公司 |
| 淨現金佔市值 | 31% | 三成市值是賬上現金 |

把它翻譯成大白話：**市場給網易的定價，相當於"賬上1635億現金打七折送你，業務只值不到10年利潤"。**

一家淨利率33%、自由現金流496億、還在增長的公司，被定價為13倍PE——這要麼是市場看到了某些嚴重的問題，要麼是市場搞錯了。

搞清楚到底是哪種情況，是這個系列要回答的問題。

## 三個關於網易的常見錯覺

在拆解之前，先破三個流傳最廣的錯覺。

### 錯覺一：網易只是一家遊戲公司

打開大多數人對網易的印象——夢幻西遊、陰陽師、永劫無間。"不就是做遊戲的嗎？"

這個判斷不完全錯，但也不完全對。

遊戲確實佔網易總營收的82%，是絕對核心。但如果只看到遊戲，就會忽略另外兩塊正在發生質變的業務：

| 業務 | 2025年營收 | 關鍵變化 |
|------|-----------|---------|
| 網易雲音樂 | 77.6億 | 營業利潤16.2億，同比+38.5%——已經跨過盈利拐點 |
| 有道 | 59億（+5%） | 其中AI訂閱收入4億（增速50%以上）——正在切換賽道 |

雲音樂從"年年虧損"變成了"年賺16億"。有道從"在線教育"轉型為"AI教育"。兩塊業務加起來137億營收——放在任何一家獨立公司裡都不算小。

**網易的確是以遊戲為核心的公司，但它不只是"一家遊戲公司"。** 更準確的描述是：一個以遊戲為引擎、以音樂和教育為兩翼的內容集團。

**反方觀點**：雲音樂和有道加起來只佔總營收18%，對整體利潤的貢獻更小。說到底，網易的命運仍然取決於遊戲——如果遊戲出了問題，兩翼救不了。

### 錯覺二：網易是騰訊的"小弟"

"騰訊是老大，網易是老二"——這句話在行業排名上沒錯。但如果因此得出結論"網易不值得單獨研究"，那就大錯特錯了。

看一組對比：

| 指標 | 騰訊（遊戲） | 網易（遊戲） | 差距 |
|------|-----------|-----------|------|
| 2025年遊戲收入 | 2,416億 | 921億 | 2.6倍 |
| 海外遊戲收入 | ~774億 | ~90億（估） | ~8倍 |
| 小程序遊戲 | 535億市場獨佔 | 基本缺席 | 無限大 |

從規模上看，騰訊是網易的2.6倍。但規模不是全部——看另一組數字：

| 指標 | 騰訊（整體） | 網易 |
|------|-----------|------|
| Non-GAAP淨利率 | ~28%（估） | **33%** |
| 毛利率 | ~53%（估） | **64.3%** |
| 資本支出/營收比 | 較高 | 僅1%（11億/1126億） |

**網易的賺錢效率比騰訊更高。** 毛利率高出11個百分點、淨利率高出5個百分點、資本支出幾乎可以忽略。

用一個比喻：騰訊是一家全球化的互聯網帝國，業務遍佈社交、遊戲、金融、雲計算。網易更像一個專注於內容的"精品作坊"——規模沒那麼大，但利潤率極高、現金流極充沛。

**這不是"大哥和小弟"的關係，而是"帝國和貴族"的關係。** 帝國什麼都做，貴族只做賺錢的事。

**反方觀點**：利潤率高可能是因為投資不夠激進。騰訊在全球收購遊戲公司（Supercell、Riot、Epic股權），建立了全球化的護城河。網易的高利潤率部分來自"少花錢"——但少花錢也意味著少佈局，長期可能落後更多。

### 錯覺三：利潤在增長 = 一切都好

2025年Non-GAAP淨利潤373億，增速可觀。但利潤增長不代表沒有隱患。

至少有三個問題藏在靚麗的利潤數字背後：

**第一，遊戲收入高度集中。** 82%的收入來自遊戲，而遊戲收入又高度依賴幾款長青產品——夢幻西遊運營了23年、永劫無間、蛋仔派對。一旦某款核心產品生命週期到頭，替補在哪裡？

**第二，海外幾乎是空白。** 海外收入僅佔約10%，而騰訊海外佔比已達30%。7個海外工作室關閉——說明出海之路遠比想象中艱難。漫威爭鋒能否扭轉這個局面，是最大的變量。

**第三，535億的小程序遊戲市場完全缺席。** 2025年中國小程序遊戲市場規模535億，被騰訊獨佔——網易在這個高速增長的賽道上幾乎沒有存在感。

**利潤在增長是事實，但增長的可持續性取決於上面三個問題的答案。**

## 看懂網易，需要回答四個問題

如果用一句話概括網易當前的處境：

> **一家極度賺錢的公司，站在增長的十字路口——向左是"舒適區裡的慢增長"，向右是"出海和新品帶來的加速增長"。**

要看懂這家公司，至少需要回答四個問題：

| 問題 | 對應篇章 |
|------|---------|
| 遊戲帝國的長青產品還能撐多久？漫威爭鋒和出海能否打開第二曲線？ | 第02篇 |
| 雲音樂和有道，是利潤貢獻者還是資源消耗者？ | 第03篇 |
| 丁磊這個人靠不靠譜？網易還有哪些風險？ | 第04篇 |
| $113到底值不值得買？ | 第05篇 · 終章 |

每個問題單獨看都有人討論過，但很少有人把它們串在一起評估。**13倍PE和1635億淨現金只是入場條件，不是買入理由——真正的理由或反對理由，藏在後面四篇裡。**

## 一個小小的預告

留幾個數字，會在後續篇章裡詳細解釋。先記住量級：

| 指標 | 數據 |
|------|------|
| 夢幻西遊同時在線紀錄 | 358萬（運營23年） |
| 漫威爭鋒首月全球收入 | $1.36億 |
| 漫威爭鋒同時在線峰值→低谷→回升 | 64萬→9.6萬→20萬+ |
| 海外工作室關閉數 | 7個 |
| 小程序遊戲市場規模 | 535億（網易缺席） |
| 版號發放數量 | 1,771個（七年新高） |
| 丁磊持股 | 45.5% |
| 某知名投資人對丁磊的評價 | "大孩子" |

把這些放一起，你看到的是一傢什麼公司：

- 手裡握著運營23年仍創紀錄的超級長青遊戲——說明產品力極強
- 漫威爭鋒首月$1.36億但隨後暴跌85%——說明出海有爆發力也有不確定性
- 7個海外工作室關閉——說明海外拓展踩了很多坑
- 創始人持股45.5%——說明公司命運和一個人深度綁定

**這些矛盾信號加在一起意味著什麼？不同的判斷會給出不同的答案。** 這正是接下來4篇要回答的。
