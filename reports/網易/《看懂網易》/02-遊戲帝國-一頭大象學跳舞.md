# 遊戲帝國——一頭大象學跳舞

> 《看懂網易》系列 · 第 02 篇 · 核心業務
> 閱讀時間約 10 分鐘

---

## 一組讓你重新認識網易遊戲的數字

先看網易遊戲在中國遊戲行業裡的位置：

| 指標 | 數據 | 說明 |
|------|------|------|
| 2025年遊戲收入 | 921億元（+11%） | 中國第二，僅次於騰訊 |
| 佔網易總營收 | 82% | 絕對核心，公司命脈 |
| 運營最久的產品 | 夢幻西遊（2003年上線，23年） | 同時在線創紀錄358萬 |
| 最大的出海嘗試 | 漫威爭鋒 | 首月全球收入$1.36億 |
| 海外收入佔比 | ~10% | 騰訊為30% |
| 研發投入 | 177億元（佔營收15.7%） | 重研發基因 |

921億的遊戲收入，11%的增速——放在全球遊戲行業裡都是頂級水準。但這頭大象有一個明顯的特徵：**它在國內跳得很好，但在國際舞臺上還在學步。**

這一篇要回答的核心問題是：**網易遊戲的921億能不能繼續增長？增長從哪裡來？**

---

## 一、長青產品：網易遊戲的"永動機"

網易遊戲最讓人驚歎的不是爆款能力——而是**讓一款遊戲活20年以上還能創新高的能力**。

### 夢幻西遊：23年不老的現金牛

| 指標 | 數據 |
|------|------|
| 上線時間 | 2003年 |
| 運營年限 | 23年 |
| 同時在線峰值 | **358萬（歷史紀錄）** |
| 商業模式 | 點卡+道具混合付費 |
| 覆蓋平臺 | 端遊 + 手遊 |

一款2003年上線的遊戲，在2025年創下了同時在線的歷史紀錄——這在全球遊戲行業裡幾乎找不到第二個案例。

夢幻西遊為什麼能活這麼久？三個原因：

**第一，社交綁定極深。** 夢幻西遊的核心玩法圍繞幫派、結婚、師徒等社交系統展開。一個玩了十幾年的玩家，幫派裡有朋友、遊戲裡有"老婆"、賬號上有數萬元的虛擬資產——遷移成本極高。

**第二，經濟系統形成了自循環。** 夢幻西遊有一套極其複雜的虛擬經濟體系——玩家之間的道具交易、寶石合成、裝備鍛造形成了自運轉的經濟循環。這套系統越成熟，玩家越難離開。

**第三，持續的內容更新。** 23年裡從未間斷的版本更新、新資料片、新玩法——讓老玩家保持新鮮感，也不斷吸引新玩家。

**反方觀點**：再強的長青遊戲也有生命週期。夢幻西遊的核心用戶群在老化——30-40歲的主力玩家群體消費能力雖強，但時間越來越少。年輕用戶對這類"古典"網遊的興趣在下降。同時在線358萬可能已經接近天花板而非起點。

### 永劫無間：全球化潛力的試金石

| 指標 | 數據 |
|------|------|
| 上線時間 | 2021年 |
| 四週年成績 | Steam全球熱銷榜登頂 |
| 遊戲類型 | 動作對戰（格鬥+大逃殺） |
| 特點 | 亞洲風格的動作美學 |

永劫無間證明瞭網易在全球市場上不是沒有競爭力——它的動作系統在全球玩家中獲得了認可。四週年登頂Steam全球熱銷，說明這款產品的生命力仍在。

但永劫無間也暴露了網易的一個結構性短板：**單點成功難以複製成系統性的全球化能力。** 永劫無間在海外的成功更多來自產品本身的品質，而非網易的全球化發行網絡和運營體系。

### 蛋仔派對：年輕化的關鍵一步

蛋仔派對是網易在"全年齡向"賽道上的重要佈局——面向年輕用戶和女性用戶，風格輕鬆可愛，用戶創作內容豐富。這款產品填補了網易在輕度休閒領域的空白。

但蛋仔派對面臨的競爭也很激烈——它本質上在和騰訊的小程序遊戲、以及各種輕度休閒遊戲搶同一批用戶的時間。

## 二、漫威爭鋒：最大的變量

如果說整個網易遊戲的故事裡只有一個變量值得跟蹤，那就是漫威爭鋒。

### 數據全景

| 階段 | 數據 | 說明 |
|------|------|------|
| 上線首月 | 全球收入$1.36億 | 2025年最亮眼的新遊戲之一 |
| 累計玩家 | 4,000萬 | 短時間內積累的用戶量驚人 |
| 同時在線峰值 | 64萬 | 上線初期 |
| 同時在線低谷 | **9.6萬** | 峰值暴跌85% |
| 同時在線回升 | **20萬+** | 版本更新後回升 |
| Steam好評率 | 63% | "褒貶不一"——不算好 |

### 這組數據怎麼讀？

**首月$1.36億——說明漫威品牌的號召力巨大。** 漫威是全球最有價值的娛樂品牌之一，網易拿到這個品牌的遊戲開發權本身就是一種能力證明。

**同時在線從64萬暴跌到9.6萬——說明首發體驗有問題。** 85%的同時在線流失率在競技遊戲裡屬於嚴重警報。大量玩家嚐鮮後離開，通常意味著遊戲的核心玩法循環（遊戲節奏、匹配體驗、角色平衡等）沒有達到預期。

**從9.6萬回升到20萬+——說明團隊在快速修正。** 版本更新和運營調整把一部分玩家拉了回來。這是積極信號，證明問題不是"不可修復的"。

**63%的Steam好評率——說明仍有大量不滿。** 在競技遊戲領域，低於70%的好評率意味著社區口碑需要持續修復。好評率是滯後指標——即使最近的版本改善了體驗，歷史差評不會消失。

### 漫威爭鋒能否成為長青遊戲？

這是決定網易未來3-5年增長故事的關鍵問題。

**支持長青化的證據：**

1. **漫威品牌的持續吸引力。** 漫威電影、漫畫、動畫不斷推出新角色和新故事——每一個新角色都是遊戲內容更新的天然素材。只要漫威品牌不衰落，遊戲就有持續的內容來源。

2. **團隊進化類遊戲的特殊優勢。** 漫威爭鋒是6v6團隊射擊遊戲——這個品類的代表作（如守望先鋒、無畏契約）都證明瞭"英雄/角色持續更新"的模式可以維持多年的用戶粘性。

3. **同時在線已觸底回升。** 從9.6萬回升到20萬+，趨勢是向上的。如果能穩定在15-20萬以上的同時在線，就具備了長期運營的基礎。

**反對長青化的證據：**

1. **63%好評率是硬傷。** 競技遊戲極度依賴社區口碑——一旦被貼上"差評多"的標籤，新玩家的進入意願會顯著降低。修復口碑比修復產品更難。

2. **同時在線暴跌85%的記憶很難抹去。** 即使目前回升到20萬+，市場和玩家都記得它曾經從64萬跌到9.6萬。這種"高開低走"的敘事會長期壓制預期。

3. **品牌授權是雙刃劍。** 網易不擁有漫威品牌——它擁有的是開發權。如果合約到期後迪士尼/漫威不續約，或者提高授權費用，遊戲的經濟模型可能完全改變。品牌授權風險在第04篇詳細展開。

**合理預期**：漫威爭鋒大概率能維持為一款"中等成功"的長線遊戲——年收入在$3-5億級別，而非首月年化的$16億級別。如果運營持續改善、新角色持續吸引玩家，有可能進入"小長青"行列。但要達到《英雄聯盟》《無畏契約》那種級別的全球長青——目前的數據不支持這個預期。

## 三、海外困境：10%的天花板怎麼突破？

### 現狀

| 指標 | 網易 | 騰訊 | 差距 |
|------|------|------|------|
| 海外遊戲收入 | ~90億（估，佔遊戲10%） | ~774億（佔遊戲32%） | ~8倍 |
| 全球化策略 | 自研出海為主 | 收購+自研+發行 | 完全不同 |
| 海外工作室 | **7個已關閉** | 多個成熟工作室運營中 | — |

8倍的海外收入差距，不是一兩款遊戲能追上的——這是兩種完全不同的全球化路徑導致的結構性差距。

**騰訊的路徑：用錢買時間。** 收購Supercell（部落衝突）、控股Riot（英雄聯盟）、投資Epic（堡壘之夜）——通過資本運作直接獲得全球頂級產品和團隊。

**網易的路徑：自研出海。** 依靠自己開發的產品打全球市場——成本更低、但成功率也更低。7個海外工作室關閉就是這條路徑代價的具體體現。

### 7個工作室關閉的教訓

7個海外工作室關閉不是一個小數字——它說明網易在海外建立本地化研發團隊的嘗試遭遇了系統性困難。

困難的根源在於：**遊戲研發的核心競爭力很大程度上取決於文化理解。** 網易在中國市場有極深的文化洞察力（夢幻西遊23年的中國文化運營就是證明），但這種能力很難簡單複製到歐美、日韓市場。

關閉工作室之後，網易的海外策略更多轉向"在中國研發、面向全球發行"——漫威爭鋒就是這種模式。這降低了成本風險，但也限制了在海外市場"本地化創新"的可能性。

**反方觀點**：7個工作室關閉也可以理解為"及時止損"——丁磊認識到海外本地化研發這條路走不通，果斷關掉，集中資源做"中國研發+全球發行"。從資本配置角度看，這不一定是壞事。

## 四、小程序遊戲：535億市場的缺席

### 這是一個多大的問題？

2025年中國小程序遊戲市場規模535億元——這幾乎等於網易雲音樂+有道的全部營收。

而網易在這個市場上的存在感接近於零。

### 為什麼缺席？

小程序遊戲的主要平臺是微信——而微信是騰訊的。

| 維度 | 解釋 |
|------|------|
| 平臺歸屬 | 微信小程序生態完全由騰訊控制 |
| 分發優勢 | 騰訊系遊戲天然獲得更多推薦和流量 |
| 技術壁壘 | 小程序遊戲的技術框架和原生遊戲不同，需要專門團隊 |
| 用戶習慣 | 小程序遊戲的用戶更偏輕度、碎片化，與網易擅長的重度遊戲基因不同 |

**這不是網易"不想做"——而是平臺不在自己手裡。** 就像一家餐廳再好，如果商場是競爭對手開的，位置分配上天然吃虧。

### 影響有多大？

535億市場，如果按照騰訊的利潤率估算，可以貢獻超過100億的利潤。網易吃不到這塊蛋糕，等於每年少賺百億級別的利潤——而且這個市場還在高速增長。

**更重要的是趨勢**：小程序遊戲的增速遠高於傳統手遊和端遊。如果未來5年小程序遊戲市場增長到1000億+，網易的缺席將變成一個越來越大的結構性劣勢。

**反方觀點**：小程序遊戲的利潤率可能不如傳統手遊——平臺抽成、用戶付費意願低、生命週期短。網易專注於高ARPU的重度遊戲，利潤率可能反而更高。缺席小程序遊戲不一定是壞事——關鍵看總利潤能不能增長。

## 五、版號：一個正在改善的外部環境

2025年，中國遊戲版號發放量達到**1,771個——七年新高**。

| 年份 | 版號發放數 | 環境 |
|------|----------|------|
| 2021年 | 755 | 版號寒冬 |
| 2022年 | 512 | 最嚴厲的一年 |
| 2023年 | 1,076 | 開始恢復 |
| 2024年 | ~1,300（估） | 持續恢復 |
| 2025年 | **1,771** | **七年新高** |

版號發放量的恢復對網易是明確的利好——更多版號意味著更多新遊戲可以上線。但版號利好對所有遊戲公司都一樣——網易能否從中獲得超額收益，取決於自身的產品儲備。

## 六、小結：遊戲帝國的成色

把這一篇的分析總結成幾句話：

1. **長青產品是網易遊戲的核心護城河**——夢幻西遊23年創紀錄、永劫無間四週年登頂Steam——這種讓遊戲"活很久"的能力在全球罕見
2. **漫威爭鋒是最大變量**——首月驚豔但同時在線暴跌85%後回升至20萬+，大概率是"中等成功"而非"超級長青"
3. **海外是最大的短板**——10%佔比、7個工作室關閉、與騰訊8倍差距——出海之路任重道遠
4. **小程序遊戲535億市場的缺席是結構性劣勢**——平臺不在自己手裡，短期內無法改變
5. **版號環境正在改善**——1,771個創七年新高，但利好全行業而非網易獨享

**如果用一句話概括網易的遊戲帝國：國內極強、海外極弱、增長靠新品和出海——而新品和出海恰恰是最不確定的部分。**
