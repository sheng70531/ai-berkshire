# 價格判斷——$113買入的真問題

> 《看懂網易》系列 · 第 05 篇 · 決策 · 系列終章
> 閱讀時間約 7 分鐘

---

## 寫在最前

這是《看懂網易》系列的最後一篇。前4篇拆了認知錯覺、遊戲帝國、雲音樂與有道、丁磊與風險。

最後一篇回答那個最直接的問題：**$113到底值不值得買？**

先說結論框架：不給精確目標價，而是告訴你在什麼情況下這是"黃金坑"、什麼情況下是"價值陷阱"——讓你根據自己的判斷做決定。

---

## 一、估值拆解：四種方法交叉驗證

### 方法一：PE法

| 指標 | 數據 |
|------|------|
| 2025年GAAP淨利潤 | ~353億元（估） |
| 2025年Non-GAAP淨利潤 | 373億元 |
| 當前市值 | ~5,300億元（$729億） |
| GAAP PE | ~15倍 |
| Non-GAAP PE | ~13倍 |
| 前瞻PE（分析師一致預期） | ~12.3倍 |

13倍Non-GAAP PE買一家淨利率33%、還在增長的公司——在中國互聯網板塊裡屬於偏低水平。

作為參照：騰訊目前PE約18-20倍、拼多多約10-12倍、嗶哩嗶哩仍在虧損。13倍PE在這個群體裡不算最便宜，但考慮到網易的盈利質量（33%淨利率、496億自由現金流），這個定價顯然沒有給予足夠的估值溢價。

### 方法二：EV/EBITDA法

| 指標 | 數據 |
|------|------|
| 企業價值（EV） | 市值5,300億 - 淨現金1,635億 = ~3,665億 |
| EBITDA | ~392億（估） |
| **EV/EBITDA** | **~9.35倍** |

9.35倍的EV/EBITDA——扣除現金後，市場給網易業務的定價不到10倍稅前利潤。

對標全球遊戲公司：動視暴雪被微軟收購時的EV/EBITDA約18倍；EA約12倍；Take-Two約15倍。9.35倍在全球遊戲行業裡屬於明顯偏低。

**但要注意**：中概股整體有"中國折價"——地緣政治風險、治理結構差異等因素讓海外投資者要求更高的風險補償。9.35倍可能不是"低估"，而是"合理反映了中國折價"。

### 方法三：自由現金流法

| 指標 | 數據 |
|------|------|
| 2025年自由現金流 | ~496億元 |
| 當前市值 | ~5,300億元 |
| P/FCF | ~9.9倍 |
| FCF收益率 | ~9.4% |

約10倍自由現金流買下整家公司——這意味著如果用5,300億買下網易，每年能拿回496億現金，10.7年回本。扣掉賬上1,635億現金（買入即到賬），實際只用3,665億買業務——**7.4年回本**。

496億自由現金流的"含金量"值得關注：網易的資本支出僅11億元——幾乎不需要重新投入就能維持現有的賺錢能力。這種"輕資產+高現金流"的組合在全球上市公司裡並不常見。

### 方法四：淨現金+業務分部估值

把網易拆成幾個部分分別估值：

| 部分 | 估值方式 | 價值（億元） |
|------|---------|------------|
| 淨現金 | 1:1計算 | 1,635 |
| 遊戲業務 | 12-15倍利潤（300-350億利潤） | 3,600-5,250 |
| 雲音樂 | 15-20倍利潤（16億利潤） | 240-320 |
| 有道 | 3-5倍營收（59億營收，尚未穩定盈利） | 177-295 |
| 創新及其他 | 5-8倍利潤（估10-15億利潤） | 50-120 |
| **總計** | — | **5,702-7,620** |
| 當前市值 | — | 5,300 |
| **低估幅度** | — | **7%-30%** |

四種方法指向同一個方向：**按當前價格，網易被低估了10-30%，具體取決於對遊戲增長的預期。**

**反方觀點**：所有估值模型都假設利潤能維持或增長。如果遊戲行業遇到系統性衝擊（版號收緊、AI顛覆、用戶偏好轉移），或者漫威爭鋒未能如預期發展、海外持續受阻——13倍PE可能不是"低估"，而是"合理定價了增長的不確定性"。

## 二、與騰訊的對比：誰更值得買？

這是投資網易時繞不開的問題——同樣的錢放騰訊好還是放網易好？

| 維度 | 網易 | 騰訊 |
|------|------|------|
| PE（Non-GAAP） | ~13倍 | ~18-20倍 |
| 淨利率 | 33% | ~28% |
| 毛利率 | 64.3% | ~53% |
| FCF | ~496億 | 更高但Capex也更高 |
| 淨現金佔市值 | 31% | 更低 |
| 業務多元化 | 遊戲82%，高度集中 | 遊戲38%+社交+廣告+金融+雲 |
| 海外收入 | ~10% | ~30% |
| 增長空間 | 主要靠出海和新品 | 多元驅動 |
| 治理風險 | 丁磊45.5%一人決策 | 職業經理人團隊 |

**選網易的理由**：更便宜（PE低30%以上）、利潤率更高、現金流更"乾淨"（資本支出極低）、淨現金安全墊更厚。

**選騰訊的理由**：業務更多元（風險更分散）、海外更強（3倍於網易）、增長驅動力更多、治理結構更好、小程序遊戲獨佔535億市場。

**數據表明**：網易更像一隻"高股息+低增長"的價值股——賺錢效率極高但增長空間受限。騰訊更像一隻"中等股息+中高增長"的成長價值混合股——賺錢效率稍低但增長路徑更寬。

**這不是"誰更好"的問題，而是"你要什麼"的問題。** 如果追求確定性和現金回報——網易更合適。如果追求長期增長和業務廣度——騰訊更合適。兩者並非互斥——按不同比例配置也是合理策略。

## 三、安全邊際在哪？

### 第一層：1,635億淨現金

賬上1,635億淨現金，佔市值31%。翻譯一下：**你買下整個網易，三成的錢馬上就能從賬上拿回來。** 剩下的七成買的是一臺年賺373億（Non-GAAP）的業務。

### 第二層：496億自由現金流

每年496億的自由現金流——且資本支出僅11億。這意味著即使網易從今天開始不再增長、不再開發新遊戲，每年仍然能產出接近500億的現金。

更關鍵的是**分配意願**：回購超$20億、分紅$2/ADS、派息比率60%——管理層在把現金回饋給股東。

### 第三層：遊戲業務的韌性

夢幻西遊23年仍創紀錄——這種產品生命力是極難複製的資產。即使新遊戲全部失敗、海外拓展全部受阻，僅靠現有長青產品組合，網易的遊戲收入在未來3-5年也不太可能出現斷崖式下跌。

**三層安全墊疊加：淨現金佔市值三成 + 年產自由現金流近500億 + 核心產品生命力極強。** 這讓"虧大錢"的概率變得很低。

## 四、什麼情況下是"價值陷阱"？

安全邊際高不等於不可能虧。如果以下兩件事**同時發生**，當前價格可能不是底：

### 1. 遊戲增長停滯

如果未來2-3年內：
- 夢幻西遊的同時在線開始實質性下降（玩家老化不可逆）
- 漫威爭鋒未能維持年收入$3億以上（品牌授權賺不回成本）
- 沒有新的爆款產品出現
- 海外收入佔比仍然停在10%左右

在這種情景下，921億的遊戲收入可能進入緩慢下滑通道。一家收入在下降的公司，即使利潤率高、現金流好——市場也不會給它合理的估值。

### 2. 中國折價持續擴大

如果中美關係繼續惡化、中概股的系統性折價從目前的30-40%擴大到50-60%——那即使基本面沒有變化，股價也可能進一步下行。

**兩件事疊加的概率中等偏低，但如果真的疊加——可能還有15-25%的下行空間。**

---

## 五、什麼情況下是"黃金坑"？

如果以下三件事中**任何兩件發生**，當前價格回頭看就是明確的黃金坑：

### 1. 漫威爭鋒成為長青遊戲

如果漫威爭鋒在持續運營1-2年後：
- 同時在線穩定在15-20萬以上
- 年收入穩定在$5億以上
- Steam好評率修復到70%以上

這意味著網易成功打造了一個全球級別的長線產品——海外收入佔比可能從10%提升到15-20%，打開全新的增長空間。

### 2. 海外收入佔比提升到20%

從10%到20%，意味著海外遊戲收入從約90億增長到約200億（假設總遊戲收入增長到1,000億+）。這個量級的變化足以讓市場重新評估網易的增長前景——從"中國遊戲公司"升級為"全球遊戲公司"。

### 3. 中概股折價收窄

如果中美關係緩和、或者中國互聯網行業恢復增長信心——中概股的系統性折價可能從30-40%收窄到15-20%。僅估值修復這一項，就意味著30-50%的股價上行空間。

**如果"漫威爭鋒長青+中概折價收窄"同時發生——PE從13倍修復到18-20倍，股價對應$155-175。從$113起步，漲幅37-55%。**

## 六、$113到底值不值得買？

不給精確答案，而是給一個判斷框架。

### 買之前問自己五個問題

**第一，網易的遊戲增長你怎麼判斷？** 如果你認為夢幻西遊還能再撐5-10年、漫威爭鋒能成為中等以上的長青遊戲、有道的AI業務能跑出來——那13倍PE買入的回報空間可觀。如果你認為長青產品在老化、新品沒有接班人、海外做不起來——那13倍PE只是"合理定價"。

**第二，你怎麼看丁磊這個人？** 45.5%的持股意味著買網易就是買丁磊。如果你信任他的產品判斷力和資本配置能力——這是加分項。如果你擔心"一個人說了算"的風險——這是減分項。

**第三，1,635億淨現金你怎麼定價？** 如果你1:1計算（現金就是現金），那扣除現金後的遊戲業務只有約10倍PE，非常便宜。但如果你對"中國公司能不能真正把現金還給股東"有疑慮——那現金的價值需要打折。目前60%的派息比率和持續回購說明丁磊在回饋股東，但未來會不會改變？不確定。

**第四，你的持有期有多長？** 漫威爭鋒能否長青需要1-2年驗證、有道的AI業務需要3-5年、中概折價的收窄時間不確定。如果持有期不足3年，很多變量來不及兌現。

**第五，同樣的錢有沒有更好的選擇？** 騰訊18-20倍PE、業務更多元、海外更強——貴30%但風險更分散。選網易還是選騰訊，取決於你對"便宜但集中"和"貴一點但分散"的偏好。

### 什麼時候必須重新評估

幾條紅線——觸發任何一條就要重新審視：

1. 遊戲收入連續兩個季度同比下降（核心業務增長邏輯被打破）
2. 漫威爭鋒同時在線跌回10萬以下且不再回升（出海最大賭註失敗）
3. 漫威品牌授權出現續約困難的信號（品牌依賴風險顯現）
4. 丁磊大幅減持或改變資本回饋策略（管理層信號轉向）
5. 版號政策再次收緊到2022年水平（外部環境惡化）

反過來，兩條積極信號值得關注：
- **海外收入佔比突破15%**——說明出海策略開始見效
- **有道AI訂閱收入突破10億**——說明第二增長極開始成形

## 七、最後

回到這個系列一開始那個反差：一家淨利率33%、自由現金流496億、淨現金1,635億的公司，被定價為13倍PE。

看完5篇之後，這個定價的邏輯變得清晰了——**市場不是在給"過去的利潤"定價，而是在給"未來的不確定性"和"中國折價"定價**。

不確定性來自：遊戲82%的單一依賴、海外10%的低佔比、漫威爭鋒能否長青、丁磊一個人說了算的治理風險。

中國折價來自：中美關係、監管政策、中概股的系統性低估。

13倍PE，就是市場對這些因素的綜合定價。如果你認為這些風險被過度放大了——那$113是一個有安全邊際的價格。如果你認為這些風險是真實的且可能惡化——那即使13倍PE也不構成足夠的安全邊際。

**兩種判斷都有道理。** 區別只在於你對每個變量的概率評估不同。

一家極度賺錢但增長面臨挑戰的公司、一個產品天才但資本運作偏保守的創始人、一個被地緣政治系統性低估的市場——三件事疊加在一起，構成了網易這道投資題目。

這道題沒有標準答案。但至少，讀完這5篇之後，你應該知道這道題在問什麼了。
