# 阿里雲與 AI——最像好生意的那一塊

> 《看懂阿里巴巴》系列 · 第 03 篇

## 阿里雲決定了阿里巴巴是"價值股"還是"成長股"

這個問題的答案在阿里雲身上。

上一篇結論：淘天份額四年丟了 14 個百分點，飛輪從"自我加速"變為"靠外力維持"。一家只有淘天的阿里，是一隻緩慢衰退的價值股——利潤豐厚但增長見頂，最終會被折價。

但阿里還有一塊資產，它的數字刺眼得像另一家公司：FY2026 收入增速 34%，AI 產品收入連續 11 季三位數增長，AI 雲市場份額 35.8% 超過第 2 到第 4 名之和。這塊資產叫**阿里雲**，是集團中**唯一同時實現高速增長和利潤擴張的板塊**，也是管理層押上 3,800 億賭注的方向。

阿里雲能不能接棒淘天，決定了阿里未來十年走"微軟式重生"還是"IBM 式停滯"。

| 指標 | AWS | Azure | Google Cloud | 阿里雲 |
|------|-----|-------|-------------|--------|

阿里雲的收入是 AWS 的 1/5，利潤率是 AWS 的 1/4。差距是巨大的。但阿里雲有一個 AWS 不具備的獨特優勢：**在中國市場的不可替代性**。由於數據主權要求和中美脫鉤，外資雲在中國幾乎不可能獲得政企客戶，阿里雲是"無可替代"的本土選項。

## 二、AI 是怎麼驅動阿里雲增長的？

### 2.1 AI 收入已成為核心增長極

阿里雲 AI 相關產品收入已經**連續 11 個季度保持三位數增長**。

FY2026 Q4 單季 AI 產品收入 89.71 億元，年化 358 億元——這個數字在一年前幾乎為零。AI 產品佔阿里雲外部收入的比例首次突破 30%，意味著**每 3 塊錢雲收入裡有 1 塊來自 AI**。

增長的驅動力主要來自：
- **AI 推理需求爆發**：大模型應用落地後，推理算力需求是訓練的數十倍
- **通義千問開源生態帶動雲消費**：Qwen 全球下載超 6 億次，17 萬+ 衍生模型——開發者在阿里雲上調試、部署這些模型，產生算力消費
- **企業 AI 落地加速**：百鍊平臺服務超 98 萬企業和開發者

### 2.2 通義千問（Qwen）的競爭力

**優勢：**
- 開源生態全球領先：HuggingFace 2026Q1 下載量第一，超過 Meta Llama
- Qwen3 系列 8 個開源模型，覆蓋全規格、全模態
- 在企業級/B 端市場有落地優勢（依託阿里雲客戶基礎）

**劣勢：**
- C 端月活差距明顯：千問 App 約 1.66 億 MAU（QuestMobile 口徑）vs 豆包 **3.45 億** MAU——差距超 2 倍
- 月人均使用次數：千問 **19.8 次** vs 豆包 **54.8 次**——用戶粘性差距 2.7 倍
- 春節"30 億免單"燒錢營銷後留存率不到 50%——靠補貼買的用戶不是真用戶

*數據來源：QuestMobile 2025-12、ai-berkshire 千問專題報告*

**阿里在 AI 領域的策略是"開源引流，雲端變現"**——模型免費用，但推理算力要花錢買阿里雲。這個邏輯和亞馬遜的 AWS 思路一致：你用我的工具建應用，你的應用越成功，你買的算力越多。

**但另一方面**：字節的豆包在 C 端應用層的優勢可能傳導至雲層。2025 年大模型 API 調用市場份額中，字節火山引擎佔 46.4%，阿里雲排第二。如果"用豆包的人多 → 用火山引擎的開發者多 → 火山引擎算力份額上升"——這就是"抖音顛覆淘寶"路徑的雲計算版本。

## 三、3,800 億 AI 投入——遠見還是泡沫？

### 3.1 投入規模

吳泳銘承諾："未來三年（FY2026-FY2028）在雲和 AI 基礎設施上的投入將超過過去十年的總和。"市場估算這個數字約為 **3,800 億元人民幣**。

吳泳銘還暗示"3,800 億偏保守"。

FY2026 全年資本開支已達 **1,261 億元**——光一年就燒了 1,261 億。

### 3.2 這筆錢值不值？

**正面論據（看多派）：**

這是"進攻性資本開支"，類似亞馬遜 2005-2015 年 AWS 早期的路徑。AWS 當年也是連續燒錢 10 年，把利潤壓到極低，換來了後來 30%+ 的利潤率和萬億市值的貢獻。

支撐數據：
- 阿里雲 AI 收入已經開始加速兌現（年化 358 億，連續 11 季三位數增長）
- 中國 AI 推理需求確實在爆發——每年數十倍的 Token 調用量增長
- 吳泳銘的 5 年目標：雲+AI 商業化年收入超 **1,000 億美元**（約 7,100 億元）

**反面論據（看空派）：**

- 蔡崇信自己說過"AI 數據中心存在泡沫"——當公司董事長都在公開場合發出警告，投資者不應該忽視
- 阿里雲利潤率僅 9%，AWS 為 36%——差距 4 倍。如果阿里雲永遠追不到 AWS 的利潤率水平，3,800 億投入就是在低迴報率上堆規模
- 中國 AI 行業正在經歷價格戰——DeepSeek 用 1/10 的算力做出了 Top 3 模型，證明"算力堆疊"未必是護城河
- 字節火山引擎、華為雲、騰訊雲都在加碼——價格戰可能把所有人的利潤率都壓下來

### 3.3 關鍵驗證節點

| 時間 | 需要看到什麼 |
|------|-----------|
| FY2027（2027 年 3 月前）| 阿里雲外部收入增速維持 30%+，AI 收入佔比超 40% |
| FY2028 | 阿里雲年收入突破 2,500 億元，EBITA 利潤率升至 12-15% |
| FY2030 | 吳泳銘的 1,000 億美元目標是否有跡象能兌現一半（500 億美元）|

如果以上節點逐一兌現，阿里雲將成為阿里集團最大的利潤引擎，3,800 億投入是值得的。如果 AI 收入增速降到 15% 以下，利潤率卡在 12%，這筆錢就是沉沒成本。

## 四、阿里雲的護城河：三層壁壘

### 4.1 第一層——規模與客戶鎖定

- 中國 IaaS 市場份額 26.8%，連續多年第一
- 政企客戶數據遷移成本極高——一旦部署在阿里雲上，遷移到華為雲或騰訊雲需要數月甚至數年
- 國資敏感數據合規優勢：阿里雲在金融雲、政務雲領域已有深厚積累

### 4.2 第二層——AI 模型生態

- 通義千問開源模型全球下載 6 億次，17 萬衍生模型
- 百鍊平臺 98 萬企業/開發者——形成"模型引流 → 雲端消費"的閉環
- 中國唯一同時擁有"基礎大模型 + IaaS + 下游應用入口（淘寶/釘釘/高德/支付寶）"的雲廠商

### 4.3 第三層——中國市場的不可替代性

- 中美脫鉤使外資雲無法服務中國政企客戶
- AWS 中國 + Azure 中國合計份額僅 5-7%，且受地緣政治限制
- 阿里雲 + 華為雲 + 天翼雲三家瓜分了政企雲的大部分蛋糕

**這三層壁壘使得阿里雲是阿里所有業務中護城河最深、且仍在加寬的板塊。**

### 4.4 護城河的威脅

但護城河不是沒有裂縫：

- **字節火山引擎**：憑藉豆包大模型在 AI 應用層的優勢，正在從 C 端切入 B 端。大模型 API 調用份額 46.4% 已經超過阿里雲。2024 年火山引擎份額僅 5-6%，2025 年飆升至 8-12%——增速驚人
- **華為雲**：憑藉信創政策和政企關係，在混合雲/政務雲領域已超過阿里雲
- **運營商雲**（天翼/移動/聯通）：合計份額超 30%，憑藉基礎設施優勢快速崛起

**十年中性預測：**
- 阿里雲中國份額：33-36% → **28-32%**（小幅下滑但仍保持第一）
- 字節火山引擎：8-12% → **18-22%**
- 華為雲：18-21% → **22-26%**

格局將從"阿里雲一家獨大"變為"三足鼎立 + 國資雲"。

## 五、吳泳銘的"中國 AWS"敘事，可信嗎？

吳泳銘的戰略願景是讓阿里變成"中國的亞馬遜"——電商是現金牛，雲是增長引擎和估值錨。

### 5.1 微軟式成功路徑

最接近的歷史類比是**微軟 2014-2024 的轉型**：

| 維度 | 微軟 | 阿里 |
|------|------|------|
| 換帥 | 納德拉 2014 上任 | 吳泳銘 2023 上任 |
| 戰略 | Mobile First → Cloud First | 電商帝國 → AI 雲 + 消費 |
| 砍業務 | 放棄手機、收縮消費者業務 | 賣銀泰、高鑫零售 |
| 老業務現金流 | Office 365 年入千億美元 | 淘天年利潤 ~2,000 億元 |
| 轉型結果 | 市值從 3,000 億漲到 3 萬億 | ？ |

### 5.2 IBM 式失敗路徑

但也有失敗案例——**IBM 2010-2024**：

| 維度 | IBM | 阿里的風險 |
|------|-----|-----------|
| 戰略方向 | 押注 Watson AI + 雲 | 押注通義千問 + 阿里雲 |
| 問題 | 老業務（大型機）下滑太快，新業務（Watson）執行力差 | 淘天份額持續流失；千問 C 端產品力弱於豆包 |
| 結果 | 營收 10 年原地踏步，市值長期跑輸大盤 | ？ |

**兩條路徑的分水嶺是：老業務的現金流能不能撐到新業務盈利。**

微軟成功是因為 Office 365 的現金流極其穩定，給 Azure 爭取了 10 年轉型時間。IBM 失敗是因為大型機收入下滑太快，接不住 Watson 的研發投入。

對阿里而言：淘天年利潤 2,000 億，阿里雲 EBITA 利潤率在緩慢提升（9% → 目標 18-20%）。如果淘天能守住 30%+ 的份額、保持千億級利潤，就能給阿里雲 5-8 年的轉型窗口。如果淘天份額加速下滑到 25% 以下，現金牛先倒了，阿里雲還沒長大——那就是 IBM 的劇本。

### 5.3 中性判斷

**阿里雲成為"中國 AWS"的概率：約 40-50%。**

樂觀路徑：5 年內 EBITA 利潤率升至 18-20%，年收入突破 4,000 億，成為集團最大利潤引擎。
悲觀路徑：價格戰壓縮利潤率，份額被火山引擎蠶食，利潤率卡在 12%，變成"還不錯但不驚豔"的生意。

## 六、核心結論：阿里雲的十年畫像

| 維度 | 當前 | 十年後（中性預測）|
|------|------|----------------|
| 年營收 | 1,581 億元 | **4,000-7,300 億元** |
| EBITA 利潤率 | ~9% | **18-20%** |
| 經營利潤 | ~140 億元 | **800-1,400 億元** |
| 在集團地位 | 第二大收入源，微利 | **與淘天並列的利潤引擎** |
| 護城河 | 正在加寬 | 中國 AI 雲龍頭，全球 Top 4 |

*預測來源：綜合高盛、ai-berkshire 10 年利潤推演報告*

用段永平的標準檢驗：**阿里雲是阿里所有業務中最像"好生意"的那一塊**——有用戶粘性、有定價權潛力、有規模經濟、有複利效應。

但"好生意"的前提是 ROIC 拐點能在 2030 年前到來。3,800 億投入如果換不來利潤率的實質性提升，"好生意的種子"就會變成"資本黑洞"。

高盛在 SOTP 估值中給阿里雲單獨估值約 **54 美元/股**——這意味著阿里雲一個板塊就值當前市值的約 40%。市場是否認可這個估值，取決於接下來幾個季度 AI 收入增速能否持續。
