## 杭州重點公司（7家詳細分析）

### 1. 宇樹科技 ★★★★✦（4.5星）

| 維度 | 數據 |
|------|------|
| 成立 | 2016年，創始人王興興（90後，前大疆） |
| 產品 | 四足機器人Go/B系列 + 人形機器人H1/G1 |
| 融資 | 10輪，IPO估值420億，計劃科創板募資42億 |
| 財務 | **2025年營收17億(+335%)，淨利6億(+674%)，毛利率60.3%** |
| 競爭 | vs 智元機器人（國內）、特斯拉Optimus（全球） |

**投資判斷**：中國機器人賽道最確定的標的。已盈利+高增長+高毛利的組合在全球機器人行業極為罕見。420億估值對應約70x PE偏貴，但高增速可消化。核心風險：人形機器人規模化應用場景尚未打開。

### 2. DeepSeek ★★★★（4星）

| 維度 | 數據 |
|------|------|
| 成立 | 2023年7月，創始人梁文鋒（幻方量化掌舵人） |
| 產品 | DeepSeek系列大模型（V2/V3/R1/V4），開源 |
| 融資 | 首輪外部融資500億元，估值3500億，國家大基金洽談領投 |
| 團隊 | **僅139人**，人才密度全球頂級 |
| 競爭 | 全球對標OpenAI/Google DeepMind/Anthropic |

**投資判斷**：國運級標的。用極小團隊和極低成本做出全球頂級模型，技術實力已獲國際驗證。核心風險：139人團隊脆弱性（已有5名核心被挖）、商業化路徑不清（開源如何變現）、梁文鋒個人意志的絕對控制。高賠率高風險，適合戰略資本而非財務投資。

### 3. 晶泰科技 ★★★★（4星）

| 維度 | 數據 |
|------|------|
| 成立 | 2015年，MIT量子物理學者三人組 |
| 產品 | AI驅動藥物發現平臺，服務全球Top20藥企中17家 |
| 市值 | 港股上市（2228.HK） |
| 財務 | **2025年營收8億(+201%)，淨利2.58億（首次盈利）** |
| 亮點 | 禮來3.45億美元大單續簽，現金70.7億 |

**投資判斷**：AI製藥賽道最安全的標的。已盈利+大藥企訂單+充裕現金。港股流動性不足是主要風險。

### 4. 智元機器人 ★★★✦（3.5星）

| 維度 | 數據 |
|------|------|
| 成立 | 2023年，CTO"稚暉君"彭志輝（前華為天才少年），CEO鄧泰華（前華為副總裁） |
| 產品 | 遠徵/精靈/靈犀人形機器人，GO-1具身基座大模型 |
| 融資 | 兩年10+輪，估值150億，計劃2026年Q3港股IPO |
| 財務 | **2025年營收10.5億，出貨5168臺（全球近四成）** |

**投資判斷**：增長速度驚人但燒錢兇猛（一邊融資一邊投資15家創企）。150億估值對應15x PS，在未盈利情況下偏貴。"稚暉君"個人IP綁定過深是隱患。

### 5. 生數科技（Vidu）★★★✦（3.5星）

| 維度 | 數據 |
|------|------|
| 成立 | 2023年，清華系+螞蟻+百度BV孵化 |
| 產品 | Vidu AI視頻生成大模型，全球排名中國第一、全球第二 |
| 融資 | B輪近20億元，估值超20億美元（150億元） |
| 財務 | ARR突破2000萬美元，用戶/收入超10倍增長 |

**投資判斷**：技術全球前二，但20億美元估值對應不到2億元ARR（PS極高）。70人團隊在大廠面前規模劣勢明顯。高彈性高波動標的。

### 6. 雲深處科技 ★★★（3星）

| 維度 | 數據 |
|------|------|
| 成立 | 2017年，創始人朱秋國（浙大副教授） |
| 產品 | "絕影"四足機器人，行業端市佔率80%+ |

**投資判斷**：四足機器人隱形冠軍，行業端市佔率極高。但四足市場天花板有限，人形產品線剛起步。

### 7. 雲知聲 ★★✦（2.5星）

| 維度 | 數據 |
|------|------|

## 投資策略建議

### 如果只能選3家

1. **宇樹科技**（確定性） — 已盈利+高增長，科創板IPO打新
2. **地平線**（安全邊際） — 智駕芯片國產替代確定性最強
3. **月之暗面/DeepSeek**（彈性） — 大模型賽道頭部，高賠率

### 需要回避的

1. **零一萬物** — 掉隊明顯，大概率被收購
2. **依圖科技** — 邊緣化不可逆
3. **沐曦股份** — AI芯片中基本面最薄弱，PS 180x+

### 等待時機的

1. **智譜AI** — 基本面紮實但4000億港元市值PS 70x，等回調
2. **MiniMax** — 海外收入極稀缺但2000億港元市值PS 350x，等回調
3. **寒武紀** — 龍頭地位確立但PS 110x，需驗證信創外的商業需求
