# 商業與競爭——幻方背景、變現路徑與全球對手

> 《看懂DeepSeek》系列 · 第 03 篇
> 閱讀時間約 10 分鐘

---

## 一個反常識的起點

全球估值最高的AI公司裡，DeepSeek是唯一一家**主動不賺錢**的。

OpenAI 2025年收入預估超過**100億美元**。Anthropic融資超過**150億美元**並開始產生顯著收入。Google DeepMind背靠Alphabet萬億美元市值。

DeepSeek呢？API定價是競品的1/10到1/50，核心模型全部免費開源，創始人公開表示"不追求盈利"。

那它憑什麼活到今天？憑什麼估值**3,500億元**？

答案藏在它的母公司裡。

---

## 幻方量化：DeepSeek的"印鈔機"

### 幻方是什麼？

| 項目 | 內容 |
|------|------|
| 全名 | 杭州幻方量化資產管理 |
| 創始人 | 梁文鋒（同時也是DeepSeek創始人） |
| 成立 | 2015年 |
| 性質 | 量化對沖基金 |
| 管理規模 | **700億元+**（來源：私募排排網） |
| 2025年收益率 | **56.55%**（來源：36氪） |
| 2025年預估利潤 | 約**50億元** |
| GPU集群 | 約**10,000張**NVIDIA A100（2023年採購，芯片禁令前） |

幻方量化是中國最大的量化對沖基金之一。它的核心能力是用AI做量化交易——這也是梁文鋒創辦DeepSeek的起點：**他在做量化交易的過程中積累了大量AI算力和工程經驗，然後決定用這些資源做通用大模型。**

### 幻方能供養DeepSeek多久？

以2025年利潤約50億元估算：

| 項目 | 估算 |
|------|------|
| DeepSeek年運營成本 | 約**15-30億元**（估，含算力、人力、API補貼） |
| 幻方年利潤 | 約**50億元** |
| 覆蓋倍數 | **1.7-3.3倍** |

看起來可以覆蓋。**但這裡有一個致命的假設：幻方的收益率能持續。**

量化基金的收益率波動極大。幻方2025年56.55%的收益率是**異常高**的——它此前也經歷過大幅回撤。如果某一年幻方收益為零甚至虧損，DeepSeek的資金來源就會斷裂。

**反方觀點**：幻方管理規模超過700億，即使收益率降到10-15%，年利潤仍有70-100億——足夠覆蓋DeepSeek。而且梁文鋒對DeepSeek的投入是"長期意志"，不會因為短期波動就斷供。

**再反方**：量化基金行業的尾部風險是真實的。2018年中國量化基金行業曾出現系統性虧損，幻方也不例外。用量化基金利潤做AI研究，本質上是**用一個高波動資產的收益去供養一個純支出項目**——如果兩者同時遇到逆風，局面會很難看。

## 首輪融資500億元：轉折點

2026年5月，DeepSeek終於啟動了成立以來的首輪外部融資。關鍵信息：

| 項目 | 內容 |
|------|------|
| 融資目標 | **500億元**（來源：華爾街見聞、新浪財經） |
| 梁文鋒個人出資 | 最高**200億元** |
| 領投方 | 國家集成電路產業投資基金（大基金）洽談中 |
| 投後估值 | 約**3,500億元**（~$450億美元） |
| 其他潛在投資者 | 多個互聯網巨頭及國資基金 |

（來源：華爾街見聞、新浪財經、36氪、投資界）

### 這輪融資意味著什麼？

**看多解讀**：

1. 國家大基金領投 = 國家隊背書，芯片供應鏈保障升級
2. 500億元彈藥充足，足以覆蓋未來2-3年的算力投入
3. 梁文鋒自掏200億，說明創始人信心極強
4. 估值3,500億元對應的是全球AI第一梯隊的定位

**看空解讀**：

1. "不融資的理想主義"終結了——融資就意味著有股東，有股東就有回報預期
2. 國家大基金參與 = 政治因素介入，研究方向可能受限
3. 3,500億元估值對應的是一家**零收入**（或近乎零收入）的公司
4. 梁文鋒出資200億，可能是因為外部投資者不願意出那麼多——也可能是控制權考量

**一個需要警惕的邏輯**：市場正在用"OpenAI估值3,000億美元"來錨定DeepSeek的估值。但OpenAI有超過100億美元年收入和1.5億+周活用戶。DeepSeek有什麼？技術影響力、開源生態、以及一個"未來可能商業化"的期權。這兩者的估值邏輯完全不同。

## 變現路徑：現在在哪？未來去哪？

### 當前收入來源

| 來源 | 規模 | 性質 |
|------|------|------|
| API服務 | 極低（定價是競品1/10-1/50） | 刻意低價 |
| 企業客戶 | **3,200+家**（來源：DemandSage） | 規模可觀但單價低 |
| 月API調用 | **57億次**（來源：DemandSage） | 用量大、單價低 |

粗略估算：假設API平均收入$0.50/百萬tokens、月調用57億次、每次平均1,000 tokens，年收入量級約在**數億元**——相比運營成本和估值，幾乎可以忽略不計。

### 潛在變現路徑

| 路徑 | 可行性 | 說明 |
|------|--------|------|
| 提高API定價 | 中 | 有生態鎖定基礎，但"低價"是品牌核心 |
| 企業級定製 | 中高 | 3,200+企業客戶是起點 |
| 政府/國防 | 高（國內） | 大基金入股後政企合作概率增大 |
| C端產品 | 低 | 產品能力是DeepSeek最大短板 |
| 授權收費 | 低 | 與MIT開源協議矛盾 |

**反方觀點**：DeepSeek的"不賺錢"也許不是問題——如果它的目標是成為"AI基礎設施"。Linux不賺錢，但Red Hat（被IBM以340億美元收購）賺錢。Android不賺錢，但Google通過Android生態賺了遠超開發成本的利潤。開源的商業化有很多成功先例。

**再反方**：Linux和Android背後有IBM/Google這樣的巨頭持續投入。DeepSeek背後是一家量化基金。兩者的資源深度不可同日而語。

## 競爭格局：四極世界

2026年5月的全球AI競爭格局，可以用一張表說清楚：

| 維度 | OpenAI | Anthropic | Google DeepMind | DeepSeek |
|------|--------|-----------|-----------------|----------|
| 最新旗艦 | GPT-5.4 | Claude Opus 4.6 | Gemini 3.1 Pro | V4-Pro |
| 策略 | 閉源+訂閱+企業 | 閉源+安全優先 | 閉源+生態整合 | **開源+低價** |
| 年收入 | **100億美元+** | 數十億美元 | 納入Google營收 | **近乎零** |
| 總融資 | **300億美元+** | **150億美元+** | Google內部 | **3,500億元估值融資中** |
| 核心優勢 | 品牌+用戶量 | 安全+長文本 | 數據+算力 | **成本+開源** |
| 核心劣勢 | 成本高 | 規模較小 | 產品化較慢 | **商業化近乎空白** |
| C端用戶 | **1.5億+周活** | 數千萬 | 數億（含搜索） | **9,690萬月活** |

（來源：各公司公開數據、DemandSage、Bloomberg）

### DeepSeek在競爭中的獨特位置

DeepSeek和其他三家的競爭不在同一個維度上。

OpenAI、Anthropic、Google在爭奪的是**閉源AI的商業市場**——誰的模型更好、誰的客戶更多、誰的訂閱收入更高。

DeepSeek爭奪的是**開源AI的生態影響力**——誰的模型被最多人使用、誰定義了開源AI的標準、誰成為"AI界的Linux"。

**這兩場戰爭有交集但不完全重疊。** DeepSeek可能在商業競爭中輸給OpenAI和Anthropic，但在開源生態中建立了難以撼動的地位。

**反方觀點**：Meta的Llama系列同樣是開源，且背後有萬億美元市值的Meta支撐。DeepSeek在開源賽道的領先並非不可挑戰。此外，如果閉源模型持續在能力上拉開差距，開源生態的吸引力可能下降。

## Anthropic的指控：蒸餾爭議

2026年2月，Anthropic公開指控DeepSeek、月之暗面（Moonshot）和MiniMax對Claude進行了"協調性蒸餾攻擊"——即通過大量調用Claude的API來提取其能力，用於訓練自己的模型（來源：CNBC）。

OpenAI此前也發出過類似指控。

**這個爭議的本質是**：當閉源模型足夠強大時，開源公司是否在"寄生"閉源模型的成果？

DeepSeek未公開回應這一指控。但從技術角度看：

- 蒸餾是AI領域的常見技術，學術上不違規
- 大規模商業蒸餾可能違反API使用條款
- 如果指控屬實，DeepSeek的部分"技術領先"需要打折扣

**這是一個懸而未決的爭議，在缺乏更多證據前不應下定論。但它提醒了一件事：DeepSeek的技術成果，不能簡單用"270人團隊的純原創"來解釋。**
