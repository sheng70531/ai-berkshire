# 快手AI利潤模型與核驗記錄

本目錄屬於2026-09-24快手investment-team研究。主報告位於上一級。

## 復現

在項目根目錄運行：

```bash
python3 reports/快手/AI利潤模型-20260924/model.py
python3 reports/快手/AI利潤模型-20260924/validate.py
```

`model.py`僅用標準庫Decimal，輸入與輸出均以人民幣億元計。所有未來假設在代碼和主報告中披露；正常化歸母利潤不等於精確未來IFRS預測。

## 審計範圍

- `audit-extract.txt`：項目工具按固定seed42、默認15%抽樣，從主報告提取30個條目。提取器上限限制樣本數量；並非全量外部審計。
- `audit-facts.json`及其verdict：7項歷史事實或基於事實的算術。來源能力不一，保留官方單源標記；同一發行人在不同公告重複披露不構成獨立來源。
- `audit-model.json`及其verdict：18項模型輸入或計算結果，核對報告轉錄與全精度模型，不可解釋為外部驗證了預測。
- `audit-exclusions.json`：3個產品版本號、2個主觀條件價格區間；不是可用財務數據源核實的歷史量，不作為通過的事實樣本。
- `validation.json`：12個年度/情景股東歸屬利潤等式復算。
- `financial-rigor.txt`：項目工具跨源、股價股數、市值、估值、三情景與精算調用的完整記錄。

實際複核修正：中間稿2025H1調整利潤誤記為102.32億元，回到Q2完整公告第2、22頁非IFRS調節表後更正為101.98億元。原始表為8,901+1,320−23=10,198百萬元。最終抽樣、校驗文件均已更新；不保留錯誤數值作為已通過事實。

2025損益SBC為26.40億元，數據庫現金流調整SBC為26.30億元，兩者口徑差異不可混用。主報告年度表採用公司損益調節表。

審計通過僅表示抽樣轉錄及算術在聲明範圍內通過。可靈獨立2026成本、融資交割時點、長期單位經濟性、單源融資票據等風險並未因此消失。

## 金融工具輸出的解釋

工具市值驗算結果：`偏差: 0.08%`，對應30.50港元乘約43.3億股，與1319.60億港元供應商市值比較。

工具三情景輸出目標股價：`樂觀137.2 / 中性66.9 / 悲觀14.5 HKD`，與主模型對應；該工具展示的3年增速是為驗證終值反推的等效增速，不是另一個獨立預測。主報告折現用3.25年。

`verify-valuation`默認把輸出PE標作TTM，但該調用輸入明確為2026E模型EPS（44億股和固定情景匯率），其9.71倍僅是模型P/E，不能標作實際TTM。

發現`financial_rigor.py calc`內部使用Python eval，個別含小數表達式的“精確值”存在浮點末位誤差，如405.59999999999997。沒有改動公共工具；本目錄全部最終計算以Decimal結果405.600000為準。錯誤僅在工具展示末位，不影響本報告兩位小數結果。
