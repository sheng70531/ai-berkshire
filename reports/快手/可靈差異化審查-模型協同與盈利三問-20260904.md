# 可靈差異化審查：模型、協同與盈利三問

**基準日：2026-09-04 ｜ 匯率沿用本目錄《賠率表更新與凱利符號臨界點》（20260903）：1 USD = 7.84 HKD，1 HKD = 0.857 CNY，推得 1 USD = 6.72 CNY**

**一句話結論：可靈的差異化真實存在，但它長在商業化執行力上，不長在模型上——而執行力是每季度都要重新證明一次的東西，不是資產。把它接回本目錄已確立的 280 億美元賭贏門檻，按 12 倍市銷率倒推，該門檻要求可靈年收入做到約 157 億人民幣，而當前年化約 34 億元，缺口 4.6 倍。這個缺口能不能補上，取決於工作流鎖定能不能建起來，而不取決於模型排名。**

### 1.1 需要撤回的一條：可靈收入"主要來自北美"

多家媒體（含新浪財經 2026-05-11 分拆報道）稱可靈收入主要來自北美等海外市場。**但本目錄《2026Q2 財報深度解讀》已明確記錄："可靈 70% 收入來自海外"這一說法在 3 票對抗性驗證中被否決，無法驗證來源，列入不得引用清單。**

我在此前的口頭討論中援引過"收入主要來自海外"這一表述，**按本目錄紀律應當撤回**。可以站住的只有《AI 賭注雙向推演》基於運營 PR 的定性表述：可靈的用戶主要在海外、客戶為企業與開發者賬號——**但"用戶在海外"不等於"收入在海外"，兩者之間沒有公開數據可以搭橋**。

這個撤回不影響協同的結論（見第三節），但改變了論證路徑：**協同不成立的理由是量級不對稱與客戶不重疊，不是"錢都在海外賺的"。**

### 1.2 一處前作勘誤：180 億美元的人民幣折算

《2026Q2 財報深度解讀》第 109 行記"180 億美元（約 1,290 億元）"，隱含匯率 USD/CNY = 7.17。按《賠率表更新》（20260903）確立的匯率鏈，1 USD = 6.72 CNY，**180 億美元 = 1,210 億人民幣，而非 1,290 億元**。

連帶修正：對 2025 年可靈收入（約 10–11 億元，取中值 10.7 億）的市銷率，**從記載的約 120 倍修正為約 113 倍**。方向不變，倍數偏高的結論不變。

## 二、第一問：差異化在哪一層

### 2.1 可靈不只做視頻——它在建一條流水線

一個常被忽略的事實：可靈已經不是單一的視頻生成模型，而是一套覆蓋內容生產全鏈路的產品矩陣。

| 環節 | 已上線能力 |
|---|---|
| 圖像 | 可圖（Kolors）文生圖，中英雙語，原生支持中文文字生成 |
| 視頻 | 核心視頻生成，官方文檔口徑含物理模擬與運鏡控制 |
| 音頻 | 文生音效、視頻配音效、語音合成、音色克隆 |
| 人物 | 對口型（真人／2D／3D 均可）、數字人（圖＋音頻出片） |
| 電商 | 虛擬試穿 |
| 交付 | 視頻、圖像、虛擬試穿等接口全線開放 API |

集團層面另有獨立的**快意（KwaiYii）大語言模型**（13B／66B／175B），落地於視頻腳本生成、數字人直播、廣告客服。**快意不在可靈體內，屬主站基礎設施**，讀分拆資產包時不應混算。

**這個矩陣的形狀值得注意：它不是在做通用多模態，是在補一條流水線的缺口。** 腳本 → 圖 → 視頻 → 配音 → 對口型 → 成片交付，每一環都往自己產品裡收。方向與"從生成模型做成內容生產的操作系統"一致。

**但要同時看到反面：這些配套能力單看沒有一個是壁壘。** 文生圖、語音合成、音色克隆、對口型，開源方案遍地都是且多數免費。它們的價值只在打包進同一個工作流，不在任何單項。

### 2.2 模型層：四條趨同壓力

| 壓力 | 內容 | 對可靈的影響 |
|---|---|---|
| 架構公開 | DiT ＋ 三維時空注意力已是行業共識 | 無獨家配方 |
| 數據 | 視頻語料稀缺，但快手庫存小於 YouTube 與抖音 | 劣勢方 |
| 算力 | 二手報道稱 Seedance 國內算力佔有率八成以上（待核） | 迭代速度劣勢 |
| 開源 | 二手報道稱 MiniMax H3 開源後第三方 API 報到 0.09 元／秒（待核） | 地板價被封 |

可靈 3.0 的領先項——原生 4K 直出、電影級打光與微表情控制——是搶跑一年半積累的工程 know-how。**但這類領先的半衰期在本代技術下大約 3 到 6 個月**：二手評測已顯示 Seedance 在最長時長（30 秒對 15 秒）和音畫同步上反超。

**結論：用畫質、時長、分辨率做差異化，已經被證偽過一輪。**

### 2.3 一個重要的負結論：跨家單價對比在公開信息下不成立

流傳的"可靈 5 秒 720P 約 4 元、Seedance 約 2.3 元，貴近一倍"這類說法，**本文核查後認為不可引用**。理由是各家計費口徑根本不可比：

- 可靈按靈感值計費，官方文檔明確不公佈每條總價與分辨率費率，只說"以調用時界面顯示為準"；第三方轉售價散佈在每秒 0.075–0.42 美元區間，隨模型版本、專業模式、是否含原生音頻（含音頻費率翻倍）浮動
- 火山引擎 Seedance 2.0 按 token 計費（不含視頻輸入約 46 元／百萬 token），15 秒視頻約 15 元，摺合每秒約 1 元；而即夢會員打折後同樣內容約 4.58 元
- 同一模型在官方 API 與會員訂閱兩個入口下的單條成本可差 3 倍以上

**同一家自己的兩個入口都差 3 倍，跨家比價沒有意義。** 把這類數字寫進投資論證是危險的。

可以站住的只有方向性判斷：**開源模型正在把地板價往下壓，而可靈的定價能力取決於質量溢價能維持多久**——這個判斷成立，但不要給它配一個精確的倍數。

### 2.4 三條可能長出差異化的路，按可行性排序

**路徑一：工作流鎖定（最現實，可靈已在路上）**

不是模型更好，是切換成本更高：素材庫、項目管理、團隊協作、版權合規、跨鏡頭角色一致性、批量生產管線、投放規格適配。對標是 Adobe——Photoshop 的算法早已不是最好的，但沒人走得掉。

**但本目錄 Q2 報告已經指出了這條路目前最大的問題：可靈約 60% 的收入來自按量計費的 API 調用，沒有續費鎖定。** 企業客戶這個月調 100 萬次、下個月可以調 0 次。**這意味著工作流鎖定目前還只是方向，不是事實。**

**路徑二：垂直場景的端到端交付（次現實，天花板明確）**

差異化不在"生成一段視頻"，在"生成一條能直接投放的廣告"：尺寸、時長、合規、A／B 變體、平臺規格。可靈已在廣告營銷、影視短劇、遊戲製作三個場景推進。

**風險是最肥的場景容易被平臺方自己吃掉**——巨量引擎、騰訊廣告完全可以把素材生成做成投放系統的內置免費功能。

**路徑三：可交互／世界模型（想象力最大，可靈最沒資格）**

從"生成一段片子"到"生成一個可進入操作的空間"，需要物理一致性、狀態記憶、實時推理，是另一個量級的技術，也是唯一可能重建代際差距的方向。

**但贏家大概率是有遊戲引擎積累和交互數據的玩家。快手在這裡既無數據也無算力。這條路的存在對可靈是風險而非機會。**

## 三、第二問：與快手的協同

### 3.1 三條真實存在的正向協同，以及它們的量級

| 協同 | 證據 | 量級判斷 |
|---|---|---|
| 廣告素材降本 | Q2 AIGC 短視頻營銷素材投放消耗同比增超 70%（業績會口徑） | 方向確鑿，但 Q2 廣告收入 206 億元同比僅增 8.7 億元（＋4.4%） |
| 短劇內容供給 | 短劇線上投流同比增超 100%，主站已上線 AI 單元劇 | 短劇營銷收入基數從未披露，無法定量 |
| 訓練語料 | 快手短視頻庫為可靈語料來源之一 | **方向是反的：快手補貼可靈** |

### 3.2 四條證偽

**第一，量級嚴重不對稱。** 可靈 H1 收入超 15 億元，集團 H1 收入 692.51 億元，佔比 2.2%（Q2 單季佔 2.4%）。即便可靈能力 100% 反哺主站，也拉不動大盤：Q2 總收入 355.35 億元同比僅增 1.4%，創上市以來新低；直播 87 億元同比下滑 13.5%。

**第二，成本即時、收益滯後。** Q2 研發費用 45.81 億元同比增 34.7%（增額 11.8 億元），Q1 折舊攤銷 17.75 億元同比增 43.7%、帶寬與服務器託管 17.49 億元同比增 18.4%，2026 年資本開支指引約 260 億元（2025 年約 140 億元）。結果是 Q2 毛利同比降 6.0%、經營利潤同比降 29.0%、H1 歸母淨利 60.49 億元同比降 32.03%。**素材效率提升到今天還沒在廣告收入上兌現出來。**

**第三，客戶不重疊。** 可靈的客戶是企業與開發者 API 賬號，快手的基本盤是國內下沉市場的內容消費者。兩邊共享算力和團隊，**不共享客戶、不共享網絡效應**。本目錄《AI 賭注雙向推演》已下過同樣的判斷："可靈的成功與快手的流量優勢基本無關……主業的流量護城河並未為可靈提供保護。"

**第四，分拆本身就是對協同的否定。** 要獨立融資就要證明獨立性：算力按關聯交易定價還是自建？海外用戶靠產品力還是靠母公司資源？這些問題一旦要在招股書裡回答，"協同"就必須被拆成可計價的關聯交易。**分拆做得越乾淨，協同的故事越站不住。**

### 3.3 定性

不是"快手託舉可靈"，而是**快手在付賬單，可靈在提供估值故事**。真金白銀的流向是快手 → 可靈（260 億資本開支、45.81 億季度研發），效率改善的流向是可靈 → 快手（AIGC 素材消耗 ＋70%），後者的規模遠小於前者。

從生意本質看，這更接近"母公司用現金流養一個高估值資產、長大後分拆做資本運作"的孵化模式。**這條路賺不賺錢，取決於資本市場願不願意給可靈定價，不取決於兩邊有沒有化學反應。**

**投資含義：如果持有快手的理由裡包含"可靈協同"，這條理由不成立，應當從論證中刪除。** 快手值不值得買，取決於淨現金託底與折價收斂（本目錄賠率表已完整推演）；可靈值不值得買，取決於它自己的單位經濟模型。兩件事捆在一起算，容易兩頭都錯。

## 四、第三問：可靈盈利了嗎

### 4.1 "毛利率轉正"是個偽口徑

公司唯一的轉正表述是：2025 年可靈毛利率轉正——**括號裡寫著"未考慮訓練成本"**。

在一個每 6 個月就要重訓一次的賽道上，剔除訓練成本談毛利，約等於只算了推理的電費。**這個口徑不構成盈利證據。**

### 4.2 已知的虧損軌跡

| 期間 | 收入 | 淨虧損 | 來源級別 |
|---|---:|---:|---|
| 2024 全年 | — | 約 5 億元 | 二手（待核） |
| 2025 全年 | 約 10–11 億元 | 約 19 億元 | 收入半一手，虧損二手 |
| 2026 H1 | 超 15 億元 | **未單獨披露** | 收入半一手 |

**快手不單獨披露可靈的利潤表。** 從母公司報表能確認的只有：AI 相關的成本項（研發、折舊、帶寬）增幅顯著快於收入增幅，且公司明確將利潤下滑歸因於 AI 訓練支出與基礎設施投入。

**合理推斷：2026 上半年可靈的實際虧損大概率高於 2025 全年的 19 億元。** 這是推斷不是數據，標註清楚。

### 4.3 真正該盯的時點

不是"毛利率轉正"，是**含訓練成本攤銷後的毛利率何時轉正**。

約束條件有三個：開源模型持續壓低地板價、競品有戰略虧損的耐受力、可靈必須自負盈虧。**在這三個條件同時成立的情況下，我傾向於該時點不早於 2027 年下半年，且前提是行業停止降價。**

一個更樸素的表述：**收入漲了 3 倍，但虧損的分母漲得比它快。可靈目前的狀態是收入曲線漂亮、單位經濟模型未跑通。**

## 五、接回 280 億美元門檻

本目錄《AI 賭注雙向推演》已核出：由回購權與投資者同意權推導，**IPO 隱含定價門檻約 280 億美元**，低於此水平投資者有動機否決上市轉而行使回購權。按 1 USD = 6.72 CNY 折算 = **1,882 億人民幣**。

把本文的業務判斷代進去：

| 情形 | 隱含市銷率 |
|---|---:|
| 280 億美元 ÷ 2026 年 Q2 年化 34 億元 | 55 倍 |
| 280 億美元 ÷ 2026 年全年按 30 億元估 | 63 倍 |
| 180 億美元 ÷ 2025 年 10.7 億元 | 113 倍（勘誤後） |

**反向倒推更有用**：一家增長放緩後的盈利型軟件公司，穩態市銷率給到 12 倍已屬慷慨。按 12 倍倒推，**280 億美元的門檻要求可靈年收入達到約 157 億人民幣**。

當前年化約 34 億元，**缺口 4.6 倍**。若按每年 ＋50% 複合，需要約 4 年（34 → 51 → 77 → 115 → 172），落在 2030 年前後，與 2031-10-30 的最遲上市日期相容——**但要求增速從當前的 ＋240% 一路下滑卻始終不跌破 ＋50%，並連續維持四年。**

**這就是本文三問的匯合點：能不能維持四年 ＋50%，不取決於模型排第幾，取決於第 2.4 節的路徑一能不能建起來。** 而路徑一今天的證據是負面的——60% 收入按量計費、無續費鎖定。

## 六、檢驗點與紅線

### 決定差異化是否成立

1. **企業客戶年度續費率**，以及按量計費收入佔比能否從 60% 往下降。**這是本文認為最關鍵、而公司至今未披露的一個數。** 在客戶數靠低價與新鮮感就能拉動的階段，只報客戶數（3 萬 → 5 萬）不報續費率，本身就是信號
2. **客戶資產沉澱深度**：有多少客戶把素材庫、項目、團隊搬進了可靈
3. **2027 年的對外宣傳口徑**：如果還在拿"模型更強、能出 4K"當主賣點，說明工作流這條腿沒長出來

### 決定協同是否成立

4. **廣告收入增速能否回到兩位數**。Q2 為 ＋4.4%。若 AIGC 素材真能拉動廣告主 ROI，2027 上半年應看到修復到 8–10%；若仍在個位數低位，素材協同的天花板就到這了
5. **分拆條款細節**：算力如何定價、快手保留股權比例、有無排他協議。條款越乾淨越等於官方承認無實質協同；留大量關聯交易則可靈的獨立估值要打折

### 決定盈利路徑

6. **含訓練成本的可靈毛利率**（若分拆後單獨披露）
7. **2027 年資本開支指引**：若仍在 260 億量級而收入未到 60 億元，單位經濟模型的證偽概率顯著上升

### 紅線（觸發即重審，不等於必賣）
