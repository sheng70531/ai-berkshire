## 預測框架

**年利潤 = 總營收 × 綜合毛利率 - 研發費用 - 銷售管理費用 + 非經營性收益 - 所得稅**

核心驅動因子分解：

```
總營收 = 交付量 × 單車收入
交付量 = 中國NEV市場規模 × 理想市場份額 + 海外交付量
單車收入 = f(產品結構, 價格策略)
綜合毛利率 = f(車輛毛利率, 規模效應, 競爭烈度)
費用 = f(研發投入強度, 人員規模, 效率優化)
```

## 一、3年後預測（2029年）

### 外部環境假設

| 假設項 | 數值 | 依據 |
|--------|------|------|
| 中國NEV市場規模 | ~2,300萬輛 | 2025年1,649萬輛，CAGR約8-9%（百人會/中汽協預測） |
| NEV滲透率 | ~60-65% | 從2025年的~50%持續提升 |
| 25-50萬SUV競爭格局 | 極度擁擠 | 2026年已有近70款六座SUV在售，持續增加 |
| 增程技術地位 | 仍有市場但不再稀缺 | 7家跨國車企2026年入局增程 |

### 理想汽車內部假設

- **產品矩陣**：L系列（L9/L8/L7/L6）完成換代 + i系列（i9/i8/i6及可能的i7）全部在售
- **自研芯片M100已量產**，智駕成為標配而非差異化優勢
- **海外業務**仍處於早期階段，貢獻有限（預計佔總交付5-10%）
- **AI/機器人業務**仍在投入期，無實質營收貢獻

**關鍵假設**：這意味著理想回到了2025年的困境——能活但不賺錢。歷史數據支撐這個判斷：2025年綜合毛利率18.7%時，經營利潤就已經轉負。如果毛利率無法回到20%以上，理想在當前費用結構下幾乎不可能盈利。

## 三、10年後預測（2036年）

### 10年預測的誠實聲明

**10年預測的不確定性極大。** 以下數據僅供參考框架，不應作為投資決策依據。原因：

1. **行業格局不可預測**。2016年特斯拉還在虧損，蔚來/理想還未成立；10年後的汽車行業可能面目全非。
2. **技術變量太多**。自動駕駛L4/L5是否普及、固態電池是否顛覆產業鏈、AI/機器人是否成為主營——任何一個變量都能根本性改變理想的價值。
3. **管理層變量**。李想屆時46歲，是否仍在掌舵？核心團隊構成完全不可預測。

因此10年預測我給出的是**情景敘事**而非精確數字。

### 情景A：成功轉型為AI科技公司（概率10%）

**敘事**：理想在2028-2030年間成功將自動駕駛技術、M100芯片、機器人業務打造為第二增長曲線。汽車業務作為AI技術的載體和數據來源，維持穩定；AI/機器人/芯片業務開始貢獻可觀利潤。類比特斯拉從純電動車向"AI+能源+機器人"公司的轉型路徑。

| 指標 | 2036E |
|------|-------|
| 汽車營收 | 2,500億元（100萬輛×25萬） |
| AI/芯片/機器人營收 | 500億元 |
| 總營收 | 3,000億元 |
| 綜合毛利率 | 25%（AI業務拉昇） |
| 經營利潤 | 300億元 |
| **淨利潤** | **~250億元** |
| 經營利潤率 | 10% |

**這個情景需要什麼**：M100芯片在車載AI推理市場取得顯著份額；人形機器人實現萬臺級出貨；建立起"數據-模型-芯片"飛輪。以當前起點看，概率很低，但不是零。

### 情景B：穩健存活的二線車企（概率35%）

**敘事**：理想在2028-2030年經歷痛苦的調整後，穩住了年交付70-80萬輛的規模。沒有成為AI公司，AI/機器人投入最終縮減或剝離。但在25-40萬元家庭SUV細分市場保住了一席之地，類似廣汽/吉利在傳統汽車行業中的位置。

| 指標 | 2036E |
|------|-------|
| 汽車營收 | 1,800億元（75萬輛×24萬） |
| 新業務收入 | 20億元 |
| 總營收 | 1,820億元 |
| 綜合毛利率 | 18% |
| 經營利潤 | 50億元 |
| **淨利潤** | **~45億元** |
| 經營利潤率 | 2.7% |

**邏輯**：這本質上是一家"能賺錢但賺不多"的車企。年淨利潤45億意味著大約2023年峰值的40%。利潤率被競爭壓制在2-3%，接近傳統車企水平（豐田淨利潤率~7%、大眾~4%、通用~3%）。考慮到中國市場的競爭烈度，2-3%可能已經是較好的結果。

### 情景C：收縮求生/被收購（概率40%）

**敘事**：持續5年以上的低毛利率和份額流失，最終迫使理想大幅收縮。李想可能在2030年前後做出重大戰略調整——出售部分業務、尋求合併，或收縮至單一產品線。類比當年威馬、恆馳的衰退路徑，但因為有現金儲備，結局不至於那麼慘。

| 指標 | 2036E |
|------|-------|
| 汽車營收 | 500-700億元（25-30萬輛） |
| 總營收 | 500-700億元 |
| 綜合毛利率 | 12-15% |
| **淨利潤** | **-30至-80億元** |

**或者另一種可能**：被大型科技/汽車集團收購。理想最有價值的資產是：品牌認知度、M100芯片團隊、1000億級別的現金儲備（屆時可能剩300-500億）。收購方可能是華為、小米、甚至某家國際車企。

### 情景D：消亡（概率15%）

**敘事**：最極端情況。連續多年鉅額虧損，現金儲備耗盡，技術人才流失，被迫退市或清算。雖然1012億現金看起來很多，但如果每年虧損80-100億+資本開支50億，10年可以全部燒光。汽車行業有大量這樣的先例——薩博、龐蒂亞克、陸風、眾泰、威馬。

|------|-------|
| **淨利潤** | **不適用（已退出市場或清算）** |

## 四、關鍵敏感性分析

### 毛利率是生死線

理想當前的費用結構（研發~120億+銷管~90億=固定費用~210億），在不同毛利率和營收水平下的經營利潤：

| 營收 \ 綜合毛利率 | 14% | 16% | 18% | 20% | 22% |
|---|---|---|---|---|---|

- 在當前費用結構下，**營收1,200億+毛利率18%是盈虧平衡點**
- 2025年實際：營收1,123億、毛利率18.7% → 經營利潤-5億。模型吻合
- 要回到2023年的利潤水平（經營利潤74億），需要**營收1,500億+毛利率19%** 或**營收1,200億+毛利率22%**

## 五、核心結論

### 一句話判斷

**理想汽車未來3-10年大概率是一家"能活但賺不了大錢"的公司。概率加權後的預期淨利潤在5-15億之間——和1,000億+現金儲備形成巨大的資產回報率反差。**

### 分時間段判斷

| 時間段 | 概率加權淨利潤 | 核心判斷 |
|--------|---------------|---------|
| **3年後（2029年）** | ~5億 | 盈虧線上掙扎。新車週期能否帶來量利雙升是唯一看點 |
| **5年後（2031年）** | ~13億 | 微利狀態。汽車業務穩住但AI/機器人大概率未兌現 |
| **10年後（2036年）** | -5至+10億 | 極度不確定。45%概率是賺錢的二線車企或AI公司，55%概率收縮/虧損/消亡 |

### 利潤恢復到100億以上需要什麼？

反向推導：淨利潤100億 → 經營利潤~90億 → 需要毛利~300億 → 需要：

**路徑A**：營收2,000億 × 毛利率20% = 400億毛利 - 210億費用 = 190億經營利潤（超額達標）
- 這意味著交付量需要達到80-85萬輛（ASP 24萬），且毛利率回到20%
- 難度：極高。80萬輛意味著3.0%+市場份額，20%毛利率意味著競爭減弱或品牌溢價恢復

**路徑B**：營收1,500億 × 毛利率22% = 330億毛利 - 210億費用 = 120億經營利潤
- 這意味著交付量60萬輛+ASP 25萬+毛利率22%
- 難度：極高。22%毛利率是2023年的巔峰水平，在當前競爭格局下幾乎不可能

**結論**：在純汽車業務框架下，理想很難再回到100億利潤水平，除非中國新能源價格戰出現拐點（競爭減弱、行業整合），或者AI/芯片/機器人等新業務開始貢獻高毛利收入。

### 最大的不確定性

1. **價格戰何時結束？** 如果行業在2027-2028年出現洗牌（2-3家車企退出），競爭烈度下降，理想的毛利率可能回升至20%+。但另一方面，比亞迪/華為/小米的規模和資金儲備意味著價格戰可能持續更久。

2. **李想的戰略執行力**。MEGA的失敗 vs i6的成功顯示李想既能犯大錯也能糾錯。未來的關鍵決策（AI投入力度、何時止損、海外節奏）將決定理想是情景A還是情景C。

3. **AI/機器人的期權價值**。如果把M100芯片+機器人視為一張"看漲期權"——出錯的話虧損有限（每年60億研發，10年600億，有現金兜底），但如果押中了，可能帶來百億級新增利潤。問題是，這張期權的執行價很高，而理想的起點（硬件為零、團隊剛建）意味著中籤概率遠低於特斯拉。
