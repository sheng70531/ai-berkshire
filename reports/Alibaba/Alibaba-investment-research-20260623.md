## AI研究偏見自覺

**信息豐富度評級：A級（信息充裕）**

阿里巴巴是全球最受關注的中國科技公司之一，2014年美股上市至今12年，41位分析師覆蓋，媒體報道極度密集，中英文研究材料海量。

**AI研究陷阱**：共識過強且高度分裂——93%的分析師給"買入"評級（一致目標價$191，隱含+82%上行），但股價仍在52周低位附近徘徊。這種"賣方一致看好+市場不買賬"的背離本身就是關鍵信號：要麼市場錯了，要麼分析師的模型忽略了某些系統性風險。

**應對策略**：本報告重點回答一個核心問題——**阿里是"被錯殺的價值窪地"還是"合理定價的價值陷阱"？** 重點檢驗空方邏輯和被市場定價的系統性風險（地緣政治、利潤塌縮、競爭惡化）。

## 第二步：生意本質分析 — 段永平"對的生意"

### 一句話定義

**阿里巴巴是中國最大的電商平臺+亞太最大的雲計算提供商，正處於從"電商現金牛"向"AI基礎設施公司"轉型的關鍵十字路口。**

### 商業模式畫布

```

┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  淘天電商       │     │  阿里雲+AI     │     │  即時零售      │
│  EBITA 1,075億  │────>│  收入+34%      │     │  收入+47%      │
│  利潤率19.4%    │ 輸血 │  EBITA 143億   │     │  大額虧損      │
└──────────────┘     └──────────────┘     └──────────────┘
        │                                        │
        v                                        v
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  國際電商AIDC   │     │  菜鳥物流      │     │  高德/大文娛   │
│  收入+9%       │     │  全球化聚焦     │     │  流量入口      │
│  虧損→盈虧平衡  │     │  200+國家      │     │                │
└──────────────┘     └──────────────┘     └──────────────┘
```

### 收入結構的本質變化

阿里正經歷三重轉型：
1. **從電商公司→AI雲公司**：雲收入增速34%，AI產品佔雲外部收入30%，連續10季三位數增長
2. **從國內公司→全球公司**：AIDC收入1,442億，菜鳥覆蓋200+國家
3. **從輕資產平臺→重資產投入**：3年3,800億AI/雲基建承諾，FCF首次轉負

### 利潤結構的"秘密"

| 分部 | 收入佔比 | EBITA貢獻 | 角色 |
|------|---------|-----------|------|
| 中國電商 | 54.1% | **~141%** | 絕對利潤核心，"輸血機" |
| 雲智能 | 15.4% | ~19% | 利潤尚小但增長最快 |
| AIDC | 14.1% | ~-3% | 接近盈虧平衡 |
| 其他 | 24.9% | ~-47% | 大額虧損 |

**核心洞察**：中國電商以54%的收入貢獻了141%的EBITA（其餘分部合計虧損）。如果將即時零售補貼從電商分部剝離，淘天的"真實"利潤率仍接近FY2025的38%水平。這意味著電商利潤下降是主動選擇（投入即時零售），而非競爭力喪失。

### 毛利率與同行對比

| 公司 | 毛利率 | 經營利潤率 | 說明 |
|------|--------|-----------|------|
| **阿里巴巴** | **39.8%** | **4.9%** | 毛利率優秀，但經營利潤被投入拖低 |
| 騰訊 | ~54% | ~33% | 遊戲+社交的高毛利天然優勢 |
| 拼多多 | ~62% | ~22% | 佣金模式+極低運營成本 |
| 亞馬遜 | ~48% | ~13% | AWS高毛利拉昇，電商偏低 |
| 京東 | ~15% | ~-0.2% | 自營重資產模式 |

阿里39.8%的毛利率在電商中屬於頂級水平（輕資產平臺模式）。經營利潤率4.9%是投入期低點——FY2025為14.1%，FY2024為12.0%。

### 經營槓桿

阿里的經營槓桿在FY2026暫時失效：收入增3%但經營利潤降64%。但這是因為三筆大額投入同時進行：(1)即時零售補貼，(2)AI/雲資本開支，(3)AIDC擴張。如果FY2027投入力度減弱（市場預期Non-GAAP EPS翻倍至$7.86），經營槓桿將強勁恢復。

### 段永平式追問

**這門生意好在哪？一句話：** 阿里擁有中國最大的電商交易平臺（10億年活躍買家×1,000萬+賣家）和亞太最大的雲計算平臺（市場份額33%），前者是中國消費的"水電煤"，後者是AI時代的"基礎設施"。

**但反面追問**：這門生意正變得"不那麼好"——電商面臨拼多多和抖音的激烈蠶食（份額從巔峰70%+降至44%），雲計算面臨字節火山引擎的挑戰（API調用量已被超越）。更根本的問題是：阿里同時在多條戰線投入重兵（即時零售、AI、國際化），能否每一仗都打贏？

## 第三步：護城河評估 — 巴菲特"經濟護城河"

### 五類護城河逐一驗證

| 護城河類型 | 具體表現 | 強度 | 趨勢 |
|-----------|---------|------|------|
| **品牌/定價權** | 淘天是中國電商第一品牌，但"性價比"心智被拼多多搶佔，"品質"心智被抖音分流。0.6%基礎服務費是提升貨幣化率的嘗試，但take rate仍遠低於抖音（>9%） | ★★★☆☆ | 變窄中→企穩 |
| **轉換成本** | 88VIP（5,300萬會員）跨平臺權益形成高轉換成本，但對非會員用戶轉換成本很低——下載拼多多或抖音零成本 | ★★★☆☆ | 88VIP在變寬，整體在變窄 |
| **網絡效應** | 10億年活躍買家×1,000萬+賣家，雙邊網絡效應仍是最強壁壘。但抖音（9.36億MAU）已形成獨立網絡效應，不依賴阿里 | ★★★★☆ | 從壟斷→多極 |
| **規模效應** | 菜鳥物流覆蓋中國GDP 90%區域次日達，阿里雲全球第四/亞太第一。規模優勢明顯但不再獨佔——京東物流、順豐、華為雲都是強競爭對手 | ★★★★☆ | 穩定 |
| **技術/專利壁壘** | 通義千問（Qwen）全球下載量突破10億，開源模型全球第一。自研芯片含光系列。技術壁壘在AI領域快速建設中 | ★★★★☆ | 快速變寬 |

### 護城河趨勢判斷

**過去5年**：電商護城河明顯變窄。從2020年的"一家獨大"到2026年的"四強並立"（阿里44%、拼多多20%、京東19%、抖音9%+）。同時，雲計算護城河在變寬（AI驅動增速從6%加速到34%）。

**未來5年預判**：
- **電商護城河**：大概率繼續收窄但速度放緩。44%→35-40%是合理區間。88VIP和即時零售是守住份額的關鍵武器。
- **雲/AI護城河**：大概率快速變寬。通義千問的開源生態（10億下載→開發者鎖定→雲收入飛輪）正在建立類似AWS的生態壁壘。
- **國際電商護城河**：不確定性最高。Trendyol在土耳其已有強壁壘（34-40%份額），但Lazada在東南亞被Shopee和TikTok Shop擠壓至9%。

### 巴菲特式追問

**10年後這條護城河還在嗎？** 電商護城河會以更弱的形態存在——阿里仍將是中國最大的電商平臺，但不再是"唯一選擇"。真正有可能大幅變寬的護城河是雲/AI——如果通義千問生態持續領先，阿里雲將成為中國版AWS，這是一條比電商更深的護城河。

**什麼能摧毀它？** (1) 中國消費長期通縮導致電商GMV停滯甚至收縮；(2) 字節跳動在AI領域全面超越（火山引擎API調用量已佔49%）；(3) 美國製裁升級切斷芯片供應，阿里雲無法獲取先進GPU。

### 偏誤自查

- **錨定效應**：阿里從$298跌至$105，很容易錨定歷史高點認為"太便宜了"。但$298對應2020年的壟斷格局，如今競爭格局根本性改變
- **敘事偏差**："阿里是中國亞馬遜"的敘事極具吸引力，但阿里缺少AWS那樣絕對領先的利潤引擎。阿里雲利潤率9%遠低於AWS的36%
- **價值陷阱風險**：PE低不等於便宜。如果利潤持續惡化（FY2026 Non-GAAP利潤-62%），低PE可能是合理定價而非低估

### 芒格式追問

**我最可能在哪裡犯錯？** 最可能高估阿里的"轉型能力"。歷史上，大型互聯網公司成功從核心業務轉型到全新業務的案例極少（亞馬遜是例外而非規則）。阿里同時要守電商、攻AI、建即時零售、拓國際化——四線作戰的公司很少全贏。

**聰明人為什麼不買？** 橋水清倉所有中概股反映了系統性地緣政治擔憂。DZ Bank給"持有"評級+$135目標價（幾乎無上行），理由是：(1)利潤惡化不是暫時的——即時零售和AI投入將持續數年；(2)中國消費疲軟是結構性問題；(3)競爭格局不可逆——拼多多和抖音不會消失。
