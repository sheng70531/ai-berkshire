# 五強爭霸與大廠圍獵

> 《看懂智譜AI》系列 · 第 03 篇 · 競爭格局

## 中國大模型賽道的殘酷現實

大模型是目前中國競爭最慘烈的賽道之一：頭上有四座大山壓著，旁邊有四個估值千億以上的創業公司虎視眈眈。智譜AI能在哪裡殺出來？

2026年5月，中國大模型賽道已經形成了兩個陣營：

**第一陣營：大廠軍團**
- 字節跳動（豆包）、阿里巴巴（通義千問/Qwen）、百度（文心一言）、騰訊（混元）
- 特點：有錢、有數據、有流量、有場景

**第二陣營：創業五強**
- DeepSeek、智譜AI、MiniMax、月之暗面（Moonshot/Kimi）、階躍星辰（StepFun）
- 特點：技術銳利、估值暴漲、但缺場景和流量

（來源：36氪、新浪財經、21經濟網）

## 創業五強：智譜排在什麼位置？

截至2026年5月，五家創業公司的最新估值和核心數據：

| 公司 | 估值/市值 | 核心產品 | 技術路線 | 商業化 |
|------|----------|---------|---------|--------|
| **DeepSeek** | **~515億美元** | DeepSeek-V4 | 極致性價比、開源 | API為主，價格極低 |
| **智譜AI** | **~4,500億港元（~580億美元）** | GLM-5.1 | 全棧、開源、國產芯片 | ToB+API，ARR 17億元 |
| **MiniMax** | **~3,042億港元** | MiniMax模型 | 成本效率優先 | 海內外API+產品 |
| **月之暗面** | **~1,000億+** | Kimi | 長文本、C端產品 | C端+API |
| **階躍星辰** | 未公開 | Step系列 | 多模態 | 早期階段 |

（來源：36氪、品玩、新浪財經、各公司公開信息）

### DeepSeek：智譜的頭號威脅

如果只能選一個最值得警惕的對手，答案是**DeepSeek**。

DeepSeek與智譜的直接對比：

| 維度 | 智譜 | DeepSeek |
|------|------|----------|
| 技術水平 | GLM-5.1，第一梯隊 | DeepSeek-V4，第一梯隊 |
| 開源策略 | MIT全開源 | MIT全開源 |
| API定價 | 中等 | **極低**（行業最低檔） |
| 商業化收入 | 7.24億元（2025年） | 預計2026年突破50億元 |
| C端產品 | 智譜清言（MAU ~838萬） | DeepSeek App（現象級增長） |
| 融資 | 上市融資52億港元 | 長期自有資金，2026年首次傳出融資 |
| 團隊背景 | 清華學術派 | 量化基金幻方，工程+算法 |
| 成本控制 | 一般 | **極致**（"用更少的錢訓更強的模型"） |

（來源：各公司公開信息、CNBC、證券時報）

DeepSeek對智譜構成的威脅是**全方位的**：

1. **技術上不落後**——DeepSeek-V4的綜合能力與GLM-5.1在同一量級
2. **成本上碾壓**——DeepSeek的API定價比智譜低得多，這直接威脅智譜的API收入
3. **品牌上更強**——DeepSeek在2025年初的"DeepSeek時刻"讓它獲得了全球關注度，品牌聲量遠超智譜
4. **財務上更健康**——DeepSeek背靠量化基金幻方，現金充裕，不急著上市融資

**反方觀點**：DeepSeek的優勢是"便宜"，但便宜不是永遠的護城河。智譜在國產芯片適配（華為昇騰）和政企客戶方面有DeepSeek沒有的優勢——很多政府和國企客戶不會選擇一家量化基金背景的AI公司，更傾向選擇"清華系+國資背景"的智譜。

### MiniMax：同賽道的港股競爭

MiniMax與智譜幾乎同期上市港股，市值也在3,000億港元量級。兩者的差異：

| 維度 | 智譜 | MiniMax |
|------|------|---------|
| 模型定位 | 全棧旗艦 | 成本效率優先 |
| 收入結構 | ToB為主（74%） | ToC和API並重 |
| 海外佈局 | 218個國家API覆蓋 | 海外產品（Talkie等）有真實用戶 |
| 團隊基因 | 清華學術 | 商湯出身，商業化更強 |

MiniMax的C端產品（Talkie等）在海外有真實的用戶基礎，這是智譜不具備的。但在ToB企業服務方面，智譜的客戶質量更高（互聯網前10中9家選用）。

### 月之暗面/Kimi：C端的贏家

Kimi在C端的表現遠好於智譜清言——它靠"長文本處理"這個差異化功能切入市場，獲得了大量學生和知識工作者。但Kimi在ToB方面遠不如智譜。

兩者的競爭重疊度其實不高——**智譜打ToB，Kimi打ToC**，短期內不是直接對手。

## 大廠圍獵：智譜面對的降維打擊

創業公司之間的競爭是"同量級拼技術"，大廠的競爭則是**降維打擊**。

### 字節跳動/豆包：流量碾壓

| 維度 | 智譜清言 | 豆包 |
|------|---------|------|
| MAU | ~838萬 | **2.27億** |
| 流量來源 | 獨立App | 抖音生態（日活7億+） |
| 場景 | 獨立對話 | 嵌入短視頻、搜索、電商、辦公 |
| 模型能力 | GLM-5.1（頂尖） | 字節自研（快速迭代） |

**差距是27倍**。這不是智譜"做得不好"——而是在C端，沒有流量入口的AI公司幾乎不可能贏。

### 阿里巴巴/通義千問：開源生態的正面對撞

通義千問（Qwen）是智譜在開源領域的最大競爭對手：

| 維度 | 智譜GLM | 通義千問Qwen |
|------|--------|-------------|
| 開源協議 | MIT | Apache 2.0 |
| 模型矩陣 | GLM系列 | Qwen系列（更豐富） |
| 全球Token份額 | 與Qwen競爭中 | **2.6%**（且快速增長） |
| 背後資源 | 清華+國資 | 阿里雲（全球第三大雲） |

通義千問的優勢在於：阿里雲的全球基礎設施可以直接為Qwen提供部署和分發渠道。智譜沒有自己的雲平臺，API需要依賴第三方。

### 百度/文心一言：ToB的老對手

百度在AI領域佈局最早，文心大模型在搜索、自動駕駛（Apollo）、雲服務等場景已深度集成。百度的ToB能力和政企關係是智譜的直接競爭。

但百度近年的市場份額在被侵蝕——"百度掉隊"的聲音越來越多。智譜在技術代際上（GLM-5.1 vs 文心4.5）可能已經反超百度。

## 全球Token消耗份額：智譜在哪裡？

一組來自OpenRouter的全球數據（2026年Q2）：

| 公司/模型 | 全球周Token消耗份額 |
|----------|-------------------|
| 月之暗面/Moonshot | **14.5%** |
| DeepSeek | **9.0%** |
| MiniMax | **4.2%** |
| 通義千問/Qwen | **2.6%** |
| 智譜/GLM | 未單獨披露，與上述競爭中 |

（來源：Digital Applied中國AI模型Q2 2026報告）

**注意**：OpenRouter主要反映全球開發者市場，不包含中國國內的企業私有部署。智譜74%的收入來自本地部署，這部分不會體現在OpenRouter數據中。

但這組數據仍然說明一個問題：**在全球API市場上，智譜的份額落後於DeepSeek和MiniMax**。

## 智譜的生態位到底是什麼？

把競爭格局拉通看，智譜的定位逐漸清晰：

| 維度 | 智譜的位置 |
|------|-----------|
| C端 | 已出局（大廠碾壓） |
| 全球API市場 | 第二梯隊（DeepSeek領先） |
| 中國政企ToB | **第一梯隊**（清華+國資背景加分） |
| 開源生態 | 第一梯隊（與Qwen、DeepSeek並列） |
| AI Agent | 先發但未確立優勢 |
| 國產芯片適配 | **獨特優勢**（華為昇騰深度適配） |

**智譜的生態位是"中國政企市場的首選AI基座模型提供商"**——靠的不只是技術，還有清華品牌、國資背景、國產芯片適配這些非技術因素。

這個生態位有多大？好消息是中國政企市場規模巨大，壞消息是競爭者同樣在湧入（百度、阿里、華為自身的盤古模型）。

**反方觀點**：如果智譜只能在"政企ToB"這個賽道上贏，那它的天花板就是一家傳統IT服務商，而不是"中國版Anthropic"。Anthropic之所以值600億美元，是因為它的API被全球開發者使用。智譜如果無法在全球開放API市場上佔據一席之地，4,500億港元的估值就很難站住腳。

## 競爭格局的三個判斷

**判斷一：創業五強格局不穩定，未來2年大概率會有掉隊者**

五家公司的估值都在千億以上，但大多數還在鉅額虧損。一旦融資環境收緊或技術路線出現重大分叉，排名靠後的公司可能被邊緣化或被收購。

**判斷二：大廠的終局優勢會越來越明顯**

AI模型的訓練成本會持續下降，但**分發渠道和場景優勢**是創業公司無法複製的。字節的抖音、阿里的淘寶+釘釘、騰訊的微信——這些流量入口決定了C端的終局。創業公司只能在ToB和API市場尋找空間。

**判斷三：智譜最大的護城河可能不是技術，而是"身份"**

清華系+國資背景+國產芯片適配——在中國特色的產業環境中，這種"身份"帶來的信任和政策紅利，可能比模型評測分數更有商業價值。

**反方觀點**：身份牌不是永久有效的。如果DeepSeek在純商業競爭中持續勝出，政企客戶最終也會用腳投票。技術和產品的競爭力才是長期壁壘。
