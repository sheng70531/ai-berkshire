## 三、結構差異：一個"以量補價"，一個"控量保價"

這是兩家最本質的分歧，方向完全相反。

### 茅臺：放量、降價、轉直銷

| 項目 | 2026H1 | 同比 |
|---|---|---|
| 茅臺酒收入 | 777.24億 | +2.82% |
| 系列酒收入 | 129.34億 | -6.02% |
| 直銷渠道 | **519.62億** | **+29.87%** |
| 批發代理 | 386.97億 | **-21.58%** |
| 直銷佔比 | 57.3% | 上年44.8% |
| i茅臺平臺 | **402.64億** | **+274.2%** |

茅臺在管理層討論中給出的解釋是"營業收入變動原因說明：主要是本期銷量增加"，"營業成本變動原因說明：主要是本期銷量增加及生產成本增加"。

對照數字：**營業成本+21.81%，營業收入只+1.47%** 。銷量增加帶來成本增加21.8%，收入卻紋絲不動——這意味著單價在跌。毛利率從91.30%降至89.56%，下滑1.74個百分點。

半年報原文："在價格機制上，推動終端價格更加符合市場真實運行規律，構建了'隨行就市、相對平穩、供需適配、量價平衡'的動態價格調整機制"。翻譯成報表語言：**主動降價放量，用直銷和i茅臺承接** 。i茅臺從107.60億做到402.64億，直銷佔比從44.8%衝到57.3%，批發渠道砍掉21.58%。

上半年基酒產量：茅臺酒4.1萬噸、系列酒3.1萬噸，正常投產。

### 一句話概括

茅臺選擇了降價保量、渠道向C端重構；老窖選擇了保價縮量、用費用補貼渠道。**茅臺在換血，老窖在止血** 。

## 四、盈利結構：老窖的稅負率反而比茅臺還高

| 佔營業收入比 | 茅臺2026H1 | 茅臺上年 | 老窖2026H1 | 老窖上年 |
|---|---|---|---|---|
| 毛利率 | 89.56% | 91.30% | 85.35% | 87.09% |
| 稅金及附加 | **16.19%** | 15.60% | **17.07%** | 13.26% |
| 銷售費用 | 3.53% | 3.65% | **12.70%** | 9.23% |
| 管理費用 | 4.01% | 4.13% | 3.74% | 2.60% |
| 歸母淨利率 | 49.08% | 50.79% | 41.44% | 46.57% |

三個反直覺的點：

**第一，老窖的稅金及附加率17.07%已經超過茅臺的16.19%。** 老窖噸價只有茅臺的零頭，稅負率卻更高。原因是白酒消費稅含從量部分，且老窖"讓利走促銷費不衝減收入"的做法保住了計稅基礎——單噸消費稅從3.52萬元漲到3.95萬元（+12.2%），而單噸酒類收入從33.52萬元跌到28.73萬元（-14.3%）。保價的代價直接體現在稅上。老窖Q2單季稅金及附加佔收入達25.84%。

**第二，茅臺的銷售費用率只有3.53%，老窖是12.70%。** 差距3.6倍，而且老窖這個比率還在惡化（+3.47個百分點）。茅臺不需要花錢推貨，老窖需要。

**第三，茅臺三項費用率全部同比下降**（銷售-0.12pct、管理-0.12pct），老窖全部上升（銷售+3.47pct、管理+1.14pct、研發+0.21pct）。費用絕對額老窖是降的（銷售-12.42%、管理-8.49%），但收入降得更快，所以費用率爆掉。典型的固定成本槓桿反噬。

老窖利潤下滑歸因（利潤總額104.10億→57.21億，減少46.89億）：

| 驅動項 | 影響（億元） |
|---|---|
| 營業收入下降 | **-59.82** |
| 營業成本下降對沖 | +5.89 |
| 稅金及附加下降對沖 | +3.94 |
| 銷售費用下降對沖 | +1.89 |
| 管理+研發費用下降對沖 | +0.45 |
| 財務費用淨收益減少 | -0.51 |
| 投資收益增加 | +0.75 |
| 公允價值變動+營業外淨改善 | +0.47 |
| 其他 | +0.05 |
| 合計 | **-46.89** |

收入減少59.82億，成本費用端只對衝回12.17億，**對沖率20.3%** 。剩下的79.7%直接砸到利潤上。

## 五、現金流：差距最刺眼的一欄

茅臺披露的經營現金流是706.91億（+438.84%），但這個數字不能直接用——它被控股子公司茅臺集團財務有限公司的銀行業務科目嚴重扭曲。剔除財務公司相關四項（客戶存款淨增73.83億、存放同業淨減218.95億、客戶貸款淨減11.70億、拆出資金淨減9.00億）後約為393.42億，上年同口徑約386.92億，實際增長約1.7%。

更乾淨的口徑是"銷售商品、提供勞務收到的現金"：

| 現金流指標 | 茅臺 | 老窖 |
|---|---|---|
| 銷售收現（億元） | 984.22（+3.51%） | 107.44（**-40.14%** ） |
| 收現比（銷售收現/營業收入） | **108.51%** （上年106.37%，上升） | **102.60%** （上年109.10%，下降） |
| 經營現金流（可比口徑，億元） | 約393.42（+1.7%） | 20.82（**-65.68%** ） |
| Q2單季經營現金流 | 正 | **-24.61億** |
| 資本開支（億元） | 8.32（**-47.86%** ） | 7.14（**-3.13%** ） |

兩個關鍵對比：

- **收現比方向相反。** 茅臺從106.37%升到108.51%，說明經銷商打款意願在增強；老窖從109.10%掉到102.60%，渠道停止超額預付。
- **資本開支方向也相反。** 茅臺在收入正增長的情況下把資本開支砍了47.86%（15.96億→8.32億）；老窖在收入砍掉36%的情況下資本開支只降3.13%（7.37億→7.14億），在建工程還增長18.2%到24.40億，另有8萬噸在建產能（對17萬噸設計產能擴產47%）。

老窖的支出剛性比茅臺強得多，而它的收入彈性比茅臺差得多——這是最危險的組合。

老窖經營現金流惡化的直接拆解（附註56補充資料）：核心拖累是"經營性應付項目減少22.35億"，可完全歸因為合同負債-9.30億、應交稅費-11.49億、待轉銷銷項稅-1.21億、應付賬款-1.33億、應付職工薪酬-0.88億。此外老窖上半年支付各項稅費53.39億，佔營業收入的51.0%（上年45.0%），其中含補繳上年末應交稅費11.49億。

老窖自由現金流（經營現金流−購建固定資產）13.68億，上年同期53.28億，同比-74.3%。

## 六、渠道與庫存：都在收縮，但含義不同

| 項目 | 茅臺 | 老窖 |
|---|---|---|
| 期末境內經銷商 | 2,307家（增220、減266，淨減46家） | 1,533家（增101、減263，淨減162家，同比-9.98%） |
| 上年同期淨變動 | 淨增137家 | 淨增2家 |
| 合同負債 | **31.78億（同比-42.30%）** | **24.37億（同比-30.94%）** |
| 合同負債/半年營收 | 3.50%（上年6.16%） | 23.27%（上年21.45%） |
| 存貨 | 613.17億（-0.18%），佔總資產19.84% | 156.81億（+1.85%），佔總資產24.38% |
| 存貨跌價準備 | 0 | 0 |
| 上半年基酒產量 | 茅臺酒4.1萬噸、系列酒3.1萬噸（正常投產） | 中高檔酒產量-77.40%（主動砍產） |

**合同負債降幅茅臺（-42.30%）比老窖（-30.94%）還大，但含義完全不同。** 茅臺在報表變動說明裡寫的原因是"公司進行市場化改革，銷售模式改變，預收貨款政策相應調整"——直銷和i茅臺不走經銷商先款後貨，預收款自然沉不下來，這是渠道結構切換的副產品；而且合同負債只相當於茅臺半年收入的3.50%，本來就不是它的核心蓄水池。

老窖是純粹的"先款後貨"且模式未變，合同負債相當於半年收入的23.27%，這個科目下降30.94%是乾淨的需求信號，直接對應下半年的收入基礎。老窖期末合同負債前五名單位合計10.33億，佔42.37%，集中度高。

存貨方面，茅臺總量幾乎持平且基酒正常投產。老窖庫存商品（成品）去化19.3%到26.48億，但在產品（基酒）逆勢增加10.28億到129.51億，佔存貨82.6%；期末半成品酒（含基礎酒）庫存46.78萬噸，按當前年化銷量7.25萬噸計相當於**6.5年** 。

**兩家的存貨跌價準備都還是零** ，這是共同的觀察點——一旦有人先計提，就是對價格體系的正式認輸。

| 淨現金 | 無有息負債，純淨現金 | 224.22億（類現金292.03億−受限4.41億−有息負債63.40億） |

| 有息負債 | 無 | 63.40億（短期30.00億+長期信用借款33.40億，年化成本約1.91%） |

兩家的應收和存貨減值都沒有問題，回款質量都是行業頂級。差別在權益端：茅臺歸母淨資產半年增長2.70%，老窖下降8.13%——老窖上半年淨利43.39億，宣告分紅65.01億（每10股44.171215元，股權登記日2026-08-27，除權除息日2026-08-28），未分配利潤被抽走41.33億，是一次分紅驅動的縮表。

老窖《2024-2026年度股東分紅回報規劃》承諾2026年度分紅"不低於歸母淨利75%且不低於85億元"。上半年歸母只有43.39億，85億下限相當於半年利潤的195.9%。若下半年延續Q2水平，全年歸母可能落在50-65億區間，**分紅將超過當年全部淨利潤** 。2025年度已按此規劃兌現：中期19.99億（2026-01-30實施）+ 年度65.02億 = 85.00億，佔2025年歸母淨利108.31億的78.48%，恰好壓線達成。

茅臺沒有這類金額型硬承諾壓頂。

## 八、結論

**茅臺是"主動換血"。** 收入還在正增長（+1.47%），代價是營業成本+21.81%、毛利率-1.74pct，靠放量和直銷轉型（直銷佔比44.8%→57.3%，i茅臺+274%）頂住了報表。它的問題是價格在讓、結構在換、Q2已經轉負（-5.14%），但基本盤、現金流（收現比108.51%還在升）、資產負債表都沒有裂縫，而且資本開支砍了47.86%，姿態是收著打。

**老窖是"被動止血"。** 收入-36.35%、Q2單季-65.54%，選擇保住出廠價體系（噸價+6.4%、中高檔毛利率只降0.29pct），代價是銷量-42.53%、境內經銷商淨減162家、合同負債-30.94%、Q2經營現金流-24.61億。更麻煩的是它的支出沒跟著收縮——銷售費用率12.70%、資本開支只降3.13%、在建產能擴產47%、分紅下限85億超過全年可能的淨利。

同一個行業下行週期，茅臺在Q2才剛剛感受到，老窖已經在承受第二輪塌方。兩家的資產負債表都是乾淨的，區別在於損益表的彈性和支出的剛性——茅臺跌5%時可以從容降本，老窖跌66%時費用率只能眼睜睜往上爬。

**茅臺的問題是"值多少錢"，老窖的問題是"什麼時候見底"。**

## 九、下一份財報的檢驗點

### 瀘州老窖（2026年三季報，預計2026年10月底）

1. **合同負債能否在24.37億止跌回升。** 觸發條件：三季度末回升至28億以上（含稅31.6億以上），說明中秋國慶旺季渠道恢復打款；若繼續跌破20億，第四季度收入基礎再降一檔。
2. **單季歸母淨利能否守住10億。** 2025Q3為31.00億，2025Q4為0.68億。若2026Q3落在10億以上屬延續Q2水平；若跌破5億，全年歸母將逼近50億，85億分紅下限對應分紅率超過170%。
3. **稅金及附加佔收入比能否從17.07%回落至15%以內。** 若公司開始通過折扣直接衝減收入（而非計入促銷費），消費稅負擔率會下降但毛利率會掉——這兩個數字必須一起看，任何一個單獨變動都是口徑問題而非經營改善。
4. **庫存商品與在產品的方向是否分化。** 庫存商品若繼續降至22億以下，去庫存進入尾聲；同時盯存貨跌價準備是否首次計提。
5. **2026年中期分紅是否宣告。** 半年報已明確不派中期紅利，參考2025年中期分紅是在2026年1月實施的先例。

### 貴州茅臺（2026年三季報）
