## 四、核心結論：Temu現在是Amazon的幾分之幾？

### 按不同維度衡量：

| 維度 | Temu/PDD 是 Amazon 的 |
|------|----------------------|
| 總營收 | **約1/12** |
| 市值 | **約1/21** |
| 淨利潤 | **約1/4** |
| 電商GMV | **約1/12** |
| 用戶規模 | **約1/10** |
| PE估值 | PDD便宜3倍（10x vs 32x） |

### 總結

1. **體量差距巨大**：按收入和GMV計，Temu/PDD大約只有Amazon的1/12，市值更是隻有1/21。差距極為懸殊。

2. **估值差距同樣巨大但方向相反**：PDD的PE僅10倍，Amazon 32倍。市場給予Amazon更高估值主要因為AWS和廣告兩個高利潤增長引擎，而市場對Temu的可持續性和關稅風險持謹慎態度。

3. **利潤差距相對較小**：PDD集團淨利潤約144億美元，是Amazon的1/4。這主要因為拼多多國內主站極度賺錢（利潤率超過40%），但Temu海外仍在虧損。

4. **Temu的獨特優勢**：覆蓋80+市場、極低價格帶（大量商品低於5美元）、供應鏈直連中國工廠。但面臨美國關稅政策（de minimis取消）的重大不確定性。

5. **Amazon Haul的反擊**：Amazon已用12個月時間將Haul擴展到25個市場、選品增長400%、訪問量翻3倍，正面對標Temu的低價市場。

6. **關鍵差異**：Amazon是一個多引擎企業（雲+廣告+電商+訂閱），AWS和廣告貢獻了絕大部分利潤。PDD本質上是一家電商公司，且正從"利潤收割期"主動轉向"重投期"。
