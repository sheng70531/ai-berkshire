# 騰訊 / 美團 / 拼多多 5 年股價相關性分析

> **報告日期**：2026-05-01
> **數據區間**：2021-05-03 ~ 2026-04-30（共 261 周）
> **數據來源**：Yahoo Finance 周線收盤價（0700.HK / 3690.HK / PDD）
> **方法**：ISO 周對齊、Pearson 相關性（價格水平 + 周對數收益率）、滾動分階段相關性、高低點時間差

## 一、核心結論（速讀）

| 問題 | 答案 |
|---|---|
| **高低點是否同時段？** | **❌ 完全不同步** |
| 三家高點最大時間差 | **1,561 天**（騰訊 2025-09 vs 美團 2021-06，相差 4.3 年） |
| 三家低點最大時間差 | **693 天**（美團 2024-01 vs PDD 2022-03，相差 1.9 年） |
| 周收益率相關性 | 中等偏強（**0.48 ~ 0.68**） |
| 價格水平相關性 | **幾乎不相關**（-0.30 ~ +0.36） |
| 5 年累計漲跌 | 騰訊 **-15%** / 美團 **-71%** / PDD **-26%** |
| 2025 年後相關性變化 | **大幅下降**（最低降至 +0.17）→ 市場開始按基本面分別定價 |

**一句話總結**：**三家公司被同一個"中概股情緒"短期聯動（周相關性 0.5-0.7），但長週期各自有獨立的命運曲線，高低點完全錯開**。

## 四、相關性分析

### 4.1 價格水平相關性（長期共動度）

| 配對 | Pearson r | 解讀 |
|---|---|---|
| 騰訊 vs 美團 | **+0.09** | **幾乎不相關** |
| 騰訊 vs PDD | +0.36 | 弱相關 |
| 美團 vs PDD | **-0.30** | **負相關**（反向走） |

**含義**：長期來看，三家公司的"價格水平"幾乎獨立。這是因為 5 年裡各自有完全不同的成長曲線——騰訊先跌後修復，美團一路下行，PDD 倒 V 形。

> **不要被"價格相關性"誤導**：這個數字主要由長期趨勢主導，不能反映短期聯動。看下面的"收益率相關性"才更準確。

### 4.2 周收益率相關性（短期共動度，更核心）

| 配對 | Pearson r | 解讀 |
|---|---|---|
| **騰訊 vs 美團** | **+0.68** | **強相關**——同為港股大盤股，被同一資金池操作 |
| 騰訊 vs PDD | +0.53 | 中等相關 |
| 美團 vs PDD | +0.48 | 中等相關 |

**含義**：周線層面，三家股票確實有顯著共動——這是"中概股β"的體現。當宏觀風險（美聯儲、中美關係、監管）來時，它們一起跌；當情緒好轉時，它們一起漲。但騰訊和美團（**同為港股**）的相關性明顯高於跨市場配對。

### 4.3 分階段周收益率相關性（看相關性如何變化）

| 階段 | 時間 | 騰訊-美團 | 騰訊-PDD | 美團-PDD | 解讀 |
|---|---|---|---|---|---|
| **階段 1** | 2021-05 ~ 2022-05 | **+0.81** | +0.65 | +0.68 | **共同被監管砸**——相關性最高 |
| 階段 2 | 2022-05 ~ 2023-05 | +0.70 | +0.52 | +0.57 | 中概股整體修復 |
| 階段 3 | 2023-05 ~ 2024-05 | +0.66 | +0.43 | +0.22 | PDD 因 Temu 走出獨立行情 |
| 階段 4 | 2024-05 ~ 2025-05 | +0.71 | +0.55 | +0.37 | 港股 vs 美股分化 |
| **階段 5** | 2025-05 ~ 2026-04 | **+0.32** | +0.37 | **+0.17** | **相關性大幅下降，獨立定價** |

**關鍵趨勢**：**5 年來相關性在持續下降**——尤其美團-PDD 從 +0.68 降到 +0.17，幾乎獨立。
- 早期：被同一個"監管恐慌"驅動 → 高相關
- 後期：各自的基本面開始主導 → 低相關
- 這是**基本面投資人最希望看到的轉變**

## 五、為什麼高低點完全不同步？

### 5.1 美團 2021 年高點 → 一路下跌的邏輯

```
2021-06: 平臺經濟反壟斷風暴啟動 → 直接砸最猛
2022:    社區團購燒錢 + 餐飲 lockdown 雙殺
2023:    抖音生活服務全面進攻外賣
2024-01: 海外 Keeta 投入未見回報 → 創最低
2024-2026: 緩慢修復，但沒有新成長故事
```
美團的核心矛盾：**主營外賣/到店增長見頂 + 抖音搶飯碗 + 海外故事未跑通**。這是基本面惡化疊加競爭升級，**沒有任何"雙擊"催化劑**。

### 5.2 PDD 2024-05 高點 → 之後下跌的邏輯

```
2022-03: 中概股最低點（俄烏+SEC退市）→ 32 美元
2022-2024: Temu 全球爆發 + 國內繼續增長 → 一路漲到 158
2024-05: Q1 財報超預期 → 頂點
2024-08: Q2 財報管理層警告利潤率下滑 → 單日 -28%
2025-2026: 川普關稅 + 800 美元免稅額取消 → Temu 模式受衝擊
```
PDD 的核心矛盾：**Temu 太成功 → 招致美國關稅打擊 → 商業模式被監管化**。

### 5.3 騰訊 2025-09 高點 → 之後下跌的邏輯

```
2022-10: 中概股最低 + 港股流動性枯竭 → 191 港元
2023-2024: 大額回購 + 視頻號變現 + 遊戲復甦 → 緩慢修復
2025-09: AI 敘事高點 + DeepSeek 熱度溢出 → 673 港元
2025-Q4: AI 投入翻倍 + 回購縮減擔憂 → 跌
2026-Q1: 加稅謠言 + Agentic AI 不及預期 → 繼續陰跌
```
騰訊的核心矛盾：**AI 投入太大 + 回購縮減 → 短期市場擔心資本配置**，但基本面（微信、遊戲、廣告）沒有變差。

### 5.4 三家"基本面驅動因素"完全不同

| 公司 | 主要驅動因素 | 當前位置 |
|---|---|---|
| 騰訊 | 微信生態、遊戲、AI | AI 投入消化期 |
| 美團 | 外賣競爭、海外、利潤率 | 主營業務防守階段 |
| PDD | Temu 全球擴張、關稅 | 關稅不確定性 |

**這就是為什麼高低點不同步**：當美團被監管砸時（2021），騰訊還沒那麼差；當 PDD 被 SEC 砸時（2022），美團還在百元以上；當騰訊靠 AI 漲時（2025），美團已經在底部躺平。

## 六、對投資決策的啟示

### 6.1 三家不是"替代品"，是"補充品"

如果你買三家做組合：
- **不會獲得分散化收益**（因為周收益率相關 0.5-0.7）
- **但會獲得不同基本面的覆蓋**（高低點完全不同步說明各自有獨立故事）
- **本質是"中概股β + 三個獨立α"的組合**

### 6.2 "三選一"該怎麼選？

| 維度 | 騰訊 | 美團 | PDD |
|---|---|---|---|
| 5年累計跌幅 | -15% | -71% | -26% |
| 當前距高點 | -30% | -75% | -37% |
| 護城河 | 最深 | 中等（受抖音威脅） | 淺但增長快 |
| 基本面方向 | 穩 + AI 期權 | 防守、尋找新故事 | 關稅不確定性 |
| 估值（參考） | 主營 PE ~12 | PE ~15 | PE ~10 |
| **價值投資視角** | **首選** | 困境反轉 | 高賠率高風險 |

### 6.3 關鍵啟示：等"全部一起跌"的時候

**最好的買點是三家相關性 = 0.9 的時候**——那意味著市場不分基本面恐慌拋售（如 2022-10）。當前階段 5（相關性降到 0.17-0.37），說明市場已經在分化定價，**不是恐慌時刻，需要選基本面優秀的那家**。

## 七、統計學補充

### 7.1 數據完整度

- 共同觀測週數：**261 周**
- 涵蓋 5 個完整年份
- 數據來源：Yahoo Finance 公開周線 API
- 對齊方式：ISO 周（解決港股/美股 timestamp 偏移）

### 7.2 侷限性說明

1. **價格水平相關性會被長期趨勢主導**，所以低數值不代表"短期不聯動"
2. **Pearson 假設線性關係**，對極端事件（黑天鵝）的捕捉可能不足
3. **未做匯率調整**：騰訊/美團是港元，PDD 是美元——但因為算的是收益率，匯率影響有限
4. **5 年區間正好涵蓋完整的"監管→修復→分化"週期**，結論對其他週期未必適用

### 7.3 進一步可做的分析

- 滾動 12 周相關性（看動態變化）
- 與恒生科技指數 / 中概股 ETF 的迴歸（提取 β 和 α）

## 八、結論

> **三家公司被同一個"中概股情緒"短期聯動（周收益率相關 0.48-0.68），但長週期完全獨立——5 年高點跨越 4.3 年，5 年低點跨越 1.9 年，5 年累計漲跌差距高達 55 個百分點。**
>
> **這意味著：**
> - **不能把三家當"同一個東西"看**——它們有完全不同的基本面驅動因素
> - **想分散中概股β風險，三家組合用處不大**（β 一致）
> - **但想覆蓋中國互聯網的不同細分賽道，三家組合是合理的**（α 獨立）
> - **當前階段（2025-2026）相關性顯著下降**，是基本面投資者的好窗口——市場不再"無腦聯動"
