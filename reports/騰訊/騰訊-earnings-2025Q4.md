## 二、本期最重要的3個變化

### 變化一：毛利率從53%跳升至56%——結構性拐點

這不是一個季度的波動，而是全年系統性提升3.3個百分點。驅動因素：
1. **高毛利的遊戲收入佔比提升**：增值服務（主要是遊戲）增速16%，快於整體14%
2. **廣告業務效率提升**：AI驅動的精準投放降低了獲客成本
3. **金融科技降本**：騰訊雲從大幅虧損轉為規模化盈利，該板塊毛利率從47%升至51%（Q3數據）
4. **混合效應**：低毛利的金融科技增速最慢(8%)，高毛利業務增速快

> 芒格視角：毛利率56%意味著每賺100元收入就有56元是毛利，這是極強的定價權和競爭壁壘的體現。

### 變化二：AI從"燒錢敘事"轉向"可見變現"

2025年AI投入的財務軌跡：
- **資本開支792億**（僅+3%），遠低於市場預期的千億級別
- 劉熾平解釋：**不是不想花，是先進GPU在中國供應受阻**
- 混元大模型+元寶專項投入180億元，Q4單季70億（加速中）
- 2026年AI新產品投入"至少翻倍"（即≥360億）

AI變現已有4條明確路徑：
1. AI優化廣告定向 → 廣告收入+19%
2. AI推薦引擎 → 用戶時長↑ → 廣告庫存↑
3. AI增強老遊戲體驗 → 遊戲ARPU↑
4. GPU雲服務 → 騰訊雲收入加速+規模化盈利

### 變化三：海外遊戲爆發式增長——第二增長曲線兌現

- Q4海外遊戲收入211億，同比**+32%**
- 全年海外遊戲收入估計774億，同比增速+33%
- 這是騰訊最具戰略意義的突破：海外收入擺脫了中國監管和宏觀經濟的單一風險

## 四、附註隱藏信息

### 4.1 股權激勵稀釋

2025年回購註銷1.534億股，總股本從約92.35億降至90.81億，**淨減少1.7%**。這意味著騰訊的回購不僅覆蓋了股權激勵稀釋，還在持續縮減股本，對每股收益有實質性增厚效果。

| 類別 | 價值 |
|------|------|
| 上市公司投資(公允值) | ~8,008億人民幣 |

| **投資組合總估值** | **~1.16萬億人民幣** |

按90.81億股計算，僅投資組合每股價值約128元人民幣（~140港元），佔當前股價508港元的**27%**。這是巨大的隱含安全邊際。

### 4.3 AI投入的會計處理

2025年混元+元寶專項投入180億元走費用化處理（體現在研發費用中），而792億資本開支走資本化處理。兩者合計AI相關投入接近1,000億，但對利潤的影響路徑不同：
- 180億費用化：立即衝擊當期利潤
- 792億資本化：通過折舊攤銷在未來數年影響利潤

## 七、關鍵問題

1. **AI投入的ROI何時可量化？** 2025年AI對各業務線的具體增量貢獻尚未明確拆分，2026年翻倍投入後需要看到更清晰的歸因分析。

2. **元寶能否追上豆包？** 馬化騰承認落後9-12個月，姚順雨加盟是積極信號，但To C大模型應用的窗口期正在收窄。微信生態的獨特壁壘是唯一殺手鐧。

3. **GPU供應瓶頸何時緩解？** 2025年資本開支低於預期的核心原因。如果2026年供應改善，資本開支可能大幅跳升，短期衝擊利潤率。

4. **金融科技增速放緩是否見底？** 8%的增速在三大板塊中最低，微信支付流水增長面臨監管和競爭雙重壓力。但云業務規模化盈利是板塊內的積極變化。

5. **回購縮減的信號意義？** 2024年回購1,120億港元 → 2025年800億港元，雖然仍然可觀，但縮減28%。是否意味著管理層認為當前估值吸引力下降？還是為AI投入保留更多現金？
