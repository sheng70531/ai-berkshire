## 摘要

**一句話結論：核心業務全面超預期（收入+11%、廣告+22%、毛利率58%創歷史新高、遞延收入+21%），但公司主動把單季自由現金流打成-138億元換取AI基礎設施——騰訊正式從"現金奶牛+回購機器"切換為"重投入換AI期權"模式。管理層給出"今明兩年一次性投入、回報不及預期即封頂"的框架承諾，市場首日用ADR跌5.4%表達了不信任。**

| 判定項 | 結論 |
|--------|------|
| 財報 vs 預期 | 經營面超預期，現金流低於預期（"質量超預期的換擋季"） |
| 利潤質量 | 高：無開發開支資本化、SBC佔收入比降至3.2%、遞延收入領先增長；IFRS淨利+0.7%為會計噪音 |
| 長期持有邏輯 | 輕微削弱未破裂：股東回報率從2025年的50-60%降檔至年化約35%且回購明示讓位；AI回報可見性上升；護城河與經營質量指標全部健康（詳見第九節） |
| 持倉行動 | 持有；Q3財報為下一個關鍵驗證點；458港元（悲觀情景支撐，測算見第八節）以下值得評估加倉 |

## 三、AI專題：投入與回報的完整賬本

### 3.1 投入側：錢花在哪、花多少

| 項目 | 數據 |
|------|------|
| 資本開支 | Q2 527.8億（+176%）；上半年847.2億（+82%，超2025全年）；Q3繼續"大幅增加算力採購"（馬化騰） |
| 算力預付款 | 單季約514億（FCF兩口徑之差）；非流動預付款餘額912億（年初245億） |
| 研發開支 | Q2 272.8億（+35%）；上半年498.2億；一般及行政費用+22%至388億 |
| **新AI產品經營拖累** | **Q1 88億 → Q2 105億**（=剔除口徑861億-實際756億；範圍：混元、元寶、CodeBuddy、WorkBuddy、小微） |
| 全年資本開支指引 | **拒絕給出具體數字**；績前賣方預估：大和1,810億（自1,080億上調）、美銀1,850億（2027/2028年2,250/2,500億）、摩根大通2,000億 |

管理層的三條框架承諾（劉熾平，電話會實錄原文）：

> "投向AI原生業務的資本開支，主要是今年和明年一次性集中投入，大家不要默認我們每年都會維持同等大額投入。模型訓練屬於固定成本……只有該業務能實現可觀回報，我們才會持續追加投入；如果回報不及預期，現有投入規模就會封頂。"

即：**時限**（2026-2027集中投入）、**封頂**（AI新產品投入"控制在集團利潤固定比例區間內"，未給比例）、**掛鉤**（新增開支對應收益水平）。105億投入的內部結構在動態騰挪——Mitchell披露：發現WorkBuddy爆發後"把資金大幅向它傾斜，同時縮減AI產品線裡其他產品的投放預算"。

**正反兩面**：框架比數字信息量更大（數字每季可改，框架是把話說死）；但三條全是無法當期驗證的遠期承諾，"固定比例""可觀回報"均無量化標準，驗證權在管理層手中。行業內尚無巨頭兌現過"AI投入是一次性的"先例。

### 3.2 回報側：已兌現、兌現中、純期權三層

**第一層——已兌現（老業務賦能）**：廣告+22%連續三季加速（AI推薦系統參數擴容、素材效率+80%）；毛利率57.8%創新高——AI基建折舊翻倍（技術基礎設施運營成本+102%）被高毛利收入增長完全消化；遊戲側《和平精英》AI NPC累計體驗用戶1.67億、最高日活1,770萬，《洛克王國：世界》AI教練上線後PVP激活率+20%。

**第二層——兌現中（雲與token變現）**：雲收入增速從Q1"高十位數"加速至Q2"20%出頭"（GPU租賃、模型即服務、WorkBuddy/CodeBuddy token用量三路驅動）；排期明確——"年底至明年將有足夠GPU/ASIC產能，加大裸金屬GPU對外出租"（Mitchell）。上季"有意推遲雲AI變現"的口徑正式轉向。token經濟學（Mitchell）："國內令牌定價確實偏低，但底層生產成本也極低……即便終端售價低廉，令牌業務依舊能實現正向毛利"；WorkBuddy付費部分與模型即服務的毛利率"已經和騰訊雲整體毛利率持平"。

**第三層——純期權（AI原生產品）**：
- **混元**：Hy3正式版7月發佈，上線一週調用量較上代+68倍，日均token用量為預覽版的約6倍（英文實錄口徑；部分中文報道為7倍），按OpenRouter token消耗持續位列全球前三；WorkBuddy內用戶模型選擇佔比60%；**Hy4年內發佈**，定位"參數量全面提升、性能超越更大規格競品"。
- **WorkBuddy**：PC端6月訪問量2,097萬次居國內同類第一，落地50+行業，接入Hy3後任務解決率72%→90%，企業版已發佈，"訂閱和充值購買詞元的付費意願強烈"。
- **CodeBuddy**：AI編程工具月訪問量前10中騰訊佔4席。
- **小微（微信AI）**：6月啟動灰度，覆蓋16個高頻場景；年度投入預算"低於往年元寶的常態化投入"。劉熾平的終局敘事："未來用戶只需給專屬智能體下達一條複雜指令，智能體就能自動完成全部交易流程……商戶智能體可以直接和用戶智能體對接"；"電腦時代QQ只是社交通訊工具，微信生態把QQ價值放大了十倍以上……AI時代，微信生態迎來第二次巨大增長機遇"。
- **元寶**：連續第二個季度未披露用戶數據（2026Q1為MAU 5,700萬，對比豆包3.4億），戰略定位已降為向WorkBuddy/微信等輸出的"原子能力"。

**反面必須記錄（觀點）**：① 第三層目前無任何收入/用戶量硬數據支撐，"十倍放大"是願景類比不是指引；② 被問"AI智能體會否擠壓廣告與交易"時劉熾平答"這些風險都不會出現"——全場唯一把不確定性說成確定性的回答；③ 微信AI當前是純敘事資產，需等小微出灰度後的用戶數據。

### 3.3 下行保護：管理層的"保底方案"論證

劉熾平在11個問答中三次主動重複同一論證：

> "哪怕停止自研應用，單純把算力對外租賃，相關業務本身就能盈利，因此我們敢於長期投入。"
> "幾個月前預付定金下單的一批算力設備，現在轉手出售，相比採購價能賺超30%。"

Mitchell同口徑："若把算力全部租給第三方，幾乎立刻就能收回設備折舊成本"，但騰訊選擇自用優先換取"更長期更優的經濟回報"。

**正反兩面（觀點）**：算力殘值論證當下成立——GPU供不應求下設備轉手溢價30%，"最壞情況變出租生意"的下行保護是真實的。但一個管理層反覆強調"我們有保底"，恰說明他們清楚這筆投入的不確定性；且30%溢價是當前供需快照，保底邏輯的有效期與GPU短缺週期同長，不應作為長期安全邊際。另注意口徑陷阱：新浪實錄標題《不準備出租算力》與正文矛盾，管理層真實排序是"先自研模型與應用、剩餘算力再對外出租"——出租是第二優先級與保底，不是不做。

## 十、結論

1. **超預期還是低於預期？** 經營面超預期（收入+1%、廣告大超、毛利率新高、遞延+21%），現金流低於預期（資本開支超預期64%、FCF轉負）。定性："質量超預期的換擋季"。
2. **這份財報+電話會改變了什麼？** 三件事：① AI投入從"看不到底的開支"變為"有時限、有上限、有保底的投資"（管理層框架自洽但當期不可驗證）；② 回購正式讓位於資本開支——"回購機器"敘事終結；③ 雲AI變現路徑首次清晰（增速加速+年底出租排期+token正毛利證據）。
3. **持倉行動：持有。** 不加倉：資本開支高峰未過（912億預付款在路上、Q3繼續大采購）、FCF拐點未現、賣方下修週期未走完。不減倉：七個持有前提僅一條失效且屬資本配置選擇而非經營惡化、八項惡化信號零觸發、核心生意（剔AI利潤+19%）在變好、現價已貼悲觀情景支撐。
4. **Q3財報為下一個關鍵驗證點，盯三個硬指標**：① AI新產品拖累是否穩在105億量級（封頂承諾第一次檢驗）；② 雲收入增速是否續升（變現承諾檢驗）；③ 下半年回購節奏（讓位聲明落地程度）。輔助觀察：國際遊戲止跌與否、小微灰度數據、混元4發佈及評測、績後賣方目標價修正幅度。
