# Temu vs Shein 五年預測（2026-2031）

> 分析日期：2026年5月15日
> 數據來源：公開財報、券商研報、行業研究機構

## 一、行業背景

### 1.1 全球跨境電商市場規模

| 指標 | 2024年 | 2025年（估） | 2031年預測 |
|------|--------|-------------|-----------|
| 全球跨境電商市場規模 | ~7,980億美元 | ~9,500億美元 | 1.74萬億美元（Verified Market Research，複合增長率13.84%） |
| 跨境B2C電商 | ~1.2萬億美元 | ~1.5萬億美元 | 5.58萬億美元（Grand View Research，複合增長率25.8%，口徑偏寬） |
| 中國跨境電商進出口 | 2.63萬億元 | ~3.0萬億元 | ~7-8萬億元（按18.7%複合增長率推算） |

**注：** 不同機構的口徑差異極大。本報告取Verified Market Research的保守口徑（1.74萬億美元）作為基準。

### 1.2 中國出海電商份額

- 2025年中國跨境電商中，Temu+Shein+TikTok Shop+速賣通四大平臺合計GMV約2,500-3,000億美元，佔全球跨境電商約25%-30%
- 預計到2031年，中國出海電商份額可達全球跨境電商的30%-35%，對應5,000-6,000億美元市場空間

### 1.3 關稅/監管環境假設

| 情景 | 假設 |
|------|------|
| **樂觀** | 中美貿易協議實質性緩和，對華關稅降至20%以下；de minimis部分恢復或提高門檻；歐盟不追加大規模關稅 |
| **中性** | 當前狀態延續——美國對華綜合關稅31%-48%區間維持；de minimis取消不變；歐盟推行但力度溫和的電商新規 |
| **悲觀** | 關稅進一步升級至60%+；歐盟跟進美國取消de minimis+徵收碳邊境稅；東南亞/拉美市場也出臺保護性措施 |

**當前現實基準（2026年5月）：**
- 美國對華平均有效關稅：31.6%-47.5%（多層疊加）
- de minimis豁免已於2025年8月正式取消
- 中美兩國領導人正在談判中，市場預期"穩定但非回暖"
- 歐盟正在審議跨境電商新規，尚未落地

## 三、Temu 2031年三情景預測

### 3.1 樂觀情景

**核心假設：**
- 關稅有所緩和（美國降至20%區間），de minimis部分恢復
- 半托管模式全球跑通，覆蓋50+國家
- 廣告貨幣化成熟，廣告收入佔GMV的3%+
- 歐洲保持領先，新興市場（拉美、東南亞、中東）高速增長
- 年複合增長率：2026-2031年GMV增長20%

| 指標 | 2025年基準 | 2031年預測 |
|------|-----------|-----------|
| GMV | ~950億美元 | 2,800億美元 |
| 平臺營收（佣金+廣告+服務費） | ~160億美元 | 560億美元 |
| 營收/GMV比率（take rate） | ~17% | ~20%（廣告拉高） |
| 營業利潤 | ~0（接近盈虧平衡） | 56-70億美元（營業利潤率10-12.5%） |
| 淨利潤 | ~負數至微利 | 45-55億美元 |

**邏輯鏈：**
- GMV 950億 -> 按20%複合增長 -> 2031年約2,800億
- take rate從17%提升至20%（廣告3%+佣金15%+其他2%）
- 營業利潤率參照拼多多國內（~25%），但海外運營成本高，按10-12.5%算

### 3.2 中性情景（基準）

**核心假設：**
- 關稅維持現狀（美國30-50%區間），無實質性貿易突破
- 半托管模式在歐洲、拉美成功，但美國受限
- 廣告貨幣化達到2%
- 年複合增長率：2026-2031年GMV增長12-15%

| 指標 | 2025年基準 | 2031年預測 |
|------|-----------|-----------|
| GMV | ~950億美元 | 1,800-2,000億美元 |
| 平臺營收 | ~160億美元 | 310-360億美元 |
| 營收/GMV比率（take rate） | ~17% | ~18% |
| 營業利潤 | ~0 | 25-36億美元（營業利潤率8-10%） |
| 淨利潤 | ~負數至微利 | 20-28億美元 |

**邏輯鏈：**
- GMV按14%複合增長 -> 2031年約1,900億
- take rate緩慢提升至18%
- 營業利潤率8-10%，反映持續的物流補貼和新市場拓展投入

### 3.3 悲觀情景

**核心假設：**
- 關稅進一步收緊至60%+，美國市場大幅萎縮至GMV佔比<15%
- 歐盟推出嚴格跨境電商法規，增長受阻
- 僅在新興市場（拉美、東南亞、中東、非洲）維持增長
- 半托管模式推進緩慢，廣告變現<1%
- 年複合增長率：5-8%

| 指標 | 2025年基準 | 2031年預測 |
|------|-----------|-----------|
| GMV | ~950億美元 | 1,200-1,350億美元 |
| 平臺營收 | ~160億美元 | 190-220億美元 |
| 營收/GMV比率（take rate） | ~17% | ~16%（競爭壓力下take rate下降） |
| 營業利潤 | ~0 | 5-10億美元（營業利潤率2.5-5%） |
| 淨利潤 | ~負數至微利 | 3-8億美元 |

**邏輯鏈：**
- 美國市場從31%縮至15%，歐洲增速放緩至個位數
- 新興市場雖增長快但單位經濟模型差（物流貴、客單價低）
- 被迫持續補貼維持市場份額，利潤率極薄

| 指標 | 2024年 | 2025年（估） |
|------|--------|-------------|
| 營收 | ~380億美元 | ~560-600億美元（ecommerceDB口徑835億包含GMV） |

## 五、Shein 2031年三情景預測

### 5.1 樂觀情景

**核心假設：**
- 香港IPO成功（2026-2027年），估值500億+美元，獲得充足資金
- 品牌升級成功，從"超低價快時尚"轉向"性價比時尚科技平臺"
- Marketplace做大，3P佔比提升至40-50%，平臺佣金+廣告收入豐厚
- 關稅環境有所緩和
- 年複合增長率：營收15-18%

| 指標 | 2025年基準 | 2031年預測 |
|------|-----------|-----------|
| GMV | ~680億美元 | 1,500-1,700億美元 |
| 營收（1P+3P佣金+廣告） | ~480億美元 | 1,000-1,100億美元 |
| 營業利潤 | ~25-30億美元 | 80-100億美元（營業利潤率8-9%） |
| 淨利潤 | ~20億美元 | 60-80億美元（淨利潤率6-7%） |

**邏輯鏈：**
- IPO資金用於品牌建設+本地化供應鏈（土耳其、巴西工廠擴產）
- 3P佔比提升意味著輕資產轉型，利潤率結構性改善
- 毛利率維持55%+，費用率下降，淨利潤率從3.5%提升至6-7%

### 5.2 中性情景（基準）

**核心假設：**
- IPO完成但估值300-400億美元，市場反應平淡
- 維持快時尚龍頭地位，但增速放緩至10-12%
- 美國市場份額被蠶食（關稅+競爭），但歐洲和新興市場補位
- 3P佔比提升至35%
- 品牌負面（ESG/勞工/環保爭議）持續但可控

| 指標 | 2025年基準 | 2031年預測 |
|------|-----------|-----------|
| GMV | ~680億美元 | 1,100-1,300億美元 |
| 營收 | ~480億美元 | 750-850億美元 |
| 營業利潤 | ~25-30億美元 | 45-60億美元（營業利潤率6-7%） |
| 淨利潤 | ~20億美元 | 35-45億美元（淨利潤率4.5-5.5%） |

**邏輯鏈：**
- 年複合增長率11% -> GMV從680億到1,200億
- take rate略有提升（3P佔比增加）
- 利潤率溫和改善，但品牌升級投入和合規成本抵消部分

### 5.3 悲觀情景

**核心假設：**
- IPO失敗或嚴重推遲（監管/地緣政治阻礙）
- 關稅持續衝擊，美國市場營收下降30-40%
- ESG/環保/勞工爭議升級，歐洲出臺強制性法規（法國已有限制先例）
- 品牌負面導致用戶增長停滯
- 年複合增長率：3-6%

| 指標 | 2025年基準 | 2031年預測 |
|------|-----------|-----------|
| GMV | ~680億美元 | 800-950億美元 |
| 營收 | ~480億美元 | 550-650億美元 |
| 營業利潤 | ~25-30億美元 | 20-30億美元（營業利潤率3.5-4.5%） |
| 淨利潤 | ~20億美元 | 15-22億美元（淨利潤率2.5-3.5%） |

**邏輯鏈：**
- 無IPO資金 -> 品牌升級受限 -> 被鎖定在低價賽道
- 美國+歐洲雙重打壓 -> 只能在新興市場低速擴張
- 毛利率被壓縮（關稅轉嫁困難+價格戰），費用率難降

## 六、對比總結

### 6.1 五年後誰更大？誰更賺錢？

| 維度 | Temu（中性） | Shein（中性） | 判斷 |
|------|------------|-------------|------|
| 2031年GMV | 1,800-2,000億美元 | 1,100-1,300億美元 | **Temu更大** |
| 2031年營收 | 310-360億美元 | 750-850億美元 | **Shein營收更高**（1P模式營收=GMV） |
| 2031年淨利潤 | 20-28億美元 | 35-45億美元 | **Shein更賺錢** |
| 淨利潤率 | 6.5-8% | 4.5-5.5% | **Temu利潤率更高**（純平臺模式） |
| 用戶規模 | 6-8億月活 | 3-4億月活 | **Temu用戶更多**（全品類） |

**核心結論：**
- **GMV維度：Temu勝出。** Temu作為全品類平臺，天花板遠高於Shein的時尚品類
- **利潤維度：Shein更賺錢。** Shein的自有品牌+柔性供應鏈帶來60%毛利率，這是Temu純平臺模式難以企及的
- **但Temu利潤率更高**——因為Temu是平臺模式，一旦跨過盈虧平衡點，邊際利潤率會快速提升

### 6.2 增長天花板

| 維度 | Temu | Shein |
|------|------|-------|
| **品類天花板** | 極高——全品類，從百貨到家電到食品 | 中等——以服裝鞋帽為核心，擴展至美妝、家居 |
| **地域天花板** | 高——已進入70+國家，新興市場潛力大 | 中高——150+國家/地區，但深度不如廣度 |
| **模式天花板** | 中——平臺模式take rate有上限（對標亞馬遜~15%、拼多多國內~5%） | 中高——1P+3P混合模式，品牌溢價空間存在 |
| **政策天花板** | 高風險——高度依賴中國供應鏈直郵，政策敏感 | 中風險——正在建設本地供應鏈（土耳其、巴西），可部分規避 |
| **終極體量估計** | GMV 3,000-5,000億美元（對標亞馬遜第三方GMV） | GMV 2,000-3,000億美元（對標Inditex+H&M+優衣庫之和的線上份額） |

## 八、最終判斷

**如果只能投一個：**

- **追求確定性 -> 通過PDD Holdings間接投資Temu。** PDD當前PE約10倍，即使Temu只實現中性情景，PDD整體（國內+Temu）的利潤增長也能支撐15-20%年化回報。關鍵是拼多多國內業務提供了利潤安全墊。

- **追求高彈性 -> 等Shein IPO。** 如果IPO定價在300億美元、2031年淨利潤達到40億美元，對應7.5倍PE，假設市場給予15-20倍PE，則市值可達600-800億美元，5年翻倍。但不確定性極高。

**核心變量排序（對兩家都適用）：**
1. 中美關稅走向（決定性因素）
2. 歐盟跨境電商法規落地力度
3. 廣告貨幣化/take rate提升速度
4. 新興市場（拉美、東南亞、中東）的增長兌現程度
5. 本地化供應鏈建設進度
