# 晨星寬護城河 × 深度折價全球篩選

**篩選條件**：晨星經濟護城河評級為"寬"（Wide Moat），且公允價值相對現價的上漲空間 ≥ +74%

**數據截止**：2026-08-17（美股價格為 2026-08-14 收盤）

**覆蓋市場**：美股、港股、A股、歐洲、日本、澳洲、加拿大、巴西、臺灣、新西蘭

---

## 一、口徑換算

"公允價值比現價高 +74% 以上"換算成晨星的 Price/Fair Value 口徑：

```
上漲空間 = 公允價值 / 現價 - 1 ≥ 0.74
        → 現價 / 公允價值 ≤ 1 / 1.74 = 0.575
        → 折價 ≥ 42.5%
```

即 **P/FV ≤ 0.575** 。

這個門檻比晨星"五星"更嚴。晨星五星只要求折價到不確定性評級對應的檔位，高不確定性股票折價 30%–40% 即可獲五星，因此五星股中相當一部分夠不到本次門檻。

## 三、反推法的誤差驗證

對兩家同時擁有"公開發布公允價值"和"官方 P/FV"的公司做對照：

| 公司 | 反推公允價值 | 獨立來源公佈值 | 誤差 |
|---|---|---|---|
| 萊茵金屬 | €1,199.80 ÷ 0.51 = €2,352 | €2,380 | 1.2% |
| WiseTech Global | A$38.00 ÷ 0.29 = A$131 | A$130（2026-07） | 0.8% |

誤差均在 1% 出頭，方法可用。

另有一次雙路徑互證：騰訊用 ADR 口徑（公允價值 $102）與用港股口徑反推（HK$795）算出的上漲空間同為 +77% 。

**反推法的前提**：晨星自 2026-06-05 以來未調整該股公允價值。對已知期間有調整的（如阿里巴巴於 2026-07-08 下調至 $241），一律採用公佈值而非反推值。

> **勘誤（2026-08-17）**：本報告初版稱阿里公允價值"於 2026-07-06 上調（此前約 $219）"，該說法錯誤，現已更正。$219 是筆者由 6 月指數 P/FV 反推的推斷值，並非晨星發佈數據。經核對 24 份晨星股票分析師報告原件確認：晨星是**下調**——道瓊斯 2026-07-08 原標題為"Fair-Value Estimate Cut by 7% to $241"，前值 $258（2025-11-18 設定）。$219 在晨星 ADR 序列中從未出現。詳見 `reports/Alibaba/阿里巴巴-晨星估值視角-20260817.md` 。
>
> 這一更正同時暴露了反推法的一個失效場景：當指數 P/FV 與個股公允價值的口徑或時點不一致時，反推會得出根本不存在的數值。阿里當時反推得 0.566 而晨星實際為 0.514，筆者已察覺不一致但誤判為"公允價值上調所致"，方向判斷反了。**凡是反推值與公佈值衝突的，一律以公佈值為準，且不得據反推值倒推變動方向。**

## 五、逐家簡介與護城河理由

### 1. WiseTech Global（ASX:WTC）— +208%

澳洲物流軟件公司，核心產品 CargoWise 是國際貨代（海運空運、報關合規）的操作系統。

**晨星護城河理由**：轉換成本 + 網絡效應。貨代一旦把全球操作跑在 CargoWise 上就極難遷移；物流業當前數字化率很低，而物流服務市場天然選擇低成本供應商，數字化作為降本核心手段是必然趨勢——要麼企業主動數字化以保持競爭力，要麼被數字化領先者奪走份額。

**為什麼折價這麼深**：股價一年跌約 70% 。創始人 Richard White 因涉嫌簽證欺詐與人口販運被澳大利亞聯邦警察調查，2026 年 7 月卸任執行主席（保留董事與首席創新官職務），疊加市場對 AI 衝擊軟件公司的普遍恐慌。晨星因領導層變動把公允價值下調 6% 至 A$130，未來十年收入複合增速預測從 21% 降至 20% 。

**關鍵點**：下調之後，它仍然是全球折價最深的寬護城河股。晨星明確表態"儘管股價反彈，股票因 AI 恐慌仍顯著低估"。

**晨星護城河理由**：品牌無形資產與長期定價權。晨星明確表態，直營轉型失誤和運動休閒趨勢降溫"並未實質損害"全球品牌無形資產或長期定價權。

## 十一、使用提示

1. **名單週轉快**。兩個月內有 4 只因股價上漲掉出門檻（Adyen、Guidewire、Veeva、LPL Financial），使用前請按最新價格重算。

2. **深度折價必有原因**。本名單每一家都有明確的市場擔憂：WiseTech 是創始人刑事調查 + AI 恐慌，耐克是轉型遲滯，萊茵金屬是股價從高位腰斬，Campbell's 是包裝食品需求結構性下行，順豐是快遞價格戰。折價本身不是買入理由，需要獨立判斷這些擔憂是否被過度定價。

3. **注意相關性**。Prosus 超過 80% 淨資產值來自騰訊，與騰訊高度相關，同時持有不構成分散。

4. **優先用風險調整口徑排序**，不要只看原始上漲空間，理由見第四節的超額安全邊際表。

5. **晨星公允價值不是價格目標**。它是分析師 DCF 模型的輸出，會隨假設修正而變動——耐克兩年內從 $112 降到 $94，碩騰五個月內從 $171 降到 $102（跌 40%）。買入後需持續跟蹤公允價值本身的變化方向。

6. **注意公允價值的新鮮度**。全表設定日跨度從 2026-01-19（順豐）到 2026-08-12（騰訊），相差近七個月。陳舊的公允價值配上下跌的股價，會製造出虛假的折價。

### 12.5 方法論教訓：反推法的失效場景

初版大量使用"本幣價格 ÷ 官方 P/FV"反推公允價值。經實測校驗，該方法在洋河（−3.3%）、騰訊（+1.9%）上誤差可接受，但存在一個致命失效場景：

**當反推值與公佈值衝突時，不能據反推值倒推變動方向。** 阿里當時反推得 P/FV 0.566 而晨星實際 0.514，筆者已察覺不一致，卻誤判為"公允價值上調所致"——方向完全反了。

**修訂後的規則**：

| 用途 | 數據源 |
|---|---|
| 公允價值、星級、不確定性、護城河、**FV 設定日**、分析師姓名 | 晨星篩選器 API（`FairValueEstimate` / `StarRating` / `FairValueDate`） |
| 調整的**理由**、DCF 分解、十年預測、評級方法論 | 分析師報告原件 PDF（API 不攜帶這些） |
| 交叉校驗 | 用 API 的 `FairValueDate` 比對 PDF 頁眉時間戳，不一致即說明 PDF 已過期 |

**API 與 PDF 沒有口徑差異，只有時效差異**——碩騰的 API 字段 `FairValueDate = 2026-08-07 03:56:23` 與 PDF 頁眉 `7 Aug 2026 03:56, UTC` 精確到秒完全一致，證明兩者讀的是同一字段。風險全在 PDF 一側：券商鏡像只在有人請求時生成，不是每日歸檔，任意一份都可能已被後續修訂取代。

**反推法自此降級為校驗手段，不再作為取數手段。**

## 十三、分析師公允價值 vs 量化公允價值

深度研究中發現，晨星對同一只股票同時維護兩套估值：**分析師公允價值**（`FairValueEstimate`，由具名人類分析師用三階段 DCF 得出，**星級由它驅動**，也是公開頁面展示的那個）與**量化公允價值**（`QuantitativeFairValue`，純統計模型輸出，對應獨立的量化星級）。

晨星的官方定位是：有分析師覆蓋時以分析師口徑為準，量化口徑用於覆蓋分析師夠不到的長尾標的。**所以本報告用分析師口徑篩選是正確的，不需要改。** 但兩套口徑的分歧值得單列。

### 13.1 分歧有多普遍

### 14.1c 更正：上一節的分母選錯了，結論應當反轉

多頭紅隊指出，14.1b 的核心論證"晨星 FV = 53.3 倍當期利潤，價值全部來自恢復假設"**使用了 2025 年這個災難年做分母**。週期股在盈利底部 PE 必然畸高，這是週期股估值的常識性陷阱，而非發現。

換用週期中性口徑後，**結論完全反轉**：

| 口徑 | 洋河 | 茅臺 | 誰更便宜 |
|---|---|---|---|
| 晨星公允價值 / **當期**利潤 | 53.3x | 25.5x | 茅臺（14.1b 的結論） |
| 晨星公允價值 / **五年均值**利潤 | **16.42x** | **29.29x** | **洋河，便宜 43.9%** |

現價口徑下的 EV / 五年均值利潤：**洋河 4.77x**、五糧液 6.50x、瀘州老窖 8.98x、山西汾酒 13.71x、貴州茅臺 21.87x —— **洋河是板塊最便宜的**。EV/五年均值收入 1.25x、PB 1.22 同樣是板塊最低。

### 14.5 一處已撤回的推論，以及一處已更正的表述

**撤回的推論**：本報告曾據"晨星公允價值 ≈ 各 agent 的樂觀情景"推斷晨星系統性偏樂觀。**該推論是循環論證，現予撤回。**

原因是各 agent 的研究任務由筆者擬定，而九份任務描述中有七份把"質疑晨星"直接寫進了目標（例如"晨星是不是錯了""重點做反面檢驗——聰明人為什麼不買""是否價值陷阱""認真論證這次不一樣是否成立"），且 investment-research 框架本身又疊加了一層芒格反向思考。**在雙重看空框架下，用 agent 自己定義的"樂觀情景"當標尺去衡量晨星，是同一個偏差測量了兩遍，不構成獨立證據。** 此外，全程沒有任何一個 agent 被要求做多頭論證。

**更正的表述**：本報告曾以"沒有一家值得重倉"概括九份研究。**該概括不準確。** 用各 agent 自己的概率加權中樞對比現價：

## 十五、晨星公允價值的可信度：十年實盤檢驗

上一節撤回了基於 agent 內部對照的推斷。本節改用**外部的、不依賴本報告任何主觀判斷的證據**。

### 15.1 最直接的檢驗對象

VanEck MOAT ETF 跟蹤的正是"美國寬護城河中 P/FV 最低的一批"——**與本報告的篩選邏輯完全一致**。它是這套方法的真金白銀實盤記錄。MOTI 是其國際版。

### 15.3 公允價值本身的穩定性

阿里巴巴的晨星公允價值軌跡（經 24 份分析師報告原件頁眉逐份核對）：

```
$100 (2024-08) → 128 → 163 → 150 → 156 → 153 → 179 → $267 (2025-09) → 258 → $241 (2026-07)
```

**13 個月內從 $100 到 $267，區間 2.67 倍。** 一家成熟公司的內在價值不會在 13 個月內變動 2.67 倍——該數列中相當一部分是在跟蹤情緒與新聞，而非測量內在價值。

碩騰：五個月從 $171 砍到 $102（−40.4%），同期股價 $125.64 → $77.27（−38.5%），**幾乎 1:1 跟隨股價**。

但需注意反例：阿里同期公允價值 −9.7% 而股價 −29.4%，耐克公允價值 −16.1% 而股價約 −49%，WiseTech 公允價值 −5.8% 而股價約 −70% 。**四家裡三家，晨星在股價崩塌時基本沒動公允價值。** 深度折價恰恰是這種"不動"製造出來的。

**所以晨星公允價值的特徵是"黏"，不是"追漲殺跌"。** 而黏本身是中性的——可能是有定力（市場錯了它對），也可能是錨定不放（現實變了它沒跟上）。本報告的證據不足以區分這兩者。

### 15.4 分用途的可信度判斷

| 用途 | 可信度 | 依據 |
|---|---|---|
| **護城河評級** | 較高 | 九次獨立複核僅兩次提出異議（萊茵金屬、洋河） |
| **當"篩選線索"用** | 有用 | 它確實能把統計意義上便宜的東西撈出來 |
| **當"合理價值"用，據此計算安全邊際** | **不可靠** | 修訂頻繁、幅度大，阿里 13 個月區間 2.67 倍 |
| **按折價排序直接建倉** | **十年實盤不如買指數** | MOAT 年化落後 1.12pp，MOTI 落後 3.27pp |

### 15.5 本節未能做到的部分

**MOAT 的業績測的是"護城河評級 + 公允價值 + 指數規則"的組合，無法把公允價值的準確性單獨剝離。** 指數還含約 0.46% 管理費與換手成本，也會拖累業績。

**樣本窗口僅十年**（stockanalysis 歷史數據上限），而 MOAT 實際 2012 年 4 月上市，2012–2016 段未納入檢驗。

**真正乾淨的檢驗尚未進行**：取晨星曆史公允價值全庫，測算"設定後 1/3/5 年，股價相對當時公允價值的實際收斂程度"——系統性夠不到即為偏樂觀，超過即為偏保守。該檢驗需要晨星曆史數據庫權限，本次未能完成。

**因此本節的結論應嚴格限定為**：這套方法在過去十年的實盤中未能戰勝指數，且公允價值數值本身不夠穩定，故不適合當作精確的價值錨。**它不構成"晨星公允價值系統性偏高"的證明。**

## 十六、這份篩選的正確用法

**當線索用，不當答案用。**

十家公司在深度複核後，估值中樞全部低於晨星公允價值，差異從 28% 到 294% 不等。但同時，五家仍有 24%–50% 的獨立口徑上漲空間。這兩句話不矛盾——**它說明晨星的折價幅度需要自己重算，但折價本身往往是真的**。

統計意義上的便宜，與生意意義上的便宜，是兩回事。這份名單隻回答第一個問題。

## 十七、多頭紅隊輪：五份對抗性檢驗

### 17.1 為什麼要跑這一輪

第十四節 14.5 已說明：九份深度研究的任務描述由筆者擬定，其中七份把"質疑晨星"直接寫進目標，且無一份要求多頭論證，構成系統性偏差。承認偏差不等於修正偏差，故對獨立口徑上漲空間 >23% 的四家（Prosus、洋河、騰訊、萊茵金屬）、以及唯一被判絕對高估的 WiseTech，各派一個紅隊做對抗性檢驗。

**紅隊的任務定義刻意不是"論證買入"，而是**：攻擊既有看空報告的每一條論斷，並被明確告知——"若某條看空論據經檢驗站得住，你必須明說它站得住，不許為了立場硬拗；一份攻擊 8 條、推翻 3 條、承認 5 條的報告，比全面翻案的報告有價值得多。"

每份紅隊報告均須產出**逐條裁決表**（推翻 / 部分成立 / 完全成立 + 證據），並同樣通過 `report_audit.py` 15% 抽樣準出。

|---|---|---|---|---|---|---|
| Prosus | €56.10 | **€55** | €72 | €37.395 | +47% | 否（倉位建議改變） |
| 洋河股份 | ¥53.42 | **¥64.86** | ¥78 | ¥39.82 | **+62.9%** | **是** |
| 騰訊控股 | HK$544 | **HK$640.61** | HK$780 | HK$445.60 | **+43.8%** | **是** |
| 萊茵金屬 | €1,405 | **€1,553.57** | €2,380 | €1,202 | +36.7%（四年年化 8.14%） | 否 |

**五次裡只有兩次改變了結論。** 紅隊推翻了大量具體論據，但在 Prosus、萊茵金屬、WiseTech 三家維持原判——其中 Prosus 與 WiseTech 的紅隊中樞**比看空方還低**。

### 17.3 五家各自最重要的一處推翻

**Prosus —「套利不是投資」被數學推翻。** 折價**恆定不變**時，每股 NAV 仍以 `a = f·d/(1−f)` = 2.16%/年 增厚。壓力測試：折價永久鎖死 38.29% 且全部資產零回報，五年仍 +11.3%；折價鎖死 + 騰訊年漲 8%，五年 +66.9% 優於直接持騰訊的 +46.9% 。**回報不依賴折價收斂。** 另發現看空方模型把增厚率符號設反——折價越闊，同樣美元買到的股份佔比越高、增厚越快，而看空方在悲觀情景裡設了最低增厚率。

**洋河 —「折價更深是模型偽像」的分母選錯了。** 詳見 14.1c。換五年均值利潤口徑後結論反轉：晨星 FV/五年均利，洋河 16.42x vs 茅臺 29.29x 。

**騰訊 — 看空方的"中性"其實是深度看空。** 把其 SOTP 從 EV/Sales 換算成 EV/非IFRS經營盈利：悲觀 8.14x / 中性 **11.78x** / 樂觀 15.83x，而晨星 HK$780 對應 17.43x 。看空方自己寫"17.4 倍並不離譜"，卻給了一個比"不離譜"低 32.4% 的中樞且從未解釋差額來源——因為 EV/Sales 口徑把它藏住了。另查出方法論硬傷：用網易 **P/S 4.76** 去錨定 **EV/Sales**，而網易 EV/Sales 實為 3.42（淨現金佔市值 29%），憑空多給自己 39% 的"保守空間"。

**萊茵金屬 — cost-plus 論證坐實。** 詳見 14.2c 的通用動力內部分部對照。

**WiseTech — 看空方混淆了兩件不相干的事。** 現金流口徑造假**完全成立且更嚴重**（紅隊找到零誤差路徑：797.8 − 361.3 = 436.50 精確等於公司口徑，436.50 − 69.5 = 367.00 精確等於法定 OCF；四個報告期全部吻合，1H26 高估已達 **42.1%**）。**但這條完全不能解釋 A$33 與 A$130 的差距**——用稅後口徑乾淨的模型，僅憑晨星的 20% 收入增速即可推出 A$135。**分歧 100% 來自增速假設，0% 來自現金流口徑。** 看空方把"公司披露不老實"與"晨星模型算錯了"混為一談，兩者沒有因果關係。

### 17.4 紅隊主動加重的看空證據

紅隊並非單向翻案，三份主動補強了對多頭不利的證據：

- **騰訊**：權益變動表顯示 H1'26 回購 RMB 214.49 億 vs H1'25 的 336.47 億，**同比 −36.25%**；Q2 攤薄股數同比僅降 1.02%（歷史 2%+）。回購減速不是 8 月 12 日電話會之後才發生，**上半年就在發生**。
- **Prosus**：騰訊自身回購被錯誤計入 Prosus 超額收益（屬共享收益，應從多頭論據中刪除）；淨債務 −$64 億可能意味著 $50 億回購是**能力上限而非主動選擇**。
- **WiseTech**：1H26 演示第 23 頁同一張幻燈片，左側寫"CargoWise +14%~21%"，右側寫"1H/2H skew 與 FY25 一致"——後者反推 FY26 僅 **+12.27%**，低於自身指引下沿。
