# 九公司凱利賠率橫評：上行、下行與倉位框架

**編制日：2026-09-03 | 數據基準：各標的2026年8月下旬收盤，逐項標註 | 匯率：1 HKD = 0.8573 CNY，1 USD = 7.8 HKD / 7.1 CNY**

**一句話結論：九家中八家的凱利公式輸出為正且全部指向滿倉加槓桿（0.31～4.56），唯一的負值出現在估值透支的標的上（−1.58）。這組分佈本身就是結論——凱利的數值不可用，符號可用。真正能拉開標的差距的不是期望回報，而是下行深度與路徑是否內生。**

---

## 零、方法與它的邊界

本文對九家公司套用同一套框架：四檔情景賠率表 → 期望回報 → 凱利公式 → 敏感性測試 → 年化折算 → 路徑判定。

**凱利公式在股票上的正確用法是取符號，不是取數值。** 原因在實測中很清楚：它把"淺下行"直接翻譯成"高槓桿"，而淺下行恰恰是所有輸入裡最不可靠的一個——尤其當下行是被現金或淨資產托住的時候。九次計算裡八次給出100%以上的倉位建議，這不構成可執行的結論。

**負值則是可執行的**：它意味著在當前價格上，無論對這家公司的判斷多正面，賠率結構都不支持買入。

**全文概率分配均為主觀判斷**，這是整套方法最薄弱的一環。讀者應代入自己的概率重算，而非直接採用。

## 二、四個跨標的規律

**規律一：凱利排序與期望排序不一致，因為凱利被下行深度主導。**

```
期望排序：拼多多 > 美團 > 騰訊 > 快手 > 泡泡瑪特 > MiniMax > 茅臺 > 訊飛 > 寒武紀
凱利排序：拼多多 > 騰訊 > 茅臺 > 美團 > 快手 > 泡泡瑪特 > 訊飛 > MiniMax > 寒武紀
```

兩組對照最能說明問題：**茅臺期望僅+13.4%，凱利排第三（2.17），因為下行只有−36%；MiniMax期望+17.2%高於茅臺，凱利卻只有0.31，因為下行是−85%。** 上行+199%這個數字在凱利公式裡幾乎不值錢——它被85%的下行吃光了。

**規律二：賠率比比期望值更能分辨標的。**

九家中七家的賠率比擠在1.8～2.8，能拉開差距的只有兩頭：一頭是厚現金壓住下行（拼多多−19%），一頭是估值透支放大下行（寒武紀上行僅+35%、下行−85%）。

**規律三：九家中只有兩家是內生路徑。**

騰訊與茅臺——不需要第三方點頭，繼續經營即可走到目的地。**其餘七家的關鍵變量都握在別人手裡**：美團看競爭對手是否維持停戰、快手看投資者是否同意上市、拼多多看各國關稅政策、泡泡瑪特看消費者對IP的偏好、MiniMax看AI應用市場成熟速度、寒武紀與科大訊飛看行業週期。

這解釋了一個反直覺的結論：**騰訊期望值只排第三，卻應獲得最高權重——它是少數"判斷對了就一定能兌現"的標的。**

**規律四：唯一的負凱利，出現在唯一一個上行小於下行的標的上。**

寒武紀按券商預測的2028年淨利138.75億、給40倍市盈率，對應市值5,550億，**低於當前6,502億市值**。這不是"貴一點"的問題——當前價格已把最樂觀的預測吃掉之後還倒欠。

## 三、快手：分部折價加期權（重點展開）

快手是九家中結構最複雜、也是唯一需要逐條核對一手法律文件的標的。本節結論均由港交所公告原文重算，相關三份底稿見文末。

### 3.1 分部加總

基準：2026-08-24 收盤 33.02 港元、市值 1,428.7 億港元（43.3 億股）

```
淨現金        939.4 億人民幣 ≈ 1,095.7 億港元
              （可動用資金1,213億 − 有息借款273.62億，一手核算）
可靈 68.33% 股權   名義 959.4 億港元（投後180億美元×7.8×68.33%）
主業經調整淨利      239 億港元（剔除可靈虧損後約205億人民幣）
```

**關鍵修正一：可靈這個減數應下修。** 投資者持有的是帶回購保護的股權（回購金額＝原始投資價格＋年化8%單利，且可靈集團承擔連帶責任），不是普通股。經核對公告，本輪認購的是北京可靈的**註冊資本**，全文**未見優先清算權、棘輪條款、反稀釋安排或IPO定價下限**。因此不宜套用優先股與普通股20%–40%的典型價差，**合理折讓區間為15%–25%**：

| | 原口徑 | 調整後 |
|---|---:|---:|
| 可靈普通股口徑整體估值 | 180億美元 | **135–153億美元** |
| 快手 68.33% 對應 | 959.4億港元 | **719–815億港元** |
| 相對市值的隱含折價 | 56% | **53%–54%** |

折價依然巨大，但**"主業隱含估值為負"這個流傳的說法，在普通股口徑下不成立**。

### 3.2 賭贏的真實門檻是280億美元，不是180億美元

這是本次分析中最關鍵的一個數字，它推翻了"IPO按一級市場價定價即算贏"的直覺。

```
投資人投入            30 億美元，取得投後 16.67%
五年後回購可得        30 × (1 + 8% × 5) = 42 億美元
IPO 後持股（稀釋後）   約 15%

IPO 優於回購的條件：   持股價值 > 42 億美元
                       42 ÷ 15% ≈ 280 億美元
```

**該門檻具備執行力**，因為股東協議載明：

> 持有超過 50% 認購金額的投資者就北京可靈及其控制實體的若干重大事宜擁有慣常同意權。

首次公開發售幾乎必然屬於需要投資者同意的重大事項。**若屆時市場僅給出100–150億美元定價，投資者具備否決IPO、等待死線行使回購權的動機與工具。** 那種情形下快手將同時承受兩件事：拿出約42億美元（約330億港元）現金履行連帶責任，以及可靈估值錨歸零重來。

**因此"IPO按180億美元定價"不是賭贏，而是觸發回購博弈的灰色地帶。**

### 3.4 三條死線（全部來自公告原文）

| 死線 | 日期 | 未達成的後果 |
|---|---|---|
| 增資交割 | **2026-12-29**（簽署起180天） | 減數由資產退回為合同，全部推演失效 |
| 牌照三項 | **約2027年年中**（最遲付款日起九個月） | 觸發回購權——唯一同時打擊資產端與負債端的事件 |
| 上市 | **最遲上市日期或2031-10-30，以較早者為準** | 觸發回購權 |

**"最遲上市日期"是獨立定義的日期，公告釋義章節未予披露。** 條款為兩者取較早，故真實死線可能明顯早於2031-10-30，本文按2031年折算的年化數據屬偏樂觀口徑。

牌照三項為：完成收購海外運營公司100%股權、取得增值電信業務經營許可證、完成AI大模型及／或算法備案。**三項均為行政審批，不完全由公司控制。**

另需注意：遞表本身不解除回購權。公告載明，即使在最遲上市日期前已遞交申請，若出現遞表後12個月內未完成發行、申請失效未及時重提、被拒或主動撤回，回購權照樣復活。

### 3.5 時間對回報的稀釋

```
+117% 兌現於 3 年    → 年化 29.3%
+117% 兌現於 5.3 年  → 年化 15.9%    （按2031-10-30死線）
+78%  兌現於 5 年    → 年化 12.2%
```

**同一判斷，兌現時點從3年推到5.3年，年化折損接近一半。** 這是快手與內生路徑標的最本質的差別——騰訊的回報來自每日發生的利潤複利，快手的回報押在一個日期未定、還需第三方點頭的單點事件上。

### 3.6 紅線清單

按殺傷力排序，觸發即減倉或清倉，不參考當期估值：

| 優先級 | 紅線 | 後果 |
|---|---|---|
| 1 | 增資交割告吹或大幅縮水（2026-12-29前） | 減數直接蒸發 |
| 2 | 九個月牌照死線未辦結（約2027年中） | 承擔約42億美元連帶責任，估值錨歸零 |
| 3 | 可靈年化收入運行率增速跌破100% | 280億美元門檻無望，A檔出局 |
| 4 | 資本開支不降反升且上市無進展 | 止損紀律失效，通往E檔的唯一路徑 |
| 5 | 線上營銷服務收入轉負（當前+4.4%，上季+9.3%） | 主業分母開始塌 |

### 3.7 一處需要更正的流傳信息

多家媒體報道騰訊參與可靈本輪融資，**這一點是準確的**，但其出資主體名稱與"騰訊"二字無關，容易在核對名單時被漏掉。公告第973行：

> 乙方包括**上海啟善投資有限公司**及 **Parallel Mars Investment Limited**……**彼等由騰訊（本公司主要股東）最終控制。**

兩家各出資681.57百萬人民幣，**騰訊合計13.63億人民幣，與阿里雲13.63億人民幣出資完全相同，並列最大單一戰略投資方**，百度為3.41億人民幣。

這同時解釋了本次交易的關連交易屬性：甲方 Atypical Holdings 的普通合夥人為獨立非執行董事盧蓉女士，丙方 Neumann Intelligence I Holdings 由獨立非執行董事張斐先生全資擁有，乙方由主要股東騰訊最終控制——三名相關董事因此就該決議案放棄投票。

## 四、其餘八家要點

**騰訊**（約450港元／市值約3.52萬億人民幣）：核心業務剔除上市投資4,872億後隱含市盈率10.4–11.8倍。Q2資本開支527.8億（+176%），AI對利潤拖累約105億；**剔除新AI產品影響後Non-IFRS經營利潤+19%至861億**，含AI則為+9%。九家中路徑可靠性最高。風險為AI投入回報節奏與回購規模縮減（已明確2026年減少回購轉投AI）。

**拼多多**（$82.39／約8,321億人民幣）：Q2營收1,123.6億（+8%）、歸母淨利272億（−12%）、**經營現金流257億（+19%）**——利潤與現金流背離，說明下滑主要來自費用化投入。現金及短期投資4,361億佔市值52%。**Temu的收入與虧損從不單列**，四檔情景中關於Temu的假設全部為外推。已發生的政策衝擊：美國2026年5月起關閉中國直髮通道，歐盟7月起每件徵3歐元。

**美團**（78.05港元／約3,991億人民幣）：**2026 Q2市場份額美團43%、淘寶閃購42%、京東15%**——曾經70%以上的份額壟斷已被追平至只剩1個百分點領先，**正常化利潤不可能回到2024年的437.7億**。但停戰信號明確：七月三家達成五項共識、京東表示2026年投入下降、經營虧損從161億（2025Q4）收窄至65億（2026Q1）。

**泡泡瑪特**（148.80港元／1,982億港元）：H1營收171.73億（+23.76%）與淨利50.38億（+10.14%）均低於市場預估（199.8億／66.4億）。**海外收入49.72億同比−11.6%**（亞太−9.7%、美洲−16.5%），中國區+47.3%。**存貨週轉天數由2025全年123天升至半年度201天**，CEO在業績會上表示今年大概率完不成20%營收增長目標。

**MiniMax**（市值134億美元）：ARR軌跡為2026年2月1.5億美元 → 5月3億 → **8月8億美元**；H1營收1.17億美元（+283.1%），企業AI服務收入+703.1%。**當前市值/ARR ≈ 16.75倍**，與全球頭部AI公司持平，非低估。關鍵反向證據：**7月Token消耗量為1月的20倍，而收入僅增3.83倍，隱含單位Token價格下降約81%。**

**茅臺**（1,292.56元／1.62萬億）：2025年為上市以來首次營收淨利雙下滑（淨利823.2億，−4.53%），2026 Q2淨利−6.9%。分紅率79%、股息率約4%。**年化4.3%中，幾乎全部來自股息。**

**科大訊飛**（41.35元／993億）：H1營收116.23億（+6.52%），歸母淨利−2.04億，**扣非淨利−6.37億、虧損同比擴大74.88%**。境外營收+160%、合同額+27%為亮點。核心問題不在數字：成立二十餘年至今扣非未盈利。

**寒武紀**（1,035元／6,502億）：H1營收59.96億（+108%）、歸母淨利23.11億（+122.6%），增長確實強勁。但按當前市值折算，券商預測的2026/2027/2028年淨利對應市盈率為132/74/47倍。**存貨82.48億佔期末總資產45.32%（+66.83%）、預付款+291.37%**——總資產的45%押在存貨上，是高槓桿的產能賭注。

## 五、三檔分類與組合框架

**可考慮（凱利>1 且年化>9%）**：拼多多、騰訊、美團、快手、泡泡瑪特

**不佔位置（年化<6%）**：茅臺（回報幾乎等於4%股息）、科大訊飛（二十餘年未盈利）、MiniMax（定價已合理，賭ARR能否再翻倍）

**明確排除**：寒武紀（期望為負，凱利為負）

**若組合僅有三個位置，一個可論證的分配是：**

```
騰訊   45%    唯一內生路徑 + 可靠性最高
拼多多 30%    賠率比6.5最優，且是唯一不屬同一生態的標的
美團   25%    期望第二，拐點可按季度驗證

組合三年期望 ≈ +41.7%  →  年化 12.3%
```

**一個必須寫明的結構性問題**：騰訊是美團與快手的大股東。同時持有這三家，實際分散度接近1.3只股票——真正的分散需要至少一個不屬於該生態的標的，這也是拼多多在此框架中的獨特價值。

**權重敏感度極低**：當各標的期望值集中在30%–50%區間時，權重從35%調到20%對組合期望的影響不足0.1個百分點。**選誰進組合，比給多少權重重要得多。**

## 六、數據缺口（不用估算掩蓋）

1. **美團數據仍為2026 Q1，其Q2財報已於8月28日發佈，本文未及更新。** 該標的在上述框架中佔25%權重，而整個論點壓在"份額43%是否守住"這一個數上——**它決定正常化利潤的錨是380億還是150億，直接影響A檔與C檔的位置。在更新前，美團部分應視為待定。**
2. 泡泡瑪特、MiniMax、科大訊飛、寒武紀的淨現金與有息負債均未取得。
3. MiniMax 2026年中報的完整財務數據未取得，H1部分指標來自券商預測。

## 七、方法論：本次兩處翻車與修正

記錄在此，因為錯誤本身比結論更有複用價值。

**翻車一：用上一財年確認收入給超高增長標的做基數。**

```
使用：MiniMax 2025財年收入 7,903.8萬美元
實際：2026年8月 ARR 已達 8億美元（約10倍）
後果：把公司當年就已越過的水平，當成了三年後的樂觀情形
```

**修正規則：當同比增速超過100%時，財年確認收入已經失效，必須換成最新運行率，並在輸出中註明基數口徑。**

**翻車二：用估算市值往下推演三層結論。**

```
第一次修正後（收入基數填對、市值仍用估算）→ 期望 +160%，f* = 2.25
市值填對（134億美元）後              → 期望 +17.2%，f* = 0.31
該標的在九家中的排序：從最好變為倒數第二 —— 基本面數據一個字未改
```

**修正規則：市值不接受估算。** 它是所有輸入中最易獲得的一個，同時是唯一同時決定上行空間與下行深度的一個。**在輸出中標註"此項為估算、待核實"不能代替核實**——帶著估算值往下推三層，等於在沙地上蓋三層樓。

**兩次錯誤方向相反**（一次過度悲觀、一次過度樂觀），說明單個基礎數字的錯誤可以把結論推向任意方向。**因此基礎數據的核實優先級，高於分析框架的精巧程度。**
