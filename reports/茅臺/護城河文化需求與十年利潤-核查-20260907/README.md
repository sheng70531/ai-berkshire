# 核查範圍與復算

對應報告：`貴州茅臺護城河文化需求與十年利潤研究報告-20260907.md`，資料截止 2026-09-07。

- `model.py` 調用項目 `financial_rigor.py` 完成七項來源核對及三情景計算，同時使用 Decimal 保存精確結果。項目 calc 當前內部先用浮點求值，本研究以獨立 Decimal 結果為精度依據，沒有修改共享工具。
- `calculations.json` 包含原始基期、來源 URL、所有假設、情景、敏感性及精確結果。
- `financial-rigor-output.txt` 是原始項目工具輸出。
- `audit.py` 調用 `report_audit.py extract --seed 42`，保留抽樣結果，並對事實、推導值和假設分別處理；同時校驗全部情景輸出表格與計算一致。
- `audit-extract.txt` 保留六項原始抽樣。兩項為歷史事實，一項為從財報計算的比率，三項為前瞻假設。
- `audit-classified.json` 保留每個原始樣本及分類。三項前瞻假設僅驗證模型輸入與正文相符，沒有填造外部真實值。
- `audit-verdict.txt` 僅對兩項事實及一項歷史推導比率輸出判決。工具自帶的“可發佈”文字僅限其實際核查範圍，不代表六項全部被外部驗證，更不代表未來利潤或企業文化結論獲審計背書。

來源核對的第三方平臺報道依然源自公司披露，不能視為獨立的財務審計。官網對改革成效的陳述與行業問卷都不是茅臺終端開瓶量的完整統計。

未來利潤使用 2025 年完整財年為基期，推算至 2036 年，共十一個增長期；研究時點到目標年份約十年。模型中的增長是區間等效年均值，未做逐年路徑預測。沒有主觀概率權重，三情景也不是統計置信區間。
