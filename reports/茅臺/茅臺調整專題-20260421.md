# 茅臺 2024-2026 調整專題：利潤何時恢復增長？vs 2013 的同與不同

**出品**：ai-berkshire 投研團隊（四角色並行框架）
**研究日期**：2026-04-21
**研究主題**：貴州茅臺 Q4 利潤 -30% 歸因 + 利潤拐點預測 + 與 2013 調整的同異對比
**研究方法**：4 個 Agent 並行（Q4 基本面 / 2013 調整覆盤 / 利潤拐點預測 / 兩次調整同異對比）

---

## 0. 三句話結論

### Q1: 利潤何時恢復增長？
**2026 Q1-Q2 利潤增速環比見底**（一季報 4-25 披露，預期 +5%），**2026 全年 +3-5%（中性）恢復正增長**，**2027 年 +8-10% 才是明顯恢復增長**。批價拐點已在 2025-12-12（1485 元歷史低點）確認；這輪"批價→利潤"的滯後只有 1-2 季度（vs 2013 的 7 季度），因為茅臺**主動控量+提價+直銷改革**三重提前對沖。

### Q2: 與 2013 有什麼相同和不同？
**形似神不似**：
- **深度更淺**：股價 -45% vs -58%，PE 17-18x vs **9x**，批價 -50% vs -56%
- **時間可能更長**：2013 是外生一刀切（半年觸底），2024-26 是內生慢性（已 6 季度）
- **公司基本面傷害更深**：2025 淨利 -4.53%（首次負增長）vs 2014 仍 +1.4%
- **但分紅率對沖**：2025 分紅率 79%（vs 2014 的 36%），股息率 ~4-5% 撐起估值底

### Q3: 對投資意味著什麼？
**不是 2014 式"百年一遇"，是"十年一遇的合理買點"**：
- **2014-01 買茅臺**：下行 -20% / 上行 +1000%（戴維斯三殺反轉）
- **2026-04 買茅臺**：下行 -15% / 上行 +60-100%（5 年，"債券+微成長"）
- 5 年預期年化回報 8-12%（中性情形）
- **段永平 2025 年三次加倉 + 2026-01 "換倉式"加倉**（從中國神華換到茅臺），暗示這不是"ALL IN 的機會"，是"優質標的的合理價"

## 1. Q4 利潤 -30% 的歸因（最犀利的分析）

### 1.1 三分之一法則
- **1/3 結構性**：系列酒（1935 等）噸價暴跌 **-13.13%**、毛利率 -3.76pct
- **1/3 改革性**：Q4 主動控貨（Q4 營收 -19.3% 主因）+ 銷售費用前置 **+28.62%**（i茅臺 推廣+渠道補貼）
- **1/3 週期性**：大眾消費降級 + 商務場景弱化

**關鍵判斷**：**1/3 的"改革性"部分是可以在 2026 釋放回補的**——這不是純粹的週期坍塌，是主動出清。

### 1.3 最警惕的信號：現金流
**經營現金流 -33.46%**（924.64 → 615.22 億）—— **遠超利潤下滑幅度**，是比利潤表更早的渠道信心度量。

### 1.4 茅臺酒噸價**上市以來首次下滑**（-0.8%）
不是銷量問題（銷量還 +1%）——是價格問題。

### 1.5 系列酒是核心拖累

- 系列酒毛利率 **-3.76pct 至 76.11%**

## 4. 與 2013 調整的同異對比

### 4.1 對比大表

| 維度 | 2012-2015 | 2024-2026 |
|------|----------|----------|
| 觸發因素 | 八項規定+塑化劑+反腐 | 消費降級+地產下行+庫存週期 |
| 衝擊性質 | **外生一刀切（急性）** | **內生+宏觀（慢性）** |
| 持續時長 | 2.5 年（2012.07-2014.12） | 已 6 季度，預計總時長 2-3 年 |
| 股價最大跌幅 | **-58%**（266→118） | -45%（2627→~1407，截至 2026-04） |
| **PE 最低** | **~9x**（2014-01，歷史最低） | 17-18x |
| 批價跌幅 | 1875→820（-56%） | 3000+→1485（-50%） |
| 政務消費佔比 | **30-40%** | **<5%** |
| 商務消費佔比 | ~40% | 50%+ |
| 大眾消費佔比 | 20-30% | 40%+ |
| **直營佔比** | **<5%** | **50.09%** |
| 分紅率 | 36%（2013） | **79%（2025）** |
| 2014/2025 淨利潤 | +1.4%（未負增長） | **-4.53%（首次負增長）** |
| 宏觀 GDP | 7.8% | ~4.5% |
| 地產 | 黃金年代 | 下行週期 |
| 通脹 | CPI +2.6% | PPI 負、溫和通縮 |

### 4.2 相同點（4 條核心）

1. **都是"外部觸發+內部過剩"的共振**：內外一面都不會調整這麼深
2. **批價是最先行、最核心的觀察指標**：比財報快 1-2 季度
3. **經銷商庫存與渠道去化是必經之痛**：都經歷"提價-壓貨-批價崩-去庫存"閉環
4. **最終都要靠"消費者升級新故事"破局**：都是一次消費者結構的重構

### 4.3 不同點（7 條核心）

1. **衝擊性質**：2013 外生急性（來得兇去得快）vs 2024-26 內生慢性（溫水煮青蛙）
2. **消費者結構**：2013 政務 30-40% 被抽空 vs 2024-26 商務+大眾主力但被宏觀壓制
3. **渠道結構**：2013 經銷商 95% vs 2024-26 直營 50%+（有 i茅臺 工具）
4. **估值起點**：2013 從 30x→9x 大跳水 vs 2024-26 從 25x→17-18x（下跌空間有限）
5. **宏觀背景**：2013 高速期估值修正 vs 2024-26 減速期估值壓力（彈性更弱）
6. **公司能力**：2013 渠道散亂管理新手 vs 2024-26 i茅臺+現金 2000 億+分紅 79%
7. **基本面傷害**：2014 淨利仍 +1.4% vs 2025 首次負增長 -4.53%

### 4.4 嚴重性多維判斷

| 維度 | 哪次更嚴重 |
|------|-----------|
| 衝擊速度 | 2024-26（時間維度更長） |
| 股價最大跌幅 | **2013**（-58% vs -45%） |
| 估值極端度 | **2013**（9x vs 17-18x） |
| 批價跌幅 | **2013**（略深） |
| 淨利潤下滑深度 | **2024-26**（首次負增長） |
| 持續時長 | **2024-26**（可能更久） |
| 復甦難度 | **2024-26**（宏觀更差） |
| 品牌傷害 | 2013（塑化劑） |

**綜合**：**2013 下跌幅度和估值極端度更嚴重，2024-26 持續時間和復甦難度更嚴重**。

## 5. 2013 調整覆盤的寶貴經驗

### 5.1 2013 的復甦五大驅動
1. **大眾消費崛起**（補位政務 60%+）
2. **批價回升**（2014 中企穩 820-850 → 2015-12 守 850 → 2016-11 突破 1000）
3. **渠道主動改革**（放開經銷商門檻，2014-06 新增 343 家）
4. **茅臺主動控量穩價**（出廠價 819 元全程未降，保住品牌調性）
5. **國企改革催化**（混改、股權激勵預期）

### 5.2 2013 觸底信號的先後順序（記住這個！）
**股價 → 業績 → 批價 → 預收款**：先後約半年到一年錯位

| 信號 | 觸底時點 | 特徵 |
|------|---------|------|
| 股價 | 2014-01 | **最先**觸底（PE 8.3-9x） |
| PE 估值 | 2014-01 | 同步 |
| 淨利潤增速 | 2014 全年（+1.4%） | 同步 |
| 批價 | 2014 Q2-Q3（滯後 ~2 季度） | 在 820-850 磨底 1 年 |
| 預收款 | 2014 Q3（-83%） | **最晚**觸底（後驗指標） |

**這次的對照**：批價拐點已在 2025-12，股價拐點在 2026-02，**利潤拐點 2026 Q1-Q2（即將驗證）**。這輪滯後時間大幅縮短（1-2 季度 vs 2013 的 7 季度），因為這次是主動調整不是被動。

### 5.3 2014-01 投資的神話回報
- 118 元 × PE 9x × 股息率 3.7%
- 持有 3 年（至 2017-01 的 330 元）：+180%，年化 40%
- 持有 7 年（至 2021-01 的 2000 元）：**+1600%，含分紅 20 倍**
- **這是 A 股史上最經典的"好公司×低估值"樣本**

## 6. 利潤拐點預測與三情景

### 6.1 拐點時序

| 拐點 | 時點 | 狀態 |
|------|------|------|
| **批價拐點** | 2025-12-12（1485 元） | **已確認** |
| **股價拐點** | 2026-02（中金目標 1860） | 基本確認 |
| **利潤增速環比拐點** | **2026 Q1（4-25 一季報）** | 即將驗證（預期 +5%） |
| **利潤絕對值恢復增長** | **2026 全年 +3-5%** | 中性基準 |
| **明顯恢復增長** | **2027 年 +8-10%** | 一致預期 |
| **完全修復** | 2027 H2 - 2028 | 長期 |

### 6.2 三情景利潤預測（2025 基數：營收 1,721 億、淨利 823.2 億）

| 情景 | 概率 | 2026E 淨利 | 2027E 淨利 | 條件 |
|------|------|-----------|-----------|------|
| **樂觀** | **15%** | +10-12%（~905-920 億） | +12-15% | 消費快速修復、批價 Q3 站上 2000 |
| **中性** | **60%** | **+3-5%**（~848-864 億） | **+8-10%**（~920-950 億） | 溫和復甦、批價企穩 1600-1800 |
| **悲觀** | **25%** | -5-0%（~782-823 億） | +0-5% | 消費持續降級、批價破 1499 |

### 6.3 核心尾部風險
**消費習慣結構性改變**（商務場景不可逆收縮、年輕人不喝白酒）——若此判斷成立，**長期增速中樞從 15%+ 降至 5-8%**。即使利潤恢復增長，也回不到過去的成長邏輯。

## 7. 投資機會直觀對比

### 7.1 2014-01 買茅臺的極致 case
- PE 9x × 大眾崛起 EPS 3x × 情緒從極悲到極樂 = **戴維斯三殺反轉**
- 下行空間 -20% / **上行空間 +1000%**
- 7 年 22 倍（含分紅 25 倍）

### 7.2 2026-04 買茅臺
- PE 17-18x × 溫和恢復 EPS 8-12% CAGR × 估值溫和修復
- 下行空間 **-15%** / **上行空間 +60-100%**（5 年）
- 5 年年化 **8-12%**（中性情形）
- **沒有戴維斯雙擊空間，更像"債券+微成長"**

### 7.3 分人群建議

| 人群 | 建議 | 行動點 |
|------|------|--------|
| **信仰派** | 當前 PE 17-18x 合理偏低，分批建倉 | 倉位 15-25% |
| **擇時派** | 等 PE 15x（股價再跌 15-20%） | ~1150-1200 元 |
| **現金流派** | 股息率 4-5% ≈ 長期國債收益率，已可接受 | 關注分紅率 79% 可持續性 |
| **絕對保守派** | 等史詩級情形 PE 9x（股價 575 元） | 概率 <10% |

### 7.4 段永平的動作（重要參照）
- **2013-2014**：重金加倉茅臺（"好公司+好價格+看得清"）
- **2025-2026**：
  - 2025-01/06/10 **三次加倉**

## 10. 一句話總結

**這輪調整是"十年一遇的合理買點"，不是 2014 式"百年一遇"**。**時間維度可能更長**（內生慢性），**但公司基本面更強**（分紅 79% + 直營 50% + 現金 2000 億）。利潤 **2026 Q1-Q2 見底、全年恢復正增長、2027 明顯恢復**。

**段永平"換倉式"加倉的信號最誠實**：優質標的的合理價，分批建倉 15-25% 倉位，不適合 ALL IN。5 年預期 8-12% 年化回報，**相對無風險利率有 3-7% 溢價**——這是當前投資茅臺的真實預期。
