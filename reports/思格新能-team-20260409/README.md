## 核心結論

> 思格新能源是一家極具爆發力的光儲新貴，創始人許映童的華為系基因賦予了其強大的執行力和技術整合能力。SigenStor五合一產品在可堆疊光儲一體機細分賽道做到全球第一，50%毛利率遠超同行。但成立僅3年多、單品依賴度超90%、800億HKD估值對應~24x PE（2025E），定價並不便宜。**短期打新有超額收益概率較高（176倍超購+頂配基石），但中長期持有需警惕增速放緩、競爭加劇和地緣政治風險。**
