## 二、商業模式分析（段永平視角）

### 核心價值主張

酷家樂用雲端渲染+AI技術，將室內設計從"幾天出圖"壓縮到"幾分鐘出圖"，極大降低了家居設計的專業門檻。本質是**設計工具SaaS**——用免費/低價個人版吸引設計師，再向B端企業客戶（家居品牌、裝修公司）收取訂閱費。

> 段永平會問：**"這個生意的用戶粘性從哪裡來？"**

### SaaS收入模式拆解

| 指標 | 數據 | 來源 |
|------|------|------|
| 個人客戶 | 43.3萬付費（2025H1） | 招股書 |
| 企業客戶 | 4.7萬付費（2025H1） | 招股書 |
| 個人付費轉化率 | 6.8%→9.6%（2023→2025） | 招股書 |
| 企業客戶NRR | 101.6% | 招股書 |
| 大客戶NRR | 110.0% | 招股書 |
| 個人客戶NRR | 92.3% | 招股書 |
| 收入結構 | 24%高級企業客戶貢獻80%收入 | 招股書 |

**單位經濟模型分析**：
- 2025年收入8.20億元，企業+個人客戶合計約48萬
- **平均ARPU**：約1,708元/年（估計）
- 大客戶貢獻佔比極高，呈典型的"頭部客戶依賴"結構
- NRR超100%說明大客戶有擴展消費，但個人客戶NRR僅92.3%，流失率偏高

### 用戶生態飛輪

```
設計師免費用 → 生成海量設計方案 → 數據積累（5000萬+雲端方案）
     ↓                                        ↓
品牌商付費對接 ← 流量入口價值 ← 戶型庫覆蓋90%中國戶型
```

### 護城河評分卡

| 護城河維度 | 評分 | 理由 |
|-----------|------|------|
| 轉換成本 | ★★★☆☆ | 設計師習慣有一定粘性，但工具替換成本不算高 |
| 網絡效應 | ★★★☆☆ | 設計師-品牌商雙邊網絡存在，但不如平臺型公司強 |
| 數據壁壘 | ★★★★☆ | 5000萬+結構化設計方案、90%戶型庫，較難複製 |
| 品牌認知 | ★★★★☆ | 家居設計領域第一品牌，"酷家樂"幾乎等於品類 |
| 規模經濟 | ★★☆☆☆ | 雲渲染有規模效應，但研發投入佔比仍極高 |
| **綜合護城河** | **★★★☆☆** | **中等偏上，有壁壘但非不可逾越** |

> **段永平點評**："做的是對的事情——幫客戶提高效率。但'做對的事情'和'把事情做對'是兩回事。SaaS生意的關鍵是看NRR能不能持續提升，個人客戶92.3%的留存率說明產品還不夠'不可替代'。"

## 七、Bull vs Bear

### 🐂 Bull Case（樂觀情景）

1. **"空間智能"不止家居**：從室內設計擴展到商業空間、地產營銷、遊戲/VR場景，TAM擴大5-10倍
2. **AI增強而非替代**：自研AI引擎形成差異化，AI功能成為付費增長點
3. **國際化突破**：Coohom在海外攻下10-20%市場份額，收入翻倍
4. **房地產觸底反彈**：中國房地產回暖帶動家居設計需求恢復增長
5. **NRR持續提升**：大客戶NRR從110%提升至120%+，ARPU顯著增長

**Bull Case目標**：2028年收入15億元+，淨利潤2億元+，市值300億港元（~3x當前）

### 🐻 Bear Case（悲觀情景）

1. **增速天花板**：中國TAM有限，增速從8.6%繼續下滑至3-5%
2. **AI民主化衝擊**：通用AI使專用設計工具的護城河被侵蝕
3. **國際化燒錢**：海外擴張投入大但回報慢，拖累利潤
4. **房地產持續寒冬**：家居行業景氣度低迷3-5年
5. **老股東減持壓力**：上市6個月後迎來解禁潮，股價承壓

**Bear Case目標**：收入停滯在9-10億元，利潤微薄，市值縮水至50-70億港元
