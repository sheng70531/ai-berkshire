## 二、被推翻的論斷（詳細）

### 2.1 論斷一：「回購腰斬 = 論文破產」—— **推翻**

看空報告第 5.2 節的核心指控：

> 🔴 **從 FY25 的 $84 億到 FY27 指引的 $50 億，回購規模腰斬 41%。**

**這個指控用錯了計量單位。**

回購創造價值的機制是**註銷股份**，不是**花掉美元**。同樣一筆美元，在股價越低時買到越多股。Prosus 股價過去 12 個月跌了 28.6%——用美元衡量回購，等於用一把在縮短的尺子量東西。

#### 換成正確的單位：公司官網股本時序表（一手數據）

| 期間 | 期初淨 N 股（千股） | 期末淨 N 股 | **年化註銷率** |
|------|------------------|-----------|--------------|
| FY2025（2024-03-31 → 2025-03-31） | 2,494,181 | 2,280,206 | **8.58%** |
| FY2026（2025-03-31 → 2026-03-31） | 2,280,206 | 2,145,428 | **5.91%** |
| **FY2027 實測（2026-03-31 → 2026-08-07，129 天）** | 2,145,428 | 2,105,025 | **5.33%（年化）** |

**驗算（financial_rigor.py）**：
```
(2494181-2280206)/2494181*100 = 8.58
(2280206-2145428)/2280206*100 = 5.91
((2145428-2105025)/129*365)/2145428*100 = 5.33
```

**三個必須說清楚的結論：**

**（1）FY26→FY27 的減速是 -9.8%，不是 -41%。** 5.91% → 5.33%。看空報告把一個 10% 的減速講成了"腰斬"。

**（2）$50 億指引不是"未來的削減"，是"當下正在發生的實況"。** 年化註銷 114,319 千股 × €37.395 = €4.27bn = **$4.97bn**——與 CFO 說的 "$5bn" 幾乎精確吻合。也就是說，**指引已經在執行中，市場已經看到了它的效果，而當前的 38.29% 折價已經包含了這個速率。** 這不是"未來會變壞"，這是"現在就是這樣，而現在就是 38% 折價"。

**（3）$50 億在當前市值下是 5.46% 的年化回購率。** 對照：標普 500 的平均回購收益率約 2%，騰訊自身 2026 年約 1.5–2%。**Prosus 減速之後的回購強度，仍是全球上市公司中的頂格水平。**

#### 一個看空報告沒有意識到的凸性

回購增厚率的公式是 `a = f·d/(1−f)`，其中 f 是註銷比例、d 是折價。**在美元金額固定時，折價越闊，同樣的錢買到的股份佔比 f 越高，增厚率 a 越高。**

| 折價 d | $50 億對應的 f | **每股 NAV 年增厚 a** |
|--------|--------------|---------------------|
| 30% | 4.81% | **1.52%** |
| **38.29%（當前）** | **5.46%** | **2.21%** |
| 45% | 6.12% | **2.93%** |
| 51%（2022 峰值） | 6.87% | **3.76%** |

> **這意味著回購機器是一個負反饋系統：折價越走闊，機器創造價值越快。** 看空報告的三情景模型把增厚率設成"樂觀 3% / 中性 2.5% / 悲觀 1.5%"——**符號完全反了**。悲觀情景（折價 45%）對應的真實增厚率是 2.93%，不是 1.5%。

這是看空報告估值模型中唯一一處實質性建模錯誤。修正它之後（第七章），悲觀情景目標價從 €30.28 上修到 €31.17。

#### 我承認的部分

- 減速本身是真的。8.58% → 5.33% 是 **-38%** 的真實減速，只不過它發生在 FY25→FY26，不是 FY26→FY27。
- 減速的**原因**是資產負債表：淨現金 +$19 億 → 淨債務 -$64 億。這個約束是硬的（見 5.3）。
- $5bn 是 CFO 口頭指引，歷史上 Prosus 有超額執行的記錄，但**我無法驗證 FY27 是否會超額**。這是需要每週跟蹤的。

### 2.2 論斷二：「這是套利不是投資」—— **推翻**

看空報告 7.7 節的判詞：

> "它不是'買入並持有一家好公司'，它是'買入一個折價並等待折價收斂'。前者是投資，後者是套利。"

**這句話的前提是：折價不收斂，你就不賺錢。這個前提是錯的。**

#### 數學證明：折價恆定時，每股 NAV 仍在複利

設當前每股 NAV = n，股價 = P，折價 d = 1 − P/n。公司用現金回購並註銷 f 比例的股份：

```
回購後每股 NAV = (n − f·P) / (1 − f)
增厚率 a = f·(n−P) / [n·(1−f)] = f·d / (1−f)
```

當前：f = 5.33%，d = 38.29% → **a = 2.16%/年**。

**這個 2.16% 不需要折價發生任何變化就能拿到。** 它是把"別人願意用 62 分買你 1 塊錢資產"這件事，轉化成永久的每股價值。

#### 壓力測試：把所有多頭假設全部關掉

| 情景（5 年） | 假設 | **Prosus 回報** |
|------------|------|---------------|
| **地獄情景** | 折價永久鎖死 38.29%，**全部資產零回報**（騰訊 5 年不動、非騰訊 5 年不動） | **+11.3%**（2.16%/年） |
| **基礎情景** | 折價永久鎖死 38.29%，騰訊 +8%/年、非騰訊 +10%/年 | **+66.9%** |
| 同期直接持有騰訊 | 騰訊 +8%/年 | +46.9% |

**驗算**：
```
(60.60*(1.0216**5)*0.6171/37.395-1)*100 = 11.28    # 地獄情景
(60.60*(1.0845**5)*(1.0216**5)*0.6171/37.395-1)*100 = 66.94
(1.08**5-1)*100 = 46.93
```

> **在"折價一分錢都不收斂"的假設下，Prosus 5 年跑贏騰訊 20 個百分點。**
> 拆解：回購增厚貢獻 **16.9pp**，非騰訊資產的超額回報貢獻 **3.4pp**。

**這就是"套利 vs 投資"之爭的答案：套利需要價差收斂才兌現，而 Prosus 的核心回報來源在價差永不收斂時依然兌現。按定義，這是投資。**

#### 一個更硬的版本：即使非騰訊資產全部歸零

看空報告的 1.5 節做過"非上市資產歸零"的壓力測試，但它只算了靜態的地板折價（20%），**沒有算這個地板在回購下的動態演進**。

假設所有非上市資產（$328 億）+ 所有非騰訊上市資產（$76 億）全部歸零，只剩騰訊 - 淨債務：

- 每股淨騰訊價值 = €46.92 − €2.82 = **€44.10**
- 現價 €37.395 仍低於它 **15.2%**
- 回購增厚（全部靠賣騰訊出資）：`(44.10 − 0.0533×37.395)/(1−0.0533) = €44.48` → **+0.86%/年**

> **絕對地板：即使 Prosus 手裡除了騰訊什麼都沒有、還倒欠 69 億美元，回購依然以 +0.86%/年 的速度增厚你的騰訊敞口，而且這筆錢全部來自賣騰訊本身。**
>
> 原理很簡單：賣 €37.395 的騰訊，註銷掉一份索取 €44.10 騰訊的股權。**只要股價低於每股騰訊價值，賣騰訊回購自己就是淨增持騰訊。**

**這一條看空報告完全沒有觸及。** 它在 1.3 節算出了 €37.55 < €46.92 這個不等式，然後在 5.2 節算了回購，但**從未把兩者連起來**。

#### 關於"段永平買網易"這個類比

任務裡提到的這個類比，我認為**只有一半成立**。

- **成立的一半**：段永平買網易的核心是"用 1 億美元買到賬上 2 億美元現金 + 一個還在運轉的遊戲公司"，回報不依賴市場重新定價，而依賴**公司自己把價值兌現**。Prosus 的回購機器是同一個邏輯。
- **不成立的一半**：網易的現金是**無爭議的現金**；Prosus 的 22.6% 是**分析師一致預期標價的非上市資產**。而且段永平當時能判斷丁磊，Prosus 的實際控制人是一個已經證明會無視 71% 股東意見的體系。

**所以我不用這個類比作為論據。** 我用上面那個數學證明——它不需要任何類比。

#### 我承認的部分

看空報告 7.7 節那個"股市關閉 5 年"的思想實驗，**在一個特定條件下是對的**：如果回購停止，Prosus 的相對優勢歸零，而你還多背了代理成本。**所以"回購是否繼續"是這個論文唯一的生死線**，這一點看空報告說對了。區別在於：它把這條生死線判成已經斷了（"腰斬"），而實測數據顯示它沒斷（5.33% 年化，正在執行中）。

### 2.3 論斷三：「市場給非騰訊資產 -160 億美元估值」—— **推翻（作為"市場判斷"的讀法）**

看空報告 1.4 節稱這是"本報告最重要的單一數字"：

```
市值 $91.95bn − 騰訊 $114.90bn + 淨債務 $6.90bn = -$16.05bn
```

（按 €37.395 重算為 **-$16.43bn**，`2105.9e6*37.395/0.86/1e9-114.9+6.9 = -16.43`）

**這個數字在算術上正確，在推理上是偽像。**

#### 為什麼是偽像

這個減法隱含了一個從未被聲明的假設：**Prosus 持有的騰訊股票，應該按 100% 市場價計入 Prosus 的價值。**

這個假設站不住：

1. **22.66% 的戰略持股不是流通股。** 它在任何交易中都會承受 blockage discount。Prosus 自己四年來賣出 $68.7 億騰訊，都是通過大宗折價完成的。
2. **所有控股公司對上市持股都有折價。** Investor AB 折價 15–30%，Exor 類似，軟銀 40–60%。這個折價適用於**全部資產**，不是"上市部分零折價、非上市部分負估值"。
3. **反證**：如果把 -$16.43bn 反過來算——假設非騰訊資產真值 0，那麼市場對騰訊持股的折價就是 `1 − (91.57+6.9)/114.9 = 14.3%`。**14.3% 恰好落在戰略持股折價的常規區間內。** 也就是說，同一個市值可以完全用"騰訊持股打 14% 折 + 非騰訊資產值 0"解釋，也可以用"騰訊打 0 折 + 非騰訊值 -164 億"解釋。**看空報告選了後者，並稱之為"市場認為它倒欠 160 億"——這是把一個分配自由度當成了市場的意見。**

### 3.2 論斷六：「下行 Beta 1.19，折價與騰訊結構性正相關」—— **部分成立**

看空報告 8.2 節稱這是"最重要的實證發現"，且關聯的騰訊報告也把它列為選騰訊的第一理由。

**我承認的部分（這是硬證據，我攻不動）**：
- 12 個月實測：騰訊 -24.59%，Prosus -29.26%，Beta **1.19**
- 歸因模型解釋度 **97%**，殘差 0.97pp
- 折價走闊獨立貢獻 **-11.43%**

**我不承認的部分：從這裡推出"結構性不對稱"。**

#### 問題一：上行 Beta 從未被測量

看空報告的原話是"它在牛市裡給你 0.77 的 Beta，在熊市裡給你 1.19 的 Beta"。

**0.77 不是測量值，是結構假設**（騰訊佔 NAV 77.4% 推出來的）。整份報告只測了一個下跌窗口。**一個只觀察了下跌的樣本，不能得出"上漲時會怎樣"的結論。**

#### 問題二：現成的上行樣本存在，而且指向相反的方向

2022-06 → 2024-03 是天然的對照窗口。公司自己披露（看空報告 5.2 節引用）：

> "從回購啟動到 2024 年 3 月底，控股折價收窄 **21 個百分點**，釋放 US$30bn 價值。"

即折價從約 51% 收窄到約 30%，歷時 21 個月。

> ⚠️ **誠實標註**：我未能取到騰訊該期間的精確月度收盤價（stockanalysis 月線只返回近 3 個月，macrotrends 返回 403）。**此處只作方向性判斷，不作為量化證據。** 但方向本身是清楚的：折價在騰訊不漲甚至下跌的 21 個月裡收窄了 21pp。

**如果折價與騰訊真的是"結構性正相關"，2022-06 → 2024-03 這 21 個月不應該發生。**

#### 真正的解釋：折價跟的不是騰訊，是回購強度

把兩段窗口並列：

| 窗口 | 折價變化 | 同期回購註銷率 | 同期併購支出 |
|------|---------|--------------|------------|
| 2022-06 → 2024-03（21 個月） | **51% → 30%（-21pp）** | 約 8–9%/年 | 極少 |
| 2024-03 → 2026-08（29 個月） | **30% → 38.3%（+8.3pp）** | 8.58% → 5.33% | **FY26 單年 $80 億**（JET + Despegar + La Centrale） |

> **折價的驅動變量不是騰訊的方向，是"賣騰訊的錢有多大比例回到股東手裡 vs 被拿去做併購"。**
>
> 2022–2024：全部回購 → 折價壓縮 21pp。
> 2024–2026：一半回購一半併購 → 折價走闊 8.3pp。

這個解釋同時兼容兩段歷史，而"結構性正相關"只兼容一段。

**裁決：1.19 的測量成立，"結構性"的推論不成立。** 12 個月裡折價與騰訊同向，是因為那 12 個月恰好同時發生了騰訊下跌**和**回購減速+大額併購。這是兩個變量的重合，被當成了一個變量的規律。

## 五、三處看空報告說得不夠重的地方（我站在空方補充）

### 5.1 「騰訊自身回購抬升 Prosus 持股比例」被錯誤計入超額收益

看空報告 8.5 節把"騰訊自身回購被動抬升 Prosus 持股比例，約 +0.5–1%/年"列為 **Prosus 相對騰訊的超額收益來源之一，確定性"高"**。

**這是錯的。**

騰訊回購註銷時，市值下降但每股價格上升。Prosus 持有**固定股數**，其持股價值 = 股數 × 股價，漲幅與**直接持有騰訊的投資者完全相同**。持股**比例**上升是會計現象，不產生任何相對超額收益。

### 5.2 回購由賣騰訊出資，會稀釋 NAV 中的騰訊佔比

Prosus 用賣騰訊的錢回購全部 NAV 的索取權。這意味著：**NAV 中騰訊的權重會隨時間下降**，非騰訊資產的權重上升。

**看空報告在 3.3 節說到了這一點（"Prosus 主動在縮窄自己最寬的那條護城河"），但沒有把它量化為對 €1.25 敞口的侵蝕。** 我也做不到精確量化——**我未能取得 Prosus 歷年持有騰訊股數的時間序列**（NAV 頁只給當前值，年報只給持股百分比而騰訊自身股本在變）。**這是一個真實的、我承認的數據缺口。**

## 六、核心問題一：**在什麼條件下 Prosus 優於直接持有騰訊？**

> **這是任務要求的"可證偽條件"。我給一個單一變量、每週可驗證的答案。**

### 6.1 推導

設：
- `d0` = 買入時折價 = **38.29%**
- `d1` = 賣出時折價（唯一未知數）
- `a` = 每股 NAV 年增厚率 = **2.16%**（當前實測參數）
- 假設非騰訊資產回報 = 騰訊回報（中性假設，剔除資產選擇的影響）

則 Prosus 與騰訊的終期財富比：

```
Prosus / 騰訊 = (1+a)^n × (1−d1) / (1−d0)
```

令其 = 1，解出**盈虧平衡退出折價**：

```
d1_max = 1 − (1−d0) / (1+a)^n
```

### 6.2 結果：一張可以貼在屏幕上的表

| 持有期 | **盈虧平衡退出折價 d1_max** | 相對當前 38.29% 的緩衝 |
|--------|---------------------------|---------------------|
| 1 年 | **39.59%** | +1.30pp |
| **3 年** | **42.12%** | **+3.83pp** |
| **5 年** | **44.54%** | **+6.25pp** |
| **10 年** | **50.16%** | **+11.87pp** |

**驗算**：`(1-(1-0.3829)/(1.0216**n))*100`

### 6.3 可證偽條件（這就是答案）

> ### **持有 3 年，Prosus 優於騰訊的充分條件是：退出時折價 < 42.1%。**
> ### **持有 5 年：< 44.5%。持有 10 年：< 50.2%——即歷史最闊水位。**
>
> **注意這個條件裡沒有出現"折價收斂"四個字。折價可以走闊，只要走闊幅度小於閾值，Prosus 依然贏。**

**參照系**：
- 歷史區間：**30% – 51%**（2022-06 峰值 51%，2024-03 谷值 30%）
- 當前：38.29%
- 2026-03（今年最闊）：約 42%（第三方口徑）/ **42.8%**（公司 FY26 年報口徑）

> ⚠️ **對多頭不利的一條**：42% 在 **2026 年 3 月剛剛被觸及過**。3 年的盈虧平衡線 42.12% 不是一個遙遠的水位，是五個月前的實際水位。**這是這個論文最薄的地方，我不掩飾。**

### 6.4 三條會讓這個條件失效的事

| 失效路徑 | 後果 | 每週可否驗證 |
|---------|------|------------|
| **回購停止或降到年化 <3% 註銷** | a 歸零 → 盈虧平衡線塌回 38.29%，任何走闊都輸 | ✅ **官網股本表每週更新** |
| **再一筆 >€30 億併購** | 資金從回購轉出 + 重演 2024–26 的折價走闊 | ✅ 公告即時 |
| **非上市資產系統性下修 >30%** | NAV 分母縮水，"折價"本身是幻覺 | ❌ 需等半年報（2026-12） |

### 6.5 反向條件：什麼時候應該換回騰訊

**折價收窄到 25% 以下時。** 那時 d1 已經優於所有盈虧平衡線，套利部分已兌現，繼續持有等於承擔代理成本卻不再獲得補償。看空報告 9.2 節的這條賣出信號我完全同意。

| 2022-06 → 2024-03（21 個月） | 51% → 30%（**-21pp**） | **-1.0pp/月** | 註銷率 8–9%/年，**幾乎無併購** |
| 2024-03 → 2026-08（29 個月） | 30% → 38.3%（**+8.3pp**） | **+0.29pp/月** | 註銷率降至 5.3%，**FY26 單年併購 $80 億** |

**按註銷率線性縮放第一段**：-1.0pp/月 × (5.33/8.5) = **-0.63pp/月**。若 FY27 恢復"只回購不併購"，從 38.29% 到 30% 需要約 **13 個月**。

> ⚠️ **這個外推有明確缺陷**：折價與回購的關係不是線性的，第二段窗口本身就證偽了簡單外推（回購持續但折價走闊）。**我把它作為量級參考，不作為預測。**

### 7.2 我的概率分佈（主觀判斷，附依據）

**基準情形**：未來 36 個月，$5bn/年回購持續執行，無 >€30 億新併購。

| 事件 | 時間框架 | **我的概率** | 依據 |

| 折價 ≤ **25%** | 36 個月內 | **12%** | 歷史上從未持續低於 25–30% |
| 折價 **≤42.1%**（3 年盈虧平衡線） | 3 年後時點 | **65%** | 42% 在 2026-03 觸及過；但 38.29% 已是歷史 65–75 分位 |

> ⚠️ **這些是我的判斷，不是頻率統計。** 依據是兩段歷史窗口 + 回購速率 + 併購約束，樣本量為 2。**任何把這些概率當作可靠估計的人都會失望。**

### 7.3 一個更重要的觀察：收斂概率不是這個論文的關鍵

由第六章：**Prosus 只需要折價 <42.1%（3 年）就贏過騰訊。**

- 折價收斂到 30%：概率 30% → 回報極佳
- 折價停在 38.29% 不動：**依然贏騰訊 20pp（5 年）**
- 折價走闊到 42%：打平
- 折價走闊到 45%+：輸（概率 35% 觸及，但需在退出時點仍在該水位）

> **把注意力放在"折價會不會收斂"上，是這份論文最常見的誤配。真正的問題是"折價會不會走闊並停在 42% 以上"——那是一個概率約 30–35% 的事件，不是基準情形。**

### 8.2 聯合概率與我的裁決

四個一票否決項中，V1/V2/V3 是可估的：

```
0.75 × 0.80 × 0.60 = 36%
```

**但這個乘法是錯的，因為它們不獨立**（V3 失敗通常伴隨 V2 失敗；V1 與 L1 高度相關）。取相關性後我的估計約為 **40–45%**。

再疊加 L1（折價 <42.1%）：**約 30–35% 的概率"一切按多頭假設走"。**

### 8.3 我的裁決：**>10% 倉位在一種情況下成立，另一種情況下不成立**

#### ❌ 不成立：作為**獨立新增**的倉位

>10% 的獨立倉位要求上述條件的聯合成立，概率約 30–35%。**對一個 30–35% 概率的事件下 10% 以上的組合權重，不符合任何合理的凱利比例。**

而且看空報告有一條我完全同意：**這是一筆中國互聯網倉位，不是歐洲倉位。** 如果組合裡已有騰訊 + 美團 + PDD，再加 10% Prosus 是在已有集中上再集中。

#### ✅ 成立：作為**已有騰訊倉位的替代**

**這是我與看空報告分歧最大、也是我認為它最重要的一處誤配。**

看空報告和關聯騰訊報告都給出"替代比例不超過騰訊倉位的 1/3"。**這個 1/3 沒有推導，是一個感覺。**

正確的框架是把決策拆成兩個獨立問題：

```
決策 A：你要多少騰訊敞口？        ← 這是關於騰訊的問題
決策 B：用什麼工具表達這個敞口？   ← 只有這個問題與 Prosus 有關
```

**Prosus 只回答決策 B。** 而對決策 B，條件只有一個（第六章）：**退出時折價 <42.1%（3 年）。** 不需要 V1（騰訊好不好是決策 A 的事），不需要 L2/L3/L4（那些隻影響 22.6%）。

> **所以：如果你的決策 A 是"組合的 15% 放在騰訊敞口上"，那麼用 Prosus 表達其中 10pp——即一個 >10% 的 Prosus 倉位——只需要 V2（回購不停，80%）+ L1（折價 <42.1%，65%）成立，聯合概率約 **55–60%**，且賠率是"贏則 5 年多賺 20pp，輸則少賺個位數"。**
>
> **這是一個可以下的注。而"獨立新增 10% Prosus"不是。**

#### 我給的具體上限

| 情況 | **倉位建議** | 約束條件 |
|------|-----------|---------|
| 組閤中無騰訊敞口，考慮新建 | **≤5%** | 與看空報告一致。理由：V1 是你沒做過的功課，不該用 Prosus 順帶做 |
| 組閤中已有騰訊，考慮**替代** | **可到騰訊倉位的 50%，且 Prosus 絕對倉位 ≤12%** | 需 V2 + V3 + V4 + L1。**比看空報告的 1/3 更激進，因為我有第六章的推導而它沒有** |
| 組閤中已有騰訊，考慮**疊加** | **❌ 不要** | 與看空報告完全一致。這是加槓桿不是分散 |
| 已重倉中國互聯網（騰訊+美團+PDD） | **❌ 不引入** | 與關聯騰訊報告的倉庫結論一致 |

> **對本倉庫的直接含義**（持騰訊 6,600 股、美團 9,800 股、PDD 4,003 股）：**我的結論與關聯騰訊報告一致——不引入 Prosus。** 不是因為 Prosus 不好，是因為決策 A 已經飽和。**這不是對 Prosus 的否定，是對組合狀態的判斷。**
