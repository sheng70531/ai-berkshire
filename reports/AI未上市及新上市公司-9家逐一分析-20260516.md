# AI賽道9家公司逐一分析

> 分析日期：2026年5月16日 | 數據來源：公開財報、招股書、媒體報道

---

## 一、自動駕駛賽道

---

### 1. 小馬智行（Pony.ai）

| 維度 | 內容 |
|------|------|
| 基本信息 | 北京/廣州，2016年12月成立，創始人彭軍（前百度自動駕駛首席架構師）、樓天城 |
| 業務 | L4級Robotaxi、Robotruck、技術授權三大業務線。第七代Robotaxi已投入商業運營，廣州已實現單車運營盈利 |
| 融資/估值 | 納斯達克（PONY）+ 港股（02026）雙上市。市值約490億港元（約47億美元）。現金儲備105.93億元 |
| 競爭定位 | 國內L4自動駕駛商業化最快的公司，全球首家實現Robotaxi城市範圍單車盈利。2026年底車隊目標3000+輛，佈局全球20+城市 |
| 財務 | 2025年全年收入6.29億元（+20%）。Robotruck收入2.84億元，技術授權2.29億元。Q4首次單季盈利，淨利潤5.28億元（含投資收益） |
| 投資判斷 | ⭐⭐⭐⭐（4星）— 自動駕駛賽道商業化進度最快，單車盈利已驗證，但整體盈利仍依賴規模擴張，估值偏高需要時間消化 |

小馬智行是自動駕駛三家中商業化落地最紮實的。核心看點是第七代車已實現單車盈利，2026年底3000輛車隊的規模目標如果達成，將形成質變。風險在於：Robotaxi政策推進節奏不確定，以及L2+量產市場（Momenta的主場）的競爭壓力。47億美元市值對應6.29億元收入，PS約50倍，估值不便宜，但賽道天花板極高。現金儲備超105億元，不缺彈藥。納入MSCI中國指數是流動性利好。

### 2. 文遠知行（WeRide）

| 維度 | 內容 |
|------|------|
| 基本信息 | 廣州，2017年4月成立，創始人韓旭（前百度自動駕駛首席科學家） |
| 業務 | Robotaxi、自動駕駛小巴、無人環衛車、自動駕駛貨運，產品矩陣最寬。全球車隊2113輛，其中Robotaxi 1125輛 |
| 融資/估值 | 納斯達克（WRD）+ 港股雙上市。港股市值約222億港元。資金儲備71億元 |
| 競爭定位 | 產品線最全的自動駕駛公司，覆蓋Taxi/小巴/環衛/貨運四大場景。但"廣而不精"的風險也最大 |
| 財務 | 2025年全年收入6.85億元（+89.6%）。產品收入3.6億元（+310%），小巴收入2.31億元。淨虧損17億元（收窄34.2%），毛利率30.2% |
| 投資判斷 | ⭐⭐⭐（3星）— 收入增速亮眼但虧損仍大，產品線過於分散，預計2026年單車盈虧平衡、2028年公司整體盈虧平衡，等待時間較長 |

文遠知行的策略是"多場景覆蓋"，這與小馬智行聚焦Robotaxi形成對比。89.6%的收入增速看起來漂亮，但絕對數只有6.85億元，淨虧損仍達17億元。毛利率30.2%遠低於小馬智行，說明產品組閤中硬件收入佔比高、軟件授權佔比低。股價從高點12.55美元跌至8美元附近，市場對其商業化節奏存疑。華泰預計2028年才能整體盈虧平衡，意味著未來2年仍需持續"燒錢"。資金儲備71億元夠用但不算充裕。相比小馬智行，文遠的確定性更低。

### 3. Momenta

| 維度 | 內容 |
|------|------|
| 基本信息 | 北京/蘇州，2016年成立，創始人曹旭東（清華本碩、前微軟亞研院） |
| 業務 | "兩條腿"戰略：L2+量產智駕方案（主營）+ L4完全無人駕駛。已累計搭載近70萬輛車，170+款車型定點，與大眾、豐田、本田、奔馳、通用等深度合作 |
| 融資/估值 | 未上市，已港股秘密遞表，IPO估值預期超千億元（約140億美元）。累計融資12.5億美元。與Uber達成戰略合作 |
| 競爭定位 | L2+量產智駕方案的絕對頭部，車企合作數量和定點車型數量遠超同行。"飛輪"模式——用量產數據反哺L4，是最核心壁壘 |
| 財務 | 未公開。據報道2021-2023年累計虧損超175億元（含股權激勵等非經常性項目）。量產業務預計已有可觀收入，但具體數字待招股書披露 |
| 投資判斷 | ⭐⭐⭐⭐（4星）— 量產智駕賽道最強玩家，70萬輛上車量是數據飛輪的護城河，但IPO估值千億元級別偏貴，建議關註上市後定價 |

Momenta與前兩家最大的區別在於：它不是純L4公司，而是"L2+量產先行、L4長期佈局"。這意味著它有真實的、可規模化的收入來源（向車企賣智駕方案），而不是純粹依賴Robotaxi這個政策敏感的場景。70萬輛搭載量和170+車型定點，構成了數據和客戶雙重壁壘。與Uber的合作打開海外想象空間。核心風險是：華為、大疆等巨頭也在搶量產智駕市場，以及千億估值隱含了極高的增長預期。建議等IPO招股書披露後再判斷。

## 二、人形機器人賽道

---

### 4. 優必選（UBTECH）

| 維度 | 內容 |
|------|------|
| 基本信息 | 深圳，2012年成立，創始人周劍 |
| 業務 | 全尺寸人形機器人（Walker系列）為核心，同時有教育機器人、物流機器人等。Walker S已在工廠場景落地 |
| 融資/估值 | 港股上市（09880），市值約514億港元（約102港元/股）。歷史高點約280港元，跌幅超60% |
| 競爭定位 | "人形機器人第一股"，全尺寸人形機器人銷量和收入全球第一。但從教育機器人轉型而來，品牌認知需要重塑 |
| 財務 | 2025年總收入20.01億元（+53.3%），淨虧損7.90億元（收窄32%），毛利率37.7%。人形機器人收入8.2億元（+2204%），銷量1079臺 |
| 投資判斷 | ⭐⭐⭐（3星）— 人形機器人出貨量已驗證需求存在，但1079臺規模仍很小，單價高（約76萬元/臺）限制了放量速度，虧損收窄但未盈利 |

優必選最大的看點是"1079臺"——這是全球人形機器人領域第一個有真實出貨量的規模數字。8.2億元的人形機器人收入佔總收入41%，已超越教育機器人成為第一大業務。但冷靜看：1079臺對應76萬元/臺的單價，說明客戶主要是大型工業企業的試點項目，而非規模化採購。514億港元市值對應20億元收入，PS約20倍，考慮到人形機器人賽道的想象空間，估值不算離譜但也不便宜。核心變量是2026-2027年出貨量能否從千臺級躍升到萬臺級。預計2026-2027年收入分別28.84/37.92億元。

### 5. 銀河通用（Galbot）

| 維度 | 內容 |
|------|------|
| 基本信息 | 北京，2023年5月成立，創始人王鶴（北大助理教授，斯坦福博士，92年生） |
| 業務 | 具身智能通用機器人，核心產品Galbot G1（雙臂+單腿+輪式底盤）和重載機器人Galbot S1。已在寧德時代產線落地 |
| 融資/估值 | 最新一輪25億元融資（2026年3月），國家大基金三期領投。累計融資約8億美元，估值超30億美元 |
| 競爭定位 | 國內估值最高的具身智能創公司。與美團共建智慧藥房，與百達精工簽約1000臺部署計劃，走"實用優先、漸進式"路線 |
| 財務 | 未公開。成立不到3年，收入規模預計極小，處於燒錢投入期 |
| 投資判斷 | ⭐⭐⭐（3星）— 學術背景強、融資節奏快、落地場景務實，但30億美元估值對應的是幾乎沒有收入的初創公司，純信仰投資 |

銀河通用是人形機器人賽道的"新貴"。2023年成立、2026年估值已超30億美元，速度驚人。核心差異化在於：不追求"全人形"的雙足行走，而是採用輪式底盤+雙臂的實用設計，優先保證能"幹活"。這一策略使其更快在寧德時代等工業場景落地。與美團的股東關係帶來了零售場景的獨家資源。風險很明顯：成立不到3年，商業收入幾乎為零，30億美元估值全靠對未來的信仰。國家大基金三期的背書是加分項，但不改變"高估值+零收入"的本質。一級市場投資者的風險容忍度可以支撐，但如果計劃港股IPO，二級市場可能會更苛刻。

## 三、AI視頻/內容賽道

---

### 6. 愛詩科技（PixVerse）

| 維度 | 內容 |
|------|------|
| 基本信息 | 北京，2023年4月成立，創始人王長虎（前字節跳動視覺技術負責人、前微軟亞研院） |
| 業務 | AI視頻生成平臺PixVerse，支持文生視頻、圖生視頻。2026年初發布全球首個通用實時世界模型PixVerse R1 |
| 融資/估值 | 2026年3月完成3億美元C輪（亞洲AI視頻領域單筆最大），估值60-80億元人民幣（約10億美元） |
| 競爭定位 | 全球視頻生成第一梯隊，圖生視頻和文生視頻均排名全球第二。全球用戶破1億，MAU超1600萬，與上萬家企業合作 |
| 財務 | 未公開具體收入。會員訂閱+企業API為主要變現方式。處於高速增長但大概率虧損階段 |
| 投資判斷 | ⭐⭐⭐⭐（4星）— 全球頭部的AI視頻生成產品，用戶破億驗證了PMF，估值10億美元級別合理，但面臨可靈AI等強敵 |

愛詩科技是這9家公司中"性價比"最高的投資標的之一。理由：1）全球用戶破1億、MAU 1600萬，產品已驗證市場需求；2）估值約10億美元，遠低於可靈的200億美元，但產品能力在全球排名僅次於可靈；3）創始人王長虎有字節視覺技術的完整經驗，團隊執行力已通過融資節奏和產品迭代速度證明。核心風險是：AI視頻生成賽道的競爭極其激烈，可靈AI、Runway、Pika等都在快速迭代，技術壁壘可能不如想象中深。商業化路徑（To C訂閱 vs To B API）的選擇也將決定天花板。

### 7. 可靈AI（快手旗下 / 擬分拆）

| 維度 | 內容 |
|------|------|
| 基本信息 | 快手自研，2024年6月上線，快手創始人程一笑直接推動 |
| 業務 | AI視頻生成大模型Kling，支持文生視頻、圖生視頻、數字人等。已成為國內商業化變現規模最大的視頻生成AI應用 |
| 融資/估值 | 快手擬分拆可靈AI獨立融資，Pre-IPO輪估值約200億美元，融資20億美元，騰訊等有望參與。計劃明年獨立IPO |
| 競爭定位 | 國內AI視頻生成的絕對龍頭，ARR已達5億美元，大部分收入來自海外。技術力全球頂尖，快手的數據和算力是核心支撐 |
| 財務 | ARR 5億美元（較春節前翻倍），2026年Q1收入7500萬美元。2025年Q4單季營收3.4億元。付費用戶環比增長350% |
| 投資判斷 | ⭐⭐⭐⭐（4星）— ARR 5億美元是硬實力，但200億美元估值對應40倍PS，快手母公司市值才290億美元，分拆定價存在爭議 |

可靈AI是這9家公司中商業化做得最好的AI應用。ARR 5億美元、海外收入佔比高、付費用戶爆發式增長——這些數據在全球AI應用中都屬於頂級。核心爭議在估值：200億美元估值 vs 快手母公司290億美元市值，一個子業務佔了母公司七成，市場能否接受？從PS角度看，200億/5億=40倍，對於一個高增長AI應用來說不算離譜（Midjourney的隱含估值更高），但前提是ARR增速能維持。另一個風險是：分拆後可靈失去快手的數據和流量加持，獨立運營能力是否足夠？建議關注分拆融資條款和未來獨立財務數據。

### 8. 地平線（Horizon Robotics）

| 維度 | 內容 |
|------|------|
| 基本信息 | 北京，2015年7月成立，創始人餘凱（前百度深度學習實驗室主任，慕尼黑大學CS博士） |
| 業務 | 車規級智能駕駛芯片+軟件平臺。征程系列芯片為核心產品，征程6系列2026年全面放量。已累計出貨數百萬套 |
| 融資/估值 | 港股上市（09660），市值約1225億港元。年初至今漲幅132%，是2026年港股表現最亮眼的AI芯片股之一 |
| 競爭定位 | 國產車規級智駕芯片的絕對龍頭，唯一實現前裝量產的本土芯片商。與大眾、比亞迪、理想等深度綁定，征程6對標英偉達Orin |
| 財務 | 2025年收入37.6億元（+57.7%），毛利率64.5%。研發費用51.5億元，仍在虧損。2026年預計收入增長50%+，2027年預計扭虧 |
| 投資判斷 | ⭐⭐⭐⭐⭐（5星）— 9家公司中確定性最高的標的。國產智駕芯片替代是確定性趨勢，64.5%毛利率證明產品力，2027年盈利可期 |

地平線是這9家公司中我最看好的。原因：1）賽道確定性最高——中國汽車智能化是確定性趨勢，國產芯片替代是政策+市場雙重驅動；2）商業模式最好——芯片+軟件平臺的模式，64.5%毛利率遠超自動駕駛運營公司的30%；3）增長可見性最強——征程6系列已獲大量定點，2026年出貨量預計突破1000萬套；4）盈利路徑最清晰——2027年扭虧。1225億港元市值對應37.6億元收入，PS約25倍，考慮到芯片公司的可擴展性和50%+的增速，估值合理。核心風險是英偉達下一代芯片的降維打擊和華為昇騰的競爭。

### 9. 商湯科技

| 維度 | 內容 |
|------|------|
| 基本信息 | 上海/北京/香港，2014年10月成立，創始人湯曉鷗（2023年12月去世）、CEO徐立 |
| 業務 | 從傳統視覺AI轉型為生成式AI平臺。生成式AI（大模型訓練/推理/微調）為核心，視覺AI為輔。擁有大規模GPU算力集群 |
| 融資/估值 | 港股上市（00020），市值約700億港元（股價約2.1港元）。2026年4月配售新股融資32億港元 |
| 競爭定位 | "AI算力+大模型"雙輪驅動，生成式AI收入佔比超72%。但定位模糊——既做算力租賃，又做模型服務，又做行業應用，缺乏聚焦 |
| 財務 | 2025年總收入50.15億元（+32.9%），歷史新高。生成式AI收入36.3億元（+51%）。經調整淨虧損收窄58.6%，下半年EBITDA首次轉正3.8億元 |
| 投資判斷 | ⭐⭐⭐（3星）— 轉型方向正確，生成式AI增長快，但累計虧損超525億元的"包袱"太重，頻繁配售稀釋股東，信任成本極高 |

商湯是這9家中爭議最大的公司。樂觀面：50億收入創新高、生成式AI佔比72%、EBITDA首次轉正——轉型確實在發生。悲觀面：累計虧損超525億元、頻繁配售股份稀釋（最新32億港元）、創始人去世後團隊穩定性存疑。股價從歷史高點近10港元跌至2.1港元，市場用腳投票。高盛預測2026年扭虧為盈，但商湯過去多次"狼來了"，市場已經不太相信。700億港元市值對應50億元收入，PS約11倍，看起來不貴，但考慮到持續稀釋和盈利不確定性，這個估值並不算便宜。除非能看到連續2-3個季度的真實盈利，否則不建議重倉。
