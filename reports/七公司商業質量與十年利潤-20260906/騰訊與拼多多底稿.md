## 生意本質、護城河與文化

騰訊的獨特性在於用戶關係可以跨越內容生命週期：某款遊戲會衰退，但交流、支付、公眾號、小程序等場景仍能反覆發生。廣告主的付費理由是有效轉化，遊戲付費理由是內容體驗，雲和支付的理由是穩定服務；這些利潤源的資本要求與競爭程度不同。[公司Q2業務說明](https://www.prnewswire.com/apac/news-releases/tencent-announces-2026-second-quarter-results-302849608.html)

研究判斷：關係鏈的遷移成本高於內容平臺的時間粘性。朋友、工作聯繫和商家關係無法用一次補貼整體遷走，但用戶可以同時刷短視頻、使用其他AI應用。因此騰訊最強的是底層關係網絡，不是佔有用戶所有時間。遊戲護城河來自研發組合、IP、運營和分發；單款爆品仍需不斷維護。廣告護城河來自用戶場景與交易閉環，若效果改善低於競爭者，流量規模也保不住預算。

文化不能由“用戶為本”等口號直接證明。可觀察行為是：騰訊2025年現金回購及現金股息合計1108.47億元；產品仍持續迭代，並投入AI。前者是已發生的資本分配；後者的回報仍待驗證。Q2公司明確披露算力預付款顯著壓低現金流，研究上不能把這筆已付資金永久刪除。由此推斷它兼顧生態、研發和資本回報，但不預設每一筆長期投入都有效。[年報現金流表](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0409/2026040901231.pdf)、[Q2原始新聞稿](https://www.prnewswire.com/apac/news-releases/tencent-announces-2026-second-quarter-results-302849608.html)

騰訊最強反方：社交入口依然強，股東經濟性卻可能變弱。如果AI競爭把業務變成需要持續算力更新的重投入生意，即使收入和會計利潤增長，每元利潤對應的自由現金也可能減少。微信的“不可替代”不能自動證明新投資回報率足夠高。

PDD的付費客戶主要是商家。平臺聚合消費者需求，組織貨品供給，並以廣告和交易服務收錢；消費者重複購買的前提是到手價格、質量、交付和售後仍然有吸引力。海外擴張還要支付物流與合規成本。**“在線營銷＝國內、交易服務＝Temu”不是公司披露的分部口徑。**不能據此把國內和海外利潤算成已知事實。[2025年報業務及收入註釋](https://investor.pddholdings.com/static-files/92dafbdc-3125-4f2c-a28f-3d61203efbaf)

研究判斷：PDD的護城河主要是成本、交易數據和組織執行，不是消費者被鎖定。商家能否持續賺到錢是關鍵；如果必須靠更高補貼才能維持低價，或者商家支付推廣費後已無合理利潤，平臺的定價權就接近上限。規模收益長期需要在平臺、消費者、商家和履約網絡之間分配。

文化證據須雙面看。PDD持續擴展業務，管理層在Q2明確將商家生態投入置於當前重點，這是公司聲稱的優先級；報表中2025經營利潤率從2024的27.53%降至21.56%，證明成本與投入正在實際佔用利潤，但不能單憑這一下降證明投入成功或全部自願。年報表示目前無可預見現金分紅計劃，這使其資本回報可預測性弱於騰訊；不分紅本身也不足以證明損害股東，最終還應看留存資金的投資回報。[Q2管理層聲明與費用](https://investor.pddholdings.com/news-releases/news-release-details/pdd-holdings-announces-second-quarter-2026-unaudited-financial/)、[年報分紅政策與利潤表](https://investor.pddholdings.com/static-files/92dafbdc-3125-4f2c-a28f-3d61203efbaf)

PDD最強反方：低價電商的消費者忠誠可以屬於“便宜”而非PDD，競爭者拿出補貼就能分流；海外規模增長也可能僅擴大低毛利交易。大量合併現金與少數股東何時收到現金是不同問題。相比騰訊，PDD的經營能力較易觀察，長期利潤在國內、海外和股東之間如何分配更難觀察。

| 公司 | 可證偽觀察項 | 推翻目前判斷的方向 |
|---|---|---|
| 騰訊 | 微信使用頻次、商家轉化；長青遊戲及新品貢獻；廣告增長的價格/負載/效果來源 | 關係鏈穩定而業務轉化連續下降，說明流量優勢不能保持經濟價值 |
| 騰訊 | 算力投入、折舊、新增服務毛利、經常性利潤現金轉化 | 新增毛利長期無法覆蓋算力與研發投入，需降低稅後利潤率假設 |
| PDD | 同款到手價、復購、獲客和補貼成本、商家淨回報 | 低價依賴持續補貼且商家回報下降，成本優勢可能減弱 |
| PDD | 交易服務毛利與合規/履約成本；披露質量；留存現金的回報 | 收入增加但持續經營利潤下降，或者資本配置缺乏可驗證回報 |

這些是研究監測方向，並非目前都已具備可直接取得的公開時間序列。文化結論置信度低於報表數據。

## 2036年度利潤的業務驅動情景

統一公式為：**各業務收入基數×十年收入增長因子×2036年歸母經濟淨利率，加常態投資收益，減其他持續虧損。**淨利率已經負擔持續研發、股權薪酬、合理折舊攤銷、獲客、履約、總部費用分攤、利息及稅項和少數股東權益；不包含公允價值變動等一次性收益。負淨利率是稅後無稅盾的淨損失假設，不因虧損自動確認退稅或遞延稅收益。這是規範化稅後會計經濟利潤，尚未扣股權資本機會成本，不是EVA，也不等於可以全額派發的現金。

兩家都沒有披露以下分業務淨利率。它們只是把預測的驅動因素展開，避免一個淨利CAGR隱藏所有競爭與投入假設。2036應以主表約數閱讀，附錄小數僅用於重算。

### 騰訊

2026全年研究收入基數：VAS 3900億元、廣告1650億元、金融科技及企業服務2400億元。它們是全年規範化假設，參考2025全年及2026H1的已披露規模，**不是2026全年實際，也不是把H1全部機械翻倍**。2026淨利校核：`3900*0.32+1650*0.35+2400*0.16+200-100=2309.5`億元，可取約2300億元。

| 假設 | 悲觀 | 基準 | 樂觀 |
|---|---:|---:|---:|
| VAS收入年增速 / 2036經濟淨利率 | 0% / 25% | 6% / 32% | 8% / 36% |
| 廣告收入年增速 / 2036經濟淨利率 | 2% / 25% | 9% / 35% | 12% / 40% |
| 金融科技及企業服務收入年增速 / 2036經濟淨利率 | 0% / 12% | 6% / 18% | 9% / 22% |
| 常態淨投資收益 | 50 | 250 | 350 |
| 其他持續稅後虧損 | -100 | -50 | -50 |
| 三項業務2036收入合計 | 8311 | 15188 | 19226 |
| 2036經濟歸母淨利潤計算值 | 1715.84 | 4575.78 | 6630.96 |
| 主表取整數 | **1700** | **4600** | **6600** |

這裡的投資收益是歸屬騰訊的經常性被投企業稅後盈利份額估計，不再重複加同一筆盈利對應的股息，也不另加投資資產價值；各業務利潤率只覆蓋合併業務，未含該投資收益。騰訊持有其他被比較公司權益，**七家公司利潤不可直接相加**，否則可能重複計入穿透利潤。

悲觀是入口仍在但遊戲停滯、廣告僅溫和增長、AI投入侵蝕利潤率；基準要求長青遊戲與新品替換、廣告效果改善、支付和雲擴張，算力回報足以維持經濟淨利率；樂觀要求海外遊戲、閉環廣告與AI服務同時成功。AI服務的營業收入和成本已含各業務，不再額外加一筆“AI估值”或重複扣同一筆投入。

```text
悲觀 = 3900*1**10*0.25 + 1650*1.02**10*0.25 + 2400*1**10*0.12 + 50 - 100
基準 = 3900*1.06**10*0.32 + 1650*1.09**10*0.35 + 2400*1.06**10*0.18 + 250 - 50
樂觀 = 3900*1.08**10*0.36 + 1650*1.12**10*0.40 + 2400*1.09**10*0.22 + 350 - 50
```

### 拼多多

2026全年研究收入基數：在線營銷及其他2200億元、交易服務2350億元。這是合併披露的收費類別模型，**不是國內與Temu分部預測**。2026盈利校核：`2200*0.35+2350*0+80=850`億元；交易服務當前淨利率0%只是分攤成本後的研究假設，不能引用為Temu已經盈虧平衡。

| 假設 | 悲觀 | 基準 | 樂觀 |
|---|---:|---:|---:|
| 在線營銷及其他收入年增速 / 2036經濟淨利率 | 0% / 25% | 5% / 35% | 8% / 40% |
| 交易服務收入年增速 / 2036經濟淨利率 | -2% / -3% | 8% / 6% | 12% / 13% |
| 常態稅後淨利息收益 | 40 | 80 | 120 |
| 兩項業務2036收入合計 | 4120 | 8657 | 12048 |
| 2036經濟歸母淨利潤計算值 | 532.40 | 1638.66 | 2968.69 |
| 主表取整數 | **500** | **1600** | **3000** |

模型淨利率已將生態支持、合規、物流售後與日常補貼視為持續成本，不因管理層稱其“投入”而加回。收益中不含無法解釋的其他損益或公允價值收益。利息假設也不是將目前鉅額現金以現有收益率永久外推。

悲觀是國內收費停滯、交易服務規模收縮且持續虧損；基準是商家收益和供給質量穩定，交易規模增長而履約合規之後僅取得溫和利潤率；樂觀要求國際業務有更強的成本攤薄和本地經營能力，低價優勢延續但不以無限補貼維持。淨利潤是否能派發給股東仍由資金可及性和資本配置決定。

```text
悲觀 = 2200*1**10*0.25 + 2350*0.98**10*(-0.03) + 40
基準 = 2200*1.05**10*0.35 + 2350*1.08**10*0.06 + 80
樂觀 = 2200*1.08**10*0.40 + 2350*1.12**10*0.13 + 120
```

## 驗算、來源邊界及可複用文件

`騰訊與拼多多計算.py` 可重新調用 `tools/financial_rigor.py`：9項交叉核驗（8項年度/半年收入及歸母、另1項PDD現金），所有金額轉換、規範化橋接及情景計算。`騰訊與拼多多計算記錄.txt/json` 保留工具原文；`騰訊與拼多多Decimal復算.json` 用40位精度獨立重算。工具內部浮點尾差保留，不把尾差寫成報告金額精度；獨立復算殘差均小於0.0000001億元。

本次已實時重新讀取騰訊年度HKEX文件、半年HKEX公告、公司Q2新聞稿及兩家獨立數據庫；PDD年度官網PDF與半年原表也重新讀取。騰訊官網半年PDF超時，已用上述HKEX原件代替，未把超時頁面視為已驗證證據。獨立數據庫主要來自S&P Global，StockAnalysis與Capital IQ不能互相再充當兩個獨立來源；此處比較的是公司原件與獨立整理源。未驗證騰訊數據庫經營利潤的全部分類差異，故經營利潤只用官方表。

補充抽檢：已執行report_audit，固定樣本中兩項歷史事實為PDD半年收入與騰訊半年經營利潤；後者另由[財中社獨立報道](https://finance.eastmoney.com/a/202608123839209916.html)核驗。其餘抽樣屬於預測輸入、公式及明確約數的重算，已單列類型。工具PASS僅表示所抽樣本的來源或算式一致，絕不表示未來利潤已被證實。詳見同目錄審計樣本和判決文件。

結論：騰訊的關係網絡與盈利分佈，使其十年利潤可預測性優於PDD；PDD在低成本組織方面較強，但海外成本、商家分配及資本回報路徑帶來更寬的結果區間。這是商業質量判斷，不能單獨推出哪隻股票在今天價格更值得買。本底稿用於學習研究，預測置信度低於歷史報表核驗；文化判斷也不是對管理層人格的認證。
