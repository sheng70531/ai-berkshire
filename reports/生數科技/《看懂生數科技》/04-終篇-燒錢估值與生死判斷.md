# 燒錢、估值與生死判斷

## 先回答一個根本問題：AI視頻生成能賺錢嗎？

在討論生數科技值多少錢之前，必須先回答一個行業級問題：**AI視頻生成這門生意，到底能不能賺錢？**

Sora的數據給了一個令人不安的答案：

| 指標 | Sora的數據 | 來源 |
|------|-----------|------|
| 日均推理成本 | **1500萬美元** | Forbes、Cantor Fitzgerald |
| 總生命週期收入 | **210萬美元** | 媒體報道 |
| 單條10秒視頻成本 | 約**1.30美元** | 分析師估算 |
| 用戶留存 | 60天后趨近於**零** | 第三方數據 |
| 結局 | 2026年4月26日**停服** | OpenAI公告 |

**一天燒的錢比一輩子賺的錢還多。** 這是AI視頻生成賽道迄今為止最昂貴的失敗。

但Sora的失敗不等於整個賽道不行。它失敗的原因有其特殊性：

1. **定價過高**：Sora綁定ChatGPT Plus訂閱（$20/月），沒有獨立的靈活定價
2. **產品體驗差**：生成速度慢、成功率低、畫面一致性差
3. **戰略錯配**：OpenAI的核心是ChatGPT，Sora只是副產品，沒有得到足夠的產品化投入
4. **推理成本失控**：沒有針對視頻推理做充分的成本優化

**反方觀點**：可靈證明瞭AI視頻生成可以有收入——ARR已達5億美元。但可靈的盈利能力同樣未知，5億收入不等於能賺錢，毛利率可能為負。整個行業800多家公司，商業閉環不足兩成。

## 行業經濟學：推理成本是生死線

AI視頻生成的成本結構和傳統SaaS完全不同：

```
           傳統SaaS成本結構              AI視頻生成成本結構

        ┌──────────────────┐         ┌──────────────────┐
        │   固定成本(低)    │         │  模型訓練(極高)    │
        │  服務器、帶寬     │         │  GPU集群、數據     │
        ├──────────────────┤         ├──────────────────┤
        │  邊際成本(極低)   │         │  推理成本(高)      │
        │  每新增用戶≈0     │         │  每生成1秒視頻     │
        │                  │         │  都要消耗GPU算力   │
        └──────────────────┘         └──────────────────┘

        毛利率：70-80%                毛利率：可能為負
```

傳統SaaS的魅力在於邊際成本趨近於零——多一個用戶幾乎不增加成本。但AI視頻生成**每生成一段視頻都要消耗大量GPU算力**，邊際成本居高不下。

這意味著：**用戶越多，虧得越多**——除非單位推理成本能降到用戶付費能覆蓋的水平。

### 生數科技的成本困境

| 維度 | 情況 | 風險等級 |
|------|------|---------|
| GPU來源 | 外採為主（無自有大規模GPU集群） | 高 |
| 華為昇騰適配 | 已部分遷移至昇騰950PR | 中（緩解了部分芯片斷供風險） |
| API定價 | $0.0375/秒（比行業均價低55%） | 高（低價意味著毛利率更低） |
| 推理成本趨勢 | 硬件進步+算法優化將持續降低 | 利好（但降速未知） |

**生數科技大概率當前處於毛利率為負的階段。** 這在高速增長的創業公司中很常見，但關鍵問題是：**它有多少時間和資金等到推理成本降到盈虧平衡點？**

累計融資30億元人民幣，如果月燒錢速度在1-3億元級別（參考同類AI創業公司），現金跑道約10-30個月。**這就是為什麼兩個月內連融26億——不是太搶手，是真的需要錢。**

## 估值拆解：20億美元貴不貴？

### 硬數據

| 指標 | 數值 | 說明 |
|------|------|------|
| B輪投後估值 | 超**20億美元**（約140億元） | 2026年4月，Bloomberg等多源驗證 |
| 已知ARR | **2000萬美元** | 2025年初數據，Pandaily、量子位 |
| 基於已知ARR的PS | **100倍** | 20億/0.2億 |
| 假設2025年底ARR達2億美元的PS | **10倍** | 基於"10倍增長"推算，但未經審計 |
| 天使輪估值 | 1億美元 | 2023年6月 |
| 3年估值增長 | **20倍** | |

### 同行對比

| 公司 | 估值 | ARR | PS倍數 | 特點 |
|------|------|-----|--------|------|
| **生數科技** | 20億美元 | 2000萬美元 | **100倍** | 技術排名第二，但收入最少 |
| **可靈** | 200億美元 | 5億美元 | **40倍** | 收入最高，快手生態加持 |
| **Pika Labs** | 9-15億美元 | 約1.3億美元（2026年預計） | **7-12倍** | 同為獨立創業公司，ARR遠高於Vidu |
| **Runway** | 53億美元 | 未公開 | 未知 | 海外創作者首選之一 |

**關鍵發現**：

1. **基於2025年初ARR，PS 100倍在同行中最高**——這個價格定入了大量樂觀預期
2. **如果2025年底ARR確實達到2億美元，PS降至10倍**——低於可靈的40倍，看起來合理。但"2億美元"是基於公司自行披露的"10倍增長"推算，沒有審計數據
3. **Pika Labs的ARR已經是Vidu的6.5倍，但估值只有Vidu的一半到同等水平**——這說明市場對Vidu的估值中包含了技術溢價和中國市場溢價

## 反向推算：20億美元隱含了什麼預期？

用反向DCF（貼現現金流）思路看，20億美元的估值需要什麼條件來支撐：

**假設條件**：
- VC要求年化回報率**20%**
- 5年後以**15倍PS**退出

**則5年後需要的ARR** = 20億 x (1.2^5) / 15 = 約**3.3億美元**

從2000萬美元增長到3.3億美元，5年需要增長**16.5倍**，對應年複合增長率約**75%**。

| 情景 | 假設 | 5年後ARR | 達成難度 |
|------|------|---------|---------|
| 樂觀 | 年增100%+ | 5億+美元 | 需要連續5年翻倍，可靈當前水平 |
| 中性 | 年增50% | 約1.5億美元 | 增速逐年放緩，未達退出估值要求 |
| 悲觀 | 年增20% | 約5000萬美元 | 大廠擠壓+商業化不力 |

**結論：20億美元的估值需要年增75%持續5年才能給VC賺到合理回報。這不是不可能，但在大廠夾縫中實現這個增速，挑戰巨大。**

## 三種情景估值

| 情景 | 2028年ARR假設 | PS倍數 | 對應估值 | vs當前估值 | 概率判斷 |
|------|-------------|--------|---------|-----------|---------|
| **樂觀** | 5億美元 | 20倍 | 100億美元 | +400% | 20% |
| **中性** | 2億美元 | 12倍 | 24億美元 | +20% | 50% |
| **悲觀** | 5000萬美元 | 5倍 | 2.5億美元 | -87.5% | 30% |

**幾個關鍵點**：

1. **樂觀情景（+400%）** 需要：AI視頻市場爆發 + Vidu保持技術前二 + B端大客戶規模化 + 成功IPO
2. **中性情景（+20%）** 意味著：當前估值基本合理，沒什麼安全邊際
3. **悲觀情景（-87.5%）** 的觸發條件：大廠價格戰 + 開源追平閉源 + 商業化持續不力

**30%的概率虧損87.5%** —— 這個風險回報結構說明：20億美元的定價對普通投資者來說**沒有足夠的安全邊際**。

## IPO定價猜想

生數科技2026年3月已完成股改，港股IPO可能在2026下半年到2027年之間啟動。

### 港股對AI公司的態度

| 參考案例 | IPO前估值 | IPO後表現 | 啟示 |
|---------|---------|---------|------|
| MiniMax | 約100億美元 | 需觀察 | 港股對AI公司估值偏保守 |
| 商湯科技 | IPO市值約1400億港元 | 上市後市值大幅縮水 | 港股不吃"純技術故事" |
| 快手 | IPO時期市值曾超萬億港元 | 隨後腰斬再腰斬 | 二級市場的估值邏輯與一級市場完全不同 |

**港股投資者更看重盈利能力和現金流，而非技術故事。** 生數科技如果以20億美元+的估值IPO，需要展示出清晰的商業化路徑和經審計的財務數據。

**可能的IPO定價區間**（純推測）：
- 如果2026下半年IPO：可能圍繞B輪估值（20億美元）上下波動，取決於當時的市場情緒
- 如果2027年IPO：取決於屆時的ARR水平。如果ARR達到3-5億美元，估值有可能上行；如果ARR停滯，可能面臨估值折讓

## 風險清單：什麼能殺死這家公司

| 風險 | 概率 | 影響 | 說明 |
|------|------|------|------|
| **大廠碾壓** | 高 | 致命 | 可靈ARR是Vidu的25倍，字節資本開支2000億。大廠可以長期虧錢搶市場 |
| **商業化不及預期** | 中高 | 嚴重 | 行業80%+公司未實現商業閉環，Sora的教訓就在眼前 |
| **開源模型侵蝕定價** | 中 | 嚴重 | 阿里Wan 2.2、騰訊HunyuanVideo等開源模型快速接近閉源質量，API定價空間被壓縮 |
| **IPO失敗或估值縮水** | 中 | 嚴重 | 港股對AI公司估值偏保守，一級市場的20億美元不等於二級市場認可 |
| **燒錢耗盡現金** | 中 | 致命 | 推理成本高企+低價策略，現金消耗速度可能快於融資速度 |
| **芯片斷供** | 中 | 中等 | 華為昇騰部分緩解，但訓練端仍有差距 |
| **核心人才流失** | 低 | 中等 | 朱軍保持清華教職（精力分散），駱怡航剛空降（磨合風險） |
| **地緣政治** | 低 | 嚴重 | Vidu海外收入佔比高，TikTok式限制可能影響海外業務 |

**最大的風險不是某一項，而是多項風險同時發生的可能性。** 大廠碾壓 + 商業化不力 + 開源追平 三者疊加的概率不低，一旦同時發生，結果是毀滅性的。

## 什麼信號值得關注

不管你是一級市場投資者、準備打新的散戶、還是純粹對AI賽道感興趣的觀察者，以下信號值得持續跟蹤：

### 積極信號（加分）

| 信號 | 為什麼重要 |
|------|-----------|
| 經審計ARR確認超**2億美元**且增速維持100%+ | 驗證收入增長的真實性 |
| 在阿里雲生態內實現規模化B端收入 | 證明B端路徑可行 |
| 推理成本公開數據顯示毛利率轉正 | 證明商業模式可持續 |
| 成功IPO且估值合理（PS 15-20倍） | 二級市場認可 |
| Vidu下一代模型繼續保持全球前二 | 技術壁壘未被追平 |

### 危險信號（減分）

| 信號 | 為什麼危險 |
|------|-----------|
| 連續兩個季度收入增速低於**50%** | 增長引擎熄火 |
| 可靈或即夢推出大規模價格戰 | 獨立公司無法承受 |
| 核心管理層（朱軍/鮑凡/駱怡航）離職 | 人才引力場消失 |
| IPO持續延期 | 可能說明財務數據不夠好看 |
| 又一輪融資但估值持平或下降 | 一級市場信心動搖 |

## 總結：生數科技的三層真相

看完整個系列，生數科技的畫像可以用三層來概括：

**第一層（最確定）：技術很強。** U-ViT原創架構、Vidu Q3全球評測前二、清華頂級團隊——這些都是經過第三方驗證的事實。

**第二層（有分歧）：商業化很難。** ARR只有2000萬美元、面對25倍收入差距的可靈和無限彈藥的即夢、行業80%公司虧損——技術領先能否轉化為商業成功，目前沒有答案。

**第三層（最不確定）：估值很貴。** PS 100倍（基於已知ARR）定價了大量樂觀預期，安全邊際不足。除非2025年底ARR確實達到2億美元（PS降至10倍），否則當前估值對投資者不友好。

**一句話總結**：

> **生數科技是一家擁有全球前二技術的AI視頻生成創業公司，面對的核心問題不是"技術夠不夠強"，而是"在大廠碾壓和燒錢競賽中，獨立創業公司能不能活到盈利那一天"。**

這個問題沒有標準答案。答案取決於AI視頻市場的增長速度、推理成本的下降曲線、阿里雲生態的協同深度、以及駱怡航能否在12個月內把商業化做起來。
