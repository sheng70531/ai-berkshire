# 技術很強，但技術不是護城河

> 《看懂生數科技》系列 · 第 02 篇
> 閱讀時間約 12 分鐘

---

## 從一篇論文說起

2022年9月，清華大學朱軍團隊的博士生鮑凡發表了一篇論文，提出了**U-ViT架構**——全球第一個將擴散模型（Diffusion Model）與Transformer深度融合的架構設計。

這篇論文獲得了ICLR 2023傑出論文獎（全球頂級AI會議，獲獎率不到1%）。

為什麼這篇論文重要？因為它比OpenAI的DiT（Diffusion Transformer，Sora的技術底座）**早了整整一年**。換句話說，Sora的核心架構思路，清華團隊更早地走通了。

這就是生數科技的技術起點：**不是在別人的技術上做改良，而是擁有原創的架構底座。**

## Vidu的技術路線：一張圖說清楚

```
             Vidu 技術架構（簡化版）

   輸入                  模型層                   輸出
┌────────┐         ┌──────────────┐         ┌────────┐
│ 文字   │         │              │         │        │
│ 圖片   │ ──────▶ │   U-ViT架構   │ ──────▶ │  視頻  │
│ 參考圖 │         │ (Diffusion +  │         │ +音頻  │
│ 音頻   │         │  Transformer) │         │        │
└────────┘         └──────────────┘         └────────┘
                          │
                   ┌──────┴──────┐
                   │  核心特性    │
                   │             │
                   │ · 統一架構   │
                   │ · 多模態輸入 │
                   │ · 長時序建模 │
                   │ · 音畫同出   │
                   └─────────────┘
```

簡單說：

- **傳統視頻生成**：分別訓練文字理解模型和視頻生成模型，再拼在一起。效果像兩個不同母語的人合作寫作文，經常"牛頭不對馬嘴"
- **U-ViT架構**：把文字理解和視頻生成統一在一個架構裡端到端訓練。效果像一個人同時理解文字和畫面，輸出更連貫

這個架構優勢在早期產品中體現為：**角色一致性好、運動連貫性強、對複雜場景的理解更準確。**

## Vidu的產品矩陣

截至2026年5月，Vidu的產品線已經從單一的"文生視頻"擴展到多個方向：

| 產品 | 功能 | 定價 | 目標用戶 |
|------|------|------|---------|
| **Vidu SaaS** | 文生視頻、圖生視頻、參考生視頻 | 免費/$9.99月起 | C端創作者 |
| **Vidu API/MaaS** | 開發者調用視頻生成能力 | 約$0.0375/秒 | B端開發者 |
| **Vidu Agent** | AI視頻創作智能體 | 未公開 | 專業創作者 |
| **Vidu Claw** | AI廣告視頻生成 | 百元級/廣告片 | 廣告主 |
| **Vidu App** | 移動端視頻生成 | 同SaaS定價 | 移動端用戶 |

**API定價值得單獨說一下**：Vidu的API價格約$0.0375/秒，比行業均價$0.084/秒低**55%**。

這個定價策略傳遞的信號很明確：**用低價換市場份額**。在當前階段，生數科技選擇的是"先跑量，後提價"的互聯網打法。

但反方觀點同樣有力：**低價是因為沒有定價權。** 如果用戶因為便宜才來，那誰更便宜他們就去誰那裡。這不是護城河，是價格戰。

## 護城河分析：五個維度逐一拆解

技術強不等於有護城河。我們用經典的五維度框架來評估：

### 1. 品牌與定價權：★★☆☆☆（弱）

- API定價比行業均價低**55%**——這說明它在**買市場**，不是在**賣品牌**
- 在專業創作者圈子有一定認知，但C端聲量遠不及可靈和即夢
- 沒有形成"用Vidu = 專業"的品牌心智

### 2. 轉換成本：★★☆☆☆（弱）

- C端用戶可以零成本切換到可靈、即夢、Runway等競品
- B端API客戶有一定集成成本（對接文檔、工作流適配），但不構成強鎖定
- 積分制預付費能製造一點點粘性，但本質上是弱鎖定

### 3. 網絡效應：★☆☆☆☆（極弱）

- 視頻生成是**工具型產品**，用戶之間幾乎沒有網絡效應
- 不像微信（越多人用越離不開）或淘寶（越多賣家越吸引買家）
- 這是AI工具類產品的通病，不只是生數科技的問題

### 4. 規模效應：★★★☆☆（中等）

- 模型訓練是高固定成本，用戶量越大推理邊際成本越低
- **但規模劣勢明顯**：字節跳動2025年資本開支**2000億元**，快手可靈背靠快手自有算力——生數科技的算力規模無法與之相比
- 規模效應存在，但在這個賽道里，獨立創業公司的規模永遠追不上大廠

### 5. 技術/專利壁壘：★★★★☆（較強）

- U-ViT原創架構，**65項專利**
- 鮑凡的ICLR傑出論文獎，朱軍的IEEE Fellow身份
- Vidu Q3在Artificial Analysis評測中全球前二

**但這是生數科技護城河中最脆弱的一項——因為技術壁壘在AI領域的衰減速度極快。**

## 技術壁壘的保鮮期：6-12個月


AI領域有一個殘酷的規律：**今天的技術突破，6-12個月後就會被追平。**

歷史證據：

| 技術突破 | 首發方 | 被追平時間 |
|---------|-------|-----------|
| GPT-4（大語言模型） | OpenAI（2023年3月） | Claude 3.5 Sonnet約18個月後追平 |
| Stable Diffusion（圖像生成） | Stability AI（2022年8月） | 6個月內多家開源模型追平 |
| Sora（視頻生成） | OpenAI（2024年2月發佈demo） | 可靈、Vidu等12個月內達到接近水平 |
| DiT架構 | U-ViT（2022年9月）→ OpenAI DiT（2023年） | 全行業已統一採用 |

U-ViT架構本身就是一個例子：它提出後不到一年，這個思路就被整個行業吸收。現在所有主流視頻生成模型都採用類似的Diffusion+Transformer架構。**原創者的先發優勢，已經被行業的快速跟進消化了大部分。**

生數科技目前的技術優勢更多體現在**工程化能力**（把架構優勢轉化為產品體驗的速度）和**持續迭代能力**（每一代模型的提升幅度），而非架構本身的獨佔性。

**看多派會說**：技術壁壘雖然衰減快，但生數科技的團隊能持續跑在前面——朱軍的學術能力保證了方向判斷，鮑凡的執行力保證了工程落地。

**看空派會說**：技術壁壘快速衰減 + 大廠有10倍以上的算力優勢 = 技術領先維持不了多久。開源模型（阿里Wan 2.2、騰訊HunyuanVideo）正在快速接近閉源模型的質量，一旦開源追平閉源，API定價將歸零。

**兩邊都有道理。** 技術壁壘是生數科技當前最強的護城河，但也是最脆弱的。它的價值不在於"現在很深"，而在於"能不能持續挖深"——這取決於團隊在接下來每一代模型上能否保持全球前二的水平。

## 65項專利：能保護多少？

專利在AI領域的保護力度值得打個問號。

**有利的一面**：
- 65項專利覆蓋了U-ViT架構及相關技術
- 在B端大客戶談判中，專利組合是一種信號（"我們有自主知識產權"）
- 如果未來涉及專利許可，這是潛在的收入來源

**不利的一面**：
- AI領域的專利繞過（workaround）相對容易——改幾個模塊設計就可以規避
- 中國AI公司之間很少互相打專利戰
- 開源模型不受專利限制——阿里可以用完全不同的架構達到類似效果

**結論：專利更多是防守工具（防止被抄襲時有法律追索權），而非進攻武器（不能阻止競品出現）。**

## 護城河趨勢判斷

| 時間維度 | 判斷 | 理由 |
|---------|------|------|
| 過去2年 | **拓寬** | 從零到全球技術排名第二，用戶突破4000萬，建立了技術和品牌的初始積累 |
| 當前 | **承壓** | 可靈、即夢快速追趕，開源模型侵蝕定價空間，技術同質化加劇 |
| 未來5年 | **高度不確定** | 取決於能否建立"技術之外"的護城河——B端生態粘性、數據飛輪、平臺化能力 |

一個直白的比喻：生數科技的護城河更像是**一條正在融化的冰河**——現在看著還在，但如果不持續補充新的冰（新技術突破、B端深度綁定、生態鎖定），它會越來越淺。
