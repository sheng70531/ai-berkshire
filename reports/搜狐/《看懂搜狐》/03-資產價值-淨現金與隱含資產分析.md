# 資產價值——淨現金與隱含資產分析

## 算一筆賬

賬上 12 億美元的現金，到底有多少是"真正屬於股東的"？這是看懂搜狐估值的核心問題。VIE 結構、境內資金出境成本、持續的經營虧損——每一項都會打折。這一篇把每個折扣量化，再把各部分資產加總，給出一個儘量保守的估算區間。

---

## 一、淨現金：12 億美元的細節

### 1.1 現金構成（截至 2025 年 12 月 31 日）

| 項目 | 金額（百萬美元） | 說明 |
|------|---------------|------|
| 現金及等價物 | **$128** | 隨時可用 |
| 短期投資 | **$702** | 理財產品、定期存款等 |
| 長期定期存款 | **$351** | 期限較長，流動性稍差 |
| **現金+投資合計** | **約 $1,181** | 來源：2025 年報 |
| 總有息負債 | **$36** | 極低 |
| **淨現金** | **約 $1,145** | 保守口徑 |

來源：搜狐 2025 年報、StockAnalysis

截至 2026 年 Q1（3 月 31 日），總流動性仍維持在**約 $12 億**水平（來源：Q1 2026 財報 PR Newswire）。回購消耗的現金被遊戲業務的經營性現金流和利息收入大致補回。

### 1.2 對比市值

| 指標 | 數值 |
|------|------|
| 當前市值（2026 年 5 月） | **約 $3.6 億** |
| 淨現金 | **約 $11.5 億** |
| 淨現金 / 市值 | **約 3.2 倍** |
| 每股淨現金 | **約 $44**（按 26M ADS） |
| 當前股價 | **約 $14** |
| **股價僅相當於每股淨現金的 32%** | |

**你花 1 塊錢買入搜狐，賬上對應 3.2 塊錢的淨現金。** 不算業務的任何價值。

這種極端折價在全球上市公司中極為罕見——通常只出現在瀕臨破產的公司、面臨重大訴訟的公司、或者治理結構極差的公司。搜狐不屬於前兩種，但第三種值得討論（下一篇展開）。

## 二、12 億美元現金的"打折項"

12 億美元聽起來很多，但不能全部按面值計算。以下是需要"打折"的因素：

### 2.1 境內資金出境成本

搜狐的絕大部分現金以人民幣形式存放在中國境內的 VIE 實體中。要把錢分給在開曼群島註冊的上市主體（進而分給股東），需要走以下路徑：

```
VIE 實體 → 分紅給 WFOE → 匯出到 HK/Cayman → 分紅給股東
```

每一步都有成本：
- **預提所得稅**：VIE 利潤分紅給境外主體需繳 **10%** 預提稅
- **外匯管制**：需國家外匯管理局審批，大額匯出有配額限制
- **時間成本**：整個流程可能需要數月甚至更長

### 2.2 業務持續虧損的消耗

搜狐的媒體/視頻業務每年在虧損，暢遊雖然盈利但扣除母公司層面的管理費用後，整體 Non-GAAP 仍在虧損：

| 年份 | Non-GAAP 淨虧損 |
|------|----------------|
| 2023 | -$0.66 億 |
| 2024 | -$0.83 億 |
| 2025 | -$0.51 億 |

來源：搜狐各年財報

**好消息是虧損在收窄**（從 $0.83 億減到 $0.51 億，改善 40%），但仍在虧。按 $0.5 億/年的消耗速度，**12 億美元的現金理論上可以"燒" 24 年**——時間不是緊迫問題。

**但反過來想**：如果每年虧 $0.5 億、回購/分紅 $1-2 億，5 年後現金會從 12 億降到 4-5 億——折價優勢會被時間侵蝕。

### 2.3 調整後的"可分配淨現金"估算

| 項目 | 金額 | 說明 |
|------|------|------|
| 賬面淨現金 | $11.5 億 | |
| 減：預提稅（10%） | -$1.15 億 | 分紅出境時繳納 |
| 減：3 年經營虧損準備 | -$1.5 億 | 按年均 $0.5 億 |
| 減：私有化/清算交易成本 | -$0.5 億 | 律師、投行、SEC 合規 |
| **調整後可分配淨現金** | **約 $8.4 億** | |
| **每股調整後淨現金** | **約 $32** | 按 26M ADS |
| **當前股價 / 調整後每股淨現金** | **約 44%** | 仍然不到一半 |

**即使做了最保守的調整，搜狐的股價仍然只有調整後每股淨現金的 44%。** 這個折價仍然是極端的。

## 三、暢遊遊戲的隱含價值

### 3.1 暢遊在搜狐市值中的"隱含估值"

搜狐市值 = 暢遊價值 + 媒體/視頻價值 + 淨現金 - 折價

如果反推：

| 假設 | 推算 |
|------|------|
| 搜狐市值 | $3.6 億 |
| 減：淨現金 | -$11.5 億 |
| **暢遊 + 媒體的隱含估值** | **-$7.9 億** |

**市場給搜狐經營業務的隱含估值是負 $7.9 億。** 這意味著：市場不僅認為暢遊不值錢，還認為這些業務是"負擔"——它們會消耗現金、拖累價值。

### 3.2 暢遊獨立來看值多少？

| 估值方法 | 估值範圍 | 邏輯 |
|---------|---------|------|
| **運營利潤倍數** | $11.9-19 億 | $2.37 億運營利潤 × 5-8 倍 |
| **收入倍數** | $7.6-15.2 億 | $5.06 億收入 × 1.5-3 倍 |
| **暢遊私有化參考** | 約 $5.79 億 | 2020 年總對價，來源：暢遊私有化公告 |
| **給 TLBB 一個"壽命折扣"** | $5-10 億 | 如果 IP 還剩 5-7 年強變現期 |

來源：暢遊私有化公告、搜狐財報、行業可比公司

**合理中位估值：$8-12 億**（注：私有化參考值 $5.79 億系當年少數股東收購對價，不代表暢遊整體估值上限）

**反方觀點**：TLBB 是一個 2007 年的端遊 IP，MAU 在下滑，不應給太高倍數。如果用"衰退期遊戲公司"標準，3-5 倍運營利潤更合理，對應 $7.1-11.9 億。

**反方的反方**：暢遊的運營利潤率 47% 非常健康，2025 年新版 TLBB Return 證明 IP 仍有翻新能力，不應按"瀕死"估值。

綜合來看，**$8-12 億是一個兩方都能接受的區間**。

## 四、其他隱含資產

### 4.1 搜狐大廈

搜狐總部位於北京中關村科技園區（搜狐網絡大廈+搜狐媒體大廈）。2019 年人民日報曾報道"搜狐市值不如搜狐大廈值錢"。

| 項目 | 估算 |
|------|------|
| 搜狐網絡大廈 + 搜狐媒體大廈 | 位於海淀區中關村 |
| 北京核心區寫字樓估值參考 | 約 3-6 萬元/平方米 |
| 搜狐辦公面積（估） | 數萬平方米 |
| **粗略估值** | **$1-3 億**（不確定度高） |

來源：人民日報 2019 年報道、北京寫字樓市場參考

**注意**：搜狐大廈的具體估值數據不夠精確，這裡僅作參考。部分面積可能是租賃而非自有。

### 4.2 搜狐品牌 + sohu.com 域名

"搜狐"作為中國最早一批互聯網品牌，仍有一定的品牌殘值。sohu.com 域名本身也有價值。

粗略估計：品牌 + 域名合計 **$0.5-2 億**。但這類無形資產很難單獨變現，除非被收購。

### 4.3 利息收入

12 億美元現金以 3-4% 的年化收益率理財，每年產生約 **$3,600-4,800 萬**的利息收入。這是一筆"隱性收入"——不算在主營業務裡，但實實在在補貼了虧損。

## 五、分部加總估值（Sum-of-the-Parts）

| 資產 | 保守估值 | 合理估值 | 樂觀估值 |
|------|---------|---------|---------|
| 淨現金（調整後） | $8.4 億 | $9.5 億 | $11.5 億 |
| 暢遊遊戲 | $5 億 | $10 億 | $15 億 |
| 媒體/視頻 | $0 | $0 | $1 億 |
| 不動產+品牌 | $1 億 | $2 億 | $4 億 |
| **合計** | **$14.4 億** | **$21.5 億** | **$31.5 億** |
| 當前市值 | $3.6 億 | $3.6 億 | $3.6 億 |
| **折價率** | **75%** | **83%** | **89%** |

**即使按最保守的估值（$14.4 億），搜狐的市值仍然只有合理價值的 25%。**

## 六、為什麼折價如此極端？

如果搜狐的資產價值遠超市值，為什麼市場不給合理定價？

答案是：**市場不是不知道搜狐有錢，而是不相信這些錢能到達股東手中。**

折價的根本原因有四個：

| 原因 | 權重 | 說明 |
|------|------|------|
| **1. VIE + 境內資金鎖定** | 高 | 12 億現金大部分在中國境內，分紅匯出有稅費和管制 |
| **2. 管理層折價** | 高 | 張朝陽歷史上不重視股東回報，戰略嗅覺弱 |
| **3. 業務無增長** | 中 | 所有主業都在萎縮，沒有"看點"吸引資金 |
| **4. 中概股小盤股困境** | 中 | 日均成交量低、被剔出主流 ETF、機構無法建倉 |

**反方觀點（看多派會說）**：2025 年搜狐完成了 $1.5 億回購計劃，管理層已經在改變。如果持續回購，折價會逐步收窄。

**這個反方是有力的**——事實上，2025 年的回購是搜狐近年來最重要的正面變化。$1.5 億回購佔市值的 30-40%，信號很強。但關鍵問題是：**這是一次性的，還是持續的政策？** 截至目前，搜狐尚未宣佈新的回購計劃。

## 七、清算情景：如果搜狐今天關門，股東能拿回多少？

這是一個極端思維實驗，但對理解搜狐的"底價"很有用：

| 步驟 | 金額 |
|------|------|
| 變現淨現金 | $11.5 億 |
| 減：預提稅 10% | -$1.15 億 |
| 變現暢遊（折價出售） | $5-8 億 |
| 變現不動產+品牌 | $1-2 億 |
| 減：清算成本（律師+投行+遣散） | -$1-2 億 |
| 減：未決負債準備 | -$0.5 億 |
| **可分配給股東的總額** | **$14-18 億** |
| 每股清算價值（26M ADS） | **$54-69** |
| 當前股價 | **約 $14** |
| **股價 / 清算價值** | **20-26%** |

**當前股價只相當於清算價值的 20-26%。**

當然，清算不會發生——張朝陽不會主動關掉搜狐。但這個數字說明一件事：**即使你對搜狐的業務前景極度悲觀，它的資產仍然遠超市值。**

---

## 八、本篇核心結論

1. **搜狐賬上淨現金約 $11.5 億，是市值的 3.2 倍。** 即使扣除出境稅費、虧損準備、交易成本，調整後淨現金仍約 $8.4 億，是市值的 2.3 倍。

2. **暢遊遊戲獨立估值約 $8-12 億**，但市場給的隱含估值是負數。這意味著市場認為業務是"負擔"而非"資產"。

3. **分部加總合理估值 $14-22 億，市值只有 $3.6 億，折價 75-83%。** 這種折價程度在全球上市公司中極為罕見。

4. **折價的根本原因不是"市場不知道"，而是"市場不相信現金能到達股東手中"。** VIE 結構、管理層歷史、業務無增長、中概小盤股流動性困境——四重因素疊加。

5. **2025 年的 $1.5 億回購是關鍵正面信號**，但需要看到持續性才能真正改變折價。
